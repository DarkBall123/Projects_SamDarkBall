### Description

Checks if client has Map enabled in description.ext (*showMap* param) or force enabled with showMap command.

### Syntax

```sqf
**shownMap**
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (shownMap) then {hint "You have Map enabled"};
```
