## BIS fnc getVirtualItemCargo

- Source: https://community.bistudio.com/wiki/BIS_fnc_getVirtualItemCargo
- Revision: 348654
- Updated: 2023-11-08T13:48:25Z

- Availability: arma3 1.24
- Groups: Inventory

### Description

Get virtual items from an object (e.g., ammo box). Virtual items can be selected in the Arsenal.

### Syntax

```sqf
object call BIS_fnc_getVirtualItemCargo
```

### Parameters

- object: Object

### Return Value

- Array of Strings - all virtual items

### Examples

#### Example 1

```sqf
BIS_ammoBox call BIS_fnc_getVirtualItemCargo;
```
