## getPosATL

- Source: https://community.bistudio.com/wiki/getPosATL
- Revision: 377531
- Updated: 2026-01-02T06:53:14Z

- Availability: arma2 1.03, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Positions

### Description

Returns the position of an object relative to the terrain.

### Syntax

```sqf
getPosATL object
```

### Parameters

- object: Object

### Return Value

- PositionATL

### Examples

#### Example 1

```sqf
_objPosition = getPosATL player;
```
