These parameters can be configured by creating a new shortcut on your desktop and then adding the appropriate option in the target line.

For Steam version:
1. Choose the game shortcut in Library
1. Right click on the game
1. Select properties
1. Hit "Set launch options"
**Example**:
`C:\Program Files (x86)/Bohemia Interactive/Carrier Command Gaea Mission/carrier.exe" -nosplash`

Notice that the parameters are not inside the quotes, only the path ishttp://forums.bistudio.com/showthread.php?84780-nosplash.

### Available Parameters

There has been no official disclosure of available startup parameters for Carrier Command: Gaea Mission, apart from a post by a developer who confirmed http://forums.bistudio.com/showthread.php?140967-TOOL-CarrierTools-(modding-tool-inside)&p=2234275&viewfull=1#post2234275 the existence of -nosplash option
