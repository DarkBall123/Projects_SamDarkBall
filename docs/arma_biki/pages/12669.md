## setPitch

- Source: https://community.bistudio.com/wiki/setPitch
- Revision: 319600
- Updated: 2022-05-13T09:24:33Z

- Availability: arma3 1.02
- Locality: argument global, effect local
- Groups: Unit Identity, Sounds

### Description

Sets the pitch of a persons voice.

### Syntax

```sqf
person setPitch pitch
```

### Parameters

- person: Object
- pitch: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
unit1 setPitch 0.5;
```
