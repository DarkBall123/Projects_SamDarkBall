## wind

- Source: https://community.bistudio.com/wiki/wind
- Revision: 378404
- Updated: 2026-04-04T08:14:45Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Environment

### Description

Returns the current wind vector (in m/s).

### Syntax

```sqf
wind
```


### Return Value

- Vector3D - [x, y, 0]. with wind being only horizontal

### Examples

#### Example 1

```sqf
_windArray = wind;
```
