## getCustomSoundControllerCount

- Source: https://community.bistudio.com/wiki/getCustomSoundControllerCount
- Revision: 309206
- Updated: 2022-05-03T18:49:18Z

- Availability: arma3 1.86
- Groups: Sounds

### Description

Returns current number of custom sound controllers supported by the engine for the given vehicle (currently 32)

### Syntax

```sqf
getCustomSoundControllerCount vehicle
```

### Parameters

- vehicle: Object - a transport type vehicle. Does not work on characters or buildings

### Return Value

- Number - number of custom controllers

### Examples

#### Example 1

```sqf
getCustomSoundControllerCount vehicle player;
```
