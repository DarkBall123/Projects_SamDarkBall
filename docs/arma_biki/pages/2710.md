## formationTask

- Source: https://community.bistudio.com/wiki/formationTask
- Revision: 310864
- Updated: 2022-05-07T20:24:09Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Groups

### Description

Return the current task of the unit in the formation.

### Syntax

```sqf
formationTask unit
```

### Parameters

- unit: Object

### Return Value

- String: "EXCLUDED", "MOVE", "COVER", "LEADER", "NOTHING"

### Examples

#### Example 1

```sqf
_currentTask = formationTask _unit;
```
