## menuSetValue

- Source: https://community.bistudio.com/wiki/menuSetValue
- Revision: 378339
- Updated: 2026-04-02T16:31:15Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Sets new value into menu entry on given path.

### Syntax

```sqf
menuSetValue [idc, path, value]
```

```sqf
control menuSetValue [path, value]
```

### Parameters

- idc: Number
- path: Tree View Path
- value: Number
- control: Control
- path: Tree View Path
- value: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuSetValue [[0, 1], 1337];
```
