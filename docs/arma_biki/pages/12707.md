## addItemToBackpack

- Source: https://community.bistudio.com/wiki/addItemToBackpack
- Revision: 318688
- Updated: 2022-05-13T09:21:19Z

- Availability: arma3 1.04
- Locality: argument global, effect global
- Groups: Containers

### Description

Create new item and store it to soldier's backpack. The item can also be a weapon or a magazine.

### Syntax

```sqf
unit addItemToBackpack item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addItemToBackpack "arifle_MXM_Hamr_pointer_F";
```

#### Example 2

```sqf
player addItemToBackpack "itemGPS";
```
