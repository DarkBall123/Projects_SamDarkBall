## lookAtPos

- Source: https://community.bistudio.com/wiki/lookAtPos
- Revision: 377146
- Updated: 2026-01-01T10:33:39Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Point the camera and center the map on the position.
Some Old Editor Command

### Syntax

```sqf
map lookAtPos position
```

### Parameters

- map: Control
- position: Position

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
findDisplay 12 displayCtrl 51 lookAtPos [0,0,0];
```
