## setFSMVariable

- Source: https://community.bistudio.com/wiki/setFSMVariable
- Revision: 330070
- Updated: 2022-08-15T16:49:43Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Set variable to given value in the variable space of given FSM.

The FSM handle is the number returned by the execFSM command.

### Syntax

```sqf
handle setFSMVariable [name, value]
```

### Parameters

- handle: Number - FSM handle
- name: String - name of the FSM variable
- value: Anything - new value of the FSM variable

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_handle = execFSM "test.fsm";
_handle setFSMVariable ["_foo", 23]; // sets variable _foo in the FSM to 23
```
