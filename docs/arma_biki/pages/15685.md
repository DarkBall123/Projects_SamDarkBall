## BIS fnc parseNumber

- Source: https://community.bistudio.com/wiki/BIS_fnc_parseNumber
- Revision: 370223
- Updated: 2024-11-11T05:36:36Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math, Strings

### Description

Return number from expression

### Syntax

```sqf
value call BIS_fnc_parseNumber
```

### Parameters

- value: Number, String, Code or Config

### Return Value

- Number - parsed number, -1 if value is not a number

### Examples

#### Example 1

```sqf
private _result = 7.62 call BIS_fnc_parseNumber;
_result = "7.62" call BIS_fnc_parseNumber;
_result = { 7.62 } call BIS_fnc_parseNumber;
```

#### Example 2

```sqf
"[10,20,30]" call BIS_fnc_parseNumber; //returns [10,20,30]
```
