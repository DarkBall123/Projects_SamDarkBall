## commandFire

- Source: https://community.bistudio.com/wiki/commandFire
- Revision: 364826
- Updated: 2024-06-16T09:28:16Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Unit Control

### Description

Order the given unit to fire on the given target (via the radio).
If the target is objNull, the unit is ordered to fire on its current target (set with doTarget or commandTarget).

### Syntax

```sqf
unit commandFire target
```

### Parameters

- unit: Object of type Unit or Array of Units
- target: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ESoldier1 commandFire _WSoldier1;
```
