## addWaypoint

- Source: https://community.bistudio.com/wiki/addWaypoint
- Revision: 377574
- Updated: 2026-01-02T06:56:28Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Waypoints

### Description

Adds (or inserts when index is given) a new waypoint to a group.

The waypoint is placed randomly within a circle with the given center and radius.

For older titles and prior to Arma 3 v1.90, use setWaypointPosition if you need exact waypoint placement.

### Syntax

```sqf
groupName addWaypoint [center, radius, index, name]
```

### Parameters

- groupName: Group
- center: PositionAGL (PositionASL if *radius* is negative!) or Object
- radius: Number - random waypoint placement within *radius* from *center*; 1.90 -1 can be used for exact waypoint placement
- index: Number - (Optional, default -1) can be used to insert a waypoint in between existing waypoints; if it is invalid, the waypoint will be added at the end
- name: String - (Optional, default "") waypointName

### Return Value

- Waypoint

### Examples

#### Example 1

```sqf
_wp = _grp addWaypoint [position player, 0];
```

#### Example 2

```sqf
_wp = _grp addWaypoint [position player, 0];			// imprecise, placed like setVehiclePosition's "NONE" placement
_wp setWaypointPosition [getPosASL player, -1];			// from {{ofpe}} to Arma 3 v1.88

private _wp = _grp addWaypoint [getPosASL player, -1];	// Arma 3 v1.90+: precise placement
```
