## BIS fnc alignTabs

- Source: https://community.bistudio.com/wiki/BIS_fnc_alignTabs
- Revision: 328461
- Updated: 2022-07-13T16:11:04Z

- Availability: arma3 1.00
- Groups: Strings

### Description

Align two columns divided by tabs. A tab counts for 8 characters.

### Syntax

```sqf
array call BIS_fnc_alignTabs
```

### Parameters

- array: Array - in format

```sqf
[
	["left column 1", "right column 1"],
	["left column 2", "right column 2"],
	// ...
]
```

### Return Value

- String

### Examples

#### Example 1

```sqf
[
	["Player:", str player],
	["Name:", name player],
	["Type:", typeOf player],
	["Location:", str getPosATL player],
	["Direction:", str getDir player]
] call BIS_fnc_alignTabs;
```
