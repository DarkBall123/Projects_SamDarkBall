## addScore

- Source: https://community.bistudio.com/wiki/addScore
- Revision: 310138
- Updated: 2022-05-05T12:27:54Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global, server execution server
- Groups: Multiplayer

### Description

Adds a number to the score of a unit. Negative values will remove from the score.

### Multiplayer

Server execution only

### Syntax

```sqf
unit addScore score
```

### Parameters

- unit: Object
- score: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
unit addScore 10;
```

#### Example 2

```sqf
unit addScore -1337; // reduce the unit's score by 1337 points
```
