## setMarkerAlphaLocal

- Source: https://community.bistudio.com/wiki/setMarkerAlphaLocal
- Revision: 370053
- Updated: 2024-10-29T12:41:01Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Sets the marker alpha. See setMarkerAlpha.

### Syntax

```sqf
marker setMarkerAlphaLocal alpha
```

### Parameters

- marker: String
- alpha: Number - alpha value from 0 (invisible) to 1 (fully visible)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"my_marker" setMarkerAlphaLocal 0.5;
```

#### Example 2

```sqf
"enemy_convoy_marker" setMarkerAlphaLocal 0;
```

### See Also

setMarkerAlpha markerAlpha
