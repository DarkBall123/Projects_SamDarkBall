## ppEffectDestroy

- Source: https://community.bistudio.com/wiki/ppEffectDestroy
- Revision: 330371
- Updated: 2022-09-04T20:26:39Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Destroy Post Process Effects given by handle or array of handles.

### Syntax

```sqf
ppEffectDestroy effect
```

```sqf
ppEffectDestroy effects
```

### Parameters

- effect: Number - effect handle
- effects: Array of Numbers - array of effect handles

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
ppEffectDestroy _hndl;
```

#### Example 2

```sqf
ppEffectDestroy [_hndl0, _hndl1, _hndl2];
```
