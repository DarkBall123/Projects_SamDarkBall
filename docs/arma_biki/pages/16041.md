## BIS fnc startLoadingScreen

- Source: https://community.bistudio.com/wiki/BIS_fnc_startLoadingScreen
- Revision: 369455
- Updated: 2024-09-06T08:44:52Z

- Availability: arma3 0.58
- Groups: Systems

### Description

Register a loading screen. Start the loading when it is the first one registered.

The loading screen can be force-ended with the [ENDLOAD cheat code](Arma 3: Cheats#ENDLOAD).

### Syntax

```sqf
[screenId, layout] call BIS_fnc_startLoadingScreen
```

### Parameters

- screenId: String - screen ID, will be used in BIS_fnc_endLoadingScreen
- layout: String - loading text. *has no effect in Arma 3*

### Return Value

- Boolean - true when registered

### Examples

#### Example 1

```sqf
["myLoadingScreen", "Loading… wait for my splendid™ mission!"] call BIS_fnc_startLoadingScreen;
uiSleep 3;
"myLoadingScreen" call BIS_fnc_endLoadingScreen;
```
