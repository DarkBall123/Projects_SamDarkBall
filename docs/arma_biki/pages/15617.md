## BIS fnc variableSpaceAdd

- Source: https://community.bistudio.com/wiki/BIS_fnc_variableSpaceAdd
- Revision: 337310
- Updated: 2023-01-15T12:01:18Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Variables

### Description

Add element to variable from someone's variable space.

### Syntax

```sqf
[object, varName, element, global, inArray] call BIS_fnc_variableSpaceAdd
```

### Parameters

- object: Object - owner of variable space
- varName: String - name of variable
- element: Anything - element which will be added (must be of same type as variable)
- global: Boolean - (Optional, default false) true to save modified variable globally
- inArray: Boolean - (Optional, default false) true to check if element is already in variable (only for Arrays)

### Return Value

- Anything - updated variable

### Examples

#### Example 1

```sqf
[player, "someVar", 1337, true, true] call BIS_fnc_variableSpaceAdd;
```
