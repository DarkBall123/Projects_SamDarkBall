## get3DENConnections

- Source: https://community.bistudio.com/wiki/get3DENConnections
- Revision: 377333
- Updated: 2026-01-02T06:39:13Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns all connections currently present on an entity.

### Syntax

```sqf
get3DENConnections  entity
```

### Parameters

- entity: Eden Entity or Eden ID

### Return Value

- Array format: `[[type1, to1], [type2, to2], ..., [typeN, toN]]`
* type: String - connection class from *Cfg3DEN >> Connections*
* to: Eden Entity: Entitiy the connection leads to

### Examples

#### Example 1

```sqf
get3DENConnections _trigger; // Can return "WaypointActivation",[B Alpha 4-5,0]
```
