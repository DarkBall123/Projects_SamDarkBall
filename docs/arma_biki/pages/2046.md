## setLightBrightness

- Source: https://community.bistudio.com/wiki/setLightBrightness
- Revision: 376672
- Updated: 2025-11-04T00:17:20Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Lights

### Description

Set brightness of light. Does nothing for light reflector, for light point the formula is setLightIntensity ((brightness * 50) ^ 2)
This command is outdated. Use setLightIntensity instead.

### Syntax

```sqf
light setLightBrightness brightness
```

### Parameters

- light: Object
- brightness: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLight setLightBrightness 2;
```
