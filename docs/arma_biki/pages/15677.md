## BIS fnc arithmeticMean

- Source: https://community.bistudio.com/wiki/BIS_fnc_arithmeticMean
- Revision: 338181
- Updated: 2023-02-23T23:53:44Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

Returns the [arithmetic mean](https://en.wikipedia.org/wiki/Mean#Arithmetic_mean_(AM)) ("average value") of an array of numbers.

### Syntax

```sqf
numbers call BIS_fnc_arithmeticMean
```

### Parameters

- numbers: Array of Numbers - must not be empty

### Return Value

- Number - arithmetic mean

### Examples

#### Example 1

```sqf
[1, 3] call BIS_fnc_arithmeticMean; // returns 2
```

#### Example 2

```sqf
[1, 9, 8, 2] call BIS_fnc_arithmeticMean; // returns 5
```
