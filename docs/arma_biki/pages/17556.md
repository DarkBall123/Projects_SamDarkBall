## get3DENMouseOver

- Source: https://community.bistudio.com/wiki/get3DENMouseOver
- Revision: 377713
- Updated: 2026-01-02T09:03:54Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns the Eden Entity the mouse is hovering over in Eden Editor.

### Syntax

```sqf
get3DENMouseOver
```


### Return Value

- Array with [type, entity]

* type: String - can be one of:
** "Object"
** "Group"
** "Trigger"
** "Logic"
** "Waypoint"
** "Marker"
* entity: Eden Entity

### Examples

#### Example 1

```sqf
systemChat str get3DENMouseOver; // returns e.g ["Object", B Alpha 1-1:1]
```
