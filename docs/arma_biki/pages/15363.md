## vectorDiff

- Source: https://community.bistudio.com/wiki/vectorDiff
- Revision: 377116
- Updated: 2026-01-01T10:12:56Z

- Availability: arma3 1.22
- Groups: Math - Vectors

### Description

Subtracts one 3D vector from another. (vector1 - vector2)

arma3|2.14|Since 2.14 any count of numbers is valid, if one array is larger than the other, the remaining elements are inserted without change.

Before 2.14, the first argument had to be vector 3D, or 2.00 2D (Which still returned 3D result, with z coordinate defaulted to 0)

### Syntax

```sqf
vector1 vectorDiff vector2
```

### Parameters

- vector1: Array of Numbers
- vector2: Array of Numbers

### Return Value

- Array of Numbers

### Examples

#### Example 1

```sqf
hint str (velocity car vectorDiff velocity bike);
```
