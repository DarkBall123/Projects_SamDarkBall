## formation

- Source: https://community.bistudio.com/wiki/formation
- Revision: 348443
- Updated: 2023-11-08T13:00:16Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Groups

### Description

Returns the current formation of a group.

### Syntax

```sqf
formation  target
```

### Parameters

- target: Object or Group

### Return Value

- String - can return:
{{Columns|3|
* "COLUMN"
* "STAG COLUMN"
* "WEDGE"
* "ECH LEFT"
* "ECH RIGHT"
* "VEE"
* "LINE"
* "FILE"
* "DIAMOND"
}}

### Examples

#### Example 1

```sqf
if (formation group player == "wedge") then { hint "this is the default formation" };
```
