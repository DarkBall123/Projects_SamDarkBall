## enableAI

- Source: https://community.bistudio.com/wiki/enableAI
- Revision: 369964
- Updated: 2024-10-22T12:39:51Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: AI Behaviour

### Description

Enables parts of the AI behavior that was disabled by disableAI. 
When player switches and leaves behind AI unit, you need to enable "TeamSwitch" AI on it 

```sqf
_unit enableAI "TeamSwitch";
```

 so that the unit continues with waypoints.
Since Arma 3 v1.96 it is possible to return the state of the given AI flag via checkAIFeature or set it using alias command enableAIFeature.

### Syntax

```sqf
unit enableAI skilltype
```

### Parameters

- unit: Object
- skilltype: String - see disableAI for possible values.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldierOne enableAI "Move";
```
