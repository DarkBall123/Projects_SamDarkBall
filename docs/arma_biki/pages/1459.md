## ! a

- Groups: Variables, Math

### Description

Returns the negation of a Boolean expression. This means `true` becomes `false` and vice versa.

### Syntax

```sqf
! a
```

### Parameters

- a: Boolean

### Return Value

- Boolean

### Examples

#### Example 1

The code

```sqf
private _isAlive = alive player;
if (!_isAlive) then
{
	hint "The player is dead!";
};
```

is the same as

```sqf
private _isAlive = alive player;
if (not _isAlive) then
{
	hint "The player is dead!";
};
```
