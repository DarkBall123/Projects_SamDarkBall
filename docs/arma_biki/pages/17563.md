## is3DEN

- Source: https://community.bistudio.com/wiki/is3DEN
- Revision: 376878
- Updated: 2025-12-15T11:17:30Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns true if the Eden Editor is currently being used.

### Syntax

```sqf
is3DEN
```


### Return Value

- Boolean - true when inside editor environment, false when outside of editor environment

### Examples

#### Example 1

```sqf
if is3DEN then { systemChat "Welcome to Eden Editor!" };
```
