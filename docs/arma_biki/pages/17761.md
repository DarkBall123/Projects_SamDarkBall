## isSprintAllowed

- Source: https://community.bistudio.com/wiki/isSprintAllowed
- Revision: 341802
- Updated: 2023-06-24T08:22:53Z

- Availability: arma3 1.54
- Locality: argument local
- Groups: Stamina System

### Description

Returns true if player is allowed to sprint

### Syntax

```sqf
isSprintAllowed unit
```

### Parameters

- unit: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (not isSprintAllowed player) then { hint "no running in the corridors!" };
```
