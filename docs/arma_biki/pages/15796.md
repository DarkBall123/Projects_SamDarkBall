## BIS fnc shutdown

- Source: https://community.bistudio.com/wiki/BIS_fnc_shutdown
- Revision: 309424
- Updated: 2022-05-05T12:04:37Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Diagnostic

### Description

Shut downs the game.
this function will only close the game once back to the main menu.

### Syntax

```sqf
call BIS_fnc_shutdown
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_shutdown;
```
