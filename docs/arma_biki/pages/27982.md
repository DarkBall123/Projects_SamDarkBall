## diag exportConfig

- Source: https://community.bistudio.com/wiki/diag_exportConfig
- Revision: 349240
- Updated: 2023-11-08T14:50:57Z

- Availability: arma3 2.02
- Groups: Diagnostic, Config

### Description

Exports given config into file of given path.

### Syntax

```sqf
diag_exportConfig [path, config]
```

### Parameters

- path: String - file path on disc
- config: Config - the config you would like to export

### Return Value

- Nothing

### Examples

#### Example 1

export an All-in-One config:

```sqf
diag_exportConfig ["O:/config.cpp", configFile];
```
