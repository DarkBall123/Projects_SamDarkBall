## isVehicleRadarOn

- Source: https://community.bistudio.com/wiki/isVehicleRadarOn
- Revision: 310732
- Updated: 2022-05-07T20:04:21Z

- Availability: arma3 1.72
- Groups: Sensors

### Description

Returns true if vehicle has active sensors on.

### Syntax

```sqf
isVehicleRadarOn vehicle
```

### Parameters

- vehicle: Object - vehicle on which check is performed

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
isVehicleRadarOn vehicle player; // returns true if radar is turned on
```
