## freeLook

- Source: https://community.bistudio.com/wiki/freeLook
- Revision: 369220
- Updated: 2024-09-03T10:34:54Z

- Availability: arma3 0.50
- Groups: Object Manipulation

### Description

Returns if freelook is active on the current machine's controlled character.

### Syntax

```sqf
freeLook
```


### Return Value

- Boolean - true if freelook is active, false otherwise

### Examples

#### Example 1

```sqf
if freeLook then
{
	systemChat "Quit looking around, soldier!";
};
```
