## a = b

- Source: https://community.bistudio.com/wiki/a_%3D_b
- Revision: 348661
- Updated: 2023-11-08T13:49:04Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Variables

### Description

Assigns the result of expression on the right to the variable on the left. Technically this is not a command and it is not listed in supportInfo; this is more of a compiler instruction.
The following structure is invalid: 

```sqf
a = b = c = 4;
```

.

### Syntax

```sqf
variable = value
```

### Parameters

- variable: Anything - see Identifier
- value: Anything

### Return Value

- Nothing The returned value is not equivalent to nil. See #Notes below for additional information.

### Examples

#### Example 1

```sqf
_value = 5;
```

#### Example 2

```sqf
_mygroup = group player;
```

#### Example 3

```sqf
_greeting = "Hello!";
```

#### Example 4

```sqf
private _enemyTank = myTank1;
```

{{Note
|user= Dedmen
|timestamp= 20161109002900
|text= This operator actually does not return a Nil. It really returns pure Nothing. Not Nil Nothing.

This can cause problems. For example:

```sqf
_var1 = call {
	_var2 = "";
};
```

The return value of the "call" is the return value of the "{{=}}" operator.

If it were a nil then of cause "_var {{=}} nil;" would work just fine.

But in reality this causes a "Generic Error in expression" because you can't assign pure Nothing to anything
