## vehicleReceiveRemoteTargets

- Source: https://community.bistudio.com/wiki/vehicleReceiveRemoteTargets
- Revision: 311075
- Updated: 2022-05-07T20:59:23Z

- Availability: arma3 1.70
- Groups: Sensors

### Description

Gets whether the vehicle can acquire targets via datalink from the Side center.

### Syntax

```sqf
vehicleReceiveRemoteTargets vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
vehicleReceiveRemoteTargets vehicle player;
```
