## BIS fnc VRDrawBorder

- Source: https://community.bistudio.com/wiki/BIS_fnc_VRDrawBorder
- Revision: 348816
- Updated: 2023-11-08T14:38:18Z

- Availability: arma3 1.24
- Groups: VR

### Description

Visualizes area border (used primarily for VR missions).

### Syntax

```sqf
[center, radius] call BIS_fnc_VRDrawBorder
```

### Parameters

- center: Position - center position
- radius: Number - radius

### Return Value

- Array - list of created objects for easy deletion

### Examples

#### Example 1

```sqf
[[0,0,0], 200] call BIS_fnc_VRDrawBorder;
```
