## worldToModelVisual

- Source: https://community.bistudio.com/wiki/worldToModelVisual
- Revision: 377846
- Updated: 2026-01-03T04:37:17Z

- Availability: arma3 1.32
- Groups: Positions, Render Time Scope

### Description

Converts position from world space to object model space in render time scope.
For scaled objects, the relative position will be divided by the object scale.

### Syntax

```sqf
object worldToModelVisual worldPosition
```

### Parameters

- object: Object
- worldPosition: PositionAGL or Position2D

### Return Value

- PositionRelative

### Examples

#### Example 1

```sqf
_relPos = myObject worldToModelVisual [0,0,0];
```

#### Example 2

```sqf
_relPos = player worldToModelVisual position car;
```

#### Example 3

```sqf
_relPos = car worldToModelVisual [12000, 5000];
```

#### Example 4

```sqf
_relPos = unit worldToModelVisual position tank;
```
