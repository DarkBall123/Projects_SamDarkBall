## BIS fnc timeline setLoop

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_setLoop
- Revision: 310501
- Updated: 2022-05-06T11:02:18Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Set's this timeline playback loop mode

### Syntax

```sqf
[timeline, loop] call BIS_fnc_timeline_setLoop
```

### Parameters

- timeline: Object - the timeline object
- loop: Boolean - (Optional, default true) true to enable loop, false to disable

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[timeline] call BIS_fnc_timeline_setLoop;
```
