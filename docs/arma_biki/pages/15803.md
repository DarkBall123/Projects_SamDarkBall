## BIS fnc GUIgrid

- Source: https://community.bistudio.com/wiki/BIS_fnc_GUIgrid
- Revision: 348772
- Updated: 2023-11-08T14:33:15Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Returns grid params and stores it into uiNamespace.

### Syntax

```sqf
[category, grid] call BIS_fnc_GUIgrid
```

### Parameters

- category: String - (Optional, default "GUI") category name
- grid: String - (Optional, default "GRID") grid name

### Return Value

- Array - in format [<nowiki/>[x,y,w,h],gridW,gridH]

### Examples

#### Example 1

```sqf
call BIS_fnc_GUIgrid; //[-0.452381,0.214286,1.2,1]
```
