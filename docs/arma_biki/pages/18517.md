## vehicleReportOwnPosition

- Source: https://community.bistudio.com/wiki/vehicleReportOwnPosition
- Revision: 311076
- Updated: 2022-05-07T20:59:46Z

- Availability: arma3 1.70
- Groups: Sensors

### Description

Gets whether the vehicle shares its own position via datalink with the Side center.

### Syntax

```sqf
vehicleReportOwnPosition vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
vehicleReportOwnPosition vehicle player;
```
