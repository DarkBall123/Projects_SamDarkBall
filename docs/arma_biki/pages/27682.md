## isNotEqualTo

- Source: https://community.bistudio.com/wiki/isNotEqualTo
- Revision: 330347
- Updated: 2022-09-02T12:25:54Z

- Availability: arma3 2.02
- Groups: Variables

### Description

Performs strict comparison between var1 and var2 and returns false if equal, otherwise true.

### Syntax

```sqf
val1 isNotEqualTo val2
```

### Parameters

- val1: Anything
- val2: Anything

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _true = 0 isNotEqualTo 1;
```
