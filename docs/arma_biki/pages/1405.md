## behaviour

- Source: https://community.bistudio.com/wiki/behaviour
- Revision: 369334
- Updated: 2024-09-03T18:43:00Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: AI Behaviour

### Description

Returns the behaviour of the individual unit, this is why it only accepts Object as the argument. For Arma 3 behaviour explanation see Arma_3_AI_Behavior

### Syntax

```sqf
behaviour unit
```

### Parameters

- unit: Object

### Return Value

- String - one of:
* "CARELESS"
* "SAFE"
* "AWARE"
* "COMBAT"
* "STEALTH"
* "ERROR" (Since 1.78 when used on empty vehicles and such)

### Examples

#### Example 1

```sqf
_soldier setBehaviour "CARELESS";
_b = behaviour _soldier; // returns "CARELESS"
```
