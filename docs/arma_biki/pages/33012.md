## ctrlURLOverlayMode

- Source: https://community.bistudio.com/wiki/ctrlURLOverlayMode
- Revision: 330165
- Updated: 2022-08-23T12:23:58Z

- Availability: arma3 2.10
- Groups: GUI Control

### Description

Returns the URL overlay mode 0, 1, 2 (see ctrlSetURLOverlayMode) or -1 if something went wrong.

### Syntax

```sqf
ctrlURLOverlayMode control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_mode = ctrlURLOverlayMode _control; // e.g. 0
```

### See Also

ctrlSetURLOverlayMode ctrlURL isSteamOverlayEnabled
