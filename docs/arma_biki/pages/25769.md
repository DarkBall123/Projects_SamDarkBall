## decayGraphValues

- Source: https://community.bistudio.com/wiki/decayGraphValues
- Revision: 309184
- Updated: 2022-05-03T18:08:43Z

- Availability: arma3 1.92
- Groups: Math

### Description

Multiplies graph values by the given coefficient. The corresponding lower bound value is used instead if the product is smaller than the bound.

### Syntax

```sqf
decayGraphValues [lowerBoundValues, graphValues, coef]
```

### Parameters

- lowerBoundValues: Array of Numbers - lower bound for the new graph
- graphValues: Array of Numbers - graph values
- coef: Number - the multiplication coefficient

### Return Value

- Array of Numbers

### Examples

#### Example 1

```sqf
decayGraphValues [[1,2,3,4,5], [1,4,9,16,25], 0.3]; // returns [1,2,3,4.8,7.5]
```
