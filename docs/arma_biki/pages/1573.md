## fillWeaponsFromPool

- Source: https://community.bistudio.com/wiki/fillWeaponsFromPool
- Revision: 309937
- Updated: 2022-05-05T12:16:59Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool

### Description

Adds magazines from the campaign pool to the given unit, depending on his weapons. Available in campaigns only.

### Syntax

```sqf
fillWeaponsFromPool  unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
fillWeaponsFromPool _soldier;
```
