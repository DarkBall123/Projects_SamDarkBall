## focusedCtrl

- Source: https://community.bistudio.com/wiki/focusedCtrl
- Revision: 348589
- Updated: 2023-11-08T13:42:42Z

- Availability: arma3 2.04
- Groups: GUI Control

### Description

Returns display's focused control.

### Syntax

```sqf
focusedCtrl display
```

### Parameters

- display: Display - parent display

### Return Value

- Control - control which has focus

### Examples

#### Example 1

```sqf
private _focusedCtrl = focusedCtrl findDisplay 12;
```

#### Example 2

```sqf
private _isFocused = focusedCtrl _display == _ctrl;
```

#### Example 3

```sqf
private _isFocused = focusedCtrl (ctrlParent _ctrl) == _ctrl;
```
