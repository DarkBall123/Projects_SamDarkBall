## setWaypointLoiterType

- Source: https://community.bistudio.com/wiki/setWaypointLoiterType
- Revision: 319603
- Updated: 2022-05-13T09:24:33Z

- Availability: arma3 1.00
- Groups: Waypoints

### Description

Sets the waypoint loiter type.

### Syntax

```sqf
waypoint setWaypointLoiterType type
```

### Parameters

- waypoint: Waypoint
- type: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointLoiterType "CIRCLE";
```

#### Example 2

```sqf
[_grp, 2] setWaypointLoiterType "CIRCLE_L";
```
