## BIS fnc camera getCinemaBordersEnabled

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_getCinemaBordersEnabled
- Revision: 349202
- Updated: 2023-11-08T14:50:43Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Check if camera uses cinema borders.

### Syntax

```sqf
[camera] call BIS_fnc_camera_getCinemaBordersEnabled
```

### Parameters

- camera: Object - the camera

### Return Value

- Boolean - returns true if cinema borders are used

### Examples

#### Example 1

```sqf
[BIS_camera] call BIS_fnc_camera_getCinemaBordersEnabled;
```
