## civilian

- Revision: 343875
- Updated: 2023-07-27T16:10:26Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Sides

### Description

Pre-defined variable for the civilian side.

When used in a format statement (

```sqf
hint format ["%1", civilian]
```

), the string returned is `"CIV"`.

### Syntax

```sqf
civilian
```


### Return Value

- Side

### Examples

#### Example 1

SQS:
<sqs>? side _unit == civilian : hint "This is a civilian unit!"</sqs>

#### Example 2

SQF:

```sqf
if (side _unit == civilian) then
{
	hint "This is a civilian unit!";
};
```
