## getPilotCameraOpticsMode

- Source: https://community.bistudio.com/wiki/getPilotCameraOpticsMode
- Revision: 349193
- Updated: 2023-11-08T14:50:40Z

- Availability: arma3 2.14
- Locality: argument local
- Groups: Pilot Camera

### Description

Returns the optics mode index (zoom) for the pilotCamera

### Syntax

```sqf
getPilotCameraOpticsMode object
```

### Parameters

- object: Object

### Return Value

- Number - the index of the optic mode

### Examples

#### Example 1

```sqf
getPilotCameraOpticsMode vehicle player
```
