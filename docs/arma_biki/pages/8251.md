## evalObjectArgument

- Source: https://community.bistudio.com/wiki/evalObjectArgument
- Revision: 376410
- Updated: 2025-10-11T01:02:41Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Return argument in mission editor of a given object. 
Some Old Editor Command

### Syntax

```sqf
map evalObjectArgument [object, argument]
```

### Parameters

- map: Control
- object: String
- argument: String

### Return Value

- Anything

### Examples

#### Example 1

```sqf
// returns string "[1009.0351, 1319.4928]"
(findDisplay 128 displayCtrl 51) getObjectArgument ["_unit_1", "POSITION"];

// returns array [1009.0351, 1319.4928]
(findDisplay 128 displayCtrl 51) evalObjectArgument ["_unit_1", "POSITION"];
```
