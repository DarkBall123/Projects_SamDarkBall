## setGroupIconsSelectable

- Source: https://community.bistudio.com/wiki/setGroupIconsSelectable
- Revision: 349137
- Updated: 2023-11-08T14:49:45Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Sets if group icons raise onGroupIconClick, onGroupIconOverEnter and onGroupIconOverLeave events.

### Syntax

```sqf
setGroupIconsSelectable selectable
```

### Parameters

- selectable: Boolean - setting to true makes the icon selectable

### Return Value

- Nothing (objNull prior to Arma 3 v1.92)

### Examples

#### Example 1

```sqf
setGroupIconsSelectable true;
```
