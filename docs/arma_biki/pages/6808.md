## toUpper

- Source: https://community.bistudio.com/wiki/toUpper
- Revision: 308976
- Updated: 2022-04-21T14:52:14Z

- Availability: arma1 1.09, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Strings

### Description

Converts the supplied Unicode string to all uppercase characters. If the string doesn't have characters with codes > 255, use toUpperANSI.

### Syntax

```sqf
toUpper string
```

### Parameters

- string: String

### Return Value

- String

### Examples

#### Example 1

```sqf
hint toUpper "AaBb1"; // returns "AABB1"
```
