## BIS fnc debugConsoleExec

- Source: https://community.bistudio.com/wiki/BIS_fnc_debugConsoleExec
- Revision: 348453
- Updated: 2023-11-08T13:00:17Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Executes Debug Console code.

### Syntax

```sqf
[target, code] call BIS_fnc_debugConsoleExec
```

### Parameters

- target: Number - 
*0 - local
*1 - global
*2 - server
- code: Code - code to be executed

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[1,{hint "Hello Players!"}] call BIS_fnc_debugConsoleExec;
```
