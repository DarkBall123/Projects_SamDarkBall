## is3DENPreview

- Source: https://community.bistudio.com/wiki/is3DENPreview
- Revision: 342107
- Updated: 2023-07-09T12:26:36Z

- Availability: arma3 2.00
- Groups: Eden Editor

### Description

Returns true if the Eden Editor is currently in mission preview mode, single player or multiplayer. (see also is3DEN, is3DENMultiplayer)

### Syntax

```sqf
is3DENPreview
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if is3DENPreview then { systemChat "Welcome to Eden Editor Preview!" };
```
