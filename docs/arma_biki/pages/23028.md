## getTrimOffsetRTD

- Source: https://community.bistudio.com/wiki/getTrimOffsetRTD
- Revision: 348915
- Updated: 2023-11-08T14:44:04Z

- Availability: arma3 1.34
- Groups: RTD

### Description

Returns controls trim offset.{{Feature|afm}}

### Syntax

```sqf
getTrimOffsetRTD RTD_helicopter
```

### Parameters

- RTD_helicopter: Object - helicopter with advanced flight model enabled

### Return Value

- Array - offsets in format [x,y,z]

### Examples

#### Example 1

```sqf
_array = getTrimOffsetRTD vehicle player;
```
