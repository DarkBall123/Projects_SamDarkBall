## playerRespawnTime

- Source: https://community.bistudio.com/wiki/playerRespawnTime
- Revision: 353208
- Updated: 2024-03-12T13:57:45Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Multiplayer

### Description

Return the player's remaining time before respawn, or -1 if it is not available (such as when the player is alive).

### Syntax

```sqf
**playerRespawnTime**
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
waitUntil { playerRespawnTime <= 0 };
```

### See Also
