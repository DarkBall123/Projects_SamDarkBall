## BIS fnc halo

- Source: https://community.bistudio.com/wiki/BIS_fnc_halo
- Revision: 327955
- Updated: 2022-07-13T13:04:47Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Systems

### Description

Makes a High Altitude Low Opening (HALO) parachute jump.
HALO feature is already implemented in Arma 3. Using this function will result in incorrect behaviour and animation.

### Syntax

```sqf
[unit, altitude] call BIS_fnc_halo
```

### Parameters

- unit: Object - the HALO-performing unit
- altitude: Number - (Optional, default 0) altitude added to the unit before HALO

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_halo; // instantly parachutes the player object
```

#### Example 2

```sqf
[player, 100] call BIS_fnc_halo; // increases the altitude of player by 100 before HALO
```
