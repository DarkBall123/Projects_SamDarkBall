## BIS fnc interpolate

- Source: https://community.bistudio.com/wiki/BIS_fnc_interpolate
- Revision: 349224
- Updated: 2023-11-08T14:50:50Z

- Availability: arma3 1.78
- Groups: Interpolation

### Description

Interpolates scalar to target, starts fast, eases out

### Syntax

```sqf
[currentValue, targetValue, delta, interpSpeed] call BIS_fnc_interpolate
```

### Parameters

- currentValue: Number - the current value
- targetValue: Number - the target value
- delta: Number - (Optional, default 0) the delta time
- interpSpeed: Number - (Optional, default 0) the interpolation speed

### Return Value

- Number - the interpolated value

### Examples

#### Example 1

```sqf
private _value = [4,8,0.2,0.1] call BIS_fnc_interpolate;
```
