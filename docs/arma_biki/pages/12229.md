## weaponCargo

- Source: https://community.bistudio.com/wiki/weaponCargo
- Revision: 310284
- Updated: 2022-05-05T13:11:26Z

- Availability: arma3 0.50
- Groups: Vehicle Inventory, Unit Inventory, Containers

### Description

Get array with weapons from ammo box (or any general weapon holder container).

### Syntax

```sqf
weaponCargo box
```

### Parameters

- box: Object

### Return Value

- Array of String - list of present classes

### Examples

#### Example 1

```sqf
hint str weaponCargo backpackContainer player;
```
