## diag resetAnims

- Source: https://community.bistudio.com/wiki/diag_resetAnims
- Revision: 353741
- Updated: 2024-03-22T13:45:12Z

- Availability: arma3 2.16
- Groups: Diagnostic

### Description

Resets the animations system cache, so that animation makers can test their animations without restarting the game. A **mission restart** is required for the changes to be applied.

### Syntax

```sqf
diag_resetAnims
```


### Return Value

- Nothing
