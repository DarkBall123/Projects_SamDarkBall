## backpackCargo

- Source: https://community.bistudio.com/wiki/backpackCargo
- Revision: 378396
- Updated: 2026-04-04T07:57:43Z

- Availability: arma3 0.50
- Groups: Containers

### Description

Get array with backpacks from ammo box (or any general weapon holder container).

### Syntax

```sqf
backpackCargo box
```

### Parameters

- box: Object

### Return Value

- Array of Strings - class names ["BackpackType1", "BackpackType1", "BackpackType2", ...]

### Examples

#### Example 1

```sqf
hint str backpackCargo vehicle player;
```
