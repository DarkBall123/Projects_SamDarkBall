## BIS fnc taskSetAlwaysVisible

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskSetAlwaysVisible
- Revision: 376121
- Updated: 2025-08-31T21:33:19Z

- Availability: arma3 1.58
- Locality: argument global, effect global
- Groups: Tasks

### Description

Flags task to be or not to be always visible. See Arma 3: Task Framework for more information.

### Syntax

```sqf
[taskID, alwaysVisible] call BIS_fnc_taskSetAlwaysVisible
```

### Parameters

- taskID: String - task ID
- alwaysVisible: Boolean - true for always visible false if not

### Return Value

- String - task ID.

### Examples

#### Example 1

```sqf
["BIS_Task_01", true] call BIS_fnc_taskSetAlwaysVisible;
```
