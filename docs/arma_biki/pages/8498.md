## waypointFormation

- Source: https://community.bistudio.com/wiki/waypointFormation
- Revision: 377745
- Updated: 2026-01-03T00:57:56Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Gets the waypoint formation.

Possible values are: 
* "NO CHANGE"
* "COLUMN"
* "STAG COLUMN"
* "WEDGE"
* "ECH LEFT"
* "ECH RIGHT"
* "VEE"
* "LINE"
* "FILE"
* "DIAMOND"

### Syntax

```sqf
waypointFormation waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- String

### Examples

#### Example 1

```sqf
waypointFormation [groupOne,1];
```
