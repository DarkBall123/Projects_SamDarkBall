## ctrlSetFontH1B

- Source: https://community.bistudio.com/wiki/ctrlSetFontH1B
- Revision: 318797
- Updated: 2022-05-13T09:21:51Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H1 bold font of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontH1B fontName
```

### Parameters

- controlName: Control
- fontName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontH1B "TahomaB";
```
