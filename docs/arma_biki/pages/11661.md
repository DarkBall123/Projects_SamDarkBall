## setTrafficDensity

- Source: https://community.bistudio.com/wiki/setTrafficDensity
- Revision: 310000
- Updated: 2022-05-05T12:20:39Z

- Availability: tkoh 1.01, arma3 0.50
- Groups: Environment

### Description

Set the density of ambient cars in a rectangle (in cars per kilometer). This command does nothing in Arma 3.

### Syntax

```sqf
setTrafficDensity [density, xMin, xMax, zMin, zMax]
```

### Parameters

- density: Number - density (in cars per kilometer)
- xMin: Number - western border of the affected rectangle
- xMax: Number - eastern border of the affected rectangle
- zMin: Number - southern border of the affected rectangle
- zMax: Number - northern border of the affected rectangle

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setTrafficDensity [40, 31000, 32000, 30000, 32000];
```
