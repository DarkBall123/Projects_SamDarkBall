## unitAddons

- Source: https://community.bistudio.com/wiki/unitAddons
- Revision: 378475
- Updated: 2026-04-24T11:31:38Z

- Availability: arma3 1.00
- Groups: Mods and Addons

### Description

Returns list with addons the unit belongs to.

### Syntax

```sqf
unitAddons className
```

### Parameters

- className: String - class name of a unit/vehicle or object

### Return Value

- Array of Strings - addon names

### Examples

#### Example 1

```sqf
hint str unitAddons typeOf player; // ["A3_Characters_F_BLUFOR"]
```

# From Arma 3 1.14 

```sqf
hint str ([player] call BIS_fnc_unitAddon) // same as unitAddons (typeOf player)
```

# To return the addon that a weapon belongs to, use BIS_fnc_weaponAddon instead. E.g. 

```sqf
(primaryWeapon player call BIS_fnc_weaponAddon); // return: "A3_Weapons_F_Rifles_Khaybar"
```
