## getFieldManualStartPage

- Source: https://community.bistudio.com/wiki/getFieldManualStartPage
- Revision: 377874
- Updated: 2026-01-04T13:13:54Z

- Availability: arma3 1.18
- Groups: System

### Description

Returns array of the starting topic and hint the given field manual should display.

### Syntax

```sqf
getFieldManualStartPage display
```

### Parameters

- display: Display

### Return Value

- Array with [startingTopic, hint]

* startingTopic: String
* hint: String

### Examples

#### Example 1

```sqf
getFieldManualStartPage (findDisplay 46); // returns ["", ""]
```
