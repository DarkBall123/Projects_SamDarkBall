## set3DENSelected

- Source: https://community.bistudio.com/wiki/set3DENSelected
- Revision: 352152
- Updated: 2024-02-01T23:25:20Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Changes selection in Eden Editor to what is inside entities array. This command will trigger the 3DEN event handler **"OnSelectionChange"**. Do not use it inside this event handler!

### Syntax

```sqf
set3DENSelected entities
```

### Parameters

- entities: Array of Eden Entity or Eden ID

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
set3DENSelected [0,5,3,6,7,12];
```
