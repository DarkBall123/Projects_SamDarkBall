## selectRandom

- Source: https://community.bistudio.com/wiki/selectRandom
- Revision: 377101
- Updated: 2026-01-01T09:58:32Z

- Availability: arma3 1.56
- Groups: Arrays

### Description

Returns a random element from the given array. Engine solution to BIS_fnc_selectRandom

### Syntax

```sqf
selectRandom array
```

### Parameters

- array: Array of Anything

### Return Value

- Anything - random selected value or Nothing if array is empty

### Examples

#### Example 1

```sqf
_randomElement = selectRandom [1,2,3,4,5];
```
