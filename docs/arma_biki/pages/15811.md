## BIS fnc displayMission

- Source: https://community.bistudio.com/wiki/BIS_fnc_displayMission
- Revision: 329370
- Updated: 2022-07-27T12:33:56Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Returns main display of current mission/intro/outro. A cleaner alternative to 

```sqf
findDisplay 46
```

.

### Syntax

```sqf
call BIS_fnc_displayMission
```


### Return Value

- Display

### Examples

#### Example 1

```sqf
_mainDisplay = call BIS_fnc_displayMission;
```
