## BIS fnc boundingCircle

- Source: https://community.bistudio.com/wiki/BIS_fnc_boundingCircle
- Revision: 327119
- Updated: 2022-07-12T21:44:51Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns size of bounding circle (calculated from X and Y coordinates). This is actually the 2D horizontal diagonal length of the boundingBox.

### Syntax

```sqf
object call BIS_fnc_boundingCircle
```

### Parameters

- object: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
vehicle player call BIS_fnc_boundingCircle;
```
