## BIS fnc dbClassSet

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbClassSet
- Revision: 349511
- Updated: 2023-11-08T17:09:15Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Add class to Scripted Database. The function modifies the passed array and returns a success flag.

### Syntax

```sqf
[database, path, (value)] call BIS_fnc_dbClassSet
```

### Parameters

- database: Array - database array
- path: Array - path to class
- value: Array - (Optional, default 

```sqf
[]
```

) the class' values

### Return Value

- Boolean: True if class was added

### Examples

#### Example 1

```sqf
private _db = ["#MILLER", ["&KILLS", 1000], "#TERRA", ["&WEAPON", "MX 6.5mm"]];
[_db, ["kavala"], ["&POPULATION", 42]] call BIS_fnc_dbClassSet;
_db // ["#MILLER",["&KILLS",1000],"#TERRA",["&WEAPON","MX 6.5mm"],"#KAVALA",["&POPULATION",42]]
```
