## do3DENAction

- Source: https://community.bistudio.com/wiki/do3DENAction
- Revision: 378238
- Updated: 2026-03-20T14:10:01Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Performs given Eden Editor action.
Prior to 2.12 it was possible to use this command outside of Eden Editor.

For example 

```sqf
do3DENAction "MissionSave";
```

 would wipe the mission.sqm without a way to restore it when executed accidentally during preview.

### Syntax

```sqf
do3DENAction action
```

```sqf
do3DENAction [action, argument]
```

### Parameters

- action: String - see Eden Editor: Actions
- action: String - see Eden Editor: Actions
- argument: Anything - depends on the used action

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
do3DENAction "MissionSave";
```

#### Example 2

```sqf
// Since 2.22
private _par = createHashMap;
_par set ["name", "testfile"];
_par set ["folder", "subfolder"];
_par set ["content", "R3voing"];

do3DENAction ["CreateTextFile", _par];
```
