## BIS fnc removeVirtualMagazineCargo

- Source: https://community.bistudio.com/wiki/BIS_fnc_removeVirtualMagazineCargo
- Revision: 363530
- Updated: 2024-04-03T23:02:44Z

- Availability: arma3 1.24
- Groups: Inventory

### Description

Remove virtual magazines from an object (e.g., ammo box). Virtual items can be selected in the Arsenal.

### Syntax

```sqf
[object, magClasses, removeGlobally] call BIS_fnc_removeVirtualMagazineCargo
```

### Parameters

- object: Object - object from which items will be removed
- magClasses: Boolean, String or Array of Strings - magazine classes
- removeGlobally: Boolean - (Optional, default false) true to remove items globally

### Return Value

- Array of Arrays of all virtual items in objects's space in format [items, weapons, magazines, backpacks]

### Examples

#### Example 1

```sqf
[BIS_ammoBox, ["class_1", "class_2"], true] call BIS_fnc_removeVirtualMagazineCargo;
```
