## setLightFlareSize

- Source: https://community.bistudio.com/wiki/setLightFlareSize
- Revision: 310116
- Updated: 2022-05-05T12:25:32Z

- Availability: arma3 0.50
- Locality: argument local, effect local
- Groups: Lights

### Description

Sets relative size of the flare for the light.

### Syntax

```sqf
light setLightFlareSize size
```

### Parameters

- light: Object
- size: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLight setLightFlareSize 5;
```
