## leaderboardDeInit

- Source: https://community.bistudio.com/wiki/leaderboardDeInit
- Revision: 323055
- Updated: 2022-06-28T21:43:11Z

- Availability: arma3 1.56
- Groups: Leaderboards

### Description

Deletes internal class for the leaderboard with given name. Returns true if the board has been found and deinitialized.

### Syntax

```sqf
leaderboardDeInit boardName
```

### Parameters

- boardName: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
leaderboardDeInit "TT01";
```
