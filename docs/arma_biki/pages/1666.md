## camSetPos

- Source: https://community.bistudio.com/wiki/camSetPos
- Revision: 377590
- Updated: 2026-01-02T06:58:01Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Camera Control

### Description

Sets the position of the given camera or seagull (see camCreate).
It is worth mentioning that camera position can also be set with setPos, in which case it would be instant.
With camSetPos it is possible to make smooth position transition in time, defined with camCommit, which is required in this case.

### Syntax

```sqf
camera camSetPos position
```

### Parameters

- camera: Object - object of type "camera" or "seagull"
- position: PositionAGL - camera destination

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_cam camSetPos [2300, 1000, 130];
_cam camCommit 10;
```
