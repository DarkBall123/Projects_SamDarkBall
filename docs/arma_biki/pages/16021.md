## BIS fnc isCampaign

- Source: https://community.bistudio.com/wiki/BIS_fnc_isCampaign
- Revision: 309322
- Updated: 2022-05-05T12:04:27Z

- Availability: arma3 1.00
- Groups: Campaign, Missions

### Description

Checks to see if a mission is being run in a campaign.

### Syntax

```sqf
[] call BIS_fnc_isCampaign
```


### Return Value

- Boolean - true if being run in a campaign, false if not

### Examples

#### Example 1

```sqf
[] call BIS_fnc_isCampaign;
```
