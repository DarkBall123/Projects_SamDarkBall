## isEqualRef

- Source: https://community.bistudio.com/wiki/isEqualRef
- Revision: 338333
- Updated: 2023-02-28T14:32:49Z

- Availability: arma3 2.12
- Groups: Variables

### Description

Compares two values by reference, returns true if equal.

### Syntax

```sqf
val1 isEqualRef val2
```

### Parameters

- val1: Anything
- val2: Anything

### Return Value

- Boolean - true if the same ref

### Examples

#### Example 1

```sqf
_arr1 = [1,[2,[3]]];
_arr2 = _arr1;
_arr1 isEqualTo _arr2;	// true
_arr1 isEqualRef _arr2;	// true

_arr2 = +_arr1;			// array copy
_arr1 isEqualTo _arr2;	// true
_arr1 isEqualRef _arr2;	// false
```
