## onBriefingNotes

- Source: https://community.bistudio.com/wiki/onBriefingNotes
- Revision: 378135
- Updated: 2026-02-24T13:54:13Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Sounds, Briefing, Event Handlers

### Description

Select a sound declared in the Description.ext of the mission to be played the first time the Notes tab is selected in the briefing.

### Syntax

```sqf
onBriefingNotes soundName
```

### Parameters

- soundName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
onBriefingNotes "NotesVoiceOver";
```
