## nil

- Source: https://community.bistudio.com/wiki/nil
- Revision: 347969
- Updated: 2023-11-08T09:38:47Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Variables

### Description

Nil value. This value can be used to undefine existing variables.

### Syntax

```sqf
nil
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
variableToDestroy = nil;
```

#### Example 2

```sqf
private _variable = 50;
_variable = nil;
hint format ["Variable = %1", _variable];	// will display "Variable = any" in [unscheduled environment](Scheduler#Unscheduled Environment)
											// will output "Error Undefined variable in expression: _variable" in [scheduled environment](Scheduler#Scheduled Environment)
// identical to
hint format ["Variable = %1", _variableThatWasNeverDefined];
```
