## getMissionDLCs

- Source: https://community.bistudio.com/wiki/getMissionDLCs
- Revision: 329346
- Updated: 2022-07-27T10:53:06Z

- Availability: arma3 1.62
- Groups: Mission Information, DLC

### Description

Returns list of DLCs that are used in the mission.
The list is created from units listed in mission.sqm and does **not** detect units later created by scripts.

### Syntax

```sqf
getMissionDLCs
```


### Return Value

- Array - list of DLCs detected for the mission

### Examples

#### Example 1

```sqf
_usedDLCs = getMissionDLCs; // returns e.g ["Orange","Enoch","Expansion","Heli","Contact","Mark","Argo","Jets"]
```
