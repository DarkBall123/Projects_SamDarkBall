## ctrlMapAnimCommit

- Source: https://community.bistudio.com/wiki/ctrlMapAnimCommit
- Revision: 321386
- Updated: 2022-05-14T11:14:10Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - Map

### Description

Plays the map animation.

### Syntax

```sqf
ctrlMapAnimCommit  mapControl
```

### Parameters

- mapControl: Control

### Return Value

- Nothing

### Examples

#### Example 1

Center map on player:

```sqf
_ctrl ctrlMapAnimAdd [0, 0.05, player];
ctrlMapAnimCommit _ctrl;
```
