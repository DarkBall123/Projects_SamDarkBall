## setToneMapping

- Source: https://community.bistudio.com/wiki/setToneMapping
- Revision: 327504
- Updated: 2022-07-12T22:24:52Z

- Availability: arma2oa 1.62, tkoh 1.00
- Locality: effect local
- Groups: System

### Description

Applies a specific tone mapping to the game. The tone mapping can be edited with setToneMappingParams.
This command is not present in Arma 3.

### Syntax

```sqf
setToneMapping toneName
```

### Parameters

- toneName: String - can be one of:
* "Arma"
* "Filmic"
* "Reinhard"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setToneMapping "Filmic";
```
