## groupOwner

- Source: https://community.bistudio.com/wiki/groupOwner
- Revision: 363282
- Updated: 2024-03-26T10:51:53Z

- Availability: arma3 1.40
- Locality: argument global, server execution server
- Groups: Multiplayer

### Description

Returns the machine network ID of the client to which the group is local. This command only works when called from the server. When called from a client, it always returns 0.

### Syntax

```sqf
groupOwner group
```

### Parameters

- group: Group

### Return Value

- Number

### Examples

#### Example 1

```sqf
_clientID = groupOwner _someGroup;
```
