## setWaterFillPercentage

- Source: https://community.bistudio.com/wiki/setWaterFillPercentage
- Revision: 363324
- Updated: 2024-03-26T16:41:40Z

- Availability: arma3 2.16
- Locality: argument local, effect local
- Groups: Object Manipulation

### Description

Set an object's water filling.

### Syntax

```sqf
obj setWaterFillPercentage level
```

### Parameters

- obj: Object - object to manipulate
- level: Number - water level in range 0..1 (empty to full)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
if (getWaterLeakiness _myCar > 0 && surfaceIsWater getPosASL _myCar) then
{
	_myCar setWaterFillPercentage 1;
	hint "I told you not to go in the water!";
};
```
