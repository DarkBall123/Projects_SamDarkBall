## dayTime

- Source: https://community.bistudio.com/wiki/dayTime
- Revision: 378415
- Updated: 2026-04-04T08:39:14Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Environment, Mission Information, Time

### Description

Returns the current in-game time in hours. For a formatted version of time, see BIS_fnc_timeToString.

### Multiplayer

Returns the current **local** in-game time in hours.

### Syntax

```sqf
dayTime
```


### Return Value

- Number in range 0..24 - day time using a 24 hour clock, using fractions of hours

### Examples

#### Example 1

```sqf
dayTime; // returns 16.5 given it is 16:30 (4.30pm) in game
```

#### Example 2

Get hour, minute, seconds:

```sqf
private _daytime = dayTime; // assuming dayTime returns 1.66046
private _hours = floor _daytime;											//  1
private _minutes = floor ((_daytime - _hours) * 60);						// 39
private _seconds = floor ((((_daytime - _hours) * 60) - _minutes) * 60);	// 37
```
