## load3DENScenario

- Source: https://community.bistudio.com/wiki/load3DENScenario
- Revision: 369783
- Updated: 2024-10-08T15:09:02Z

- Availability: arma3 2.18
- Groups: Eden Editor

### Description

Load the provided scenario or an empty scenario in the provided world.

### Syntax

```sqf
load3DENScenario scenarioOrWorld
```

### Parameters

- scenarioOrWorld: String - scenario name or world name

### Return Value

- Boolean - true on success, false otherwise

### Examples

#### Example 1

```sqf
load3DENScenario "MyMission.VR";
```

#### Example 2

```sqf
load3DENScenario "Stratis";
```

#### Example 3

```sqf
//For a scenario located at ...\Arma 3 - Other Profiles\<PROFILENAME>\missions\subfolder\myMission.VR
//full path needs to be provided without leading \
load3DENScenario "missions\subfolder\myMission.VR";
```
