## size

- Source: https://community.bistudio.com/wiki/size
- Revision: 378398
- Updated: 2026-04-04T08:01:25Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations

### Description

Returns a location's size.

### Syntax

```sqf
size location
```

### Parameters

- location: Location

### Return Value

- Array with [x,y]
* x: Number - horizontal distance in meters
* y: Number - vertical distance in meters

### Examples

#### Example 1

```sqf
_locSize = size myLocation;
```
