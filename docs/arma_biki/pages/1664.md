## camSetFov

- Source: https://community.bistudio.com/wiki/camSetFov
- Revision: 318602
- Updated: 2022-05-13T09:21:10Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Camera Control

### Description

Set the zoom level (**F**ield **O**f **V**iew) of the given camera.

The zoom level is from *`0.01`* for the nearest and *`8.5`* for the furthest zoom value, with a default zoom level of *`0.75`*

The angle of the field of view is *`atan(FOV)*2`* radians when in 4:3 aspect ratio. Needs the call of camCommit to be conducted.

### Syntax

```sqf
camera camSetFov level
```

### Parameters

- camera: Object - object of type "camera"
- level: Number - zoom level, range 0.01 to 8.5 (see description above)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_cam camSetFov 0.75;
```
