## ropeAttachedObjects

- Source: https://community.bistudio.com/wiki/ropeAttachedObjects
- Revision: 377098
- Updated: 2026-01-01T09:57:17Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Returns an array of all entities that are attached to the transport with ropes. This command is the opposite of ropeAttachedTo.

400px

### Syntax

```sqf
ropeAttachedObjects ropesOwner
```

### Parameters

- ropesOwner: Object - transport from which a single or multiple ropes are originating

### Return Value

- Array of Objects - array of attached entities on ropes

### Examples

#### Example 1

```sqf
_cargoArray = ropeAttachedObjects heli1;
```
