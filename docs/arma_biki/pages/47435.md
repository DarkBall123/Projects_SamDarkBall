## detachChild

- Source: https://community.bistudio.com/wiki/detachChild
- Revision: 378900
- Updated: 2026-08-11T14:56:33Z

- Availability: arma3 2.22
- Locality: argument local, effect global
- Groups: PhysX

### Description

Detaches previously attached with attachChild object.

### Syntax

```sqf
detachChild parent
```

### Parameters

- parent: Object - The parent object that another object is attached to. Must be a Transport vehicle like Car/Tank (Maybe helicopter/airplane works?).

### Return Value

- Nothing or Object
