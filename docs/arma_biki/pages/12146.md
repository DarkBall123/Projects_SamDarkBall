## clearItemCargo

- Source: https://community.bistudio.com/wiki/clearItemCargo
- Revision: 309943
- Updated: 2022-05-05T12:16:59Z

- Availability: arma3 0.50
- Groups: Containers

### Description

Removes all items from ammo box (or any general weapon holder container).

### Syntax

```sqf
clearItemCargo box
```

### Parameters

- box: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
clearItemCargo myBox;
```
