## lockedCargo

- Source: https://community.bistudio.com/wiki/lockedCargo
- Revision: 321015
- Updated: 2022-05-13T11:15:18Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Check whether cargo position of the vehicle is locked.

### Syntax

```sqf
vehicle lockedCargo cargoIndex
```

### Parameters

- vehicle: Object
- cargoIndex: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_result = vehicleName lockedCargo 0;
```
