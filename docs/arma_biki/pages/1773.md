## setViewDistance

- Source: https://community.bistudio.com/wiki/setViewDistance
- Revision: 364699
- Updated: 2024-05-25T17:28:31Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: System, Environment

### Description

Set rendering distance. Setting view distance to <= 0 resets the value to the client's options (set in `Options → Video → General → Visibility → Overall`).
In previous versions, client's max view distance was limited by the server's view distance.
View distance also defines the maximum distance between a unit and any other unit they can know about.
Higher view distance will involve more AI simulation cycles for every unit, which causes low performance. See Arma 3: Performance Optimisation.

### Syntax

```sqf
setViewDistance distance
```

### Parameters

- distance: Number - distance in metres; 1.00 a negative value resets the view distance to user video setting

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setViewDistance 2250;
```

#### Example 2

```sqf
setViewDistance -1; // reset view distance in Arma 3
```
