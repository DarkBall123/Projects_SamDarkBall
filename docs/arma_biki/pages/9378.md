## removeMagazinesTurret

- Source: https://community.bistudio.com/wiki/removeMagazinesTurret
- Revision: 377499
- Updated: 2026-01-02T06:49:26Z

- Availability: arma2oa 1.52, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Turrets

### Description

Removes all magazines of the given type from given vehicle. Use turret path [-1] for driver's turret.

### Syntax

```sqf
vehicle removeMagazinesTurret [magazineName, turretPath]
```

### Parameters

- vehicle: Object
- magazineName: String
- turretPath: Turret Path

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player removeMagazinesTurret ["60rnd_CMFlareMagazine", [-1]];
```

#### Example 2

```sqf
_tank removeMagazinesTurret ["20Rnd_120mmSABOT_M1A2", [0]];
```
