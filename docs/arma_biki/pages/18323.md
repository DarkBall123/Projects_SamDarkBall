## BIS fnc 3DENNotification

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENNotification
- Revision: 352420
- Updated: 2024-02-09T15:26:08Z

- Availability: arma3 1.58
- Locality: effect Local
- Groups: Eden Editor

### Description

Shows notification banner with given text, animated or not, at the top of the screen in the Eden Editor.

Since 2.10 this function will no longer throw an error outside of Eden Editor. Because `Display3DEN` (

```sqf
findDisplay 313
```

) is not available, it will only play the sound according to the message type.
The sound is played through the UI channel with playSoundUI.

### Syntax

```sqf
[text, type, duration, animate] call BIS_fnc_3DENNotification
```

### Parameters

- text: String or Structured Text - either text or class from 

```sqf
"Cfg3DEN" >> "Notifications"
```
- type: Number - (Optional, default 0) 0: Notification (Green) 1: Warning (Red)
- duration: Number - (Optional, default 2) duration in seconds (+ 1 sec for each new line)
- animate: Boolean - (Optional, default true) toggle animation
- volume: Number - (Optional, default 1) volume adjustment

### Return Value

- Number - selected Mode

### Examples

#### Example 1

```sqf
["This is an animated notification", 0] call BIS_fnc_3DENNotification;
```

#### Example 2

```sqf
["This is a warning that is not animated", 1, 2, false] call BIS_fnc_3DENNotification;
```

#### Example 3

```sqf
["For more information visit <t colorLink='#E69710'>Community Wiki</t>"] call BIS_fnc_3DENNotification;
```
