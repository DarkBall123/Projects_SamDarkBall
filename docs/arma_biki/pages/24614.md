## BIS fnc zoomLock

- Source: https://community.bistudio.com/wiki/BIS_fnc_zoomLock
- Revision: 328000
- Updated: 2022-07-13T15:48:50Z

- Availability: arma3 1.78
- Locality: effect local
- Groups: Map and Markers

### Description

Locks the camera in place when the map is open.

### Syntax

```sqf
[cameraCenter] call BIS_fnc_zoomLock
```

### Parameters

- cameraCenter: Array format Position2D - (Optional, default [0, 0]) position where the camera should be placed and locked

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
0, 0 call BIS_fnc_zoomLock;
```

### See Also

BIS_fnc_zoomUnlock BIS_fnc_zoomLockEH
