## eyePos

- Updated: 2026-01-02T06:46:41Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Positions

### Description

Returns the object's eyes / main turret position.

### Syntax

```sqf
eyePos object
```

### Parameters

- object: Object

### Return Value

- PositionASL

### Examples

#### Example 1

```sqf
_eyesPos = eyePos player;
```
