## BIS fnc boundingBoxMarker

- Source: https://community.bistudio.com/wiki/BIS_fnc_boundingBoxMarker
- Revision: 348837
- Updated: 2023-11-08T14:39:09Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Creates marker on object with size of objects' bounding box.

### Syntax

```sqf
object call BIS_fnc_boundingBoxMarker
```

### Parameters

- object: Object

### Return Value

- String - marker
