## ctrlSetDisabledColor

- Source: https://community.bistudio.com/wiki/ctrlSetDisabledColor
- Revision: 347537
- Updated: 2023-09-28T08:53:50Z

- Availability: arma3 1.00
- Groups: GUI Control

### Description

Sets the colorDisabled attribute of a control.

### Syntax

```sqf
ctrlSetDisabledColor [idc, color]
```

```sqf
ctrl ctrlSetDisabledColor color
```

### Parameters

- idc: Number
- color: Color (RGBA)
- ctrl: Control
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetDisabledColor [0.5, 0.5, 0.5, 0.5];
```
