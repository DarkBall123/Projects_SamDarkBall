## rankId

- Source: https://community.bistudio.com/wiki/rankId
- Revision: 319405
- Updated: 2022-05-13T09:24:01Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Unit Identity

### Description

Return the rank of the given unit for comparison.

Value may be:
* **0** - Private
* **1** - Corporal
* **2** - Sergeant
* **3** - Lieutenant
* **4** - Captain
* **5** - Major
* **6** - Colonel

### Syntax

```sqf
rankId unit
```

### Parameters

- unit: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
_myIdRank = rankId player;
```
