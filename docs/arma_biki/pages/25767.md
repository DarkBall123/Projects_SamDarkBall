## matrixTranspose

- Source: https://community.bistudio.com/wiki/matrixTranspose
- Revision: 364808
- Updated: 2024-06-15T13:13:33Z

- Availability: arma3 1.92
- Groups: Math, Math - Vectors

### Description

thumb|Matrix transposition
Returns [transposed](https://en.wikipedia.org/wiki/Transpose) version of the given matrix.
The matrix is an Array of rows.
Each row is an Array of corresponding column values for the row. The minimum number of rows is 1.

### Syntax

```sqf
matrixTranspose matrix
```

### Parameters

- matrix: Array of Array of Numbers - given matrix

### Return Value

- Array of Array of Numbers - transposed matrix

### Examples

#### Example 1

```sqf
matrixTranspose 
[
	[1,2,3], 
	[3,1,2], 
	[2,3,1]
];
/* returns 
[
	[1,3,2], 
	[2,1,3], 
	[3,2,1]
] */
```

#### Example 2

```sqf
matrixTranspose 
[
	[1,2,3]
];
/* returns 
[
	[1],
	[2],
	[3]
] */
```

#### Example 3

```sqf
matrixTranspose 
[
	[1],
	[2],
	[3]
];
/* returns 
[
	[1,2,3]
] */
```
