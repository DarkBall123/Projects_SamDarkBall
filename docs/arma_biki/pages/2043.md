## setDropInterval

- Source: https://community.bistudio.com/wiki/setDropInterval
- Revision: 336719
- Updated: 2023-01-04T15:24:43Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Particles

### Description

Set interval of emitting particles from particle source. In Arma 3 hardcoded limit of how many particles can exist at the same time is [text= 18000](link= http://forums.bistudio.com/showthread.php?177797-Ruin-your-copy-of-Arma-and-your-PC#post2691090). Correspondence between CfgCloudlets class param name and command param:

```sqf
particleSource setDropInterval interval;
```

### Syntax

```sqf
particleSource setDropInterval interval
```

### Parameters

- particleSource: Object
- interval: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_source setDropInterval 0.05;
```
