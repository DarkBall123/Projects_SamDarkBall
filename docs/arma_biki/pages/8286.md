## hcShownBar

- Source: https://community.bistudio.com/wiki/hcShownBar
- Revision: 319103
- Updated: 2022-05-13T09:23:11Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Return whether the High Command bar is shown/active.

### Syntax

```sqf
hcShownBar
```


### Return Value

- Boolean - true if HC bar is shown, otherwise false

### Examples

#### Example 1

```sqf
if (hcShownBar) then { hint "HC bar is active"; };
```
