## ctrlSetFontHeight

- Source: https://community.bistudio.com/wiki/ctrlSetFontHeight
- Revision: 336297
- Updated: 2022-12-21T11:10:07Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets the `sizeEx` property for most controls as follows: 
* `CT_MAP` - "sizeExNames"
* `CT_HTML` - "P" >> "sizeEx"
* Other - "sizeEx"
* 2.02 `CT_STRUCTURED_TEXT` - "size"

### Syntax

```sqf
control ctrlSetFontHeight  size
```

### Parameters

- control: Control
- size: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontHeight 0.05;
```
