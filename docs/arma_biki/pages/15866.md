## BIS fnc radioSetPlaylist

- Source: https://community.bistudio.com/wiki/BIS_fnc_radioSetPlaylist
- Revision: 327542
- Updated: 2022-07-12T22:38:04Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Radio

### Description

Set a random music playlist for the current set channel (default "Rock"). Musics with "genre" set in CfgMusic are selected and shuffled.

### Syntax

```sqf
call BIS_fnc_radioSetPlaylist
```


### Return Value

- Array of Strings - created music playlist

### Examples

#### Example 1

```sqf
call BIS_fnc_radioSetPlaylist;
```
