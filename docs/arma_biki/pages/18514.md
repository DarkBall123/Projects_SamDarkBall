## environmentEnabled

- Source: https://community.bistudio.com/wiki/environmentEnabled
- Revision: 377680
- Updated: 2026-01-02T09:02:45Z

- Availability: arma3 1.68
- Groups: Environment, Sounds

### Description

Returns status of enableEnvironment command

### Syntax

```sqf
environmentEnabled
```


### Return Value

- Array with [ambientLife, ambientSound, windyCoef]
* ambientLife: Boolean 
* ambientSound: Boolean
* 2.12 windyCoef: Number - see enableEnvironment

### Examples

#### Example 1

```sqf
private _enabled = environmentEnabled;
```
