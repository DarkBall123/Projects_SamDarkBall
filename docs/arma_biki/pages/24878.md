## BIS fnc camera getHUDEnabled

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_getHUDEnabled
- Revision: 349232
- Updated: 2023-11-08T14:50:53Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Returns wether camera HUD is enabled.

### Syntax

```sqf
[camera] call BIS_fnc_camera_getHUDEnabled
```

### Parameters

- camera: Object - the camera

### Return Value

- Boolean - returns true if HUD is enabled

### Examples

#### Example 1

```sqf
[BIS_camera] call BIS_fnc_camera_getHUDEnabled;
```
