## allEnv3DSoundSources

- Source: https://community.bistudio.com/wiki/allEnv3DSoundSources
- Revision: 309140
- Updated: 2022-05-03T11:50:33Z

- Availability: arma3 2.08
- Groups: Sounds

### Description

Returns all environmental 3D sound sources (Objects) like trees and houses in camera vicinity.

### Syntax

```sqf
allEnv3DSoundSources
```


### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
private _sources = allEnv3DSoundSources;
```
