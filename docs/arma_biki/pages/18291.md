## menuExpand

- Source: https://community.bistudio.com/wiki/menuExpand
- Revision: 378347
- Updated: 2026-04-02T16:31:34Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Expands given menu entry on given path and all its parents so entry is visible.

### Syntax

```sqf
menuExpand [idc, path]
```

```sqf
control menuExpand path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuExpand [0, 1];
```
