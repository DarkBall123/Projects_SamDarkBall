## moveTime

- Source: https://community.bistudio.com/wiki/moveTime
- Revision: 310173
- Updated: 2022-05-05T13:10:28Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Animations

### Description

Returns the current time of the most important RTM animation currently being played on the soldier.

### Syntax

```sqf
moveTime soldier
```

### Parameters

- soldier:  Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
moveTime player;
```
