## addCuratorEditingArea

- Source: https://community.bistudio.com/wiki/addCuratorEditingArea
- Revision: 348372
- Updated: 2023-11-08T12:59:56Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Adds or changes curator edit area (depends on if ID is already used).

### Syntax

```sqf
curatorObj addCuratorEditingArea [editAreaID, position, radius]
```

### Parameters

- curatorObj: Object - curator module.
- editAreaID: Number
- position: Position
- radius: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myCurator addCuratorEditingArea [4, position player, 1000];
```
