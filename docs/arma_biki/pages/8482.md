## uiNamespace

- Source: https://community.bistudio.com/wiki/uiNamespace
- Revision: 353040
- Updated: 2024-03-12T11:58:15Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Namespaces, Variables, GUI Control

### Description

Returns the global namespace attached to user interface.

### Syntax

```sqf
uiNamespace
```


### Return Value

- Namespace

### Examples

#### Example 1

```sqf
uiNamespace setVariable ["LIB_interruptDisplay", _display];
```

#### Example 2

```sqf
uiNamespace setVariable ["myVar", 46];
with uiNamespace do
{
	hint str myVar; // 46
};
```
