## calculatePlayerVisibilityByFriendly

- Source: https://community.bistudio.com/wiki/calculatePlayerVisibilityByFriendly
- Revision: 309210
- Updated: 2022-05-03T22:23:29Z

- Availability: arma3 1.84
- Groups: System

### Description

Sets if friendly units will calculate player's visibility or not. Default value is false.

### Syntax

```sqf
calculatePlayerVisibilityByFriendly calculate
```

### Parameters

- calculate: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
calculatePlayerVisibilityByFriendly true;
```
