### File Structure

Each HTML file contains different parts.

#### Body

Each HTML file has values to build a 'body'. For our purpose a valid body look like this:
- 

```
<html>
<head>
	<meta http-equiv="Content-Type" content="text/html; charset=utf-8">
	<title>PageTitle</title>
</head>
<body>

</body>
</html>
```

#### LineBreak

Within paragraphs the control will show your text without any new line you wrote in your HTML file. A new line is parsed like a 'space'. But you can use the '<br>' (break) tag, to tell the parser you want to continue the following text on a new line. This tag is a standalone tag, meaning it doesn't have a start and end tag.

With Links you can link to an other section you defined in you html file. The Text (or image) between the tags will be displayed as link. If you later click on this link, the HTML Control will show the linked section.

You need to add an "#" to the section name in tag attribute `href`.

#### Images

You can implement images to your control. The image tag is a standalone tag, so it has no end tag. You can specify the *height* and the *width* of your control with the *height* and *width* attributes. You also have to add the *src* attribute which will point to your image.
- Image tag
- 

```
<img src="Image.paa" height="100" width="150">
```

### Special Chars

- For '<' use '&lt;' (**l**ess**t**han).
- For '>' use '&gt;' (**g**reater**t**han).
- For '&' use '&amp;'.
