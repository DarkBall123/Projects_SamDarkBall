## ctFindHeaderRows

- Source: https://community.bistudio.com/wiki/ctFindHeaderRows
- Revision: 377180
- Updated: 2026-01-01T10:48:22Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Gets array of indices of rows under this header.

### Syntax

```sqf
ctrl ctFindHeaderRows index
```

### Parameters

- ctrl: Control
- index: Number - header's index

### Return Value

- Array of Numbers

### Examples

#### Example 1

```sqf
private _indices = _control ctFindHeaderRows 0;
```
