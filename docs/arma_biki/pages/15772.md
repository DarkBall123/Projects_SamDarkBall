## BIS fnc dbIsClass

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbIsClass
- Revision: 328437
- Updated: 2022-07-13T16:00:51Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Checks if string is class definition.

### Syntax

```sqf
text call BIS_fnc_dbIsClass
```

### Parameters

- text - String: Check if text is in class format

### Return Value

- Boolean: true when the argument starts with "#" (class symbol returned with BIS_fnc_dbSymbolClass)

### Examples

#### Example 1

```sqf
"#MYCLASS" call BIS_fnc_dbIsClass; // true
"#myclass" call BIS_fnc_dbIsClass; // true
"MYCLASS" call BIS_fnc_dbIsClass; // false
1234 call BIS_fnc_dbIsClass; // false
```
