## tvSetSelected

- Source: https://community.bistudio.com/wiki/tvSetSelected
- Revision: 378326
- Updated: 2026-04-02T16:30:29Z

- Availability: arma3 2.02
- Groups: GUI Control - Tree View

### Description

Sets the selection state of given treeview item in multi-select control.

### Syntax

```sqf
control tvSetSelected [path, selected]
```

### Parameters

- control: Control
- path: Tree View Path
- selected: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control tvSetSelected [[0], true];
```
