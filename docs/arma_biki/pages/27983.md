## flatten

- Source: https://community.bistudio.com/wiki/flatten
- Revision: 377162
- Updated: 2026-01-01T10:41:18Z

- Availability: arma3 2.02
- Groups: Arrays

### Description

Flattens an array.

### Syntax

```sqf
flatten array
```

### Parameters

- array: Array of Anything

### Return Value

- Array of Anything - flattened array

### Examples

#### Example 1

```sqf
flatten [1, [2], 3, [4]]; // returns [1, 2, 3, 4]
```

#### Example 2

```sqf
flatten getUnitLoadout player;
```
