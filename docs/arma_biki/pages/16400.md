## BIS fnc curatorSayMessage

- Source: https://community.bistudio.com/wiki/BIS_fnc_curatorSayMessage
- Revision: 349430
- Updated: 2023-11-08T16:27:36Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Plays some radio message from CfgRadio locally.

### Syntax

```sqf
[speaker, sentence] call BIS_fnc_curatorSayMessage
```

### Parameters

- target: Object - curator entity
- sentence: String - sentence from CfgRadio

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, "mp_groundsupport_01_casrequested_BHQ_0"] call BIS_fnc_curatorSayMessage;
```
