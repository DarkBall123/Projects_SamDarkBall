## setWaypointForceBehaviour

- Source: https://community.bistudio.com/wiki/setWaypointForceBehaviour
- Revision: 377890
- Updated: 2026-01-05T17:35:07Z

- Availability: arma3 1.58
- Groups: Waypoints

### Description

Forces the behavior of waypoint, disables AUTOCOMBAT.

### Syntax

```sqf
waypoint setWaypointForceBehaviour state
```

### Parameters

- waypoint: Waypoint
- state: Boolean - force or not

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[grp, 2] setWaypointForceBehaviour true;
```
