## BIS fnc wpFastRope

- Source: https://community.bistudio.com/wiki/BIS_fnc_wpFastRope
- Revision: 328383
- Updated: 2022-07-13T16:00:48Z

- Availability: tkoh 1.00
- Groups: Waypoints

### Description

FAST-ROPE custom waypoint.

Let everybody in vehicles' cargo space rappel down on a rope.

### Syntax

```sqf
Custom Waypoint arguments: [limitHeight,limitSpeed,fastropeID]
```

### Parameters

- limitHeight: Number - height tolerance from waypoint's height (default: 10m)
- limitSpeed: Number - maximum speed ov vehicle (default: 10km/h)
- fastropeID: Number - ID of vehicle's fast-rope position. Positions are defined in vehicle's config under RopePositions >> Fastrope

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, position dude, 50, 5, 15, 1] spawn BIS_fnc_wpFastRope;
```
