## BIS fnc 3den onKeyUp

- Source: https://community.bistudio.com/wiki/BIS_fnc_3den_onKeyUp
- Revision: 363859
- Updated: 2024-04-23T20:52:51Z

- Availability: arma3 1.56
- Groups: KeyframeAnimation

### Description

Used internally by the Key Frame Animation system. Called when a button is released.

### Syntax

```sqf
[display, button, shift, ctrl, alt] call BIS_fnc_3den_onKeyUp
```

### Parameters

- display: Display - the display
- button: Number - key code of the pressed button
- shift: Boolean - SHIFT key
- ctrl: Boolean - CTRL key
- alt: Boolean - ALT key

### Return Value

- Boolean - whether or not to consume the input

### Examples

#### Example 1

```sqf
findDisplay 313 displayAddEventHandler ["keyUp", {_this call BIS_fnc_3den_onKeyUp}];
```
