## BIS fnc timeline setInterpMode

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_setInterpMode
- Revision: 348070
- Updated: 2023-11-08T11:29:53Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Set's the interpolation mode of the timeline.

### Syntax

```sqf
[timeline, mode] call BIS_fnc_timeline_setInterpMode
```

### Parameters

- timeline: Object - the timeline object
- mode: Number - (Optional, default 0) interpolation mode, see BIS_fnc_timeline_getInterpMode's return value for possible values

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[timeline,15] call BIS_fnc_timeline_setInterpMode;
```
