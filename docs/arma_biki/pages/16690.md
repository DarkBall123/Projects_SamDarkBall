## addWeaponTurret

- Source: https://community.bistudio.com/wiki/addWeaponTurret
- Revision: 377484
- Updated: 2026-01-02T06:49:02Z

- Availability: arma3 1.32, arma2oa 1.64
- Locality: argument local, effect global
- Groups: Turrets

### Description

Adds a weapon to the turret. Use turret path [-1] for driver's turret.

### Syntax

```sqf
vehicle addWeaponTurret [weaponName, turretPath]
```

### Parameters

- vehicle: Object
- weaponName: String
- turretPath: Turret Path

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_tank addWeaponTurret ["LMG_M200", [0,0]];
```
