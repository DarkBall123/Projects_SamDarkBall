## BIS fnc taskState

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskState
- Revision: 352114
- Updated: 2024-02-01T23:25:00Z

- Availability: arma3 0.76
- Locality: argument global
- Groups: Tasks

### Description

Returns task's state. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskID call BIS_fnc_taskState
```

### Parameters

- taskID: String - ID of the task

### Return Value

- String - state of the task. Can be:
* "AUTOASSIGNED"
* "ASSIGNED"
* "CREATED"
* "SUCCEEDED"
* "FAILED"
* "CANCELED"

### Examples

#### Example 1

```sqf
"task_1" call BIS_fnc_taskState;
```

#### Example 2

```sqf
["task_1"] call BIS_fnc_taskState;
```
