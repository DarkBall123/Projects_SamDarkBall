## private

- Source: https://community.bistudio.com/wiki/private
- Revision: 377850
- Updated: 2026-01-03T11:40:32Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Variables

### Description

Sets a variable to the innermost scope. See also param and params.
{{Feature|warning|
* private variables **must** start with an underscore: {{hl|c= private **{{Color|red|_}}**myVar1 = "myVar";}} - see Identifier.
* **Always** make your local variables **private** (through private or params) in order to avoid overwriting a local variable of the same name.
}}

### Syntax

```sqf
private variableName
```

```sqf
private variableNameList
```

```sqf
private _identifier = value **{{Color|red|From {{arma2}} v1.00 to Arma 3 v1.52:}}** see **local**
```

### Parameters

- variableName: String - e.g 

```sqf
"_myVar"
```
- variableNameList: Array of Strings - e.g 

```sqf
["_target", "_damage"]
```
- _identifier: underscored variable name, for example 

```sqf
_myVar
```
- value: Anything: value to assign to the variable

### Return Value

- Nothing
- Nothing
- Nothing

### Examples

#### Example 1

```sqf
private _varname = "this is my new variable"; // since Arma 3 v1.54

// identical, but less performant
private "_varname";
_varname = "this is my new variable";
```

#### Example 2

```sqf
private ["_varname1", "_varname2"];
_varname1 = "variable 1";
_varname2 = "variable 2";
```

#### Example 3

```sqf
_lol = 123; call { hint str [_lol] }; // [123]
_lol = 123; call { private "_lol"; hint str [_lol] }; // [any]
```

#### Example 4

```sqf
_myvar = 123;
systemChat str [_myvar];		// [123]
call {
	systemChat str [_myvar];	// [123]
	private "_myvar";
	systemChat str [_myvar];	// [any]
	_myvar = 345;
	systemChat str [_myvar];	// [345]
};
systemChat str [_myvar];		// [123]
```
