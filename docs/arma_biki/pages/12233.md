## handgunWeapon

- Source: https://community.bistudio.com/wiki/handgunWeapon
- Revision: 320951
- Updated: 2022-05-13T10:04:47Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns the name of a unit's handgun (an empty string if there is none).

### Syntax

```sqf
handgunWeapon unit
```

### Parameters

- unit: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
hint handgunWeapon player; //"hgun_P07_F"
```
