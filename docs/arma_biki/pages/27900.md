## continueWith

- Source: https://community.bistudio.com/wiki/continueWith
- Revision: 378202
- Updated: 2026-03-12T15:42:26Z

- Availability: arma3 2.02
- Groups: Program Flow

### Description

Skips the current loop iteration, continues with the next one and returns the given value.

### Syntax

```sqf
continueWith return
```

```sqf
scriptHandle continueWith code
```

```sqf
scriptHandle continueWith [code, args]
```

### Parameters

- return: Anything - value to be returned when iteration is skipped
- scriptHandle: Script Handle
- code: Code - Code to execute once the Promise has completed. The code will be executed in Unscheduled Environment.
- scriptHandle: Script Handle
- code: Code - Code to execute once the Promise has completed. The code will be executed in Unscheduled Environment.
- args: Anything - Arguments passed into code in _thisArgs variable

### Return Value

- Anything
- Nothing
- Nothing

### Examples

#### Example 1

```sqf
// results in [2, "TEST", 4]
private _result = [1, 2, 3] apply {
	if (_x == 2) then {
		continueWith "TEST";
	} else {
		_x + 1;
	};
};
```
