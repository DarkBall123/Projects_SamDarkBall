## difficulty

- Source: https://community.bistudio.com/wiki/difficulty
- Revision: 353045
- Updated: 2024-03-12T12:13:06Z

- Availability: arma3 0.56
- Groups: Difficulty

### Description

Returns high-level selected difficulty mode.

### Syntax

```sqf
difficulty
```


### Return Value

- Number - Can be one of:
* 0 (Recruit)
* 1 (Regular)
* 2 (Veteran)
* 3 (Elite)

### Examples

#### Example 1

```sqf
if (difficulty == 0) then
{
	hint "You will need to follow my lead - read the Field Manual!";
};
```

#### Example 2

```sqf

```
