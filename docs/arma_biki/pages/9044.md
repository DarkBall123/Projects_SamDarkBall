## LineMapper Tutorial for Visitor 3

- Source: https://community.bistudio.com/wiki/LineMapper_Tutorial_for_Visitor_3
- Revision: 156537
- Updated: 2020-08-24T08:56:59Z

Basic steps so far:
- Open Shapefile in Globe Mapper
- Export Vector Data > Arc (Line/Area) *.dat
- Convert Lat/lon to Visitor X/Y
- Run through LineMapper
- Import into Visitor
- Tidy up any issues
