## isPiPEnabled

- Source: https://community.bistudio.com/wiki/isPiPEnabled
- Revision: 310808
- Updated: 2022-05-07T20:22:00Z

- Availability: tkoh 1.01, arma3 0.50
- Groups: System

### Description

Returns whether Picture-In-Picture video option (Render to Texture) is enabled or not.

### Syntax

```sqf
isPiPEnabled
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _PiPState = isPiPEnabled;
```
