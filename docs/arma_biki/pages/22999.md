## infoPanel

- Source: https://community.bistudio.com/wiki/infoPanel
- Revision: 378511
- Updated: 2026-05-03T17:16:42Z

- Availability: arma3 1.72
- Groups: Custom Panels

### Description

Returns information about what is currently displayed on given player's info panel.

### Syntax

```sqf
infoPanel infoPanelId
```

### Parameters

- infoPanelId: String - info panel classname, or "left" or "right"

### Return Value

- Array with [componentClass, componentType]
* componentClass: String - *EmptyDisplay* when no panel is open
* componentType: String -  *EmptyDisplayComponent* when no panel is open

### Examples

#### Example 1

```sqf
infoPanel "left" params ["_componentClass", "_componentType"];
```
