## needService

- Source: https://community.bistudio.com/wiki/needService
- Revision: 377624
- Updated: 2026-01-02T08:52:02Z

- Availability: arma3 2.12
- Groups: Object Manipulation

### Description

Returns array with how much vehicle needs repairing, refueling and rearming.

### Syntax

```sqf
needService vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array with [repair, refuel, rearm]. Values are in range 0..1: 0: no need, 1: maximum need

### Examples

#### Example 1

```sqf
needService tank params ["_needRepair", "_needRefuel", "_needRearm"];
```

#### Example 2

```sqf
onEachFrame { hintSilent str needService vehicle player };
```
