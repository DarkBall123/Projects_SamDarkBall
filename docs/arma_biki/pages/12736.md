## uniformContainer

- Source: https://community.bistudio.com/wiki/uniformContainer
- Revision: 369268
- Updated: 2024-09-03T18:42:43Z

- Availability: arma3 1.04
- Groups: Containers, Unit Inventory

### Description

Returns a cargo container of a unit's uniform.

### Syntax

```sqf
uniformContainer unit
```

### Parameters

- unit: Object

### Return Value

- Object - cargo container, objNull if *unit* does not wear any uniform/clothing

### Examples

#### Example 1

```sqf
hint str uniformContainer player; //2df7dd00# 163941: dummyweapon.p3d
```

#### Example 2

```sqf
hint str getMagazineCargo uniformContainer player;
/*
	returns e.g
	[
		["30Rnd_65x39_caseless_mag"],
		[3]
	]
*/
```
