## menuEnable

- Source: https://community.bistudio.com/wiki/menuEnable
- Revision: 378329
- Updated: 2026-04-02T16:30:39Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Enables or disables menu entry on given path.

### Syntax

```sqf
menuEnable [idc, path, enable]
```

```sqf
control menuEnable [path, enable]
```

```sqf
control menuEnable path This old syntax is kept only for backward compatibility.|arma3|2.06
```

### Parameters

- idc: Number
- path: Tree View Path
- enable: Boolean - (Optional, default true) disabled if false
- control: Control
- path: Tree View Path
- enable: Boolean - (Optional, default true) disabled if false
- control: Control
- path: Tree View Path

### Return Value

- Nothing
- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuEnable [0]; // old syntax, do not use
```

#### Example 2

```sqf
findDisplay 313 displayCtrl 120 menuEnable [[0, 0, 1], false]; // since Arma 3 v2.06
```
