### Description

Classic camera script, replaced by the Splendid™ BIS_fnc_camera.

### Syntax

```sqf
[target] call BIS_fnc_cameraOld
```

### Parameters

- target: Object - (Optional, default cameraOn)

### Return Value

- Script Handle

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_cameraOld; // starts the camera on the player
```
