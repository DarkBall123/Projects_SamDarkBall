## lnbDeleteRow

- Source: https://community.bistudio.com/wiki/lnbDeleteRow
- Revision: 310126
- Updated: 2022-05-05T12:25:40Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Removes row with the given index from the given listbox or combobox.

### Syntax

```sqf
_ctrl lnbDeleteRow row
```

### Parameters

- _ctrl: Control
- row: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl lnbDeleteRow 1;
```
