## initAmbientLife

- Source: https://community.bistudio.com/wiki/initAmbientLife
- Revision: 319259
- Updated: 2022-05-13T09:23:27Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Environment

### Description

Initialises the ambient life on local client from `CfgWorlds >> worldName >> AmbientA3`. Has no effect on dedicated server or headless client.

### Syntax

```sqf
**initAmbientLife**
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
initAmbientLife;
```

enableEnvironment sideAmbientLife
