- Groups: Groups

### Description

A non-existing Group. To compare non-existent groups use isNull or isEqualTo:

```sqf
grpNull == grpNull;			// false
isNull grpNull;				// true
grpNull isEqualTo grpNull;	// true
```

### Syntax

```sqf
grpNull
```


### Return Value

- Group

### Examples

#### Example 1

```sqf
!isNull grpNull; // false
```

#### Example 2

```sqf
str grpNull; // <NULL-group>
```
