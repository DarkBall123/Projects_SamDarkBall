## canDeployWeapon

- Source: https://community.bistudio.com/wiki/canDeployWeapon
- Revision: 310452
- Updated: 2022-05-05T18:08:10Z

- Availability: arma3 2.06
- Locality: argument local
- Groups: Weapons

### Description

Returns true if a unit's weapon can be deployed.

### Syntax

```sqf
canDeployWeapon unit
```

### Parameters

- unit : Object

### Return Value

- Boolean - true if unit's weapon can be deployed

### Examples

#### Example 1

```sqf
if (canDeployWeapon player) then { hint "I could rest my weapon here..." };
```
