## currentMuzzle

- Source: https://community.bistudio.com/wiki/currentMuzzle
- Revision: 321269
- Updated: 2022-05-13T19:08:05Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapons

### Description

Returns a unit's current weapon muzzle. Does not work on vehicles.

### Syntax

```sqf
currentMuzzle unit
```

### Parameters

- unit: Object

### Return Value

- String - current muzzle
In earlier games/versions, this command could return a Number (`0`) if *unit* was in a vehicle.
Use the following to circumvent the issue:

```sqf
_muzzle = weaponState unit select 1;
```

### Examples

#### Example 1

```sqf
_muzzle = currentMuzzle player;
```

#### Example 2

```sqf
_muzzle = currentMuzzle (gunner (vehicle player));
```
