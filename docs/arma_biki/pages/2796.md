## cameraOn

- Source: https://community.bistudio.com/wiki/cameraOn
- Revision: 347206
- Updated: 2023-09-05T08:55:52Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control, Remote Control

### Description

Returns the vehicle to which the camera is attached. If you need the person, see focusOn.

### Syntax

```sqf
cameraOn
```


### Return Value

- Object - vehicle

### Examples

#### Example 1

```sqf
_object = cameraOn;
```
