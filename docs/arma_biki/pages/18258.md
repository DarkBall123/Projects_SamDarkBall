## enableAimPrecision

- Source: https://community.bistudio.com/wiki/enableAimPrecision
- Revision: 351309
- Updated: 2023-11-27T04:50:52Z

- Availability: arma3 1.62
- Groups: Stamina System

### Description

Set whether animation's aim precision affects weapon sway.

### Syntax

```sqf
unit enableAimPrecision enable
```

### Parameters

- unit: Object
- enable: Boolean - true enable, false, disabled

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player enableAimPrecision false;
```
