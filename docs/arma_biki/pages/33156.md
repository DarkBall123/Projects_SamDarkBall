## assignedVehicles

- Source: https://community.bistudio.com/wiki/assignedVehicles
- Revision: 338334
- Updated: 2023-02-28T14:33:58Z

- Availability: arma3 2.12
- Groups: Groups

### Description

Returns all vehicles added to the given Group with addVehicle.

### Syntax

```sqf
assignedVehicles group
```

### Parameters

- group: Group

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_vehicles = assignedVehicles group player;
```
