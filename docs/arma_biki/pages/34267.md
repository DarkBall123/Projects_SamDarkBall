## getForcedSpeed

- Source: https://community.bistudio.com/wiki/getForcedSpeed
- Revision: 338349
- Updated: 2023-02-28T14:44:10Z

- Availability: arma3 2.12
- Groups: Object Manipulation

### Description

Returns forced speed set with forceSpeed or -1 if not set.

### Syntax

```sqf
getForcedSpeed entity
```

### Parameters

- entity: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
_spd = getForcedSpeed _heli;
```
