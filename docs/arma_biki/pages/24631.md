## BIS fnc WLSmoothText

- Source: https://community.bistudio.com/wiki/BIS_fnc_WLSmoothText
- Revision: 326960
- Updated: 2022-07-12T21:44:41Z

- Availability: arma3 1.86
- Locality: effect local
- Groups: Warlords, GUI

### Description

Display given text smoothly.

### Syntax

```sqf
[text, nbOfLines, duration, color, outline] call BIS_fnc_WLSmoothText
```

### Parameters

- text: String - text to display
- nbOfLines: Number - (Optional, default 3) maximum number of lines to be shown at the same time
- duration: Number - (Optional, default 5) on-screen duration
- color: Color (RGBA) - (Optional, default [1,1,1,1]) text color
- outline: Boolean - (Optional, default true) true to outline the text, false not to

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["Hello, hidden FX", 2, 3, [1,0,0,1], true] spawn BIS_fnc_WLSmoothText; // no sounds, letters appear in a smooth transition
```
