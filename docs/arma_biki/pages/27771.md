## ctrlSetTextSecondary

- Source: https://community.bistudio.com/wiki/ctrlSetTextSecondary
- Revision: 349266
- Updated: 2023-11-08T14:51:08Z

- Availability: ofp, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets the secondary text of a text control.

### Syntax

```sqf
control ctrlSetTextSecondary text
```

### Parameters

- control: Control - text control
- text: String - secondary text

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrlText ctrlSetTextSecondary "Hello World!";
```
