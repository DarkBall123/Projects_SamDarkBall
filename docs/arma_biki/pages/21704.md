## lbSetPictureRightColorSelected

- Source: https://community.bistudio.com/wiki/lbSetPictureRightColorSelected
- Revision: 377370
- Updated: 2026-01-02T06:42:16Z

{{RV|type=command

|game1= arma3
|version1= 1.20

|gr1= GUI Control - ListBox

|descr= Sets the selected color of the second (right aligned) picture of the item with the given index of the listbox with id idc of the topmost user dialog to the given color.
Color which consists from only zeros means disable this override.

|s1= control lbSetPictureRightColorSelected [index, color]

|p1= control: Control

|p2= index: Number

|p3= color: Color (RGBA)

|r1= Nothing

|x2=

```sqf
_ctrl lbSetPictureRightColorSelected [0, [1, 1, 1, 1]];
```
