Set mission countdown.

### Syntax

```sqf
[time] call BIS_fnc_estimatedTimeLeft
```

### Parameters

- time: Number - mission countdown

### Return Value

- Number - estimatedEndServerTime

```sqf
[180] call BIS_fnc_estimatedTimeLeft;
```
