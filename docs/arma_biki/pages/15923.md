## BIS fnc diagWiki

- Source: https://community.bistudio.com/wiki/BIS_fnc_diagWiki
- Revision: 353796
- Updated: 2024-03-23T16:33:07Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Scans specific config folder and outputs the values in wiki format.

### Syntax

```sqf
[mode] call BIS_fnc_diagWiki
```

### Parameters

- mode: String - can be one of:
{{Columns|4|
* `"Anims_aimPrecision"`
* `"CfgDiary_Icons"`
* `"CfgActions"`
* `"CfgActions_CfgVehicles"`
* `"CfgLocationTypes"`
* `"CfgMarkers"`
* `"CfgMarkerBrushes"`
* `"CfgMarkerColors"`
* `"CfgVehicles_identityTypes"`
* `"CfgVehicles_mapSize"`
* `"CfgVehicles_speechVariants"`
* `"CfgVehicleIcons"`
* `"CfgWrapperUI_Cursors"`
* `"IslandMap_colors"`
* `"IslandMap_icons"`
* `"RadioProtocol_Select"`
* `"RadioProtocol_Sent"`
* `"RadioProtocol_Stats"`
* `"RadioProtocol_Variables"`
* `"RadioProtocol_Words"`
* `"RscMapControl_colors"`
* `"RscMapControl_icons"`
* `"RscMapControl_fonts"`
}}

### Return Value

- String - data in wiki format

### Examples

#### Example 1

```sqf
["RadioProtocol_Sent"] call BIS_fnc_diagWiki;
```
