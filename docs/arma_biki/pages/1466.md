## a less= b

- Source: https://community.bistudio.com/wiki/a_less%3D_b
- Revision: 321223
- Updated: 2022-05-13T15:38:11Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math, Variables

### Description

Returns true if **a** is less than or equal to **b**, else returns false.

### Syntax

```sqf
a <= b
```

### Parameters

- a: Number
- b: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (fuel truck1 <= 0) then { hint "Truck1 has no fuel left." };
```
