## removeBinocularItem

- Source: https://community.bistudio.com/wiki/removeBinocularItem
- Revision: 310306
- Updated: 2022-05-05T13:24:30Z

- Availability: arma3 2.02
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes given weapon item, including magazine, from the binocular weapon.

### Syntax

```sqf
unit removeBinocularItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeBinocularItem "Laserbatteries";
```
