## getPosVisual

- Source: https://community.bistudio.com/wiki/getPosVisual
- Revision: 377526
- Updated: 2026-01-02T06:52:47Z

- Availability: arma3 1.32
- Locality: argument global
- Groups: Object Manipulation, Render Time Scope

### Description

Returns an object's AGLS position in render time scope. Alias of visiblePosition.
This command must **not** be used for actual 3D calculations. See getPos for more details.

### Syntax

```sqf
getPosVisual object
```

### Parameters

- object: Object - name of the object

### Return Value

- PositionAGLS

### Examples

#### Example 1

```sqf
_playerRenderedPos = getPosVisual player;
```
