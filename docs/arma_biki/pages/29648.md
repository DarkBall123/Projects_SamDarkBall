## serverNamespace

- Source: https://community.bistudio.com/wiki/serverNamespace
- Revision: 351793
- Updated: 2024-01-11T04:51:36Z

- Availability: arma3 2.06
- Locality: server execution server
- Groups: Namespaces, Variables, Multiplayer

### Description

Returns server's namespace.
This namespace is only available on the server for the server's uptime duration (same as uiNamespace).

All server event handlers, which are available in server config, use this namespace.

### Syntax

```sqf
serverNamespace
```


### Return Value

- Namespace on the server, Nothing on clients or in single-player.

### Examples

#### Example 1

```sqf
if (isServer) then
{
	hint str allVariables serverNamespace;
}
else
{
	hint "you do not have permission!";
};
```
