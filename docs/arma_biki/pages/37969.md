## isUsingAISteeringComponent

- Source: https://community.bistudio.com/wiki/isUsingAISteeringComponent
- Revision: 369751
- Updated: 2024-10-08T15:08:54Z

- Availability: arma3 2.18
- Groups: AI Behaviour

### Description

Returns whether the AI steering component setting is enabled globally.

### Syntax

```sqf
isUsingAISteeringComponent
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isUsingAISteeringComponent) then
{
	useAISteeringComponent false;
};
```
