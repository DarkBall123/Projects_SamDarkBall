## curatorAddons

- Source: https://community.bistudio.com/wiki/curatorAddons
- Revision: 377174
- Updated: 2026-01-01T10:46:28Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns list of addons allowed to given curator. The addon names are not guaranteed to be all lower case

### Syntax

```sqf
curatorAddons curatorObj
```

### Parameters

- curatorObj: Object - curator module

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
private _addons = curatorAddons myCurator;
```
