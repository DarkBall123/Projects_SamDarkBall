## BIS fnc validateParametersOO

- Source: https://community.bistudio.com/wiki/BIS_fnc_validateParametersOO
- Revision: 349337
- Updated: 2023-11-08T14:53:28Z

- Availability: arma3 1.00
- Groups: OO

### Description

Validating the parameters of a certain method in a class.

### Syntax

```sqf
[class,method,params] call BIS_fnc_validateParametersOO
```

### Parameters

- class: String - class name
- method: String - method used for validating (Taken from **class >> "Methods"**)
- params: Array - to be validated parameters

### Return Value

- Boolean - validating flag

### Examples

#### Example 1

```sqf
["someClass","someMethod",[5,47,"test"]] call BIS_fnc_validateParametersOO;
```
