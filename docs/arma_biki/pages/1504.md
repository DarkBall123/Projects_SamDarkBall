## removeMagazines

- Source: https://community.bistudio.com/wiki/removeMagazines
- Revision: 373502
- Updated: 2025-05-18T11:00:18Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes all magazines of given type from the unit. If magazine class does not exist, nothing happens, not even .rpt message, unlike with addMagazine command.

### Syntax

```sqf
unitName removeMagazines magazineName
```

### Parameters

- unitName: Object
- magazineName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeMagazines "30Rnd_556x45_Stanag";
```
