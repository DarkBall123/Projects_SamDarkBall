## particlesQuality

- Source: https://community.bistudio.com/wiki/particlesQuality
- Revision: 310765
- Updated: 2022-05-07T20:21:39Z

- Availability: arma3 0.50
- Locality: effect local
- Groups: Particles

### Description

Returns current user settings for particles quality (configure->video->general->particles). 0-low, 1-normal, 2-high

### Syntax

```sqf
**particlesQuality**
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
_currentQuality = particlesQuality;
```
