## BIS fnc zoomUnlock

- Source: https://community.bistudio.com/wiki/BIS_fnc_zoomUnlock
- Revision: 309295
- Updated: 2022-05-05T12:02:22Z

- Availability: arma3 1.78
- Groups: Map and Markers

### Description

Function that unlocks the camera in which has been previously locked with BIS_fnc_zoomLock.

### Syntax

```sqf
call BIS_fnc_zoomUnlock
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[] call BIS_fnc_zoomUnlock;
```
