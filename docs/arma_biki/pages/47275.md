## addMagazinesTurret

- Source: https://community.bistudio.com/wiki/addMagazinesTurret
- Revision: 377487
- Updated: 2026-01-02T06:49:07Z

- Availability: arma3 2.20
- Locality: argument local, effect global
- Groups: Turrets

### Description

Adds given number of a magazine to the given turret. Use turret path `[-1]` for driver's turret.

### Syntax

```sqf
vehicle addMagazinesTurret [magazineName, turretPath, quantity]
```

### Parameters

- vehicle: Object
- magazineName: String
- turretPath: Turret Path
- quantity: Number - desired number of the magazines

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_tank addMagazinesTurret ["20Rnd_120mmSABOT_M1A2", [0], 10];
```
