## setSpeedMode

- Source: https://community.bistudio.com/wiki/setSpeedMode
- Revision: 336415
- Updated: 2023-01-02T16:21:11Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Groups

### Description

Sets group speed mode. If unit is passed as param, unit's group is used. Mode may be one of: 
* **"UNCHANGED"** (unchanged)
* **"LIMITED"** (half speed)
* **"NORMAL"** (full speed, maintain formation)
* **"FULL"** (do not wait for any other units in formation)

### Syntax

```sqf
groupName setSpeedMode mode
```

### Parameters

- groupName: Object or Group
- mode: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_groupOne setSpeedMode "LIMITED";
```
