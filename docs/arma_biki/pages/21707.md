## allAirports

- Source: https://community.bistudio.com/wiki/allAirports
- Revision: 377737
- Updated: 2026-01-03T00:52:41Z

- Availability: arma3 1.76
- Groups: Roads and Airports

### Description

Returns all map airports, both static and dynamic.

### Syntax

```sqf
allAirports
```


### Return Value

- Array with [staticAirports, dynamicAirports]
* staticAirports: Array of Numbers - static airports IDs
* dynamicAirports: Array of Objects - dynamic airports objects (such as "DynamicAirport_01_F" found on aircraft carrier)

### Examples

#### Example 1

```sqf
_airplane landAt selectRandom (allAirports select 0);
```
