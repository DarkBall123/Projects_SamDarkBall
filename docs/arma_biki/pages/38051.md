## getCurrentPlayerLevel

- Source: https://community.bistudio.com/wiki/getCurrentPlayerLevel
- Revision: 351571
- Updated: 2023-12-07T16:53:56Z

- Availability: argo 1.00
- Groups: Argo

### Description

Get the level of the currently logged client.

### Syntax

```sqf
getCurrentPlayerLevel
```


### Return Value

- Number - the current player's level, or -1 if servers are unreachable

### Examples

#### Example 1

```sqf
if (getCurrentPlayerLevel > 9) then
{
	hint "Wow, you're good!";
};
```
