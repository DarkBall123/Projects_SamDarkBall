## shownScoretable

- Source: https://community.bistudio.com/wiki/shownScoretable
- Revision: 363424
- Updated: 2024-03-29T21:13:39Z

- Availability: arma3 1.60
- Groups: Interaction

### Description

Returns the state of the score table set with showScoretable command.

### Syntax

```sqf
shownScoretable
```


### Return Value

- Number - 0: Force hidden, 1: Force shown, -1: Default

### Examples

#### Example 1

```sqf
_state = shownScoretable;
```
