## didJIPOwner

- Source: https://community.bistudio.com/wiki/didJIPOwner
- Revision: 318912
- Updated: 2022-05-13T09:22:01Z

- Availability: arma3 1.50
- Locality: server execution server
- Groups: Multiplayer

### Description

Checks if the current owner of supplied Object Joined In Progress. Returns false on clients.

### Syntax

```sqf
didJIPOwner  object
```

### Parameters

- object: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_ownerDidJip = didJIPOwner tank;
```
