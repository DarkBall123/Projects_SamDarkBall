## buldozer enableRoadDiag

- Source: https://community.bistudio.com/wiki/buldozer_enableRoadDiag
- Revision: 310178
- Updated: 2022-05-05T13:10:30Z

- Availability: arma3 1.26
- Groups: System

### Description

Enables road diagnostics in buldozer.

### Syntax

```sqf
buldozer_enableRoadDiag enable
```

### Parameters

- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
buldozer_enableRoadDiag true;
```
