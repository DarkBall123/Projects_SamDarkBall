{{TOC|side}}
Zeus logic which provides access to the 3D real-time editor.

### Parameters

#### Owner

Unit with access to Zeus interface. Can be an object's variable name, player UID (Steam64 ID) or you can use #adminLogged or #adminVoted to give access to the server admin. In single player, the player will automatically assume control of game master module when this field is left blank. An error message will also be displayed:
 [BIS_fnc_moduleCurator] Curator owner not defined, player used instead in single player.

#### Name

Custom name displayed for other players.

#### Default addons

Which addons (ie., object packs) will be available at the beginning. You can unlock more using the Manage Addons module.
1. All addons (including unoffial ones)
1. All official addons - *Default*
1. Addons present in the scenario
1. None

#### Forced Interface

Open the interface by default and prevent the player from closing it.
1. Enabled
1. Disabled - *Default*
