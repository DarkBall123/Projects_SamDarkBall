## removeAllWeapons

- Source: https://community.bistudio.com/wiki/removeAllWeapons
- Revision: 352410
- Updated: 2024-02-09T15:16:20Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes all weapons and magazines from the given unit. Does not remove items like map, compass, radio (see removeWeapon for this).
Does not quite work with vehicles. If you need to remove all weapons from a vehicle, remove each weapon individually (see removeWeapon).

### Syntax

```sqf
removeAllWeapons unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllWeapons player;
```
