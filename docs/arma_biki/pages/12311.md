## setObjectViewDistance

- Source: https://community.bistudio.com/wiki/setObjectViewDistance
- Revision: 309992
- Updated: 2022-05-05T12:19:42Z

- Availability: arma3 0.50
- Locality: effect local
- Groups: System, Environment

### Description

Sets the rendering distance of objects and shadows.

### Syntax

```sqf
setObjectViewDistance objectDistance
```

```sqf
setObjectViewDistance [objectDistance, shadowDistance]
```

### Parameters

- objectDistance: Number
- objectDistance: Number
- shadowDistance: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
setObjectViewDistance 2000;
```

#### Example 2

```sqf
setObjectViewDistance [2000, 800];
```
