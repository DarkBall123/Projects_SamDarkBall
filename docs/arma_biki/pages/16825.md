## getPersonUsedDLCs

- Source: https://community.bistudio.com/wiki/getPersonUsedDLCs
- Revision: 352086
- Updated: 2024-02-01T23:24:46Z

- Availability: arma3 1.36
- Locality: argument global
- Groups: Broken Commands, DLC

### Description

Returns a list of all DLCs objects the unit is currently using. For example if a unit is inside a vehicle from DLC, it will return the code of that DLC.

### Syntax

```sqf
getPersonUsedDLCs unit
```

### Parameters

- unit: Object

### Return Value

- Array of Numbers

### Examples

#### Example 1

```sqf
_objects = getPersonUsedDLCs player;
```
