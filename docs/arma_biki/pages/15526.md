## allMines

- Source: https://community.bistudio.com/wiki/allMines
- Revision: 377194
- Updated: 2026-01-01T10:55:10Z

- Availability: arma3 1.24
- Groups: Mines

### Description

Returns an array of all mines in the mission

### Syntax

```sqf
allMines
```


### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
hint format ["there are %1 mines total", count allMines];
```

#### Example 2

```sqf
private _isFirstMineDetected = (allMines select 0) mineDetectedBy blufor;
```
