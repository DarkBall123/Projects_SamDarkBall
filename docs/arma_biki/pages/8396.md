## removeGroupIcon

- Source: https://community.bistudio.com/wiki/removeGroupIcon
- Revision: 363186
- Updated: 2024-03-25T09:04:50Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Remove icon with given ID from group.

### Syntax

```sqf
group removeGroupIcon iconID
```

### Parameters

- group: Group
- iconID: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_target removeGroupIcon (_target getVariable "hc_attackicon");
```
