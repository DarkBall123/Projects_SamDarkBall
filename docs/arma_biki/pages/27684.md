## tvSelection

- Source: https://community.bistudio.com/wiki/tvSelection
- Revision: 378378
- Updated: 2026-04-04T04:45:23Z

- Availability: arma3 2.02
- Groups: GUI Control - Tree View

### Description

Returns array of paths to selected items.

### Syntax

```sqf
tvSelection control
```

### Parameters

- control: Control

### Return Value

- Tree View Path

### Examples

#### Example 1

```sqf
private _selection = tvSelection _ctrlTV;
```
