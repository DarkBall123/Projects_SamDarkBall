## speed

- Source: https://community.bistudio.com/wiki/speed
- Revision: 376345
- Updated: 2025-10-07T16:59:25Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Object speed (in km/h). Returns relative speed of given object along Y axis. An equivalent to: 

```sqf
3.6 * (velocityModelSpace _obj select 1)
```

### Syntax

```sqf
speed object
```

### Parameters

- object: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
if (speed _truck1 >= 100) then { hint "You're going too fast!" };
```

#### Example 2

```sqf
if ((speed objectParent player) < 0) then { hint "You're going reverse!" };
```
