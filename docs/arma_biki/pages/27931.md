## menuSetURL

- Source: https://community.bistudio.com/wiki/menuSetURL
- Revision: 378344
- Updated: 2026-04-02T16:31:28Z

- Availability: arma3 2.02
- Groups: GUI Control - Menu

### Description

Sets weblink (URL) of given menu strip entry, subject to `allowedHTMLLoadURIs[]` whitelisting in CfgCommands config.

### Syntax

```sqf
menuSetURL [idc, path, link]
```

```sqf
control menuSetURL [path, link]
```

### Parameters

- idc: Number
- path: Tree View Path of Numbers
- link: String
- control: Control
- path: Tree View Path of Numbers
- link: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_ctrlMenuStrip menuSetURL [[0,0,1], "https://arma3.com/"];
```
