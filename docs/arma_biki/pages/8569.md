## addTeamMember

- Source: https://community.bistudio.com/wiki/addTeamMember
- Revision: 310084
- Updated: 2022-05-05T12:25:11Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Teams

### Description

Add given member to given team. Effect is local, unless both member and team are local to PC on which command is executed, then effect is global.

 The same Team Member can be member of several different teams at the same time.

### Syntax

```sqf
team addTeamMember member
```

### Parameters

- team: Team Member
- member: Team Member

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_team addTeamMember _teamMember;
```
