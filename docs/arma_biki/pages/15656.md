## BIS fnc invSlots

- Source: https://community.bistudio.com/wiki/BIS_fnc_invSlots
- Revision: 363571
- Updated: 2024-04-07T08:41:24Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Inventory

### Description

Returns config inventory slots of given unit (total numbers of available slots in array).

### Syntax

```sqf
[object] call BIS_fnc_invSlots
```

### Parameters

- object: Object

### Return Value

- Array - array with total available slots of all types that are given by config

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_invSlots;	// returns [1,1,1,8,12,1,0,12] for "B_T_Recon_TL_F" class
								// means: 1 x WeaponSlotPrimary, 1 x WeaponSlotHangun, ... , 12 x WeaponSlotInventory
```
