## cbChecked

- Source: https://community.bistudio.com/wiki/cbChecked
- Revision: 310825
- Updated: 2022-05-07T20:23:49Z

- Availability: arma3 1.12
- Groups: GUI Control

### Description

Returns the current state of a CT_CHECKBOX control.

### Syntax

```sqf
cbChecked control
```

### Parameters

- control : Control

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_checked = cbChecked _myCheckBox;
```
