## BIS fnc initRespawnBackpack

- Source: https://community.bistudio.com/wiki/BIS_fnc_initRespawnBackpack
- Revision: 323738
- Updated: 2022-07-01T11:53:37Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Init respawn backpack.
	Whover "assembles" it will receive a new respawn position.
	When backpack object has 'respawnNearbyPlayers' attribute set to 1, nearby player will receive the respawn as well.

### Syntax

```sqf
call BIS_fnc_initRespawnBackpack
```


### Return Value

- Boolean

### Examples

#### Example 1

call BIS_fnc_initRespawnBackpack;
