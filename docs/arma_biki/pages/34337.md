## getTowParent

- Source: https://community.bistudio.com/wiki/getTowParent
- Revision: 377973
- Updated: 2026-01-19T17:39:21Z

- Availability: arma3 2.12
- Locality: argument local
- Groups: PhysX, Ropes and Sling Loading

### Description

Get the vehicle towing the provided one.

### Syntax

```sqf
getTowParent towedVehicle
```

### Parameters

- towedVehicle: Object - the towed vehicle

### Return Value

- Object - the object towing the provided object - objNull if not towed

### Examples

#### Example 1

```sqf
private _towParent = getTowParent _towedVehicle;
```
