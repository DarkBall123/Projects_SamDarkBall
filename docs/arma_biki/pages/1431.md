Joins units into a given Group.

To make a unit leave its current group, join it into grpNull (e.g. 

```sqf
[MyUnit] join grpNull
```

) - but beware: A new group is created for the leaving unit; this could result in the number of groups growing out of control.

### Syntax

```sqf
unitArray join group
```

### Parameters

- unitArray: Array of Objects - units to join group
- group: Group or Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_unitOne, _unitTwo] join player;
```

#### Example 2

```sqf
[_unitOne, _unitTwo] join (group player);
```
