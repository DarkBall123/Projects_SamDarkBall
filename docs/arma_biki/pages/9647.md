## sendUDPMessage

- Source: https://community.bistudio.com/wiki/sendUDPMessage
- Revision: 351538
- Updated: 2023-12-06T23:45:43Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Multiplayer

### Description

Send message to given address using UDP protocol. Returns false if the message has not been delivered 

Disabled in retail version (see the talk page for more info).

### Syntax

```sqf
sendUDPMessage [ip, port, message]
```

### Parameters

- ip: String
- port: Number
- message: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_bool = sendUDPMessage ["192.168.0.1", 2302, "Here goes you message..."];
```
