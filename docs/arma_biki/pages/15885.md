## BIS fnc sortAlphabetically

- Source: https://community.bistudio.com/wiki/BIS_fnc_sortAlphabetically
- Revision: 348643
- Updated: 2023-11-08T13:48:23Z

- Availability: arma3 1.10
- Groups: Arrays, Strings

### Description

Alphabetically sort an array of strings without modifying the original. See also sort.

### Syntax

```sqf
arrayOfStrings call BIS_fnc_sortAlphabetically
```

### Parameters

- arrayOfStrings: Array of Strings

### Return Value

- Array of Strings sorted alphabetically.

### Examples

#### Example 1

```sqf
private _sortedNames = ["John", "Jane", "Julia", "Geronimo"] call BIS_fnc_sortAlphabetically; // will return ["Geronimo", "Jane", "John", "Julia"]
```
