## setThrottleRTD

- Source: https://community.bistudio.com/wiki/setThrottleRTD
- Revision: 377784
- Updated: 2026-01-03T01:32:42Z

- Availability: tkoh 1.00
- Groups: RTD

### Description

Set the throttle for the given engine(s) of a helicopter.

### Syntax

```sqf
helicopterRTD setThrottleRTD [value, engineIndex]
```

### Parameters

- helicopterRTD: ObjectRTD - helicopter
- value: Number - throttle level, range 0..1
* throttle 0: fully closed
* throttle ~0.15: average flight idle
* throttle 1: full
- engineIndex: Number - engine index
* engine index 0: engine #1
* engine index 1: engine #2
* engine index 2: engine #3
* engine index -1: all engines

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setThrottleRTD [0.5, 1];
```
