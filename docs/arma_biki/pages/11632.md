## throttleRTD

- Source: https://community.bistudio.com/wiki/throttleRTD
- Revision: 377773
- Updated: 2026-01-03T01:32:24Z

- Availability: tkoh 1.00
- Groups: RTD

### Description

Return the current throttle level for all engines of a helicopter.

### Syntax

```sqf
throttleRTD helicopterRTD
```

### Parameters

- helicopterRTD : ObjectRTD - helicopter

### Return Value

- Array

### Examples

#### Example 1

```sqf
_throttleValues = throttleRTD vehicle player;
```
