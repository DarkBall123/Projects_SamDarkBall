## hcSetGroup

- Source: https://community.bistudio.com/wiki/hcSetGroup
- Revision: 376359
- Updated: 2025-10-07T21:40:53Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Add group to unit's high command bar.

The previous HC leader should be removed before adding the new one (see **#Example 3**).

### Syntax

```sqf
unit hcSetGroup [group, groupName, team]
```

### Parameters

- unit: Object - the leader
- group: Group
- groupName: String - (Optional)
- team: String - (Optional, default "teamMain") can be one of:
* "teamMain"
* "teamRed"
* "teamGreen"
* "teamBlue"
* "teamYellow"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
unit hcSetGroup [_group, "HQ", "teamred"];
```

#### Example 2

```sqf
player hcSetGroup [_group];
```

#### Example 3

```sqf
if (player != hcLeader _group) then
{
	hcLeader _group hcRemoveGroup _group;
	player hcSetGroup [_group];
};
```
