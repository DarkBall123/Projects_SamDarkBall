## getFSMVariable

- Source: https://community.bistudio.com/wiki/getFSMVariable
- Revision: 330370
- Updated: 2022-09-04T20:25:49Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Variables

### Description

Return the value of variable in the variable space of given FSM. The FSM handle is the number returned by the execFSM command.

### Syntax

```sqf
FSMhandle getFSMVariable name
```

```sqf
FSMhandle getFSMVariable [name, defaultValue]
```

### Parameters

- FSMhandle: Number
- name: String - name of the variable
- FSMhandle: Number
- name: String - name of the variable
- defaultValue: Anything - value to return if variable is nil

### Return Value

- Anything
- Anything

### Examples

#### Example 1

```sqf
_handle getFSMVariable "_foo";
```

#### Example 2

```sqf
_handle getFSMVariable ["_foo", 123];
```
