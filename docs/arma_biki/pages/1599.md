## deleteIdentity

- Source: https://community.bistudio.com/wiki/deleteIdentity
- Revision: 348911
- Updated: 2023-11-08T14:40:02Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Unit Identity

### Description

Deletes an identity created with saveIdentity from the campaign's progress file.

### Syntax

```sqf
deleteIdentity  identityName
```

### Parameters

- identityName: String - name of the saved identity

### Return Value

- Boolean - true if the identity was deleted successfully, false if not

### Examples

#### Example 1

```sqf
_deleted = deleteIdentity "playerIdentity";
```
