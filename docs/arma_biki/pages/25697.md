- Updated: 2026-01-02T06:47:13Z

- Availability: arma3 1.92

### Description

Returns a guided missile's target position.

### Syntax

```sqf
missileTargetPos munition
```

### Parameters

- munition: Object

### Return Value

- PositionASL

### Examples

#### Example 1

```sqf
private _targetDistance = vehicle player distance missileTargetPos missile1;
```
