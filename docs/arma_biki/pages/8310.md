## lifeState

- Source: https://community.bistudio.com/wiki/lifeState
- Revision: 329358
- Updated: 2022-07-27T12:23:13Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Returns the life state of the given unit.
{{{!}} class="wikitable"
! {{arma2}}
! Arma 3
{{!}}-
{{!}}
* "ALIVE"
* "DEAD"
* "DEAD-RESPAWN"
* "DEAD-SWITCHING"
* "ASLEEP"
* "UNCONSCIOUS"
{{!}}
* "HEALTHY"
* "DEAD"
* "DEAD-RESPAWN"
* "DEAD-SWITCHING"
* "INCAPACITATED"
* "INJURED"
{{!}}}

{{Feature | arma3 | In Arma 3, lifeState seems to change to "INJURED" when 

```sqf
damage aliveUnit >= 0.1
```

 (0.1 seeming to be the value defined in config under {{sic|"InjuredTreshold"|Threshold}}). When the state is "INCAPACITATED", a sub-state is available via incapacitatedState command.}}

### Syntax

```sqf
lifeState unit
```

### Parameters

- unit: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
private _lifeState = lifeState player;
```
