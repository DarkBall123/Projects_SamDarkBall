## tvSetValue

- Source: https://community.bistudio.com/wiki/tvSetValue
- Revision: 321508
- Updated: 2022-05-17T11:23:14Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Sets scalar data to item on given path. IDC means id of parent Tree View. If the given value is not integer, it will be converted to integer

### Syntax

```sqf
tvSetValue [idc, path, val]
```

```sqf
ctrl tvSetValue [path, val]
```

### Parameters

- idc: Number
- path: Array of Numbers
- val: Number
- ctrl: Control
- path: Array of Numbers
- val: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvSetValue [101, [0], 555];
```

#### Example 2

```sqf
_ctrl tvSetValue [[0,0,0], 14];
```
