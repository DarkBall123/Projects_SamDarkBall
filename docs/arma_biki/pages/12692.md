## incapacitatedState

- Source: https://community.bistudio.com/wiki/incapacitatedState
- Revision: 341186
- Updated: 2023-05-13T22:13:49Z

{{RV|type=command

|game1= arma3
|version1= 1.00

|gr1= Object Manipulation

|descr= Returns the incapacitated sub-state of the given unit, when the lifeState of the unit is "INCAPACITATED". Could be one of:
- "UNCONSCIOUS"
- "MOVING"
- "SHOOTING"

|s1= incapacitatedState person

|p1= person: Object

|r1= String - incapacitated sub-state (see description) or empty string ""

|x1=

```sqf
_result = incapacitatedState player;
```

|seealso= setUnconscious lifeState
}}

This command returns "SHOOTING" (intentional behaviour?) when checking a unit's state while they are unconscious. Tested with BIS revive. I recommend just using the lifeState command instead.

Posted on 2019-12-29 - 21:13 (UTC)
Tankbuster

Returns
"UNCONSCIOUS" when awaiting revive.
"" when alive or when awaiting respawn. This means that when a unit dies instantly, ie through drowning, this command will return empty string throughout. As Haz says above, it sometimes show "SHOOTING" when the player is unconscious for reasons that are not clear.
