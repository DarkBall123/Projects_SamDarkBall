## ctrlParent

- Source: https://community.bistudio.com/wiki/ctrlParent
- Revision: 310860
- Updated: 2022-05-07T20:24:09Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns the parent Display of the given control. For parent Controls group see ctrlParentControlsGroup.

### Syntax

```sqf
ctrlParent control
```

### Parameters

- control: Control

### Return Value

- Display

### Examples

#### Example 1

```sqf
_display = ctrlParent _control;
```
