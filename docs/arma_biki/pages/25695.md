## setMissileTarget

- Source: https://community.bistudio.com/wiki/setMissileTarget
- Revision: 373564
- Updated: 2025-05-22T22:04:50Z

- Availability: arma3 1.92
- Groups: Object Manipulation, Weapons

### Description

Sets a guided missile target. Does not work for all types of missiles. If the target is dead, it is ignored. The target has to be inside the missile's configured targeting cone for the command to work.

### Syntax

```sqf
munition setMissileTarget target
```

```sqf
munition setMissileTarget [target, force]
```

### Parameters

- munition: Object - missile
- target: Object - valid missile target or objNull to cancel targeting
- munition: Object - missile
- target: Object - valid missile target or objNull to cancel targeting
- force: Boolean - true to force target (for example to target countermeasure flare object)

### Return Value

- Boolean - true if successful
- Boolean - true if successful

### Examples

#### Example 1

```sqf
missile1 setMissileTarget tank1;
```

#### Example 2

```sqf
private _missile = createVehicle ["Missile_AGM_01_F", player modelToWorld [0,0,50], [], 0, "CAN_COLLIDE"];
_missile setDir getDir player;
private _target = createVehicle ["O_APC_Wheeled_02_rcws_v2_F", player modelToWorld [0,300,0], [], 0, "CAN_COLLIDE"];
_target setVehicleTiPars [1, 1, 1];
[_missile, _target] spawn {
	params ["_missile", "_target"];
	sleep 0.1;
	_missile setMissileTarget _target;
};
```

#### Example 3

```sqf
_missile setMissileTarget objNull; // cancels targeting
```

#### Example 4

```sqf
_missile setMissileTarget [flare1, true];
```
