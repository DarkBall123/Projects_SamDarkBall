## isInRemainsCollector

- Source: https://community.bistudio.com/wiki/isInRemainsCollector
- Revision: 353433
- Updated: 2024-03-18T11:57:36Z

- Availability: arma3 1.32
- Locality: argument global
- Groups: Object Manipulation

### Description

Checks if unit or vehicle is queued for disposal after death.

### Syntax

```sqf
isInRemainsCollector remain
```

### Parameters

- remain: Object - vehicle or unit

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isInRemainsCollector unit1) then {hint "unit1 is queued for disposal"};
```
