## tvCount

- Source: https://community.bistudio.com/wiki/tvCount
- Revision: 319984
- Updated: 2022-05-13T09:25:50Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Returns children count on given path. IDC means id of parent Tree View.

### Syntax

```sqf
tvCount [idc, path]
```

```sqf
ctrl tvCount path
```

### Parameters

- idc: Number
- path: Array of Numbers
- ctrl: Control
- path: Array of Numbers

### Return Value

- Number
- Number

### Examples

#### Example 1

```sqf
tvCount [101, [0]];
```

#### Example 2

```sqf
_ctrl tvCount [1,0];
```
