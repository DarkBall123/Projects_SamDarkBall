## remove3DENEventHandler

- Source: https://community.bistudio.com/wiki/remove3DENEventHandler
- Revision: 369147
- Updated: 2024-09-03T10:34:38Z

- Availability: arma3 1.56
- Groups: Eden Editor, Event Handlers

### Description

Removes Eden Editor event handler of given type and ID.

See the list of all Eden Editor Event Handlers.

### Syntax

```sqf
remove3DENEventHandler [type,id]
```

### Parameters

- type: String - name of event handler
- id: Number - ID of event handler, returned by add3DENEventHandler

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
eh = add3DENEventHandler ["onUndo",{systemChat "Zip..."}];
remove3DENEventHandler ["onUndo",eh];
```
