## toUpperANSI

- Source: https://community.bistudio.com/wiki/toUpperANSI
- Revision: 339630
- Updated: 2023-04-28T14:11:56Z

- Availability: arma3 1.96
- Groups: Strings

### Description

thumb|right|ISO-8859-1Converts the supplied string to all upper case characters fast (could be 3x faster than toUpper).
[ANSI](https://stackoverflow.com/questions/701882/what-is-ansi-format/701920) in this case refers to [ISO-8859-1](https://en.wikipedia.org/wiki/ISO/IEC_8859-1) code page.
The command is primary designed to convert characters with codes 0...127 however will also convert other characters in 128...255 range as long as they are present in ISO-8859-1 codepage.
For Unicode alternative see toUpper.

### Syntax

```sqf
toUpperANSI string
```

### Parameters

- string: String - string to convert

### Return Value

- String - all upper case string

### Examples

#### Example 1

```sqf
hint toUpperANSI "AaBb1"; // returns "AABB1"
```
