## assignedGunner

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control, Object Manipulation

### Description

Returns the soldier assigned to the given vehicle as a gunner.

### Syntax

```sqf
assignedGunner vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Object

### Examples

#### Example 1

```sqf
_gunner = assignedGunner vehicle player;
```
