## ctrlURL

- Source: https://community.bistudio.com/wiki/ctrlURL
- Revision: 309293
- Updated: 2022-05-05T11:52:21Z

- Availability: arma3 2.02
- Groups: GUI Control

### Description

Returns the URL property of a button control. Getter for ctrlSetURL.

### Syntax

```sqf
ctrlURL control
```

### Parameters

- control: Control

### Return Value

- String

### Examples

#### Example 1

```sqf
private _ctrlUrl = ctrlURL _control; // e.g. "http://arma3.com/"
```
