## BIS fnc EXP camp dynamicAISkill

- Source: https://community.bistudio.com/wiki/BIS_fnc_EXP_camp_dynamicAISkill
- Revision: 364260
- Updated: 2024-05-06T09:38:26Z

- Availability: arma3 1.62
- Locality: server execution server
- Groups: Campaign

### Description

Changes AI skill based on player count, responding to player connected / player disconnected events. This function does exactly the same as BIS_fnc_EXP_camp_setSkill execept that it automatically executes when a player joins or disconnects.

### Syntax

```sqf
[mode, affectedSides] call BIS_fnc_EXP_camp_dynamicAISkill
```

### Parameters

- mode: Boolean - (Optional, default true) true to enable, false to disable
- affectedSides: Array - array of affected sides and their skill sets. For details see BIS_fnc_EXP_camp_setSkill

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[
	true,
	[
		[WEST, 0.1, 0.2, 0.7, 0.6],
		[EAST, 0.1, 0.2, 0.7, 0.6]
	]
] call BIS_fnc_EXP_camp_dynamicAISkill;
```
