## saveGame

- Revision: 311106
- Updated: 2022-05-10T14:30:26Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Autosaves the game (used for Retry). The saving is not started immediately, the request for autosave is made instead. To check the status of the request, use isSaving. The game can then be loaded from the last autosave with loadGame. Will not save if the player is null or dead.
Since 1.88 a `"OnSaveGame"` scripted event handler is available.

### Syntax

```sqf
saveGame
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
saveGame;
```
