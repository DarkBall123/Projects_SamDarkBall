## savingEnabled

- Source: https://community.bistudio.com/wiki/savingEnabled
- Revision: 342154
- Updated: 2023-07-09T12:26:50Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Check if saving the game is enabled.
If saving is disabled by Eden Editor mission attribute, this command will still return true.

### Syntax

```sqf
savingEnabled
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (savingEnabled) then
{
	hint "Saving is enabled!";
};
```
