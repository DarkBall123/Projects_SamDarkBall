## glanceAt

- Source: https://community.bistudio.com/wiki/glanceAt
- Revision: 377158
- Updated: 2026-01-01T10:39:40Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control

### Description

Control what the unit(s) is/are glancing at (target or Position). If target is used, it will get revealed fully.

How frequently the unit(s) is/are glancing there depends on behaviour.

### Syntax

```sqf
unit(s) glanceAt position
```

### Parameters

- unit(s): Object or Array of Objects
- position: Object or Position

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_someSoldier glanceAt _otherSoldier;
```

#### Example 2

```sqf
[_someSoldier, _otherSoldier] glanceAt markerPos "markerOne";
```
