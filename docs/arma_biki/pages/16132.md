## BIS fnc respawnNone

- Source: https://community.bistudio.com/wiki/BIS_fnc_respawnNone
- Revision: 348557
- Updated: 2023-11-08T13:39:18Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Create a death screen.

### Syntax

```sqf
[killed, killer] spawn BIS_fnc_respawnNone
```

### Parameters

- killed: Object - killed unit (player)
- killer: Object - any unit

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, someUnit] spawn BIS_fnc_respawnNone;
```
