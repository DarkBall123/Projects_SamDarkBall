## tvSetTooltip

- Source: https://community.bistudio.com/wiki/tvSetTooltip
- Revision: 377817
- Updated: 2026-01-03T04:13:45Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Sets the tooltip text associated with the specified tree view path.

### Syntax

```sqf
tvSetTooltip [idc, path, text]
```

```sqf
ctrl tvSetTooltip [path, text]
```

### Parameters

- idc: Number - IDC of the tree view control
- path: Tree View Path
- text: String
- ctrl: Control
- path: Tree View Path
- text: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvSetTooltip [101, [0,2], "This is a tooltip"];
```

#### Example 2

```sqf
_tree tvSetTooltip [[0,2], "This is a tooltip"];
```
