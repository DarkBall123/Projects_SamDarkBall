## BIS fnc laptopPlayVideo

- Source: https://community.bistudio.com/wiki/BIS_fnc_laptopPlayVideo
- Revision: 310729
- Updated: 2022-05-07T20:01:16Z

- Availability: arma3 1.72
- Locality: argument global
- Groups: Scripts

### Description

Plays an easter egg video on the screen of an old laptop.

### Syntax

```sqf
laptop call BIS_fnc_laptopPlayVideo
```

### Parameters

- laptop: Object - the old laptop to play the video on

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
this call BIS_fnc_laptopPlayVideo;
```
