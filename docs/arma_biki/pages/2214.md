|DESCRIPTION= WavToLip is an application that generates a lip files (*.lip) from wav files (*.wav).

|NOTES= **Usage:**

A lip file accompanies a sound file meant for spoken words in a mission. The file lip-syncs the mouth of the character to the spoken words in a sound file. It shares the same name of the sound file and must be in the same folder.

**Example:**
- talking1.ogg
- talking1.lip

**Known issues:**
The tool cannot process files with spaces in the name or path. Files on the desktop cannot be process for most users because of this.
