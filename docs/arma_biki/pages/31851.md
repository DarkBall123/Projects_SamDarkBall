## ctrlBackgroundColor

- Source: https://community.bistudio.com/wiki/ctrlBackgroundColor
- Revision: 377353
- Updated: 2026-01-02T06:40:17Z

- Availability: arma3 2.06
- Groups: GUI Control

### Description

Returns control's background color.

### Syntax

```sqf
ctrlBackgroundColor control
```

### Parameters

- control: Control

### Return Value

- Color (RGBA)

### Examples

#### Example 1

```sqf
ctrlBackgroundColor _control;
```
