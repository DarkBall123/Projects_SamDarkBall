## allowGetIn

- Source: https://community.bistudio.com/wiki/allowGetIn
- Revision: 318643
- Updated: 2022-05-13T09:21:14Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Object Manipulation, Unit Control

### Description

Set if the units given in the list are allowed to enter vehicles.
See AI Group Vehicle Management for more information.

### Syntax

```sqf
unitArray allowGetIn allow
```

### Parameters

- unitArray: Array of Objects
- allow: Boolean - true allows the units to enter, false denies them

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_soldier1, _soldier2] allowGetIn true;
```
