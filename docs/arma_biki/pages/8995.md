## unitsBelowHeight

- Source: https://community.bistudio.com/wiki/unitsBelowHeight
- Revision: 325197
- Updated: 2022-07-01T14:53:08Z

- Availability: arma2 1.04, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Detection, Positions

### Description

Returns units in group/array below given Above Terrain Level (ATL) altitude.
an object's ATL altitude can be found with 

```sqf
_altitude = (getPosATL _obj) select 2;
```

.

### Syntax

```sqf
units unitsBelowHeight height
```

```sqf
group unitsBelowHeight height
```

### Parameters

- units: Array of Objects
- height: Number - height above terrain level (PositionATL)
- group: Group - AI group
- height: Number - height above terrain level (PositionATL)

### Return Value

- Array of Objects
- Array of Objects

### Examples

#### Example 1

```sqf
_allOnGroudUnits = group player unitsBelowHeight 10;
```

#### Example 2

```sqf
_units = allUnits unitsBelowHeight 30;
```
