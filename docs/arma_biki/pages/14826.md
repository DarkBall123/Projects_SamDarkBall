## addCuratorPoints

- Source: https://community.bistudio.com/wiki/addCuratorPoints
- Revision: 376978
- Updated: 2026-01-01T06:07:36Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Adds or removes curator points.

### Syntax

```sqf
curatorObj addCuratorPoints points
```

### Parameters

- curatorObj: Object - curator module.
- points: Number in range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
curatorModule addCuratorPoints 0.5;
```
