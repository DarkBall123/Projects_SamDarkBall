## setVelocity

- Source: https://community.bistudio.com/wiki/setVelocity
- Revision: 378408
- Updated: 2026-04-04T08:14:56Z

- Availability: ofp 1.80, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Sets velocity vector of an object in m/s.

Since 2.06 each velocity component is limited to the range +-5000 m/s.

### Syntax

```sqf
object setVelocity vector
```

### Parameters

- object: Object
- vector: Vector3D

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_truck1 setVelocity [20, 0, 0];
```

#### Example 2

Advanced method used for relative acceleration:

```sqf
_vel = velocity _vehicle;
_dir = getDir _vehicle;
_additionalSpeed = 10; // in m/s
_vehicle setVelocity [
	(_vel select 0) + (sin _dir * _additionalSpeed), 
	(_vel select 1) + (cos _dir * _additionalSpeed), 
	(_vel select 2) // horizontal only
];
```
