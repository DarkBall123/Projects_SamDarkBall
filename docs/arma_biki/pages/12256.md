## isAbleToBreathe

- Source: https://community.bistudio.com/wiki/isAbleToBreathe
- Revision: 378057
- Updated: 2026-02-02T20:53:32Z

- Availability: arma3 0.50
- Groups: Object Manipulation

### Description

If unit is diving and doesn't have a rebreather, it returns false.
Diving means the unit's head is underwater. If unit is underwater and has a rebreather, the command returns true.

### Syntax

```sqf
isAbleToBreathe unit
```

### Parameters

- unit: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_canBreath = isAbleToBreathe player;
```
