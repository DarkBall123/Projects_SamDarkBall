## enableTeamSwitch

- Source: https://community.bistudio.com/wiki/enableTeamSwitch
- Revision: 310209
- Updated: 2022-05-05T13:10:42Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Team Switch

### Description

Enable / disable Team Switch. The default setting is enabled.

### Syntax

```sqf
enableTeamSwitch enable
```

### Parameters

- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableTeamSwitch true;
```
