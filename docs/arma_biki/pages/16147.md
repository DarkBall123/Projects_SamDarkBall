## BIS fnc friendlySides

- Source: https://community.bistudio.com/wiki/BIS_fnc_friendlySides
- Revision: 341628
- Updated: 2023-06-12T19:02:54Z

- Availability: arma3 1.00
- Groups: Sides

### Description

Returns sides allied to the given side / object.

### Syntax

```sqf
toCheck call BIS_fnc_friendlySides
```

### Parameters

- toCheck - Side or Object: Side or object whose friendly sides should be returned

### Return Value

- Array of Sides

### Examples

#### Example 1

```sqf
player call BIS_fnc_friendlySides; // -can- return [FRIENDLY,WEST,GUER,CIV]
```
