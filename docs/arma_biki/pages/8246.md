## enableSentences

- Source: https://community.bistudio.com/wiki/enableSentences
- Revision: 310190
- Updated: 2022-05-05T13:10:32Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Radio and Chat, Sounds

### Description

Enables radio transmissions to be heard and seen on screen. It does not affect KBTell conversations.

### Syntax

```sqf
enableSentences enable
```

### Parameters

- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableSentences false;
```
