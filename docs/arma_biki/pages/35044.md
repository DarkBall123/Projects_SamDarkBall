This article covers the basic setup and troubleshooting of Arma 3 on Mac.

See also:
- Arma 3: Play on Linux
- Arma 3: Experimental Ports

### Setup

1. Download and install the Steam client, create an account and purchase the [retail version of Arma 3](http://store.steampowered.com/app/107410/).
1. Install the game (it will automatically download the data for Mac, depending on the platform you are installing from).
1. The launch options will offer a choice of the default non-native version, and the more experimental native version.
#* Select *Play Arma 3* for the default non-native version.
#* Select *Launch experimental Apple silicon native version* for the experimental native version.
1. Click Play!

In some cases Steam client has difficulties downloading the game or an update on Mac.
A solution may be to go into *Settings* > *Privacy & Security* > *App Management*, and to allow Steam client permission to modify executables.

### Known Issues

- If the native version fails to launch and crashes with *E.MetalCachePrecompilation*, it may help to try deleting the pre-existing .DAT file found at *"~/Library/Application Support/com.vpltd.Arma3/eONprecompiledShaders.dat"*.

### BattlEye

Only the non-native version supports BattlEye anti-cheat.

### Mods

In order to launch Arma 3 with mods, they must be downloaded from the Steam Workshop or another source.
The mod directory should be moved into the game directory, then loaded using the game's Steam launch options.
There also exists a way to launch the game with mods via Terminal, or by making an Alias with the help of the Apple Script Editor.

{{Feature|important|
- Moving the folder will stop the mod from updating via Steam Workshop. If you want the Workshop to update the mods, you must write the whole path to the original folder.
- **Keep in mind that you need to start your path with `C:`**
- Launch Options Example: {{hl|-mod{{=}}C:/Users/macuser/Desktop/rhs}}
}}
{{Feature|important|
- Having whitespaces in your path may cause issues with parsing the launch options. You can use escape characters in this case.
- Launch Options Example: {{hl|-mod{{=}}\"C:/Users/UserName/Library/Application\ Support/Steam/steamapps/workshop/content/107410/123456789\"}}
}}

Most mods will work out of the box for Arma 3 on Mac (this may change in case the Windows version of the game gets updated, but the Mac port does not yet, since mods may rely on new platform features).

See [Muttley's Arma 3 Unix Launcher](https://github.com/muttleyxd/arma3-unix-launcher) for an alternative launcher that can be used to manage mods and launch options.
It can be installed from the project's "Releases" page or in one's respective package repository.

See also [viktorholk's Mod Manager Console](https://github.com/viktorholk/arma3-mod-manager-console).

#### Steam

1. Subscribe to and download the mod from the [https://steamcommunity.com/app/107410/workshop/ Steam Workshop].
1. Locate the folder with mods. Default path: `/Users/macuser/Library/Application Support/Steam/steamapps/workshop/content`
1. Look for folders with number IDs. Those should be the mods.
1. Open the game folder. Default path: `/Users/macuser/Library/Application Support/Steam/steamapps/common/Arma 3`
You can locate the game folder quickly by using Steam. Press {{Controls|RMB}} on Arma 3 → Manage → Browse local files
1. Copy (or [symlink](https://en.wikipedia.org/wiki/Symbolic_link)) the mod folder inside the game folder (in our example: 450814997)It is recommended to rename the copied folder to a simpler name (example: mod1)**Do not** place it in Addons folder!
1. Open Steam and go to Arma 3 properties once again.
1. Find `Launch Options` in the General tab and enter: {{hl|-mod{{=}}<directoryNameOrFullPath>}} (separate multiple mods by a semi-colon `;`)
#* Example 1: {{hl|-mod{{=}}mod1;mod2}}
#* Example 2: {{hl|-mod{{=}}C:/Users/macuser/Desktop/mod1}}
1. Close the properties and launch the game; the game should launch with the mod(s) loaded.

#### Terminal

1. Open the Terminal.
1. Write the following command:

```
open -a Arma3 --args -mod=<directoryName or directoryFullPath> -p default -no-remote
```

#* Example 1:

```
open -a Arma3 --args -mod=rhs -p default -no-remote
```

#* Example 2:

```
open -a Arma3 --args -mod=C:/Users/macuser/Desktop/rhs -p default -no-remote
```

1. Press Enter to confirm the command.
1. Press OK on the dialog that appeared; the game should launch with the selected mod(s) loaded.

#### Apple Script Editor

1. Open Script Editor.
1. Write command:

```
do shell script "open -a Arma3 --args -mod=<directoryName or directoryFullPath> -p default -no-remote"
```

#* Example 1:

```
do shell script "open -a Arma3 --args -mod=rhs -p default -no-remote"
```

#* Example 2:

```
do shell script "open -a Arma3 --args -mod=C:/Users/macuser/Desktop/rhs -p default -no-remote"
```

1. Go to File → Export.
1. Name the file and choose where it will be created (e.g the desktop) - change the File Format to **Application** and click **Save**.
1. The new custom-made Application should have now been created - close the Script Editor and open the created Application.
1. Hit OK on the dialog that appeared; the game should launch with the mod(s) loaded.

### Dedicated Server

1. Run the Steam client (if you do not start the normal game first, it will not let you launch after the Dedicated Server is on).
1. Run Arma 3 and wait for the game to get to the main menu.
1. Run Terminal.
1. Change the current directory to the path where the **Arma3.app** is - e.g.

```
cd ~/Library/Application\ Support/Steam/SteamApps/common/Arma\ 3/
```

.
1. Run the Dedicated Server by command:

```
./Arma3.app/Contents/MacOS/Arma3 --args -server -config=Server.cfg
```

.

### Cross-Platform Windows Compatibility

For now, the version of the Mac ports and primary Windows version should be compatible, at least until further Windows version updates.
When that happens, players on the Windows platform wishing to keep playing with players on the ports version must use the *legacyports* beta branch, as described below.

How to revert back to the compatible branch on Windows (not currently necessary):
1. Open the *Properties...* of Arma 3 in the Steam library
1. Open the *Betas* tab
1. Enter access code: *Arma3LegacyPorts*. This should unlock *legacyports - Legacy Build (2.20 - ports)*
1. Download and play together.
