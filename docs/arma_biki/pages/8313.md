## lnbAddColumn

- Source: https://community.bistudio.com/wiki/lnbAddColumn
- Revision: 378410
- Updated: 2026-04-04T08:30:26Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Adds a column at given position.

### Syntax

```sqf
control lnbAddColumn position
```

```sqf
lnbAddColumn [controlOrIdc, position]
```

### Parameters

- control: Control
- position: Number - position of the new column where 0 means all the way to the left and 1 all the way to the right of the control
- controlOrIdc: Control or Number - control or the idc of the control
- position: Number - position of the new column where 0 means all the way to the left and 1 all the way to the right of the control

### Return Value

- Number or Nothing - returns the zero based index of the new column
- Number or Nothing - returns the zero based index of the new column

### Examples

#### Example 1

```sqf
_ctrl lnbAddColumn 0.8;
```

#### Example 2

```sqf
lnbAddColumn [105, 0.8];
```
