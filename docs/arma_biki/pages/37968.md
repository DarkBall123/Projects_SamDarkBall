## selectThrowable

- Source: https://community.bistudio.com/wiki/selectThrowable
- Revision: 369741
- Updated: 2024-10-08T15:05:51Z

- Availability: arma3 2.18
- Groups: Weapons, Unit Inventory

### Description

Selects current throwable, which will be launched if the user presses {{Controls|G}}.

### Syntax

```sqf
unit selectThrowable throwable
```

### Parameters

- unit: Object
- throwable: String - either the name of the throwable magazine or the name of the throwable muzzle

### Return Value

- Boolean - true on success

### Examples

#### Example 1

```sqf
player selectThrowable "SmokeShellGreen";
```

#### Example 2

```sqf
player selectThrowable "SmokeShellGreenMuzzle";
```
