## BIS fnc vehicleRoles

- Source: https://community.bistudio.com/wiki/BIS_fnc_vehicleRoles
- Revision: 330776
- Updated: 2022-11-01T15:58:26Z

- Availability: arma3 1.00
- Groups: Vehicles

### Description

Returns vehicle roles.

### Syntax

```sqf
vehicle call BIS_fnc_vehicleRoles
```

### Parameters

- Object or String - vehicle itself or a classname

### Return Value

- Array - to format [<nowiki/>[role, path], [role, path], …] like this:

```sqf
[
	["Driver",[]],
	["Turret",[0]],
	["Turret",[0,0]],
	["Cargo",[0]],
	["Cargo",[1]],
	// ...
]
```

### Examples

#### Example 1

```sqf
cursorObject call BIS_fnc_vehicleRoles;
```

#### Example 2

```sqf
"B_MBT_01_cannon_F" call BIS_fnc_vehicleRoles;
```
