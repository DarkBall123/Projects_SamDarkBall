## BIS fnc locationDescription

- Source: https://community.bistudio.com/wiki/BIS_fnc_locationDescription
- Revision: 329682
- Updated: 2022-08-01T09:39:35Z

- Availability: arma3 1.00
- Groups: Map and Markers, Positions

### Description

Return location description (e.g. "NE of Agia Marina")

### Syntax

```sqf
position call BIS_fnc_locationDescription
```

### Parameters

- position: Position - (Optional, default 

```sqf
cameraOn call BIS_fnc_position
```

)

### Return Value

- String

### Examples

#### Example 1

```sqf
hint format ["Player's position: %1", player call BIS_fnc_locationDescription];
```
