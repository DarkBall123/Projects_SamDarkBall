## locationNull

- Source: https://community.bistudio.com/wiki/locationNull
- Revision: 321059
- Updated: 2022-05-13T12:19:56Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations, Variables

### Description

A non-existing Location. To compare non-existent locations use isNull or isEqualTo:

```sqf
locationNull == locationNull;			// false
isNull locationNull;					// true
locationNull isEqualTo locationNull;	// true
```

### Syntax

```sqf
locationNull
```


### Return Value

- Location

### Examples

#### Example 1

```sqf
!isNull locationNull; // false
```

#### Example 2

```sqf
str locationNull; // No location
```

#### Example 3

```sqf
position locationNull; // [0,0,0]
```
