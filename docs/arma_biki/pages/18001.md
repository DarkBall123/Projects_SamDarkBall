## logNetworkTerminate

- Source: https://community.bistudio.com/wiki/logNetworkTerminate
- Revision: 347532
- Updated: 2023-09-28T06:16:33Z

- Availability: arma3 1.56
- Groups: Multiplayer, Diagnostic

### Description

Terminates a network log file started with logNetwork with the given handle

### Syntax

```sqf
logNetworkTerminate handle
```

### Parameters

- handle:  Number - handle to terminate (created with logNetwork)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
logNetworkTerminate _someHandle;
```
