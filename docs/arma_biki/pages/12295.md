## cancelSimpleTaskDestination

- Revision: 320959
- Updated: 2022-05-13T10:04:50Z

- Availability: arma3 0.50

### Description

Cancels a simple task destination.

### Syntax

```sqf
cancelSimpleTaskDestination task
```

### Parameters

- task: Task

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
cancelSimpleTaskDestination myTask;
```
