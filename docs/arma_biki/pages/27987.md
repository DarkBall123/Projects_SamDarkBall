## tvSortByValueAll

- Source: https://community.bistudio.com/wiki/tvSortByValueAll
- Revision: 378327
- Updated: 2026-04-02T16:30:32Z

- Availability: arma3 2.02
- Groups: GUI Control - Tree View

### Description

Sorts all children, including trees deriving from given path.  Value of Tree View entries is used for sorting.

### Syntax

```sqf
control tvSortByValueAll [path, reversed]
```

### Parameters

- control: Control
- path: Tree View Path - path to start sorting from
- reversed: Boolean - true to reverse sort it.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl tvSortByValueAll [[], false]; // Sorts the complete Tree View
```
