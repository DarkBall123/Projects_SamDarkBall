## isOnRoad

- Source: https://community.bistudio.com/wiki/isOnRoad
- Revision: 377415
- Updated: 2026-01-02T06:45:20Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Roads and Airports

### Description

Checks if given position is inside road segment. Same as roadAt, only return is boolean instead of road object.

### Syntax

```sqf
isOnRoad position
```

### Parameters

- position: Object or PositionAGL (especially on bridges) or 2.00 Position2D, in which case Z will be automatically deduced as the height of the road surface

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_objOnRoad = isOnRoad player;
```

#### Example 2

```sqf
_posOnRoad = isOnRoad ASLToAGL getPosASL player;
```
