## getPhysicsCollisionFlag

- Source: https://community.bistudio.com/wiki/getPhysicsCollisionFlag
- Revision: 373902
- Updated: 2025-06-26T12:11:11Z

- Availability: arma3 2.18
- Locality: argument global
- Groups: PhysX

### Description

Returns the currently set physics collision flags.

### Syntax

```sqf
getPhysicsCollisionFlag object
```

### Parameters

- object: Object

### Return Value

- Array of Booleans - array of collision flags (only one value is returned for now)
