## BIS fnc taskCurrent

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskCurrent
- Revision: 352232
- Updated: 2024-02-01T23:26:09Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Returns unit's current task. See Arma 3: Task Framework for more information.

### Syntax

```sqf
unit call BIS_fnc_taskCurrent
```

### Parameters

- unit: Object - unit to be checked

### Return Value

- String - task ID

### Examples

#### Example 1

```sqf
private _currentTask = player call BIS_fnc_taskCurrent;
```
