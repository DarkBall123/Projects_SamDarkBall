## ropes

- Source: https://community.bistudio.com/wiki/ropes
- Revision: 340878
- Updated: 2023-05-13T21:30:53Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Returns all ropes attached to a ropes owner transport vehicle.

### Syntax

```sqf
ropes ropesOwner
```

### Parameters

- ropesOwner: Object - a transport from which the ropes originate

### Return Value

- Array of Objects - array of the actual rope objects

### Examples

#### Example 1

```sqf
hint str (ropes vehicle player);
```

#### Example 2

```sqf
_rope1 = (ropes heli1) select 0;
```
