## isDedicated

- Source: https://community.bistudio.com/wiki/isDedicated
- Revision: 337566
- Updated: 2023-02-10T01:14:00Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Multiplayer

### Description

Returns true if the machine executing the command is a dedicated multiplayer server. Returns false in single player.

### Syntax

```sqf
isDedicated
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isDedicated) then { diag_log "Dedicated Server on the run !"; };
```
