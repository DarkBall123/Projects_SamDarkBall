## diag resetShapes

- Source: https://community.bistudio.com/wiki/diag_resetShapes
- Revision: 310721
- Updated: 2022-05-07T19:53:41Z

- Availability: arma3 1.70
- Groups: Diagnostic

### Description

Reload models on-the-fly without the need of restarting the game.
Changes applied by **diag_resetShapes** are applied to all new entities so restart of mission is not necessarily  required - spawning vehicle again or changing back forth weapon should usually do the trick.
It works only with `-filePatching` in combination with local data. Command will reload **only** models present in local data.
Limitation: `CfgSkeletons` (inside `model.cfg`) cannot be reloaded.

### Syntax

```sqf
diag_resetShapes
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
diag_resetShapes;
```
