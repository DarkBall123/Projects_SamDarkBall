## isAISteeringComponentEnabled

- Source: https://community.bistudio.com/wiki/isAISteeringComponentEnabled
- Revision: 369774
- Updated: 2024-10-08T15:08:59Z

- Availability: arma3 2.18
- Locality: argument local
- Groups: AI Behaviour

### Description

Returns whether the AI steering component feature is enabled for the specified vehicle.

### Syntax

```sqf
isAISteeringComponentEnabled vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean - true if AI steering component is supported by the vehicle (i.e. defined in config) and enabled, false otherwise

### Examples

#### Example 1

```sqf
isAISteeringComponentEnabled myTank;
```
