## magazinesDetailUniform

- Source: https://community.bistudio.com/wiki/magazinesDetailUniform
- Revision: 377202
- Updated: 2026-01-01T11:36:50Z

- Availability: arma3 1.04
- Groups: Unit Inventory

### Description

Returns an array with the type names of all the unit's uniform magazines.

### Syntax

```sqf
magazinesDetailUniform unit
```

```sqf
magazinesDetailUniform [unit, includeEmpty, includeLoaded]
```

### Parameters

- unit: Object
- unit: Object - unit
- includeEmpty: Boolean - (Optional, default false) true to include empty magazines
- includeLoaded: Boolean - (Optional, default false) true to include magazines loaded in weapons (Since Arma 3 v2.07.148195)

### Return Value

- Array of Strings
- Array of Strings

### Examples

#### Example 1

```sqf
magazinesDetailUniform player;
/*
[
	"6.5 mm 30Rnd Sand Mag(30/30)[id/cr:10000003/0]",
	"Chemlight (Green)(1/1)[id/cr:10000020/0]"
]
*/
```

```sqf
magazinesDetailUniform player apply {
	private _reverse = reverse _x;

	private_i2 = (_reverse find ["/", _id1]) + 1;
	private_i3 = _reverse find ["(", _id2];
	parseNumber reverse (_reverse select [_i2, _i3 - _i2]); // return cnt
};
```
