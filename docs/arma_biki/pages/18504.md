## tvExpandAll

- Source: https://community.bistudio.com/wiki/tvExpandAll
- Revision: 330358
- Updated: 2022-09-03T09:09:58Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Expands all tree items for the given Tree View.

### Syntax

```sqf
tvExpandAll idc
```

```sqf
tvExpandAll control
```

### Parameters

- idc: Number
- control: Control

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvExpandAll 101;
```

#### Example 2

```sqf
tvExpandAll _ctrl;
```
