## lbTooltip

- Revision: 309997
- Updated: 2022-05-05T12:20:38Z

- Availability: arma3 2.06
- Groups: GUI Control

### Description

Returns tooltip for ListBox, ComboBox and Toolbox

### Syntax

```sqf
lbTooltip [idc, index]
```

```sqf
control lbTooltip index
```

### Parameters

- idc: Number
- index: Number
- control: Control
- index: Number

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
lbTooltip [1, 1];
```
