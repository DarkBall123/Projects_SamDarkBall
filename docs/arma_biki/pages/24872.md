## BIS fnc camera setFocus

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_setFocus
- Revision: 348055
- Updated: 2023-11-08T11:29:08Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Sets camera focus.

### Syntax

```sqf
[camera, focusValues] call BIS_fnc_camera_setFocus
```

### Parameters

- camera: Object - the camera
- focusValues: Array - (Optional, default [-1, -1]) focus values in format [distance, blur]

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera, [0.5,0.5]] call BIS_fnc_camera_setFocus;
```
