## getPosASLVisual

- Source: https://community.bistudio.com/wiki/getPosASLVisual
- Revision: 377445
- Updated: 2026-01-02T06:46:58Z

- Availability: arma3 1.32
- Locality: argument global
- Groups: Object Manipulation, Render Time Scope

### Description

Returns an object's rendered ASL position (z value above sea level) in render time scope.

### Syntax

```sqf
getPosASLVisual object
```

### Parameters

- object: Object - name of the object

### Return Value

- PositionASL

### Examples

#### Example 1

```sqf
private _playerRenderedPosASL = getPosASLVisual player;
```
