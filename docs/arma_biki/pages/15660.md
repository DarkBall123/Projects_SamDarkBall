## BIS fnc getFactions

- Source: https://community.bistudio.com/wiki/BIS_fnc_getFactions
- Revision: 327746
- Updated: 2022-07-13T11:00:20Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Sides

### Description

Gets list and sides of current factions.

### Syntax

```sqf
[parameter] call BIS_fnc_getFactions
```

### Parameters

- parameter:
* Nothing or empty Array - returns all factions
* Object - returns index of the object side
* Array - side of the first element is returned, others are ignored

### Return Value

- * Array of Strings
* Array of Sides
* Number - an index

### Examples

#### Example 1

```sqf
call BIS_fnc_getFactions; // returns all factions
```

#### Example 2

```sqf
[] call BIS_fnc_getFactions; // same as Example 1
```

#### Example 3

```sqf
[player] call BIS_fnc_getFactions; // returns index of player's faction
```

#### Example 4

```sqf
["BLU_F"] call BIS_fnc_getFactions; // returns index of given faction
```

#### Example 5

```sqf
[[]] call BIS_fnc_getFactions; // will return all faction sides
```

#### Example 6

```sqf
player call BIS_fnc_getFactions; // will return player's side
```
