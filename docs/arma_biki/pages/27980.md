## getAllPylonsInfo

- Source: https://community.bistudio.com/wiki/getAllPylonsInfo
- Revision: 378172
- Updated: 2026-03-03T11:43:19Z

- Availability: arma3 2.02
- Groups: Vehicle Loadouts

### Description

Return an array with the vehicle's all pylons info.

Note that the podObject can only be used for very few operations. It is not a real Entity.

Note until 2.22 the relativeDir orientation was inverted.

### Syntax

```sqf
getAllPylonsInfo vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array of Arrays in format [Pylon index, Pylon name, Assigned turret, Magazine className, Magazine ammo count, Magazine detail, 2.20 [relativePos, relativeDir, relativeUp]<nowiki/>, 2.22 podObject]
