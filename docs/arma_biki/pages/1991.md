## dissolveTeam

- Source: https://community.bistudio.com/wiki/dissolveTeam
- Revision: 322979
- Updated: 2022-06-28T21:42:55Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Groups

### Description

Dissolves the given team. All members become members of the main team.

### Syntax

```sqf
dissolveTeam teamColor
```

### Parameters

- teamColor: String - can be one of:
* "RED"
* "GREEN"
* "BLUE"
* "YELLOW"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
dissolveTeam "RED";
```
