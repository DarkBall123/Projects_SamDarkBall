## BIS fnc drawRespawnPositions

- Source: https://community.bistudio.com/wiki/BIS_fnc_drawRespawnPositions
- Revision: 349423
- Updated: 2023-11-08T16:27:33Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Draws respawn positions on the map which were added by BIS_fnc_addRespawnPosition.

### Syntax

```sqf
[state] call BIS_fnc_drawRespawnPositions
```

### Parameters

- state: Boolean - true to start drawing, false to end it

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[true] call BIS_fnc_drawRespawnPositions;
```
