## deleteStatus

- Source: https://community.bistudio.com/wiki/deleteStatus
- Revision: 348884
- Updated: 2023-11-08T14:39:49Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect global
- Groups: Object Manipulation

### Description

Deletes a status created with saveStatus from the campaign's progress file.

### Syntax

```sqf
deleteStatus statusName
```

### Parameters

- statusName: String - name of the saved status

### Return Value

- Boolean - true if the status was deleted successfully, false if not

### Examples

#### Example 1

```sqf
_deleted = deleteStatus "playerStatus";
```
