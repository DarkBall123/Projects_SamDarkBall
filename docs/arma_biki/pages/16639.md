## ctrlSetModelScale

- Source: https://community.bistudio.com/wiki/ctrlSetModelScale
- Revision: 318942
- Updated: 2022-05-13T09:22:05Z

- Availability: arma3 1.32
- Groups: GUI Control - Object, GUI Control - Positioning

### Description

Sets 3D control model scale

### Syntax

```sqf
control ctrlSetModelScale  scale
```

### Parameters

- control : Control - 3D control
- scale : Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl3D ctrlSetModelScale 1.5;
```
