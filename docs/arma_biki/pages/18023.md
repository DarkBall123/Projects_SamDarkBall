## ctrlAngle

- Source: https://community.bistudio.com/wiki/ctrlAngle
- Revision: 378507
- Updated: 2026-05-03T17:04:17Z

- Availability: arma3 1.52
- Groups: GUI Control - Positioning

### Description

Gets rotation info of a control set as `ST_PICTURE`. Supported control types:
* CT_STATIC
* 2.10 CT_ACTIVETEXT

### Syntax

```sqf
ctrlAngle control
```

### Parameters

- control: Control  - picture control

### Return Value

- Array with [angle, centerX, centerY]
* angle: Number
* centerX: Number
* centerY: Number

### Examples

#### Example 1

```sqf
ctrlAngle _control;
```
