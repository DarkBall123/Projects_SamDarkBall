## removeTeamMember

- Source: https://community.bistudio.com/wiki/removeTeamMember
- Revision: 310128
- Updated: 2022-05-05T12:25:41Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Teams

### Description

Remove given member from given team. Effect is local, unless both member and team are local to PC on which command is executed, then effect is global.

### Syntax

```sqf
team removeTeamMember member
```

### Parameters

- team: Team Member
- member: Team Member

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_team removeTeamMember _teamMember;
```
