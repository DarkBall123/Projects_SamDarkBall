## ropeAttachEnabled

- Source: https://community.bistudio.com/wiki/ropeAttachEnabled
- Revision: 309984
- Updated: 2022-05-05T12:17:03Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Returns true if entity can be attached to a rope end.

### Syntax

```sqf
ropeAttachEnabled entity
```

### Parameters

- entity: Object - entity to check

### Return Value

- Boolean - true if allowed

### Examples

#### Example 1

```sqf
ropeAttachEnabled veh1;
```
