## get3DENParent

- Source: https://community.bistudio.com/wiki/get3DENParent
- Revision: 370441
- Updated: 2024-12-09T16:33:11Z

- Availability: arma3 2.18
- Groups: Eden Editor

### Description

Obtains the provided entity's parent.

### Syntax

```sqf
get3DENParent entity
```

### Parameters

- entity: Object, Group, Array, Number, String - Eden Entity

### Return Value

- Object, Array, Number - Returns Eden Entity or the Eden ID representing it. -1 for system layers such as *BLUFOR*, *OPFOR* etc.

### Examples

#### Example 1

```sqf
private _parent = get3DENParent _myObject;
```
