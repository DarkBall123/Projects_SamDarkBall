## BIS fnc crossProduct

- Source: https://community.bistudio.com/wiki/BIS_fnc_crossProduct
- Revision: 327951
- Updated: 2022-07-13T12:58:34Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Vectors

### Description

Return the cross product of two 3D vectors.
Use vectorCrossProduct instead.

### Syntax

```sqf
[vector1, vector2] call BIS_fnc_crossProduct
```

### Parameters

- vector1: Array
- vector2: Array

### Return Value

- Array

### Examples

#### Example 1

```sqf
private _product = [[1,2,3], [3,2,1]] call BIS_fnc_crossProduct;
```
