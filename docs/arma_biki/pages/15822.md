## BIS fnc ctrlTextHeight

- Source: https://community.bistudio.com/wiki/BIS_fnc_ctrlTextHeight
- Revision: 349287
- Updated: 2023-11-08T14:51:15Z

- Availability: arma3 1.00
- Groups: GUI

### Description

Resize control according to it is text.

### Syntax

```sqf
[control] call BIS_fnc_ctrlTextHeight
```

### Parameters

- control: Control - the control which should changed

### Return Value

- Boolean - true

### Examples

#### Example 1

```sqf
[_ctrl] call BIS_fnc_ctrlTextHeight;
```
