## isSteamMission

- Source: https://community.bistudio.com/wiki/isSteamMission
- Revision: 369183
- Updated: 2024-09-03T10:34:45Z

- Availability: arma3 0.74
- Groups: Mission Information

### Description

Returns true if the current mission is a Steam Workshop mission.

### Syntax

```sqf
**isSteamMission**
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isSteamMission) then
{
	hint "Thank you for subscribing to my mission on Steam!";
}
else
{
	hint "Thank you for downloading my mission off the Internet!";
};
```
