## BIS fnc commsMenuCreate

- Source: https://community.bistudio.com/wiki/BIS_fnc_commsMenuCreate
- Revision: 309303
- Updated: 2022-05-05T12:04:22Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Communication Menu

### Description

Creates the global communications menu, if it is not already created. All entries are invisible by default. Unhide appropriate sections by using BIS_fnc_commsMenuToggleVisibility.

### Syntax

```sqf
call BIS_fnc_commsMenuCreate
```


### Return Value

- Boolean - true if successful

### Examples

#### Example 1

```sqf
call BIS_fnc_commsMenuCreate;
```
