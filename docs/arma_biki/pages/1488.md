## onBriefingGear

- Source: https://community.bistudio.com/wiki/onBriefingGear
- Revision: 323001
- Updated: 2022-06-28T21:43:03Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00
- Groups: Event Handlers, Sounds, Briefing

### Description

Select a sound declared in the Description.ext of the mission to be played the first time the Gear tab is selected in the briefing.

### Syntax

```sqf
onBriefingGear  soundName
```

### Parameters

- soundName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
onBriefingGear "GearVoiceOver";
```
