## floor

- Source: https://community.bistudio.com/wiki/floor
- Revision: 369333
- Updated: 2024-09-03T18:43:00Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

Returns the next **lowest** integer in relation to the provided number.

### Syntax

```sqf
floor num
```

### Parameters

- num: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
floor 5.1;		// result is  5
floor 5.999;	// result is  5
floor -2.01;	// result is -3
floor -2.99;	// result is -3
```
