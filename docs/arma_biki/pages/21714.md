## enableVehicleSensor

- Source: https://community.bistudio.com/wiki/enableVehicleSensor
- Revision: 349214
- Updated: 2023-11-08T14:50:48Z

- Availability: arma3 1.72
- Locality: argument global, effect local
- Groups: Sensors

### Description

Enable/disable given sensor

### Syntax

```sqf
vehicle enableVehicleSensor [componentName, enabled]
```

### Parameters

- vehicle: Object
- componentName : String - the component's name (can either be its "real name" or its className)
- enabled: Boolean - component status

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player enableVehicleSensor ["PassiveRadarSensorComponent", false]; // disables passive radar
```
