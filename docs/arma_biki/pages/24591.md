## BIS fnc timeline setPlayRate

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_setPlayRate
- Revision: 348110
- Updated: 2023-11-08T11:32:00Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Sets playrate of timeline.

### Syntax

```sqf
[timeline, rate] call BIS_fnc_timeline_setPlayRate
```

### Parameters

- timeline: Object - the timeline object
- rate: Boolean - (Optional, default 1) play rate

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[timeline,2] call BIS_fnc_timeline_setPlayRate;
```
