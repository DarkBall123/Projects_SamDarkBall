|descr= Sets text color of given control. As of Arma 3 v1.40 this command can also be used to change fill-color of a CT_PROGRESS control.

Also try ctrlSetForegroundColor, if this command doesn't have the desired effect.

|s1= control ctrlSetTextColor color

|p1= control: Control

|p2= color: Color (RGBA)

|r1= Nothing

|x1=

