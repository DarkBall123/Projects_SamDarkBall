## BIS fnc threat

- Source: https://community.bistudio.com/wiki/BIS_fnc_threat
- Revision: 349272
- Updated: 2023-11-08T14:51:10Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Combat

### Description

Calculates threat values of given unit.

### Syntax

```sqf
[unit] call BIS_fnc_threat
```

### Parameters

- unit: Object - given unit

### Return Value

- Number - threat level in range from 0 to 3

### Examples

#### Example 1

```sqf
private _threatLevel = [player] call BIS_fnc_threat;
```
