## toArray

- Source: https://community.bistudio.com/wiki/toArray
- Revision: 377121
- Updated: 2026-01-01T10:18:13Z

- Availability: arma1 1.09, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays, HashMap, Strings

### Description

Converts the supplied String into an Array of Numbers. The numbers in the created array are the decimal [Unicode](https://en.wikipedia.org/wiki/Unicode) representations of characters.
Since v2.04 this command can also handle HashMaps. See alternative syntax.

### Syntax

```sqf
toArray string
```

```sqf
toArray hashMap
```

```sqf
hashMap toArray splitArrays
```

### Parameters

- string: String
- hashMap: HashMap
- hashMap: HashMap
- splitArrays: Boolean - see return value

### Return Value

- Array of Numbers
- Array - array in format [[key, key, ...], [value, value, ...]]
- Array - array in either one of the following formats:
* splitArrays: true - `[<nowiki/>[key1, key2, ...], [value1, value2, ...]]`
* splitArrays: false - `[<nowiki/>[key1, value1], [key2, value2], ...]` This is **very inefficient** since the engine has to create many small arrays

### Examples

#### Example 1

```sqf
hint format ["%1", toArray "AaŒ"];// Returns "[65,97,338]"
```

#### Example 2

```sqf
toArray _hashMap params ["_keys", "_values"];
```

#### Example 3

```sqf
private _hashmap = ["cow", "cat", "chicken"] createHashMapFromArray [10000, 20000, 20000];
_hashmap toArray true;	// returns [["cow", "cat", "chicken"], [10000, 20000, 20000]] - same as Syntax 2
_hashmap toArray false;	// returns [["cow", 10000], ["cat", 20000], ["chicken", 20000]]
```
