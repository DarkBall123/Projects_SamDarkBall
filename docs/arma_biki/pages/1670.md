|gr1= Unit Control

|descr= Order the given unit(s) to watch the given position or target (without radio messages). Use objNull as the target to order a unit to stop watching a position/target.

|s1= unit(s) doWatch position

|p1= unit(s): Object or Array of Objects

|p2= position: Position

|r1= Nothing

|s2= unit(s) doWatch  target

|p21= unit(s): Object or Array of Objects

|p22= target: Object

|r2= Nothing

|x1=

```sqf
_soldierOne doWatch markerPos "MarkerMoveOne";
```

The unit named "soldierOne" will watch the position where the marker "MarkerMoveOne" is placed.

|x2=

```sqf
_soldierOne doWatch _eastSoldier;
```

The unit named "soldierOne" will watch the unit named "eastSoldier".
