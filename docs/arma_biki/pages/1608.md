## doFire

- Source: https://community.bistudio.com/wiki/doFire
- Revision: 378648
- Updated: 2026-05-17T15:10:41Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Control

### Description

Order the given unit(s) to fire on the given target (without radio messages).

The target is set with doTarget or commandTarget.

The target can be a unit or a vehicle, but not an object.

### Syntax

```sqf
unit doFire target
```

### Parameters

- unit: Object or Array of Objects
- target: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ESoldier1 doFire _WSoldier1;
```
