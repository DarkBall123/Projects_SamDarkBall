## BIS fnc initVehicleKart

- Source: https://community.bistudio.com/wiki/BIS_fnc_initVehicleKart
- Revision: 348244
- Updated: 2023-11-08T11:40:32Z

- Availability: arma3 1.20
- Groups: Vehicles

### Description

Customise given kart and its driver.

### Syntax

```sqf
[kart,number,livery,raceTeam] call BIS_fnc_initVehicleKart
```

### Parameters

- kart: Object
- number: Array - (Optional, default [-1,-1]) kart number from 00 to 99
- livery: Number - (Optional, default *Random*) kart livery. A integer from 0 to 9
- raceTeam: Number - (Optional, default *Matches the livery*) driver uniform

### Return Value

- Boolean - always true

### Examples

#### Example 1

```sqf
[BIS_kart, [9,7], -1, -1] call BIS_fnc_initVehicleKart;
```
