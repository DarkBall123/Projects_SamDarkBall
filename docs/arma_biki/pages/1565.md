## getMarkerType

- Source: https://community.bistudio.com/wiki/getMarkerType
- Revision: 348864
- Updated: 2023-11-08T14:39:13Z

- Availability: ofp 1.21, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Markers

### Description

Gets type of marker. See CfgMarkers for a list of standard markers.

### Syntax

```sqf
getMarkerType  markerName
```

### Parameters

- markerName: String

### Return Value

- String - marker class name. See CfgMarkers.

### Examples

#### Example 1

```sqf
if (getMarkerType "Marker1" == "") then { hint "Marker1 is not an icon!" };
```
