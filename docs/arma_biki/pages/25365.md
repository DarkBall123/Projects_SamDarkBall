## lnbSetTooltip

- Source: https://community.bistudio.com/wiki/lnbSetTooltip
- Revision: 349264
- Updated: 2023-11-08T14:51:08Z

- Availability: arma3 1.94
- Groups: GUI Control - ListNBox

### Description

Sets tooltip on the item with the given row and column of CT_LISTNBOX.
By default, tooltips are added for all columns no matter what column index is provided.
This behaviour can be overwritten since 2.02 by setting the control's property `tooltipPerColumn` to true.
See CT_LISTNBOX documentation.

### Syntax

```sqf
lnbSetTooltip [idc, [row, column], text]
```

```sqf
ctrl lnbSetTooltip [<nowiki/>[row, column], text]
```

### Parameters

- idc: Number - control's IDC
- row: Number - row where the tooltip should be shown
- column: Number - column where tooltip should be shown. By default it is set for every column, see description
- text: String - tooltip text
- ctrl: Control - control
- row: Number - row where the tooltip should be shown
- column: Number - column where tooltip should be shown. By default it is set for every column, see description
- text: String - tooltip text

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lnbSetTooltip [1234, [1,0], "tip"];
```

#### Example 2

```sqf
_ctrl lnbSetTooltip [[3,0], "top"];
```
