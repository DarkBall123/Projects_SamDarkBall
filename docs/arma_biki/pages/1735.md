## someAmmo

### Description

Check if unit has some ammo.

### Syntax

```sqf
someAmmo unitName
```

### Parameters

- unitName: Object

### Return Value

- Boolean

### Examples

#### Example 1

<sqs>? not (someAmmo _loon1) : hint "Loon1 is out of ammo!"</sqs>

#### Example 2

```sqf
if (not someAmmo _loon1) then { hint "Loon1 is out of ammo!" };
```
