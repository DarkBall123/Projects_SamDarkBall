## speaker

- Source: https://community.bistudio.com/wiki/speaker
- Revision: 319837
- Updated: 2022-05-13T09:25:34Z

- Availability: arma3 1.02
- Groups: Unit Identity, Sounds

### Description

Returns the speaker class name of a unit.

### Syntax

```sqf
speaker unit
```

### Parameters

- unit: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
speaker player; // Can return "male09eng"
```
