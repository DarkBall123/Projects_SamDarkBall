## getPlayerScores

- Source: https://community.bistudio.com/wiki/getPlayerScores
- Revision: 376996
- Updated: 2026-01-01T08:04:57Z

- Availability: arma3 1.56
- Groups: Multiplayer

### Description

Returns the unit's table of scores (infantry kills, soft vehicle kills, armor kills, air kills, deaths, total score) **in multiplayer** or an empty array in singleplayer.
This command does not work (returns empty array) if the unit's side has been changed (e.g 

```sqf
[player] joinSilent createGroup east
```

).

### Syntax

```sqf
getPlayerScores unitName
```

### Parameters

- unitName: Object

### Return Value

- Array with [killsInfantry, killsSoft, killsArmor, killsAir, score]
* killsInfantry: Number - number of infantry units killed
* killsSoft: Number - number of soft vehicles killed
* killsArmor: Number - number of armored vehicles killed
* killsAir: Number - number of air vehicles killed
* score: Number - total score

### Examples

#### Example 1

```sqf
getPlayerScores BIS_player1;	// e.g [4, 0, 3, 1, 2, 16]
								// or in SP: []
```
