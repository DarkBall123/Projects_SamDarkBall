## lbSetData

- Source: https://community.bistudio.com/wiki/lbSetData
- Revision: 319184
- Updated: 2022-05-13T09:23:19Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListBox

### Description

Sets the additional text (invisible) in the item with the given index of the listbox or combobox with id idc of the topmost user dialog to the given data.

See more information on the CT_LISTBOX command family here.

### Syntax

```sqf
lbSetData [idc, index, data]
```

```sqf
control lbSetData [index, data]
```

### Parameters

- idc: Number - control's IDC
- index: Number
- data: String
- control: Control
- index: Number
- data: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lbSetData [101, 1, "#1"];
```

#### Example 2

```sqf
_control lbSetData [1, "#1"];
```
