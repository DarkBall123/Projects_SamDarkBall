## BIS fnc wpSlingLoadAttach

- Source: https://community.bistudio.com/wiki/BIS_fnc_wpSlingLoadAttach
- Revision: 349275
- Updated: 2023-11-08T14:51:11Z

- Availability: tkoh 1.00
- Groups: Waypoints

### Description

ATTACH SLINGLOAD custom waypoint.

Load an object to rope.

### Syntax

```sqf
Custom Waypoint arguments: [posLimit, failCode, weight]
```

### Parameters

- posLimit: Number or Boolean - time in seconds it takes to attach the cargo. When true, cargo is attached immediately (default: -1)
- failCode: Code - code executed if rope is cut by accident (e.g. collision with another object) (default: {})
- weight: Number - cargo weight (default: model weight)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, dude, 50, 10, { hintC "You lost the cargo!" }, 1000] spawn BIS_fnc_wpSlingLoadAttach;
```

#### Example 2

```sqf
[player, dude, 0, true] spawn BIS_fnc_wpSlingLoadAttach; // attaches the cargo immediately
```
