### Description

Gets FOV of camera.

### Syntax

```sqf
[camera] call BIS_fnc_camera_getFOV
```

### Parameters

- camera: Object - the camera

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera] call BIS_fnc_camera_getFOV;
```
