## isUAVConnected

- Source: https://community.bistudio.com/wiki/isUAVConnected
- Revision: 378863
- Updated: 2026-07-27T13:47:06Z

- Availability: arma3 0.76
- Locality: argument global, effect local
- Groups: Remote Control

### Description

Returns true if UAV is connected to some terminal. Terminal connection is handled locally, therefore the result of this command will be returned only for the client on which this command is executed.

### Syntax

```sqf
isUAVConnected uav
```

### Parameters

- uav: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isConnected = isUAVConnected cursorTarget;
```
