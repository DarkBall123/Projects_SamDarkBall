## Arma 3: Module: Combat Get In

- Source: https://community.bistudio.com/wiki/Arma_3:_Module:_Combat_Get_In
- Revision: 339843
- Updated: 2023-04-28T16:20:23Z

### Introduction:
Bohemia Interactive's Combat Get In module allows you to easily set up crew behavior to a team in your missions.

When the troops reach combat mode, for example after identifying an enemy, they will climb aboard the linked vehicle.

### Properties:

This module doesn't have any property.

### How to:

Open the editor and create the module "Group Modifiers\Combat Get In". Synchronize it with the crew group leader, and with the empty vehicle to get in.
