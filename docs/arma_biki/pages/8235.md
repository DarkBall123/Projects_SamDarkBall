## diarySubjectExists

- Source: https://community.bistudio.com/wiki/diarySubjectExists
- Revision: 322992
- Updated: 2022-06-28T21:42:59Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Briefing

### Description

Checks whether given subject is present in the Diary of given player.

### Syntax

```sqf
player diarySubjectExists  name
```

### Parameters

- player: Object
- name: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_exists = player diarySubjectExists "subjectName";
```
