## BIS fnc selectRandom

- Source: https://community.bistudio.com/wiki/BIS_fnc_selectRandom
- Revision: 348921
- Updated: 2023-11-08T14:44:05Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Arrays

### Description

Selects one of the arguments at random.
Use selectRandom instead.

### Syntax

```sqf
values call BIS_fnc_selectRandom
```

### Parameters

- values: Array - array of values of which one will be selected at random

### Return Value

- Anything - one of the values you passed, chosen at random

### Examples

#### Example 1

```sqf
private _bestShooter = [_rento, _ben, _trit] call BIS_fnc_selectRandom; // returns one of the variables
_bestSeries = [["halo1","halo2"],["ofp","arma2"]] call BIS_fnc_selectRandom; // returns one of the arrays
```
