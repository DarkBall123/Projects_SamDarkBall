## setDiaryRecordText

- Source: https://community.bistudio.com/wiki/setDiaryRecordText
- Revision: 322036
- Updated: 2022-05-23T22:41:48Z

- Availability: arma3 1.96
- Groups: Briefing

### Description

Set text of a log record.

### Syntax

```sqf
unit setDiaryRecordText [[subject, diaryRecord], [title, text, icon]]
```

### Parameters

- unit: Object
- subject: String
- diaryRecord: Diary Record
- title: String
- text: String
- icon: String - (Optional) icon to show next to the title. "" to remove.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setDiaryRecordText [["diary", _diaryRec], ["Kill all enemies.", "The enemies are the bad guys. Kill them because you are the good guy."]];
```
