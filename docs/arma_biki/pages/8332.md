## lnbValue

- Source: https://community.bistudio.com/wiki/lnbValue
- Revision: 319419
- Updated: 2022-05-13T09:24:03Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Returns the additional integer value in the item with the given position of the 2D listbox.

### Syntax

```sqf
lnbValue [idc, [row, column]]
```

```sqf
ctrl lnbValue [row, column]
```

### Parameters

- idc: Number
- row: Number
- column: Number
- ctrl: Control
- row: Number
- column: Number

### Return Value

- Number
- Number

### Examples

#### Example 1

```sqf
_ctrl lnbValue [0,0]; // 1, default is 0 if value is String set by lnbSetValue
```
