## setSuppression

- Source: https://community.bistudio.com/wiki/setSuppression
- Revision: 376979
- Updated: 2026-01-01T06:08:32Z

- Availability: arma3 1.42
- Locality: argument local
- Groups: Object Manipulation

### Description

Sets the given suppression value for the given unit.

### Syntax

```sqf
unit setSuppression value
```

### Parameters

- unit: Object
- value: Number in range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
unit_1 setSuppression 1;
```
