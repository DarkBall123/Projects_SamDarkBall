## setHorizonParallaxCoef

- Source: https://community.bistudio.com/wiki/setHorizonParallaxCoef
- Revision: 309900
- Updated: 2022-05-05T12:16:47Z

- Availability: arma3 0.50
- Groups: Camera Control, System

### Description

Sets coef used to shift horizon position based on camera height (use 0 to disable shifting).

### Syntax

```sqf
setHorizonParallaxCoef coef
```

### Parameters

- coef: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setHorizonParallaxCoef 1;
```
