## saveStatus

- Source: https://community.bistudio.com/wiki/saveStatus
- Revision: 337534
- Updated: 2023-02-06T23:57:52Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool, Mission Information

### Description

Saves object's properties to Objects.sav file in campaign directory as entry name.

### Syntax

```sqf
object saveStatus name
```

### Parameters

- object: Object
- name: String

### Return Value

- Boolean - true if successful, otherwise false

### Examples

#### Example 1

```sqf
player saveStatus "playerstate";
```
