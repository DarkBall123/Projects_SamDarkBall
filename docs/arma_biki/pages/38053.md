## getNextId

- Source: https://community.bistudio.com/wiki/getNextId
- Revision: 351573
- Updated: 2023-12-07T17:08:20Z

- Availability: argo 1.00
- Groups: Argo

### Description

Generate a new random-based UUID version 4 string as described in https://tools.ietf.org/html/rfc4122#section-4.4.

### Syntax

```sqf
getNextId
```


### Return Value

- String

### Examples

#### Example 1

```sqf
_uuid = getNextId; // e.g 5806a469-d1b2-404c-b0ac-8e51d0f533e4
```
