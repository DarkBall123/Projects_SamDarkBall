## markerBrush

- Source: https://community.bistudio.com/wiki/markerBrush
- Revision: 322955
- Updated: 2022-06-28T21:42:49Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Markers

### Description

Gets the marker brush. See setMarkerBrush.

### Syntax

```sqf
markerBrush name
```

### Parameters

- name: String - marker name

### Return Value

- String

### Examples

#### Example 1

```sqf
if (markerBrush "Marker1" == "Solid") then { hint "Marker1 is solid!" };
```
