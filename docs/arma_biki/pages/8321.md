## lnbGetColumnsPosition

- Source: https://community.bistudio.com/wiki/lnbGetColumnsPosition
- Revision: 377147
- Updated: 2026-01-01T10:34:03Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Returns relative screen X of ListNBox control columns position [0.1,0.3,0.6...]. Use lnbSetColumnsPos to set positions.

### Syntax

```sqf
lnbGetColumnsPosition _ctrl
```

### Parameters

- _ctrl: Control

### Return Value

- Array of Numbers

### Examples

#### Example 1

```sqf
lnbGetColumnsPosition _ctrl;
```
