## BIS fnc missionRespawnType

- Source: https://community.bistudio.com/wiki/BIS_fnc_missionRespawnType
- Revision: 327021
- Updated: 2022-07-12T21:44:45Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Return respawn type defined in Description.ext. Can return as Number (e.g 1) or String (e.g "BIRD").

### Syntax

```sqf
type call BIS_fnc_missionRespawnType
```

### Parameters

- type: Number or String - wanted return value type

### Return Value

- Number or String - return type depends on *type*

### Examples

#### Example 1

```sqf
private _respawnAsNumber = 0 call BIS_fnc_missionRespawnType;
```

#### Example 2

```sqf
private _respawnAsString = "" call BIS_fnc_missionRespawnType;
```
