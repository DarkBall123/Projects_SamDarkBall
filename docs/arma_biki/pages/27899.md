## continue

- Source: https://community.bistudio.com/wiki/continue
- Revision: 309284
- Updated: 2022-05-04T15:26:09Z

- Availability: arma3 2.02
- Groups: Program Flow

### Description

Skips current loop iteration and continues with the next one.

### Syntax

```sqf
continue
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
// prints 0, 1, 3
for "_i" from 0 to 3 do 
{
	if (_i == 2) then { continue };
	systemChat str _i;
};
```
