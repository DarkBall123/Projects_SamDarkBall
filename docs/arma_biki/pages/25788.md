## getAudioOptionVolumes

- Source: https://community.bistudio.com/wiki/getAudioOptionVolumes
- Revision: 377864
- Updated: 2026-01-04T11:30:15Z

- Availability: arma3 1.94
- Groups: Sounds

### Description

Returns profile audio volumes.

### Syntax

```sqf
getAudioOptionVolumes
```


### Return Value

- Array - [effects, music, radio, von, UI, map]
* effects: Number - fx volume factor 
* music: Number - music volume factor
* radio: Number - speech volume factor
* von: Number - Voice over Network (VoN) volume factor
* 2.10 UI: Number - UI volume factor
* 2.12 map: Number - map volume factor

### Examples

#### Example 1

```sqf
getAudioOptionVolumes params ["_effects", "_music", "_radio", "_von", "_ui", "_map"];
```
