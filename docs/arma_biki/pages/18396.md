## diag list

- Source: https://community.bistudio.com/wiki/diag_list
- Revision: 348389
- Updated: 2023-11-08T13:00:00Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Returns an array of all diagnostic modes available in the game.

### Syntax

```sqf
diag_list  mode
```

### Parameters

- mode: String - can be `"toggle"` or `"drawMode"`

### Return Value

- Array - ["Force", "Animation", "Mines", "HitPoints", "AnimSrcUnit", "AnimSrcTarget", "Suspension", "EPEForce", "EPEVehicle", "ParticleNames", "Particles", "SurfaceUnder", "AISkill", "AIDriving", "AIAiming", "AIBrain", "AIDynamicError", "AISuppression"] 1.66

### Examples

#### Example 1

```sqf
diag_list "toggle";
```

#### Example 2

```sqf
diag_list "drawMode";
```

### See Also

diag_toggle diag_enable
