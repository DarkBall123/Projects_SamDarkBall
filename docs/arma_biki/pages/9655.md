## removeAllMPEventHandlers

- Source: https://community.bistudio.com/wiki/removeAllMPEventHandlers
- Revision: 321196
- Updated: 2022-05-13T15:24:42Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Multiplayer

### Description

Removes all MP event handlers of the given type which were added by addMPEventHandler. Command needs to be executed only on one PC for MP event handler to be removed globally.

### Syntax

```sqf
objectName removeAllMPEventHandlers event
```

### Parameters

- objectName: Object
- event: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeAllMPEventHandlers "MPKilled";
```
