## BIS fnc buildingPositions

- Source: https://community.bistudio.com/wiki/BIS_fnc_buildingPositions
- Revision: 309416
- Updated: 2022-05-05T12:04:36Z

- Availability: arma3 1.00
- Groups: Positions

### Description

Get all available positions within a building or structure.

### Syntax

```sqf
param call BIS_fnc_buildingPositions
```

### Parameters

- param: Object
- param: Number

### Return Value

- Array

### Examples

#### Example 1

```sqf
[_building] call BIS_fnc_buildingPositions;
```

#### Example 2

```sqf
[_building, _maxNumberOfPositions] call BIS_fnc_buildingPositions;
```
