- Updated: 2022-05-13T15:15:54Z

- Availability: arma3 1.54
- Locality: argument local, effect global
- Groups: Stamina System

### Description

Enable/disable stamina system

### Syntax

```sqf
unit enableStamina enabled
```

### Parameters

- unit: Object
- enabled: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player enableStamina true;
```
