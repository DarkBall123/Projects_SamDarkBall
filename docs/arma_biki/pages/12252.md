## setLightFlareMaxDistance

- Source: https://community.bistudio.com/wiki/setLightFlareMaxDistance
- Revision: 310082
- Updated: 2022-05-05T12:25:10Z

- Availability: arma3 0.50
- Locality: argument local, effect local
- Groups: Lights

### Description

Sets max distance where the flare is visible.

### Syntax

```sqf
light setLightFlareMaxDistance distance
```

### Parameters

- light: Object
- distance: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLight setLightFlareMaxDistance 500;
```
