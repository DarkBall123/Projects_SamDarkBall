## getSensorThreats

- Source: https://community.bistudio.com/wiki/getSensorThreats
- Revision: 373682
- Updated: 2025-06-12T15:41:21Z

- Availability: arma3 2.06
- Locality: argument local
- Groups: Sensors

### Description

Returns vehicle sensors' threats.

### Syntax

```sqf
getSensorThreats vehicle
```

### Parameters

- vehicle: Object - the sensors-equipped vehicle

### Return Value

- Array of Arrays - format [<nowiki/>[object, type, sensor], ...]:
* object: Object
* type: String - can be one of:
** "missile"
** "marked"
** "locked"
* sensors: Array of Strings - values can be:
** "ir"
** "laser"
** "missile"
** "radar" (**not** "activeradar"/"passiveradar")
** "visual"

### Examples

#### Example 1

```sqf
private _dangers = getSensorThreats vehicle player;
/*
	returns e.g
	[
		[164230: titan_missile_atl_fly.p3d, "missile", ["visual"]],
		[164233: titan_missile_atl_fly.p3d, "threatmissile", ["radar"]]
	]
*/
```
