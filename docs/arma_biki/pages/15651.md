## BIS fnc inv

- Source: https://community.bistudio.com/wiki/BIS_fnc_inv
- Revision: 327932
- Updated: 2022-07-13T12:32:54Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Inventory

### Description

Returns inventory contents of given vehicle (unit). For vehicles it returns mounted gun and its ammo, **not** cargo weapons and ammo.

### Syntax

```sqf
[unit] call BIS_fnc_inv
```

### Parameters

- unit: Object - unit or vehicle

### Return Value

- Array of Config - weapons then magazines

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_inv;
```
