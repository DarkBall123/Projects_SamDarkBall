## setOxygenRemaining

- Source: https://community.bistudio.com/wiki/setOxygenRemaining
- Revision: 377982
- Updated: 2026-01-20T14:37:17Z

- Availability: arma3 0.50
- Groups: Object Manipulation

### Description

Sets oxygen remaining. It has no effect when soldier is not diving.

### Syntax

```sqf
unit setOxygenRemaining value
```

### Parameters

- unit: Object
- value: Number in range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
if (!isAbleToBreathe player) then
{
	player setOxygenRemaining 0; // drowns player
};
```
