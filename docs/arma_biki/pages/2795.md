## cameraInterest

- Source: https://community.bistudio.com/wiki/cameraInterest
- Revision: 320962
- Updated: 2022-05-13T10:04:50Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Return camera interest for given entity, as set by setCameraInterest, or as autodetected.

### Syntax

```sqf
cameraInterest entity
```

### Parameters

- entity: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
camInterest = cameraInterest myUnit;
```
