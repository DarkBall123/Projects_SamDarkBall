## synchronizedTriggers

- Source: https://community.bistudio.com/wiki/synchronizedTriggers
- Revision: 377126
- Updated: 2026-01-01T10:22:24Z

- Availability: arma3 0.50
- Groups: Triggers

### Description

Returns the list of triggers synchronized with a given waypoint.

### Syntax

```sqf
synchronizedTriggers waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- Array of Objects - Trigger objects

### Examples

#### Example 1

```sqf
synchronizedTriggers _someWaypoint;
```
