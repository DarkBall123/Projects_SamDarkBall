## sentencesEnabled

- Source: https://community.bistudio.com/wiki/sentencesEnabled
- Revision: 349008
- Updated: 2023-11-08T14:47:05Z

- Availability: arma3 2.06
- Groups: Radio and Chat

### Description

A getter for enableSentences.

### Syntax

```sqf
sentencesEnabled
```


### Return Value

- Boolean - returns true if sentences are enabled

### Examples

#### Example 1

```sqf
if (sentencesEnabled) then
{
	hint "sentences are enabled; changing that now";
	enableSentences false;
};
```
