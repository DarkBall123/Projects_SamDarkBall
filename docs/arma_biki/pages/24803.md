## BIS fnc reviveOnBeingRevived

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveOnBeingRevived
- Revision: 349314
- Updated: 2023-11-08T14:52:25Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Used to execute specific code locally on every client whenever "being revived" flag changes.

### Syntax

```sqf
[nil, flagState, unit] call BIS_fnc_reviveOnBeingRevived
```

### Parameters

- nil: Nothing - *This parameter has not been implemented*
- flagState: Boolean - (Optional, default false) flag state - true or false
- unit: Object - unit to set the flag for

### Return Value

- Boolean - returns true or Nothing if state didn't change

### Examples

#### Example 1

```sqf
[nil, true, squadLeader] call BIS_fnc_reviveOnBeingRevived;
```
