## BIS fnc removeVirtualWeaponCargo

- Source: https://community.bistudio.com/wiki/BIS_fnc_removeVirtualWeaponCargo
- Revision: 349397
- Updated: 2023-11-08T16:27:25Z

- Availability: arma3 1.24
- Groups: Inventory

### Description

Remove virtual weapons from an object (e.g., ammo box). Virtual items can be selected in the Arsenal.

### Syntax

```sqf
[object,weaponClasses,removeGlobally] call BIS_fnc_removeVirtualWeaponCargo
```

### Parameters

- object: Object - object from which items will be removed
- weaponClasses: Boolean, String or Array of Strings - weapon classes
- removeGlobally: Boolean - (Optional, default false) true to remove items globally

### Return Value

- Array of arrays - all virtual items in objects's space in format:
*0: Array - Items
*1: Array - Weapons
*2: Array - Magazines
*3: Array - Backpacks

### Examples

#### Example 1

```sqf
[BIS_ammoBox, ["class_1","class_2"], true] call BIS_fnc_removeVirtualWeaponCargo;
```
