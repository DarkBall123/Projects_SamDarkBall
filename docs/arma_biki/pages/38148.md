## BIS fnc unflipVehicle

- Source: https://community.bistudio.com/wiki/BIS_fnc_unflipVehicle
- Revision: 352643
- Updated: 2024-02-17T15:56:50Z

- Availability: arma3 2.02 <!-- 2021-04-01 (not a joke) -->
- Groups: Vehicles

### Description

Can be used to unflip a vehicle or a turret, without transition.

### Syntax

```sqf
[veh] call BIS_fnc_unflipVehicle
```

### Parameters

- veh: Object - the vehicle/turret that should be flipped

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[quad1] call BIS_fnc_unflipVehicle;
```
