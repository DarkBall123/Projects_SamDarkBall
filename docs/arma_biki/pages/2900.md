## ctrlSetFade

- Source: https://community.bistudio.com/wiki/ctrlSetFade
- Revision: 369232
- Updated: 2024-09-03T10:35:00Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets wanted transparency for control animation. Requires ctrlCommit to commit changes. To hide or show a control instantly, use ctrlShow.
If there are multiple (interactable) controls on top of each other but the top-most control is faded using 

```sqf
ctrlSetFade 1
```

,
this control will interfere with other controls that were defined earlier and in the exact same position.
To counter that, the faded control **must** be disabled with ctrlEnable.

### Syntax

```sqf
controlName ctrlSetFade fade
```

### Parameters

- controlName: Control
- fade: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFade 1;
_control ctrlCommit 5;
```
