## BIS fnc kbCreateDummy

- Source: https://community.bistudio.com/wiki/BIS_fnc_kbCreateDummy
- Revision: 326868
- Updated: 2022-07-12T21:35:32Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Conversations

### Description

Creates a dummy speaker (as a Game Logic). If given dummy variable has already been created, returns this one.

### Syntax

```sqf
dummyVarName call BIS_fnc_kbCreateDummy
```

### Parameters

- dummyVarName: String - can be anything, but if an identity from CfgIdentities the dummy will take this identity.

### Return Value

- Object - dummy speaker game logic

### Examples

#### Example 1

```sqf
private _dummySpeaker = "BIS_dummySpeaker" call BIS_fnc_kbCreateDummy; // _dummySpeaker == BIS_dummySpeaker now
```

#### Example 2

```sqf
private _dummySpeaker = "Miller" call BIS_fnc_kbCreateDummy; // given Miller is defined in CfgIdentities
```
