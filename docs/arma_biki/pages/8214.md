## ctrlRemoveAllEventHandlers

- Source: https://community.bistudio.com/wiki/ctrlRemoveAllEventHandlers
- Revision: 363228
- Updated: 2024-03-26T10:51:07Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Event Handlers, Event Handlers

### Description

Remove all event handlers from the given control.

### Syntax

```sqf
control ctrlRemoveAllEventHandlers handlerName
```

### Parameters

- control: Control
- handlerName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrlButton ctrlRemoveAllEventHandlers "ButtonDown";
```
