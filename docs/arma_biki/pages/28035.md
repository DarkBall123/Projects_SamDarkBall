## tvSetSelectColor

- Source: https://community.bistudio.com/wiki/tvSetSelectColor
- Revision: 377360
- Updated: 2026-01-02T06:40:27Z

- Availability: arma3 1.00
- Groups: GUI Control - Tree View

### Description

Sets the select color of given path.

### Syntax

```sqf
ctrl tvSetSelectColor [path, color]
```

### Parameters

- ctrl: Control
- path: Array of Numbers - path of the item
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control tvSetSelectColor [[0, 0], [1,1,1,0.5]];
```
