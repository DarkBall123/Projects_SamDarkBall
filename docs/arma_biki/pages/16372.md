## BIS fnc curatorPinged

- Source: https://community.bistudio.com/wiki/BIS_fnc_curatorPinged
- Revision: 349428
- Updated: 2023-11-08T16:27:34Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Show effects when player pings curator. Icon and entity list highlighting is handled by engine

### Syntax

```sqf
[module, player] call BIS_fnc_curatorPinged
```

### Parameters

- module: Object - Arma 3: Curator module
- player: Object - Player entity

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[module_curator, player] call BIS_fnc_curatorPinged;
```
