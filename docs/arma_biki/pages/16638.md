- Revision: 310836
- Updated: 2022-05-07T20:23:59Z

- Availability: arma3 1.32
- Groups: GUI Control - Object, GUI Control - Positioning

### Description

Returns 3D control model scale.

### Syntax

```sqf
ctrlModelScale  control
```

### Parameters

- control : Control - 3D control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_currentScale = ctrlModelScale _ctrl3D;
```
