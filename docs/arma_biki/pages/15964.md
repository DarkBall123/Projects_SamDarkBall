## BIS fnc dirtEffect

- Source: https://community.bistudio.com/wiki/BIS_fnc_dirtEffect
- Revision: 327927
- Updated: 2022-07-13T12:25:13Z

- Availability: arma3 1.00
- Locality: effect local
- Groups: Feedback

### Description

Screen dirt (texture) postprocess. 
Displays dust PP according to damage obtained from near explosion; takes array from "Explosion" event handler.

### Syntax

```sqf
[unit, damage] call BIS_fnc_dirtEffect
```

### Parameters

- unit: Object - who gets the damage. **Unused and useless parameter**
- damage: Number - damage given to unit by explosion

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[nil, 0.5] call BIS_fnc_dirtEffect;
```
