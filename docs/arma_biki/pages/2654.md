## round

- Source: https://community.bistudio.com/wiki/round
- Revision: 319690
- Updated: 2022-05-13T09:24:42Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

Rounds the provided value to the closest integer.

### Syntax

```sqf
round value
```

### Parameters

- value: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
round 5.25; // returns 5
```

#### Example 2

```sqf
round -5.25; // returns -5
```
