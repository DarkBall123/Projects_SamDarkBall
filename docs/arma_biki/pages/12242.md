## setWindStr

- Source: https://community.bistudio.com/wiki/setWindStr
- Revision: 370475
- Updated: 2024-12-16T18:10:00Z

- Availability: arma3 0.50
- Groups: Environment

### Description

Changes the wind strength smoothly during the given time (in seconds). A time of zero means there will be an immediate change.

### Syntax

```sqf
time setWindStr value
```

### Parameters

- time: Number
- value: Number - new value in range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
60 setWindStr 0.8; // set the wind strength to 0.8 gradually over the next 60 seconds
```
