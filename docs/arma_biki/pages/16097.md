## BIS fnc objectType

- Source: https://community.bistudio.com/wiki/BIS_fnc_objectType
- Revision: 327120
- Updated: 2022-07-12T21:44:51Z

- Availability: arma3 1.08
- Groups: Object Manipulation

### Description

Return object category and type.

### Syntax

```sqf
anObject call BIS_fnc_objectType
```

### Parameters

- anObject: String or Object
