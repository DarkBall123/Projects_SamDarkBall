## BIS fnc animateTaskWaypoint

- Source: https://community.bistudio.com/wiki/BIS_fnc_animateTaskWaypoint
- Revision: 348615
- Updated: 2023-11-08T13:45:39Z

- Availability: arma3 1.24
- Groups: Tasks

### Description

Plays an animation that pushes the active task waypoint up and down.

### Syntax

```sqf
param call BIS_fnc_animateTaskWaypoint
```

### Parameters

- Object - unit that should have animations played.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_animateTaskWaypoint;
```
