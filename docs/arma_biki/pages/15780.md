## BIS fnc dbClassList

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbClassList
- Revision: 327487
- Updated: 2022-07-12T22:19:49Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Returns all classes within class.

### Syntax

```sqf
[database, path] call BIS_fnc_dbClassList
```

### Parameters

- database - Array: database array
- path - Array: path to array of classes

### Return Value

- Array: List of classnames

### Examples

#### Example 1

```sqf
[["#MILLER", ["&KILLS", 1000], "#TERRA", ["&WEAPON", "MX 6.5mm"]], []] call BIS_fnc_dbClassList; // ["MILLER","TERRA"]
```
