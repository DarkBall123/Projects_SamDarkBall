## isStressDamageEnabled

- Source: https://community.bistudio.com/wiki/isStressDamageEnabled
- Revision: 310782
- Updated: 2022-05-07T20:21:46Z

- Availability: arma3 1.34
- Locality: argument local, effect local
- Groups: RTD

### Description

Returns true if stress damage is enabled in the game settings. A getter for enableStressDamage.
{{Feature|afm}}

### Syntax

```sqf
isStressDamageEnabled
```


### Return Value

- Boolean Returns true if enabled, otherwise false

### Examples

#### Example 1

```sqf
_settingEnabled = isStressDamageEnabled;
```
