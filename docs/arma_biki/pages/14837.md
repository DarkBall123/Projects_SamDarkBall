## curatorEditingArea

- Source: https://community.bistudio.com/wiki/curatorEditingArea
- Revision: 348379
- Updated: 2023-11-08T12:59:58Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns all curator editing areas.

### Syntax

```sqf
curatorEditingArea curator
```

### Parameters

- curator: Object - curator module.

### Return Value

- Array of arrays in format: [ID, PositionAGL, radius]

### Examples

#### Example 1

```sqf
_editingAreas = curatorEditingArea myCurator;
```
