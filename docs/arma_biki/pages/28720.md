## markerShadow

- Source: https://community.bistudio.com/wiki/markerShadow
- Revision: 349196
- Updated: 2023-11-08T14:50:41Z

- Availability: arma3 2.04
- Groups: Markers

### Description

Returns if the marker is drawn with shadow enabled.

### Syntax

```sqf
markerShadow marker
```

### Parameters

- marker: String - the marker

### Return Value

- Boolean: true if marker is enabled, false if not

### Examples

#### Example 1

```sqf
private _shadowEnabled = markerShadow _myMarker;
```
