## enableDynamicSimulationSystem

- Source: https://community.bistudio.com/wiki/enableDynamicSimulationSystem
- Revision: 373713
- Updated: 2025-06-21T11:20:46Z

- Availability: arma3 1.68
- Locality: effect global, server execution server
- Groups: Dynamic Simulation

### Description

Enables or disables the whole Arma 3: Dynamic Simulation system

### Syntax

```sqf
enableDynamicSimulationSystem enable
```

### Parameters

- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableDynamicSimulationSystem true;
```
