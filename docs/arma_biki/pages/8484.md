## unregisterTask

- Source: https://community.bistudio.com/wiki/unregisterTask
- Revision: 376348
- Updated: 2025-10-07T17:06:51Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Unregisters a task type from given agent. The task type is the name given in `CfgTasks` classes in `name` property. Also available from registeredTasks array.

### Syntax

```sqf
teamMember unregisterTask name
```

### Parameters

- teamMember: Team Member - teamMember agent
- name: String - name of the task

### Return Value

- Boolean - true on success

### Examples

#### Example 1

```sqf
teamMember _agent unregisterTask ((registeredTasks _agent) select 0);
```
