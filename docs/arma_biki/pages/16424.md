## BIS fnc isUnitVirtual

- Source: https://community.bistudio.com/wiki/BIS_fnc_isUnitVirtual
- Revision: 348563
- Updated: 2023-11-08T13:42:06Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Return if unit is virtual (used for example for Zeus players).

### Syntax

```sqf
[object] call BIS_fnc_isUnitVirtual
```

### Parameters

- object: Object - object to be turned into virtual unit

### Return Value

- Boolean - true if virtual unit

### Examples

#### Example 1

```sqf
private _isVirtual = someObject call BIS_fnc_isUnitVirtual;
```
