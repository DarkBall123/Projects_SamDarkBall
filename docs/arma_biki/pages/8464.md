## taskCompleted

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Return if task is completed. (state Succeeded, Failed or Canceled)

### Syntax

```sqf
taskCompleted task
```

### Parameters

- task: Task

### Return Value

- Boolean - true if task has been Succeeded, Failed or Canceled

### Examples

#### Example 1

```sqf
_task = player createSimpleTask ["task_1"];
_done = taskCompleted _task;
```
