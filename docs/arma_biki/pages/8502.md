### Description

Gets the waypoint speed.

Possible values are:
* "UNCHANGED"
* "LIMITED"
* "NORMAL"
* "FULL"

### Syntax

```sqf
waypointSpeed waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- String - see description

### Examples

#### Example 1

```sqf
_speed = waypointSpeed [groupOne,1];
```
