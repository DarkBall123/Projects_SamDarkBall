## lnbData

- Source: https://community.bistudio.com/wiki/lnbData
- Revision: 320643
- Updated: 2022-05-13T09:38:23Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Returns the additional text (invisible) in an item with the given position of the 2D listbox.

### Syntax

```sqf
lnbData [idc, [row, column]]
```

```sqf
ctrl lnbData [row, column]
```

### Parameters

- idc: Number or Control
- row: Number
- column: Number
- ctrl: Control
- row: Number
- column: Number

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
_ctrl lnbData [lnbCurSelRow _ctrl,0]; // "#1"
```
