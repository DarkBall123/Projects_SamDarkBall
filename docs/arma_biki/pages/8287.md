## hintSilent

- Source: https://community.bistudio.com/wiki/hintSilent
- Revision: 308951
- Updated: 2022-04-18T20:23:57Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Interaction, Structured Text, Strings

### Description

Same as hint, but without a sound.

### Syntax

```sqf
hintSilent text
```

### Parameters

- text: String or Structured Text

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
hintSilent format ["Hello, %1!", name player];
```

#### Example 2

```sqf
hint "Hello there!";
sleep 5;
hintSilent ""; // removes message
```
