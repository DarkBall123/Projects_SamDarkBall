## getPlayerCloudId

- Source: https://community.bistudio.com/wiki/getPlayerCloudId
- Revision: 351574
- Updated: 2023-12-07T17:16:57Z

- Availability: argo 1.00
- Locality: argument global
- Groups: Argo

### Description

Return the provided player's unique Cloud service account id.

### Multiplayer

Only works in multiplayer and on official servers.

### Syntax

```sqf
getPlayerCloudId unit
```

### Parameters

- unit: Object - the player unit from whom to obtain the Cloud ID

### Return Value

- String - the Cloud ID or empty string if in single player or if *unit* is not a live player unit

### Examples

#### Example 1

```sqf
_localPlayerCloudID = getPlayerCloudId player;
_remotePlayerCloudID = getPlayerCloudId _otherPlayer;
_emptyString = getPlayerCloudId objNull;
```
