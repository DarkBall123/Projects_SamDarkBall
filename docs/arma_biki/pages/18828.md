## BIS fnc storeParamsValues

- Source: https://community.bistudio.com/wiki/BIS_fnc_storeParamsValues
- Revision: 352537
- Updated: 2024-02-12T16:42:20Z

- Availability: arma3 1.00
- Locality: server execution server
- Groups: Mission Parameters

### Description

Parses mission params and stores them into public variable **"BIS_fnc_storeParamsValues_data"**. Use BIS_fnc_getParamValue to retrieve params values from the variable.

### Syntax

```sqf
call BIS_fnc_storeParamsValues
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_storeParamsValues;
```
