## listRemoteTargets

- Source: https://community.bistudio.com/wiki/listRemoteTargets
- Revision: 377652
- Updated: 2026-01-02T09:01:59Z

- Availability: arma3 1.72
- Groups: Sensors

### Description

Return list of datalink targets and time for which they will be/were known.

### Syntax

```sqf
listRemoteTargets side
```

### Parameters

- side: Side

### Return Value

- Array of Arrays with [remoteTarget, lastDetected]
* remoteTarget: Object
* lastDetected: Number

### Examples

#### Example 1

```sqf
listRemoteTargets opfor;
```
