## BIS fnc preload

- Source: https://community.bistudio.com/wiki/BIS_fnc_preload
- Revision: 309413
- Updated: 2022-05-05T12:04:36Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Start automatic loading screen upon mission start.
On client, it will finish only when server is finished.

### Syntax

```sqf
call BIS_fnc_preload
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
call BIS_fnc_preload;
```
