### Syntax

```sqf
weaponClass call BIS_fnc_itemType
```

### Parameters

- weaponClass: String - weapon's class name

### Return Value

- Array of Strings format [category, type]

### Examples

#### Example 1

```sqf
"arifle_MX_pointer_F" call BIS_fnc_itemType;
```
