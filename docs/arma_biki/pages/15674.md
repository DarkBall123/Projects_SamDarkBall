## BIS fnc version

- Source: https://community.bistudio.com/wiki/BIS_fnc_version
- Revision: 353287
- Updated: 2024-03-15T17:03:27Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Diagnostic

### Description

Detects which **{{arma2}}** expansions and addons are available. Only works in {{arma2}}/{{arma2oa}}.
arma2acr is not detected by this function.

### Syntax

```sqf
call BIS_fnc_version
```


### Return Value

- Array of Numbers - can contain:
* 0: {{arma2}}
* 1: {{arma2oa}}
* 2: arma2baf
* 4: arma2pmc

### Examples

#### Example 1

```sqf
private _availableExpansions = call BIS_fnc_version;
```

#### Example 2

```sqf
private _playerHasPMC = 4 in (call BIS_fnc_version);
```
