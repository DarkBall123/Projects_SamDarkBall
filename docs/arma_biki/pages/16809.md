## enginesIsOnRTD

- Source: https://community.bistudio.com/wiki/enginesIsOnRTD
- Revision: 330055
- Updated: 2022-08-15T16:03:50Z

- Availability: arma3 1.34
- Groups: RTD

### Description

Returns which engines are producing some work.
{{Feature|afm}}

### Syntax

```sqf
enginesIsOnRTD RTD_helicopter
```

### Parameters

- RTD_helicopter: Object

### Return Value

- Array of Booleans - value for each engine

### Examples

#### Example 1

```sqf
_enginesTaru = enginesIsOnRTD _taru; // returns [true, true]
```
