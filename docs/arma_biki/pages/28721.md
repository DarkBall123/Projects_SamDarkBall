## setMarkerShadow

- Source: https://community.bistudio.com/wiki/setMarkerShadow
- Revision: 349188
- Updated: 2023-11-08T14:50:39Z

- Availability: arma3 2.04
- Locality: effect global
- Groups: Markers

### Description

Sets the shadow property of given marker.

### Syntax

```sqf
marker setMarkerShadow shadowState
```

### Parameters

- marker: String - the marker
- shadowState: Boolean - true to enable the shadow, false to disable it

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_myMarker setMarkerShadow true; // enable shadow
```
