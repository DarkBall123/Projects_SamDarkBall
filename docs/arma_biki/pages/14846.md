## objectCurators

- Source: https://community.bistudio.com/wiki/objectCurators
- Revision: 377144
- Updated: 2026-01-01T10:32:33Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns array with all curators which can edit given object.

### Syntax

```sqf
objectCurators obj
```

### Parameters

- obj: Object

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_curatorsThatcanEdit = objectCurators BIS_Tank;
```
