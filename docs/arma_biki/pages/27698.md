## binocularMagazine

- Source: https://community.bistudio.com/wiki/binocularMagazine
- Revision: 377189
- Updated: 2026-01-01T10:53:24Z

- Availability: arma3 2.02
- Locality: argument global
- Groups: Unit Inventory

### Description

Collects all loaded magazines from all binocular muzzles and returns them in Array, otherwise it returns []. This command is used for infantry weapons only.

### Syntax

```sqf
binocularMagazine  unit
```

### Parameters

- unit: Object

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
hint str binocularMagazine player; // ["Laserbatteries"]
```
