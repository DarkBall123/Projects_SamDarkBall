## setGroupIconsVisible

- Source: https://community.bistudio.com/wiki/setGroupIconsVisible
- Revision: 369184
- Updated: 2024-09-03T10:34:45Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: High Command

### Description

Sets if group icons added with addGroupIcon are visible on map and in the HUD.

### Syntax

```sqf
setGroupIconsVisible [showOnMap, showOnHUD]
```

### Parameters

- showOnMap: Boolean - true to show on map. Default is false
- showOnHUD: Boolean - true to show on HUD. Default is false

### Return Value

- Nothing (prior to Arma 3 v1.94 this command returned Object of null value)

### Examples

#### Example 1

```sqf
setGroupIconsVisible [true, true];
(group player) addGroupIcon ["b_inf", [0, 0]];
```
