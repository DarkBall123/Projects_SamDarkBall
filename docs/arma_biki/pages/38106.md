## getBoneNames

- Source: https://community.bistudio.com/wiki/getBoneNames
- Revision: 369763
- Updated: 2024-10-08T15:08:57Z

- Availability: arma3 2.18
- Groups: Object Manipulation

### Description

Returns an array of bone names and their parents.

### Syntax

```sqf
getBoneNames object
```

### Parameters

- object: Object

### Return Value

- Array of Strings - bone names and bone parents in separate arrays, in format: [[bone1, bone2,...], [parent1, parent2, ....]]
