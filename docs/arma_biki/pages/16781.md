## isDLCAvailable

- Source: https://community.bistudio.com/wiki/isDLCAvailable
- Revision: 369281
- Updated: 2024-09-03T18:42:47Z

- Availability: arma3 1.00
- Groups: DLC

### Description

Returns true if the DLC (CDLC included) is marked as available on Steam.
Official and Creator DLC appIds can be found on Arma 3: DLCs & Expansions and Arma 3: CDLCs pages.
This command will return true if the DLC is owned, even if it is **not** installed!

### Syntax

```sqf
isDLCAvailable appId
```

### Parameters

- appId : Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _karts = 288520;
isDLCAvailable _karts; // returns true
```
