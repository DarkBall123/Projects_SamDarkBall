## setVehicleReportOwnPosition

- Source: https://community.bistudio.com/wiki/setVehicleReportOwnPosition
- Revision: 311072
- Updated: 2022-05-07T20:57:10Z

- Availability: arma3 1.70
- Groups: Sensors

### Description

Sets that the vehicle will share its own position via datalink to the Side center.

### Syntax

```sqf
vehicle setVehicleReportOwnPosition report
```

### Parameters

- vehicle: Object
- report: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setVehicleReportOwnPosition true;
```
