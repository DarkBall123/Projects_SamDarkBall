## all3DENEntities

- Source: https://community.bistudio.com/wiki/all3DENEntities
- Revision: 377599
- Updated: 2026-01-02T07:01:24Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns an array of all currently placed Eden Editor entities.
This information is only available in Eden Editor. If used during mission, it will return `[<nowiki/>[],[],[],[],[],[],[],[-999]]`.

### Syntax

```sqf
all3DENEntities
```


### Return Value

- Array of Eden Entities

### Examples

#### Example 1

```sqf
systemChat str all3DENEntities;
```

#### Example 2

```sqf
all3DENEntities params ["_objects", "_groups", "_triggers", "_systems", "_waypoints", "_markers", "_layers", "_comments"];
```

#### Example 3

```sqf
// select all Eden entities
set3DENSelected all3DENEntities;
```
