## add3DENEventHandler

- Source: https://community.bistudio.com/wiki/add3DENEventHandler
- Revision: 364159
- Updated: 2024-05-05T10:46:40Z

- Availability: arma3 1.56
- Groups: Eden Editor, Event Handlers

### Description

Adds an Eden Editor Event Handler.

### Syntax

```sqf
add3DENEventHandler [type, code]
```

### Parameters

- type: String - see Eden Editor Event Handler
- code: Code
* Event Handler parameters are accessible via 

```sqf
_this
```

* The Event Handler type is available as 

```sqf
_thisEvent
```

* The Event Handler index is available as 

```sqf
_thisEventHandler
```

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _ehID = add3DENEventHandler ["onUndo", { systemChat "Zip..." }];
```
