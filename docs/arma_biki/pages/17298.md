## isObjectHidden

- Source: https://community.bistudio.com/wiki/isObjectHidden
- Revision: 319236
- Updated: 2022-05-13T09:23:25Z

- Availability: arma3 1.48
- Locality: argument global, effect local
- Groups: Object Manipulation

### Description

Checks visibility of a given object on the local machine.

### Syntax

```sqf
isObjectHidden object
```

### Parameters

- object: Object - object to test

### Return Value

- Boolean - true if hidden, false if visible

### Examples

#### Example 1

```sqf
_bobIsHidden = isObjectHidden bob;
```
