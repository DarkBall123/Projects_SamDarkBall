## showUAVFeed

- Source: https://community.bistudio.com/wiki/showUAVFeed
- Revision: 364255
- Updated: 2024-05-06T09:38:21Z

- Availability: arma3 1.16
- Groups: Remote Control, Custom Panels

### Description

Shows/hides video feed transmitted from UAV in its custom info panel.

### Syntax

```sqf
showUAVFeed show
```

### Parameters

- show: Boolean

### Return Value

- Boolean - always true unless error

### Examples

#### Example 1

```sqf
showUAVFeed true;
```
