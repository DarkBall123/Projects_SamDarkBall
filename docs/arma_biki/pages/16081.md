## BIS fnc phoneticalWord

- Source: https://community.bistudio.com/wiki/BIS_fnc_phoneticalWord
- Revision: 349006
- Updated: 2023-11-08T14:46:14Z

- Availability: arma3 1.00
- Groups: Strings

### Description

Convert number to NATO phonetical alphabet word (e.g. 2 becomes "Bravo") or letter of alphabet.

### Syntax

```sqf
[integer, short] call BIS_fnc_phoneticalWord
```

### Parameters

- integer: Number - any integer from 1 to 26.
- short: Boolean - (Optional, default false) true for the short version, false for the long version.

### Return Value

- String - phonetical word or letter of alphabet. In case of full word the returned string is localised.

### Examples

#### Example 1

```sqf
[1] call BIS_fnc_phoneticalWord; // returns "Alpha"
```

#### Example 2

```sqf
[1, true] call BIS_fnc_phoneticalWord; // returns "A"
```
