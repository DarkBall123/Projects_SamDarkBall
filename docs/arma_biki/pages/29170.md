## getEngineTargetRPMRTD

- Source: https://community.bistudio.com/wiki/getEngineTargetRPMRTD
- Revision: 348667
- Updated: 2023-11-08T13:51:28Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Returns RPM of all engines. {{Feature|afm}}

### Syntax

```sqf
getEngineTargetRPMRTD helicopter
```

### Parameters

- helicopter: Object

### Return Value

- Array of Numbers with the RPM of each engine

### Examples

#### Example 1

```sqf
private _rpm = getEngineTargetRPMRTD _helicopter;
```
