## loadAbs

- Source: https://community.bistudio.com/wiki/loadAbs
- Revision: 353757
- Updated: 2024-03-23T13:51:29Z

- Availability: arma3 0.50
- Groups: Unit Inventory

### Description

Returns current sum of mass from items stored in all unit's containers, linked items and weapons.

### Syntax

```sqf
loadAbs unit
```

### Parameters

- unit: Object - (before 2.08 the command did not support containers, ammo boxes, weapon holders, vehicle cargos)

### Return Value

- Number

### Examples

#### Example 1

Player weight: 

```sqf
_weight = loadAbs player;
```

#### Example 2

```sqf
private _loadUniform = loadAbs uniformContainer player;
private _loadVest = loadAbs vestContainer player;
private _loadBackpack = loadAbs backpackContainer player;
hint format [
	"Player's load:\nUniform: %1\nVest:%2\nBackpack: $3\nTotal: %4",
	_loadUniform,
	_loadVest,
	_loadBackpack,
	_loadUniform + _loadVest + _loadBackpack
];
```
