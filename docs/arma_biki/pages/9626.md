## addBackpackCargoGlobal

- Source: https://community.bistudio.com/wiki/addBackpackCargoGlobal
- Revision: 341861
- Updated: 2023-07-01T14:05:59Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Containers

### Description

Add backpack(s) to the cargo space of vehicle.
Classname list of available backpacks:
* arma2oa backpacks
* Arma 3 backpacks - objects starting with "B_", starts near ["B_AssaultPack_khk"](Arma 3: CfgVehicles Equipment#Bag Base)

### Syntax

```sqf
vehicle addBackpackCargoGlobal [packClassName, count]
```

### Parameters

- vehicle: Object - object to add the Backpack to
- packClassName: String - see the topic :Category:Weapons for reference about possible values.
- count: Number - number of backpacks to add; 2.14 a negative value will remove backpacks.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
this addBackpackCargoGlobal ["TK_RPG_Backpack_EP1", 2];
```

#### Example 2

```sqf
_apc addBackpackCargoGlobal ["US_Patrol_Pack_EP1", 4];
```
