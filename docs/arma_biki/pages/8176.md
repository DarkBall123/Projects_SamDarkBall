## assignedDriver

- Source: https://community.bistudio.com/wiki/assignedDriver
- Revision: 363250
- Updated: 2024-03-26T10:51:23Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control, Object Manipulation

### Description

Returns the soldier assigned to the given vehicle as a driver.

### Syntax

```sqf
assignedDriver vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Object

### Examples

#### Example 1

```sqf
_driver = assignedDriver vehicleName;
```
