|game4= arma3
|version4= 0.50

|gr1= Diagnostic

|descr= Dumps the argument's value to the report file. Each call creates a new line in the file.

|s1= diag_log  output

|p1= output: Anything

|r1= Nothing

|x1=

```sqf
diag_log time;
```

|x2=

```sqf
diag_log format ["%1, %2", player, time];
```

|x3=

```sqf
_array = [1, "foo", player, "bar"];
{
	diag_log _x;
} forEach _array ; // creates 4 entries on 4 lines
```

|x4=

```sqf
_array = [1, "foo", player, "bar"];
diag_log _array; // Creates one entry of e.g. [1,"foo",B Alpha 1-1:1 (Player Name),"bar"]
```
