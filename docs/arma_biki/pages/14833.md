## curatorCameraArea

- Source: https://community.bistudio.com/wiki/curatorCameraArea
- Revision: 377883
- Updated: 2026-01-04T16:25:20Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns all curator camera areas.

### Syntax

```sqf
curatorCameraArea curatorObj
```

### Parameters

- curatorObj: Object - curator module.

### Return Value

- Array with [cameraAreaID, position, radius]
* cameraAreaID: Number
* position: Position
* radius: Number

### Examples

#### Example 1

```sqf
_camArea = curatorCameraArea myCurator; // [[8052,[4027.36,4024.89,0],250]]
```
