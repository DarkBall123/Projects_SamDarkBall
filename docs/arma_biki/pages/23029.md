## airDensityCurveRTD

- Source: https://community.bistudio.com/wiki/airDensityCurveRTD
- Revision: 377671
- Updated: 2026-01-02T09:02:30Z

- Availability: arma3 1.34
- Groups: RTD

### Description

Returns array with air density data.{{Feature|afm}}

### Syntax

```sqf
airDensityCurveRTD
```


### Return Value

- Array with arrays Returns air density graph
 
Each array consists of:
* 0: Altitude (-60000 metres to 10^7 metres)
* 1: Air density

### Examples

#### Example 1

```sqf
private _densityArray = airDensityCurveRTD;
```
