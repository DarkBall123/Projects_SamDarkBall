## BIS fnc vectorDiff

- Source: https://community.bistudio.com/wiki/BIS_fnc_vectorDiff
- Revision: 327961
- Updated: 2022-07-13T13:36:27Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Vectors

### Description

Returns a vector that is the difference between two vectors.
Use vectorDiff instead.

### Syntax

```sqf
[vector1, vector2] call BIS_fnc_vectorDiff
```

### Parameters

- vector1: Array
- vector2: Array

### Return Value

- Array - vector difference

### Examples

#### Example 1

```sqf
private _vectorDiff = [[1,2,3], [5,6,7]] call BIS_fnc_vectorDiff;
```
