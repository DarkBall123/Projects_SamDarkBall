## estimatedTimeLeft

- Source: https://community.bistudio.com/wiki/estimatedTimeLeft
- Revision: 370869
- Updated: 2025-02-21T10:43:59Z

- Availability: ofp 1.35, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect global, server execution server
- Groups: Time, Mission Information, Multiplayer

### Description

Sets the estimated time left in the game that is shown in the "Game in progress" screen or in the master browser.
This command will force the server to broadcast serverTime to all clients without waiting for the next broadcast window (usually every 5 minutes).

### Syntax

```sqf
estimatedTimeLeft seconds
```

### Parameters

- seconds: Number - estimated time in seconds, max 36000 (10 hours), 7200 (2 hours) before 1.70

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
estimatedTimeLeft 600; // 10 min
```

#### Example 2

**{{ofp}}:** for missions with a hard set limit adjusted via [param1](Description.ext#param1/param2), the following example can be used in the init.sqs file:
<sqs>estimatedTimeLeft param1</sqs>
