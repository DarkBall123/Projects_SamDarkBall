## removeAllUserActionEventHandlers

- Source: https://community.bistudio.com/wiki/removeAllUserActionEventHandlers
- Revision: 322842
- Updated: 2022-06-27T07:33:49Z

- Availability: arma3 2.06
- Locality: effect local
- Groups: Event Handlers

### Description

Removes all UserAction event handlers of the given type which were added by addUserActionEventHandler.

This command also resets the Event Handler creation index to 0.

### Syntax

```sqf
removeAllUserActionEventHandlers [keyName, eventType]
```

### Parameters

- keyName: String - see inputAction/actions
- eventType: String - event name; see UserAction Event Handlers. Can be one of:
* "Activate"
* "Deactivate"
* "Analog"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllUserActionEventHandlers ["Reload", "Activate"];
```
