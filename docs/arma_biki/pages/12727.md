## setMusicEventHandler

- Source: https://community.bistudio.com/wiki/setMusicEventHandler
- Revision: 319639
- Updated: 2022-05-13T09:24:37Z

- Availability: arma3 1.02
- Groups: Event Handlers, Sounds

### Description

Sets given music track event handler. Will overwrite other music event handlers.
Use addMusicEventHandler instead as it can stack music event handlers.

### Syntax

```sqf
setMusicEventHandler [type, function]
```

### Parameters

- type: String - "MusicStart" or "MusicStop"
- function: String - script to be executed. Passes params array 0: class name of the sound in CfgMusic, 1: event handler id

### Return Value

- Number - id of the event handler

### Examples

#### Example 1

```sqf
_ehID = setMusicEventHandler ["MusicStart", "hint str _this"];
```

#### Example 2

```sqf
_ehID = setMusicEventHandler ["MusicStop", "hint str _this"];
```
