## menuURL

- Source: https://community.bistudio.com/wiki/menuURL
- Revision: 378348
- Updated: 2026-04-02T16:31:36Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns current URL set in entry on given path.

### Syntax

```sqf
menuURL [idc, path]
```

```sqf
control menuURL path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuURL [7, 0]; // returns "https://community.bistudio.com/wiki/Eden_Editor"
```
