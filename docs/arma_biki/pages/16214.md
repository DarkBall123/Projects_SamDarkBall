## BIS fnc getVirtualMagazineCargo

- Source: https://community.bistudio.com/wiki/BIS_fnc_getVirtualMagazineCargo
- Revision: 348659
- Updated: 2023-11-08T13:48:27Z

- Availability: arma3 1.24
- Groups: Inventory

### Description

Get virtual magazines from an object (e.g., ammo box). Virtual items can be selected in the Arsenal.

### Syntax

```sqf
object call BIS_fnc_getVirtualMagazineCargo
```

### Parameters

- object: Object

### Return Value

- Array of Strings - all virtual magazines

### Examples

#### Example 1

```sqf
BIS_ammoBox call BIS_fnc_getVirtualMagazineCargo;
```
