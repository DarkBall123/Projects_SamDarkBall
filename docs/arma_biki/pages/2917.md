## boundingBox

- Revision: 377835
- Updated: 2026-01-03T04:32:05Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

right|200px Returns a bounding box of given object in model coordinate space, adjusted according to destruction/animation of an object. This command is rather generous on the size estimation, for more precise coordinates use boundingBoxReal.
In 1.92 The output of both syntaxes got extended to include bounding sphere diameter. See also sizeOf.

### Syntax

```sqf
boundingBox object
```

```sqf
clippingType boundingBox object
```

### Parameters

- object: Object
- clippingType: Number - clipping type could be:
* 0 - ClipVisual (could significantly reduce the size of bounding boxes on buildings)
* 1 - ClipShadow
* 2 - ClipGeometry
* 3 - ClipGeneral (Default, the same type that is used in main syntax)
- object: Object

### Return Value

- PositionRelative - an array with the extreme points of the model, as well as bounding box sphere diameter.
Format [<nowiki/>[xmin, ymin, zmin], [xmax, ymax, zmax], boundingSphereDiameter].
- PositionRelative - an array with the extreme points of the model bounding box, as well as bounding box sphere diameter.
Format [<nowiki/>[xmin, ymin, zmin], [xmax, ymax, zmax], boundingSphereDiameter].
