## isActionMenuVisible

- Source: https://community.bistudio.com/wiki/isActionMenuVisible
- Revision: 378567
- Updated: 2026-05-08T21:15:48Z

- Availability: arma3 1.96
- Groups: Interaction

### Description

Returns true if scroll menu is visible.

### Syntax

```sqf
isActionMenuVisible
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isActionMenuVisible) then { hint "Scroll menu is opened" };
```
