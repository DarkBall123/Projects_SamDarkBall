## worldSize

- Source: https://community.bistudio.com/wiki/worldSize
- Revision: 373463
- Updated: 2025-05-09T16:51:14Z

- Availability: arma3 1.48
- Groups: Mission Information

### Description

Returns the engine calculated size (terrain side length) of the current world in meters. In Arma, terrains are always square. (BIS_fnc_mapSize may return the same value, but is just a simple look up in config).

### Syntax

```sqf
worldSize
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
private _size = worldSize; // VR and Stratis: 8192; Altis: 30720
```

#### Example 2

```sqf
// A round marker that should cover the whole map, placed in the center of the map, should have the following radius (a, b)
private _radius = sqrt 2 / 2 * worldSize;
```

#### Example 3

```sqf
private _axis = worldSize / 2;
private _center = [_axis, _axis , 0];
private _radius = sqrt 2 * _axis;
```
