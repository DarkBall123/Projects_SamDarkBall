## setBatteryChargeRTD

- Source: https://community.bistudio.com/wiki/setBatteryChargeRTD
- Revision: 377771
- Updated: 2026-01-03T01:32:21Z

- Availability: tkoh 1.00
- Groups: RTD

### Description

Set the actual battery charge of a helicopter.
* 0: no charge
* 1: fully charged

### Syntax

```sqf
helicopterRTD setBatteryChargeRTD charge
```

### Parameters

- helicopterRTD: ObjectRTD - helicopter
- charge: Number - battery charge level

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setBatteryChargeRTD 0.5;
```
