## ctrlFontHeight

- Source: https://community.bistudio.com/wiki/ctrlFontHeight
- Revision: 309906
- Updated: 2022-05-05T12:16:53Z

- Availability: arma3 2.02
- Groups: GUI Control

### Description

Returns control's font size, usually `sizeEx` value (see ctrlSetFontHeight).

### Syntax

```sqf
ctrlFontHeight control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
ctrlFontHeight _control;
```

### See Also

ctrlTextHeight ctrlTextWidth ctrlSetFontHeight
