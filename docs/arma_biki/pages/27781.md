## markerPolyline

- Source: https://community.bistudio.com/wiki/markerPolyline
- Revision: 377288
- Updated: 2026-01-02T06:37:29Z

- Availability: arma3 2.02
- Groups: Markers

### Description

Returns a polyline marker's path data.

### Syntax

```sqf
markerPolyline marker
```

### Parameters

- marker: String

### Return Value

- Array format `[x1, y1, x2, y2, ... xn, yn]`

### Examples

#### Example 1

```sqf
markerPolyline "_USER_DEFINED #0/0/1"; // returns your first polyline's data in Singleplayer
```
