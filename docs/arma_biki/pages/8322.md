## lnbPicture

- Source: https://community.bistudio.com/wiki/lnbPicture
- Revision: 364186
- Updated: 2024-05-05T10:46:48Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Returns the picture name or path of the item with the given position of the 2D listbox.

### Syntax

```sqf
lnbPicture [idc, [row, column]]
```

```sqf
control lnbPicture [row, column]
```

### Parameters

- idc: Number - number of Control
- row: Number - index of Row
- column: Number - index of Column
- control: Control
- row: Number - index of Row in given Control
- column: Number - index of Column in given Control

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
lnbPicture [200, [1, 1]];
```

#### Example 2

```sqf
_control lnbPicture [1, 1]; // "a3\ui_f\data\gui\cfg\ranks\corporal_gs.paa"
```
