## resources

- Source: https://community.bistudio.com/wiki/resources
- Revision: 319310
- Updated: 2022-05-13T09:23:51Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Teams

### Description

Returns the resources of a team member. Results are local to the PC on which command was executed.

### Syntax

```sqf
resources member
```

### Parameters

- member: Team Member

### Return Value

- Array

### Examples

#### Example 1

```sqf
resources teamMember _unit;
```
