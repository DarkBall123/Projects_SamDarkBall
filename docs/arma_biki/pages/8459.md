## synchronizeObjectsAdd

- Source: https://community.bistudio.com/wiki/synchronizeObjectsAdd
- Revision: 377071
- Updated: 2026-01-01T09:31:05Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Add given objects to the unit's list of synchronized objects.

### Syntax

```sqf
unit synchronizeObjectsAdd objects
```

### Parameters

- unit: Object
- objects: Array of Objects

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_acm = _groupLogic createUnit ["AmbientCombatManager", position player, [], 0, "NONE"];
_acm synchronizeObjectsAdd [player];
```
