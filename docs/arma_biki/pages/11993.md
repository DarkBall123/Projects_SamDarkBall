## diag logSlowFrame

- Source: https://community.bistudio.com/wiki/diag_logSlowFrame
- Revision: 370296
- Updated: 2024-11-20T13:52:40Z

- Availability: arma2oa 1.63
- Groups: Diagnostic

### Description

Log all frames, where section takes longer than the threshold (in seconds).
Only available in specific builds. See Performance Profiling for details.
This command is not implemented in **Arma 3** builds. 2.20 Use diag_captureSlowFrame with **toFile** parameter instead. Or admin chat commands for server side captures.

### Syntax

```sqf
diag_logSlowFrame [section, threshold]
```

### Parameters

- section: String
- threshold: Number - duration of frame in seconds

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
diag_logSlowFrame ['total', 0.3];
```
