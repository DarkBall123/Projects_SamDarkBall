## ctrlSetFontSecondary

- Source: https://community.bistudio.com/wiki/ctrlSetFontSecondary
- Revision: 348687
- Updated: 2023-11-08T14:29:23Z

- Availability: arma3 1.62
- Locality: effect local
- Groups: GUI Control

### Description

Sets the font size of the secondary text of given control.

### Syntax

```sqf
ctrl ctrlSetFontSecondary fontClass
```

### Parameters

- ctrl: Control
- fontClass: String - font class

### Return Value

- Nothing

### Examples

#### Example 1

_control ctrlSetFontSecondary "TahomaB";

### See Also

ctrlSetFontP ctrlSetFontHeightSecondary
