## getMarkerColor

- Source: https://community.bistudio.com/wiki/getMarkerColor
- Revision: 369401
- Updated: 2024-09-03T18:43:21Z

- Availability: ofp 1.21, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Markers

### Description

Returns marker color for given marker.
This command is identical to markerColor.

### Syntax

```sqf
getMarkerColor markerName
```

### Parameters

- markerName: String - marker name

### Return Value

- String

### Examples

#### Example 1

```sqf
"MarkerOne" setMarkerColor "ColorBlack";
_color = getMarkerColor "MarkerOne"; // returns "ColorBlack"
```
