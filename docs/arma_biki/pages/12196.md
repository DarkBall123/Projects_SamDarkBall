## primaryWeaponItems

- Source: https://community.bistudio.com/wiki/primaryWeaponItems
- Revision: 378479
- Updated: 2026-04-24T11:51:13Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns array with all items assigned to the primaryWeapon except magazines. Use primaryWeaponMagazine command for the latter. This command is used for infantry weapons only.

### Syntax

```sqf
primaryWeaponItems unit
```

### Parameters

- unit: Object

### Return Value

- Array with [muzzle, rail, optic, bipod]
* muzzle: String - class name of the muzzle attachment (silencer, flash hider)
* rail: String - class name of the rail attachement (laserpointer/flashlight)
* optic: String
* bipod: String

### Examples

#### Example 1

```sqf
primaryWeaponItems player;
/*
[
	"muzzle_snds_H",	// silencer
	"acc_pointer_IR",	// laser
	"optic_Aco",		// optics
	"bipod_01_F_blk"	// bipod
]
*/
```
