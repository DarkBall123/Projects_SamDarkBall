## removeAction

- Source: https://community.bistudio.com/wiki/removeAction
- Revision: 348246
- Updated: 2023-11-08T11:40:32Z

- Availability: ofp 1.20, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Interaction

### Description

Removes user added action with given ID. This only removes actions added with the addAction command. You cannot remove default game actions, such as reload.

### Syntax

```sqf
unit removeAction actionID
```

### Parameters

- unit: Object - unit, vehicle or static object
- actionID: Number - action ID returned by addAction

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeAction 0;
```
