## setSimpleTaskType

- Source: https://community.bistudio.com/wiki/setSimpleTaskType
- Revision: 349265
- Updated: 2023-11-08T14:51:08Z

- Availability: arma3 1.58
- Groups: Briefing

### Description

Attach type to the simple task. See Default Task Types.

### Syntax

```sqf
task setSimpleTaskType taskType
```

### Parameters

- task: Task
- taskType: String - type of task

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
(currentTask player) setSimpleTaskType "attack";
```

### See Also
