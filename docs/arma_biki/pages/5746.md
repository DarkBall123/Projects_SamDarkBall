## waypoints

- Source: https://community.bistudio.com/wiki/waypoints
- Revision: 347556
- Updated: 2023-09-28T09:43:23Z

- Availability: arma1 1.05, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Waypoints

### Description

Returns an array of waypoints for the specified unit/group.

### Syntax

```sqf
waypoints groupName
```

### Parameters

- groupName: Group or Object

### Return Value

- Array of Waypoints

### Examples

#### Example 1

```sqf
waypoints player;
```

#### Example 2

```sqf
_wPosArray = waypoints group10; // returns e.g [[EAST 1-1-A,0],[EAST 1-1-A,1],[EAST 1-1-A,2]]
```
