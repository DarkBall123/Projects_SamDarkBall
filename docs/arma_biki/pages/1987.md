## deleteCenter

- Source: https://community.bistudio.com/wiki/deleteCenter
- Revision: 310241
- Updated: 2022-05-05T13:11:01Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect global
- Groups: Sides

### Description

In a nutshell, this command removes gaming Side (see createCenter). If a side has >0 Groups it cannot be deleted. Center can only be created for: east, west, resistance, civilian and sideLogic, therefore only centers from the mentioned sides can be deleted.

**Old description:** Destroys the AI center of the given side.

### Syntax

```sqf
deleteCenter side
```

### Parameters

- side: Side

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
deleteCenter east;
```
