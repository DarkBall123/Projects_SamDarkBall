## setCompassDeclination

- Source: https://community.bistudio.com/wiki/setCompassDeclination
- Revision: 377875
- Updated: 2026-01-04T13:22:06Z

- Availability: arma3 2.18
- Locality: effect local
- Groups: Interaction

### Description

Sets the [declination angle](https://en.wikipedia.org/wiki/Magnetic_declination) of player's compass, which is the difference between magnetic north and true north.

### Syntax

```sqf
setCompassDeclination angleRad
```

### Parameters

- angleRad: Number - Declination angle in radians. Use 0 to reset it to default.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setCompassDeclination rad 10; // declination angle is 10 degrees
```
