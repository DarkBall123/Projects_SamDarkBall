## showRadio

- Source: https://community.bistudio.com/wiki/showRadio
- Revision: 370852
- Updated: 2025-02-18T00:23:17Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Interaction, Radio and Chat

### Description

Shows or hides the radio on the map screen, if enabled for the mission and you possess the item. (default true).
This command does nothing in Arma 3.

### Syntax

```sqf
showRadio show
```

### Parameters

- show: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
showRadio false;
```
