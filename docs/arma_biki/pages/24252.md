## BIS fnc compareDateTimes

- Source: https://community.bistudio.com/wiki/BIS_fnc_compareDateTimes
- Revision: 323790
- Updated: 2022-07-01T11:53:40Z

- Availability: arma3 1.86
- Groups: Environment

### Description

Returns the newer date or returns true if they are identical.

### Syntax

```sqf
[date1, date2] call BIS_fnc_compareDateTimes
```

### Parameters

- date1: Array format Date
- date2: Array format Date

### Return Value

- Boolean or Array

### Examples

#### Example 1

```sqf
[[2035,5,28,13,37], [2032,5,28,13,37]] call BIS_fnc_compareDateTimes;
```
