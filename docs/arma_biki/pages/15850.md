## BIS fnc saveGame

- Source: https://community.bistudio.com/wiki/BIS_fnc_saveGame
- Revision: 349308
- Updated: 2023-11-08T14:52:21Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Missions

### Description

Evaluates the current battlefield situation and saves the game when appropriate.

### Syntax

```sqf
[objects] call BIS_fnc_saveGame
```

### Parameters

- objects: Array - units to check

### Return Value

- Boolean - true if saved

### Examples

#### Example 1

```sqf
[unit_1, unit_2] call BIS_fnc_saveGame;
```
