## BIS fnc moveAction

- Source: https://community.bistudio.com/wiki/BIS_fnc_moveAction
- Revision: 327869
- Updated: 2022-07-13T11:36:50Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Return current move action (used in playAction, playActionNow and switchAction)

### Syntax

```sqf
[unit, returnConfig] call BIS_fnc_moveAction
```

### Parameters

- unit: Object
- returnConfig: Boolean - (Optional, default false) true to return action config path, false to return the action name

### Return Value

- Config or String - depends on *returnConfig*

### Examples

#### Example 1

```sqf
_actionName		= [player, false] call BIS_fnc_moveAction;
_actionConfig	= [player,  true] call BIS_fnc_moveAction;
```
