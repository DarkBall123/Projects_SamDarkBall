## BIS fnc nearestRoad

- Source: https://community.bistudio.com/wiki/BIS_fnc_nearestRoad
- Revision: 378228
- Updated: 2026-03-17T23:25:48Z

- Availability: arma3 0.76
- Groups: Positions

### Description

Find the nearest road segment to certain position, within given radius.

### Syntax

```sqf
[centre, radius, blacklist] call BIS_fnc_nearestRoad
```

### Parameters

- centre: Position
- radius: Number - (Optional, default 50) search radius from *centre*
- blacklist: Array - (Optional, default 

```sqf
[]
```

) blacklisted road objects

### Return Value

- Object - nearest road object, objNull if not found

### Examples

#### Example 1

```sqf
private _nearestRoad = [getPosATL player, 500] call BIS_fnc_nearestRoad;
```

#### Example 2

```sqf
private _nearestRoad = [getPosATL vehicle player, 50, getPosATL vehicle player nearRoads 20] call BIS_fnc_nearestRoad;
```
