## enableReload

- Source: https://community.bistudio.com/wiki/enableReload
- Revision: 370150
- Updated: 2024-11-02T14:23:00Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Weapons

### Description

Enable / disable auto-reload (including AI) when magazine is empty. Default - enabled.

### Syntax

```sqf
object enableReload enable
```

### Parameters

- object: Object
- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_vehicle enableReload false;
```
