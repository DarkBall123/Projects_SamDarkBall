## mapAnimAdd

- Source: https://community.bistudio.com/wiki/mapAnimAdd
- Revision: 377554
- Updated: 2026-01-02T06:54:54Z

- Availability: ofp 1.27, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Map

### Description

Add next frame to map animation.

### Syntax

```sqf
mapAnimAdd [time, zoom, position]
```

### Parameters

- time: Number - animation duration in seconds
- zoom: Number - range from 0.01 (max. zoom) to 1 (zoomed out)
- position: Object or Position2D, Position3D

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
mapAnimAdd [1, 0.1, markerPos "anim1"];
mapAnimCommit;
```

#### Example 2

```sqf
mapAnimAdd [3, 0.01, player];
mapAnimCommit;
```
