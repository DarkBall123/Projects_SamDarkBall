## markerSize

- Source: https://community.bistudio.com/wiki/markerSize
- Revision: 377691
- Updated: 2026-01-02T09:03:12Z

- Availability: ofp, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Markers

### Description

Returns marker size. This command is identical to getMarkerSize.

### Syntax

```sqf
markerSize markerName
```

### Parameters

- markerName: String

### Return Value

- Array with [a_axis, b_axis]
* a_axis: Number - 1/2 width of marker
* b_axis: Number - 1/2 height of marker

### Examples

#### Example 1

```sqf
_mSize = markerSize "Marker1";
```
