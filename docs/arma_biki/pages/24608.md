## BIS fnc moveMarker

- Source: https://community.bistudio.com/wiki/BIS_fnc_moveMarker
- Revision: 351272
- Updated: 2023-11-26T14:20:51Z

- Availability: arma3 1.78
- Locality: argument global, effect global
- Groups: Map and Markers

### Description

Moves marker to a new position

### Syntax

```sqf
[marker, newPosition, duration, interpolationType] call BIS_fnc_moveMarker
```

### Parameters

- marker: String - marker
- newPosition: Array - new position
- duration: Number - (Optional, default 5) how long it takes to move the marker in seconds
- interpolationType: Number - (Optional, default 4) can be one of:
{{Columns|3|
* 0: LINEAR
* 1: CUBIC
* 2: EASEIN
* 3: EASEOUT
* 4: EASEINOUT
* 5: HERMITE
* 6: BERP
* 7: BOUNCEIN
* 8: BOUNCEOUT
* 9: BOUNCEINOUT
* 10: QUINTICIN
* 11: QUINTICOUT
* 12: QUINTICINOUT

}}

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["BIS_marker", [1111,2222,0]] call BIS_fnc_moveMarker;
```

#### Example 2

```sqf
["BIS_marker", getMarkerPos "BIS_marker2", 2, 9] call BIS_fnc_moveMarker;
```
