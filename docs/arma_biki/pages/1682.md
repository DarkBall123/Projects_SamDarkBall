## commander

- Source: https://community.bistudio.com/wiki/commander
- Revision: 363370
- Updated: 2024-03-28T10:39:29Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

In {{ofp}} it returns the commander of a vehicle. Since {{arma1}} it returns the primary observer. The commander of a vehicle can be found with effectiveCommander.

### Syntax

```sqf
commander  vehicle
```

### Parameters

- vehicle: Object - vehicle

### Return Value

- Object - the unit sitting in the commander place is returned. If vehicle is not a vehicle but a person, the person is returned.

### Examples

#### Example 1

```sqf
moveOut commander _tank;
```

#### Example 2

Detect if player is in commander turret of a vehicle:

```sqf
_isVehicleCommander = player isEqualTo commander objectParent player;
```
