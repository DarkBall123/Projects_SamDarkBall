## setPilotCameraDirection

- Source: https://community.bistudio.com/wiki/setPilotCameraDirection
- Revision: 377431
- Updated: 2026-01-02T06:46:14Z

- Availability: arma3 1.64
- Locality: argument local
- Groups: Pilot Camera

### Description

Sets the direction of airplane's or helicopter's [pilotCamera](Arma 3: Targeting config reference#class pilotCamera).

### Syntax

```sqf
object setPilotCameraDirection vector3D
```

### Parameters

- object: Object - a vehicle equipped with pilot camera
- vector3D: Vector3D - in model space, relative to the model centre (In a similar fashion to PositionRelative)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setPilotCameraDirection [0,1,0] // re-centers the camera
```
