## a != b

- Source: https://community.bistudio.com/wiki/a_%21%3D_b
- Revision: 376993
- Updated: 2026-01-01T08:00:36Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Variables, Math

### Description

Returns whether one value is **not** equal to another. String comparison is case-**in**sensitive (e.g 

```sqf
"STRINGtext" != "stringTEXT" // returns false - strings are equivalent
```

).
*a* and *b* types **must** match: comparing e.g String with Number is invalid.

### Syntax

```sqf
a != b
```

### Examples

#### Example 1

```sqf
if (_counter != 4) then
{
	hint "The counter is not equal to the number 4";
};
```

#### Example 2

```sqf
if (vehicle player != player) then
{
	hint "you are in a vehicle";
}
else
{
	hint "you are on foot";
};
```

#### Example 3

```sqf
if (fuel truck1 != 1) then
{
	hint "Truck1 has less than a full tank of fuel.";
};
```

#### Example 4

```sqf
if (alive _unit1 != alive _unit2) then { hint "One of the units is dead while another is alive" };
```
