## get3DENEntity

- Source: https://community.bistudio.com/wiki/get3DENEntity
- Revision: 378362
- Updated: 2026-04-03T16:26:44Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns Eden Entity based on its Eden ID.

### Syntax

```sqf
get3DENEntity  ID
```

### Parameters

- ID: Number - Eden ID

### Return Value

- Eden Entity or Number
* If the *ID* points to an Eden Entity the entity is returned
* If it points to a Eden Editor: Layer or Eden Editor: Comment the *ID* is returned
* If no entity with given *ID* exists `-1` is returned

### Examples

#### Example 1

```sqf
myEntity = get3DENEntity 1;
```
