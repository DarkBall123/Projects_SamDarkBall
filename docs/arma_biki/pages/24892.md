### Description

Returns the key owner of given control point.

### Syntax

```sqf
[controlPoint] call BIS_fnc_controlPoint_getOwnerKey
```

### Parameters

- controlPoint: Object - the control point

### Return Value

- Object - the key

### Examples

#### Example 1

```sqf
private _key = [controlPoint] call BIS_fnc_controlPoint_getOwnerKey;
```
