### Presentation

An identity declaration is done with setIdentity command, and its declaration looks like this:

```
class CfgIdentities
{
	class SomeGuy
	{
		face = "WhiteHead_10";
		glasses = "G_Tactical_Clear";
		name = "Adams";
		nameSound = "Adams";
		pitch = 1.0;
		speaker = "Male01ENG";
	};
};
```

- **face**: String - defines the unit's face.
  - This must be a value defined in the Faces list
  - See commands face, setFace
- **glasses**: String - defines the unit's glasses/goggles.
  - This must be a value defined in the Glasses list
  - See commands goggles, addGoggles, removeGoggles
- **name**: String - the unit's name.
  - Can be anything
- **nameSound**: String - defines how the unit is called (instead of "**2**, take cover" it will be for example "**Adams**, take cover").
  - This must be a value defined in the NameSounds list ***or*** any valid word found in

```sqf
configFile >> "RadioProtocolENG" >> "Words"
```

  - See commands nameSound, setNameSound
- **pitch**: Number - defines unit's voice pitch.
  - Must be a positive number, but can be anything over zero
  - See commands pitch, setPitch
- **speaker**: String defines unit's voice actor.
  - This must be a value defined in the Speakers list
  - See commands speaker, setSpeaker

See also the Description.ext#CfgIdentities chapter.
