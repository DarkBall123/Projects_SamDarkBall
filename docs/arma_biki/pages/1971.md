## addLiveStats

- Source: https://community.bistudio.com/wiki/addLiveStats
- Revision: 318778
- Updated: 2022-05-13T09:21:29Z

- Availability: ofpe 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Adds score to the Xbox Live Statistics score for the given unit (or the commander unit of the given vehicle).

### Syntax

```sqf
unit addLiveStats score
```

### Parameters

- unit: Object
- score: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addLiveStats 10;
```
