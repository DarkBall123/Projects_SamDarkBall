## preloadTitleRsc

- Source: https://community.bistudio.com/wiki/preloadTitleRsc
- Revision: 322925
- Updated: 2022-06-28T21:42:39Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Resource title - preload data. The resource can be defined in the Description.ext file.

### Syntax

```sqf
preloadTitleRsc [name, type, speed, showInMap]
```

### Parameters

- name: String - defined in Description.ext for the mission
- type: String - e.g "PLAIN"
- speed: Number - (Optional) ignored
- showInMap: Boolean - (Optional)

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_ok = preloadTitleRsc ["BIS", "PLAIN"];
```
