## periscopeElevation

- Source: https://community.bistudio.com/wiki/periscopeElevation
- Revision: 378227
- Updated: 2026-03-17T23:24:58Z

- Availability: arma3 2.00
- Groups: Object Manipulation, Animations

### Description

Returns current periscope elevation value, see also elevatePeriscope.

### Syntax

```sqf
vehicle periscopeElevation turretPath
```

### Parameters

- vehicle: Object - vehicle with periscope tech
- turretPath: Turret Path

### Return Value

- Array format [elevation, isLocked]:
* elevation: Number - current periscope elevation value. -1 in case of an invalid turret
* isLocked: Boolean - whether or not user override is blocked

### Examples

#### Example 1

```sqf
_eddie periscopeElevation [0] params ["_elevation", "_isLocked"];
```
