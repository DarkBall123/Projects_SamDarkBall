- Updated: 2024-10-08T15:08:55Z

### Description

Returns various mission options

### Syntax

```sqf
getMissionOptions
```


### Return Value

- HashMap - Containing the names and values of all options (see setMissionOptions)

### Examples

#### Example 1

```sqf
private _missionOptions = getMissionOptions;
```
