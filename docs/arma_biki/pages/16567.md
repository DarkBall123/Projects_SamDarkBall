This page contains all necessary data to install Arma 3 Tools in your computer.

### Prerequisites
- Preferably don't have BI Tools installed as it conflicts somehow (on Windows registry entries level) with the Arma 3 Tools from Steam
- Own a valid Steam account
- Internet connection
- At least 1.1 GB free space on your Hard Drive

### Step by Step Setup

#### Preparation

1. Open your Steam library (switch the filter to "Tools") - "Arma 3 Tools"
1. Configure which branch you want to use
200px
  1. Right click, then click on "Properties"
  1. go into "BETAS" tab
  1. Select the appropriate "beta"
*Details about branches are in the point "Details about branches"*
1. Automatic updates, behaviour
200px
  1. Go into "UPDATES" tab and select the appropriate value
To help you, there is a label under the list box that describes the selected option
  1. Be sure that "Enable Steam Cloud synchronization for Arma 3 Tools" is checked (*prepare the future ;)*)

#### Installation

1. From the Steam tools library, right click on Arma 3 Tools and click on "Install Game..."
1. Choose the appropriate location for install if needed
1. Review the general EULA
1. Click "next" and let Steam download the tools
1. Wait for the download to be completed

#### Configuration

1. Play Arma 3 Tools from Steam
200px
This step will add all needed registry entries for the rest of tools.

### Details about branches

#### Default

- Update frequency: Same as Arma 3 main branch
- Hard drive: 550+ MB free space
- Changelog: [Arma 3 TECHREPs](http://dev.arma3.com/techrep)
- Description:
- This is the main stable branch, used by the most of users.

#### Development Build

- Update frequency: Same as Arma 3 main branch
- Hard drive: 700+ MB free space
- Changelog: [Thread on BI Forums](http://forums.bistudio.com/showthread.php?179347-Tools-Development-Branch-Changelog)
- Description:
- This branch contains the latest public version of "Arma 3 Tools", including features, tools, fixes... and perhaps new issues, you bear the risk of using it.
- The updates are not daily like the Arma 3 development branch does, but rather in irregular intervals according to needs and additions by our team.
- Development branch does not pass internal QA before publication. Stick with main branch (default) if you do not want to deal with the (big) potential issues and frequent data transfers.

#### Huge Data Packages

- Update frequency: Same as Arma 3 main branch
- Hard drive: 22+ GB free space
- Changelog: [Arma 3 TECHREPs](http://dev.arma3.com/techrep)
- Description:
- In addition to the tools from the default branch, it will download the [Public Data](Category:Public Data).
- Be warned, this represents around 22 GB of additional download, but it is downloaded once since it is excluded from the update plan.

### Notes

#### Uninstall

Be aware, if you use the Arma 3 Tools as P Drive (default location), your P Drive content will be erased.
In some cases, the content that was added by Steam (I.e. settings.ini or other user files) remains present into the installation directory and should be deleted manually in case of need.

##### Steam solution
1. Open your Steam library (switch the filter to "Tools") - "Arma 3 Tools"
1. right click on Arma 3 Tools, then click on delete local content

##### Windows solution
1. Open the control panel, then go into "Program and Features"
1. Locate "Arma 3 Tools", do a left click and click uninstall
1. The rest of the process will be handled by Steam, it will have for effect to delete the content of "Arma 3 Tools" and the registry keys related by the tools
