## ctrlSetFontHeightH1

- Source: https://community.bistudio.com/wiki/ctrlSetFontHeightH1
- Revision: 323080
- Updated: 2022-06-28T21:43:13Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H1 font size of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontHeightH1 height
```

### Parameters

- controlName: Control
- height: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontHeightH1 0.05;
```
