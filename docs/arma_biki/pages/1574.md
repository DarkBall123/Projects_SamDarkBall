## flag

- Source: https://community.bistudio.com/wiki/flag
- Revision: 353769
- Updated: 2024-03-23T14:27:22Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Flags

### Description

Returns the original flag pole of the flag the unit is carrying.

### Syntax

```sqf
flag unit
```

### Parameters

- unit: Object

### Return Value

- Object - flag pole object the flag belongs to. If the unit carries no flag, objNull is returned.

### Examples

#### Example 1

```sqf
_flag = flag _soldier;
```
