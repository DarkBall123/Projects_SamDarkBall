## useAISteeringComponent

- Source: https://community.bistudio.com/wiki/useAISteeringComponent
- Revision: 352369
- Updated: 2024-02-08T14:10:38Z

- Availability: arma3 1.60
- Locality: argument local, effect global
- Groups: AI Behaviour

### Description

Enable the new [text= AI driving](link= https://forums.bistudio.com/topic/191515-ai-driving-feedback-topic/), used to test the old and new AI driving.
setDriveOnPath does not work if the vehicle doesn't have an AI steering component or if it's disabled.

### Syntax

```sqf
useAISteeringComponent enabled
```

```sqf
vehicle useAISteeringComponent enabled
```

### Parameters

- enabled: Boolean
- vehicle: Object - the vehicle to enable/disable the feature for
- enabled: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
useAISteeringComponent true;
```

#### Example 2

```sqf
myTank useAISteeringComponent false;
```
