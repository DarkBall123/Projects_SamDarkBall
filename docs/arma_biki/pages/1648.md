## lockWP

- Source: https://community.bistudio.com/wiki/lockWP
- Revision: 321186
- Updated: 2022-05-13T15:20:16Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Waypoints

### Description

Disable switching to next waypoint (current waypoint will never complete while lockwp is used). Sometimes used during cut-scenes.

### Syntax

```sqf
groupName lockWP lock
```

### Parameters

- groupName: Object or Group
- lock: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_groupOne lockWP true;
```

#### Example 2

```sqf
_Soldier lockWP true;
```

#### Example 3

```sqf
_MyTank lockWP false;
```
