## tvDelete

- Source: https://community.bistudio.com/wiki/tvDelete
- Revision: 378380
- Updated: 2026-04-04T04:46:06Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Removes an item with given Tree View Path from Tree View.
The paths of other items on the same branch after delete operation are updated accordingly; therefore, when deleting multiple entries, start with the one with the highest index and proceed in reverse order.

### Syntax

```sqf
tvDelete [idc, path]
```

```sqf
control tvDelete path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvDelete [101, [0, 0]];
```

#### Example 2

```sqf
_ctrl tvDelete [0, 0];
```
