## diag dumpTerrainSynth

- Source: https://community.bistudio.com/wiki/diag_dumpTerrainSynth
- Revision: 310309
- Updated: 2022-05-05T16:20:41Z

- Availability: arma3 2.04
- Groups: Diagnostic

### Description

Returns OutsideTerrain's current world's values.

### Syntax

```sqf
diag_dumpTerrainSynth
```


### Return Value

- Array of Number, Array of Numbers: [analysisLength, [min1, max1], [min2, max2], ..., [min512, max512]]. There are 512 min/max pairs.
* analysisLength: Number - altitude analysis distance from terrain's border towards its centre
* min1..512: Number - minimum altitude
* max1..512: Number - maximum altitude

### Examples

#### Example 1

```sqf
private _terrainSynth = diag_dumpTerrainSynth;
```
