## gearSlotAmmoCount

- Source: https://community.bistudio.com/wiki/gearSlotAmmoCount
- Revision: 376113
- Updated: 2025-08-26T21:33:41Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Unit Inventory, GUI Control

### Description

Returns ammo count of assigned magazine.

### Syntax

```sqf
gearSlotAmmoCount control
```

### Parameters

- control: Control - `CT_ITEMSLOT 103`

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _ammoCount = gearSlotAmmoCount _control;
```
