## BIS fnc dbValueId

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbValueId
- Revision: 327496
- Updated: 2022-07-12T22:22:44Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Converts string to value definition or vice versa.

### Syntax

```sqf
valueString call BIS_fnc_dbValueId
```

### Parameters

- valueString - String or Array:
* String - converts string to value definition
* Array: converts value definition to string

### Return Value


### Examples

#### Example 1

```sqf
"MYVALUE" call BIS_fnc_dbValueId; // "&MYVALUE"
```

#### Example 2

```sqf
["&MYVALUE"] call BIS_fnc_dbValueId; // "MYVALUE"
```
