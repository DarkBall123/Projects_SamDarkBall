## activateKey

- Source: https://community.bistudio.com/wiki/activateKey
- Revision: 341303
- Updated: 2023-05-20T20:40:03Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Activates the given keyname for the current user profile. The keys are used to unlock missions or campaigns.
See 

```
keys
```

, 

```
keysLimit
```

 and 

```
doneKeys
```

 in the Description.ext#Mission Keys chapter.

### Syntax

```sqf
activateKey keyname
```

### Parameters

- keyname: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
activateKey "Mission04Key";
```
