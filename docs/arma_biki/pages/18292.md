## menuCollapse

- Source: https://community.bistudio.com/wiki/menuCollapse
- Revision: 378331
- Updated: 2026-04-02T16:30:43Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Collapses item on given path and all its children.

### Syntax

```sqf
menuCollapse [idc, path]
```

```sqf
control menuCollapse path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuCollapse [0];
```
