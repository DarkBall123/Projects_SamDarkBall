## BIS fnc addVirtualBackpackCargo

- Source: https://community.bistudio.com/wiki/BIS_fnc_addVirtualBackpackCargo
- Revision: 349390
- Updated: 2023-11-08T16:27:25Z

- Availability: arma3 1.24
- Groups: Inventory

### Description

Add virtual backpacks to an object (e.g., ammo box). Virtual items can be selected in the Arsenal.

### Syntax

```sqf
[object,backpackClasses,addItemsGlobal,arsenal] call BIS_fnc_addVirtualBackpackCargo
```

### Parameters

- object: Object - object to which items will be added
- backpackClasses: Boolean, String or Array of Strings - backpack classes
- addItemsGlobal: Boolean - (Optional, default false) true to add items globally
- arsenal: Boolean - (Optional, default true) true to add Arsenal action

### Return Value

- Array of Strings - all virtual backpacks

### Examples

#### Example 1

```sqf
[BIS_ammoBox, ["class_1","class_2"], false, true] call BIS_fnc_addVirtualBackpackCargo;
```
