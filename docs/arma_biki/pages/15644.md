## BIS fnc fps

- Source: https://community.bistudio.com/wiki/BIS_fnc_fps
- Revision: 370886
- Updated: 2025-02-21T10:44:04Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Diagnostic

### Description

Function to measure FPS. Spawns code running for given time and displays result on screen via titleText, globalChat **and** diag_log.
Variable **BIS_fps_output** is filled with diag_log content too.

### Syntax

```sqf
[duration, sceneId, startDelay] call BIS_fnc_fps
```

### Parameters

- duration: Number - the FPS test duration
- sceneId: String - (Optional, default "") scene ID, used in outputs. Fills global variable **currentScene**
- startDelay: Number - (Optional, default 0) delay before starting measurement

### Return Value

- Script Handle

### Examples

#### Example 1

```sqf
private _scriptHandle = [10, "50 units on screen", 3] call BIS_fnc_fps;
```
