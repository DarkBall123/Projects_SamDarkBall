## setMarkerTypeLocal

- Source: https://community.bistudio.com/wiki/setMarkerTypeLocal
- Revision: 349126
- Updated: 2023-11-08T14:49:40Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Sets marker type locally. Marker type is a class name in CfgMarkers.

### Syntax

```sqf
markerName setMarkerTypeLocal type
```

### Parameters

- markerName: String
- type: String - see CfgMarkers.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"MarkerOne" setMarkerTypeLocal "Warning";
```
