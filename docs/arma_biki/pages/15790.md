## BIS fnc dbConfigPath

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbConfigPath
- Revision: 327355
- Updated: 2022-07-12T22:11:56Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

If there is a database present in the config (config.cpp or descritpion.ext) then this function can be used to get the config path of the passed array. So it basically converts the array into a config entry.

### Syntax

```sqf
[path, config] call BIS_fnc_dbConfigPath
```

### Parameters

- path - Array: Path to class or value
- config - Config: Database config

### Return Value

- Config: Config path to the class or value
