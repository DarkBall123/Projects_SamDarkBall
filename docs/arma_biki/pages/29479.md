Textures available for use with setFlagTexture. See Command Group: Flags for all flag commands.

### File Location

{{ofp}} comes with an addon called `Flags.pbo` which contains all the flags of the world. You can find it in the addons folder.

### Flag Textures

- "\flags\usa.jpg"
- "\flags\ussr.jpg"
- "\flags\fia.jpg"

### Flag Texture Files

- "usa_vlajka.pac" (US flag)
- "rus_vlajka.pac" (Soviet Union flag)
- "guba_vlajka.pac" (Guba's private flag)
