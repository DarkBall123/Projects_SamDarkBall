## BIS fnc moduleEffectsFire

- Source: https://community.bistudio.com/wiki/BIS_fnc_moduleEffectsFire
- Revision: 352226
- Updated: 2024-02-01T23:26:09Z

- Availability: arma3 1.00
- Groups: Modules

### Description

Creates fire on position of module (called usually by BIS_fnc_moduleEffectsEmitterCreator). Mainly meant to be used by modules available in Eden Editor

### Syntax

```sqf
[module] call BIS_fnc_moduleEffectsFire
```

### Parameters

- module: Object - module

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_module] call BIS_fnc_moduleEffectsFire;
```
