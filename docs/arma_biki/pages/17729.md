## removeAll3DENEventHandlers

- Source: https://community.bistudio.com/wiki/removeAll3DENEventHandlers
- Revision: 342137
- Updated: 2023-07-09T12:26:45Z

- Availability: arma3 1.56
- Groups: Eden Editor, Event Handlers

### Description

Removes all Eden Editor event handlers of given type. 

See the list of all Eden Editor Event Handlers.

### Syntax

```sqf
removeAll3DENEventHandlers type
```

### Parameters

- type: String - name of event handler

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAll3DENEventHandlers "onUndo";
```
