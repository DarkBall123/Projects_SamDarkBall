## BIS fnc ambientPlanes

- Source: https://community.bistudio.com/wiki/BIS_fnc_ambientPlanes
- Revision: 378072
- Updated: 2026-02-11T08:03:13Z

- Availability: tkoh 1.00, arma3 0.50
- Locality: effect global
- Groups: Ambient

### Description

Creates ambient airplanes fly-by near airports around the player. It will automatically get classes from 

```sqf
configFile >> "CfgVehicles"
```

 on all planes that have "ambientType" attribute > 0.

### Multiplayer

Since this function uses player and its effect is global,
this can only be used in singleplayer or executed locally on a player, usually the group leader.

### Syntax

```sqf
[quantity, areaRadius, dirStep] call BIS_fnc_ambientPlanes
```

### Parameters

- quantity: Number - (Optional, default 5)
- areaRadius: Number - (Optional, default 10000) area radius around airports where planes can spawn/fly
- dirStep: Number - (Optional, default 30)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[] call BIS_fnc_ambientPlanes;
```

#### Example 2

```sqf
[30, 3000] call BIS_fnc_ambientPlanes;
```
