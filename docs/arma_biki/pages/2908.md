## ctrlSetActiveColor

- Source: https://community.bistudio.com/wiki/ctrlSetActiveColor
- Revision: 377734
- Updated: 2026-01-03T00:21:56Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets text color of given control when it is selected.

### Syntax

```sqf
control ctrlSetActiveColor color
```

### Parameters

- control: Control
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetActiveColor [1, 0, 0, 1];
```
