## BIS fnc rotateVector3D

- Source: https://community.bistudio.com/wiki/BIS_fnc_rotateVector3D
- Revision: 338142
- Updated: 2023-02-23T23:47:39Z

- Availability: arma3 1.00
- Groups: Vectors

### Description

Rotates the vector around the given axis by the given angle

### Syntax

```sqf
[vector, angle, axis] call BIS_fnc_rotateVector3D
```

### Parameters

- vector: Array in format Vector3D
- angle: Number - given angle (taken in the opposite direction to the one defined by the [right hand rule](https://en.wikipedia.org/wiki/Right-hand_rule))
- axis: Number - rotation axis:
* 0 - **X** axis
* 1 - **Y** axis
* 2 - **Z** axis

### Return Value

- Array - rotated vector in format Vector3D

### Examples

#### Example 1

```sqf
[vectorDir player, 90, 2] call BIS_fnc_rotateVector3D;
```
