## sendAUMessage

- Source: https://community.bistudio.com/wiki/sendAUMessage
- Revision: 321116
- Updated: 2022-05-13T14:14:53Z

- Availability: arma3 0.50
- Groups: Multiplayer

### Description

Send the command to the list of clients.

### Syntax

```sqf
sendAUMessage [clientList, command]
```

### Parameters

- clientList: Array
- command: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
sendAUMessage [[dpnid1, dpnid2], "ConnectTo: 192.168.1.66"];
```
