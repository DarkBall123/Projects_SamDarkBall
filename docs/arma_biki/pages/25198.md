## getUserMFDValue

- Source: https://community.bistudio.com/wiki/getUserMFDValue
- Revision: 310918
- Updated: 2022-05-07T20:39:37Z

- Availability: arma3 1.70
- Groups: Interaction

### Description

Returns array of user text variables used in MFD.

### Syntax

```sqf
getUserMFDValue vehicle
```

### Parameters

- vehicle: Object - a vehicle with MFD

### Return Value

- Array of Numbers

### Examples

#### Example 1

```sqf
getUserMFDValue vehicle player; // user0 in MFD will return 1
```
