## isMultiplayerSolo

- Source: https://community.bistudio.com/wiki/isMultiplayerSolo
- Revision: 310750
- Updated: 2022-05-07T20:21:31Z

- Availability: arma3 1.66
- Groups: Multiplayer

### Description

Returns true when playing a game in **solo multiplayer** (for example Apex coop campaign PLAY SOLO option).

### Syntax

```sqf
isMultiplayerSolo
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_state = isMultiplayerSolo;
```
