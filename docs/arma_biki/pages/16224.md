## BIS fnc VREffectKilled

- Source: https://community.bistudio.com/wiki/BIS_fnc_VREffectKilled
- Revision: 349396
- Updated: 2023-11-08T16:27:25Z

- Availability: arma3 1.24
- Groups: VR

### Description

Delete body of a virtual soldier after he's killed.

### Syntax

```sqf
[object, instant, delay] call BIS_fnc_VREffectKilled
```

### Parameters

- object: Object - object
- instant: Boolean - (Optional, default false) true to delete the body right away, false to add **killed** EH which will delete it after death
- delay: Number - (Optional, default 10) time in seconds before the body disappears

### Return Value

- Boolean - true when the function is done

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_VREffectKilled;
```

#### Example 2

```sqf
[player, true, 5] spawn BIS_fnc_VREffectKilled;
```
