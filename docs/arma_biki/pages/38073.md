## getLeaning

- Source: https://community.bistudio.com/wiki/getLeaning
- Revision: 369757
- Updated: 2024-10-08T15:08:56Z

- Availability: arma3 2.18
- Locality: argument global
- Groups: Unit Control

### Description

Returns the leaning factor of the given unit.

### Syntax

```sqf
getLeaning unit
```

### Parameters

- unit: Object

### Return Value

- Number - leaning factor from -1 to 1

### Examples

#### Example 1

```sqf
if (getLeaning player < 0) then { systemChat "player is leaning left" };
```
