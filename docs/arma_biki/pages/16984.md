## isWeaponDeployed

- Source: https://community.bistudio.com/wiki/isWeaponDeployed
- Revision: 321095
- Updated: 2022-05-13T13:54:06Z

- Availability: arma3 1.42
- Locality: argument global
- Groups: Weapons

### Description

Returns true if weapon is currently deployed.

### Syntax

```sqf
isWeaponDeployed unit
```

```sqf
isWeaponDeployed [unit, onGround]
```

### Parameters

- unit: Object
- unit: Object
- onGround: Boolean - (Optional) true to check if deployed on ground, false to check if deployed on object. Omitted - same as main syntax.

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
_dep = isWeaponDeployed player;
```

#### Example 2

```sqf
_depOnObj = isWeaponDeployed [player, false];
```
