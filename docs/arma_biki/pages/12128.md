## addItemCargo

- Source: https://community.bistudio.com/wiki/addItemCargo
- Revision: 341379
- Updated: 2023-05-25T12:43:57Z

- Availability: arma3 0.50
- Locality: argument local, effect local
- Groups: Vehicle Inventory

### Description

Creates new items and stores them in given container.
Works with items, weapons, magazines, equipment and glasses but not backpacks.
In the latter case use addBackpackCargo instead. For the global variant, see addItemCargoGlobal.

### Syntax

```sqf
box addItemCargo [item, count]
```

### Parameters

- box: Object
- item: String
- count: Number - number of items to add; 2.14 a negative value removes items

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
supplyBox addItemCargo ["optic_ARCO", 10];
```
