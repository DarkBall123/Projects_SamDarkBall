## BIS fnc dbValueList

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbValueList
- Revision: 327497
- Updated: 2022-07-12T22:23:10Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Returns all values within class.

### Syntax

```sqf
[database, path] call BIS_fnc_dbValueList
```

### Parameters

- database - Array: database array
- path- Array: path to class

### Return Value

- Array: List of all value names

### Examples

#### Example 1

```sqf
"#MILLER", ["&KILLS", 1000, "&RANK", "CAPTAIN", ["miller"]] call BIS_fnc_dbValueList; // ["KILLS", "RANK"]
```
