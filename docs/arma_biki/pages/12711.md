## removeItemFromUniform

- Source: https://community.bistudio.com/wiki/removeItemFromUniform
- Revision: 376273
- Updated: 2025-09-23T06:13:21Z

- Availability: arma3 1.04
- Locality: argument global, effect global
- Groups: Containers

### Description

Removes item from soldier's uniform. Can be used with magazines and weapons too.

### Syntax

```sqf
unit removeItemFromUniform item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeItemFromUniform "FirstAidKit";
```
