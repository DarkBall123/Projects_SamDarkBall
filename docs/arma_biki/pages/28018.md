## lnbPictureRight

- Source: https://community.bistudio.com/wiki/lnbPictureRight
- Revision: 348973
- Updated: 2023-11-08T14:45:44Z

- Availability: arma3 1.00
- Groups: GUI Control - ListNBox

### Description

Returns the right picture of given row. The *column* parameter does not matter.

### Syntax

```sqf
lnbPictureRight [idc, [row, column]]
```

```sqf
ctrl lnbPictureRight [row, column]
```

### Parameters

- idc: Number
- row: Number - index of the row
- column: Number - index of the column
- ctrl: Control
- row: Number - index of the row
- column: Number - index of the column

### Return Value

- String - path of image
- String - path of image

### Examples

#### Example 1

```sqf
_path = _control lnbPictureRight [0, 0];
```
