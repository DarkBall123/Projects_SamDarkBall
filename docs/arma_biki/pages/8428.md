## setGroupIconParams

- Source: https://community.bistudio.com/wiki/setGroupIconParams
- Revision: 377887
- Updated: 2026-01-04T16:31:07Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: High Command

### Description

Set group icons parameters.

### Syntax

```sqf
group setGroupIconParams properties
```

### Parameters

- group: Group
- properties: Array with [color, text, scale, visibility, WPvisibility, WPcolor]
* color: Color (RGBA)
* text: String
* scale: Number
* visibility: Boolean
* WPvisibility: Boolean
* WPcolor: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_grp setGroupIconParams [[0.9,0,0,1], "The Group", 1.25, false];
```
