## reportRemoteTarget

- Source: https://community.bistudio.com/wiki/reportRemoteTarget
- Revision: 310923
- Updated: 2022-05-07T20:45:37Z

- Availability: arma3 1.70
- Locality: argument local
- Groups: Sensors

### Description

Shares the target vehicle via datalink to the Side center for a given time.

### Syntax

```sqf
side reportRemoteTarget [target, time]
```

### Parameters

- side: Side
- target: Object
- time: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
blufor reportRemoteTarget [vehicle player, 60];
```
