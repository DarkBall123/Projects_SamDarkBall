## BIS fnc halt

- Source: https://community.bistudio.com/wiki/BIS_fnc_halt
- Revision: 348819
- Updated: 2023-11-08T14:38:18Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Halts current function and all its parents and logs an error message.

### Syntax

```sqf
[param1, param2, ..., param10] call BIS_fnc_halt
```

### Parameters

- param1: String - logged message (formatted)
- param2 - param10: Anything

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
["You are now supposed to be %1", rank player] call BIS_fnc_halt;
```
