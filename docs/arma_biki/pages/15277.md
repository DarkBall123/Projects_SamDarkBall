## visibleWatch

- Source: https://community.bistudio.com/wiki/visibleWatch
- Revision: 364092
- Updated: 2024-05-03T19:50:40Z

- Availability: arma3 1.22
- Groups: Interaction

### Description

Checks if the player has watch opened and visible. Keep in mind that the GPS minimap in Arma 3 also shows the time.

### Syntax

```sqf
visibleWatch
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (visibleWatch) then { hint "Watch is visible" };
```
