## halt

- Source: https://community.bistudio.com/wiki/halt
- Revision: 377978
- Updated: 2026-01-19T18:48:19Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow, Broken Commands

### Description

This command was meant to break the script into debugger, however currently **it does not do anything** except displaying and logging the following error: `Error Debugger breakpoint hit`.

### Syntax

```sqf
halt
```


### Return Value

- Boolean - always returns false

### Examples

#### Example 1

```sqf
if (_displayAnError) then {halt};
```
