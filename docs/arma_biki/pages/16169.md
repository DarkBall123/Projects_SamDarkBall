## BIS fnc taskReal

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskReal
- Revision: 348603
- Updated: 2023-11-08T13:45:16Z

- Availability: arma3 1.00
- Locality: argument global
- Groups: Tasks

### Description

Find the actual task associated with a task name assigned to a unit.
See Arma 3: Task Framework for more information.

### Syntax

```sqf
[taskName, owner] call BIS_fnc_taskReal
```

### Parameters

- taskName: String
- owner: Object - task owner

### Return Value

- Task - task

### Examples

#### Example 1

```sqf
["testTask", player] call BIS_fnc_taskReal; // returns "Task testTask (id 0)"
```
