## radioChannelInfo

- Source: https://community.bistudio.com/wiki/radioChannelInfo
- Revision: 377628
- Updated: 2026-01-02T08:52:11Z

- Availability: arma3 2.00
- Groups: Radio and Chat, Custom Radio and Chat

### Description

Obtains custom radio channel's details. if 'customChannelID' is invalid, the return is either the first custom radio channel (customChannelID < firstCCChannel) or the last (customChannelID > lastCCChannel). 'inUse' true indicates if the channel was made available using radioChannelCreate, false means it can be created.

### Syntax

```sqf
radioChannelInfo customChannelID
```

```sqf
radioChannelInfo option
```

### Parameters

- customChannelID: Number - custom channel ID returned by radioChannelCreate
- option: Boolean - true to return only channels in use, false to return all available channels

### Return Value

- Array with [colour, label, callSign, units, sentenceType, inUse, 2.22 callSignVoN] (see radioChannelCreate)
- Array of Arrays in format [ [colour, label, callSign, units, sentenceType, inUse, callSignVoN],....] (see radioChannelCreate)

### Examples

#### Example 1

```sqf
private _channelID = radioChannelCreate [[1, 0, 0.5, 0.8], "Q-dance Radio", "%UNIT_NAME", [u1, u2], false];
radioChannelInfo _channelID; // returns [[1,0,0.5,0.8], "Q-dance Radio", "%UNIT_NAME", [u1, u2], false, true]
```
