## BIS fnc relativeDirTo

- Source: https://community.bistudio.com/wiki/BIS_fnc_relativeDirTo
- Revision: 327966
- Updated: 2022-07-13T13:59:46Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Geometry

### Description

Returns the relative direction from object 1 to object/position 2. Return value is always in between 0 and 360.
Use getRelDir instead.

### Syntax

```sqf
[from, to] call BIS_fnc_relativeDirTo
```

### Parameters

- from: Object
- to: Object or Array format Position

### Return Value

- Number

### Examples

#### Example 1

```sqf
[[0,0,0], player] call BIS_fnc_relativeDirTo;
```
