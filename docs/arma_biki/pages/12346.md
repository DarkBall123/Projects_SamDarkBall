## simulWeatherSync

- Source: https://community.bistudio.com/wiki/simulWeatherSync
- Revision: 363572
- Updated: 2024-04-07T08:45:59Z

- Availability: arma3 0.50
- Groups: Environment

### Description

Synchronizes Simul Weather with {{arma}} weather, generates all keyframes.

### Syntax

```sqf
simulWeatherSync
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
simulWeatherSync;
```
