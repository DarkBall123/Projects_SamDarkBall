## addCuratorEditableObjects

- Source: https://community.bistudio.com/wiki/addCuratorEditableObjects
- Revision: 377067
- Updated: 2026-01-01T09:24:50Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Register objects which can be edited by a curator.

### Syntax

```sqf
curatorObj addCuratorEditableObjects [objects, addCrew]
```

### Parameters

- curatorObj: Object - curator module
- objects: Array of Objects
- addCrew: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
MyCuratorModule addCuratorEditableObjects [[MyCar], true];
```
