## ctrlSetFontHeightH3

- Source: https://community.bistudio.com/wiki/ctrlSetFontHeightH3
- Revision: 322957
- Updated: 2022-06-28T21:42:50Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H3 font size of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontHeightH3 height
```

### Parameters

- controlName: Control
- height: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontHeightH3 0.05;
```
