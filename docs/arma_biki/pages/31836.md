## ambientTemperature

- Source: https://community.bistudio.com/wiki/ambientTemperature
- Revision: 347561
- Updated: 2023-09-28T09:49:53Z

- Availability: arma3 2.06
- Groups: Environment

### Description

Returns ambient temperature on the current terrain in Celsius in format: [airTemperature, blackSurfaceTemperature, whiteSurfaceTemperature]

### Syntax

```sqf
ambientTemperature
```


### Return Value

- Array of Numbers in format [airTemperature, blackSurfaceTemperature, whiteSurfaceTemperature]

### Examples

#### Example 1

```sqf
private _airTemp = ambientTemperature select 0;
```
