## BIS fnc holdActionRemove

- Source: https://community.bistudio.com/wiki/BIS_fnc_holdActionRemove
- Revision: 349409
- Updated: 2023-11-08T16:27:27Z

- Availability: arma3 1.62
- Groups: Interaction

### Description

Removes a hold action. This does exactly the same as removeAction.

### Syntax

```sqf
[target,ID] call BIS_fnc_holdActionRemove
```

### Parameters

- target: Object - object the action is attached to
- ID: Number - action ID

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player,10] call BIS_fnc_holdActionRemove;
```
