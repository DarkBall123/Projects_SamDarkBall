## ctrlModelDirAndUp

- Source: https://community.bistudio.com/wiki/ctrlModelDirAndUp
- Revision: 365012
- Updated: 2024-07-10T09:58:01Z

- Availability: arma3 1.32
- Groups: GUI Control - Object

### Description

Returns vectorDir and vectorUp of the model used in 3D-Dialogs. Returns [[],[]] if control is null.

### Syntax

```sqf
ctrlModelDirAndUp control
```

### Parameters

- control : Control - 3D control

### Return Value

- Array of Vector3Ds format [<nowiki/>vectorDir, vectorUp] or [[],[]]

### Examples

#### Example 1

```sqf
_vectorDirAndUp = ctrlModelDirAndUp _control3D;
```
