## BIS fnc invRemove

- Source: https://community.bistudio.com/wiki/BIS_fnc_invRemove
- Revision: 349422
- Updated: 2023-11-08T16:27:33Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Inventory

### Description

Removes from inventory. Given number of items. Returns actually removed items count.

### Syntax

```sqf
[object,class,count] call BIS_fnc_invRemove
```

### Parameters

- object: Object
- class: String - item class to be added
- count: Number - (Optional, default 1) number of items to be removed

### Return Value

- Number - number of items which were removed

### Examples

#### Example 1

```sqf
[player,"someClass",5] call BIS_fnc_invRemove;
```
