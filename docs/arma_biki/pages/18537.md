## ctValue

- Source: https://community.bistudio.com/wiki/ctValue
- Revision: 310913
- Updated: 2022-05-07T20:33:32Z

- Availability: arma3 1.70
- Groups: GUI Control - Controls Table

### Description

Returns metadata (number) associated with a particular row of RscControlsTable.

### Syntax

```sqf
control ctValue index
```

### Parameters

- control: Control
- index: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
_number = _control ctValue 0;
```
