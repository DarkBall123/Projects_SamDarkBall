## progressLoadingScreen

- Source: https://community.bistudio.com/wiki/progressLoadingScreen
- Revision: 376972
- Updated: 2026-01-01T06:03:03Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: System

### Description

If loading screen is shown, sets progress bar to the given value (interval is from 0 to 1]).
The loading screen can be force-ended with the [ENDLOAD cheat code](Arma 3: Cheats#ENDLOAD).

### Syntax

```sqf
progressLoadingScreen progress
```

### Parameters

- progress: Number in range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
startLoadingScreen ["Loading My Mission"];
// 
// batch of code
// 
progressLoadingScreen 0.25;
// 
// batch of code
// 
progressLoadingScreen 0.50;
// 
// batch of code
// 
progressLoadingScreen 0.95;
// 
// batch of code
// 
endLoadingScreen;
```
