## setRandomLip

- Source: https://community.bistudio.com/wiki/setRandomLip
- Revision: 310244
- Updated: 2022-05-05T13:11:05Z

- Availability: arma3 0.50
- Locality: argument global, effect local
- Groups: Object Manipulation

### Description

Enables/Disables random lip. When enabled, the unit continuously moves its lips as if it is talking.

### Syntax

```sqf
unit setRandomLip bool
```

### Parameters

- unit: Object
- bool: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setRandomLip true;
```
