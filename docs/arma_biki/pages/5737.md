## distributionRegion

- Source: https://community.bistudio.com/wiki/distributionRegion
- Revision: 318977
- Updated: 2022-05-13T09:22:07Z

- Availability: arma1 1.05, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Returns the numerical index for the distribution region of this copy of {{arma1}}.
# USA
# Rest of the world

### Syntax

```sqf
distributionRegion
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
if (distributionRegion == 1) then { hint "miles"; } else { hint "kilometres"; };
```
