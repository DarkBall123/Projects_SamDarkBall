## BIS fnc taskDescription

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskDescription
- Revision: 352119
- Updated: 2024-02-01T23:25:02Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Return a task's description. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskName call BIS_fnc_taskDescription
```

### Parameters

- taskName: String

### Return Value

- Array - task's description in the format ["description", "title", "marker"]

### Examples

#### Example 1

```sqf
"BIS_task_01" call BIS_fnc_taskDescription;
```
