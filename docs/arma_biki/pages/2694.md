## hideBehindScripted

- Source: https://community.bistudio.com/wiki/hideBehindScripted
- Revision: 321181
- Updated: 2022-05-13T15:18:14Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00
- Groups: Object Manipulation, Unit Control

### Description

When set to true it disables the default engine hiding behavior.

### Syntax

```sqf
object hideBehindScripted scriptedHideBehind
```

### Parameters

- object: Object
- scriptedHideBehind: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_unit hideBehindScripted true;
```
