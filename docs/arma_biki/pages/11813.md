## terrainIntersectASL

- Source: https://community.bistudio.com/wiki/terrainIntersectASL
- Revision: 377458
- Updated: 2026-01-02T06:47:25Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Math - Geometry

### Description

Checks for intersection of terrain between two ASL positions. Returns true if intersects with terrain.
For AGL variant, see terrainIntersect.

### Syntax

```sqf
terrainIntersectASL [start, end]
```

### Parameters

- start: PositionASL - start position
- end: PositionASL - end position

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_intersects = terrainIntersectASL [getPosASL player, getPosASL chopper];
```

#### Example 2

```sqf
_intersects = terrainIntersectASL [eyePos player, eyePos enemy1];
```
