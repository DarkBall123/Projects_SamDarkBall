## failMission

- Source: https://community.bistudio.com/wiki/failMission
- Revision: 363258
- Updated: 2024-03-26T10:51:31Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Finish the mission. If the server is set to run persistent mission, failMission will not end the mission when last player gets kicked to the lobby. Use endMission to end the mission.

The end type can be:
* "CONTINUE" - this is default type, basically an alias to do nothing
* "KILLED"
* "LOSER"
* "END1"
* "END2"
* "END3"
* "END4"
* "END5"
* "END6"

**Mission saves won't be deleted**.

To maintain Arma 3 visual style, it is recommended to use BIS_fnc_endMission instead.

### Syntax

```sqf
failMission endtype
```

### Parameters

- endtype: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
failMission "LOSER";
```
