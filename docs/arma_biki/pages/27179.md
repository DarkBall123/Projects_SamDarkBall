## lnbSetPictureColor

- Source: https://community.bistudio.com/wiki/lnbSetPictureColor
- Revision: 377350
- Updated: 2026-01-02T06:40:12Z

- Availability: arma3 1.42
- Groups: GUI Control - ListNBox

### Description

Sets the cell picture's colour.

### Syntax

```sqf
lnbSetPictureColor [idc, [row, column], colour]
```

```sqf
ctrl lnbSetPictureColor [<nowiki/>[row, column], colour]
```

### Parameters

- idc: Number
- row: Number - 0-based index (first column is 0, second is 1, etc)
- column: Number - 0-based index (first column is 0, second is 1, etc)
- colour: Color (RGBA)
- ctrl: Control
- row: Number - 0-based index (first column is 0, second is 1, etc)
- column: Number - 0-based index (first column is 0, second is 1, etc)
- colour: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lnbSetPictureColor [1492, [1,0], [0,0.75,0.3,0.5]];
```

#### Example 2

```sqf
ctrl lnbSetPictureColor [[0, 3], [1,0,0,1]];
```
