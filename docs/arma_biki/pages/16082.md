## BIS fnc teamColor

- Source: https://community.bistudio.com/wiki/BIS_fnc_teamColor
- Revision: 377980
- Updated: 2026-01-19T20:38:21Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Convert number to color team name or color.

### Syntax

```sqf
[teamId, getColour] call BIS_fnc_teamColor
```

### Parameters

- teamId: Number - in range 1..5
- getColour: Boolean - (Optional, default false) true to get Color (RGBA), false to get the *localised* team name

### Return Value

- Color (RGBA) or String - color format [r, g, b, a] or localised team name

### Examples

#### Example 1

```sqf
_colour = [2, true] call BIS_fnc_teamColor;
```

#### Example 2

```sqf
_teamName = [2] call BIS_fnc_teamColor;
hint format ["%1 is %2", 2, _teamName];
```
