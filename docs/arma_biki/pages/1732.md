## speedMode

- Source: https://community.bistudio.com/wiki/speedMode
- Revision: 336416
- Updated: 2023-01-02T16:21:28Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Groups

### Description

Returns speed mode of the group, which can be any of the following: 
* **"LIMITED"**
* **"NORMAL"**
* **"FULL"**

### Syntax

```sqf
speedMode groupName
```

### Parameters

- groupName: Object or Group

### Return Value

- String

### Examples

#### Example 1

```sqf
_speed = speedMode group player;
```
