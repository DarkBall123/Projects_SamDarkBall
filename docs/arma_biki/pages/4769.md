## camPreloaded

- Source: https://community.bistudio.com/wiki/camPreloaded
- Revision: 321907
- Updated: 2022-05-22T12:22:10Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Checks whether the camera has finished preloading.

### Syntax

```sqf
camPreloaded camera
```

### Parameters

- camera: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (camPreloaded _camera) exitWith { hint "loaded" };
```
