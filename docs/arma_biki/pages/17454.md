## diag fpsMin

- Source: https://community.bistudio.com/wiki/diag_fpsMin
- Revision: 310884
- Updated: 2022-05-07T20:28:57Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Diagnostic, Performance Profiling

### Description

Returns minimal framerate. Calculated from the longest frame over last 16 frames.

### Syntax

```sqf
diag_fpsMin
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
_minfps = diag_fpsMin;
```
