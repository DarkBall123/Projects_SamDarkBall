## BIS fnc getObjectBBD

- Source: https://community.bistudio.com/wiki/BIS_fnc_getObjectBBD
- Revision: 327920
- Updated: 2022-07-13T12:13:12Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Get object boundingBoxReal max values and store them with setVariable ["BIS_EGSpectator_objectBBD", [maxWidth, maxLength, maxHeight]] for later calls.

### Syntax

```sqf
[object] call BIS_fnc_getObjectBBD
```

### Parameters

- object: Object - object to measure

### Return Value

- Array to format [maxWidth, maxLength, maxHeight]

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_getObjectBBD;
```

#### Example 2

```sqf
[vehicle player] call BIS_fnc_getObjectBBD;
```
