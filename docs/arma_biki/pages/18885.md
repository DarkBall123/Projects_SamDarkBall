## BIS fnc exportVehicle

- Source: https://community.bistudio.com/wiki/BIS_fnc_exportVehicle
- Revision: 363634
- Updated: 2024-04-08T21:57:47Z

- Availability: arma3 1.00
- Groups: Vehicles

### Description

Export vehicle settings

### Syntax

```sqf
[vehicle,vehicleClass] call BIS_fnc_exportVehicle
```

### Parameters

- vehicle: Object
- vehicleClass: String - use "" to skip createVehicle part and set components / textures only

### Return Value

- String - SQF code

### Examples

#### Example 1

```sqf
[BIS_tank,""] call BIS_fnc_exportVehicle;

//Returns 
"[
  _this,
  [""Hex"",1], 
  [""showCamonetHull"",1,""showCamonetTurret"",1]
] call BIS_fnc_initVehicle;"
```

#### Example 2

```sqf
[BIS_tank] call BIS_fnc_exportVehicle;

//Returns 
"_veh = createVehicle [""O_MBT_04_cannon_F"",position player,[],0,""NONE""];
[
  _veh,
  [""Hex"",1], 
  [""showCamonetHull"",1,""showCamonetTurret"",1]
] call BIS_fnc_initVehicle;"
```
