## formationMembers

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50

### Description

Return list of units (drivers) in the formation.

### Syntax

```sqf
formationMembers person
```

### Parameters

- person: Object

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_drivers = formationMembers _person;
```
