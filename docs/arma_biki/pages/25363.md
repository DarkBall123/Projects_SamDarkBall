## BIS fnc stringToMarkerLocal

- Source: https://community.bistudio.com/wiki/BIS_fnc_stringToMarkerLocal
- Revision: 378264
- Updated: 2026-03-26T17:30:17Z

- Availability: arma3 1.92
- Locality: effect local
- Groups: Map and Markers

### Description

Converts serialized data from BIS_fnc_markerToString into a local map marker.

### Syntax

```sqf
data call BIS_fnc_stringToMarkerLocal
```

### Parameters

- data: String - serialized data

### Return Value

- String - created local marker

### Examples

#### Example 1

```sqf
"|marker_0|[3799.0110,2781.9880,0.0000]|mil_pickup|ICON|[1,1]|0|Solid|Default|1|You are here" call BIS_fnc_stringToMarkerLocal;
```
