## BIS fnc sideType

- Source: https://community.bistudio.com/wiki/BIS_fnc_sideType
- Revision: 348592
- Updated: 2023-11-08T13:44:37Z

- Availability: arma3 1.00
- Groups: Sides

### Description

Returns side type based on side ID. See BIS_fnc_sideID for more information.

### Syntax

```sqf
sideID call BIS_fnc_sideType
```

### Parameters

- sideID - Number - Side ID.

### Return Value

- Side - side based on side ID

### Examples

#### Example 1

```sqf
0 call BIS_fnc_sideType; // returns EAST
```
