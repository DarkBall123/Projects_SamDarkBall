## missionDifficulty

- Source: https://community.bistudio.com/wiki/missionDifficulty
- Revision: 337653
- Updated: 2023-02-16T13:02:43Z

- Availability: arma3 1.62
- Groups: Difficulty, Mission Information

### Description

Return difficulty that has been forced for this mission, returns -1 if difficulty is not forced and it is used one from player's options.

### Syntax

```sqf
missionDifficulty
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
private _number = missionDifficulty;
```

#### Example 2

```sqf
private _playedDifficulty = missionDifficulty;
if (_playedDifficulty == -1) then
{
	_playedDifficulty = difficulty;
};
```
