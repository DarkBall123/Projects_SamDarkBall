## getAllUnitTraits

- Source: https://community.bistudio.com/wiki/getAllUnitTraits
- Revision: 377673
- Updated: 2026-01-02T09:02:33Z

- Availability: arma3 2.00
<!--
- Locality: argument local
-->
- Groups: Object Manipulation

### Description

Returns unit traits (native or set by setUnitTrait).

### Syntax

```sqf
getAllUnitTraits unit
```

### Parameters

- unit: Object or 2.18 String - a unit or a class name

### Return Value

- Array of Arrays with [name, value]
* name: String - trait's name
* value String or Boolean - trait's value

### Examples

#### Example 1

```sqf
private _playerTraits = getAllUnitTraits player;
/*
Could return something like this:
[
	["Medic", false],
	["Engineer", false],
	["ExplosiveSpecialist", false],
	["UavHacker", false],
	["CamouflageCoef", 1],
	["AudibleCoef", 1],
	["LoadCoef", 1],
	["test", "custom"]
]
*/
```

#### Example 2

```sqf
private _unitTraits = getAllUnitTraits _unit;
private _indexes = [_unitTraits, "Medic"] call BIS_fnc_findNestedElement;
private _unitCanHeal = _unitTraits select (_indexes select 0) select 1;
```

#### Example 3

Since 2.18:

```sqf
hint str getAllUnitTraits "O_Engineer_F";
/*
[
	["Medic", false],
	["Engineer", true],
	["ExplosiveSpecialist", true],
	["UavHacker", false],
	["CamouflageCoef", 1],
	["AudibleCoef", 1],
	["LoadCoef", 1]
]
*/
```
