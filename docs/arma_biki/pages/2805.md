## configFile

- Source: https://community.bistudio.com/wiki/configFile
- Revision: 369418
- Updated: 2024-09-03T18:48:49Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Config

### Description

Return root of config entries hierarchy.

### Syntax

```sqf
configFile
```


### Return Value

- Config

### Examples

#### Example 1

```sqf
_isMyClassActive = isClass (configFile >> "CfgPatches" >> "MyClass");
```

|text= 1.24 It is recommended to use configClasses instead of BIS_fnc_getCfgSubClasses and BIS_fnc_uniqueClasses on subclasses collection or conditional selection.

```sqf
_faces = "true" configClasses (configFile >> "CfgFaces");
// same as:
_faces = (configfile >> "CfgFaces") call BIS_fnc_getCfgSubClasses;
```

```sqf
//Extract all animals:
animals = "configName _x isKindOf 'animal'" configClasses (configFile >> "CfgVehicles");
// same as:
animals = [];
[
	configFile >> "CfgVehicles",
	{
		if ((configName _this) isKindOf "animal") then {
			animals set [count animals, _this]
		}
	}
] call BIS_fnc_uniqueClasses;
```

Return nested subclasses, currently still BIS_fnc_returnChildren

```sqf
// return all nested config classes
[configFile >> "CfgFaces", 1, true, true] call BIS_fnc_returnChildren;
```
