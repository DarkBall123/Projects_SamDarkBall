## taskState

- Revision: 320998
- Updated: 2022-05-13T10:30:31Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Returns the current state of a task.

### Syntax

```sqf
taskState task
```

### Parameters

- task: Task - the task you want to query

### Return Value

- String - current state of task - can be one of:
* "None"
* "Created"
* "Assigned"
* "Succeeded"
* "Failed"
* "Canceled"

### Examples

#### Example 1

```sqf
tskSomeTask = player createSimpleTask ["NewTask"];
hint format["Taskstate: %1", taskState tskSomeTask];
```
