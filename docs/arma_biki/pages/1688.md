## commandWatch

- Source: https://community.bistudio.com/wiki/commandWatch
- Revision: 378095
- Updated: 2026-02-12T23:52:45Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Control

### Description

Orders the unit(s) to watch the given position or target (via the radio). Use objNull as the target to order a unit to stop watching a position/target.

### Multiplayer

This command is only effective when used on local units.
When used on a remote unit, this command will create radio dialogue on the machine the unit is local to, but the unit will not watch the target object/position.

### Syntax

```sqf
units commandWatch target
```

### Parameters

- units: Object or Array of Objects
- target: Position or Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldierOne commandWatch markerPos "MarkerMoveOne";
```

#### Example 2

```sqf
[s1, s2] commandWatch player;
```
