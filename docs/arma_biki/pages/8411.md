## scriptName

- Source: https://community.bistudio.com/wiki/scriptName
- Revision: 369379
- Updated: 2024-09-03T18:43:13Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Assign a user friendly name to the VM script this command is executed from.
Once a name is assigned, it cannot be changed.

### Syntax

```sqf
scriptName name
```

### Parameters

- name: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
scriptName "leetScript.sqf";
```

#### Example 2

```sqf
scriptName format ["%1ARTY\data\scripts\ARTY_sadarmDeploy.sqf (_this: %1)", _this];
```
