## forgetTarget

- Source: https://community.bistudio.com/wiki/forgetTarget
- Revision: 332529
- Updated: 2022-12-01T12:21:06Z

- Availability: arma3 1.70
- Locality: argument local, effect global
- Groups: Unit Control, Groups

### Description

Resets the info a group has about a target, forcing knowsAbout value to 0.

### Syntax

```sqf
group forgetTarget target
```

### Parameters

- group: Group or Object - group itself or unit in a group
- target: Object - group target

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
soldier1 forgetTarget soldier2;
```

#### Example 2

Give enemyBob some amnesia:

```sqf
onEachFrame { enemyBob forgetTarget player };
```
