## removeMPEventHandler

- Source: https://community.bistudio.com/wiki/removeMPEventHandler
- Revision: 364089
- Updated: 2024-05-03T19:34:19Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Multiplayer, Event Handlers

### Description

Removes MP event handler added by addMPEventHandler.

### Syntax

```sqf
unitName removeMPEventHandler [event, index]
```

### Parameters

- unitName: Object
- event: String
- index: Number - index returned by addMPEventHandler

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeMPEventHandler ["MPKilled", 0];
```

EventHandlers list addMPEventHandler removeAllMPEventHandlers
