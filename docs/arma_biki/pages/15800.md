## BIS fnc GUIbackground

- Source: https://community.bistudio.com/wiki/BIS_fnc_GUIbackground
- Revision: 348790
- Updated: 2023-11-08T14:33:18Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Creates GUI background.

### Syntax

```sqf
[position] call BIS_fnc_GUIbackground
```

### Parameters

- position: Array - in format:

0: - Position in X

1: - Position in Y

2: - Width

3: - Height

### Return Value

- Display

### Examples

#### Example 1

```sqf
[1,1,1,1] call BIS_fnc_GUIbackground;
```
