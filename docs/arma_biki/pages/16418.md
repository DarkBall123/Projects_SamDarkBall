## BIS fnc drawMinefields

- Source: https://community.bistudio.com/wiki/BIS_fnc_drawMinefields
- Revision: 309394
- Updated: 2022-05-05T12:04:35Z

- Availability: arma3 1.00
- Groups: Map and Markers

### Description

Draw minefields on the map. Dynamically calculated from all mines positions. Distinguishes AP and AT minefields.

### Syntax

```sqf
call BIS_fnc_drawMinefields
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_drawMinefields;
```
