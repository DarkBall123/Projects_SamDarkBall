## distance2D

- Source: https://community.bistudio.com/wiki/distance2D
- Revision: 363614
- Updated: 2024-04-08T11:45:05Z

- Availability: arma3 1.50
- Locality: argument global
- Groups: Math - Geometry

### Description

Returns a 2D distance (distance projected to X,Y plane) in meters between Objects and/or Positions.
250px|right

### Syntax

```sqf
from distance2D to
```

### Parameters

- from: Object, Position2D or Position3D
- to: Object, Position2D or Position3D

### Return Value

- Number - distance in meters or 1e10 if distance cannot be calculated

### Examples

#### Example 1

```sqf
_meters = player distance2D heli;
```
