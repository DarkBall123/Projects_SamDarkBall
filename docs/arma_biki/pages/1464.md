## a greater= b

- Groups: Math, Variables

### Description

Returns if *a* is greater than or equal to *b*.

### Syntax

```sqf
a >= b
```

### Parameters

- a: Number
- b: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (fuel truck1 >= 0.5) then { hint "Truck1 has at least half a tank of fuel left." };
```
