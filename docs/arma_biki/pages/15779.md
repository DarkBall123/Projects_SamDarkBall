## BIS fnc dbClassReturn

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbClassReturn
- Revision: 327488
- Updated: 2022-07-12T22:21:03Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Returns content of given class.

### Syntax

```sqf
[database, path] call BIS_fnc_dbClassReturn
```

### Parameters

- database - Array: database array
- path - Array: path to the class which content should be returned

### Return Value

- Array - class content

### Examples

#### Example 1

```sqf
[["#MILLER", ["&KILLS", 1000], "#TERRA", ["&WEAPON", "MX 6.5mm"]], ["miller"]] call BIS_fnc_dbClassReturn; // ["&KILLS", 1000]
```
