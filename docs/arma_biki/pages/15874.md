## BIS fnc ambientAnimGetParams

- Source: https://community.bistudio.com/wiki/BIS_fnc_ambientAnimGetParams
- Revision: 348306
- Updated: 2023-11-08T12:59:37Z

- Availability: arma3 1.00
- Groups: Ambient

### Description

Feeds params of given animset to BIS_fnc_ambientAnim.

### Syntax

```sqf
animType call BIS_fnc_ambientAnimGetParams
```
