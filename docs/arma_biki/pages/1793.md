## setFuel

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Sets fuel level.

### Syntax

```sqf
vehicle setFuel amount
```

### Parameters

- vehicle: Object
- amount: Number in range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_jeepOne setFuel 0.5;
```
