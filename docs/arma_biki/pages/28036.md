## setEngineRpmRTD

- Source: https://community.bistudio.com/wiki/setEngineRpmRTD
- Revision: 349351
- Updated: 2023-11-08T15:35:07Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Sets the RPM of given engines. {{Feature|afm}}

### Syntax

```sqf
helicopter setEngineRpmRTD [rpm, engineIndex]
```

### Parameters

- helicopter: Object
- rpm: Number - wanted RPM
- engineIndex: Number - index of the engine
* engine index 0: engine #1
* engine index 1: engine #2
* engine index 2: engine #3
* engine index -1: all engines

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myHelicopter setEngineRpmRTD [1337, -1];
```
