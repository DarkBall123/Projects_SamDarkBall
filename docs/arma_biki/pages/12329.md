## ctrlIDD

- Source: https://community.bistudio.com/wiki/ctrlIDD
- Revision: 376847
- Updated: 2025-12-05T16:57:27Z

- Availability: arma3 0.50
- Groups: GUI Control

### Description

Returns display IDD.

### Syntax

```sqf
ctrlIDD  display
```

### Parameters

- display: Display

### Return Value

- Number

### Examples

#### Example 1

```sqf
_display = findDisplay 46;
ctrlIDD _display; // 46
```
