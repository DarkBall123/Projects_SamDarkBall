## BIS fnc colorConfigToRGBA

- Source: https://community.bistudio.com/wiki/BIS_fnc_colorConfigToRGBA
- Revision: 327483
- Updated: 2022-07-12T22:17:18Z

- Availability: arma3 1.00
- Groups: Arrays

### Description

Converts config color format to RGBA array of numbers.

### Syntax

```sqf
configColor call BIS_fnc_colorConfigToRGBA
```

### Parameters

- configColor: Array - config color

### Return Value

- Array format Color (RGBA)

### Examples

#### Example 1

```sqf
["0.5 + 0.25",0,0,1] call BIS_fnc_colorConfigToRGBA; // returns [0.75,0,0,1]
```
