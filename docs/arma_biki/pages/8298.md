### Description

Returns true if the mission editor is operating in real time mode. 
Some Old Editor Command

### Syntax

```sqf
isRealTime map
```

### Parameters

- map: Control

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isRealTime = isRealTime _map;
```
