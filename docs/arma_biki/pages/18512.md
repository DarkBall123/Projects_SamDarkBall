## lnbSortByValue

- Source: https://community.bistudio.com/wiki/lnbSortByValue
- Revision: 330120
- Updated: 2022-08-21T19:54:07Z

- Availability: arma3 1.08
- Groups: GUI Control - ListNBox

### Description

Sorts given multicolumn listbox by lnbValue in given column in ascending or descending order.

### Syntax

```sqf
lnbSortByValue [idc, column, reversed]
```

```sqf
control lnbSortByValue [column, reversed]
```

### Parameters

- idc: Number
- column: Number
- reversed: Boolean - (Optional, default false) false: descending / true: ascending
- control: Control
- column: Number
- reversed: Boolean - (Optional, default false) false: descending / true: ascending

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lnbSortByValue [1800, 1, false];
```

#### Example 2

```sqf
_ctl lnbSortByValue [1, true];
```
