## simulationEnabled

- Source: https://community.bistudio.com/wiki/simulationEnabled
- Revision: 310189
- Updated: 2022-05-05T13:10:32Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Check if the entity has enabled simulation. 

{{Feature | important | The entity could be local or remote but the result returned by this command will be for the entity simulation set up locally on the client that executed the command.
See enableSimulation for more info.}}

### Syntax

```sqf
simulationEnabled entity
```

### Parameters

- entity: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
simulationEnabled player;
```
