## config greater greater name

- Source: https://community.bistudio.com/wiki/config_greater_greater_name
- Revision: 363978
- Updated: 2024-04-29T22:51:43Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Config

### Description

Returns config entry with given name (alias of a / b, slightly faster but with lower precedence)

### Syntax

```sqf
config >> name
```

### Parameters

- config: Config
- name: String

### Return Value

- Config - config entry

### Examples

#### Example 1

```sqf
configFile >> "CfgVehicles";
```
