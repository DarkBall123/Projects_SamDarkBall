## BIS fnc moduleSaveGame

- Source: https://community.bistudio.com/wiki/BIS_fnc_moduleSaveGame
- Revision: 348905
- Updated: 2023-11-08T14:40:00Z

- Availability: arma3 1.00
- Groups: Modules

### Description

Saves the game. Saving has to be enabled.

### Syntax

```sqf
[nil,nil,activated] call BIS_fnc_moduleSaveGame
```

### Parameters

- nil: Nothing - not used
- nil: Nothing - not used
- activated: Boolean - (Optional, default true) when true game will be saved

### Return Value

- Boolean - always true

### Examples

#### Example 1

```sqf
call BIS_fnc_moduleSaveGame;
```
