## BIS fnc liveFeedSetSource

- Source: https://community.bistudio.com/wiki/BIS_fnc_liveFeedSetSource
- Revision: 328602
- Updated: 2022-07-13T17:02:31Z

- Availability: arma3 1.00
- Groups: Live Feed

### Description

Set the source of the current live feed.

### Syntax

```sqf
source call BIS_fnc_liveFeedSetSource
```

### Parameters

- source:
* Object
* Position
* Array: in the format [object, [x, y, z]]

### Return Value

- Boolean - true if successful, false if not

### Examples

#### Example 1

```sqf
[player, [0, 0.25, 1.6]] call BIS_fnc_liveFeedSetSource;
```
