## ctrlSetPositionW

- Source: https://community.bistudio.com/wiki/ctrlSetPositionW
- Revision: 309180
- Updated: 2022-05-03T18:04:27Z

- Availability: arma3 1.92
- Groups: GUI Control - Positioning

### Description

Sets the width of a 2D control. ctrlCommit is required to complete the operation.

### Syntax

```sqf
control ctrlSetPositionW w
```

### Parameters

- control: Control - 2D control
- w: Number - width of the control

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl ctrlSetPositionW 0.5;
_ctrl ctrlCommit 1;
```
