## enableCopilot

- Source: https://community.bistudio.com/wiki/enableCopilot
- Revision: 369225
- Updated: 2024-09-03T10:34:55Z

{{RV|type=command

|game1= tkoh
|version1= 1.01

|game2= arma3
|version2= 0.50

|arg= global

|eff= local

|gr1= Object Manipulation

|descr= Enables copilot actions, toggles availability of the actions related to copilots, such as taking over controls, suspending controls, etc. This command triggers the `"ControlsShifted"` event handler.

|mp= Execute this command globally (e.g with remoteExec) to have it synced on all clients.

|s1= vehicle enableCopilot enable

|p1= vehicle: Object - vehicle on which to toggle copilot actions

|p2= enable: Boolean - enable or disable

|r1= Nothing

|x1=

```sqf
if (!isCopilotEnabled myHeli) then
{
	myHeli enableCopilot true;
};
```

|seealso= isCopilotEnabled currentPilot
}}

Posted on 2014-02-17
Strangepete
Only enables the user actions, not who is in control - pilot can lock or unlock co-pilot controls in multiplayer while still true.
- Actions: LockVehicleControl, UnlockVehicleControl, SuspendVehicleControl and TakeVehicleControl
- You can use the Arma 3 Event Handler - ControlsShifted to detect Take and Release actions.
