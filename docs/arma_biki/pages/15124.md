## getDLCs

- Source: https://community.bistudio.com/wiki/getDLCs
- Revision: 377087
- Updated: 2026-01-01T09:46:01Z

- Availability: arma3 1.16
- Groups: DLC

### Description

Returns array of app IDs of DLCs.

### Syntax

```sqf
getDLCs filter
```

### Parameters

- filter: Number one of:
* 0 - all
* 1 - owned
* 2 - not owned

### Return Value

- Array of Numbers - App IDs

### Examples

#### Example 1

```sqf
_ownedDLCs = getDLCs 1;
```

#### Example 2

```sqf
_hasKarts = (288520 in (getDLCs 1));
```

|text= App ID can be found in CfgMods. Here is an example path from zeus using the Splendid Config Viewer:

```sqf
configFile >> "CfgMods" >> "Curator" >> "appId"
```

This method can be used to find app IDs without having to find a list like the one above.

I am also pretty sure you are able to define your own app ID for your own mods using this method.
