## ppEffectCommitted

- Source: https://community.bistudio.com/wiki/ppEffectCommitted
- Revision: 348518
- Updated: 2023-11-08T13:06:00Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Check whether given post process effect is committed.

### Syntax

```sqf
ppEffectCommitted effect
```

```sqf
ppEffectCommitted handle
```

### Parameters

- effect: String - effect name
- handle: Number - effect handle

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
ppEffectCommitted "colorCorrection";
```

#### Example 2

```sqf
ppEffectCommitted _hndl;
```

#### Example 3

```sqf
if (ppEffectCommitted "colorCorrection") then { hint "alteration done !" };
```
