## batteryChargeRTD

- Source: https://community.bistudio.com/wiki/batteryChargeRTD
- Revision: 377774
- Updated: 2026-01-03T01:32:26Z

- Availability: tkoh 1.00
- Groups: RTD

### Description

Returns the current charge of a helicopter's batteries.
* 0: empty
* 1: fully charged

### Syntax

```sqf
batteryChargeRTD helicopterRTD
```

### Parameters

- helicopterRTD: ObjectRTD - helicopter

### Return Value

- Number

### Examples

#### Example 1

```sqf
_charge = batteryChargeRTD vehicle player;
```
