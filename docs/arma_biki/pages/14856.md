## setCuratorCoef

- Source: https://community.bistudio.com/wiki/setCuratorCoef
- Revision: 348442
- Updated: 2023-11-08T13:00:15Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Sets coef for some action (coef have to be bigger than -1 000 000, anything lower is considered as disabled action).

### Syntax

```sqf
curatorObj setCuratorCoef [action, coef]
```

### Parameters

- curatorObj: Object - curator module
- action: String - can be one of:
* "Place"
* "Edit"
* "Delete"
* "Destroy"
* "Group"
* "Synchronize"
- coef: Number or Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
curatorModule setCuratorCoef ["Place", 1];
```

#### Example 2

```sqf
curatorModule setCuratorCoef ["Delete", -1e10];
```
