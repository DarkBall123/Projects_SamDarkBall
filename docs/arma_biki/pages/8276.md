## groupSelectedUnits

- Source: https://community.bistudio.com/wiki/groupSelectedUnits
- Revision: 377896
- Updated: 2026-01-05T17:44:14Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Interaction

### Description

Returns selected units in source group for normal commanding mode (individual units). For the High Command equivalent, see hcSelected.

### Syntax

```sqf
groupSelectedUnits unit
```

### Parameters

- unit: Object

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_selectedUnits = groupSelectedUnits player;
```
