## setTriggerActivation

- Source: https://community.bistudio.com/wiki/setTriggerActivation
- Revision: 378817
- Updated: 2026-07-01T00:11:02Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Triggers

### Description

Defines the trigger activation type.

See ArmA:Mission Editor - Triggers for a thorough overview of triggers and its fields for activation, effects, etc.

### Multiplayer

Activation changes are local.

### Syntax

```sqf
trigger setTriggerActivation [by, type, repeating, persistent]
```

- persistent (Optional): Boolean - when false stops persistent condition execution and vehicle list building on non-repeating trigger; is ignored in radio and repeating triggers. Default: true

### Return Value

- Nothing
