## setFlagTexture

- Source: https://community.bistudio.com/wiki/setFlagTexture
- Revision: 378480
- Updated: 2026-04-24T11:57:06Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Flags

### Description

Sets flag texture.

### Syntax

```sqf
flag setFlagTexture texture
```

### Parameters

- flag: Object - a flag pole
- texture: String - flag texture. If texture is `""`, flag is not drawn. Custom texture can be used:
* Prior Arma 3: Dimension 200×200, file extension .jpg
* Since Arma 3: Dimension 512×256, file extension .paa

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_flagE setFlagTexture "\ca\misc\data\sever_vlajka.paa";
```

#### Example 2

```sqf
_flagW setFlagTexture "\ca\misc\data\usa_vlajka.paa";
```

#### Example 3

```sqf
flag1 setFlagTexture "\A3\Data_F\Flags\Flag_red_CO.paa";
```

#### Example 4

```sqf
_customFlag setFlagTexture "myMissionFlag.paa";
```

#### Example 5

```sqf
_flag_Arma_3 setFlagTexture "\a3\ui_f\data\Logos\arma3_expansion_ca.paa";
```

#### Example 6

Capturable OPFOR flag:

```sqf
private _flag = "FlagPole_F" createVehicle position player;
_flag setFlagTexture "\A3\Data_F\Flags\Flag_CSAT_CO.paa";
_flag setFlagSide east;
```
