## removePrimaryWeaponItem

- Source: https://community.bistudio.com/wiki/removePrimaryWeaponItem
- Revision: 347501
- Updated: 2023-09-24T01:03:45Z

- Availability: arma3 0.70
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes given weapon item, including magazine, from the primaryWeapon.

### Syntax

```sqf
unit removePrimaryWeaponItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removePrimaryWeaponItem "acc_flashlight";
```
