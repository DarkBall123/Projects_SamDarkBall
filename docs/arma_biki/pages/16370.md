## BIS fnc isCurator

- Source: https://community.bistudio.com/wiki/BIS_fnc_isCurator
- Revision: 348562
- Updated: 2023-11-08T13:42:06Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns if given object is curator logic. Despite the misleading name this does not check if a player has access to Zeus. It just check if the given object's simulation is of type "curator".

### Syntax

```sqf
object call BIS_fnc_isCurator
```

### Parameters

- object: Object - object which should be checked

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
player call BIS_fnc_isCurator;
```
