## BIS fnc hideMarkerArray

- Source: https://community.bistudio.com/wiki/BIS_fnc_hideMarkerArray
- Revision: 348051
- Updated: 2023-11-08T11:28:50Z

- Availability: arma3 1.78
- Locality: argument global, effect global
- Groups: Map and Markers

### Description

Hides a list of markers one by one.

### Syntax

```sqf
[markerArray, duration] spawn BIS_fnc_hideMarkerArray
```

### Parameters

- markerArray: Array of Strings - array of marker names
- duration: Number - (Optional, default 1) duration in seconds until all markers are hidden. If duration is 0 markers are hidden as fast as possible

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[["BIS_marker_1", "BIS_marker_2", "BIS_marker_3"], 5] spawn BIS_fnc_hideMarkerArray;
```
