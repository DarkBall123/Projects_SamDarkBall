## getSpeed

- Source: https://community.bistudio.com/wiki/getSpeed
- Revision: 347558
- Updated: 2023-09-28T09:45:46Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Get the speed for the given speed mode.

SpeedMode can be:
*"AUTO"
*"SLOW"
*"NORMAL"
*"FAST"

### Syntax

```sqf
object getSpeed speedMode
```

### Parameters

- object: Object
- speedMode: String

### Return Value

- Number - m/s

### Examples

#### Example 1

```sqf
_spd = player getSpeed "FAST";
```
