## setSimpleTaskDestination

- Source: https://community.bistudio.com/wiki/setSimpleTaskDestination

- Updated: 2026-01-02T06:50:22Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Attach a destination to the simple task.
Overrides setSimpleTaskTarget

### Syntax

```sqf
task setSimpleTaskDestination pos
```

### Parameters

- task: Task
- pos: Position

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_tskGoHere setSimpleTaskDestination (getMarkerPos "obj1");
```
