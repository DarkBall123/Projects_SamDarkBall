## BIS fnc invSlotType

- Source: https://community.bistudio.com/wiki/BIS_fnc_invSlotType
- Revision: 349431
- Updated: 2023-11-08T16:27:36Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Inventory

### Description

Returns empty inventory slots of given unit.

### Syntax

```sqf
[class] call BIS_fnc_invSlotType
```

### Parameters

- class: String - inventory item

### Return Value

- Array of Numbers - numbers representing slots taken by given item (one item can take more slots of same or different type), empty if type 0 or not found

### Examples

#### Example 1

```sqf
[currentWeapon player] call BIS_fnc_invSlotType;//Can return [1,0,0,0,0,0,0,0]
```
