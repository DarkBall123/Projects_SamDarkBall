## BIS fnc reviveSecureUnit

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveSecureUnit
- Revision: 349321
- Updated: 2023-11-08T14:52:29Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Make player secured (killed without execution penalties) by _source unit.

### Syntax

```sqf
[unit, source] call BIS_fnc_reviveSecureUnit
```

### Parameters

- unit: Object - unit to be checked
- source: Object - reviving unit

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player_1,player2] call BIS_fnc_reviveSecureUnit;
```
