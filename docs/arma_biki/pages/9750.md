## waypointVisible

- Source: https://community.bistudio.com/wiki/waypointVisible
- Revision: 377744
- Updated: 2026-01-03T00:57:55Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

A getter for setWaypointVisible command.

Returns **0** (Number) instead of Booleanfor an invalid waypoint.

### Syntax

```sqf
waypointVisible waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_visible = waypointVisible [groupOne, 1];
```

#### Example 2

```sqf
_visible = waypointVisible [group player, currentWaypoint group player];
```
