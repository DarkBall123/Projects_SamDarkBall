## curatorEditingAreaType

- Source: https://community.bistudio.com/wiki/curatorEditingAreaType
- Revision: 310854
- Updated: 2022-05-07T20:24:08Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns type of edit areas assigned to curator (blacklist/whitelist).

### Syntax

```sqf
curatorEditingAreaType curator
```

### Parameters

- curator: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isBlacklist = curatorEditingAreaType _curator;
```
