## createGearDialog

- Source: https://community.bistudio.com/wiki/createGearDialog
- Revision: 321391
- Updated: 2022-05-14T11:20:25Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Opens gear dialog for given unit.
action command can also be used:

```sqf
player action ["Gear", player];
```

### Syntax

```sqf
createGearDialog [unit, resource]
```

### Parameters

- unit: Object
- resource: String - (Optional)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
createGearDialog [player];
```
