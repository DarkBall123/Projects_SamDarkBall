## vectorMagnitude

- Source: https://community.bistudio.com/wiki/vectorMagnitude
- Revision: 373022
- Updated: 2025-03-18T15:33:55Z

{{RV|type=command

|game1= arma3
|version1= 1.22

|gr2= Math - Vectors

|descr=Magnitude of a 3D vector.

arma3|2.14|Since 2.14 any count of numbers is valid.

Before 2.14, the argument had to be vector 3D, or 2.00 2D (With z coordinate defaulted to 0)

|s1= vectorMagnitude vector

|p1= vector: Array of Numbers

|r1= Number

|x1=

```sqf
_size = vectorMagnitude [0,3,4]; // returns 5
```

|x2=

```sqf
_speed = vectorMagnitude velocity player;				// return velocity of player in m/s
_speed = (vectorMagnitude velocity player) * 3.6;		// return velocity of player in km/h
_speed = (vectorMagnitude velocity player) * 2.23694;	// return velocity of player in mph
```

1.22 Algorithm:

```sqf
Vector = [x,y,z];
Result = sqrt ((x ^ 2) + (y ^ 2) + (z ^ 2));
```

It is recommended to use vectorMagnitude instead of BIS_fnc_magnitude.
