## addItemCargoGlobal

- Source: https://community.bistudio.com/wiki/addItemCargoGlobal
- Revision: 376380
- Updated: 2025-10-09T02:13:10Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Vehicle Inventory

### Description

Global variant of addItemCargo.

### Syntax

```sqf
box addItemCargoGlobal [item, count]
```

### Parameters

- box: Object
- item: String
- count: Number - number of items to add. 2.14 negative count will remove items.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
supplyBox addItemCargoGlobal ["optic_Arco", 10];
```
