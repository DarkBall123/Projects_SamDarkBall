## clearMagazineCargoGlobal

- Source: https://community.bistudio.com/wiki/clearMagazineCargoGlobal
- Revision: 309919
- Updated: 2022-05-05T12:16:57Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Containers

### Description

Removes all magazines from the vehicle cargo space. MP synchronized.

### Syntax

```sqf
clearMagazineCargoGlobal  object
```

### Parameters

- object: Object - vehicle or ammo box

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
clearMagazineCargoGlobal jeepOne;
```
