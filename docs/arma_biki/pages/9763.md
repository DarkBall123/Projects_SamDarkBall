## clearWeaponCargoGlobal

- Source: https://community.bistudio.com/wiki/clearWeaponCargoGlobal
- Revision: 309985
- Updated: 2022-05-05T12:17:03Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Containers

### Description

Removes all weapons from the vehicle cargo space. MP synchronized.

### Syntax

```sqf
clearWeaponCargoGlobal unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
clearWeaponCargoGlobal jeepOne;
```
