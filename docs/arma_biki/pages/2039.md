## setAttributes

- Source: https://community.bistudio.com/wiki/setAttributes
- Revision: 351277
- Updated: 2023-11-27T02:34:49Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Strings, Structured Text

### Description

Returns a Structured Text created from the given structured text and sets attributes to the given values.
Even though command accepts plain String too, the argument should be Structured Text in order for the set attributes to have an effect.
Additionally the result of the command should be fed to composeText (See #Example 1) or formatText.

### Syntax

```sqf
text setAttributes [name1, value1, name2, value2, ...]
```

### Parameters

- text: String or Structured Text - only passing Structured Text has any effect
- nameN: String - name of the attribute
- valueN: String - value of the attribute

### Return Value

- Structured Text

### Examples

#### Example 1

```sqf
_txt = text "Red text, right align";
_txt setAttributes ["color", "#FF0000", "align", "right"];
hint composeText [_txt];
```
