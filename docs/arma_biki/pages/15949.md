## BIS fnc effectFiredRifle

- Source: https://community.bistudio.com/wiki/BIS_fnc_effectFiredRifle
- Revision: 349187
- Updated: 2023-11-08T14:50:39Z

- Availability: arma3 1.00
- Locality: effect local
- Groups: Effects

### Description

Used to add an effect to fired bullets. Should be executed from Fired Event Handler.

### Syntax

```sqf
[unit, nil, nil, nil, ammoType] call BIS_fnc_effectFiredRifle
```

### Parameters

- unit: Object - the unit, the effect should be added to
- nil: Nothing
- nil: Nothing
- nil: Nothing
- ammoType: String - the type of ammo the effect should be triggered for

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
unit addEventHandler ["Fired", 
{
   _this call BIS_fnc_effectFiredRifle;
}];
```
