## addMagazineCargoGlobal

- Source: https://community.bistudio.com/wiki/addMagazineCargoGlobal
- Revision: 376382
- Updated: 2025-10-09T02:13:45Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Containers

### Description

Add magazines to the cargo space of vehicles, which can be taken out by infantry units.

MP Synchronized

### Syntax

```sqf
vehicleName addMagazineCargoGlobal [magazineName, count]
```

### Parameters

- vehicleName: Object - vehicle to add the magazines to
- magazineName: String - magazine name. See :Category:Weapons for reference about possible values.
- count: Number - number of magazines to add. 2.14 negative count will remove magazines.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_truck addMagazineCargoGlobal ["M16", 5];
```
