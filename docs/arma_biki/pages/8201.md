## createDiaryRecord

- Source: https://community.bistudio.com/wiki/createDiaryRecord
- Revision: 370359
- Updated: 2024-12-02T16:08:54Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Briefing

### Description

Creates a Diary entry. Supported tags and their parameters: 
{

### Syntax

```sqf
player createDiaryRecord [subject, textInfo, task, taskState, showTitle]
```

### Parameters

- player: Object
- subject: String
- textInfo: String or Array of Strings - can be:
* String - the record's content - its title will be empty
* Array of Strings - format [title, text, icon]:
** title: String
** text: String
** 2.10 icon: String - (Optional) icon to show next to the title
- task: Task - (Optional, default taskNull)
- taskState: String - (Optional, default `"NONE"`) changes the state of the given task. Can be one of:
{{Columns|3|
* `"NONE"`
* `"CREATED"`
* `"ASSIGNED"`
* `"SUCCEEDED"`
* `"FAILED"`
* `"CANCELED"`
}}
- showTitle: Boolean - (Optional, default true) whether or not to show title in the description section as well

### Return Value

- Diary Record

### Examples

#### Example 1

```sqf
player createDiaryRecord ["Diary", ["Intel", "Enemy base is on grid <marker name='enemyBase'>161170</marker>"]];
```

#### Example 2

```sqf
player createDiaryRecord ["Diary", "Information gathered.
<img image='wellDone_ca.paa' />"];
```

#### Example 3

```sqf
player createDiaryRecord ["Diary", ["Title", "Description"], taskNull, "", false];
```

#### Example 4

```sqf
player createDiaryRecord [
	"Diary",
	["Font tag", "This will changed text size, colour and font"],
	taskNull,
	"",
	false
];
```

#### Example 5

```sqf
player createDiaryRecord [
	"Diary",
	["Image", "<img image='\A3\Ui_F_Curator\Data\Logos\arma3_curator_artwork.jpg' width='500' height='800' />"],
	taskNull,
	"",
	false
];
```

#### Example 6

```sqf
player createDiaryRecord ["Diary", ["Linebreak", "Line1
Line2

Line4"], taskNull, "", false];
```

#### Example 7

```sqf
player createDiaryRecord ["Diary", ["Execute","<execute expression='hint ""Some code"";'>Some text</execute>"], taskNull, "", false];
```

#### Example 8

