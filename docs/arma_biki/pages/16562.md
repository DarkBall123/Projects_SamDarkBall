## getPosWorld

- Source: https://community.bistudio.com/wiki/getPosWorld
- Revision: 377455
- Updated: 2026-01-02T06:47:19Z

- Availability: arma3 1.32
- Locality: argument global
- Groups: Positions

### Description

Returns the provided object's model centre position ([0,0,0]) in PositionASL, rather than the transformed boundingCenter or LandContact vertices.

### Syntax

```sqf
getPosWorld object
```

### Parameters

- object: Object

### Return Value

- PositionASL - **the model's centre**

### Examples

#### Example 1

```sqf
_obj setPosWorld getPosWorld _obj;
```

#### Example 2

```sqf
ATLToASL (_groundObj modelToWorld [0,0,0]) isEqualTo getPosWorld _groundObj; // true
```

#### Example 3

Wave height under a boat:

```sqf
private _h = ((boat modelToWorld [0,0,0]) vectorDiff getPosWorld boat) select 2;
```
