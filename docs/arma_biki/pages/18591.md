## setFeatureType

- Source: https://community.bistudio.com/wiki/setFeatureType
- Revision: 378060
- Updated: 2026-02-04T23:41:20Z

- Availability: arma3 1.68
- Locality: argument global, effect local
- Groups: Object Manipulation

### Description

Enable/disable object as a feature/landmark. Possible feature types:
* 0 - Feature disabled
* 1 - Object is always visible within object view distance
* 2 - Object is always visible within terrain view distance

The limit is **500** map/static objects and **200** dynamic objects including config features and auto features (flying helicopters, airplanes).

The command returns false if the related limit is reached.

### Syntax

```sqf
object setFeatureType type
```

### Parameters

- object: Object
- type: Number - the desired feature type

### Return Value

- Boolean - true if the feature is set, false otherwise (limit reached)

### Examples

#### Example 1

Set a building to be always rendered:

```sqf
building setFeatureType 2;
```
