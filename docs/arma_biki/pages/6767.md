## setName

- Source: https://community.bistudio.com/wiki/setName
- Revision: 370891
- Updated: 2025-02-21T10:44:05Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Unit Identity, Locations

### Description

Sets the name of a location or a person (person only in single player).

### Syntax

```sqf
thing setName name
```

```sqf
unit setName [name, firstName, lastName]
```

### Parameters

- thing: Location or 1.02 Object
- name: String
- unit: Object
- name: String
- firstName: String
- lastName: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
myLocation setName "My Location Name";
```

#### Example 2

```sqf
player setName "New Name";
```

#### Example 3

```sqf
player setName ["Ben Kerry","Ben","Kerry"];
```
