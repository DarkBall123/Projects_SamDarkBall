## airDensityRTD

- Source: https://community.bistudio.com/wiki/airDensityRTD
- Revision: 318555
- Updated: 2022-05-13T09:21:05Z

- Availability: arma3 1.34
- Groups: RTD

### Description

Returns air density in given altitude. {{Feature|afm}}

### Syntax

```sqf
airDensityRTD altitude
```

### Parameters

- altitude: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
_density = airDensityRTD 0; // returns 1.22406
```

#### Example 2

```sqf
_density = airDensityRTD 1000; // Returns 1.11096
```
