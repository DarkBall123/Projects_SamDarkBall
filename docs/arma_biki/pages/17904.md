## tvSetText

- Source: https://community.bistudio.com/wiki/tvSetText
- Revision: 321506
- Updated: 2022-05-17T11:22:38Z

- Availability: arma3 1.56
- Groups: GUI Control - Tree View

### Description

Sets string text to item on given path. IDC means id of parent Tree View.

### Syntax

```sqf
tvSetText [idc, path, text]
```

```sqf
control tvSetText [path, text]
```

### Parameters

- idc: Number
- path: Array of Numbers
- text: String
- control: Control
- path: Array of Numbers
- text: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvSetText [101, [0], "Test data"];
```

#### Example 2

```sqf
_ctrl tvSetText [[0,0,0], "Test data"];
```
