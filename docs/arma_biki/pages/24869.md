## BIS fnc camera tick

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_tick
- Revision: 349290
- Updated: 2023-11-08T14:51:16Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Ticks a camera. Updates position and view mode.

### Syntax

```sqf
[camera] call BIS_fnc_camera_tick
```

### Parameters

- camera: Object - the camera

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera] call BIS_fnc_camera_tick;
```
