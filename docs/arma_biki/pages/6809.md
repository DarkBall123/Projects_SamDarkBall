## toString

- Source: https://community.bistudio.com/wiki/toString
- Revision: 351525
- Updated: 2023-12-06T11:24:40Z

- Availability: arma1 1.09, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Strings, Arrays

### Description

Converts the supplied Array of Numbers into a String through https://en.wikipedia.org/wiki/Unicode characters representation conversion, or provided Code to compilable String.

### Syntax

```sqf
toString array
```

```sqf
toString code
```

### Parameters

- array: Array of Numbers
If *array* contains non-number values, the following error might appear in .rpt file: `Bad conversion: scalar`. See parseSimpleArray for multi-type array.
- code: Code

### Return Value

- String - https://en.wikipedia.org/wiki/Unicode numbers converted to String of characters
- String - compilable String from provided code

### Examples

#### Example 1

```sqf
hint toString [65,97,338]; // returns "AaŒ"
```

#### Example 2

```sqf
["test", "test"] joinString toString [12345] splitString toString [12345]; // ["test", "test"]
```

#### Example 3

```sqf
private _compilableString = toString { hint "it works!" };
hint _compilableString; // hints ' hint "it works!" '
sleep 2;
call compile _compilableString; // hints ' it works! '
```

_tab = toString [9];
