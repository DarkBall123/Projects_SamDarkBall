## setMarkerColorLocal

- Source: https://community.bistudio.com/wiki/setMarkerColorLocal
- Revision: 370056
- Updated: 2024-10-29T12:43:04Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Markers

### Description

Set marker's colour. Arma 3's marker colour names and their corresponding RGBA values can be found here: Arma 3: CfgMarkerColors.

### Syntax

```sqf
markerName setMarkerColorLocal colour
```

### Parameters

- markerName: String
- colour: String
* `[CfgMarkerColors](Arma 3: CfgMarkerColors)`'s class name
* 2.20 direct colour definition in one of the following formats (values in range 0..1):
** "#(r,g,b)" (e.g `"#(1,0,1)"`, `#FF00FF` equivalent)
** "#(r,g,b,a)" (e.g `"#(0.678,0.749,0.514,0.5)"`, `#ADBF8380` equivalent). Alpha 'a' in this format is independent of markerAlpha

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"MarkerOne" setMarkerColorLocal "ColorBlack";
```

#### Example 2

```sqf
"MarkerOne" setMarkerColorLocal "#(1,0,0,1)"; // red color (since Arma 3 v2.20)
```
