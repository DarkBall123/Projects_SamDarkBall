## ppEffectEnabled

- Source: https://community.bistudio.com/wiki/ppEffectEnabled
- Revision: 327511
- Updated: 2022-07-12T22:24:54Z

- Availability: arma3 1.56
- Groups: Camera Control

### Description

Checks whether given post process effect is enabled

### Syntax

```sqf
ppEffectEnabled effect
```

```sqf
ppEffectEnabled effect
```

### Parameters

- effect: Number - effect handle
- effect: String - effect name

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
_enabled = ppEffectEnabled _hndl;
```

#### Example 2

```sqf
_enabled = ppEffectEnabled "DynamicBlur";
```
