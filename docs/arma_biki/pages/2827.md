## ctrlSetFontH5

- Source: https://community.bistudio.com/wiki/ctrlSetFontH5
- Revision: 322973
- Updated: 2022-06-28T21:42:53Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H5 font of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontH5 fontName
```

### Parameters

- controlName: Control
- fontName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontH5 "TahomaB";
```
