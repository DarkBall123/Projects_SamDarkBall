### Description

Remove value from Scripted Database.

### Syntax

```sqf
[database, path] call BIS_fnc_dbValueRemove
```

### Parameters

- database - Array: Databse array
- path - Array: Path to the value to remove

### Return Value

- Boolean: True if the value was removed
