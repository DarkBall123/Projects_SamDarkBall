## isSwitchingWeapon

- Source: https://community.bistudio.com/wiki/isSwitchingWeapon
- Revision: 376101
- Updated: 2025-08-20T14:10:18Z

- Availability: arma3 2.20
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns wether or not the unit is in the process of switching weapon.

### Syntax

```sqf
isSwitchingWeapon unit
```

### Parameters

- unit: Object

### Return Value

- Boolean - true if the unit is switching weapon.

### Examples

#### Example 1

```sqf
isSwitchingWeapon player;
```
