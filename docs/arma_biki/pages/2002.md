### Description

Checks whether the object is marked for weapons collection.

### Syntax

```sqf
isMarkedForCollection  object
```

### Parameters

- object: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_marked = isMarkedForCollection _truck;
```
