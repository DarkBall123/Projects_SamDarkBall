## rain

- Source: https://community.bistudio.com/wiki/rain
- Revision: 348549
- Updated: 2023-11-08T13:10:02Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Environment

### Description

Returns the current value of rain density.

### Multiplayer

Pre-Arma 3, each client and the server could have different rain values. Since Arma 3 the value is synced over network.

### Syntax

```sqf
rain
```


### Return Value

- Number in range 0..1

### Examples

#### Example 1

```sqf
_rainLevel = rain;
```
