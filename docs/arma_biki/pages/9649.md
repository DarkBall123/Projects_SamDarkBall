## setCamUseTI

- Source: https://community.bistudio.com/wiki/setCamUseTI
- Revision: 369156
- Updated: 2024-09-03T10:34:40Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Sets thermal vision mode for currently used camera. This command only works with camCreate created camera that is currently the main camera for the player (see Example 2).

### Syntax

```sqf
state setCamUseTI modeIndex
```

### Parameters

- state: Boolean - true to enable, false to disable the effect
- modeIndex: Number - TI mode. Can be:
* 0 - White Hot
* 1 - Black Hot
* 2 - Light Green Hot / Darker Green cold
* 3 - Black Hot / Darker Green cold
* 4 - Light Red Hot /Darker Red Cold
* 5 - Black Hot / Darker Red Cold
* 6 - White Hot . Darker Red Cold
* 7 - Thermal (Shade of Red and Green, Bodies are white)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
true setCamUseTI 1;
```

#### Example 2

*Predator* vision:

```sqf
_cam = "camera" camCreate [0, 0, 0];
_cam camSetTarget player;
_cam camSetRelPos [0, 1, 1.5];
_cam cameraEffect ["Internal", "Back"];
_cam camCommit 0;
true setCamUseTI 7;
```
