## BIS fnc taskHint

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskHint
- Revision: 352105
- Updated: 2024-02-01T23:24:54Z

- Availability: arma3 1.00
- Groups: Tasks

### Description

Shows a task hint. See Arma 3: Task Framework for more information.

### Syntax

```sqf
[taskName, taskState] call BIS_fnc_taskHint
```

### Parameters

- taskName: String
- taskState: String - can be:
*"CREATED"
*"ASSIGNED"
*"SUCCEEDED"
*"FAILED"
*"CANCELED"

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
["BIS_task_01","CANCELED"] call BIS_fnc_taskHint;
```
