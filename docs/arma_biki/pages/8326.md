## lnbSetData

- Source: https://community.bistudio.com/wiki/lnbSetData
- Revision: 349203
- Updated: 2023-11-08T14:50:43Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Sets the additional text (invisible) on the item with the given position of the 2D listbox.

### Syntax

```sqf
lnbSetData [idc, [row, column], data]
```

```sqf
ctrl lnbSetData [<nowiki/>[row, column], data]
```

### Parameters

- idc: Number
- row: Number
- column: Number
- data: String - the invisible text to add
- ctrl: Control
- row: Number
- column: Number
- data: String - the invisible text to add

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lnbSetData [123, [0,0],"#1"];
```

#### Example 2

```sqf
_ctrl lnbSetData [[0,0],"#1"];
```
