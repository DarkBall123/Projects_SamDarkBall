## unitTurret

- Source: https://community.bistudio.com/wiki/unitTurret
- Revision: 377504
- Updated: 2026-01-02T06:49:34Z

- Availability: arma3 2.00
- Groups: Turrets

### Description

Returns the turret path the given vehicle's gunner is in.
To get the turret's unit see turretUnit.

### Syntax

```sqf
vehicle unitTurret gunner
```

### Parameters

- vehicle: Object
- gunner: Object

### Return Value

- Turret Path
- `[-1]` is returned if the gunner is also the driver.
When no units are in any of vehicle's turret, empty array `[]` is returned.

### Examples

#### Example 1

```sqf
_vehicle unitTurret _gunner;
```

#### Example 2

```sqf
vehicle player unitTurret player;
```
