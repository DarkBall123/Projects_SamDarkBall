## BIS fnc liveFeed

- Source: https://community.bistudio.com/wiki/BIS_fnc_liveFeed
- Revision: 328590
- Updated: 2022-07-13T17:02:28Z

- Availability: arma3 1.00
- Groups: Live Feed

### Description

Display a live feed.

### Syntax

```sqf
[source, target, receiver, effect] call BIS_fnc_liveFeed
```

### Parameters

- source: Object or Position - live feed source
- target: Object or Position - live feed target
- receiver: Object - player that will see the feed - if not local, function will do nothing
- effect: Number - (Optional, default 0)  live feed effect. Can be one of:
* -1: reset
*  0: normal
*  1: night vision
*  2: thermal imaging

### Return Value

- Boolean - true if successful, false if not

### Examples

#### Example 1

```sqf
[myUAV, player, player, 2] call BIS_fnc_liveFeed;
```

#### Example 2

live feed display:

```sqf
private _UAVFeedDisplay = uiNamespace getVariable "BIS_fnc_PIP_RscPIP";
```
