## unlockAchievement

- Source: https://community.bistudio.com/wiki/unlockAchievement
- Revision: 364204
- Updated: 2024-05-05T11:07:39Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Broken Commands, System

### Description

Unlocks the given achievement. The achievements are listed in CfgAchievements, however none of the currently listed achievements is used in Arma 3, hence the command always returns false.

{{Feature|important|
This command is obsolete and was used in the experimental (unreleased) {{arma2}} Xbox 360 version as stated
{{Link|https://forums.bohemia.net/forums/topic/187873-unlockachievment-command/?tab{{=}}comments#comment-2978436|here}}.
}}
To unlock a Steam Achievement for Arma 3, see setStatValue.

### Syntax

```sqf
unlockAchievement name
```

### Parameters

- name: String - achievement name

### Return Value

- Boolean - true if achievement was unlocked

### Examples

#### Example 1

```sqf
_isUnlocked = unlockAchievement "Hunter";
```
