### Description

Check if config entry represents array.

### Syntax

```sqf
isArray config
```

### Parameters

- config: Config

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_ok = isArray (configFile >> "CfgVehicles") // returns false
```
