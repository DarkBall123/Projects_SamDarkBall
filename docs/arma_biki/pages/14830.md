## assignCurator

- Source: https://community.bistudio.com/wiki/assignCurator
- Revision: 348458
- Updated: 2023-11-08T13:00:18Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Assign player as curator. Two players cannot act as one curator.

### Multiplayer

Can be executed only on server

### Syntax

```sqf
player assignCurator curatorObj
```

### Parameters

- player: Object
- curatorObj: Object - curator module.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player assignCurator myCurator;
```

### See Also

Arma 3: Curator unassignCurator
