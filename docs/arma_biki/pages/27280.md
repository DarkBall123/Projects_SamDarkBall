## BIS fnc drawBoundingBox

- Source: https://community.bistudio.com/wiki/BIS_fnc_drawBoundingBox
- Revision: 376923
- Updated: 2025-12-29T12:16:33Z

- Availability: arma3 1.98
- Groups: Object Manipulation

### Description

Draws bounding box around given objects.

### Syntax

```sqf
[objects, color, draw] call BIS_fnc_drawBoundingBox
```

### Parameters

- objects: Array of Objects - (Optional, default 

```sqf
[objNull]
```

)
- color: Array in format Color (RGBA) - (Optional, default [1,0,1,1])
- draw: Boolean - (Optional, default nil) true to draw, false to remove

### Return Value

- Boolean - true if successful, false if not

### Examples

#### Example 1

```sqf
[[BIS_building], [1,0,1,1], true] call BIS_fnc_drawBoundingBox;
```

#### Example 2

```sqf
[[], [], false] call BIS_fnc_drawBoundingBox;
```
