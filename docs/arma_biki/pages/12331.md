## ctrlTextHeight

- Source: https://community.bistudio.com/wiki/ctrlTextHeight
- Revision: 377912
- Updated: 2026-01-09T17:38:24Z

- Availability: arma3 0.50
- Groups: GUI Control

### Description

Returns the text control's height. Supported control types:
{{Columns|3|
* CT_STATIC
* CT_STRUCTURED_TEXT
* CT_EDIT
* 2.06 CT_XKEYDESC
* 2.06 CT_XBUTTON
* 2.06 CT_SHORTCUTBUTTON
* 2.06 CT_BUTTON
* 2.06 CT_ACTIVETEXT
}}

### Syntax

```sqf
ctrlTextHeight  control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_h = ctrlTextHeight _ctrl;
```
