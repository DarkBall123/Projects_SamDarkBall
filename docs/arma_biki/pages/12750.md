## BIS fnc isBuildingEnterable

- Source: https://community.bistudio.com/wiki/BIS_fnc_isBuildingEnterable
- Revision: 309316
- Updated: 2022-05-05T12:04:26Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Check whether a building or structure has available positions defined within model.

### Syntax

```sqf
param call BIS_fnc_isBuildingEnterable
```

### Parameters

- param: Object
- param: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[_building] call BIS_fnc_isBuildingEnterable;
```

#### Example 2

```sqf
[_building, _minNumberOfPositions] call BIS_fnc_isBuildingEnterable;
```
