## getCargoIndex

- Source: https://community.bistudio.com/wiki/getCargoIndex
- Revision: 369168
- Updated: 2024-09-03T10:34:42Z

- Availability: arma3 1.26
- Locality: argument global
- Groups: Object Manipulation

### Description

Returns index of the unit in cargo. -1 if not in cargo.

### Syntax

```sqf
vehicle getCargoIndex unit
```

### Parameters

- vehicle: Object
- unit: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
player moveInCargo heli;
hint str (heli getCargoIndex player);
```
