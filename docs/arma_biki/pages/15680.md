## BIS fnc greatestNum

- Source: https://community.bistudio.com/wiki/BIS_fnc_greatestNum
- Revision: 326905
- Updated: 2022-07-12T21:44:38Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays, Math

### Description

Returns the greatest number out of the passed set.

### Syntax

```sqf
numbers call BIS_fnc_greatestNum
```

### Parameters

- numbers: Array - a set of numbers

### Return Value

- Number - greatest number in the set

### Examples

#### Example 1

```sqf
private _result = [7,2,1,5,10] call BIS_fnc_greatestNum; //_result = 10
```
