## ctrlSetPositionH

- Source: https://community.bistudio.com/wiki/ctrlSetPositionH
- Revision: 309179
- Updated: 2022-05-03T18:04:10Z

- Availability: arma3 1.92
- Groups: GUI Control - Positioning

### Description

Sets the height of a 2D control. ctrlCommit is required to complete the operation.

### Syntax

```sqf
control ctrlSetPositionH h
```

### Parameters

- control: Control - 2D control
- h: Number - height of the control

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl ctrlSetPositionH 0.5;
_ctrl ctrlCommit 1;
```
