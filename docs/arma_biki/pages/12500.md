## tvSort

- Source: https://community.bistudio.com/wiki/tvSort
- Revision: 377597
- Updated: 2026-01-02T07:01:07Z

- Availability: arma3 0.74
- Groups: GUI Control - Tree View

### Description

Sorts all children of given path. Text of Tree View entries is used for sorting.

### Syntax

```sqf
control tvSort [path, reversed]
```

```sqf
tvSort [idc, path, reversed]
```

### Parameters

- control: Control
- path: Tree View Path - the parent item to sort
- reversed: Boolean - (Optional, default false) true to reverse sort it
- idc: Number - control idc
- path: Tree View Path - the parent item to sort
- reversed: Boolean - (Optional, default false) true to reverse sort it

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
control tvSort [[0], true];
```

#### Example 2

```sqf
tvSort [102, [0], true];
```
