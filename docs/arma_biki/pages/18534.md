## ctRowCount

- Source: https://community.bistudio.com/wiki/ctRowCount
- Revision: 309962
- Updated: 2022-05-05T12:17:01Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Returns number of rows (headers not included) in the RscControlsTable.

### Syntax

```sqf
ctRowCount control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
ctRowCount _control;
```
