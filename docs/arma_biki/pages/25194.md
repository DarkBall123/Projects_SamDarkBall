### Description

Add two Numbers, concatenate two Arrays or two Strings, or create a copy of an Array or HashMap.

Array copy methods `ARRAY + []` and `+ ARRAY` have different behaviours:
* `ARRAY + []` creates copy of the 1st dimension, but preserves references in other dimensions ([shallow copy](https://en.wikipedia.org/wiki/Object_copying#Shallow_copy)).
* `+ ARRAY` clones every element, so if the array is multi-dimensional, the created copy contains no references ([deep copy](https://en.wikipedia.org/wiki/Object_copying#Deep_copy)).
See Example 6.

### Syntax

```sqf
numberA + numberB
```

```sqf
+ number
```

```sqf
arrayA + arrayB
```

```sqf
stringA + stringB
```

```sqf
+ array
```

```sqf
+ hashMap
```

### Parameters

- numberA: Number
- numberB: Number
- number: Number
- arrayA: Array of Anything
- arrayB: Array of Anything
- stringA: String
- stringB: String
- array: Array of Anything
- hashMap: HashMap

### Return Value

- Number - the sum of *numberA* and *numberB*
- Number - the value of the parameter *number*
- Array of Anything - a new array filled with *arrayA* and *arrayB* elements, in that order
- String - a string concatenating *stringA* and *stringB*
- Array of Anything - a new instance of the provided array filled with same elements ([deep copy](https://en.wikipedia.org/wiki/Object_copying#Deep_copy))
- HashMap - a new instance of the provided HashMap filled with the same key-value pairs ([deep copy](https://en.wikipedia.org/wiki/Object_copying#Deep_copy))

### Examples

#### Example 1

```sqf
5 +  3	// returns  8
-5 + -3	// returns -8
```

#### Example 2

```sqf
+  2	// returns  2
+ -7	// returns -7
```

#### Example 3

```sqf
_arrayA = [1,2,3];
_arrayB = [3,4,5];
_arrayAB = _arrayA + _arrayB; // _arrayAB = [1,2,3,3,4,5]
// _arrayA and _arrayB remain unchanged
```

#### Example 4

```sqf
_result = "Hello" + " " + "there"; // "Hello there"
```

#### Example 5

```sqf
_arrayA = [1,2,3];
_arrayB = + _arrayA;
_arrayB set [0, 99]; // _arrayA = [1,2,3], _arrayB = [99,2,3]
```

#### Example 6

Shallow copy with `ARRAY + []`:

```sqf
private _subArray = [1, 2, 3];
private _array1 = [_subArray, 1, 2, 3];
private _array2 = _array1 + [];
_array2 select 0 set [0, "oops"];
hint str _subArray; // ["oops", 2, 3]
```

Deep copy with `+ ARRAY`:

```sqf
private _subArray = [1, 2, 3];
private _array1 = [_subArray, 1, 2, 3];
private _array2 = + _array1;
_array2 select 0 set [0, "oops"];
hint str _subArray; // [1, 2, 3]
```
