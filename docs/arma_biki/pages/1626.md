## lbSetCurSel

- Source: https://community.bistudio.com/wiki/lbSetCurSel
- Revision: 376677
- Updated: 2025-11-04T00:29:50Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListBox

### Description

Selects the item with the given index in the listbox, listnbox, combobox, xcombobox, xlistbox

**The following only applies to the [Alternative Syntax](#Syntax 2) when used with CT_LISTBOX and CT_LISTNBOX.**

To deselect all entries, use -1: 

```sqf
_ctrl lbSetCurSel -1;
```

 For listbox of style LB_MULTI use lbSetSelected instead.

CT_COMBO does not allow deselecting entries, it will instead select the first one as it is not a combobox usual behaviour.
If you really need to deselect a combobox, see [DreadedEntity's note](#Notes). For the ComboBox you might as well want to explicitly select index 0 to avoid showing ghost row.

### Syntax

```sqf
lbSetCurSel [idc, index]
```

```sqf
control lbSetCurSel index
```

### Parameters

- idc: Number - control's IDC
- index: Number
- control: Control
- index: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lbSetCurSel [101, 0];
```

#### Example 2

```sqf
_control lbSetCurSel 0;
```
