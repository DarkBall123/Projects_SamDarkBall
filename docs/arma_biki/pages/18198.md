## BIS fnc taskSetType

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskSetType
- Revision: 369828
- Updated: 2024-10-15T15:21:35Z

- Availability: arma3 1.58
- Locality: argument global, effect global
- Groups: Tasks

### Description

Sets task type to given task. See Arma 3: Task Framework for more information.

### Syntax

```sqf
[id, type] call BIS_fnc_taskSetType
```

### Parameters

- id: String - task ID
- type: String - [vanilla](Arma 3: Task Framework#Task Icons) or [custom](Description.ext#CfgTaskTypes) task type; if not defined, empty (no) type is used

### Return Value

- String - task ID.

### Examples

#### Example 1

```sqf
["BIS_Task_01","attack"] call BIS_fnc_taskSetType;
```
