## BIS fnc endLoadingScreen

- Source: https://community.bistudio.com/wiki/BIS_fnc_endLoadingScreen
- Revision: 369457
- Updated: 2024-09-06T08:44:54Z

- Availability: arma3 0.58
- Groups: GUI

### Description

Unregister a loading screen. When none other remains, end the loading.
The loading screen can be force-ended with the [ENDLOAD cheat code](Arma 3: Cheats#ENDLOAD).

### Syntax

```sqf
screenId call BIS_fnc_endLoadingScreen
```

### Parameters

- screenId: String - screen ID, used in BIS_fnc_startLoadingScreen

### Return Value

- Boolean - true when unregistered

### Examples

#### Example 1

```sqf
["myLoadingScreen", "Loading… wait for my splendid™ mission!"] call BIS_fnc_startLoadingScreen;
uiSleep 3;
"myLoadingScreen" call BIS_fnc_endLoadingScreen;
```
