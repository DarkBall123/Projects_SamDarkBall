## setAirportSide

- Source: https://community.bistudio.com/wiki/setAirportSide
- Revision: 322975
- Updated: 2022-06-28T21:42:54Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Roads and Airports, Sides

### Description

Set owning side of the airport. ID is the number to identify which airport on the island you want to check.

### Syntax

```sqf
id setAirportSide side
```

```sqf
target setAirportSide side
```

### Parameters

- id: Number
- side: Side
- target: Object
- side: Side

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
0 setAirportSide east;
```
