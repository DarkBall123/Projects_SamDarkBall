## onOfficialServer

- Source: https://community.bistudio.com/wiki/onOfficialServer
- Revision: 351585
- Updated: 2023-12-07T18:29:17Z

- Availability: argo 1.00
- Groups: Argo

### Description

Get if the current machine is an official server or is connected to one.

### Syntax

```sqf
onOfficialServer
```


### Return Value

- Boolean - true if the machine is an official server or is connected to one, false otherwise (e.g disconnected or single player)

### Examples

#### Example 1

```sqf
if (onOfficialServer) then
{
	systemChat "I am safe here! Wait, why is this bush crawling towards me";
};
```
