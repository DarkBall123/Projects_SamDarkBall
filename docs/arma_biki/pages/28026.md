## isAutoStartUpEnabledRTD

- Updated: 2026-01-02T21:48:47Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Returns state of automatic start up action. {{Feature|afm}}

### Syntax

```sqf
isAutoStartUpEnabledRTD helicopter
```

### Parameters

- helicopter: Object

### Return Value

- Boolean - returns true if automatic start up action is enabled.

### Examples

#### Example 1

```sqf
_state = isAutoStartUpEnabledRTD _myHelicopter;
```
