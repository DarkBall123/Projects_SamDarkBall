## ropesAttachedTo

- Source: https://community.bistudio.com/wiki/ropesAttachedTo
- Revision: 352477
- Updated: 2024-02-11T23:39:44Z

- Availability: arma3 2.10
- Groups: Ropes and Sling Loading

### Description

Returns the owners of all ropes attached to the cargo - the transports to which other entities are attached with ropes.

### Syntax

```sqf
ropesAttachedTo cargo
```

### Parameters

- cargo: Object - entity attached to the ends of the ropes

### Return Value

- Array of Objects which are transports from which the ropes originate, the ropes owners

### Examples

#### Example 1

```sqf
r1 = ropeCreate [car1, [0,0,0], car3, [0,0,0], 10];
r2 = ropeCreate [car2, [0,0,0], car3, [0,0,0], 10];
ropesAttachedTo car3; // [car1,car2]
```
