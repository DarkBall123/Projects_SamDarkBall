## isLightOn

- Source: https://community.bistudio.com/wiki/isLightOn
- Revision: 377881
- Updated: 2026-01-04T16:20:38Z

- Availability: arma3 1.32
- Locality: argument global
- Groups: Lights

### Description

Returns true if vehicle headlights are on otherwise false.

### Syntax

```sqf
isLightOn vehicle
```

```sqf
isLightOn [vehicle, turret]
```

### Parameters

- vehicle: Object - vehicle with headlights
- vehicle: Object - vehicle with search light on a turret
- turret: Turret Path

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
_headlightsOn = isLightOn vehicle player;
```

#### Example 2

```sqf
_pilotLightOn = isLightOn heli;
```

#### Example 3

```sqf
_searchLightOn = isLightOn [heli, [0]];
```
