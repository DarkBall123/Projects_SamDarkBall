### Description

ArcCosine of a number, result in Degrees

### Syntax

```sqf
acos x
```

### Parameters

- x: Number in range -1..+1 - any other value returns NaN

### Return Value

- Number

### Examples

#### Example 1

```sqf
_degrees = acos 0.5; // Returns 60
```
