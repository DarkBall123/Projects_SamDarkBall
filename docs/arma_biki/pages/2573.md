## moveToFailed

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50

### Description

Check if latest low level moveTo command failed.

### Syntax

```sqf
moveToFailed unit
```

### Parameters

- unit: Object

### Return Value

- Boolean - NOT IMPLEMENTED, ALWAYS false

### Examples

#### Example 1

```sqf
private _hasFailed = moveToFailed _unit;
```
