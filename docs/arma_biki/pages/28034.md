## lnbSetPictureColorSelectedRight

- Source: https://community.bistudio.com/wiki/lnbSetPictureColorSelectedRight
- Revision: 377729
- Updated: 2026-01-03T00:21:11Z

- Availability: arma3 1.00
- Groups: GUI Control - ListNBox

### Description

Sets the color of the right picture when it is selected.

### Syntax

```sqf
lnbSetPictureColorSelectedRight [idc, [row, column], color]
```

```sqf
ctrl lnbSetPictureColorSelectedRight [<nowiki/>[row, column], color]
```

### Parameters

- idc: Number
- row: Number - index of the row
- column: Number - index of the column
- color: Color (RGBA)
- ctrl: Control
- row: Number - index of the row
- column: Number - index of the column
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_control lnbSetPictureColorSelectedRight [[0, 0], [1,1,1,0.5]];
```
