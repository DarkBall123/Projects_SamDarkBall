## BIS fnc compatibleItems

- Source: https://community.bistudio.com/wiki/BIS_fnc_compatibleItems
- Revision: 349367
- Updated: 2023-11-08T15:35:11Z

- Availability: arma3 1.24
- Groups: Inventory

### Description

Use compatibleItems instead. Return all compatible weapon attachments.

### Syntax

```sqf
weapon call BIS_fnc_compatibleItems
```

### Parameters

- weapon: String - weapon class

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
(currentWeapon player) call BIS_fnc_compatibleItems;
```
