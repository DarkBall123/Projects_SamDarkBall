## pixelGridBase

- Source: https://community.bistudio.com/wiki/pixelGridBase
- Revision: 348722
- Updated: 2023-11-08T14:31:29Z

- Availability: arma3 1.62
- Groups: GUI Control - Positioning

### Description

Returns grid size based on screen resolution.

### Syntax

```sqf
**pixelGridBase**
```


### Return Value

- Number - grid size, see Arma 3: Pixel Grid System

### Examples

#### Example 1

```sqf
_gridBaseHeight = pixelH * pixelGridBase;
```
