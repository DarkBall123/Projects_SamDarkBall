## BIS fnc encodeFlags

- Source: https://community.bistudio.com/wiki/BIS_fnc_encodeFlags
- Revision: 348540
- Updated: 2023-11-08T13:06:07Z

- Availability: arma3 1.00
- Groups: Bitwise

### Description

Encodes array of unique binary flags with indexes between 0-15 into a single scalar.

### Syntax

```sqf
flags call BIS_fnc_encodeFlags
```

### Parameters

- flags: Array - array of unique binary flags with indexes between 0-15

### Return Value

- Number - encoded flags

### Examples

#### Example 1

```sqf
private _encodedFlags = [0,2,3] call BIS_fnc_encodeFlags;//Returns 13
```
