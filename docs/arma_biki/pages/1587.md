## gunner

- Source: https://community.bistudio.com/wiki/gunner
- Revision: 348608
- Updated: 2023-11-08T13:45:17Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Returns the gunner of a vehicle.

### Syntax

```sqf
gunner  vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Object - the person sitting in the gunner place is returned. If vehicle is not a vehicle but a person, the person is returned.

### Examples

#### Example 1

```sqf
gunner _tank action ["getout", _tank];
```
