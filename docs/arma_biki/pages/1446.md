## titleCut

- Source: https://community.bistudio.com/wiki/titleCut
- Revision: 319886
- Updated: 2022-05-13T09:25:39Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Displays text on screen.
cutText should be used instead.

### Syntax

```sqf
titleCut [text, type, speed]
```

### Parameters

- text: String - text to be displayed on screen
- type: String - can be one of Title Effect Types
- speed: Number - (Optional, default 1)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
titleCut ["Hello, how are you?","Plain Down",3];
```
