## SQS to SQF conversion

- Source: https://community.bistudio.com/wiki/SQS_to_SQF_conversion
- Revision: 377918
- Updated: 2026-01-11T15:31:56Z

__NOEDITSECTION__
{{TOC|side}}
SQF Syntax has been introduced in {{ofpr}} v1.85 and is the {{arma}} series' main scripting language until Arma 3.
The main differences with SQS Syntax are:

- **execVM** is used (instead of exec for SQS)
- Every command has to end with a semicolon (

```sqf
- 
```

)
- the following commands disappeared:
  - goto/[#label](SQS Syntax#Label) (Note, # is a command in itself in Arma 3)
  - exit - a partial SQF equivalent can be found in exitWith
- Line returns do not impact code
- SQF can return a variable, where SQS cannot

=== Conditional Command ===
|-
|
<sqs>? CONDITION : COMMAND</sqs>
<sqs>? alive player : player setDammage 1</sqs>
|

```sqf
if (CONDITION) then { COMMAND };
```

```sqf
if (alive player) then { player setDammage 1 };
```

=== Multi-Conditional Command ===
|-
|
<sqs>
? CONDITION : goto "SKIP"
 COMMAND_2
goto "END"
#SKIP
 COMMAND_1
 #END
</sqs>
|

```sqf
if (CONDITION) then
{
	COMMAND_1
}
else
{
	COMMAND_2
};
```

=== Cycle ===
|-
| <sqs>
#loop
COMMAND
~DELAY
? CONDITION : goto "LOOP"
</sqs>
|

```sqf
while { CONDITION } do
{
	COMMAND;
	sleep DELAY;
};
```

|-
| <sqs>

 COMMAND

```sqf
for "_i" from 0 to COUNT -1 do
{
	COMMAND;
};
```

```sqf
		{ COMMAND_2 };
	default
		{ DEFAULT_COMMAND };
};
```
