## assignItem

- Source: https://community.bistudio.com/wiki/assignItem
- Revision: 369096
- Updated: 2024-09-03T10:25:27Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Unit Inventory

### Description

Assigns existing item from inventory (uniform, vest, backpack) to a correct slot. If the slot is occupied by another item, it gets replaced. See also linkItem.

### Syntax

```sqf
unit assignItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
bluforUnit addItem "NVGoggles";
bluforUnit assignItem "NVGoggles";
opforUnit addItem "NVGoggles_OPFOR";
opforUnit assignItem "NVGoggles_OPFOR";
independentUnit addItem "NVGoggles_INDEP";
independentUnit assignItem "NVGoggles_INDEP";
```
