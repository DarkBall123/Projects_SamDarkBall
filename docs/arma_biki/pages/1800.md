## setFaceAnimation

- Source: https://community.bistudio.com/wiki/setFaceAnimation
- Revision: 340876
- Updated: 2023-05-13T21:15:37Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Animations, Broken Commands

### Description

Sets facial animation phase (eye blinking).
This command is not functional in Arma 3.

### Syntax

```sqf
unit setFaceAnimation blink
```

### Parameters

- unit: Object
- blink: Number - range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldier1 setFaceAnimation 0.5;
```
