## typeOf

- Source: https://community.bistudio.com/wiki/typeOf
- Revision: 378246
- Updated: 2026-03-21T09:42:52Z

- Availability: ofp 1.90, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns the class name of given target.

### Syntax

```sqf
typeOf target
```

### Parameters

- target: Object, since 2.22 Control, Display

### Return Value

- String - config class name, or empty string if *target* does not have a class

### Examples

#### Example 1

```sqf
if (typeOf vehicle player == "B_Heli_Light_01_armed_F") then { hint "Player is in a AH-9 Pawnee"; };
```

#### Example 2

```sqf
// Since 2.22
typeOf (findDisplay 313); // "Display3DEN"
```
