## Objects.sav

- Source: https://community.bistudio.com/wiki/Objects.sav
- Revision: 292565
- Updated: 2021-08-10T12:50:54Z

The Objects.sav file is the save/load location of the following commands:
- saveIdentity / loadIdentity
- saveStatus / loadStatus
It was first introduced in **{{ofpr}}** campaign.
