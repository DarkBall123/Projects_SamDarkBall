## BIS fnc earthquake

- Source: https://community.bistudio.com/wiki/BIS_fnc_earthquake
- Revision: 378184
- Updated: 2026-03-09T19:48:10Z

- Availability: arma3 1.00
- Locality: effect local
- Groups: Environment

### Description

Earthquake simulated through camera shake and sound. Stamina is impacted by the earthquake too.
Earthquake will last between 13 and 20 seconds. While earthquake is in progress missionNamespace variable `BIS_fnc_earthquake_inprogress` will be true.

### Syntax

```sqf
[intensity] spawn BIS_fnc_earthquake
```

### Parameters

- intensity: Number - (Optional, default 2) can be 1, 2, 3 or 4. Any other value will fall back to the default value

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[4] spawn BIS_fnc_earthquake;
```
