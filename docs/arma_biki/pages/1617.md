## land

- Source: https://community.bistudio.com/wiki/land
- Revision: 373721
- Updated: 2025-06-23T00:49:43Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Control

### Description

Forces a helicopter landing. If there is a helipad nearby, the helicopter will attempt to land on it. VTOL he other hand will just land somewhere. To make helicopter or VTOL land on a specific helipad use landAt.

### Syntax

```sqf
helicopter land mode
```

### Parameters

- helicopter: Object helicopter or VTOL
- mode: String - can be one of:
* "LAND" - Complete stop
* "GET IN" - Hovering very low, for another unit to get in
* "GET OUT" - Hovering low, for another unit to get out
* {{GVI|arma2|1.00|size= 0.75}} "NONE" - Cancel a landing

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_cobraOne land "LAND";
```

|text= To make a helicopter LAND correctly and not hovering over the landing position use unitReady to check if the helicopter already has reached his destination.
You can fix a landing bug by using a short delay bevore checking the unitReady command.

```sqf
_helicopter move getPosATL _destination;
sleep 3;
while { alive _helicopter && not unitReady _helicopter } do
{
	sleep 1;
};

if (alive _helicopter) then
{
	_helicopter land "LAND";
};
```
