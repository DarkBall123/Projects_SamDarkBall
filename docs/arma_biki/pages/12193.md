## objectFromNetId

- Source: https://community.bistudio.com/wiki/objectFromNetId
- Revision: 373126
- Updated: 2025-04-02T15:43:29Z

- Availability: arma3 0.50, arma2oa 1.63
- Groups: Multiplayer

### Description

Get object with given unique ID. For groups, use groupFromNetId.

### Multiplayer

Before 2.18 it would return objNull in multiplayer - see BIS_fnc_objectFromNetId

### Syntax

```sqf
objectFromNetId id
```

### Parameters

- id: String

### Return Value

- Object

### Examples

#### Example 1

```sqf
objectFromNetId "2:3"
```
