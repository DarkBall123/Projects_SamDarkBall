### Description

Return all simple tasks assigned to given unit.

### Syntax

```sqf
simpleTasks unit
```

### Parameters

- unit: Object

### Return Value

- Array of Tasks

### Examples

#### Example 1

```sqf
_tasks = simpleTasks player;
```
