## onBriefingTeamSwitch

- Source: https://community.bistudio.com/wiki/onBriefingTeamSwitch
- Revision: 319537
- Updated: 2022-05-13T09:24:16Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing, Sounds, Team Switch, Event Handlers

### Description

Select a sound defined in the CfgSounds of the mission to be played the first time the TeamSwitch tab is selected in the briefing.

### Syntax

```sqf
onBriefingTeamSwitch soundName
```

### Parameters

- soundName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
onBriefingTeamSwitch "TeamSwitchVoiceOver";
```
