## lnbDeleteColumn

- Source: https://community.bistudio.com/wiki/lnbDeleteColumn
- Revision: 310134
- Updated: 2022-05-05T12:25:45Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Removes column with given index from ListNBox control.

### Syntax

```sqf
lnbDeleteColumn [idc, index]
```

```sqf
ctrl lnbDeleteColumn index
```

### Parameters

- idc: Number
- index: Number
- ctrl: Control
- index: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_ctrl lnbDeleteColumn 1;
```
