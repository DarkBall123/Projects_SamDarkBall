## tvTooltip

- Source: https://community.bistudio.com/wiki/tvTooltip
- Revision: 377816
- Updated: 2026-01-03T04:13:43Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Gets the tooltip text associated with the specified tree view path.

### Syntax

```sqf
tvTooltip [idc, path]
```

```sqf
ctrl tvTooltip path
```

### Parameters

- idc: Number - IDC of the tree view control
- path: Tree View Path
- ctrl: Control
- path: Tree View Path

### Return Value

- String - tooltip text
- String - tooltip text

### Examples

#### Example 1

```sqf
_text = tvTooltip [101, [0,2]];
```

#### Example 2

```sqf
_text = _treeCtrl tvTooltip [0,2];
```
