## setTimeMultiplier

- Source: https://community.bistudio.com/wiki/setTimeMultiplier
- Revision: 378416
- Updated: 2026-04-04T08:44:07Z

- Availability: arma3 1.26
- Locality: effect global, server execution server
- Groups: Time, Mission Information, Environment

### Description

Sets a time multiplier for in-game time. The command range is capped at 0.1 - 120 to avoid performance problems.

### Syntax

```sqf
setTimeMultiplier value
```

### Parameters

- value: Number in range 0.1 .. 120

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setTimeMultiplier 60;
```

#### Example 2

```sqf
setTimeMultiplier 0.5;
```
