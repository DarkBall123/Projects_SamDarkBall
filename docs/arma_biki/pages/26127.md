## isGamePaused

- Source: https://community.bistudio.com/wiki/isGamePaused
- Revision: 349063
- Updated: 2023-11-08T14:47:20Z

- Availability: arma3 1.96
- Groups: System

### Description

Returns the state of game simulation. Simulation can get paused by pressing {{Controls|Alt|Tab}} or a system dialog opening (e.g. {{Controls|Esc}} menu).
Simulation will not get paused if `-noPause` startup parameter is used.
onEachFrame event and `"EachFrame"` event handler continue to execute when the simulation is paused, which could result in undesired backlog. Use isGamePaused to skip loop if needed.

### Multiplayer

In multiplayer the simulation will not get paused and this command will always return false.

### Syntax

```sqf
isGamePaused
```


### Return Value

- Boolean - returns true if game simulation is paused, false if not

### Examples

#### Example 1

```sqf
onEachFrame 
{
	if (isGamePaused) exitWith {};
	// ...do stuff
};
```
