## BIS fnc findAllNestedElements

- Source: https://community.bistudio.com/wiki/BIS_fnc_findAllNestedElements
- Revision: 327526
- Updated: 2022-07-12T22:33:34Z

- Availability: arma3 1.00
- Groups: Arrays

### Description

Returns array of paths to all matching elements in deeply nested array, similar to BIS_fnc_findNestedElement but with all occurences.

### Syntax

```sqf
[array, query] call BIS_fnc_findAllNestedElements
```

### Parameters

- array: Array - array to explore
- query: Anything - wanted item

### Return Value

- Array of Array of Numbers - path to the first occurence of *query*

### Examples

#### Example 1

```sqf
private _array = [[1, 2, 3], [[1, 2, 3], 1, 2, 3]];
_result = [_array, 2] call BIS_fnc_findAllNestedElements; // returns [[0, 1], [1, 0, 1], [1, 2]]
```
