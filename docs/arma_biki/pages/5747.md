## addVehicle

- Source: https://community.bistudio.com/wiki/addVehicle
- Revision: 330327
- Updated: 2022-08-31T15:18:42Z

- Availability: arma1 1.05, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Object Manipulation

### Description

Adds a specified vehicle for use by a specified AI led group.
See AI Group Vehicle Management for more information.

### Syntax

```sqf
groupName addVehicle vehicleName
```

### Parameters

- groupName: Group
- vehicleName: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_grp addVehicle _vehicle;
```

#### Example 2

Using on crewed vehicle:

```sqf
group tank addVehicle tank;
```
