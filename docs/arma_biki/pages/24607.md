## BIS fnc resizeMarker

- Source: https://community.bistudio.com/wiki/BIS_fnc_resizeMarker
- Revision: 351261
- Updated: 2023-11-26T08:03:52Z

- Availability: arma3 1.78
- Locality: argument global, effect global
- Groups: Map and Markers

### Description

Resize marker. Use either absolute values or proportional values.

### Syntax

```sqf
[marker, size, duration] spawn BIS_fnc_resizeMarker
```

### Parameters

- marker: String - marker
- size: Array - (Optional, default [1,1]) array in form of:

0: Number - Size x

1: Number - Size y
- duration: Number - (Optional, default 1) duration of the transition

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["BIS_marker",[2,2],3] spawn BIS_fnc_resizeMarker;
```
