## setSize

- Source: https://community.bistudio.com/wiki/setSize
- Revision: 377130
- Updated: 2026-01-01T10:24:37Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations

### Description

Sets the size (radius)  of a location.

The width  is 2 * x, the height is 2 * y.

### Syntax

```sqf
location setSize [x,y]
```

### Parameters

- location: Location
- x: Number
- y: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLocation setSize [10,30];
```
