## ctrlPosition

- Source: https://community.bistudio.com/wiki/ctrlPosition
- Revision: 377302
- Updated: 2026-01-02T06:38:20Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Positioning

### Description

Returns the current position of 2D control as `[x, y, w, h]` array. For 3D control it returns relative `[x, z, y]`.

If the control is within a CT_CONTROLS_GROUP, the returned position will be relative to the group's position.

If the control is a CT_CONTROLS_TABLE header or row the returned position is relative to the table's position.

### Syntax

```sqf
ctrlPosition controlName
```

### Parameters

- controlName: Control

### Return Value

- Array format `[x, y, w, h]` (2D) or `[x, z, y]` (3D)

### Examples

#### Example 1

```sqf
_pos = ctrlPosition _control;
```
