## waypointTimeout

- Source: https://community.bistudio.com/wiki/waypointTimeout
- Revision: 377668
- Updated: 2026-01-02T09:02:25Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Gets the waypoint timeout values.

### Syntax

```sqf
waypointTimeout waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- Array with [min, mid, max]
* min: Number
* mid: Number
* max: Number

### Examples

#### Example 1

```sqf
waypointTimeout [groupOne,1];
```
