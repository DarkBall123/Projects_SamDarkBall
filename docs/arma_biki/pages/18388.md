## setPilotCameraTarget

- Source: https://community.bistudio.com/wiki/setPilotCameraTarget
- Revision: 377764
- Updated: 2026-01-03T01:00:05Z

- Availability: arma3 1.64
- Locality: argument local
- Groups: Pilot Camera

### Description

Sets an area or target to be tracked by the object airplane or helicopter pilotCamera. 
To track an object the vehicle has to have appropriate sensors (scanners) that can detect the given target type.
Using objNull will unlock the camera

### Syntax

```sqf
object setPilotCameraTarget target
```

### Parameters

- object: Object
- target: Object or PositionASL

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_pilotCamTrack = vehicle player setPilotCameraTarget [2100,4200,4.2];
```

#### Example 2

```sqf
_pilotCamTrack = vehicle player setPilotCameraTarget BIS_Edita;
```
