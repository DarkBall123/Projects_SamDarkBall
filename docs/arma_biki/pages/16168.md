## BIS fnc taskParent

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskParent
- Revision: 352072
- Updated: 2024-02-01T23:24:41Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Return a sub-task's parent task. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskName call BIS_fnc_taskParent
```

### Parameters

- taskName: String

### Return Value

- String - parent task

### Examples

#### Example 1

```sqf
"BIS_task_01" call BIS_fnc_taskParent;
```
