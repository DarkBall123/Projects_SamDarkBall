## suppressFor

- Source: https://community.bistudio.com/wiki/suppressFor
- Revision: 321213
- Updated: 2022-05-13T15:31:19Z

- Availability: arma2 1.05, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control

### Description

Force suppressive fire from the unit.

### Syntax

```sqf
unit suppressFor duration
```

### Parameters

- unit: Object
- duration: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldier1 suppressFor 10; // Will force soldier1 to do suppressive fire to known enemies for 10 seconds
```
