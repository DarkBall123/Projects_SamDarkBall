## taskType

- Source: https://community.bistudio.com/wiki/taskType
- Revision: 339088
- Updated: 2023-04-26T10:54:07Z

- Availability: arma3 1.58
- Groups: Briefing

### Description

Returns the type of the given task. A new task returns "Default" for the type.

### Syntax

```sqf
taskType task
```

### Parameters

- task: Task

### Return Value

- String

### Examples

#### Example 1

```sqf
_type = taskType (currentTask player);
```
