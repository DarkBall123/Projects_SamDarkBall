## removeAllMagazinesTurret

- Source: https://community.bistudio.com/wiki/removeAllMagazinesTurret
- Revision: 378391
- Updated: 2026-04-04T07:52:47Z

- Availability: arma3 2.20
- Locality: argument local, effect global
- Groups: Turrets

### Description

Removes all magazines from the given turret or from all turrets. Use turret path [-1] for driver's turret or [] for all turrets.

### Syntax

```sqf
vehicle removeAllMagazinesTurret turretPath
```

### Parameters

- vehicle: Object
- turretPath: Turret Path - [-1] for driver's turret or [] for all turrets

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player removeAllMagazinesTurret [-1];
```

#### Example 2

```sqf
_tank removeAllMagazinesTurret [];
```
