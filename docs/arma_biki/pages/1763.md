## setBehaviour

- Source: https://community.bistudio.com/wiki/setBehaviour
- Revision: 364537
- Updated: 2024-05-16T20:46:45Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Groups, AI Behaviour

### Description

Sets individual unit behaviour **on every unit in a group**.
This command doesn't set AI Group behaviour, see setCombatBehaviour or setBehaviourStrong for this.
See AI Behaviour for details of the effect of this command on AI units.

{

### Syntax

```sqf
groupOrUnit setBehaviour behaviour
```

### Parameters

- groupOrUnit : Group or Object - unit or a group
- behaviour: String - can be one of:
* "CARELESS"
* "SAFE"
* "AWARE"
* "COMBAT"
* "STEALTH"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_group1 setBehaviour "SAFE";
```

### See Also
