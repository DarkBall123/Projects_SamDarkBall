## getContainerMaxLoad

- Source: https://community.bistudio.com/wiki/getContainerMaxLoad
- Revision: 376219
- Updated: 2025-09-19T07:31:28Z

- Availability: arma3 1.62
- Groups: Unit Inventory

### Description

Returns max load value of given uniform, vest or backpack container. For other types of containers, use maxLoad command

### Syntax

```sqf
getContainerMaxLoad containerClass
```

### Parameters

- containerClass: String - uniform, vest or backpack class

### Return Value

- Number - load value, -1 if not available.

### Examples

#### Example 1

```sqf
private _maxLoadUniform		= getContainerMaxLoad uniform player;
private _maxLoadVest		= getContainerMaxLoad vest player;
private _maxLoadBackpack	= getContainerMaxLoad backpack player;
```
