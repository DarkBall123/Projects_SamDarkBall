### Description

Exponential function with the base [e](https://en.wikipedia.org/wiki/E_(mathematical_constant)). Equal to `e^x`. thumb|See how green and blue are identical except for the offset

### Syntax

```sqf
exp x
```

### Parameters

- x: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
_e = exp 1; // Returns e (2.7182...)
```

#### Example 2

```sqf
ln exp 1; // Returns 1
```
