## didJIP

- Source: https://community.bistudio.com/wiki/didJIP
- Revision: 376937
- Updated: 2025-12-31T22:33:08Z

- Availability: arma3 1.50
- Groups: Multiplayer

### Description

Checks if the current client [Joined In Progress](Multiplayer Scripting#Join In Progress).

### Syntax

```sqf
didJIP
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (didJIP) then
{
	hint "you're late to the party!";
};
```
