## BIS fnc geometricMean

- Source: https://community.bistudio.com/wiki/BIS_fnc_geometricMean
- Revision: 348249
- Updated: 2023-11-08T11:40:33Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

Returns the [geometric mean](https://en.wikipedia.org/wiki/Geometric_mean) of an array of numbers.

### Syntax

```sqf
array call BIS_fnc_geometricMean
```

### Parameters

- array: Array - array of numbers.

### Return Value

- Number - geometric mean

### Examples

#### Example 1

```sqf
[0,1,3] call BIS_fnc_geometricMean;//Returns 1.73205
```
