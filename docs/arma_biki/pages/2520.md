## vehicles

- Source: https://community.bistudio.com/wiki/vehicles
- Revision: 377110
- Updated: 2026-01-01T10:06:56Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Object Detection

### Description

Returns an array of all vehicles available to current client. This command returns both empty and crewed vehicles but not soldiers. It will also return "WeaponHolderSimulated" of dead bodies (weapon on the ground). Vehicles created with createVehicleLocal will only be returned on the client that created them.

### Syntax

```sqf
vehicles
```


### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_vehicles = vehicles;
```
