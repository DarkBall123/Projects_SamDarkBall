- Locality: argument global
- Groups: Math - Vectors, Render Time Scope

### Description

thumb|right|An object with its vectorDirVisual, [[vectorUpVisual and vectorSideVisual (vectors not to scale)]]
Returns an object's side vector in world space and render time scope.

The vector is **not necessarily normalized**. The magnitude of the vector depends on the object's scale.

### Syntax

```sqf
vectorSideVisual object
```

### Parameters

- object: Object

### Return Value

- Vector3D

### Examples

#### Example 1

```sqf
_vecSideVis = vectorSideVisual MyObject;
```
