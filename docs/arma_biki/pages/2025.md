## runInitScript

- Source: https://community.bistudio.com/wiki/runInitScript
- Revision: 347552
- Updated: 2023-09-28T09:35:18Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: System

### Description

Fades in mission screen and re-executes init.sqf and init.sqs scripts. In Eden Editor the code inside the "Init" mission attribute is executed.

### Syntax

```sqf
runInitScript
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
runInitScript;
```
