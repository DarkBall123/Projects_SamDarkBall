## BIS fnc updatePlayerArray

- Source: https://community.bistudio.com/wiki/BIS_fnc_updatePlayerArray
- Revision: 348288
- Updated: 2023-11-08T11:40:40Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Updates dead player objects to their current respawned objects.

### Syntax

```sqf
[input] call BIS_fnc_updatePlayerArray
```

### Parameters

- input: Array of Objects - array of old player objects

### Return Value

- Array - array with new player objects

### Examples

#### Example 1

```sqf
private _newPlayerObjects = _oldPlayerObjects call BIS_fnc_updatePlayerArray;
```
