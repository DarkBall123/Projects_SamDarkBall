## BIS fnc respawnConfirm

- Source: https://community.bistudio.com/wiki/BIS_fnc_respawnConfirm
- Revision: 348120
- Updated: 2023-11-08T11:32:18Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Shows a message box which the user needs to accept in order to respawn.

### Syntax

```sqf
[respawnDelay] spawn BIS_fnc_respawnConfirm
```

### Parameters

- respawnDelay: Number - (Optional, default 3) respawn delay

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[3] spawn BIS_fnc_respawnConfirm;
```
