## showWaypoint

- Source: https://community.bistudio.com/wiki/showWaypoint
- Revision: 348989
- Updated: 2023-11-08T14:45:47Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Defines how waypoints are shown to the player in map view. For 3D HUD visibility see setWaypointVisible.

### Syntax

```sqf
waypoint showWaypoint show
```

### Parameters

- waypoint: Waypoint
- show: String - possible values are:
* "NEVER" - Never show
* "EASY" - Show only if `showCadetWP` is enabled in global difficulty.
* "ALWAYS" - Always show

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] showWaypoint "ALWAYS";
```
