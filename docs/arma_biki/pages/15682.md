## BIS fnc nearestNum

- Source: https://community.bistudio.com/wiki/BIS_fnc_nearestNum
- Revision: 328545
- Updated: 2022-07-13T17:02:17Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays, Math

### Description

Returns the provided set closest number to the target number.

### Syntax

```sqf
[values, value] call BIS_fnc_nearestNum
```

### Parameters

- values: Array of Numbers - values to choose from
- value: Number - the reference value

### Return Value

- Number - the closest value

### Examples

#### Example 1

```sqf
private _closestValueTo4 = [[1,5,10], 4] call BIS_fnc_nearestNum; // returns 5
```
