## BIS fnc respawnCounter

- Source: https://community.bistudio.com/wiki/BIS_fnc_respawnCounter
- Revision: 349173
- Updated: 2023-11-08T14:50:37Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Set or execute respawn counter params.

### Syntax

```sqf
[text,colour] call BIS_fnc_respawnCounter
```

### Parameters

- text: String - text displayed below the respawn counter
- colour: Number - (Optional, default 0) can be:

0 = default

1 = warning

2 = error

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
["Some text", 2] call BIS_fnc_respawnCounter;
```
