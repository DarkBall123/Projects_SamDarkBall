## secondaryWeapon

- Source: https://community.bistudio.com/wiki/secondaryWeapon
- Revision: 348320
- Updated: 2023-11-08T12:59:40Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Inventory

### Description

Returns the name of a unit's secondary weapon (launcher). To detect the weapon which is **currently** being used by the unit use currentWeapon.

### Syntax

```sqf
secondaryWeapon unit
```

### Parameters

- unit: Object

### Return Value

- String - class name of the secondary weapon or 

```sqf
""
```

 if none available

### Examples

#### Example 1

```sqf
private _secondaryWeapon = secondaryWeapon player;
```

#### Example 2

```sqf
hint secondaryWeapon player; // "launch_NLAW_F"
```
