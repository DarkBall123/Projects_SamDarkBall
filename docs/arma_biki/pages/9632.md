## getMagazineCargo

- Source: https://community.bistudio.com/wiki/getMagazineCargo
- Revision: 348622
- Updated: 2023-11-08T13:46:04Z

- Availability: arma2oa 1.54, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Vehicle Inventory, Containers

### Description

Returns all magazines types and count from the cargo space

### Syntax

```sqf
getMagazineCargo object
```

### Parameters

- object: Object - vehicle or ammo box

### Return Value

- Array of arrays. [["5MagsType1","10MagsType2"],[5,10]]

### Examples

#### Example 1

```sqf
_content = getMagazineCargo carName;
```

#### Example 2

```sqf
_content = getMagazineCargo ammoBoxName;
```

#### Example 3

```sqf
hint str getMagazineCargo unitBackpack cursorTarget;
```
