## getStatValue

- Source: https://community.bistudio.com/wiki/getStatValue
- Revision: 347571
- Updated: 2023-09-28T10:03:14Z

- Availability: arma3 1.18
- Groups: System

### Description

Returns value of the given stat.

A list of possible StatNames can be found here: Arma 3: Stat Names

### Syntax

```sqf
getStatValue name
```

### Parameters

- name: String

### Return Value

- Number - (can return Nothing)

### Examples

#### Example 1

```sqf
getStatValue "ExpWarlockDown"; // Checks if the "Warlock Down" Achivement was already aquired
```
