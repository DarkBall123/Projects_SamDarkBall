## ctData

- Source: https://community.bistudio.com/wiki/ctData
- Revision: 309082
- Updated: 2022-04-30T15:25:34Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Returns metadata associated with a particular row of a CT_CONTROLS_TABLE control.

### Syntax

```sqf
ctrl ctData row
```

### Parameters

- ctrl: Control - the respective control
- row: Number - the row index

### Return Value

- String

### Examples

#### Example 1

```sqf
private _data = _ctrl ctData 0;
```
