## playActionNow

- Source: https://community.bistudio.com/wiki/playActionNow
- Revision: 364763
- Updated: 2024-06-08T18:43:24Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Animations

### Description

When used on a person, a smooth transition to the given action will be initiated, but all previous playAction are discarded.
For Arma 3 actions, see playAction/actions.

### Syntax

```sqf
soldier playActionNow action
```

### Parameters

- soldier: Object
- action: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
soldierOne playActionNow "SitDown";
```

#### Example 2

```sqf
rabbitTwo playActionNow "WalkF";
```

### See Also
