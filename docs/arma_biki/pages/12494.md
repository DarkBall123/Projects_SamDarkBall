## tvSetData

- Source: https://community.bistudio.com/wiki/tvSetData
- Revision: 378314
- Updated: 2026-04-02T16:15:57Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Sets string data to item on given path. IDC means id of parent Tree View.

### Syntax

```sqf
tvSetData [idc, path, data]
```

```sqf
ctrl tvSetData [path, data]
```

### Parameters

- idc: Number
- path: Tree View Path
- data: String
- ctrl: Control
- path: Tree View Path
- data: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvSetData [101, [0], "Test data"];
```

#### Example 2

```sqf
_ctrl tvSetData [[0,0,0], "Test data"];
```
