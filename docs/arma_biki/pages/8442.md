## setUnconscious

- Source: https://community.bistudio.com/wiki/setUnconscious
- Revision: 310114
- Updated: 2022-05-05T12:25:30Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

In {{arma2}} and since Arma 3 v1.64, this command sets unit into incapacitated state.

lifeState results:
* {{arma2}}: "UNCONSCIOUS"
* Arma 3: "INCAPACITATED"

The unit goes in ragdoll mode and animation played while incapacitated depends on the injuries received.

### Syntax

```sqf
unit setUnconscious set
```

### Parameters

- unit: Object
- set: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_unit setUnconscious true;
```
