## BIS fnc sideColor

- Source: https://community.bistudio.com/wiki/BIS_fnc_sideColor
- Revision: 353604
- Updated: 2024-03-19T17:37:26Z

- Availability: arma3 1.00
- Groups: Sides

### Description

Returns colour of define side either as Array in format RGBA or the name of the colour as String

### Syntax

```sqf
[side, returnString] call BIS_fnc_sideColor
```

### Parameters

- side: Side
- returnString: Boolean - (Optional, default false) wanted output:
* false: [R, G ,B, A]
* true: "ColourName"

### Return Value

- or String or Array format Color (RGBA)

### Examples

#### Example 1

```sqf
[blufor, false] call BIS_fnc_sideColor; // returns [0,0.3,0.6,1]
```

#### Example 2

```sqf
[blufor, true] call BIS_fnc_sideColor; // returns "ColorWEST"
```
