## buldozer loadNewRoads

- Revision: 318691
- Updated: 2022-05-13T09:21:20Z

- Availability: arma3 0.50
- Groups: System

### Description

Generates new roads. Working only in buldozer.

### Syntax

```sqf
buldozer_loadNewRoads path
```

### Parameters

- path: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_loaded = buldozer_loadNewRoads "C:/A3/Map_Stratis/data/roads/"
```
