## waypointAttachObject

- Source: https://community.bistudio.com/wiki/waypointAttachObject
- Revision: 377746
- Updated: 2026-01-03T00:57:58Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Attaches a static object via its numeric ID to the given waypoint. Not to be confused with synchronizeWaypoint!

{{Feature|important|
* The main syntax doesn't work in Arma 3 anymore.
* The alternative syntax is (at least) available since {{arma2}}.
}}

### Syntax

```sqf
waypoint waypointAttachObject objectID
```

```sqf
waypoint waypointAttachObject object
```

### Parameters

- waypoint: Waypoint
- objectID: Number
- waypoint: Waypoint
- object: Object - static object

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] waypointAttachObject 1234;
```

#### Example 2

```sqf
private _wp = group player addWaypoint [[1907.5, 5746.5, 0.00144196], 0];
_wp waypointAttachObject ((waypointPosition _wp) nearestObject 66220);
```
