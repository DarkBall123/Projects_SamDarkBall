## ctrlChecked

- Source: https://community.bistudio.com/wiki/ctrlChecked
- Revision: 353343
- Updated: 2024-03-15T17:11:52Z

- Availability: arma3 0.50
- Groups: GUI Control

### Description

Returns the current state of given CT_CHECKBOXES control. Since Arma 3 v1.72 it is possible to query multiple checkboxes by providing checkbox index. For more information see CT_CHECKBOXES.The `"CheckBoxesSelChanged"` control EH returns the control, index of changed checkbox and its current checked state. The checked state however is not a Boolean but Number 0 or 1. To convert ctrlChecked command output into number as well, use parseNumber command

### Syntax

```sqf
ctrlChecked control
```

```sqf
control ctrlChecked  index
```

### Parameters

- control: Control - CT_CHECKBOXES control. If control contain multiple checkboxes, only checkbox with index 0 is queried.
- control: Control - CT_CHECKBOXES control
- index: Number - checkbox index

### Return Value

- Boolean - true checked, false unchecked
- Boolean - true checked, false unchecked

### Examples

#### Example 1

```sqf
ctrlChecked _control;
```

#### Example 2

```sqf
_control ctrlChecked 3;
```
