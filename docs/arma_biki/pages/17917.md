## getMousePosition

- Source: https://community.bistudio.com/wiki/getMousePosition
- Revision: 378523
- Updated: 2026-05-04T01:55:30Z

- Availability: arma3 1.54
- Groups: GUI Control - Positioning

### Description

Returns mouse position in UI coordinates.

### Syntax

```sqf
getMousePosition
```


### Return Value

- Position2D - x and y UI coordinates of the mouse position

### Examples

#### Example 1

```sqf
getMousePosition params ["_mouseX", "_mouseY"];
```
