## lbSetSelected

- Source: https://community.bistudio.com/wiki/lbSetSelected
- Revision: 352415
- Updated: 2024-02-09T15:26:07Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListBox

### Description

Sets the selection state of the given row of the given listbox of style LB_MULTI.
The command has to be called for every row which is needed to be selected in multi-selection listbox. Use negative index -1 to select/deselect all rows (since 2.12).
For single selection listbox use lbSetCurSel instead.

### Syntax

```sqf
control lbSetSelected [index, selected, forceEH]
```

### Parameters

- control: Control
- index: Number or since 2.12 Array of Numbers
- selected: Boolean
- forceEH: Boolean - (Optional, default false) will force lbSelChanged EH to fire

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control lbSetSelected [0, true];
```
