## ropeDestroy

- Source: https://community.bistudio.com/wiki/ropeDestroy
- Revision: 309944
- Updated: 2022-05-05T12:16:59Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Destroys the given rope. If the rope is attached to a vehicle, it will be detached and then destroyed.

### Syntax

```sqf
ropeDestroy rope
```

### Parameters

- rope: Object - rope object returned by ropeCreate command

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
ropeDestroy myRope;
```
