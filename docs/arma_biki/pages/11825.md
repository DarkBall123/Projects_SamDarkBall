## deActivateKey

- Source: https://community.bistudio.com/wiki/deActivateKey
- Revision: 318885
- Updated: 2022-05-13T09:21:59Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Deactivates the given keyname for the current user profile. The keys are used to unlock missions or campaigns.

See keys, keysLimit and doneKeys in the description.ext file of the missions.

### Syntax

```sqf
deActivateKey keyname
```

### Parameters

- keyname: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
deActivateKey "Mission04Key";
```
