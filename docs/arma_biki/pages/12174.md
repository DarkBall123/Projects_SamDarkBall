## inRangeOfArtillery

- Source: https://community.bistudio.com/wiki/inRangeOfArtillery
- Revision: 347548
- Updated: 2023-09-28T09:25:36Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Artillery

### Description

Returns true if all given units are able to fire at given position with given magazineType.

### Syntax

```sqf
pos inRangeOfArtillery [units, magazineType]
```

### Parameters

- pos: Position
- units: Array of Objects - array of units.
- magazineType: String - **case-sensitive**

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isInRange = getMarkerPos "myTarget" inRangeOfArtillery [[myArty], "32Rnd_155mm_Mo_shells"];
```
