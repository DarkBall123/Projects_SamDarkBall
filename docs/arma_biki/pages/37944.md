## setAngularVelocityModelSpace

- Source: https://community.bistudio.com/wiki/setAngularVelocityModelSpace
- Revision: 377262
- Updated: 2026-01-02T06:33:08Z

- Availability: arma3 2.18
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Sets the angular velocity of the object in model space as a 3D vector. The units are in Rad/s and rotations are clockwise.
Angular velocity is limited to a range of +-1000 Rad/s.

### Syntax

```sqf
obj setAngularVelocityModelSpace vector
```

### Parameters

- obj: Object
- vector: Vector3D - angular velocity of the object in model space

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myHeli setAngularVelocityModelSpace [0,0,1]; // will cause the helicopter to spin around its main rotor shaft
```
