## BIS fnc lowestNum

- Source: https://community.bistudio.com/wiki/BIS_fnc_lowestNum
- Revision: 326955
- Updated: 2022-07-12T21:44:40Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays, Math

### Description

Returns the lowest number out of the passed set.

### Syntax

```sqf
numbers call BIS_fnc_lowestNum
```

### Parameters

- numbers: Array - a set of numbers

### Return Value

- Number - lowest number in the set

### Examples

#### Example 1

```sqf
private _result = [7,2,1,5,10] call BIS_fnc_lowestNum; //_result = 1
```
