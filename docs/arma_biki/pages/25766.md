## matrixMultiply

- Source: https://community.bistudio.com/wiki/matrixMultiply
- Revision: 364807
- Updated: 2024-06-15T13:13:13Z

- Availability: arma3 1.92
- Groups: Math, Math - Vectors

### Description

right|600px
Returns resulting matrix from the [multiplication](https://en.wikipedia.org/wiki/Matrix_multiplication) of two matrices. First matrix must be of the size n × **k**, while the second must be of the size **k** × m, i.e `columns` matrix1 == `rows` matrix2. The resulting matrix will be of the size n × m. If the shapes do not match, empty array [] will be returned.

### Syntax

```sqf
matrix1 matrixMultiply matrix2
```

### Parameters

- matrix1: Array of Array of Numbers - matrix of the size `n`*(rows)* × `k`*(columns)*
- matrix2: Array of Array of Numbers - matrix of the size `k`*(rows)* × `m`*(columns)*

### Return Value

- Array of Array of Numbers - resulting matrix of the size `n`*(rows)* × `m`*(columns)*

### Examples

#### Example 1

```sqf
[
	[2],
	[2]
] 
matrixMultiply 
[
	[3] 
]
/* returns 
[
	[6],
	[6]
] */
```

#### Example 2

```sqf
[
	[-1,0,0],
	[0,-1,0]
] 
matrixMultiply 
[
	[1,2],
	[3,1],
	[2,3]
] 
/* returns 
[
	[-1,-2],
	[-3,-1]
] */
```

```sqf
[[-1,0,0],[0,-1,0],[0,0,-1]] matrixMultiply [1,2,3] // wrong, syntax error
[[-1,0,0],[0,-1,0],[0,0,-1]] matrixMultiply 1,2,3 // wrong, will return []
[[-1,0,0],[0,-1,0],[0,0,-1]] matrixMultiply [[1], [2], [3]] // correct, will return [[-1], [-2], [-3]]
```
