## lnbSetPictureColorRight

- Source: https://community.bistudio.com/wiki/lnbSetPictureColorRight
- Revision: 377730
- Updated: 2026-01-03T00:21:13Z

- Availability: arma3 1.00
- Groups: GUI Control - ListNBox

### Description

Sets color of the right picture in a CT_LISTNBOX.

### Syntax

```sqf
lnbSetPictureColorRight [idc, [row, column], color]
```

```sqf
ctrl lnbSetPictureColorRight [<nowiki/>[row, column], color]
```

### Parameters

- idc: Number
- row: Number - index of the row
- column: Number - index of the column
- color: Color (RGBA)
- ctrl: Control
- row: Number - index of the row
- column: Number - index of the column
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_control lnbSetPictureColorRight [[0, 0], [1,1,1,0.5]];
```
