## getGroupIcons

- Source: https://community.bistudio.com/wiki/getGroupIcons
- Revision: 376588
- Updated: 2025-10-29T23:16:41Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: High Command

### Description

Returns all group icons. Since Arma 3 v2.22 command also returns 3d offsets.

### Syntax

```sqf
getGroupIcons group
```

### Parameters

- group: Group

### Return Value

- Array - id,icon,[offsetx,offsety,offsetX3d,offsetY3d,..]
