## processInitCommands

- Source: https://community.bistudio.com/wiki/processInitCommands
- Revision: 319317
- Updated: 2022-05-13T09:23:52Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00
- Locality: effect global
- Groups: System

### Description

Process statements stored using setVehicleInit. The statements will only be executed once even if processInitCommands is called multiple times.
For security reasons, the command was disabled in Arma 3.

For remote execution, see Arma 3: Remote Execution, remoteExec and remoteExecCall.

### Syntax

```sqf
processInitCommands
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
processInitCommands;
```
