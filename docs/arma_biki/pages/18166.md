## tvSetPictureRightColorSelected

- Source: https://community.bistudio.com/wiki/tvSetPictureRightColorSelected
- Revision: 377791
- Updated: 2026-01-03T01:40:06Z

- Availability: arma3 1.62
- Groups: GUI Control - Tree View

### Description

Sets the color of the right picture of a tree item defined by path when item is selected

### Syntax

```sqf
control tvSetPictureRightColorSelected [path, color]
```

### Parameters

- control: Control
- path: Tree View Path
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control tvSetPictureRightColorSelected [[0], [1,0,1,1]];
```
