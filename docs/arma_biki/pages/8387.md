## progressSetPosition

- Source: https://community.bistudio.com/wiki/progressSetPosition
- Revision: 369221
- Updated: 2024-09-03T10:34:54Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets progress position of a progress bar.

### Syntax

```sqf
control progressSetPosition progress
```

### Parameters

- control: Control - progress bar control
- progress: Number - 0: no progress; 1: full progress

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control progressSetPosition 0.5;
```

#### Example 2

```sqf
with uiNamespace do {
	bar = findDisplay 46 ctrlCreate ["RscProgress", -1];
	bar ctrlSetPosition [0,0,1,0.01];
	bar ctrlCommit 0;
	bar progressSetPosition 0.75;
};
```
