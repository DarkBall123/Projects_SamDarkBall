## lnbAddRow

- Source: https://community.bistudio.com/wiki/lnbAddRow
- Revision: 378642
- Updated: 2026-05-16T15:05:17Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Adds a row of strings.

### Syntax

```sqf
lnbAddRow [ctrl, data]
```

```sqf
ctrl lnbAddRow data
```

### Parameters

- ctrl: Number, Control since 2.22
- data: Array of Strings
- ctrl: Control
- data: Array of Strings

### Return Value

- Number - row index
- Number - row index

### Examples

#### Example 1

```sqf
lnbAddRow [1, ["COL1", "COL2"]];
```

#### Example 2

```sqf
_ctrl lnbAddRow ["COL1", "COL2"];
```
