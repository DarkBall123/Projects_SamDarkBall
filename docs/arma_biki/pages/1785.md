## setMimic

- Source: https://community.bistudio.com/wiki/setMimic
- Revision: 341210
- Updated: 2023-05-13T22:48:34Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Object Manipulation, Unit Identity

### Description

Sets person's facial expression. To set it back to default, use "".
Prior to Arma 3 v2.01.146630 Mimics must be written in all lower case letters.

### Syntax

```sqf
person setMimic mimic
```

### Parameters

- person: Object
- mimic: String - can be one of:
{{{!}} class="valign-top"
! style="padding-right: 2em" {{!}} Before Arma 2 OA v1.6x !! Since Arma 2 OA v1.6x
{{!}}-
{{!}}
* "Default"
* "Normal"
* "Smile"
* "Hurt"
* "Ironic"
* "Sad"
* "Cynic"
* "Surprised"
* {{sic|"Agresive"}}
* "Angry"
{{!}}
* "neutral"
* "dead"
* "danger"
* "hurt"
* "aware"
* "safe"
* "combat"
* "unconscious"
{{!}}}

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldier1 setMimic "hurt";
```
