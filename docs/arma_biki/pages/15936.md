## BIS fnc diagFindMissingAuthors

- Source: https://community.bistudio.com/wiki/BIS_fnc_diagFindMissingAuthors
- Revision: 309317
- Updated: 2022-05-05T12:04:26Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Copies a list of objects to the clipboard which miss the author attribute.

### Syntax

```sqf
call BIS_fnc_diagFindMissingAuthors
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_diagFindMissingAuthors;
```
