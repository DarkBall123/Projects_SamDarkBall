## BIS fnc 3DENFlashlight

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENFlashlight
- Revision: 349107
- Updated: 2023-11-08T14:49:36Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Toggle or set Eden Editor flashlight (light source snapped to the camera).

### Syntax

```sqf
mode call BIS_fnc_3DENFlashlight
```

### Parameters

- mode: Number - can be:
* -2: restore the current mode
* -1: toggle mode
*  0: off
*  1: on

### Return Value

- Number - selected mode

### Examples

#### Example 1

```sqf
private _mode = 0 call BIS_fnc_3DENFlashlight;
```
