## getHit

- Source: https://community.bistudio.com/wiki/getHit
- Revision: 340840
- Updated: 2023-05-10T13:56:15Z

- Availability: arma3 1.32, arma2oa 1.64
- Locality: argument global
- Groups: Object Manipulation

### Description

Returns selection damage. Same as getHitPointDamage, only the argument is selection part instead of hit point.
Some part names are in Czech; see the translation table.

### Syntax

```sqf
vehicle getHit selection
```

### Parameters

- vehicle : Object - vehicle to be queried
- selection: String - selection part name

### Return Value

- Number - before 1.94, Nothing was returned when an invalid *selection* was provided (now returns `0`)

### Examples

#### Example 1

```sqf
hint str (player getHit "head");
```

#### Example 2

```sqf
private _engineDamage = _car getHit "motor";
```
