## ASLToATL

- Source: https://community.bistudio.com/wiki/ASLToATL
- Revision: 377532
- Updated: 2026-01-02T06:53:16Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Positions

### Description

Converts a position from PositionASL to PositionATL

### Syntax

```sqf
ASLToATL pos
```

### Parameters

- pos: PositionASL - position to convert

### Return Value

- PositionATL

### Examples

#### Example 1

```sqf
ASLToATL getPosASL player isEqualTo getPosATL player;
```
