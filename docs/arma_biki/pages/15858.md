## BIS fnc singleMissionName

- Source: https://community.bistudio.com/wiki/BIS_fnc_singleMissionName
- Revision: 327143
- Updated: 2022-07-12T21:45:23Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Missions

### Description

Returns name of currently selected single mission.

### Syntax

```sqf
call BIS_fnc_singleMissionName
```


### Return Value

- String - the mission name

### Examples

#### Example 1

```sqf
private _missionName = call BIS_fnc_singleMissionName;
```
