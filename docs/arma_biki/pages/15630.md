## BIS fnc arrayPushStack

- Source: https://community.bistudio.com/wiki/BIS_fnc_arrayPushStack
- Revision: 327475
- Updated: 2022-07-12T22:13:25Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays

### Description

This function is similar to the array push function; however, it pushes the contents of an array onto the stack array.
Use append or pushBack instead

### Syntax

```sqf
[array1, array2] call BIS_fnc_arrayPushStack
```

### Parameters

- array1: Array
- array2: Array

### Return Value

- Array - the modified *array1*

### Examples

#### Example 1

```sqf
private _array = [0,1,2];
[_array, [3,4,5]] call BIS_fnc_arrayPushStack; // _array is [0,1,2,3,4,5]
```

#### Example 2

```sqf
private _array = [[5, 6, 7], [8, [9], 10]] call BIS_fnc_arrayPushStack; // _array is [5, 6, 7, 8, [9], 10]
```
