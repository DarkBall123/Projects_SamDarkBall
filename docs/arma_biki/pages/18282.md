## weaponInertia

- Source: https://community.bistudio.com/wiki/weaponInertia
- Revision: 378476
- Updated: 2026-04-24T11:32:50Z

- Availability: arma3 1.48
- Groups: Weapons

### Description

Returns current rate of how much the weapon view is distorted because of quick aiming.

### Syntax

```sqf
weaponInertia unit
```

### Parameters

- unit: Object

### Return Value

- Array with [x, y]
* x: Number - Amount of x-axis sway
* y: Number - Amount of y-axis sway

### Examples

#### Example 1

```sqf
_inertia = weaponInertia player; //[-0.0126307,0.038023]
```
