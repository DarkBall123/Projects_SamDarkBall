### Description

thumb|right|An object with its vectorDir, [[vectorUp and vectorSide (vectors not to scale)]]
Returns an object's up vector in world space.

The vector is **not necessarily normalized**. The magnitude of the vector depends on the object's scale.

### Syntax

```sqf
vectorUp object
```

### Parameters

- object: Object

### Return Value

- Vector3D

### Examples

#### Example 1

```sqf
_vecUp = vectorUp MyObject;
```
