## BIS fnc dbValueIndex

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbValueIndex
- Revision: 327204
- Updated: 2022-07-12T22:11:45Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Returns indexes leading to given value.

### Syntax

```sqf
[database, path] call BIS_fnc_dbValueIndex
```

### Parameters

- database - Array: Database array
- path - Array: Path leading to value entry

### Return Value

- Array: List of indexes
