## lnbAddArray

- Source: https://community.bistudio.com/wiki/lnbAddArray
- Revision: 378641
- Updated: 2026-05-16T15:03:10Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Adds list of rows of strings.

### Syntax

```sqf
lnbAddArray [ctrl, arrayOfTextAndValues]
```

### Parameters

- ctrl: Number, Control since 2.22
- arrayOfTextAndValues: Array of Arrays format [[text], [value], [data]]:
* text: String
* value: Number
* data: String

### Return Value

- Number - index

### Examples

#### Example 1

```sqf
lnbAddArray [
	102,
	[
		[
			["#1"],
			[1],
			["#1"]
		],
		[
			["#2"],
			[2],
			["#2"]
		]
	]
];
```
