## windDir

- Source: https://community.bistudio.com/wiki/windDir
- Revision: 321137
- Updated: 2022-05-13T14:31:42Z

- Availability: arma3 0.50
- Groups: Environment

### Description

Returns the current wind azimuth.

### Syntax

```sqf
windDir
```


### Return Value

- Number - azimuth

### Examples

#### Example 1

```sqf
if (windDir < 45 || windDir > 315) then {
	hint "I feel a southern wind"; // wind going from South to North
};
```
