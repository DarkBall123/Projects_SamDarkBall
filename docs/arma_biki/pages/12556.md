## removeWeaponGlobal

- Source: https://community.bistudio.com/wiki/removeWeaponGlobal
- Revision: 373147
- Updated: 2025-04-04T06:15:31Z

- Availability: arma3 0.76
- Locality: argument global, effect global
- Groups: Unit Inventory, Vehicle Inventory

### Description

Remove a weapon from a unit. An attempt to remove a weapon, which is not in unit's possession, is simply ignored.

### Syntax

```sqf
unit removeWeaponGlobal weapon
```

```sqf
object removeWeaponGlobal [weapon, autoselect]
```

### Parameters

- unit: Object - unit or vehicle
- weapon: String - weapon class name
- object: Object - unit or vehicle
- weapon: String - weapon class name
- autoselect: String - (Optional, default true) false to abort weapon autoselection when removing primary weapon.

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
{
	_x removeWeaponGlobal "Laserdesignator";
} forEach allUnits;
```

#### Example 2

```sqf
{
	if (typeOf _x == "O_Heli_Attack_02_black_F") then {
		_x removeWeaponGlobal "rockets_Skyfire";
	};
} forEach vehicles;
```
