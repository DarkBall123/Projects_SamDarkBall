## removeAllCuratorAddons

- Source: https://community.bistudio.com/wiki/removeAllCuratorAddons
- Revision: 348433
- Updated: 2023-11-08T13:00:12Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Restrict access to all addons for given curator.

### Syntax

```sqf
removeAllCuratorAddons curatorObj
```

### Parameters

- curatorObj: Object - curator module

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllCuratorAddons myCurator;
```
