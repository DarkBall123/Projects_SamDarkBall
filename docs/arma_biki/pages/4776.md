## camPrepareFovRange

- Source: https://community.bistudio.com/wiki/camPrepareFovRange
- Revision: 369600
- Updated: 2024-09-26T20:16:06Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Broken Commands, Camera Control

### Description

Prepares the camera field of view range for auto zooming.
This command is **non-functional**!

### Syntax

```sqf
camera camPrepareFovRange [minFovRange, maxFovRange]
```

### Parameters

- camera: Object
- minFovRange: Number
- maxFovRange: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_camera camPrepareFovRange [0.1, 0.5];
```
