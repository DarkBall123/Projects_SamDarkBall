If you for example used this code to add the eventHandler:

```sqf
_myEH = findDisplay 46 displayAddEventHandler ["KeyDown", "hint str _this"];
```

Then later in that same script you can use the

```sqf
_myEH
```

 private variable to remove that same eventHandler again:

```sqf
findDisplay 46 displayRemoveEventHandler ["KeyDown", _myEH];
```

( if obviously that private variable is known to the script environment you are referencing

```sqf
_myEH
```
