## menuSetPicture

- Source: https://community.bistudio.com/wiki/menuSetPicture
- Revision: 378346
- Updated: 2026-04-02T16:31:33Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Sets new picture into menu entry on given path. The picture will be replaced by a tick if the entry was set to checkable with menuSetCheck.

### Syntax

```sqf
menuSetPicture [idc, path, picture]
```

```sqf
control menuSetPicture [path, picture]
```

### Parameters

- idc: Number
- path: Tree View Path
- picture: String
- control: Control
- path: Tree View Path
- picture: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuSetPicture [[0, 1], "\a3\modules_f\data\iconunlock_ca.paa"];
```
