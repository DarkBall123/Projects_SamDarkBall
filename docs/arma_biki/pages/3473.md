## ArmA: Armed Assault: Selection Translations

- Source: https://community.bistudio.com/wiki/ArmA:_Armed_Assault:_Selection_Translations
- Revision: 332485
- Updated: 2022-11-28T16:08:05Z

Some Named Selections require Czech names for them to work.

If, for example, you want to define the source for the left headlight (in the Memory LOD) you would need to name that selection "L svetlo".

To find out which names are required for which object you can either check the Modelling Tutorials or check the CfgVehicles Config Reference directly.
