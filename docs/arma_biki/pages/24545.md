## BIS fnc encodeFlags2

- Source: https://community.bistudio.com/wiki/BIS_fnc_encodeFlags2
- Revision: 337995
- Updated: 2023-02-23T21:11:09Z

- Availability: arma3 1.00
- Groups: Bitwise

### Description

Encodes array of unique binary flags (zeroes or ones) into a single scalar.
{{Feature | important | Note that the input array is in [Big Endian](https://en.wikipedia.org/wiki/Endianness#Definition), meaning that the smallest value is **to the left**.}}

### Syntax

```sqf
arrayOfNumbers call BIS_fnc_encodeFlags2
```

### Parameters

- arrayOfNumbers: Array of Numbers - "boolean" flags where 0 = false and 1 = true

### Return Value

- Number - the calculated number

### Examples

#### Example 1

```sqf
private _result = [1,0,1,1] call BIS_fnc_encodeFlags2;
hint str _result; // Displays 13
```
