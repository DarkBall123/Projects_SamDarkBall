## loadStatus

- Source: https://community.bistudio.com/wiki/loadStatus
- Revision: 319462
- Updated: 2022-05-13T09:24:07Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool, Mission Information

### Description

Loads object's properties from Objects.sav file in campaign directory (from entry name).

### Multiplayer

This command does not work in Multiplayer.

### Syntax

```sqf
object loadStatus  entryName
```

### Parameters

- object: Object
- entryName: String

### Return Value

- Boolean - true if successfull, otherwise false

### Examples

#### Example 1

```sqf
_ok = player loadStatus "playerState";
```
