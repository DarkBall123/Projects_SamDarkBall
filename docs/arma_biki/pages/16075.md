## BIS fnc missionTimeLeft

- Source: https://community.bistudio.com/wiki/BIS_fnc_missionTimeLeft
- Revision: 349227
- Updated: 2023-11-08T14:50:52Z

- Availability: arma3 1.00
- Groups: Missions

### Description

Returns time in seconds until the mission end. Remaining time can be set using estimatedTimeLeft command or using BIS_fnc_countdown.

### Syntax

```sqf
call BIS_fnc_missionTimeLeft
```


### Return Value

- Number - time left

### Examples

#### Example 1

```sqf
call BIS_fnc_missionTimeLeft;
```

### See Also

estimatedTimeLeft BIS_fnc_countdown
