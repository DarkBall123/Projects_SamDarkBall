## getModelInfo

- Source: https://community.bistudio.com/wiki/getModelInfo
- Revision: 352365
- Updated: 2024-02-08T14:09:28Z

- Availability: arma3 1.50
- Groups: Object Manipulation

### Description

Returns object's model info. Model path is suitable for use with createSimpleObject command.

### Syntax

```sqf
getModelInfo object
```

### Parameters

- object: Object

### Return Value

- Array - array in format [modelName, modelPath, hasSkeleton, placingPoint, mass]
* modelName: String - For example "car.p3d"
* modelPath: String - Full path to model. For example: "a3\data\models\car.p3d"
* hasSkeleton: Boolean - Returns whether the model has a skeleton (which usually means it's also animated)
* 2.08 placingPoint: Vector3D - Placing point of the model in model coordinates. Placing point is always in format [0,0,z].
* 2.18 mass: Number - Mass defined in the p3d model

### Examples

#### Example 1

```sqf
_modelInfo = getModelInfo player; // ["b_soldier_03.p3d", "a3\characters_f\blufor\b_soldier_03.p3d", true, [0,0,0]]
```

#### Example 2

```sqf
_modelInfo = getModelInfo cursorObject;
```

#### Example 3

Get Z ASL using placing point:

```sqf
_zASL = (heli modelToWorldWorld (getModelInfo heli select 3)) select 2;
```
