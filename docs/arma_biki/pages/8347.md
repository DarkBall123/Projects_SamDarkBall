### Description

Get the provided unit's current morale level.

### Syntax

```sqf
morale unit
```

### Parameters

- unit: Object

### Return Value

- Number - in range -1..+1

#### Example 1

```sqf
hint format ["Leader's morale: %1", morale leader player];
```
