## shownArtilleryComputer

- Source: https://community.bistudio.com/wiki/shownArtilleryComputer
- Revision: 321212
- Updated: 2022-05-13T15:31:01Z

- Availability: arma3 0.50
- Groups: Artillery

### Description

Checks whether the player has the artillery computer currently open.

### Syntax

```sqf
**shownArtilleryComputer**
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (shownArtilleryComputer) then { hint "Artillery Computer shown on screen"; };
```
