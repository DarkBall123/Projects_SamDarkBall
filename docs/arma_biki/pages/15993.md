## BIS fnc credits movie

- Source: https://community.bistudio.com/wiki/BIS_fnc_credits_movie
- Revision: 328530
- Updated: 2022-07-13T16:47:54Z

- Availability: arma3 1.00
- Groups: GUI

### Description

Movie credits function.

### Syntax

```sqf
[display, mode] call BIS_fnc_credits_movie
```

### Parameters

- display: Display - (Optional) display to use to show the credits
- mode: Number - (Optional, default 0) 0 to start the credits, 1 to end them

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[] spawn BIS_fnc_credits_movie;
```

#### Example 2

Display the credits full screen:

```sqf
[] spawn {
	disableSerialization;
	// create credits
	(findDisplay 46) createDisplay "RscCredits";
	[] call BIS_fnc_credits_movie;
};
```
