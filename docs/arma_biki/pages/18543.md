## ctRemoveHeaders

- Source: https://community.bistudio.com/wiki/ctRemoveHeaders
- Revision: 377178
- Updated: 2026-01-01T10:47:51Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Takes array of header indices as a parameter and removes headers with those indices. Indices of remaining headers will be recomputed.

### Syntax

```sqf
ctrl ctRemoveHeaders indices
```

### Parameters

- ctrl: Control
- indices: Array of Numbers

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctRemoveHeaders [0, 1, 2];
```
