## removeAllItems

- Source: https://community.bistudio.com/wiki/removeAllItems
- Revision: 378942
- Updated: 2026-08-26T10:51:46Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes all special items from the unit.

### Syntax

```sqf
removeAllItems unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllItems unitName;
```
