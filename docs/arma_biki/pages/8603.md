## turretUnit

- Source: https://community.bistudio.com/wiki/turretUnit
- Revision: 377501
- Updated: 2026-01-02T06:49:29Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Turrets

### Description

Returns the unit in the vehicle turret. To find turret path of known unit, see unitTurret.

### Syntax

```sqf
vehicle turretUnit turretPath
```

### Parameters

- vehicle: Object
- turretPath: Turret Path - since 1.58 [-1] (driver) is supported.

### Return Value

- Object

### Examples

#### Example 1

```sqf
_vehicle turretUnit _thisTurret;
```

#### Example 2

```sqf
vehicle player turretUnit [0];
```
