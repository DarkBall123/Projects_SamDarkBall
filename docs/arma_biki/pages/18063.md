## BIS fnc sideIsEnemy

- Source: https://community.bistudio.com/wiki/BIS_fnc_sideIsEnemy
- Revision: 349213
- Updated: 2023-11-08T14:50:48Z

- Availability: arma3 1.56
- Groups: Sides

### Description

Determines if side B is enemy to side A the way the game engine does it. The relationship table can be found here:  Side Relations.

### Syntax

```sqf
[sideA, sideB] call BIS_fnc_sideIsEnemy
```

### Parameters

- sideA: Side
- sideB: Side

### Return Value

- Boolean - true if side B is enemy to side A.

### Examples

#### Example 1

```sqf
private _isEnemy = [west, east] call BIS_fnc_sideIsEnemy; //Checks if EAST is enemy to WEST.
```
