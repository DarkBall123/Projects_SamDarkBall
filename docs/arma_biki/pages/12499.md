## tvCurSel

- Source: https://community.bistudio.com/wiki/tvCurSel
- Revision: 378354
- Updated: 2026-04-02T16:36:18Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Returns path to currently selected item. IDC means id of parent Tree View.

### Syntax

```sqf
tvCurSel idc
```

```sqf
tvCurSel control
```

### Parameters

- idc: Number
- control: Control

### Return Value

- Tree View Path - selected item
- Tree View Path - selected item

### Examples

#### Example 1

```sqf
tvCurSel 101;
```

#### Example 2

```sqf
tvCurSel _ctrl;
```
