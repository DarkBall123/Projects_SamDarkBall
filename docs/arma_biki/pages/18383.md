## getPilotCameraDirection

- Source: https://community.bistudio.com/wiki/getPilotCameraDirection
- Revision: 377256
- Updated: 2026-01-02T06:32:48Z

- Availability: arma3 1.64
- Locality: argument local
- Groups: Pilot Camera

### Description

Returns model space vector of the object airplane or helicopter pilotCamera .

### Syntax

```sqf
getPilotCameraDirection object
```

### Parameters

- object: Object

### Return Value

- Vector3D - relative to the model centre (In a similar fashion to PositionRelative). Returns [0,0,0] if object has no pilotCamera.

### Examples

#### Example 1

```sqf
_pilotCamVector = getPilotCameraDirection vehicle player;
```
