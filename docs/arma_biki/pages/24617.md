## BIS fnc getBorderMarkers

- Source: https://community.bistudio.com/wiki/BIS_fnc_getBorderMarkers
- Revision: 309405
- Updated: 2022-05-05T12:04:36Z

- Availability: arma3 1.78
- Groups: Map and Markers

### Description

Retrieves marker names used in the border restrictions module.

### Syntax

```sqf
call BIS_fnc_getBorderMarkers
```


### Return Value

- Array of Strings - list of markers

### Examples

#### Example 1

```sqf
call BIS_fnc_getBorderMarkers;
```
