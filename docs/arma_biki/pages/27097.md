## setWaypointLoiterAltitude

- Source: https://community.bistudio.com/wiki/setWaypointLoiterAltitude
- Revision: 377129
- Updated: 2026-01-01T10:23:44Z

- Availability: arma3 2.00
- Groups: Waypoints

### Description

Assigns loiter altitude to the provided waypoint.

### Syntax

```sqf
waypoint setWaypointLoiterAltitude loiterAltitude
```

### Parameters

- waypoint: Waypoint
- loiterAltitude: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointLoiterAltitude 100;
```
