## BIS fnc limitSupport

- Source: https://community.bistudio.com/wiki/BIS_fnc_limitSupport
- Revision: 310412
- Updated: 2022-05-05T18:03:14Z

- Availability: arma3 1.00
- Groups: Supports

### Description

Limits support runs during a mission.

### Syntax

```sqf
[module, supportType, quantity] call BIS_fnc_limitSupport
```

### Parameters

- module: Object - the requester module
- supportType: String - can be one of:
* "Artillery"
* "Transport"
* "CAS_Heli"
* "CAS_Bombing"
* "Drop"
- quantity: Number - support run limit. -1 for unlimited support

### Return Value

- Boolean - true when done

### Examples

#### Example 1

```sqf
[reqModule, "Transport", -1] call BIS_fnc_limitSupport;
```
