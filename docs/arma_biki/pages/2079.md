## setWaypointCombatMode

- Source: https://community.bistudio.com/wiki/setWaypointCombatMode
- Revision: 377750
- Updated: 2026-01-03T00:58:04Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Changes a group's combat mode when the waypoint becomes active.

### Syntax

```sqf
waypoint setWaypointCombatMode mode
```

### Parameters

- waypoint: Waypoint
- mode: String - can be:
* "NO CHANGE"
* "BLUE"
* "GREEN"
* "WHITE"
* "YELLOW"
* "RED"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointCombatMode "RED";
```
