## getSubtitleOptions

- Source: https://community.bistudio.com/wiki/getSubtitleOptions
- Revision: 309170
- Updated: 2022-05-03T14:55:20Z

- Availability: arma3 1.94
- Groups: Radio and Chat

### Description

Returns subtitles settings.

### Syntax

```sqf
getSubtitleOptions
```


### Return Value

- Array of Booleans - options in format [subtitlesEnabled, radioSubtitlesEnabled]

### Examples

#### Example 1

```sqf
private _subtitleSettings = getSubtitleOptions;
```
