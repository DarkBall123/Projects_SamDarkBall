## isSimpleObject

- Source: https://community.bistudio.com/wiki/isSimpleObject
- Revision: 310876
- Updated: 2022-05-07T20:24:10Z

- Availability: arma3 1.68
- Groups: Object Manipulation

### Description

Returns true if given object is simple object

### Syntax

```sqf
isSimpleObject object
```

### Parameters

- object: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isSimple = isSimpleObject _obj1;
```
