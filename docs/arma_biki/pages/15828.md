## BIS fnc helicopterType

- Source: https://community.bistudio.com/wiki/BIS_fnc_helicopterType
- Revision: 348739
- Updated: 2023-11-08T14:32:10Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Helicopters

### Description

Returns helicopter type.

### Syntax

```sqf
[object] call BIS_fnc_helicopterType
```

### Parameters

- start: Object - helicopter to be checked.

### Return Value

- Number - one of:
* -1 - Unknown
*  0 - Light
*  1 - Medium
*  2 - Heavy

### Examples

#### Example 1

```sqf
private _helicopterType = [vehicle player] call BIS_fnc_helicopterType;
```
