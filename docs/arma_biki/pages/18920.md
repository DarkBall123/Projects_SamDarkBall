## BIS fnc 3DENExportOldSQM

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENExportOldSQM
- Revision: 342122
- Updated: 2023-07-09T12:26:41Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Export current mission (usually in Eden Editor) in 2D Editor format to the clipboard.

### Syntax

```sqf
call BIS_fnc_3DENExportOldSQM
```


### Return Value

- Nothing - old SQM is copied to the clipboard

### Examples

#### Example 1

See Debug Console

```sqf
call BIS_fnc_3DENExportOldSQM; // execute in debug console
```
