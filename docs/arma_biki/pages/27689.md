## ctrlSetMousePosition

- Source: https://community.bistudio.com/wiki/ctrlSetMousePosition
- Revision: 348960
- Updated: 2023-11-08T14:45:40Z

- Availability: arma3 2.02
- Groups: GUI Control - Positioning

### Description

Similar to setMousePosition but relative to the given control.

### Syntax

```sqf
control ctrlSetMousePosition [x, y]
```

### Parameters

- control: Control
- x: Number - position in x
- y: Number - position in y

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetMousePosition [0.5, 0.5];
```
