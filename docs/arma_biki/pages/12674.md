## simulInClouds

- Source: https://community.bistudio.com/wiki/simulInClouds
- Revision: 378513
- Updated: 2026-05-03T17:21:12Z

- Availability: arma3 1.00
- Groups: Environment

### Description

Returns if given position is in clouds.

### Syntax

```sqf
simulInClouds pos
```

### Parameters

- pos: Position

### Return Value

- Boolean, Nothing - true if given position is in clouds. Nothing if given arguments are incorrect

### Examples

#### Example 1

```sqf
simulInClouds getPos player;
```
