## queryItemsPool

- Source: https://community.bistudio.com/wiki/queryItemsPool
- Revision: 319415
- Updated: 2022-05-13T09:24:03Z

- Availability: arma3 1.12
- Groups: Weapon Pool

### Description

Returns the number of items of type in the weapon pool (used in campaigns to transfer weapons to the next mission).

### Syntax

```sqf
queryItemsPool name
```

### Parameters

- name: String

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _amountOfFAKgiven = queryItemsPool "FirstAidKit";
```
