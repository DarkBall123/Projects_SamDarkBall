## allDead

- Source: https://community.bistudio.com/wiki/allDead
- Revision: 377005
- Updated: 2026-01-01T08:15:58Z

- Availability: arma2oa 1.57, tkoh 1.00, arma3 0.50
- Groups: Object Detection

### Description

Return a list of all dead units including agents and destroyed vehicles. Dead units may be in vehicles.

### Syntax

```sqf
allDead
```


### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
{ deleteVehicle _x } forEach allDead;
```

#### Example 2

allAlive:

```sqf
_all = allUnits + vehicles;
{
	_all pushBack agent _x;
} forEach (agents - [teamMemberNull]);
allAlive = _all - allDead;
```
