## diag activeSQSScripts

- Source: https://community.bistudio.com/wiki/diag_activeSQSScripts
- Revision: 377696
- Updated: 2026-01-02T09:03:19Z

- Availability: arma3 1.44
- Groups: Diagnostic

### Description

Returns array with active SQSs. To see number of all scripts currently in the scheduler use diag_activeScripts.

### Syntax

```sqf
diag_activeSQSScripts
```


### Return Value

- Array with [<nowiki/>[name, fileName, isRunning, currentLine],...]
* name: String - function or file name
* fileName: String
* isRunning: Boolean
* currentLine: Number - line currently executing

### Examples

#### Example 1

```sqf
{ systemChat str _x } forEach diag_activeSQSScripts;
```
