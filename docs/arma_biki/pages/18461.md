## gearIDCAmmoCount

- Source: https://community.bistudio.com/wiki/gearIDCAmmoCount
- Revision: 363874
- Updated: 2024-04-23T21:04:42Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Unit Inventory, GUI Control

### Description

Returns ammo count of assigned magazine.

### Syntax

```sqf
gearIDCAmmoCount idc
```

### Parameters

- idc: Number - idc of control type CT_ITEMSLOT 103

### Return Value

- Number

### Examples

#### Example 1

```sqf
_ammoCount = gearIDCAmmoCount _control;
```
