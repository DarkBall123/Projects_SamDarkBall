## putWeaponPool

- Source: https://community.bistudio.com/wiki/putWeaponPool
- Revision: 310280
- Updated: 2022-05-05T13:11:24Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool

### Description

Transfers weapons and magazines from weapon pool into cargo of given object. Used in campaign to transfer weapons into next mission.

### Syntax

```sqf
putWeaponPool object
```

### Parameters

- object: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
putWeaponPool player;
```
