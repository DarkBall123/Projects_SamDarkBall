### Syntax

```sqf
WFSideText value
```

### Parameters

- value: Object, Group or Side

### Return Value

- String - unlocalized side text value

### Examples

#### Example 1

```sqf
WFSideText player;
```

#### Example 2

```sqf
WFSideText group player;
```

#### Example 3

```sqf
WFSideText west;
```
