## forceWeatherChange

- Source: https://community.bistudio.com/wiki/forceWeatherChange
- Revision: 369386
- Updated: 2024-09-03T18:43:16Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Environment

### Description

Forcibly applies previously set weather settings. Skips smooth transitions. This might cause lag.

To prevent the engine from overwriting custom weather settings, enable the *Manual Control* settings in Eden Editor's intel section.

### Syntax

```sqf
forceWeatherChange
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
0 setOvercast 1;
0 setRain 1;
forceWeatherChange; // Force immediate change overriding smooth transitions
```
