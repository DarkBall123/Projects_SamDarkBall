## cadetMode

- Source: https://community.bistudio.com/wiki/cadetMode
- Revision: 325302
- Updated: 2022-07-10T22:51:20Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Difficulty

### Description

**Prior to Arma 3** it returns if the player is currently playing in cadet or veteran mode.

### Syntax

```sqf
cadetMode
```


### Return Value

- Boolean - true when playing in cadet mode, false when playing in veteran mode

### Examples

#### Example 1

SQS Syntax: <sqs>? (cadetMode) : _AIsoldier setSkill 0.1</sqs>

#### Example 2

SQF Syntax: 

```sqf
if (cadetMode) then { _AIsoldier setSkill 0.1 };
```
