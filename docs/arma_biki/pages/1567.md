## getWPPos

- Source: https://community.bistudio.com/wiki/getWPPos
- Revision: 377567
- Updated: 2026-01-02T06:55:33Z

- Availability: ofp 1.21, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Waypoints

### Description

Returns the position of a selected waypoint of a given group. Waypoints include only those which were placed in the mission editor.

### Syntax

```sqf
getWPPos [groupOrUnit, index]
```

### Parameters

- groupOrUnit: Group or Object - the group (or unit) of which to select a waypoint
- index: Number - 0 equals the starting position of the group.

The number used in this and other waypoint commands is *one more* than the one displayed in the waypoint window in the editor: e.g if the editor labeled a waypoint `"0:MOVE"` then it can be accessed using 

```sqf
getWPPos [grp, 1]
```

### Return Value

- Position3D - the returned position equals [0,0,0] if the selected waypoint does not exist.

### Examples

#### Example 1

```sqf
[_group1, 1] setWPPos [200,600,0];
_pos = getWPPos [_group1, 1]; // returns [200, 600, 0]
```
