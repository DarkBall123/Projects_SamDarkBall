## camSetDir

- Source: https://community.bistudio.com/wiki/camSetDir
- Revision: 377244
- Updated: 2026-01-02T04:23:26Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Camera Control

### Description

Sets the orientation of the given camera in the direction of the given vector. Needs camCommit. Since 0.50, only the second syntax with a Vector3D is available.

### Syntax

```sqf
camera camSetDir azimuth
```

```sqf
camera camSetDir direction
```

### Parameters

- camera: Object - object of type "camera"
- azimuth: Number - camera azimuth
- camera: Object - object of type "camera"
- direction: Vector3D - direction of camera. Must be a valid vector.

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

Since Arma 3:

```sqf
private _pos1 = player modelToWorld [0, 5, 5];
private _pos2 = player modelToWorld [0, 50, 50];

private _cam = "camera" camCreate _pos1;
_cam cameraEffect ["INTERNAL", "BACK"];

_cam camSetPos _pos2;
_cam camSetDir (_pos2 vectorFromTo _pos1);
_cam camCommit 5;
waitUntil { camCommitted _cam };

_cam camSetPos _pos1;
_cam camCommit 5;
```

#### Example 2

Before Arma 3:

```sqf
private _pos1 = player modelToWorld [0, 5, 5];
private _pos2 = player modelToWorld [0, 50, 50];

private _cam = "camera" camCreate _pos1;
_cam cameraEffect ["INTERNAL", "BACK"];

_cam camSetPos _pos2;
_cam camSetDir 180;
_cam camCommit 5;
waitUntil { camCommitted _cam };

_cam camSetPos _pos1;
_cam camCommit 5;
```
