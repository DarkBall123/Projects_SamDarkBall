## rectangular

- Source: https://community.bistudio.com/wiki/rectangular
- Revision: 319430
- Updated: 2022-05-13T09:24:03Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations

### Description

Checks if a location is rectangular (returns true) or elliptical (returns false).

### Syntax

```sqf
rectangular location
```

### Parameters

- location: Location

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isRect = rectangular myLocation;
```
