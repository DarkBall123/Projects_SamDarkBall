### Description

{{{!}} class="float-right valign-top"
{{!}} thumb|120px|#Syntax 2|Syntax 2's distribution
{{!}}  thumb|120px|#Syntax 2|Syntax 2's distribution if *mid* is off-centre
{{!}}}
{{{!}} class="valign-top"
! style="padding-right: 1em; white-space: nowrap" {{!}} #Syntax 1
{{!}} generates a random floating point value
{{!}}-
! style="padding-right: 1em; white-space: nowrap" {{!}} #Syntax 2
{{!}} generates a [Gaussian Distribution](https://en.wikipedia.org/wiki/Normal_distribution)Technically, it is a rescaled https://en.wikipedia.org/wiki/Bates_distribution with n = 4.
The distribution is split in two at its midpoint and scaled linearly such that its maximum lies at the specified midpoint.. It uses the same method as setTriggerTimeout command and is quite useful for e.g spawning loot, making more valuable items more rare
{{!}}-
! style="padding-right: 1em; white-space: nowrap" {{!}} #Syntax 3
{{!}} generates a [seed-based](https://en.wikipedia.org/wiki/Random_seed) random number
{{!}}-
! style="padding-right: 1em; white-space: nowrap" {{!}} #Syntax 4
{{!}} generates a [seed-based](https://en.wikipedia.org/wiki/Random_seed) random noise (**not** Perlin) texture based on provided seed and returning the value at supplied coordinates
{{!}}}

### Syntax

```sqf
random x
```

```sqf
random [min, mid, max]
```

```sqf
seed random x
```

```sqf
seed random [x, y]
```

### Parameters

- x: Number
- min: Number
- mid: Number
- max: Number
- seed: Number - an **integer**. Any float value will be truncated (e.g -0.9, -0.1, 0.1 or 0.9 will be read as **0**)
- x: Number
- seed: Number
- x: Number - x texture position
- y: Number - y texture position

### Return Value

- Number from 0 (included) to *x*, **ex**cluded
{{Feature|important|*x* was accidentally **in**cluded due to a bug introduced in {{GVI|arma2|1.00|size= 0.75}} and fixed in 2.18.}}
- Number in range from *min* to *max*, weighted by *mid* - **can** be higher than max (maximum value is `min + max - mid`)
- Number from 0 (included) to *x* (**in**cluded)
- Number from 0 (included) to 1 (**ex**cluded)

### Examples

#### Example 1

```sqf
_rNumber = random 1;
```

#### Example 2

```sqf
_rNumber = random -10;
```

#### Example 3

Generate a random position inside a circle (see also Example Code: Random Area Distribution)

```sqf
_center getPos [_radius * sqrt random 1, random 360];
```

#### Example 4

Select a random value from an array:

```sqf
_array = ["apples", "pears", "bananas", "M16"];

_random = _array select floor random count _array;	// before {{arma2}}
_random = _array call BIS_fnc_selectRandom;			// since {{arma2}}
_random = selectRandom _array;						// since Arma 3 v1.56
```

{{Note
|user= Hcpookie
|timestamp= 20150712203200
|text= Random selections including negative numbers can be obtained via:

```sqf
_xRnd = round (random 200) - 100;
```

This will yield numbers between -100 and 100.
* Be careful using random numbers in multiplayer, each client will come up with a different result. See multiplayer tutorials for more general information about locality. 
* The number returned is unlikely to be a whole number.

To return a whole number use either **round**, **ceil** or **floor** together with random

```sqf
x = round	(random 5) // will return 0, 1, 2, 3, 4 or 5.	(non-uniform distribution, 0 and 5 are half as likely to be selected than any of the other numbers)
x = floor	(random 5) // will return 0, 1, 2, 3 or 4.		(uniform distribution, all numbers have the same probability of being selected)
x = ceil	(random 5) // will return 0, 1, 2, 3, 4 or 5.	(0 is very unlikely, but possible, as ceil 0 is 0)
```
