## allowSprint

- Source: https://community.bistudio.com/wiki/allowSprint
- Revision: 341801
- Updated: 2023-06-24T08:22:32Z

- Availability: arma3 1.54
- Locality: argument local, effect local
- Groups: Stamina System

### Description

Force player to run/jog if set to false.

### Syntax

```sqf
unit allowSprint  state
```

### Parameters

- unit: Object
- state: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player allowSprint false;
```
