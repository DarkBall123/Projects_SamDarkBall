## BIS fnc paramIn

- Updated: 2022-07-13T11:38:41Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Arrays

### Description

See BIS_fnc_param.
Overloading default values is disabled in this variant.
It's intended to be used where _this is not used as an input param.

```sqf
See BIS_fnc_param
```
