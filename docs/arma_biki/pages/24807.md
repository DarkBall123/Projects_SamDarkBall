## BIS fnc reviveBleedOut

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveBleedOut
- Revision: 349293
- Updated: 2023-11-08T14:52:16Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Make a unit bleed out over time while incapacitated.

### Syntax

```sqf
[player] call BIS_fnc_reviveBleedOut
```

### Parameters

- player: Object - unit that is bleeding out

### Return Value

- Boolean - returns true if successful, false is not

### Examples

#### Example 1

```sqf
[BIS_unit] call BIS_fnc_reviveBleedOut;
```
