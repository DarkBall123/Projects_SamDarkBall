## BIS fnc unitCaptureFiring

- Source: https://community.bistudio.com/wiki/BIS_fnc_unitCaptureFiring
- Revision: 336358
- Updated: 2022-12-29T08:47:04Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Scenes

### Description

Records weapon fire data of input unit over a specified period of time. Pressing the {{Controls|ESC}} key, the duration ending, or the unit dying ends the recording.

### Syntax

```sqf
[unit, duration, startTime] spawn BIS_fnc_unitCaptureFiring
```

### Parameters

- unit: Object - unit to capture weapon fire data from
- duration: Number - maximum duration to capture
- startTime: Number - (Optional, default 0) starting time offset for the frame time

### Return Value

- Script Handle

### Examples

#### Example 1

```sqf
[BIS_Vehicle, 50, 10] spawn BIS_fnc_unitCaptureFiring;
```

#### Example 2

```sqf
[[2.135, "GAU8", "<NULL-object>"], [2.157, "GAU8", "<NULL-object>"]] // output example
```
