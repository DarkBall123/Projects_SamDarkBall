## BIS fnc magnitude

- Source: https://community.bistudio.com/wiki/BIS_fnc_magnitude
- Revision: 349333
- Updated: 2023-11-08T14:53:28Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Vectors

### Description

Returns the magnitude of an array of numbers. The vector can have any number of elements. Use vectorMagnitude instead

### Syntax

```sqf
vector call BIS_fnc_magnitude
```

### Parameters

- vector: Array - vector

### Return Value

- Array - new vector

### Examples

#### Example 1

```sqf
[5,3] call BIS_fnc_magnitude;
```
