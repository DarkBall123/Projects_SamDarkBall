## BIS fnc curatorHint

- Source: https://community.bistudio.com/wiki/BIS_fnc_curatorHint
- Revision: 347964
- Updated: 2023-11-08T08:50:05Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Show hint in curator interface.

### Syntax

```sqf
[title, text, duration] call BIS_fnc_curatorHint
```

### Parameters

- title: String
- text: String
- duration: Number - (Optional, default 30) duration in seconds

### Return Value

- Control - UI control of the hint text

### Examples

#### Example 1

```sqf
["Title", "Some text", 1337] call BIS_fnc_curatorHint;
```
