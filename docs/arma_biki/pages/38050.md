## gameValueToJson

- Source: https://community.bistudio.com/wiki/gameValueToJson
- Revision: 351579
- Updated: 2023-12-07T17:38:47Z

- Availability: argo 1.00
- Groups: Argo

### Description

Generate a JSON string from the provided array values.

### Syntax

```sqf
gameValueToJson data
```

### Parameters

- data: Array of Arrays format [<nowiki/>[key, value], [key, value], ...]

### Return Value

- String - a JSON string or an empty string if *data* is not an array

### Examples

#### Example 1

```sqf
_json = gameValueToJson [["ID", 42], ["Message", "Hello there!"], ["HasHighGround", true]];
```

result:

```
{
	"ID": 42,
	"Message": "Hello there!",
	"HasHighGround": true
}
```
