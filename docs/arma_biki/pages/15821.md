## BIS fnc titleText

- Source: https://community.bistudio.com/wiki/BIS_fnc_titleText
- Revision: 349598
- Updated: 2023-11-14T13:35:38Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Display given string as structured text. In Arma 3 this function displays a bottom-left message, limited to two lines of approximately 53 characters each.

### Syntax

```sqf
message call BIS_fnc_titleText
```

### Parameters

- message: String - Structured Text formatting supported

### Return Value

- Boolean - true when done

### Examples

#### Example 1

right|300px

```sqf
"Stratis, 2035-07-14 0130
A dark night ahead…" call BIS_fnc_titleText;
```
