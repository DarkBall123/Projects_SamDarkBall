## queryWeaponPool

- Source: https://community.bistudio.com/wiki/queryWeaponPool
- Revision: 323019
- Updated: 2022-06-28T21:43:07Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool

### Description

Return number of weapons of type name in weapon pool (used in campaign to transfer weapons into next mission).

### Syntax

```sqf
queryWeaponPool name
```

### Parameters

- name: String

### Return Value

- Number

### Examples

#### Example 1

```sqf
_num = queryWeaponPool "M16";
```
