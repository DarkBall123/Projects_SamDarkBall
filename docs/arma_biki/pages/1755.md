## shownRadio

- Source: https://community.bistudio.com/wiki/shownRadio
- Revision: 353339
- Updated: 2024-03-15T17:11:51Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Interaction, Radio and Chat

### Description

Check if player has Radio enabled.
This command exists in Arma 3 but doesn't do much

### Syntax

```sqf
**shownRadio**
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (shownRadio) then {hint "You have Radio enabled."};
```
