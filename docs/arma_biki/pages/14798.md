## waypointTimeoutCurrent

- Source: https://community.bistudio.com/wiki/waypointTimeoutCurrent
- Revision: 319799
- Updated: 2022-05-13T09:25:29Z

- Availability: arma3 1.08
- Groups: Waypoints

### Description

Gets the current timeout for currentWaypoint of a group or -1 if countdown is not in progress.

### Syntax

```sqf
waypointTimeoutCurrent group
```

### Parameters

- group: Group

### Return Value

- Number

### Examples

#### Example 1

```sqf
_timeout = waypointTimeoutCurrent group player;
```
