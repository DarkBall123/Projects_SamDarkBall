## BIS fnc textureMarker

- Source: https://community.bistudio.com/wiki/BIS_fnc_textureMarker
- Revision: 327439
- Updated: 2022-07-12T22:12:09Z

- Availability: arma3 1.00
- Groups: Map and Markers

### Description

Checks whether texture is defined in CfgMarkers and if so, returns the marker texture.

### Syntax

```sqf
[wantedMarker] call BIS_fnc_textureMarker
```

### Parameters

- wantedMarker: String - marker type

### Return Value

- String - icon texture path, or *wantedMarker* if not found

### Examples

#### Example 1

```sqf
private _notWhiteFlag = ["flag_France"] call BIS_fnc_textureMarker;
```
