## ctrlSetFontHeightH5

- Source: https://community.bistudio.com/wiki/ctrlSetFontHeightH5
- Revision: 323046
- Updated: 2022-06-28T21:43:09Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H5 font size of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontHeightH5 height
```

### Parameters

- controlName: Control
- height: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontHeightH5 0.05;
```
