## sendTask

- Source: https://community.bistudio.com/wiki/sendTask
- Revision: 330641
- Updated: 2022-10-03T11:04:22Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing, Teams

### Description

Create a new AI task (subtask of parentTask). Type is name of registered task type.

### Syntax

```sqf
sender sendTask [receiver,[type] or [type,parentTask],priority,name1,value1,name2,value2,...]
```

### Parameters

- sender:  Team Member
- [receiver,[type] or [type,parentTask],priority,name1,value1,name2,value2,...]: Array

### Return Value

- Task
