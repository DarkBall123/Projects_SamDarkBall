## velocity

- Source: https://community.bistudio.com/wiki/velocity
- Revision: 377249
- Updated: 2026-01-02T06:14:11Z

- Availability: ofp 1.80, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns the velocity of the object as vector in m/s.

### Syntax

```sqf
velocity object
```

### Parameters

- object: Object

### Return Value

- Vector3D

### Examples

#### Example 1

```sqf
_vector = velocity jeep;
```

#### Example 2

```sqf
if ((velocity _plane1 select 2) > 50) then { hint "Aircraft is climbing up too fast!"; };
```
