## setObjectMaterialGlobal

- Source: https://community.bistudio.com/wiki/setObjectMaterialGlobal
- Revision: 370027
- Updated: 2024-10-27T23:19:13Z

- Availability: arma3 1.54
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Set the material of the given selection on all computers in a network session.

### Syntax

```sqf
obj setObjectMaterialGlobal [selection, material]
```

### Parameters

- obj: Object
- selection: Number or 2.10 String
- material: String - material path. Since 2.20 using **"#reset"** would reset to default material.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setObjectMaterialGlobal [0, "A3\Structures_F\Data\Windows\window_set.rvmat"];
```
