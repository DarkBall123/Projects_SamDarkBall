## taskName

- Source: https://community.bistudio.com/wiki/taskName
- Revision: 310323
- Updated: 2022-05-05T16:32:29Z

- Availability: arma3 2.04
- Groups: Briefing

### Description

Returns the name of the given task.

### Syntax

```sqf
taskName task
```

### Parameters

- task: Task

### Return Value

- String - task name

### Examples

#### Example 1

```sqf
private _taskName = taskName _mytask;
```
