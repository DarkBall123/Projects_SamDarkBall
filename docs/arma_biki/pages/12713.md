### Description

Removes item from soldier's backpack.

### Syntax

```sqf
unit removeItemFromBackpack item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

```sqf
player removeItemFromBackpack "itemGPS";
```
