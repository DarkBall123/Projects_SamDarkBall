## waypointCompletionRadius

- Source: https://community.bistudio.com/wiki/waypointCompletionRadius
- Revision: 377743
- Updated: 2026-01-03T00:57:53Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Gets the radius around the waypoint where the waypoint is completed.

### Syntax

```sqf
waypointCompletionRadius waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- Number

### Examples

#### Example 1

```sqf
_radius = waypointCompletionRadius [groupOne, 1];
```
