## curatorSelected

- Source: https://community.bistudio.com/wiki/curatorSelected
- Revision: 377660
- Updated: 2026-01-02T09:02:11Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns list of all curator selected items.

### Syntax

```sqf
curatorSelected
```


### Return Value

- Array with [objects, groups, waypoints, markers]
* objects: Array of Objects
* groups: Array of Groups
* waypoints: Waypoint
* markers: Array of Strings

### Examples

#### Example 1

```sqf
_selectedItems = curatorSelected;
```

#### Example 2

```sqf
curatorSelected params ["_selObjects", "_selGroups", "_selWaypoints", "_selMarkers"];
```
