## enableEnvironment

- Source: https://community.bistudio.com/wiki/enableEnvironment
- Revision: 349663
- Updated: 2023-11-18T17:02:32Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Environment, Sounds

### Description

Enable/disable environmental effects: ambient life and/or ambient sound.

This command has to be executed after mission start: be sure to use e.g 

```sqf
sleep 0.1;
```

 for it to take effect.
Influenced sounds among others are:
{{Columns|2|
* bird sounds
* insect sounds
* waves
* wind
* rain
* sounds produced by air conditioners and similar
}}
* 2.06 thunder (an already started sound will not be cut but future ones will be prevented)

### Syntax

```sqf
enableEnvironment enable
```

```sqf
enableEnvironment [ambientLife, ambientSound, windyCoef]
```

### Parameters

- enable: Boolean - false to disable ambient life and ambient sounds, true to re-enable it
- ambientLife: Boolean - enable/disable ambient life (bees, rabbits, birds, snakes, fish)
- ambientSound: Boolean - enable/disable ambient sounds (cicadas, owls, etc)
- windyCoef: Number - (Optional, default 1) howling wind at heights, range 0..1

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
enableEnvironment false; // identical to enableEnvironment [false, false]
```

#### Example 2

```sqf
enableEnvironment [false, true];
enableEnvironment [false, true, 0.5]; // since Arma 3 v2.12
```
