## BIS fnc carAlarm

- Source: https://community.bistudio.com/wiki/BIS_fnc_carAlarm
- Revision: 327206
- Updated: 2022-07-12T22:11:45Z

- Availability: arma3 1.76
- Groups: Object Manipulation

### Description

Play car alarm effect.

### Syntax

```sqf
[mode, car] call BIS_fnc_carAlarm
```

### Parameters

- mode: String - can be one of:
* "init": add "Hit" and "GetIn" event handler on the car
* "play": play the alarm effect
- car: Object - vehicle protected by alarm

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["init", myCar] call BIS_fnc_carAlarm;
```
