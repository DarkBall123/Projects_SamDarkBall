## soundVolume

- Source: https://community.bistudio.com/wiki/soundVolume

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Sounds

### Description

Returns the current sound volume (set by fadeSound).

### Syntax

```sqf
**soundVolume**
```


### Return Value

- Number in range 0..1

### Examples

#### Example 1

```sqf
hint str soundVolume;
```
