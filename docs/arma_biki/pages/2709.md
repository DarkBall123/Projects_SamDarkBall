## from

- Revision: 311162
- Updated: 2022-05-12T09:47:42Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Continue sequence of for construct. It sets the start value of the index variable.

### Syntax

```sqf
for from b
```

### Parameters

- for: For Type
- b: Number

### Return Value

- For Type

### Examples

#### Example 1

```sqf
for "_i" from 10 to 20 do
{
	hint str _i; // will hint from 10 to 20, spaced by 1 second
	sleep 1;
};
```
