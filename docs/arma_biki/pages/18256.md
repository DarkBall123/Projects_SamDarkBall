## ctrlSetFontHeightSecondary

- Source: https://community.bistudio.com/wiki/ctrlSetFontHeightSecondary
- Revision: 297936
- Updated: 2022-01-20T13:02:47Z

- Availability: arma3 1.62
- Locality: effect local
- Groups: GUI Control

### Description

Sets the font size of the secondary text of given control.

### Syntax

```sqf
ctrl ctrlSetFontHeightSecondary value
```

### Parameters

- ctrl: Control
- value: Number

### Return Value

- Nothing

### Examples

#### Example 1

_control ctrlSetFontHeightSecondary 0.05;

### See Also

ctrlSetFontP ctrlSetFontSecondary
