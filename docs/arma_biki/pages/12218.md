## stance

- Source: https://community.bistudio.com/wiki/stance
- Revision: 363221
- Updated: 2024-03-25T22:48:35Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Unit Control

### Description

Returns the stance of the given unit.

### Syntax

```sqf
stance unit
```

### Parameters

- unit: Object

### Return Value

- String - can be:
* `"STAND"`
* `"CROUCH"`
* `"PRONE"`
* `"UNDEFINED"` (for example, swimming)
* `""` (on non-person object)

### Examples

#### Example 1

```sqf
if (stance player == "STAND") then { hint "I am standing!" };
```
