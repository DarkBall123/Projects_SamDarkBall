## AGLToASL

- Source: https://community.bistudio.com/wiki/AGLToASL
- Revision: 377450
- Updated: 2026-01-02T06:47:08Z

- Availability: arma3 1.50
- Groups: Positions

### Description

Converts position from PositionAGL to PositionASL.

### Syntax

```sqf
AGLToASL posAGL
```

### Parameters

- posAGL: PositionAGL - position to convert

### Return Value

- PositionASL

### Examples

#### Example 1

```sqf
_playerPosASL = AGLToASL (player modelToWorld [0,0,0]);
```

#### Example 2

```sqf
_camPosASL = AGLToASL positionCameraToWorld [0,0,0];
```
