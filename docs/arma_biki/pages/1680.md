## closeDialog

- Source: https://community.bistudio.com/wiki/closeDialog
- Revision: 349590
- Updated: 2023-11-11T22:42:19Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control

### Description

Closes the currently active dialog with exit code. It does not instantly close the dialog but does it on next simulation cycle. Most common exit codes are:

```
#define IDC_OK		1 // emulate "OK" button
#define IDC_CANCEL	2 // emulate "Cancel" button
```

### Syntax

```sqf
closeDialog  exitcode
```

### Parameters

- exitcode: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
closeDialog 2;
```

#### Example 2

```sqf
#define IDC_CANCEL 2
closeDialog IDC_CANCEL;
```
