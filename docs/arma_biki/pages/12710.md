## canAddItemToBackpack

- Source: https://community.bistudio.com/wiki/canAddItemToBackpack
- Revision: 369124
- Updated: 2024-09-03T10:33:08Z

- Availability: arma3 1.04
- Groups: Containers

### Description

Checks if given object can be stored into soldier's backpack.

Avoid passing an empty string 

```sqf
""
```

 to this command as it will create a warning dialog:
none|alt= Warning Message: Bad vehicle type|Warning Message: Bad vehicle type
This message will show once per mission restart.

### Syntax

```sqf
unit canAddItemToBackpack item
```

```sqf
unit canAddItemToBackpack [item, count, ignoreSoldierMaxLoad]
```

### Parameters

- unit: Object
- item: String
- unit: Object
- item: String
- count: Number
- ignoreSoldierMaxLoad: Boolean - (Optional, default false) true to ignore 'soldierMaxLoad' param, container maxLoad is still counted.

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
if (player canAddItemToBackpack "HandGrenade") then { player addItemToBackpack _item } else { hint "no room!" };
```

```sqf
player canAddItemToBackpack "5Rnd_127x108_APDS_Mag"
```
