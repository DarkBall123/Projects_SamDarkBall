## tvSetColor

- Source: https://community.bistudio.com/wiki/tvSetColor
- Revision: 378383
- Updated: 2026-04-04T04:48:24Z

- Availability: arma3 0.74
- Groups: GUI Control - Tree View

### Description

Sets text color on given Tree View Item

### Syntax

```sqf
tvSetColor [idc, path, color]
```

```sqf
control tvSetColor [path, color]
```

### Parameters

- idc: Number
- path: Tree View Path
- color: Color (RGBA)
- control: Control
- path: Tree View Path
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvSetColor [101, [0,0], [1,0,0,1]];
```

#### Example 2

```sqf
_ctrl tvSetColor [[0,0], [1,0,0,1]];
```
