## ctrlSetFontPB

- Source: https://community.bistudio.com/wiki/ctrlSetFontPB
- Revision: 323083
- Updated: 2022-06-28T21:43:13Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets P bold font of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontPB fontName
```

### Parameters

- controlName: Control
- fontName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontPB "TahomaB";
```
