## BIS fnc deleteVehicleCrew

- Source: https://community.bistudio.com/wiki/BIS_fnc_deleteVehicleCrew
- Revision: 327416
- Updated: 2022-07-12T22:11:59Z

- Availability: arma3 1.00
- Groups: Vehicles

### Description

Deletes specific crew member directly from the vehicle.

### Syntax

```sqf
[vehicle, crewMember] call BIS_fnc_deleteVehicleCrew
```

### Parameters

- vehicle: Object
- crewMember: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_tank, gunner BIS_tank] call BIS_fnc_deleteVehicleCrew;
```
