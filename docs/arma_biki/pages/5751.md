## titleFadeOut

- Source: https://community.bistudio.com/wiki/titleFadeOut
- Revision: 369166
- Updated: 2024-09-03T10:34:41Z

- Availability: arma1 1.05, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Terminate the title effect and set duration of the fade out phase to the given time. Same as cutFadeOut but for the title layer.

### Syntax

```sqf
titleFadeOut duration
```

### Parameters

- duration: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
titleText ["Hi", "plain"];
titleFadeOut 2;
```
