## mineDetectedBy

- Source: https://community.bistudio.com/wiki/mineDetectedBy
- Revision: 378787
- Updated: 2026-06-05T12:20:54Z

- Availability: arma3 1.24
- Groups: Mines

### Description

Returns true if mine has been detected by a given side

### Syntax

```sqf
mine mineDetectedBy side
```

### Parameters

- mine: Object
- side: Side

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (_myMine mineDetectedBy opfor) then
{
	hint "Children yearn for the mines";
};
```
