## BIS fnc reviveIconControl

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveIconControl
- Revision: 348857
- Updated: 2023-11-08T14:39:13Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Manage the adding, removing, and effects applied to 3D icons used for visualizing incapacitated units.

### Syntax

```sqf
[mode, unitVar] call BIS_fnc_reviveIconControl
```

### Parameters

- mode: String - mode
- unitVar: String - (Optional, default "") unit variable

### Return Value

- Boolean - true if successful, false if not
