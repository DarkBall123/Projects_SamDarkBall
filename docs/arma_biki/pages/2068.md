### Syntax

```sqf
unitName setUnitRank rank
```

### Parameters

- unitName: Object
- rank: String - see above. If a wrong string is provided, the command errors and reverts to using "PRIVATE"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setUnitRank "COLONEL";
```
