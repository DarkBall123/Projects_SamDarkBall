## setWPPos

- Groups: Waypoints

### Description

Sets waypoint position.
This command is identical to 

```sqf
setWaypointPosition [pos, -1]
```

 (see setWaypointPosition description for more information).

### Syntax

```sqf
waypoint setWPPos pos
```

### Parameters

- waypoint: Waypoint
- pos: PositionAGL

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_groupOne, 1] setWPPos markerPos "MarkerOne";
```
