## setBatteryRTD

- Source: https://community.bistudio.com/wiki/setBatteryRTD
- Revision: 377782
- Updated: 2026-01-03T01:32:39Z

- Availability: tkoh 1.00
- Groups: RTD

### Description

Toggle a helicopter's electrical systems on and off.

### Syntax

```sqf
helicopterRTD setBatteryRTD enable
```

### Parameters

- helicopterRTD : ObjectRTD - helicopter
- enable : Boolean - on or off

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
(vehicle player) setBatteryRTD false;
```
