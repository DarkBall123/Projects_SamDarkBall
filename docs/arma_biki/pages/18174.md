## removeAllOwnedMines

- Source: https://community.bistudio.com/wiki/removeAllOwnedMines
- Revision: 310204
- Updated: 2022-05-05T13:10:41Z

- Availability: arma3 1.62
- Groups: Mines

### Description

Removes ownership of all owned mines/explosive devices of the given unit

### Syntax

```sqf
removeAllOwnedMines unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllOwnedMines player;
```
