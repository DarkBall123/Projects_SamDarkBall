## BIS fnc dbValueCheck

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbValueCheck
- Revision: 327201
- Updated: 2022-07-12T22:11:45Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Check if value exists in Scripted Database.

### Syntax

```sqf
[database, path] call BIS_fnc_dbValueCheck
```

### Parameters

- database - Array: Database array
- path - Array: Path to value

### Return Value

- Boolean: True when value exists

### Examples

#### Example 1

```sqf
"#MILLER", ["&KILLS", 1000, "&RANK", "CAPTAIN"] call BIS_fnc_dbValueCheck; // true
```
