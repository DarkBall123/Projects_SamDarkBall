## sliderPosition

- Source: https://community.bistudio.com/wiki/sliderPosition
- Revision: 310899
- Updated: 2022-05-07T20:31:43Z

- Availability: ofp 1.85, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns current thumb position of CT_SLIDER or CT_XSLIDER with given idc of topmost user dialog.

### Syntax

```sqf
sliderPosition idc
```

```sqf
sliderPosition control
```

### Parameters

- idc: Number
- control: Control

### Return Value

- Number
- Number

### Examples

#### Example 1

```sqf
_slidepos1 = sliderPosition 105;
```
