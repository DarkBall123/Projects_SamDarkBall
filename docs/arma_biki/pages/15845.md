## BIS fnc onEnd

- Source: https://community.bistudio.com/wiki/BIS_fnc_onEnd
- Revision: 329730
- Updated: 2022-08-03T13:27:33Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Event Handlers

### Description

Register code to be executed after mission end.
Replaced by "Ended" mission event handler.

This function now exists only because of backward compatibility.

### Syntax

```sqf
argument call BIS_fnc_onEnd
```

### Parameters

- argument: Code, Array or Number:
* Code - code to be executed
* Array - code with arguments in format [code, arguments]
* Number - remove code at given index

### Return Value

- Number - index of onEnd code

### Examples

#### Example 1

```sqf
private _onEndIndex = { player addRating 10000; } call BIS_fnc_onEnd;
```

#### Example 2

```sqf
private _onEndIndex = [{ { _x addRating 10000; } forEach _this; }, units group player] call BIS_fnc_onEnd;
```
