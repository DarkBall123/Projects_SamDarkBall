## isText

- Source: https://community.bistudio.com/wiki/isText
- Revision: 321182
- Updated: 2022-05-13T15:18:34Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Config

### Description

Checks if config entry represents a text value.

### Syntax

```sqf
isText  config
```

### Parameters

- config: Config

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isText = isText (configFile >> "CfgVehicles") // false
```

#### Example 2

```sqf
_isText = isText (configFile >> "CfgVehicles" >> "B_MRAP_01_F" >> "displayName") // true
```
