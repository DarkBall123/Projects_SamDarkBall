## BIS fnc timeline setLength

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_setLength
- Revision: 348093
- Updated: 2023-11-08T11:31:32Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Set's the length of this timeline in seconds.

### Syntax

```sqf
[timeline, length] call BIS_fnc_timeline_setLength
```

### Parameters

- timeline: Object - the timeline object
- length: Number - (Optional, default 10) new length

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[timeline,5.5] call BIS_fnc_timeline_setLength;
```
