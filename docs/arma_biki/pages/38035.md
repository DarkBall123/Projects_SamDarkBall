## get3DENMissionAttributes

- Source: https://community.bistudio.com/wiki/get3DENMissionAttributes
- Revision: 373745
- Updated: 2025-06-24T21:49:17Z

- Availability: arma3 2.18
- Groups: Eden Editor

### Description

Retrieve all attributes and their values from the specified section/category (category is optional).

### Syntax

```sqf
section get3DENMissionAttributes category
```

### Parameters

- section: String
- category: String Category name or `""` to return all attributes

### Return Value

- Array

### Examples

#### Example 1

```sqf
private _result = "Multiplayer" get3DENMissionAttributes "";
```
