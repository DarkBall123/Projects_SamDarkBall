## curatorRegisteredObjects

- Source: https://community.bistudio.com/wiki/curatorRegisteredObjects
- Revision: 377172
- Updated: 2026-01-01T10:45:58Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns array with all objects that has curator registered and their settings.

### Syntax

```sqf
curatorRegisteredObjects curator
```

### Parameters

- curator: Object - curator module

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
curatorRegisteredObjects _curatorModule;
```
