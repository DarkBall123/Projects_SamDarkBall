## setVelocityModelSpace

- Source: https://community.bistudio.com/wiki/setVelocityModelSpace
- Revision: 377260
- Updated: 2026-01-02T06:33:01Z

- Availability: arma3 1.68
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Sets the velocity (i.e. speed) vector of the given vehicle relative to its model.

Since 2.06, each velocity component is limited to ±5000 m/s.

### Syntax

```sqf
vehicle setVelocityModelSpace velocity
```

### Parameters

- vehicle: Object
- velocity: Vector3D - relative velocity vector

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
MyCar setVelocityModelSpace [0, 10, 0]; // Pushes MyCar forward.
```
