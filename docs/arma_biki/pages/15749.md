## BIS fnc spotter

- Source: https://community.bistudio.com/wiki/BIS_fnc_spotter
- Revision: 341832
- Updated: 2023-06-28T09:26:11Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation, Combat

### Description

Make spotter report target distance to sniper. Will only stop if one of the two units dies.

### Syntax

```sqf
[sniper, spotter] spawn BIS_fnc_spotter
```

### Parameters

- sniper: Object - sniper unit
- spotter: Object - spotter unit

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, spotter] spawn BIS_fnc_spotter;
```
