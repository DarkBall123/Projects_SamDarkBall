## BIS fnc wpHover

- Source: https://community.bistudio.com/wiki/BIS_fnc_wpHover
- Revision: 349358
- Updated: 2023-11-08T15:35:09Z

- Availability: tkoh 1.00
- Groups: Waypoints

### Description

HOVER custom waypoint.
Hover on specific spot.

### Syntax

```sqf
Custom Waypoint arguments: [minTime, reset, altDiff, visualize]
```

### Parameters

- minTime: Number - what time in seconds must be spent hovering before completion
- reset: Boolean - reset the timer every time you fail hovering
- altDiff: Number - how far from the waypoint height must you hover (-1: altitude does not matter, only completionRadius does) (default: -1)
- visualize: Boolean - true to show hint (default: false)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, position dude, 10, 10, false, -1, true] spawn BIS_fnc_wpLand;
```
