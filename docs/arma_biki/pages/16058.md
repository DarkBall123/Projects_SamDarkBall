## BIS fnc disableSaving

- Source: https://community.bistudio.com/wiki/BIS_fnc_disableSaving
- Revision: 349305
- Updated: 2023-11-08T14:52:21Z

- Availability: arma3 1.00
- Groups: Missions

### Description

Controls the disabling of saving, stacking each request to prevent saving being enabled too early.

### Syntax

```sqf
id call BIS_fnc_disableSaving
```

### Parameters

- id: String - unique id to be used with BIS_fnc_enableSaving

### Return Value

- Boolean - true if successful, false if not

### Examples

#### Example 1

```sqf
"savingID" call BIS_fnc_disableSaving;
```
