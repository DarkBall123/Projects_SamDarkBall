## BIS fnc titlecard

- Source: https://community.bistudio.com/wiki/BIS_fnc_titlecard
- Revision: 348972
- Updated: 2023-11-08T14:45:44Z

- Availability: arma3 1.00
- Groups: GUI

### Description

Display a mission-specific titlecard before the mission begins. Only works the first time it is called.

### Syntax

```sqf
[path, subtitle] call BIS_fnc_titlecard
```

### Parameters

- path: String - path to video
- subtitle: String - (Optional, default "") subtitle displayed

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
["\a3\missions_f_epb\video\b_out2_quotation.ogv", "your translation"] call BIS_fnc_titlecard;
```
