## getEnvSoundController

- Source: https://community.bistudio.com/wiki/getEnvSoundController
- Revision: 319197
- Updated: 2022-05-13T09:23:21Z

- Availability: arma3 1.64
- Groups: Sounds

### Description

Returns value of the specified controller, see getAllEnvSoundControllers

### Syntax

```sqf
position getEnvSoundController controller
```

### Parameters

- position: Position
- controller: String - name of environmental variable like "trees" or "houses"

### Return Value

- Number

### Examples

#### Example 1

```sqf
position player getEnvSoundController "trees"; //0.3333
```
