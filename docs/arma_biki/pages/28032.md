## lnbTextRight

- Source: https://community.bistudio.com/wiki/lnbTextRight
- Revision: 348794
- Updated: 2023-11-08T14:33:18Z

- Availability: arma3 1.00
- Groups: GUI Control - ListNBox

### Description

Returns CT_LISTNBOX's right aligned cell text.

### Syntax

```sqf
lnbTextRight [idc, [row, column]]
```

```sqf
ctrl lnbTextRight [row, column]
```

### Parameters

- idc: Number
- row: Number - index of the row
- column: Number - index of the column
- ctrl: Control
- row: Number - index of the row
- column: Number - index of the column

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
_text = _control lnbTextRight [0, 0];
```
