## ctrlSetURLOverlayMode

- Source: https://community.bistudio.com/wiki/ctrlSetURLOverlayMode
- Revision: 376033
- Updated: 2025-07-22T09:12:10Z

- Availability: arma3 2.10
- Groups: GUI Control

### Description

Sets how to handle opening of URL, default browser or Steam overlay. Possible values:
* 0 - default browser
* 1 - Steam overlay if enabled, otherwise default browser 
* 2 - Steam overlay, shows error message box if disabled (the box has a button to continue with default browser)

Toggling Steam overlay in Steam options will require game restart for the changes to take effect.

### Syntax

```sqf
control ctrlSetURLOverlayMode mode
```

### Parameters

- control: Control - control that contain url opening action
- mode: Number - overlay mode, see description

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetURLOverlayMode 1;
```
