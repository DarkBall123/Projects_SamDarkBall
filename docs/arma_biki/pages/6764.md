## attachObject

- Source: https://community.bistudio.com/wiki/attachObject
- Revision: 318700
- Updated: 2022-05-13T09:21:20Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation, Locations

### Description

Attaches a location to the specified object. To detach a location, attach it to objNull.

### Syntax

```sqf
location attachObject object
```

### Parameters

- location: Location
- object: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLocation attachObject player;
```
