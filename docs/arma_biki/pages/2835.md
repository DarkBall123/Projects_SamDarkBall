## ctrlSetFontHeightH4

- Source: https://community.bistudio.com/wiki/ctrlSetFontHeightH4
- Revision: 323040
- Updated: 2022-06-28T21:43:09Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H4 font size of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontHeightH4 height
```

### Parameters

- controlName: Control
- height: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontHeightH4 0.05;
```
