## BIS fnc moduleEffectsBubbles

- Source: https://community.bistudio.com/wiki/BIS_fnc_moduleEffectsBubbles
- Revision: 364220
- Updated: 2024-05-06T09:38:11Z

- Availability: arma3 1.00
- Groups: Modules

### Description

Creates underwater bubble effect on defined place (called usually by BIS_fnc_moduleEffectsEmitterCreator).Mainly meant to be used by modules available in Eden Editor

### Syntax

```sqf
[module] call BIS_fnc_moduleEffectsBubbles
```

### Parameters

- module: Object - module

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_module] call BIS_fnc_moduleEffectsBubbles;
```
