## systemOfUnits

- Source: https://community.bistudio.com/wiki/systemOfUnits
- Revision: 321214
- Updated: 2022-05-13T15:31:34Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: System

### Description

Returns the currently selected system of units.
* 0: Metric
* 1: Mixed (ground vehicles use Metric / air vehicles use Imperial)
* 2: Imperial

### Syntax

```sqf
**systemOfUnits**
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
_system = systemOfUnits;
```
