- Revision: 349329
- Updated: 2023-11-08T14:53:27Z

- Availability: arma3 1.58
- Groups: Eden Editor

### Description

Is used to set the weather settings in Eden Editor. Internal use only.

### Syntax

```sqf
[controlGroup, value] call BIS_fnc_3DENIntel
```

### Parameters

- controlGroup: Control - control group used in Eden Editor to manipulate the weather settings
- value: Number - value used for weather settings like setFog

### Return Value

- Nothing
