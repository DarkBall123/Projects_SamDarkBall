## lbTextRight

- Source: https://community.bistudio.com/wiki/lbTextRight
- Revision: 377807
- Updated: 2026-01-03T04:08:07Z

- Availability: ofp, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListBox

### Description

Returns the shown right text in the item with the given index of the listbox or combobox with id idc of the topmost user dialog.

### Syntax

```sqf
lbTextRight [idc, index]
```

```sqf
control lbTextRight index
```

### Parameters

- idc: Number
- index: Number
- control: Control
- index: Number

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
_text = lbTextRight [101, 0];
```

#### Example 2

```sqf
_text = _control lbTextRight 0;
```
