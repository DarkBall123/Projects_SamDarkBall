## a less b

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math, Variables

### Description

Returns if *a* is lesser than *b*.

### Syntax

```sqf
a < b
```

### Parameters

- a: Number
- b: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_test = 1 < 2; // true
```

#### Example 2

```sqf
_test = 2 < 1; // false
```
