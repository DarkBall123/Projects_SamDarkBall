## BIS fnc traceBullets

- Source: https://community.bistudio.com/wiki/BIS_fnc_traceBullets
- Revision: 329387
- Updated: 2022-07-27T13:25:25Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Visualise unit's bullet trajectories. Can only be used on one shooter in a single instance.

If you want to change the unit, first set 

```sqf
BIS_tracedShooter = nil
```

 *then* execute the script again.

### Syntax

```sqf
[unit, number] call BIS_fnc_traceBullets
```

### Parameters

- unit: Object
- number: Number - (Optional, default 20) maximum displayed trajectories

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player] spawn BIS_fnc_traceBullets;
```

#### Example 2

```sqf
[player, 50] spawn BIS_fnc_traceBullets;
```

#### Example 3

```sqf
[player, 0] spawn BIS_fnc_traceBullets; // remove bullet tracing
```
