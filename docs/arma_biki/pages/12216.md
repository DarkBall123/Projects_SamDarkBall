## setWaypointName

- Source: https://community.bistudio.com/wiki/setWaypointName
- Revision: 319666
- Updated: 2022-05-13T09:24:40Z

- Availability: arma3 0.50
- Groups: Waypoints

### Description

Changes the waypoint name.

### Syntax

```sqf
waypoint setWaypointName name
```

### Parameters

- waypoint: Waypoint
- name: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp,2] setWaypointName "myName";
```
