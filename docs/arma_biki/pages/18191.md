## pixelGridNoUIScale

- Source: https://community.bistudio.com/wiki/pixelGridNoUIScale
- Revision: 378048
- Updated: 2026-01-29T12:07:20Z

- Availability: arma3 1.62
- Groups: GUI Control - Positioning

### Description

Returns grid size based on screen resolution and configs: 

```
uiScaleFactor
```

, 

```
uiScaleMaxGrids
```

.
As mentioned in the name of this command, **the user interface scale is ignored**.

### Syntax

```sqf
pixelGridNoUIScale
```


### Return Value

- Number - grid size, see Arma 3: Pixel Grid System

### Examples

#### Example 1

```sqf
private _gridHeightNoUIScale = pixelH * pixelGridNoUIScale;
```
