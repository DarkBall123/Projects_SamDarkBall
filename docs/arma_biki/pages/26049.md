## toLowerANSI

- Source: https://community.bistudio.com/wiki/toLowerANSI
- Revision: 339603
- Updated: 2023-04-28T14:11:50Z

- Availability: arma3 1.96
- Groups: Strings

### Description

thumb|right|ISO-8859-1
Converts the supplied string to all lower case characters fast (could be 3× faster than toLower).
[ANSI](https://stackoverflow.com/questions/701882/what-is-ansi-format/701920) in this case refers to [ISO-8859-1](https://en.wikipedia.org/wiki/ISO/IEC_8859-1) code page.
The command is primary designed to convert characters with codes 0...127 however it will also convert other characters in 128...255 range as long as they are present in ISO-8859-1 codepage.
For Unicode alternative see toLower.

### Syntax

```sqf
toLowerANSI string
```

### Parameters

- string: String - string to convert

### Return Value

- String - all lower case string

### Examples

#### Example 1

```sqf
hint toLowerANSI "AaBb1"; // returns "aabb1"
```
