## getSlotItemName

- Source: https://community.bistudio.com/wiki/getSlotItemName
- Revision: 353032
- Updated: 2024-03-12T11:47:36Z

- Availability: arma3 2.14
- Groups: Unit Inventory

### Description

Returns the name of assigned item in given slot or the empty string.

### Syntax

```sqf
unit getSlotItemName slot
```

### Parameters

- unit: Object
- slot: Number - can be one of:
{{Columns|4|
* 603 - Goggles
* 605 - Headgear
* 608 - Map
* 609 - Compass
* 610 - Watch
* 611 - Radio
* 612 - GPS
* 616 - HMD
* 617 - Binoculars
* 701 - Vest
* 801 - Uniform
* 901 - Backpack
}}

### Return Value

- String - item name

### Examples

#### Example 1

```sqf
hint (player getSlotItemName 610);
```
