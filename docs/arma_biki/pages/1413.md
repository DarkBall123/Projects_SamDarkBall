## queryMagazinePool

- Source: https://community.bistudio.com/wiki/queryMagazinePool
- Revision: 319440
- Updated: 2022-05-13T09:24:05Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool

### Description

Return number of magazines of type name in magazine pool (used in campaign to transfer magazines into next mission).

### Syntax

```sqf
queryMagazinePool name
```

### Parameters

- name: String

### Return Value

- Number

### Examples

#### Example 1

```sqf
_num = queryMagazinePool "M16";
```
