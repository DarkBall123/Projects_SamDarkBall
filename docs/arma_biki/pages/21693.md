## vectorWorldToModelVisual

- Source: https://community.bistudio.com/wiki/vectorWorldToModelVisual
- Revision: 377893
- Updated: 2026-01-05T17:39:06Z

- Availability: arma3 1.72
- Groups: Math - Vectors, Render Time Scope

### Description

Converts vector direction from world to model space in render time scope.
For scaled objects, the resulting vector's magnitude will be divided by the object scale.

### Syntax

```sqf
object vectorWorldToModelVisual worldDir
```

### Parameters

- object: Object
- worldDir: Vector3D - vector direction in world space in format [x,y,z]

### Return Value

- Vector3D - vector direction in model space in format [x,y,z]

### Examples

#### Example 1

Convert world space vector [0,-10,4] to model space of object _airplane:

```sqf
private _vector = _airplane vectorWorldToModelVisual [0,-10,4];
```
