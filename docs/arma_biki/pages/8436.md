### Description

Set the proxy object associated with the given editor object.
Some Old Editor Command

### Syntax

```sqf
map setObjectProxy [object, proxy]
```

### Parameters

- map: Control
- object: String
- proxy: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_map setObjectProxy ["_group_0", vehicle (leader _group)];
```
