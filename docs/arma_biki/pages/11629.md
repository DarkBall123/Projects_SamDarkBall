## collectiveRTD

- Source: https://community.bistudio.com/wiki/collectiveRTD
- Revision: 377772
- Updated: 2026-01-03T01:32:23Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Returns the current position of a helicopter's collective pitch control.
* 0: fully lowered
* 1: fully raised 
{{Feature|afm}}

### Syntax

```sqf
collectiveRTD helicopterRTD
```

### Parameters

- helicopterRTD: ObjectRTD - helicopter

### Return Value

- Number

### Examples

#### Example 1

```sqf
_collective = collectiveRTD vehicle player;
```
