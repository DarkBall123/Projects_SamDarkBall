## step

- Source: https://community.bistudio.com/wiki/step
- Revision: 369298
- Updated: 2024-09-03T18:42:52Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Optional step value. A countdown can be made with a negative value. If not set, the default step is 1.

### Syntax

```sqf
for step stepSize
```

### Parameters

- for: For Type
- stepSize: Number

### Return Value

- For Type

### Examples

#### Example 1

```sqf
for "_i" from 20 to 10 step -2 do
{
	// ...
};
```
