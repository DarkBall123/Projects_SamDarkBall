## menuSetAction

- Source: https://community.bistudio.com/wiki/menuSetAction
- Revision: 378340
- Updated: 2026-04-02T16:31:17Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Sets new action into menu entry on given path.

### Syntax

```sqf
menuSetAction [idc, path, action]
```

```sqf
control menuSetAction [path, action]
```

### Parameters

- idc: Number
- path: Tree View Path
- action: String - expression that should be executed when entry is clicked
- control: Control
- path: Tree View Path
- action: String - expression that should be executed when entry is clicked

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuSetAction [[0, 1], "systemChat 'Hello World!'"];
```
