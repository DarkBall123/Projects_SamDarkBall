## BIS fnc dbClassIndex

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbClassIndex
- Revision: 327486
- Updated: 2022-07-12T22:19:31Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Returns indices leading to given class.

### Syntax

```sqf
[database, path] call BIS_fnc_dbClassIndex
```

### Parameters

- database - Array: database array
- path - Array: path to class

### Return Value

- Array: List of indices

### Examples

#### Example 1

```sqf
"#MILLER", ["&NAME", "Miller", "&UID", "1234", "&MONEY", 1000, ["miller"]] call BIS_fnc_dbClassIndex; // [0]
```
