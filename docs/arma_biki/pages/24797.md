## BIS fnc reviveEhHandleHeal

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveEhHandleHeal
- Revision: 349306
- Updated: 2023-11-08T14:52:21Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Handles healing of unit. Unit gets fully healed after 10 seconds if current damage is smaller than initial damage, e.g. a medic healed the unit.

### Syntax

```sqf
[unit] call BIS_fnc_reviveEhHandleHeal
```

### Parameters

- unit: Object - unit to be healed

### Return Value

- Boolean - if revive is enabled for given unit it always returns false, if revive is disabled it returns Nothing

### Examples

#### Example 1

```sqf
[BIS_unit] call BIS_fnc_reviveEhHandleHeal;
```
