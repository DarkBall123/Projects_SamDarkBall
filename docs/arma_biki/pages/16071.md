## BIS fnc addScore

- Source: https://community.bistudio.com/wiki/BIS_fnc_addScore
- Revision: 349163
- Updated: 2023-11-08T14:49:51Z

- Availability: arma3 1.00
- Locality: server execution server
- Groups: Multiplayer

### Description

Adds a set amount of points to the score of a unit *(MP only)*

### Syntax

```sqf
[object, number] call BIS_fnc_addScore
```

### Parameters

- Object - unit to add score to.
- Number - number of points (score) to add to unit.

### Return Value

- Number - score added to unit

### Examples

#### Example 1

```sqf
[player,20] call BIS_fnc_addScore;
```
