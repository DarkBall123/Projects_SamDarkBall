## loadVest

- Source: https://community.bistudio.com/wiki/loadVest
- Revision: 323062
- Updated: 2022-06-28T21:43:11Z

- Availability: arma3 0.50
- Groups: Unit Inventory

### Description

Returns current percentage of mass from items stored in a vest relative to the maximum capacity of the vest. 

It is equivalent to this formula:

```sqf
_loadVest = massOfAllItemsInVest / getContainerMaxLoad vest player;
```

### Syntax

```sqf
loadVest unit
```

### Parameters

- unit: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
_weight = loadVest player;
```
