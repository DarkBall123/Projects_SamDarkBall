## BIS fnc removeRespawnPosition

- Source: https://community.bistudio.com/wiki/BIS_fnc_removeRespawnPosition
- Revision: 327904
- Updated: 2022-07-13T11:43:10Z

- Availability: arma3 0.50
- Locality: effect global
- Groups: Respawn

### Description

Remove a respawn position added by BIS_fnc_addRespawnPosition.

### Syntax

```sqf
[target, id] call BIS_fnc_removeRespawnPosition
```

### Parameters

- **target**: Namespace, Side, Group or Object
- **id**: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[west, 1] call BIS_fnc_removeRespawnPosition;
```

#### Example 2

```sqf
myRespawn = [missionNamespace,"arena"] call BIS_fnc_addRespawnPosition;
myRespawn call BIS_fnc_removeRespawnPosition;
```
