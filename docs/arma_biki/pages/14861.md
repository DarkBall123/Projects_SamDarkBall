## unassignCurator

- Source: https://community.bistudio.com/wiki/unassignCurator
- Revision: 348367
- Updated: 2023-11-08T12:59:54Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Unassign curator (will destroy both sides of connection).

### Syntax

```sqf
unassignCurator curatorObj
```

### Parameters

- curatorObj: Object - curator module.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
unassignCurator myCurator;
```
