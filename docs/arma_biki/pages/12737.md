## forceRespawn

- Source: https://community.bistudio.com/wiki/forceRespawn
- Revision: 320952
- Updated: 2022-05-13T10:04:47Z

- Availability: arma3 1.04
- Locality: argument local, effect global
- Groups: Multiplayer

### Description

Forces the unit to respawn. The effect is as if the player pressed the RESPAWN button in the game pause menu; the unit is killed but there is no "X was killed" message and no score adjustment.

### Syntax

```sqf
forceRespawn unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
forceRespawn player;
```
