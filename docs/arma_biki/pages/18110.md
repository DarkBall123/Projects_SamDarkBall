## getTerrainGrid

- Source: https://community.bistudio.com/wiki/getTerrainGrid
- Revision: 353047
- Updated: 2024-03-12T12:19:53Z

- Availability: arma3 1.60
- Groups: System, Environment

### Description

A getter for setTerrainGrid, returns the current terrain grid.

### Syntax

```sqf
getTerrainGrid
```


### Return Value

- Number - terrain grid value

### Examples

#### Example 1

```sqf
_terrainGrid = getTerrainGrid;
```

#### Example 2

```sqf
if (getTerrainGrid < 50) then
{
	hint "Grass is enabled";
};
```
