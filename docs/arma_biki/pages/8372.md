## playAction

- Source: https://community.bistudio.com/wiki/playAction
- Revision: 341827
- Updated: 2023-06-28T04:46:19Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Control, Animations

### Description

When used on a person, a smooth transition to the given action will be initiated.

For Arma 3 actions see: playAction/actions.

### Syntax

```sqf
soldier playAction action
```

### Parameters

- soldier: Object
- action: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
soldierOne playAction "SitDown";
```
