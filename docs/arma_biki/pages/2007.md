## lineBreak

- Source: https://community.bistudio.com/wiki/lineBreak
- Revision: 321099
- Updated: 2022-05-13T13:56:57Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Strings, Structured Text

### Description

Creates a structured text containing a line break.

### Syntax

```sqf
lineBreak
```


### Return Value

- Structured Text

### Examples

#### Example 1

```sqf
hint composeText ["First line", lineBreak, "Second line"];
```

#### Example 2

```sqf
hint str (composeText [lineBreak] == parseText "
"); // true
```
