## BIS fnc EXP camp setSkill

- Source: https://community.bistudio.com/wiki/BIS_fnc_EXP_camp_setSkill
- Revision: 364258
- Updated: 2024-05-06T09:38:24Z

- Availability: arma3 1.62
- Locality: server execution server
- Groups: Campaign

### Description

Sets skill for an entire AI side. The skill will be calculated using a lerp function. Function will take player as multiplier.

### Syntax

```sqf
[side,skillMin,skillAimMin,skillMax,skillAimMax] call BIS_fnc_EXP_camp_setSkill
```

### Parameters

- side: Side - side of which AI skill should be changed
- skillMin: Number - (Optional, default 0.5) minimal general skill
- skillAimMin: Number - (Optional, default 0.3) minimal aiming skill
- skillMax: Number - (Optional, default 0.8) maximal general skill
- skillAimMax: Number - (Optional, default 0.5) maximal aiming skill

### Return Value


### Examples

#### Example 1

```sqf
[WEST,0.1,0.2,0.7,0.6] call BIS_fnc_EXP_camp_setSkill;
```
