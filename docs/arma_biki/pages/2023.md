## radioVolume

- Source: https://community.bistudio.com/wiki/radioVolume
- Revision: 376982
- Updated: 2026-01-01T06:23:17Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Sounds

### Description

Returns the current radio volume (set by fadeRadio).

### Syntax

```sqf
radioVolume
```


### Return Value

- Number in range 0..2

### Examples

#### Example 1

```sqf
hint str radioVolume;
```
