## tvCollapseAll

- Source: https://community.bistudio.com/wiki/tvCollapseAll
- Revision: 309956
- Updated: 2022-05-05T12:17:01Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Collapses all tree items for the given Tree View.

### Syntax

```sqf
tvCollapseAll idc
```

```sqf
tvCollapseAll control
```

### Parameters

- idc: Number
- control: Control

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvCollapseAll 101;
```

#### Example 2

```sqf
tvCollapseAll _ctrl;
```
