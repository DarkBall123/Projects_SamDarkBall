## BIS fnc customGPS

- Source: https://community.bistudio.com/wiki/BIS_fnc_customGPS
- Revision: 327288
- Updated: 2022-07-12T22:11:51Z

- Availability: arma2oa 1.56, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: GUI

### Description

Replaces GPS frame.

The following line **must** be defined in mission Description.ext:

```
onMinimapScript[] = {"BIS_fnc_customGPS_Spawn"};
```

### Syntax

```sqf
[path, *deltaX*, *deltaY*] call BIS_fnc_customGPS
```

### Parameters

- path: String - full path to image file
- deltaX *(Optional)*: Number
- deltaY *(Optional)*: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
["ca\missions_pmc\data\ui_gps_ca.paa", -0.05, 0.16] call BIS_fnc_customGPS;
```
