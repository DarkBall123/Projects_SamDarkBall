## showPad

- Source: https://community.bistudio.com/wiki/showPad
- Revision: 322923
- Updated: 2022-06-28T21:42:28Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Interaction

### Description

Shows or hides the notebook on the map screen, if enabled for the mission. (default true). It is no longer relevant to Arma 2.

### Syntax

```sqf
showPad show
```

### Parameters

- show: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
showPad false;
```
