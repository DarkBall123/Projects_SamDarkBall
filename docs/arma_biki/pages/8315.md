## lnbClear

- Source: https://community.bistudio.com/wiki/lnbClear
- Revision: 309988
- Updated: 2022-05-05T12:17:03Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Clears all items in the given listbox or combobox.

### Syntax

```sqf
lnbClear idc
```

```sqf
lnbClear ctrl
```

### Parameters

- idc: Number
- ctrl: Control

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lnbClear _ctrl;
```
