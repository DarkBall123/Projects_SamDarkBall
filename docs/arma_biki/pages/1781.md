## setRadioMsg

- Source: https://community.bistudio.com/wiki/setRadioMsg
- Revision: 378813
- Updated: 2026-06-30T23:28:57Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Triggers, Interaction

### Description

Sets radio trigger menu title text (0 -> 0 -> map radio). Use "NULL" to disable radio slot. Use "" to restore default title. 
The same effect could be achieved by using setTriggerText (see Example 2)

### Syntax

```sqf
index setRadioMsg text
```

### Parameters

- index: Number - from 1 to 10

* 1 - Alpha (key 1)
* 2 - Bravo (key 2)
* 3 - Charlie (key 3)
* 4 - Delta (key 4)
* 5 - Echo (key 5)
* 6 - Foxtrot (key 6)
* 7 - Golf (key 7)
* 8 - Hotel (key 8)
* 9 - India (key 9)
* 10 - Juliet (key 0)
- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
1 setRadioMsg "Click meeeeeeeeee"; //changes title of radio Alpha
```

#### Example 2

```sqf
_radioTrigger setTriggerText "Click meeeeeeeeee"; //changes title of whatever radio the trigger was set to
```
