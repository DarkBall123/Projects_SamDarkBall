## setMarkerDrawPriority

- Source: https://community.bistudio.com/wiki/setMarkerDrawPriority
- Revision: 373673
- Updated: 2025-06-09T15:29:58Z

- Availability: arma3 2.14
- Locality: effect local
- Groups: Markers

### Description

Sets marker draw priority. Higher priority markers are drawn on top. Default priority is 0.
Be aware that this command has **local** effect despite the command name missing the word **local**!

### Syntax

```sqf
markerName setMarkerDrawPriority priority
```

### Parameters

- markerName: String
- priority: Number - draw priority

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"MarkerOne" setMarkerDrawPriority 0.5;
```

#### Example 2

```sqf
"MarkerTwo" setMarkerDrawPriority -2.1;
```
