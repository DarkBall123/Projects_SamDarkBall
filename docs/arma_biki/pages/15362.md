## vectorAdd

- Source: https://community.bistudio.com/wiki/vectorAdd
- Revision: 378392
- Updated: 2026-04-04T07:53:40Z

- Availability: arma3 1.22
- Groups: Math - Vectors

### Description

Adds two arrays of numbers. Replaces BIS_fnc_vectorAdd.

arma3|2.14|Since 2.14 any count of numbers is valid, if one array is larger than the other, the remaining elements are inserted without change.

Before 2.14, the first argument had to be vector 3D, or 2.00 2D (Which still returned 3D result, with z coordinate defaulted to 0)

### Syntax

```sqf
vector1 vectorAdd vector2
```

### Parameters

- vector1: Array of Numbers - can be any size
- vector2: Array of Numbers - can be any size

### Return Value

- Array of Numbers

### Examples

#### Example 1

```sqf
hint str (velocity unit1 vectorAdd velocity unit2);
```

#### Example 2

```sqf
[5, 10, 5] vectorAdd [5, 5, 10];			// returns [10, 15, 15]
```

#### Example 3

```sqf
[0, 0] vectorAdd [1, -2];					// returns [1, -2]
```

#### Example 4

```sqf
[1, 2, 3, 4, 5, 6] vectorAdd [10, 10, 10];	// returns [11, 12, 13, 4, 5, 6]
```

#### Example 5

```sqf
[1, 2, 3] vectorAdd [1, 2, 3];	// [2, 4, 6]
[1, 2, 3] vectorAdd [1, 2];		// [2, 4, 3]
[1, 2] vectorAdd [1, 2, 3];		// [2, 4, 3]
[1, 2] vectorAdd [1, 2];		// [2, 4]
```
