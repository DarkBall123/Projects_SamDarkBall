## diag enable

- Source: https://community.bistudio.com/wiki/diag_enable
- Revision: 349134
- Updated: 2023-11-08T14:49:45Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Toggles various diagnostics.

### Syntax

```sqf
mode diag_enable  state
```

### Parameters

- mode: String - see Arma 3: Diagnostics Exe
- state: Boolean - true to enable diag mode, false to disable it

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"All" diag_enable true;
```
