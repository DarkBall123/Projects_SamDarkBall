Heightmap
{{TerrainProcessorManual|Heightmap: Perlin Noise|BITasksPlugin.dll|Polygon, PolygonM, PolygonZ|Yes
|DESCRIPTION=Algorithm adds perlin noise in terrain heightmap. It uses Shapefile as mask polygons. [Perlin noise on Wikipedia](https://en.wikipedia.org/wiki/Perlin_noise).
|TASKPARAMETERS=
- **Amplitude** - Maximal +- height added to terrain heightmap.
- **Scale** - Perlin noise mapping scale.
|OBJECTPROTOTYPEPARAMETERS=
|USAGE=Good to for creating some terrain corrugation within a particular area, e.g. more rugged terrain in a forest offering some additional cover to infantry. Gentle noise adds natural feel to meadows or brownfield.
|ALGORITHM=# Load heightmap
1. For each shapefile polygon
  1. For each heightmap point in polygon
    1. Get Perlin noise value and add it to height in heightmap
|SAMPLE=
}}
