## BIS fnc cutDecimals

- Source: https://community.bistudio.com/wiki/BIS_fnc_cutDecimals
- Revision: 349047
- Updated: 2023-11-08T14:47:17Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

Function that rounds specified number to specified amount of decimals.
Use toFixed instead.

### Syntax

```sqf
[number, precision] call BIS_fnc_cutDecimals
```

### Parameters

- number: Number - decimal number to round.
- precision: Number - (Optional, default 0) amount of decimals to round to

### Return Value

- Number - rounded number.

### Examples

#### Example 1

```sqf
private _cutDecimals = [33.3333, 1] call BIS_fnc_cutDecimals; // returns 33.3
```
