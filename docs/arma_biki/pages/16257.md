## BIS fnc moduleEffectsPlankton

- Source: https://community.bistudio.com/wiki/BIS_fnc_moduleEffectsPlankton
- Revision: 352077
- Updated: 2024-02-01T23:24:42Z

- Availability: arma3 1.00
- Groups: Modules

### Description

Creates underwater plankton effect around player (called usually by BIS_fnc_moduleEffectsEmitterCreator).Mainly meant to be used by modules available in Eden Editor

### Syntax

```sqf
[module] call BIS_fnc_moduleEffectsPlankton
```

### Parameters

- module: Object - module

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_module] call BIS_fnc_moduleEffectsPlankton;
```
