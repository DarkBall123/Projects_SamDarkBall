## radioChannelAdd

- Source: https://community.bistudio.com/wiki/radioChannelAdd
- Revision: 370595
- Updated: 2025-01-14T13:03:39Z

- Availability: tkoh 1.00, arma3 0.50
- Locality: effect global
- Groups: Radio and Chat, Custom Radio and Chat

### Description

Add the units to the custom channel.

### Syntax

```sqf
customChannelID radioChannelAdd units
```

### Parameters

- customChannelID: Number - custom channel ID returned by radioChannelCreate command
- units: Array of Objects - list of units

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
2 radioChannelAdd [player, unit1];
```
