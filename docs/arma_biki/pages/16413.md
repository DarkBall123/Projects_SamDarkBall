## BIS fnc setOvercast

- Source: https://community.bistudio.com/wiki/BIS_fnc_setOvercast
- Revision: 323950
- Updated: 2022-07-01T11:58:29Z

- Availability: arma3 1.00
- Groups: Environment

### Description

Instantly set weather conditions and share it across network. Must be executed in scheduled environment.

### Syntax

```sqf
[value] call BIS_fnc_setOvercast
```

### Parameters

- value: Number - value ranging from 0 (sunny) to 1 (stormy).

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[0.5] call BIS_fnc_setOvercast;
```
