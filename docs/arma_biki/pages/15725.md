## BIS fnc taskAttack

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskAttack
- Revision: 327472
- Updated: 2022-07-12T22:12:11Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Tasks

### Description

This function adds a Seek and Destroy waypoint on defined position to the group and set its behaviour to "AWARE". If the group has other waypoints, the waypoint will be added at the end of the list.

### Syntax

```sqf
[group, position] call BIS_fnc_taskAttack
```

### Parameters

- group: Group
- position: Position

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[opforGroup, getPosATL player] call BIS_fnc_taskAttack;
```
