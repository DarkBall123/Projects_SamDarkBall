## getServerInfo

- Source: https://community.bistudio.com/wiki/getServerInfo
- Revision: 373696
- Updated: 2025-06-17T13:55:14Z

- Availability: arma3 2.20
- Locality: server execution server
- Groups: Multiplayer

### Description

Get the current server instance's settings from [server config](Arma 3: Server Config File).
Player-hosted (non-dedicated) servers have fewer entries as they do not use a server config file.

### Syntax

```sqf
getServerInfo
```


### Return Value

- HashMap
