## nearestLocationWithDubbing

- Source: https://community.bistudio.com/wiki/nearestLocationWithDubbing
- Revision: 377422
- Updated: 2026-01-02T06:45:33Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations

### Description

Find the nearest location having a non-empty speech.
No locations are dubbed in Arma 3.

### Syntax

```sqf
nearestLocationWithDubbing position
```

### Parameters

- position: Object or PositionAGL or Position2D

### Return Value

- Location

### Examples

#### Example 1

```sqf
_location = nearestLocationWithDubbing player;
```

#### Example 2

```sqf
_location = nearestLocationWithDubbing getMarkerPos "myMarker";
```
