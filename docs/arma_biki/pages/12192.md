## netId

- Source: https://community.bistudio.com/wiki/netId
- Revision: 364973
- Updated: 2024-07-04T17:25:50Z

- Availability: arma3 0.50, arma2oa 1.63
- Groups: Multiplayer

### Description

Get the unique ID of an object or a group.

### Multiplayer

<nowiki/>
* In singleplayer: 2.18 returns a net ID (different from BIS_fnc_netId's output), before that it returned an empty string in single player (see BIS_fnc_netId and BIS_fnc_objectVar)
* In multiplayer: works as described

### Syntax

```sqf
netId objOrGroup
```

### Parameters

- objOrGroup: Object or Group

### Return Value

- String

### Examples

#### Example 1

```sqf
_playerNetId = netId player;
```
