## HashMapKey

- Source: https://community.bistudio.com/wiki/HashMapKey
- Revision: 330441
- Updated: 2022-09-15T21:04:29Z

HashMapKey is a virtual compound type containing all the possible types that can be used as keys in a HashMap.

The types are:
- Number
- Boolean
- String
- Code
- Side
- Config
- Namespace
- NaN
- Array

Category: Magic Types
