## menuSize

- Source: https://community.bistudio.com/wiki/menuSize
- Revision: 378332
- Updated: 2026-04-02T16:30:46Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns how many sub entries is in item on given path.

### Syntax

```sqf
menuSize [idc, path]
```

```sqf
control menuSize path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Number
- Number

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuSize [];
```
