## addForce

- Source: https://community.bistudio.com/wiki/addForce
- Revision: 377384
- Updated: 2026-01-02T06:43:53Z

- Availability: arma3 1.72
- Locality: argument global, effect global
- Groups: PhysX

### Description

Applies given force for one frame (essentially an impulse) to unit or given PhysX object at given position.
For more information see [NVIDIA docs](http://docs.nvidia.com/gameworks/content/gameworkslibrary/physx/apireference/files/classPxRigidBody.html).

### Syntax

```sqf
object addForce [force, position, setUnconscious]
```

### Parameters

- object: Object - PhysX object or 2.04{{Icon|localargument|24}} unit, in which case the unit must be local and will be set unconscious
- force: Vector3D - force vector in **world** space; force is expressed in
[newton-seconds](https://en.wikipedia.org/wiki/Newton-second) (used by [PxForceMode::eIMPULSE](https://docs.nvidia.com/gameworks/content/gameworkslibrary/physx/apireference/files/structPxForceMode.html))
- position: PositionRelative - relative to object
- setUnconscious: Boolean - (Optional, default true) only applies to "CAManBase" *object*; set to false to keep the person conscious

### Return Value

- Nothing

### Examples

#### Example 1

Apply force [0,1000,0] defined in world space (not factoring object actual positioning) to object position [1,0,0]:

```sqf
_object addForce [[0,1000,0], [1,0,0]];
```

#### Example 2

Apply force [0,1000,0] defined in model space (relative to object) to object position [1,0,0]:

```sqf
_object addForce [_object vectorModelToWorld [0,1000,0], [1,0,0]];
```

#### Example 3

Can be used on units since Arma 3 v2.04:

```sqf
if (local bob) then
{
	0 spawn 
	{
		bob addForce [bob vectorModelToWorld [0,-200,0], bob selectionPosition "rightfoot"];
		sleep 5;
		bob setUnconscious false;
	};
};
```

#### Example 4

```sqf
player addForce [player vectorModelToWorld [0, -1, 0], [0, 1, 0], false]; // not unconscious
```
