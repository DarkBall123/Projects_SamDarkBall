## setVehicleReportRemoteTargets

- Source: https://community.bistudio.com/wiki/setVehicleReportRemoteTargets
- Revision: 311073
- Updated: 2022-05-07T20:57:55Z

- Availability: arma3 1.70
- Groups: Sensors

### Description

Sets that the vehicle will share targets that were acquired by its own sensors via datalink to the Side center.

### Syntax

```sqf
vehicle setVehicleReportRemoteTargets bool
```

### Parameters

- vehicle: Object
- bool: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setVehicleReportRemoteTargets true;
```
