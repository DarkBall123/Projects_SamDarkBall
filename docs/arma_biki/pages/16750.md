## getSlingLoad

- Source: https://community.bistudio.com/wiki/getSlingLoad
- Revision: 319143
- Updated: 2022-05-13T09:23:15Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Return object which is sling loaded by vehicle

### Syntax

```sqf
getSlingLoad vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Object - the sling loaded vehicle. objNull if nothing is sling loaded.

### Examples

#### Example 1

```sqf
_cargo = getSlingLoad heli1;
```
