## BIS fnc dbClassRemove

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbClassRemove
- Revision: 328348
- Updated: 2022-07-13T16:00:46Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Remove class from Scripted Database. The function does not return the modified database but modifies the passed array directly.

### Syntax

```sqf
[database, path] call BIS_fnc_dbClassRemove
```

### Parameters

- database - Array: Database array
- path - Array: Path to class to be deleted

### Return Value

- Boolean: True if class was removed

### Examples

#### Example 1

```sqf
private _db = ["#MILLER", ["&KILLS", 1000], "#TERRA", ["&WEAPON", "MX 6.5mm"]];
[_db, ["terra"]] call BIS_fnc_dbClassRemove; // true
_db // ["#MILLER",["&KILLS",1000]]
```
