## setLightAmbient

- Source: https://community.bistudio.com/wiki/setLightAmbient
- Revision: 377373
- Updated: 2026-01-02T06:42:43Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Lights

### Description

Set ambient color of light. This includes surfaces that **face away** from the light, unlike setLightColor.

### Syntax

```sqf
light setLightAmbient color
```

### Parameters

- light: Object
- color: Color (RGB)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLight setLightAmbient [0.5,0,0]; // produces red light around the origin source
```
