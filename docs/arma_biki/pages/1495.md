## rad

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math - Geometry

### Description

Converts given value in degrees to radians. 1 radian equals 180 degrees divided by pi.

### Syntax

```sqf
rad value
```

### Parameters

- value: Number - degrees

### Return Value

- Number - radians

### Examples

#### Example 1

```sqf
_radians = rad 180; // returns 3.1415 (pi)
```
