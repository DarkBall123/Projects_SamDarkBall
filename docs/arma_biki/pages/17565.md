## get3DENGrid

- Source: https://community.bistudio.com/wiki/get3DENGrid
- Revision: 348872
- Updated: 2023-11-08T14:39:45Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns the grid increment for the given transformation type.

### Syntax

```sqf
get3DENGrid  type
```

### Parameters

- type: String - name of transformation type. Can be:
* `"r"` - Rotation
* `"t"` - Translation
* `"s"` - Scale

### Return Value

- Number

### Examples

#### Example 1

```sqf
_currentIncrement = get3DENGrid "t";
```
