## removeWeaponTurret

- Source: https://community.bistudio.com/wiki/removeWeaponTurret
- Revision: 377481
- Updated: 2026-01-02T06:48:57Z

- Availability: arma3 1.32, arma2oa 1.64
- Locality: argument local, effect global
- Groups: Turrets

### Description

Removes weapon from the turret. Use turret path [-1] for driver's turret.

### Syntax

```sqf
vehicle removeWeaponTurret [weaponName, turretPath]
```

### Parameters

- vehicle: Object
- weaponName: String
- turretPath: Turret Path

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_tank removeWeaponTurret ["LMG_M200", [0,0]];
```

#### Example 2

```sqf
vehicle player removeWeaponTurret ["SportCarHorn", [-1]];
```
