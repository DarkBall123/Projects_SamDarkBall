## allowCuratorLogicIgnoreAreas

- Source: https://community.bistudio.com/wiki/allowCuratorLogicIgnoreAreas
- Revision: 348345
- Updated: 2023-11-08T12:59:49Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Allows curator placing and working with modules outside of edit areas.

### Syntax

```sqf
curatorObj allowCuratorLogicIgnoreAreas allow
```

### Parameters

- curatorObj: Object - curator module.
- allow: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
curatorModule allowCuratorLogicIgnoreAreas true;
```
