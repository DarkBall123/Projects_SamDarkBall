## isAutoHoverOn

- Source: https://community.bistudio.com/wiki/isAutoHoverOn
- Revision: 319208
- Updated: 2022-05-13T09:23:22Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Return true if vehicle has enabled auto hover. (always returns false if the vehicle can't set auto hover)

### Syntax

```sqf
isAutoHoverOn vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isOn = isAutoHoverOn vehicle player;
```
