## getAimingCoef

- Source: https://community.bistudio.com/wiki/getAimingCoef
- Revision: 351281
- Updated: 2023-11-27T02:47:48Z

- Availability: arma3 1.62
- Groups: Stamina System

### Description

Get current aiming coefficient (higher ~ less precise, default is 1)

### Syntax

```sqf
getAimingCoef unit
```

### Parameters

- unit: Object

### Return Value

- Number

### Examples

#### Example 1

_coef = getAimingCoef player
