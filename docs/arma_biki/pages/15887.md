### Description

Initialize animated briefing markers.

### Syntax

```sqf
marker call BIS_fnc_briefingInit
```

### Parameters

- marker: String - marker to initialise

### Return Value

- Nothing

### Examples

#### Example 1

"marker_1" call BIS_fnc_briefingInit;
