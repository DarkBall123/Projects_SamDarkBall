## camPreparePos

- Source: https://community.bistudio.com/wiki/camPreparePos

- Updated: 2026-01-03T00:59:06Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Prepares the camera position. Needs the call of camCommitPrepared to be conducted.

### Syntax

```sqf
camera camPreparePos  position
```

### Parameters

- camera: Object
- position: Position

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_camera camPreparePos getPos player;
```
