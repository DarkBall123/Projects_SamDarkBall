## lockCameraTo

- Source: https://community.bistudio.com/wiki/lockCameraTo
- Revision: 377889
- Updated: 2026-01-05T17:33:18Z

- Availability: arma3 1.26
- Locality: argument local
- Groups: Camera Control

### Description

Lock/Unlock stabilized camera to target. Works only on turrets which have optic mode selected with direction stabilization enabled.

Since 2.08 the command also works with non-stabilized turrets (such as main turret of a tank). See [syntax 2](#Alternative_Syntax).

The command is local to the **turret** gunner, not the vehicle.

### Syntax

```sqf
vehicle lockCameraTo [target, turretPath]
```

```sqf
vehicle lockCameraTo [target, turretPath, temporary]
```

### Parameters

- vehicle: Object - UAV
- target: Object or PositionASL - use objNull to unlock
- turretPath: Turret Path - path to the turret with required camera
- vehicle: Object - UAV
- target: Object or PositionASL - use objNull to unlock
- turretPath: Turret Path - path to the turret with required camera
- temporary: Boolean - if set to true, the engine will automatically remove the lock-on once the turret reaches its target.
If the target is out of turret's reach, once the turret reaches its limits the lock-on will be released.

### Return Value

- Nothing

* This syntax only works with stabilized turrets.
* When using this syntax, if target is out of possible view, the turret will move to its limit and get stuck there, with blocked input.
- Nothing

This syntax also works with non-stabilized turrets, unlike #Syntax 1.

### Examples

#### Example 1

```sqf
uav lockCameraTo [cursorObject, [0,0]];
```

#### Example 2

```sqf
uav lockCameraTo [objNull, [0,0]]; // unlocks the turret
```

#### Example 3

```sqf
vehicle player lockCameraTo [enemyTarget, vehicle player unitTurret player, false];
```
