## assignedCargo

- Source: https://community.bistudio.com/wiki/assignedCargo
- Revision: 323004
- Updated: 2022-06-28T21:43:04Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control, Object Manipulation

### Description

Returns the list of soldiers assigned to the given vehicle as a cargo.

### Syntax

```sqf
assignedCargo vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_list = assignedCargo _vehicleName;
```
