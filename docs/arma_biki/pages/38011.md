## setWaterLeakiness

- Source: https://community.bistudio.com/wiki/setWaterLeakiness
- Revision: 363318
- Updated: 2024-03-26T16:41:37Z

- Availability: arma3 2.16
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Set an object's water intake ratio when immersed.

### Syntax

```sqf
obj setWaterLeakiness leakiness
```

### Parameters

- obj: Object - object to manipulate
- leakiness: Number - in range 0..1 where 0 is waterproof and 1 is full leak

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
private _veh = vehicle player;
if (surfaceIsWater getPosASL _veh) then
{
	_veh setWaterLeakiness 1;
};
```
