## ropeLength

- Source: https://community.bistudio.com/wiki/ropeLength
- Revision: 364981
- Updated: 2024-07-04T19:58:04Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Return rope length in meters (set by ropeCreate, ropeCut, ropeUnwind).
Returned rope length will remain the same, even if the rope is stretched.

### Syntax

```sqf
ropeLength rope
```

### Parameters

- rope: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
_length = ropeLength (ropes heli1 select 0);
```
