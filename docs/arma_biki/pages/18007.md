## lockIdentity

- Source: https://community.bistudio.com/wiki/lockIdentity
- Revision: 321185
- Updated: 2022-05-13T15:19:51Z

- Availability: arma3 1.56
- Groups: Unit Identity

### Description

Locks the identity of a person. This will disable default identity.

### Syntax

```sqf
lockIdentity unit
```

### Parameters

- unit: Object

### Return Value

- Boolean - true, if it was applied

### Examples

#### Example 1

```sqf
_success = lockIdentity player;
```
