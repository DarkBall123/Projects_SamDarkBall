## getItemCargo

- Source: https://community.bistudio.com/wiki/getItemCargo
- Revision: 378322
- Updated: 2026-04-02T16:23:27Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Vehicle Inventory

### Description

Returns all items names and count from ammo box (or any general weapon holder container).

### Syntax

```sqf
getItemCargo box
```

### Parameters

- box: Object

### Return Value

- Array with [classes, counts]
* classes: Array of Strings - Item class names
* counts: Array of Numbers - Item counts

### Examples

#### Example 1

```sqf
getItemCargo cursorTarget;
/*
	returns e.g
	[
        ["5ItemA", "10ItemB"]
        [5, 10]
	]
*/
```
