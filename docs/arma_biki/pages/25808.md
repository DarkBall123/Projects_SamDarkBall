## removeDiarySubject

- Source: https://community.bistudio.com/wiki/removeDiarySubject
- Revision: 309156
- Updated: 2022-05-03T14:17:34Z

- Availability: arma3 1.96
- Locality: effect local
- Groups: Briefing

### Description

Removes a page and all its subjects from the Diary.

### Syntax

```sqf
player removeDiarySubject diaryPage
```

### Parameters

- player: Object
- diaryPage: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeDiarySubject "myPage";
```
