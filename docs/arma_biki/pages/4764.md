## enableAttack

- Source: https://community.bistudio.com/wiki/enableAttack
- Revision: 321173
- Updated: 2022-05-13T15:15:34Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Groups, Unit Control

### Description

Set if leader can issue attack commands to the soldiers in his group.

### Syntax

```sqf
group enableAttack enable
```

### Parameters

- group: Object or Group
- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_group1 enableAttack true;
```
