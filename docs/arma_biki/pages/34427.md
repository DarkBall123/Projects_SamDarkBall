## stopSound

- Source: https://community.bistudio.com/wiki/stopSound
- Revision: 376804
- Updated: 2025-11-21T13:58:54Z

- Availability: arma3 2.12
- Locality: effect local
- Groups: Sounds

### Description

Terminates the given sound

### Syntax

```sqf
stopSound id
```

### Parameters

- id: Number - id returned by playSoundUI and playSound3D commandsSound ids are **local**.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
stopSound 10;
```

### See Also
