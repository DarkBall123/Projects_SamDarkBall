## copyToClipboard

- Source: https://community.bistudio.com/wiki/copyToClipboard
- Revision: 337563
- Updated: 2023-02-10T01:05:53Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: server execution server
- Groups: System, Strings

### Description

Copies ANSI text string to the clipboard. If Unicode support is desired, see forceUnicode.

### Multiplayer

Restricted to **the server** for safety reasons.

### Syntax

```sqf
copyToClipboard text
```

### Parameters

- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
copyToClipboard str _data;
```

|text= To add a line break in output text do this:

```sqf
_br = toString [13,10]; // (carriage return & line feed)
_string = "Line 1" + _br + "Line 2";
copyToClipboard _string;
```

Paste into text editor of choice, you get:
<pre>
Line 1
Line 2
</pre>
(A3 1.30 Stable executed inside .sqf via execVM)
