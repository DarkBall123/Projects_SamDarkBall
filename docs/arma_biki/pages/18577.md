## getCursorObjectParams

- Source: https://community.bistudio.com/wiki/getCursorObjectParams
- Revision: 364830
- Updated: 2024-06-16T09:59:43Z

- Availability: arma3 1.70
- Groups: Object Detection

### Description

Returns object and named selections under cursor and distance to object's surface (to the point cursor points at). If object surface is further away than 50 meters, selections are always an empty array and distance is 1e10 (10^10).

### Syntax

```sqf
**getCursorObjectParams**
```


### Return Value

- Array with [cursorObject, selections, distance]
* cursorObject: Object
* selections: Array of Strings
* distance: Number - distance to object's surface (to the point cursor points at)

### Examples

#### Example 1

```sqf
hint str getCursorObjectParams;
```
