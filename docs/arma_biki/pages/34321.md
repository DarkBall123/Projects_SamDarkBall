## ctrlMapDir

- Source: https://community.bistudio.com/wiki/ctrlMapDir
- Revision: 347213
- Updated: 2023-09-05T16:49:02Z

- Availability: arma3 2.14
- Groups: GUI Control - Map

### Description

Returns the current orientation angle of the map control in degrees.

### Syntax

```sqf
ctrlMapDir ctrl
```

### Parameters

- ctrl: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _mapControl = findDisplay 12 displayCtrl 51; // get the map
private _dir = ctrlMapDir _mapControl; // returns 0 as the main map does not autorotate
```
