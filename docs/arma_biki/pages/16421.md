## BIS fnc playEndMusic

- Source: https://community.bistudio.com/wiki/BIS_fnc_playEndMusic
- Revision: 323870
- Updated: 2022-07-01T11:53:44Z

- Availability: arma3 1.00
- Groups: Sound

### Description

Play mission end music (when it is nearing the end)

### Syntax

```sqf
play call BIS_fnc_playEndMusic
```

### Parameters

- play: Boolean - true to play it, false to stop playing

### Return Value

- Boolean - true when function is done

### Examples

#### Example 1

```sqf
true call BIS_fnc_playEndMusic;
```
