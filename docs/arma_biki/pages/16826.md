## shownChat

- Source: https://community.bistudio.com/wiki/shownChat
- Revision: 310766
- Updated: 2022-05-07T20:21:39Z

- Availability: arma3 1.36
- Groups: Radio and Chat

### Description

Returns true if chat window is enabled. Chat window can be disabled with showChat command.

### Syntax

```sqf
**shownChat**
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_bool = shownChat;
```
