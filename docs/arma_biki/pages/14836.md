## curatorEditableObjects

- Source: https://community.bistudio.com/wiki/curatorEditableObjects
- Revision: 377173
- Updated: 2026-01-01T10:46:13Z

- Availability: arma3 1.16
- Locality: argument global
- Groups: Curator

### Description

Returns all editable objects which belong to a curator.

### Syntax

```sqf
curatorEditableObjects curatorObj
```

### Parameters

- curatorObj: Object - curator module.

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_objects = curatorEditableObjects myCurator;
```
