## addMagazineTurret

- Source: https://community.bistudio.com/wiki/addMagazineTurret
- Revision: 377495
- Updated: 2026-01-02T06:49:20Z

- Availability: arma2oa 1.52, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Turrets

### Description

Adds a magazine to the turret. Use turret path `[-1]` for driver's turret.
Invalid combinations may be created by using this command, for example by adding 20 grenades. In these cases, behaviour is undefined.

### Syntax

```sqf
vehicle addMagazineTurret [magazineName, turretPath, ammoCount]
```

### Parameters

- vehicle: Object
- magazineName: String
- turretPath: Turret Path
- ammoCount: Number - (Optional, default 0) desired ammo count

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_tank addMagazineTurret ["SmokeLauncherMag", [0,0]];
```

#### Example 2

```sqf
_tank addMagazineTurret ["20Rnd_120mmSABOT_M1A2", [0]];
```

#### Example 3

```sqf
_tank addMagazineTurret ["20Rnd_120mmSABOT_M1A2", [0], 10]; // add magazine with 10 rounds
```
