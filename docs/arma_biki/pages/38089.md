## forceHitPointsDamageSync

- Source: https://community.bistudio.com/wiki/forceHitPointsDamageSync
- Revision: 370215
- Updated: 2024-11-09T23:07:51Z

- Availability: arma3 2.18
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Synchronises hitpoints values and total damage across current network clients as well as JIP.
Possible uses after executing script commands such as setHit, setHitIndex, setHitPointDamage or in conjunction with [HandleDamage](Arma 3: Event Handlers#HandleDamage) event handler (see #Example 2).

### Multiplayer

Static buildings synchronisation should be executed on the server as the server is the authority in building damage and you would want every client in MP to have the same level of damage as the server has.

### Syntax

```sqf
forceHitPointsDamageSync entity
```

### Parameters

- entity: Object - entity

### Return Value

- Boolean - true if sync was attempted

### Examples

#### Example 1

```sqf
forceHitPointsDamageSync house1;
```

#### Example 2

```sqf
house1 addEventHandler ["HandleDamage", 
{
	if (isServer && { _this select 9 == 2 }) then { (_this select 0) spawn { forceHitPointsDamageSync _this; } };
	if (_this select 7 find "glass" >= 0) then { _this select 2 } else { 0 };
}];
```
