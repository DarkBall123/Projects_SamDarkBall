## isTurnedOut

- Source: https://community.bistudio.com/wiki/isTurnedOut
- Revision: 319215
- Updated: 2022-05-13T09:23:23Z

- Availability: arma3 1.42
- Groups: Object Manipulation

### Description

Returns true if given unit is turned out, otherwise false. The output changes to true after unit finished turning out, however will change to false almost immediately after unit is ordered to turn in.

### Syntax

```sqf
isTurnedOut unit
```

### Parameters

- unit: Object - unit on turn(in/out) enabled turret

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_commanderOut = isTurnedOut (tank turretUnit [0,0]);
```
