## tvSetPictureColor

- Source: https://community.bistudio.com/wiki/tvSetPictureColor
- Revision: 377815
- Updated: 2026-01-03T04:13:41Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Sets the colour of the picture (set via tvSetPicture) under the specified tree view path.

### Syntax

```sqf
tvSetPictureColor [idc, path, color]
```

```sqf
ctrl tvSetPictureColor [path, color]
```

### Parameters

- idc: Number - IDC of the tree view control
- path: Tree View Path
- color: Color (RGBA)
- ctrl: Control
- path: Tree View Path
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvSetPictureColor [101, [0,2], [1,0,1,1]];
```

#### Example 2

```sqf
_tree tvSetPictureColor [[0,2], [1,0,1,1]];
```
