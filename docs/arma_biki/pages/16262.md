## BIS fnc moduleChat

- Source: https://community.bistudio.com/wiki/BIS_fnc_moduleChat
- Revision: 328357
- Updated: 2022-07-13T16:00:47Z

- Availability: arma3 1.00
- Locality: effect local
- Groups: Modules

### Description

Make a list of units use any *chat command (groupChat, vehicleChat, sideChat, commandChat, globalChat).

### Syntax

```sqf
[logic, units, isActivated] call BIS_fnc_moduleChat
```

### Parameters

- logic: Object the logic. Possible setVariable parameters:
* "Text": String - the text to be sent
* "Channel": String - (Optional, default "0") a number **as a string**:
** "0": groupChat
** "1": vehicleChat
** "2": sideChat
** "3": commandChat
** "4": globalChat
- units: Array of Objects - list of chatting units
- isActivated: Boolean - (Optional, default true) if true, the module is activated and chat is send. false disables the module

### Return Value

- Boolean - true when done, even if *isActivated* equals false

### Examples

#### Example 1

```sqf
myLogic setVariable ["Channel", "2"];
myLogic setVariable ["Text", "Hello everyone, this is side chat!"];
[myLogic, [player], true] call BIS_fnc_moduleChat;
```
