## addItemToUniform

- Source: https://community.bistudio.com/wiki/addItemToUniform
- Revision: 318719
- Updated: 2022-05-13T09:21:22Z

- Availability: arma3 1.04
- Locality: argument global, effect global
- Groups: Unit Inventory

### Description

Create new item and store it to soldier's uniform. The item can also be a weapon or a magazine.

### Syntax

```sqf
unit addItemToUniform item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addItemToUniform "itemGPS";
```

#### Example 2

```sqf
player addItemToUniform "hgun_Rook40_F";
```
