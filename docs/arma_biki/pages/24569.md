## BIS fnc timeline getAlpha

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_getAlpha
- Revision: 348336
- Updated: 2023-11-08T12:59:45Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Get's current alpha in given timeline.

### Syntax

```sqf
[timeline] call BIS_fnc_timeline_getAlpha
```

### Parameters

- timeline: Object - the timeline object

### Return Value

- Number - current Alpha value

### Examples

#### Example 1

```sqf
private _alpha = [timeline] call BIS_fnc_timeline_getAlpha;
```
