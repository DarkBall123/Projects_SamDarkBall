## moveObjectToEnd

- Source: https://community.bistudio.com/wiki/moveObjectToEnd
- Revision: 363294
- Updated: 2024-03-26T10:52:01Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Shifts an editor object to the end of the objects array. This means,that the object will be drawn last (after all other objects). 
Some Old Editor Command

### Syntax

```sqf
map moveObjectToEnd object
```

### Parameters

- map: Control
- object: String

### Return Value

- Nothing
