## BIS fnc setObjectRotation

- Source: https://community.bistudio.com/wiki/BIS_fnc_setObjectRotation
- Revision: 349342
- Updated: 2023-11-08T14:53:30Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Set object rotation.

### Syntax

```sqf
[object, rotation] call BIS_fnc_setObjectRotation
```

### Parameters

- object: Object - object to manipulate
- rotation: Array - vector in format:
# Yaw
# Pitch
# Roll

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[cursorObject, [100,100,100]] call BIS_fnc_setObjectRotation;
```
