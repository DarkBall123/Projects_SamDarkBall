## canAddItemToUniform

- Source: https://community.bistudio.com/wiki/canAddItemToUniform
- Revision: 376946
- Updated: 2025-12-31T22:55:22Z

- Availability: arma3 1.04
- Groups: Unit Inventory

### Description

Checks if given object can be stored into soldier's uniform.

Avoid passing an empty string 

```sqf
""
```

 to this command as it will create a warning dialog:
none|alt= Warning Message: Bad vehicle type|Warning Message: Bad vehicle type
This message will show once per mission restart.

### Syntax

```sqf
unit canAddItemToUniform item
```

```sqf
unit canAddItemToUniform [item, count, ignoreSoldierMaxLoad]
```

### Parameters

- unit: Object
- item: String
- unit: Object
- item: String
- count: Number
- ignoreSoldierMaxLoad: Boolean - (Optional, default false) true to ignore 'soldierMaxLoad' param, container maxLoad is still counted.

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
_item = "HandGrenade";
_fits = player canAddItemToUniform _item;
if (_fits) then
{
	player addItemToUniform _item;
}
else
{
	hint "no room!";
};
```
