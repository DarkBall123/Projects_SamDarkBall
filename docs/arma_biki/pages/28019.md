## lnbColorRight

- Source: https://community.bistudio.com/wiki/lnbColorRight
- Revision: 377818
- Updated: 2026-01-03T04:15:56Z

- Availability: arma3 1.00
- Groups: GUI Control - ListNBox

### Description

Returns the right color of given row.

### Syntax

```sqf
lnbColorRight [idc, [row, column]]
```

```sqf
ctrl lnbColorRight [row, column]
```

### Parameters

- idc: Number
- row: Number - index of the row
- column: Number - index of the column
- ctrl: Control
- row: Number - index of the row
- column: Number - index of the column

### Return Value

- Color (RGBA)
- Color (RGBA)

### Examples

#### Example 1

```sqf
private _result = _control lnbColorRight [0, 0];
```
