## camSetFovRange

- Source: https://community.bistudio.com/wiki/camSetFovRange
- Revision: 369601
- Updated: 2024-09-26T20:17:08Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Broken Commands, Camera Control

### Description

Set the zoom level (**F**ield **O**f **V**iew) start and end values for automatical zooming. 

The default zoom level is *`0.7`* where *`0`* is the nearest and *`1`* is the most far zoom value.
 This command is **non-functional**!

### Syntax

```sqf
camera camSetFovRange [minFovRange, maxFovRange]
```

### Parameters

- camera: Object - object of type "camera"
- minFovRange: Number
- maxFovRange: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_cam camSetFovRange [0.1, 0.7];
```
