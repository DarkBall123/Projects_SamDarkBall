## needReload

- Source: https://community.bistudio.com/wiki/needReload
- Revision: 376453
- Updated: 2025-10-14T11:29:23Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapons

### Description

Returns how much vehicle wants to reload its weapons.

### Syntax

```sqf
needReload entity
```

```sqf
entity needReload muzzle
```

### Parameters

- entity: Object - unit or vehicle
- entity: Object - unit or vehicle
- muzzle: String - muzzle to check. "" to check all muzzles

### Return Value

- Number - range: 0-1, 0: full mag, 1: empty mag
- Number - range: 0-1, 0: full mag, 1: empty mag

### Examples

#### Example 1

```sqf
_seriousness = needReload _vehicle;
```

#### Example 2

```sqf
if (needReload player == 1) then { reload player };
```

#### Example 3

```sqf
player needReload currentMuzzle player;
```
