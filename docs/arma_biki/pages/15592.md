## vectorNormalized

- Source: https://community.bistudio.com/wiki/vectorNormalized
- Revision: 378403
- Updated: 2026-04-04T08:14:40Z

- Availability: arma3 1.26
- Groups: Math - Vectors

### Description

Returns normalised vector (unit vector, vectorMagnitude {{=}}{{=}} 1) of given vector. If given vector is 0 result is a 0 vector as well.
* 2.14 any count of numbers is valid
* 2.00 now supports Vector2D (z defaulted to 0)
* 1.26 command introduction, only works with Vector3D

### Syntax

```sqf
vectorNormalized vector
```

### Parameters

- vector: Array of Numbers

### Return Value

- Vector3D

### Examples

#### Example 1

```sqf
vectorNormalized [12345,7890,38383]; // [0.300481,0.192045,0.934254]
vectorMagnitude [0.300481,0.192045,0.934254]; // 1
```
