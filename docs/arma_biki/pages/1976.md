## clearRadio

- Source: https://community.bistudio.com/wiki/clearRadio
- Revision: 370204
- Updated: 2024-11-06T23:34:35Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Radio and Chat

### Description

Clean up the content of radio protocol history.

### Syntax

```sqf
clearRadio
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
for "_i" from 3 to 1 step -1 do
{
	systemChat format ["The chat history will disappear in %1", _i];
	sleep 1;
};

clearRadio;			// removes previous messages
enableRadio false;	// disables the chat
```
