## nMenuItems

- Updated: 2024-03-15T17:11:54Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Returns the total number of user-added menu items belonging to the given menu. Some Old Editor Command

### Syntax

```sqf
map nMenuItems menuName
```

```sqf
map nMenuItems  index
```

### Parameters

- map: Control
- menuName: String - "file" or "view"
- map: Control
- index: Number

### Return Value

- Number
- Number
