## formationDirection

- Source: https://community.bistudio.com/wiki/formationDirection
- Revision: 310863
- Updated: 2022-05-07T20:24:09Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Groups

### Description

Return the direction in degrees of the 'unit' watching in formation.

### Syntax

```sqf
formationDirection unitName
```

### Parameters

- unitName: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
_degrees = formationDirection _unit;
```
