## BIS fnc lerp

- Source: https://community.bistudio.com/wiki/BIS_fnc_lerp
- Revision: 378113
- Updated: 2026-02-17T13:29:28Z

- Availability: arma3 1.00
- Groups: Interpolation

### Description

Linear floating point interpolation (see [Linear Interpolation](https://en.wikipedia.org/wiki/Linear_interpolation)).

### Syntax

```sqf
[currentValue, targetValue, alpha] call BIS_fnc_lerp
```

### Parameters

- currentValue: Number - first point (start)
- targetValue: Number - second point (end)
- alpha: Number - interpolation speed

### Return Value

- Number - interpolated value

### Examples

#### Example 1

```sqf
[1, 10, 0.5] call BIS_fnc_lerp; // returns 5.5
```
