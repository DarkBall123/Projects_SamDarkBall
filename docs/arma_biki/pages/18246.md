## configSourceAddonList

- Source: https://community.bistudio.com/wiki/configSourceAddonList
- Revision: 318786
- Updated: 2022-05-13T09:21:30Z

- Availability: arma3 1.58
- Groups: Mods and Addons, Config

### Description

Returns an array of addons (CfgPatches) in which the given config class is defined.

### Syntax

```sqf
configSourceAddonList config
```

### Parameters

- config: Config

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
_addons = configSourceAddonList (configFile >> "CfgVehicles" >> "Man"); // returns ["A3_Data_F", "A3_Characters_F", "A3_Data_F_Curator", "A3_Air_F_Heli"]
```
