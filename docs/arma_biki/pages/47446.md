## parentAttached

- Source: https://community.bistudio.com/wiki/parentAttached
- Revision: 378907
- Updated: 2026-08-11T14:57:07Z

- Availability: arma3 2.22
- Locality: argument local
- Groups: PhysX

### Description

Get the parent of a attachChild attached child.

### Syntax

```sqf
parentAttached child
```

### Parameters

- child: Object -  Must be a Transport vehicle like Car/Tank (Maybe helicopter/airplane works?).

### Return Value

- Object
