## setAutonomous

- Source: https://community.bistudio.com/wiki/setAutonomous
- Revision: 364993
- Updated: 2024-07-04T19:58:05Z

- Availability: arma3 1.16
- Locality: argument global, effect local
- Groups: Remote Control

### Description

Sets UAV autonomous mode.

### Syntax

```sqf
uav setAutonomous bool
```

### Parameters

- uav: Object
- bool: Boolean

### Return Value

- Boolean - whether the operation was successful. Returns false when the object is not a uav.

### Examples

#### Example 1

```sqf
uav setAutonomous true;
```
