## joinAsSilent

- Source: https://community.bistudio.com/wiki/joinAsSilent
- Revision: 330017
- Updated: 2022-08-15T14:39:44Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Groups

### Description

Joins the unit to the given group, if position id is available, this one is used. Avoid any radio communication related to joining.

### Syntax

```sqf
unit joinAsSilent [group, id]
```

### Parameters

- unit: Object
- group: Group
- id: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player joinAsSilent [_group, 4];
```

#### Example 2

To get the position id:

```sqf
getUnitPositionId = {
	private ["_vvn", "_str"];
	_vvn = vehicleVarName _this;
	_this setVehicleVarName "";
	_str = str _this;
	_this setVehicleVarName _vvn;
	parseNumber (_str select [(_str find ":") + 1])
};
player joinAsSilent [createGroup west, 5];
_id = player call getUnitPositionId;
hint str _id; // 5
```
