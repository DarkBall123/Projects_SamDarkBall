## BIS fnc displayLoading

- Source: https://community.bistudio.com/wiki/BIS_fnc_displayLoading
- Revision: 327045
- Updated: 2022-07-12T21:44:46Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Loading Screens init.

### Syntax

```sqf
[onLoad, id] call BIS_fnc_displayLoading
```

### Parameters

- onLoad: Array - params provided by onLoad UI Event Handler
- id: Number - id of loading screen. Used only for debugging

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
([_this, 2302] call (uiNamespace getVariable 'BIS_fnc_displayLoading')
```
