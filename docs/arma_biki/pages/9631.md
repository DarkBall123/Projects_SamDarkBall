## getBackpackCargo

- Source: https://community.bistudio.com/wiki/getBackpackCargo
- Revision: 378356
- Updated: 2026-04-02T16:38:51Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Groups: Containers

### Description

Returns all backpack types and count from the cargo space.

### Syntax

```sqf
getBackpackCargo object
```

### Parameters

- object: Object - object to check

### Return Value

- Array with [classes, counts]
* classes: Array of Strings - Backpack class names
* counts: Array of Numbers - Backpack counts

### Examples

#### Example 1

```sqf
getBackpackCargo cursorTarget;
/*
	returns e.g
	[
        ["5BackpackA", "10BackpackB"]
        [5, 10]
	]
*/
```

#### Example 2

```sqf
_content = getBackpackCargo carName;
```

#### Example 3

```sqf
_content = getBackpackCargo ammoBoxName;
```
