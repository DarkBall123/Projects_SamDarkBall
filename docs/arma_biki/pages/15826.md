## BIS fnc helicopterSeat

- Source: https://community.bistudio.com/wiki/BIS_fnc_helicopterSeat
- Revision: 323864
- Updated: 2022-07-01T11:53:44Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Helicopters

### Description

Check if unit sits on right or left seat.

### Syntax

```sqf
unit call BIS_fnc_helicopterSeat
```

### Parameters

- unit: Object - unit which should be checked.

### Return Value

- Number:
* -1: Not in a vehicle
*  0: left seat
*  1: right seat

### Examples

#### Example 1

```sqf
player call BIS_fnc_helicopterSeat;
```
