## leaderboardInit

- Source: https://community.bistudio.com/wiki/leaderboardInit
- Revision: 323025
- Updated: 2022-06-28T21:43:08Z

- Availability: arma3 1.56
- Groups: Leaderboards

### Description

Initialize the leaderboard structure for board with given name. Returns true if board is already initialized.

### Syntax

```sqf
leaderboardInit boardName
```

### Parameters

- boardName: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
leaderboardInit "TT01";
```
