## taskDescription

- Source: https://community.bistudio.com/wiki/taskDescription
- Revision: 378417
- Updated: 2026-04-04T08:44:52Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Returns the sub-parts of the task description.

### Syntax

```sqf
taskDescription task
```

### Parameters

- task: Task

### Return Value

- Array with [description, title, waypoint]
* description: String
* title: String
* waypoint: Waypoint

### Examples

#### Example 1

```sqf
_taskDescArray = taskDescription _task;
```

|text= Be careful if you want to use this to retrieve the title of a task.
If the task has no description set, then "taskDescription" will only return an array of empty Strings.

Therefore always use setSimpleTaskDescription directly after creating a new task, even if you set the Description to "".
