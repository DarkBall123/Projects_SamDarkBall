## isSteamOverlayEnabled

- Source: https://community.bistudio.com/wiki/isSteamOverlayEnabled
- Revision: 330173
- Updated: 2022-08-23T12:24:04Z

- Availability: arma3 2.10
- Groups: GUI Control

### Description

Returns true if Steam overlay is enabled, otherwise false.

### Syntax

```sqf
isSteamOverlayEnabled
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_overlayEnabled = isSteamOverlayEnabled;
```
