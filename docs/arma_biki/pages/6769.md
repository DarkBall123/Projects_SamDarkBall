## setText

- Source: https://community.bistudio.com/wiki/setText
- Revision: 322962
- Updated: 2022-06-28T21:42:51Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations

### Description

Sets the text associated with a location. This text will be displayed on the game map at the location's position.

### Syntax

```sqf
location setText text
```

### Parameters

- location: Location
- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLocation setText "Rahmadi Village";
```
