## removeOwnedMine

- Source: https://community.bistudio.com/wiki/removeOwnedMine
- Revision: 347976
- Updated: 2023-11-08T09:47:29Z

- Availability: arma3 1.62
- Groups: Mines

### Description

Removes ownership over a remotely detonatable mine from the unit.

### Syntax

```sqf
unit removeOwnedMine mine
```

### Parameters

- unit: Object
- mine: Object - the mine object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeOwnedMine SuperMine;
```
