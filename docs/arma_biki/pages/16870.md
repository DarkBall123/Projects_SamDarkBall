## removeSecondaryWeaponItem

- Source: https://community.bistudio.com/wiki/removeSecondaryWeaponItem
- Revision: 319509
- Updated: 2022-05-13T09:24:13Z

- Availability: arma3 1.38
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes given weapon item, including magazine, from the secondaryWeapon.

### Syntax

```sqf
unit removeSecondaryWeaponItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeSecondaryWeaponItem (secondaryWeaponItems player select 0);
```
