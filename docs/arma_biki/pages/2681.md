## isNumber

- Source: https://community.bistudio.com/wiki/isNumber
- Revision: 323074
- Updated: 2022-06-28T21:43:12Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Config

### Description

Check if config entry represents number.

### Syntax

```sqf
isNumber config
```

### Parameters

- config: Config

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_ok = isNumber (configFile >> "CfgVehicles");
```

Result is false
