## kbHasTopic

- Source: https://community.bistudio.com/wiki/kbHasTopic
- Revision: 319151
- Updated: 2022-05-13T09:23:15Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Conversations

### Description

Check if conversation topic was registered to given person. See Conversations for more details.

### Syntax

```sqf
person kbHasTopic topicName
```

### Parameters

- person: Object
- topicName: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_obiHasTopic = player kbHasTopic "helloThereGeneralK";
```

#### Example 2

```sqf
if (player kbHasTopic "dontShoot") then { player kbRemoveTopic "dontShoot"; };
```
