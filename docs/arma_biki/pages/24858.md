## BIS fnc 3den onKeyDown

- Source: https://community.bistudio.com/wiki/BIS_fnc_3den_onKeyDown
- Revision: 363331
- Updated: 2024-03-27T09:38:04Z

- Availability: arma3 1.56
- Groups: KeyframeAnimation

### Description

Used internally by the Arma 3: Key Frame Animation system. Called when a button is pressed.

### Syntax

```sqf
[display, button, shift, ctrl, alt] call BIS_fnc_3den_onKeyDown
```

### Parameters

- display: Display - the display
- button: Number - key code of the pressed button
- shift: Boolean - {{Controls|Shift}} key
- ctrl: Boolean - {{Controls|Ctrl}} key
- alt: Boolean - {{Controls|Alt}} key

### Return Value

- Boolean - whether or not to consume the input

### Examples

#### Example 1

```sqf
findDisplay 313 displayAddEventHandler ["keyDown", { _this call BIS_fnc_3den_onKeyDown }];
```
