## lnbColor

- Source: https://community.bistudio.com/wiki/lnbColor
- Revision: 377372
- Updated: 2026-01-02T06:42:22Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Returns the text color of the item with the given position of the 2D listbox. The color is returned in format Color (RGBA).

### Syntax

```sqf
lnbColor [idc, [row, column]]
```

```sqf
control lnbColor [row, column]
```

### Parameters

- idc: Number
- row: Number
- column: Number
- control: Control
- row: Number
- column: Number

### Return Value

- Color (RGBA)
- Color (RGBA)

### Examples

#### Example 1

```sqf
_ctrl lnbColor [0,0];
```
