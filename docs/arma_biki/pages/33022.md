## ctrlShadow

- Source: https://community.bistudio.com/wiki/ctrlShadow
- Revision: 330174
- Updated: 2022-08-23T12:24:04Z

- Availability: arma3 2.10
- Groups: GUI Control

### Description

Returns 'shadow' property of the control (see ctrlSetShadow).

### Syntax

```sqf
ctrlShadow control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_shadow = ctrlShadow _control;
```

### See Also

ctrlSetShadow ctrlCreate
