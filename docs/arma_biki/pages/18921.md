## BIS fnc 3DENExportTerrainBuilder

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENExportTerrainBuilder
- Revision: 342143
- Updated: 2023-07-09T12:26:47Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Gets all empty vehicles placed in the currently opened Eden mission and converts data into the format used by the Terrain Builder.

### Syntax

```sqf
call BIS_fnc_3DENExportTerrainBuilder
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_3DENExportTerrainBuilder;
```
