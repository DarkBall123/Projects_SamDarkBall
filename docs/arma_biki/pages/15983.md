## BIS fnc liveFeedEffects

- Source: https://community.bistudio.com/wiki/BIS_fnc_liveFeedEffects
- Revision: 348076
- Updated: 2023-11-08T11:30:43Z

- Availability: arma3 1.00
- Groups: Live Feed

### Description

Add effect to the current live feed.

### Syntax

```sqf
effect call BIS_fnc_liveFeedEffects
```

### Parameters

- effect: Number - (Optional, default 0) live feed effect. Can be one of:
* -1: reset
*  0: normal
*  1: night vision
*  2: thermal imaging

### Return Value

- Boolean - true if successful, false if not

### Examples

#### Example 1

```sqf
1 call BIS_fnc_liveFeedEffects;
```
