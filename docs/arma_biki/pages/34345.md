## addCuratorSelected

- Source: https://community.bistudio.com/wiki/addCuratorSelected
- Revision: 377569
- Updated: 2026-01-02T06:56:16Z

- Availability: arma3 2.14
- Groups: Curator

### Description

Add items to the selected curator items.

### Syntax

```sqf
addCuratorSelected items
```

### Parameters

- items: Array - items to add; items can be an Object, Group, Waypoint, or String (marker)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
addCuratorSelected [unit1, group1, [group1, waypointIndex], markerName1];
```

#### Example 2

```sqf
addCuratorSelected [vehicle1, unit1, unit2, unit3, unit4, group1];
```
