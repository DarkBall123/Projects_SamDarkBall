## vectorFromTo

- Source: https://community.bistudio.com/wiki/vectorFromTo
- Revision: 378369
- Updated: 2026-04-03T16:47:19Z

- Availability: arma3 1.26
- Groups: Math - Vectors

### Description

Unit vector, equal to direction from vector1 to vector2. In other words this command produces normalised vector between given 2 points.

To get a non-normalised vector, use vectorDiff.

### Syntax

```sqf
vector1 vectorFromTo vector2
```

### Parameters

- vector1: Vector3D or Vector2D - 3D or 2.00 2D vector (z coordinate is defaulted to 0)
- vector2: Vector3D or Vector2D - 3D or 2.00 2D vector (z coordinate is defaulted to 0)

### Return Value

- Vector3D

### Examples

#### Example 1

```sqf
[1,2,3] vectorFromTo [4,5,6];
// is the same as
vectorNormalized ([4,5,6] vectorDiff [1,2,3]);
```
