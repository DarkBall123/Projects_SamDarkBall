## ctrlTextSecondary

- Source: https://community.bistudio.com/wiki/ctrlTextSecondary
- Revision: 349260
- Updated: 2023-11-08T14:51:05Z

- Availability: ofp, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns the secondary text of a text control.

### Syntax

```sqf
ctrlTextSecondary control
```

### Parameters

- control: Control - text control

### Return Value

- String - secondary text of given control

### Examples

#### Example 1

```sqf
_secondaryText = ctrlTextSecondary _ctrlText;
```
