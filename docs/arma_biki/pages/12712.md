- Revision: 376274
- Updated: 2025-09-23T06:13:45Z

- Availability: arma3 1.04
- Locality: argument global, effect global
- Groups: Containers

### Description

Removes item from soldier's vest.

### Syntax

```sqf
unit removeItemFromVest item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeItemFromVest "itemWatch";
```
