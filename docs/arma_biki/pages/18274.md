## setSimpleTaskAlwaysVisible

- Source: https://community.bistudio.com/wiki/setSimpleTaskAlwaysVisible
- Revision: 304127
- Updated: 2022-01-20T16:59:47Z

- Availability: arma3 1.58
- Locality: effect local
- Groups: Briefing

### Description

Sets task's visibility.

### Syntax

```sqf
taskID setSimpleTaskAlwaysVisible state
```

### Parameters

- taskID: Task
- state: Boolean - true for always visible, false for fade out

### Return Value

- Nothing

### Examples

#### Example 1

currentTask player setSimpleTaskAlwaysVisible true;
