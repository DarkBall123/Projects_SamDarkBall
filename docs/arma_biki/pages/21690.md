## vectorModelToWorld

- Source: https://community.bistudio.com/wiki/vectorModelToWorld
- Revision: 378448
- Updated: 2026-04-16T17:00:30Z

- Availability: arma3 1.72
- Groups: Math - Vectors

### Description

Converts vector direction from model to world space.
For scaled objects, the resulting vector's magnitude will also be multiplied by the object scale.

### Syntax

```sqf
object vectorModelToWorld modelDir
```

### Parameters

- object: Object
- modelDir: Vector3D - vector direction in model space in format [x,y,z]

### Return Value

- Vector3D - vector direction in world space

### Examples

#### Example 1

Convert model space vector [0,-10,4] to world space; vector gets rotated according to _airplane: 

```sqf
_airplane vectorModelToWorld [0,-10,4];
```
