## setWaypointHousePosition

- Source: https://community.bistudio.com/wiki/setWaypointHousePosition
- Revision: 377754
- Updated: 2026-01-03T00:58:10Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

For waypoints attached to a house, this defines the target buildingPos index.

### Syntax

```sqf
waypoint setWaypointHousePosition pos
```

### Parameters

- waypoint: Waypoint
- pos: Number - buildingPos index

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointHousePosition 1;
```
