## addSecondaryWeaponItem

- Source: https://community.bistudio.com/wiki/addSecondaryWeaponItem
- Revision: 318671
- Updated: 2022-05-13T09:21:17Z

- Availability: arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Adds weapon item, including magazine, directly to the secondaryWeapon. This is used for infantry weapons.

### Syntax

```sqf
unit addSecondaryWeaponItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addSecondaryWeaponItem "muzzle_snds_L";
```
