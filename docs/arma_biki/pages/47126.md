## allExtensions

- Source: https://community.bistudio.com/wiki/allExtensions
- Revision: 378520
- Updated: 2026-05-04T01:49:51Z

- Availability: arma3 2.18
- Groups: System

### Description

Returns information about all loaded Extensions

### Syntax

```sqf
allExtensions
```


### Return Value

- Array of HashMaps - one for each extension, containing the following keys
* name: String
* hash: String - sha1
* hasRVExtensionVersion: Boolean
* hasRVExtensionRequestUI: Boolean
* hasRVExtensionArgs: Boolean
* hasRVExtensionContext: Boolean
* hasRVExtensionRegisterCallback: Boolean
* hasRVExtension: Boolean
* hasRVExtensionFeatureFlags: Array of Strings
* signatures: Array of Strings
* productVersion: String
* dllVersion: Boolean
* fileVersion: Boolean
* dllVersion: Boolean
* mod: String

### Examples

#### Example 1

```sqf
// Get hash for extension emm_api
private _extensionHash = ""; 
{ 
    if ((_x getOrDefault ["name", ""]) == "emm_api") exitWith { 
        _extensionHash = _x getOrDefault ["hash", ""]; 
    }; 
} forEach allExtensions;
_extensionHash // "4CD820DBDBCAEBE6FF654762DA41AF6C97D013B4"
```
