## connectToServer

- Source: https://community.bistudio.com/wiki/connectToServer
- Revision: 373150
- Updated: 2025-04-04T09:14:53Z

- Availability: arma3 2.00
- Groups: System

### Description

Connects the client to the provided server.
* only works on the Main Menu.
* must be executed from UI context, such as *onButtonDown* or similar events (see User Interface Event Handlers).

arma3|2.20|
If port is 0, the IP will be resolved as a SRV DNS Record.

["domain.com", 0, "password"] will be resolved as "_arma3._udp.domain.com".

Only the first found record will be used, there is no support for multiple records with priority/weights.

### Syntax

```sqf
connectToServer [ip, port, password]
```

### Parameters

- ip: String - IP in https://en.wikipedia.org/wiki/IPv4 format or 2.20 domain name
- port: Number
- password: String - "" if no password

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
connectToServer ["192.168.0.2", 2302, "test"];
```

#### Example 2

```sqf
connectToServer ["publicserver.mydomain.com", 2302, ""];
```
