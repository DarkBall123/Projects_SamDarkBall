## modelToWorldVisual

- Source: https://community.bistudio.com/wiki/modelToWorldVisual
- Revision: 377834
- Updated: 2026-01-03T04:32:01Z

- Availability: arma3 1.32
- Groups: Object Manipulation, Render Time Scope

### Description

Converts position from object model space to world space in render time scope. For ASL version see modelToWorldVisualWorld.
For scaled objects, the relative position will first be multiplied by the object scale.

For example, if the object scale is 2, 

```sqf
_obj modelToWorldVisual [0,1,0]
```

 will be offset **2 meters** from the model center (

```sqf
[0,0,0]
```

).

### Syntax

```sqf
object modelToWorldVisual  modelPos
```

### Parameters

- object: Object
- modelPos: Array - in format PositionRelative ([x,y,z] offset relative to the model centre)

### Return Value

- PositionAGL - world position

### Examples

#### Example 1

```sqf
_aboveAndBehindPlayer = player modelToWorldVisual [0,-1,3];
```
