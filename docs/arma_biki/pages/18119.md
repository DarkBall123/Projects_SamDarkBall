## hideSelection

- Source: https://community.bistudio.com/wiki/hideSelection
- Revision: 330039
- Updated: 2022-08-15T15:23:51Z

- Availability: arma3 1.58
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Hides or shows the simple object's provided selection.

### Syntax

```sqf
object hideSelection [selection, hidden]
```

### Parameters

- object: Object - simple object
- selection: String - selection name
- hidden: Boolean - true to hide, false to show

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_simpleObject hideSelection ["some_selection", true];
```
