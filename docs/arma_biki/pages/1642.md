## loadIdentity

- Source: https://community.bistudio.com/wiki/loadIdentity
- Revision: 322977
- Updated: 2022-06-28T21:42:55Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Identity

### Description

Loads person's identity from Objects.sav file in campaign directory (from entry name).

### Multiplayer

This command does not work in Multiplayer.

### Syntax

```sqf
unit loadIdentity  name
```

### Parameters

- unit: Object
- name: String

### Return Value

- Boolean - true if successfull, otherwise false

### Examples

#### Example 1

```sqf
_ok = player loadIdentity "playerIdentity";
```
