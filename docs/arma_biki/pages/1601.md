## deleteVehicle

- Source: https://community.bistudio.com/wiki/deleteVehicle
- Revision: 352346
- Updated: 2024-02-08T14:01:50Z

- Availability: ofp 1.34, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Deletes an object. Only objects inserted in the mission editor and objects created during the game's progress can be deleted by this command. Terrain objects and players cannot be deleted.
The actual object deletion, when the object becomes objNull, happens on the next frame after command execution, but there are some object modifications that happen immediately. For example if the object is a unit in a group, it immediately becomes groupless (

```sqf
isNull group _unit; // true
```

).

### Syntax

```sqf
deleteVehicle object
```

```sqf
deleteVehicle objects
```

### Parameters

- object: Object
- objects: Array of Objects

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
deleteVehicle _house1;
```

#### Example 2

Deleting a vehicle with crew:

```sqf
// might want to make sure that the car is local
{ car deleteVehicleCrew _x } forEach crew car;
deleteVehicle car;
```
