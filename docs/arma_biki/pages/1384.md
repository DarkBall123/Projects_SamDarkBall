### Description

Get provided waypoint's position.

### Syntax

```sqf
waypointPosition [groupOrUnit, index]
```

### Parameters

- groupOrUnit: Group or Object
- index: Number

### Return Value

- PositionAGL

### Examples

#### Example 1

```sqf
_wPos = waypointPosition [_groupOne, 1];
```
