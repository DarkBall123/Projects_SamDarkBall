### Description

Defines a comment. See SQF Syntax#Comments to learn more about comments.
This command is evaluated during execution, and as such is infinitely slower than other SQF comment methods (

```sqf
// comment
```

 or 

```sqf
/* comment */
```

) which get preprocessed and do not exist at runtime).
See SQF Syntax for additional documentation on comments.
This command is only used to place comments in unpreprocessed codes, such as trigger On Activation field, object init field, etc.
Alternatively, one can use a plain string followed by a semicolon as a way to comment; e.g 

```sqf
"Some comment";
```

.

### Syntax

```sqf
comment text
```

### Parameters

- text: String - the comment

### Return Value

- Nothing

### Examples

#### Example 1

In a preprocessed SQF script (e.g. when doing 

```sqf
execVM "myScript.sqf"
```

)

```sqf
comment "This is a commented line";		// bad
"This is a commented line";				// slightly better
// This is a commented line				// perfect
```

#### Example 2

In an object init field (in editor):

```sqf
comment "This comment works";
"This comment works too";
// This doesn't work
/* This doesn't work either */
```
