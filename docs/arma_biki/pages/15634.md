## BIS fnc arrayCompare

- Source: https://community.bistudio.com/wiki/BIS_fnc_arrayCompare
- Revision: 327523
- Updated: 2022-07-12T22:31:18Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays

### Description

This function checks if two arrays are containing the same elements in the same order.
{{Feature|important|This function is deprecated in {{arma2}} as it fails with certain data types; see BIS_fnc_areEqual for {{arma2}}.}}
Use isEqualTo instead.

### Syntax

```sqf
[array1, array2] call BIS_fnc_arrayCompare
```

### Parameters

- array1: Array
- array2: Array

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _array1 = [0,1,2];
private _array2 = [0,1,2];
[_array1, _array2] call BIS_fnc_arrayCompare; // returns true
```
