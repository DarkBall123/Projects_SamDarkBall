## enableAutoTrimRTD

- Source: https://community.bistudio.com/wiki/enableAutoTrimRTD
- Revision: 377767
- Updated: 2026-01-03T01:32:12Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Toggle auto-trim for RTD helicopters. 
{{Feature|afm}}

### Syntax

```sqf
helicopterRTD enableAutoTrimRTD enable
```

### Parameters

- helicopterRTD: ObjectRTD - helicopter
- enable: Boolean - enable or disable

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
myHelicopterRTD enableAutoTrimRTD true;
```
