## getBurningValue

- Source: https://community.bistudio.com/wiki/getBurningValue
- Revision: 319274
- Updated: 2022-05-13T09:23:29Z

- Availability: arma3 0.50
- Groups: Object Manipulation

### Description

Returns how much the unit is exposed to fire damage.

### Syntax

```sqf
getBurningValue unit
```

### Parameters

- unit: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _fireDamage = getBurningValue player;
```
