## getObjectArgument

- Source: https://community.bistudio.com/wiki/getObjectArgument
- Revision: 376411
- Updated: 2025-10-11T01:03:00Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Return name of object argument in mission editor.
Some Old Editor Command

### Syntax

```sqf
map getObjectArgument [object, argument]
```

### Parameters

- map: Control
- object: Object
- argument: String

### Return Value

- String

### Examples

#### Example 1

```sqf
// returns string "[1009.0351, 1319.4928]"
(findDisplay 128 displayCtrl 51) getObjectArgument ["_unit_1", "POSITION"];

// returns array [1009.0351, 1319.4928]
(findDisplay 128 displayCtrl 51) evalObjectArgument ["_unit_1", "POSITION"];
```
