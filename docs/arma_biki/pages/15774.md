## BIS fnc dbClassId

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbClassId
- Revision: 363984
- Updated: 2024-04-29T23:12:17Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Converts string to class definition.

### Syntax

```sqf
text call BIS_fnc_dbClassId
```

### Parameters

- text - String: string to convert to class definition

### Return Value

- String: class definition

### Examples

#### Example 1

```sqf
"miller" call BIS_fnc_dbClassId; // "#MILLER"
```
