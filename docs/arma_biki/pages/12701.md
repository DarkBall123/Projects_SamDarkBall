## setWaypointLoiterRadius

- Source: https://community.bistudio.com/wiki/setWaypointLoiterRadius
- Revision: 319763
- Updated: 2022-05-13T09:24:51Z

- Availability: arma3 1.00
- Groups: Waypoints

### Description

Assignes loiter radius to waypoint

### Syntax

```sqf
waypoint setWaypointLoiterRadius radius
```

### Parameters

- waypoint: Waypoint
- radius: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointLoiterRadius 200;
```
