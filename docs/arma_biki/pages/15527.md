## detectedMines

- Source: https://community.bistudio.com/wiki/detectedMines
- Revision: 377169
- Updated: 2026-01-01T10:45:10Z

- Availability: arma3 1.24
- Groups: Mines

### Description

Returns an array of all mines detected by a given side

### Syntax

```sqf
detectedMines side
```

### Parameters

- side: side

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
detectedMines west;
```

#### Example 2

```sqf
detectedMines side player;
```
