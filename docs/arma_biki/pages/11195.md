## BIS fnc wpTimed

- Source: https://community.bistudio.com/wiki/BIS_fnc_wpTimed
- Revision: 329167
- Updated: 2022-07-25T12:42:19Z

- Availability: tkoh 1.00
- Groups: Waypoints

### Description

COUNTDOWN custom waypoint.

Player has to reach waypoint area before time runs out.

### Syntax

```sqf
Custom Waypoint arguments: [failCode,timeLimit,showHint]
```

### Parameters

- failCode: Code - (Optional, default 

```sqf
{}
```

 code executed when time runs oout before player reach the waypoint
- timeLimit: Number - (Optional, default 30) limit in seconds
- showHint: Boolean - (Optional, default false) true to show info about time left

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, position dude, 100, { hintC "You failed!" }, 42, true] spawn BIS_fnc_wpTimed;
```
