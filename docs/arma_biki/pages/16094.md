## BIS fnc setRank

- Source: https://community.bistudio.com/wiki/BIS_fnc_setRank
- Revision: 349416
- Updated: 2023-11-08T16:27:30Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Set rank of vehicle crew.

### Syntax

```sqf
[target, rank] call BIS_fnc_setRank
```

### Parameters

- target: Object - the vehicle whose crew's rank should be adjusted
- rank: String or Number - rank name or rank ID, can be:

0 - "Private"

1 - "Corporal"

2 - "Sergeant"

3 - "Lieutenant"

4 - "Captain"

5 - "Major"

6 - "Colonel"

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[vehicle player, "Captain"] call BIS_fnc_setRank;
```
