## BIS fnc paramDaytime

- Source: https://community.bistudio.com/wiki/BIS_fnc_paramDaytime
- Revision: 352533
- Updated: 2024-02-12T16:42:18Z

- Availability: arma3 1.00
- Locality: server execution server
- Groups: Mission Parameters

### Description

Sets time of the day to the hour. Minutes will always be zero.

### Syntax

```sqf
datetime call BIS_fnc_paramDaytime
```

### Parameters

- datetime: Number or Array - (Optional, default dayTime):
* Number - day hour. This will set the hour **in the same day** (unless 23 < *hour* < 0).
Float numbers are floored
* Array - dayTime format: [year, month, day, hour, minute]

### Return Value

- Array - set date

### Examples

#### Example 1

```sqf
private _date = 12 call BIS_fnc_paramDaytime;
```

#### Example 2

```sqf
private _date = [2001, 01, 01, 12, 00] call BIS_fnc_paramDaytime;
```

#### Example 3

```sqf
private _date = call BIS_fnc_paramDaytime;
```
