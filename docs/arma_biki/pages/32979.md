## OGV File Format

- Source: https://community.bistudio.com/wiki/OGV_File_Format
- Revision: 373411
- Updated: 2025-05-08T11:27:11Z

The **OGV** format is a video format that is playable in {{arma2oa}} and Arma 3 (through e.g BIS_fnc_playVideo).

The ffmpeg tool provides a conversion output that works in Arma 3 up until ffmpeg's **4.0.2** version
(4.1 and above versions have a documented bug regarding this feature: [bug report](https://trac.ffmpeg.org/ticket/8471)).
