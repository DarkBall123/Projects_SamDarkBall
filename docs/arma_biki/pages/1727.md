## switchLight

- Source: https://community.bistudio.com/wiki/switchLight
- Revision: 364994
- Updated: 2024-07-04T19:58:05Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Lights

### Description

Controls whether a lamp is lit or not.
This command was originally designed to only work with `CfgNonAIVehicles` class `"StreetLamp"` only.
Since Arma 3 v1.92 this command was extended to work with street lights and some prop lights, like portable construction light.

### Syntax

```sqf
lamp switchLight mode
```

### Parameters

- lamp: Object
- mode: String - mode can be: "ON", "OFF" or "AUTO" (*lamp* is on only during nighttime, default)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
(object 12345) switchLight "OFF";
```

#### Example 2

```sqf
nearestObject [player, "Streetlamp"] switchLight "OFF";
```

#### Example 3

```sqf
cursorObject switchLight "ON";
```

Switch all lights off in the 500 radius of player:

```sqf
private _lamps = nearestObjects [player, ["Lamps_base_F", "PowerLines_base_F", "PowerLines_Small_base_F"], 500];

{
	for "_i" from 0 to (count getAllHitPointsDamage _x -1) do
	{
		_x setHitIndex [_i, 0.97];
	};
} forEach _lamps;
```

|text= How to disable all lamps using the latest Arma 3 commands, a modern method. Disable all lights that are pre-placed on the map, on the entire map:

```sqf
{
	_x switchLight "OFF";
} forEach (1 allObjects 0);
```

Disable all script-spawned and editor-placed lamps:

```sqf
{
	_x switchLight "OFF";
} forEach (8 allObjects 0);
```

These snippets iterate through all buildings and run switchLight on them. If they're lamps, they'll be turned off.
