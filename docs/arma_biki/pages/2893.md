## ctrlSetTooltipColorText

- Source: https://community.bistudio.com/wiki/ctrlSetTooltipColorText
- Revision: 377176
- Updated: 2026-01-01T10:47:06Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets tooltip text color of given control.

### Syntax

```sqf
display ctrlSetTooltipColorText color
```

### Parameters

- display: Control
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetTooltipColorText [1, 0, 0, 1];
```
