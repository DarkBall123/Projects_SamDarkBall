## turretOwner

- Source: https://community.bistudio.com/wiki/turretOwner
- Revision: 377490
- Updated: 2026-01-02T06:49:12Z

- Availability: arma3 1.38
- Locality: argument global, server execution server
- Groups: Turrets

### Description

Returns id of the turret's owner. Returns 0 on non-server and SP.

### Multiplayer

A vehicle turret will change locality when player gunner gets in it, just like vehicle changes locality when player driver gets in it. Many commands for turrets work only where turret is local. When gunner leaves turret it is supposed to change locality to the locality of the vehicle. A vehicle can have one owner while turrets have different owners.

### Syntax

```sqf
vehicle turretOwner turretPath
```

### Parameters

- vehicle: Object
- turretPath: Turret Path - since 2.08 [-1] (driver) is supported

### Return Value

- Number - owner id

### Examples

#### Example 1

```sqf
_ownerId = vehicle player turretOwner [0];
```
