## BIS fnc removeScriptedEventHandler

- Source: https://community.bistudio.com/wiki/BIS_fnc_removeScriptedEventHandler
- Revision: 327930
- Updated: 2022-07-13T12:30:39Z

- Availability: arma3 1.00
- Groups: Event Handlers

### Description

Removes scripted event handler with given name and id.
Additionally "ScriptedEventHandlerRemoved" scripted EH is called.
For a list of available scripted event handlers, see Arma 3: Scripted Event Handlers.

### Syntax

```sqf
[namespace, name, id] call BIS_fnc_removeScriptedEventHandler
```

### Parameters

- namespace: Namespace, Object, Group, Location, Boolean, Control or Display - namespace in which handler is saved
- name: String - handler name
- id: Number - EH id

### Return Value

- Boolean - true if removed, false if didn't exist

### Examples

#### Example 1

```sqf
[missionNamespace, "event", 2] call BIS_fnc_removeScriptedEventHandler;
```
