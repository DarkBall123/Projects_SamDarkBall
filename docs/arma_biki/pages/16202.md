## BIS fnc saveInventory

- Source: https://community.bistudio.com/wiki/BIS_fnc_saveInventory
- Revision: 378580
- Updated: 2026-05-10T21:43:21Z

- Availability: arma3 1.00
- Groups: Inventory

### Description

Save unit's loadout.

### Syntax

```sqf
[unit, input, params, delete] call BIS_fnc_saveInventory
```

### Parameters

- unit: Object - unit whose inventory should be saved
- input: Array format [target, loadoutName]:
* target: Namespace, Group or Object - target where the loadout is stored
* loadoutName: String - loadout name
- params: Array - (Optional, default []) custom parameters stored with the loadout
- delete: Boolean - (Optional, default false) whether or not to delete the loadout

### Return Value

- Array - saved value

### Examples

#### Example 1

```sqf
[player, [missionNamespace, "BIS_inv"], [], true] call BIS_fnc_saveInventory;
```
