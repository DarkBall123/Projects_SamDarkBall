## isVehicleSensorEnabled

- Source: https://community.bistudio.com/wiki/isVehicleSensorEnabled
- Revision: 363162
- Updated: 2024-03-24T17:32:35Z

- Availability: arma3 1.72
- Groups: Sensors

### Description

Returns class name (to identify list based on component name) and info if given sensor is enabled.

### Syntax

```sqf
vehicle isVehicleSensorEnabled componentName
```

### Parameters

- vehicle: Object
- componentName : String - the component's name (can either be it is "real name" or it is className)

### Return Value

- Array

### Examples

#### Example 1

```sqf
vehicle player isVehicleSensorEnabled "PassiveRadarSensorComponent"; // [<nowiki/>["PassiveRadarSensorComponent", true]]
```
