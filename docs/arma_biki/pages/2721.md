## echo

- Source: https://community.bistudio.com/wiki/echo
- Revision: 321915
- Updated: 2022-05-22T12:29:47Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Diagnostic, Broken Commands

### Description

Sends any text into the debugger console or the logfile. This command is only **present in internal version ** not in the retail version. Use diag_log instead!

### Syntax

```sqf
echo  text
```

### Parameters

- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
echo "Text in logfile";
```
