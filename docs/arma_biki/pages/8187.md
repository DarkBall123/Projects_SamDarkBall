## clearGroupIcons

- Source: https://community.bistudio.com/wiki/clearGroupIcons
- Revision: 347632
- Updated: 2023-09-28T20:46:38Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Removes all icons from group.

### Syntax

```sqf
clearGroupIcons  group
```

### Parameters

- group: Group

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
clearGroupIcons (group player);
```
