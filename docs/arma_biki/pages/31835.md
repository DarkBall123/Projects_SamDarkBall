## hashValue

- Source: https://community.bistudio.com/wiki/hashValue
- Revision: 373375
- Updated: 2025-05-04T09:05:03Z

- Availability: arma3 2.06
- Groups: HashMap

### Description

Processes provided *value*<nowiki/>'s hash, and encodes it using [Base64](https://en.wikipedia.org/wiki/Base64). The hash algorithm is [FNV-1A 64bit](https://en.wikipedia.org/wiki/Fowler%E2%80%93Noll%E2%80%93Vo_hash_function).
A hash value remains the same between game restarts but for Object and Group type, their hash being based on their netId.

### Syntax

```sqf
hashValue value
```

### Parameters

- value: Array, Boolean, Code, Config, Group, Namespace, NaN, Number, Object, Side or String

### Return Value

- String - base64-encoded 64 bits hash

### Examples

#### Example 1

```sqf
private _valueHash = hashValue "Hello There";
```

#### Example 2

```sqf
private _isCorrectPW = hashValue _enteredPassword == "eWkXUUqiinE";
```

#### Example 3

```sqf
hashValue (systemTime joinString ""); // Returns a unique hash value such as "xoMQ9qd7S60"
```
