## loadCuratorSelectionPreset

- Source: https://community.bistudio.com/wiki/loadCuratorSelectionPreset
- Revision: 347228
- Updated: 2023-09-05T17:11:28Z

- Availability: arma3 2.14
- Groups: Curator

### Description

Load the given selection preset to the current selection of the curator.

### Syntax

```sqf
loadCuratorSelectionPreset numkey
```

### Parameters

- numkey: Number - the number key under which the selection preset is saved

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
loadCuratorSelectionPreset 1;
```
