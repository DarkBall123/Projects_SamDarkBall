## ASLToAGL

- Source: https://community.bistudio.com/wiki/ASLToAGL
- Revision: 377463
- Updated: 2026-01-02T06:47:34Z

- Availability: arma3 1.50
- Groups: Positions

### Description

Converts position from PositionASL to PositionAGL

### Syntax

```sqf
ASLToAGL posASL
```

### Parameters

- posASL: PositionASL - position to convert

### Return Value

- PositionAGL

### Examples

#### Example 1

```sqf
_playerPosAGL = ASLToAGL getPosASL player;
```
