## BIS fnc findExtreme

- Source: https://community.bistudio.com/wiki/BIS_fnc_findExtreme
- Revision: 327983
- Updated: 2022-07-13T15:22:38Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays, Math

### Description

Returns the minimum or maximum value in an array of numbers.

### Syntax

```sqf
[numbers, mode] call BIS_fnc_findExtreme
```

### Parameters

- numbers: Array - a set of numbers
- mode: Number - 0 (find minimum) or 1 (find maximum)

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _result = [[1,4,5,8,3,7], 1] call BIS_fnc_findExtreme; // returns 8
_result = [[1,4,5,8,3,7], 0] call BIS_fnc_findExtreme; // returns 1
```
