## roadAt

- Source: https://community.bistudio.com/wiki/roadAt
- Revision: 377838
- Updated: 2026-01-03T04:32:28Z

- Availability: arma3 1.58
- Locality: argument global
- Groups: Roads and Airports

### Description

Returns a road segment containing given position, objNull otherwise. Same as isOnRoad only returns the actual road object instead of boolean.

### Syntax

```sqf
roadAt position
```

### Parameters

- position: Object or PositionAGL (especially on bridges) or 2.00 Position2D - array, in which case Z will be automatically deduced as the height of the road surface

### Return Value

- Object - road segment or objNull

### Examples

#### Example 1

```sqf
_road = roadAt ASLToAGL getPosASL player;
```

#### Example 2

```sqf
_isOnRoad = !isNull roadAt player;
```

#### Example 3

For detecting bridges, for example:

```sqf
getModelInfo (roadAt ASLToAGL getPosASL player); // ["bridgesea_01_f.p3d", "a3\structures_f_exp\infrastructure\bridges\bridgesea_01_f.p3d", true]
```
