## sliderSetRange

- Source: https://community.bistudio.com/wiki/sliderSetRange
- Revision: 348823
- Updated: 2023-11-08T14:39:08Z

- Availability: ofp 1.85, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets limits of CT_SLIDER or CT_XSLIDER.

### Syntax

```sqf
sliderSetRange [idc, min, max]
```

```sqf
control sliderSetRange [min, max]
```

### Parameters

- idc: Number - idc of the control
- min: Number - minimal value
- max: Number - maximum value
- control: Control
- min: Number - minimal value
- max: Number - maximum value

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
sliderSetRange [101, 0, 100];
```
