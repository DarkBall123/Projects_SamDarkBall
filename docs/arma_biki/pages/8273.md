## groupIconSelectable

- Source: https://community.bistudio.com/wiki/groupIconSelectable
- Revision: 310231
- Updated: 2022-05-05T13:10:57Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Returns whether or not group icons raise onGroupIconClick, onGroupIconOverEnter and onGroupIconOverLeave events.

### Syntax

```sqf
**groupIconSelectable**
```


### Return Value

- Boolean - true is selectable

### Examples

#### Example 1

```sqf
hint str groupIconSelectable;
```
