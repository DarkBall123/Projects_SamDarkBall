## BIS fnc taskVar

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskVar
- Revision: 352089
- Updated: 2024-02-01T23:24:47Z

- Availability: arma3 1.00
- Groups: Tasks

### Description

Returns task's variable name. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskID call BIS_fnc_taskVar
```

### Parameters

- taskID: String - ID of the task

### Return Value

- String - returns **"@test"** for a task with the variable name **"test"**.

### Examples

#### Example 1

```sqf
"task_1" call BIS_fnc_taskVar;
```
