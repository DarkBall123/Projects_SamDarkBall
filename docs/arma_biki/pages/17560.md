## delete3DENEntities

- Source: https://community.bistudio.com/wiki/delete3DENEntities
- Revision: 342152
- Updated: 2023-07-09T12:26:49Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Delete given entities in Eden Editor.

### Syntax

```sqf
delete3DENEntities  entities
```

### Parameters

- entities: Array of Eden Entity or Eden ID

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
delete3DENEntities (all3DENEntities select 0); // Removes all objects
```
