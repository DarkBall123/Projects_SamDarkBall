## create3DENComposition

- Source: https://community.bistudio.com/wiki/create3DENComposition
- Revision: 377506
- Updated: 2026-01-02T06:50:07Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Create new Composition. To create individual entities, use create3DENEntity.

### Syntax

```sqf
create3DENComposition [configPath,  position]
```

### Parameters

- configPath: Config - path to `CfgGroups` or since 2.18 `configFile >> "Cfg3DEN" >> "Compositions"` class of a composition
- position: Position

### Return Value

- Array of Eden Entities

### Examples

#### Example 1

```sqf
myComposition = create3DENComposition [
	configFile >> "CfgGroups" >> "West" >> "BLU_F" >> "Infantry" >> "BUS_InfSquad",
	screenToWorld [0.5, 0.5]
];
```
