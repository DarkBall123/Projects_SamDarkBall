- Revision: 378334
- Updated: 2026-04-02T16:30:50Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns current value set in menu entry on given path.

### Syntax

```sqf
menuValue [idc, path]
```

### Parameters

- idc: Number
- path: Tree View Path

### Return Value

- Number
