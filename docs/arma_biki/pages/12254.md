## isBleeding

- Source: https://community.bistudio.com/wiki/isBleeding
- Revision: 322981
- Updated: 2022-06-28T21:42:55Z

- Availability: arma3 0.50
- Groups: Object Manipulation

### Description

Returns whether the unit is bleeding.

### Syntax

```sqf
isBleeding  unit
```

### Parameters

- unit: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isBleeding player) then { player groupChat "I'm bleeding!!"; };
```
