## removeMagazineTurret

- Source: https://community.bistudio.com/wiki/removeMagazineTurret
- Revision: 377469
- Updated: 2026-01-02T06:48:35Z

- Availability: arma2oa 1.52, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Turrets

### Description

Removes the magazine from the turret. Use turret path [-1] for driver's turret.

Note: you may create invalid combinations by using this function. When doing so, application behaviour is undefined.

### Syntax

```sqf
vehicle removeMagazineTurret [magazineName, turretPath]
```

### Parameters

- vehicle: Object
- magazineName: String
- turretPath: Turret Path

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player removeMagazineTurret ["60rnd_cmflaremagazine",[-1]];
```

#### Example 2

```sqf
_tank removeMagazineTurret ["20Rnd_120mmSABOT_M1A2",[0]];
```
