## tvSetPictureColorDisabled

- Source: https://community.bistudio.com/wiki/tvSetPictureColorDisabled
- Revision: 377792
- Updated: 2026-01-03T01:40:08Z

- Availability: arma3 1.62
- Groups: GUI Control - Tree View

### Description

Sets the color of left picture of a tree item defined by path when that item is disabled.

### Syntax

```sqf
control tvSetPictureColorDisabled [path, color]
```

### Parameters

- control: Control
- path: Tree View Path
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control tvSetPictureColorDisabled [[0], [1,0,1,1]];
```
