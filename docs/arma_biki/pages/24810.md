## BIS fnc reviveAllowed

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveAllowed
- Revision: 349060
- Updated: 2023-11-08T14:47:19Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Returns true if unit is in general able to revive someone.

### Syntax

```sqf
[medic, unit] call BIS_fnc_reviveAllowed
```

### Parameters

- medic: Object - unit performing revive
- unit: Array - unit that will be revived

### Return Value

- Boolean - returns true if possible, false is not

### Examples

#### Example 1

```sqf
private _canRevive = [medic,target] call BIS_fnc_reviveAllowed;
```
