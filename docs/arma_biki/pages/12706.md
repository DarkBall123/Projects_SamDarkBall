## addItemToVest

- Source: https://community.bistudio.com/wiki/addItemToVest
- Revision: 320961
- Updated: 2022-05-13T10:04:50Z

- Availability: arma3 1.04
- Locality: argument global, effect global
- Groups: Unit Inventory

### Description

Create new item and store it to soldier's vest. The item can also be a weapon or a magazine.

### Syntax

```sqf
unit addItemToVest item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addItemToVest "itemGPS";
```

#### Example 2

```sqf
player addItemToVest "hgun_Rook40_F";
```
