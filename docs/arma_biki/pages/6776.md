## type

- Source: https://community.bistudio.com/wiki/type
- Revision: 319936
- Updated: 2022-05-13T09:25:45Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations, Briefing

### Description

Returns a string of a Location's class name or Task's name (same as taskName).

### Syntax

```sqf
type location
```

```sqf
type task
```

### Parameters

- location: Location
- task: Task

### Return Value

- String
- String - the type of the task

### Examples

#### Example 1

```sqf
_locationType = type myLocation;
```

#### Example 2

```sqf
_taskName = type myTask;
```
