{{RV|type=command

|game1= arma3
|version1= 1.22

|gr2= Math - Vectors

|descr= Returns [Euclidean distance](https://en.wikipedia.org/wiki/Euclidean_distance) between two points.

|s1= point1 vectorDistance point2

|p1= point1: Position3D or Position2D - (since 2.00, z coordinate is defaulted to 0)

|p2= point2: Position3D or Position2D - (since 2.00, z coordinate is defaulted to 0)

|r1= Number

|x1=

```sqf
_euclideanDist = getPosASL player vectorDistance [0,0,0];
```

|x2=

```sqf
(getPosASL _a) vectorDistance (getPosASL _b);
// same as
(getPosATL _a) distance (getPosATL _b);
```

1.22 Algorithm:

```sqf
Vector1 = [x1,y1,z1];
Vector2 = [x2,y2,z2];
Result = sqrt ((x2 - x1) ^ 2 + (y2 - y1) ^ 2 + (z2 - z1) ^ 2);
```
