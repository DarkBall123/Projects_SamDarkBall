## getVehicleTIPars

- Source: https://community.bistudio.com/wiki/getVehicleTIPars
- Revision: 377635
- Updated: 2026-01-02T08:52:29Z

- Availability: arma3 2.00
- Groups: Object Manipulation

### Description

Returns TI parameters of a vehicle.

### Syntax

```sqf
getVehicleTIPars vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array with [aliveFactor, movementFactor, metabolismFactor]

### Examples

#### Example 1

```sqf
getVehicleTIPars _veh;
```
