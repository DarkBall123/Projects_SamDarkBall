## ctHeaderControls

- Source: https://community.bistudio.com/wiki/ctHeaderControls
- Revision: 377179
- Updated: 2026-01-01T10:48:06Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Returns array of controls on the header with the given index.

### Syntax

```sqf
ctrl ctHeaderControls index
```

### Parameters

- ctrl: Control
- index: Number

### Return Value

- Array of Controls

### Examples

#### Example 1

```sqf
_array = _control ctHeaderControls 0;
```
