## isBurning

- Source: https://community.bistudio.com/wiki/isBurning
- Revision: 323033
- Updated: 2022-06-28T21:43:08Z

- Availability: arma3 0.50
- Groups: Object Manipulation

### Description

Returns whether the unit is burning.
This returns true only if unit is damaged by nearby fire, it does **not** check whether a fireplace is burning, use inflamed command for that.

### Syntax

```sqf
isBurning unit
```

### Parameters

- unit: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isBurning player) then { player groupChat "I'm burning!!"; };
```
