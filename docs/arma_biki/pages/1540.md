## missionName

- Source: https://community.bistudio.com/wiki/missionName
- Revision: 364087
- Updated: 2024-05-03T19:33:29Z

- Availability: ofp 1.80, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Return currently loaded mission file (path to mission.pbo, relative to game exe).

### Syntax

```sqf
missionName
```


### Return Value

- String

### Examples

#### Example 1

```sqf
hint format ["You are playing mission ""%1""", missionName];
```
