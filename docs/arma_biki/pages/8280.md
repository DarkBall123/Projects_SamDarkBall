## hcRemoveAllGroups

- Source: https://community.bistudio.com/wiki/hcRemoveAllGroups
- Revision: 363244
- Updated: 2024-03-26T10:51:19Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Remove all groups from unit's high command bar.

### Syntax

```sqf
hcRemoveAllGroups unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
hcRemoveAllGroups player;
```
