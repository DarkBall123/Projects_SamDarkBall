## BIS fnc getNetMode

- Source: https://community.bistudio.com/wiki/BIS_fnc_getNetMode
- Revision: 327037
- Updated: 2022-07-12T21:44:46Z

- Availability: arma3 1.00
- Groups: Multiplayer

### Description

Returns the current net mode as a string.

### Syntax

```sqf
call BIS_fnc_getNetMode
```


### Return Value

- String - can be one of:
* "DedicatedServer"
* "Server"
* "HeadlessClient"
* "Client"
* "SinglePlayer"

### Examples

#### Example 1

```sqf
private _netMode = call BIS_fnc_getNetMode;
```
