## mapCenterOnCamera

- Source: https://community.bistudio.com/wiki/mapCenterOnCamera
- Revision: 377461
- Updated: 2026-01-02T06:47:30Z

- Availability: arma2 1.02, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Map

### Description

The main syntax enables/disables continuous centering of the main map type control on the camera position. Needs to be executed once.

The alternative syntax centers mini map type control on camera. Needs to be executed each frame (preferably inside an `onDraw` event handler).

### Syntax

```sqf
mainmap mapCenterOnCamera enable
```

```sqf
mapCenterOnCamera  minimap
```

### Parameters

- mainmap: Control
- enable: Boolean
- minimap: Control

### Return Value

- Nothing
- PositionASL of the map center (camera focus object's **model centre**<nowiki/>'s position (see getPosWorld)) in render scope

### Examples

#### Example 1

```sqf
// --- Minimap update
((uiNamespace getVariable "BIS_UAV_DISPLAY") displayCtrl 112410) mapCenterOnCamera true;
```
