## ctrlSetFontH2B

- Source: https://community.bistudio.com/wiki/ctrlSetFontH2B
- Revision: 323059
- Updated: 2022-06-28T21:43:11Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H2 bold font of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontH2B fontName
```

### Parameters

- controlName: Control
- fontName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontH2B "TahomaB";
```
