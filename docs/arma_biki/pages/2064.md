## setTriggerText

- Source: https://community.bistudio.com/wiki/setTriggerText
- Revision: 319703
- Updated: 2022-05-13T09:24:44Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Triggers

### Description

Sets the text label attached to the trigger object. This is used for example as a radio slot label for radio activated triggers.

### Syntax

```sqf
trigger setTriggerText text
```

### Parameters

- trigger: Object
- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
trigger setTriggerText "Call for support";
```
