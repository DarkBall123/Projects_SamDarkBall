## menuShortcut

- Source: https://community.bistudio.com/wiki/menuShortcut
- Revision: 378341
- Updated: 2026-04-02T16:31:19Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns shortcut related to menu entry on given path in form of a bitflag. To get the shortcut text use menuShortcutText.

### Syntax

```sqf
menuShortcut [idc, path]
```

```sqf
control menuShortcut path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Number
- Number

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuShortcut [0, 1];
```
