## is3DENMultiplayer

- Source: https://community.bistudio.com/wiki/is3DENMultiplayer
- Revision: 349042
- Updated: 2023-11-08T14:47:14Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns true if the Eden Editor is in multiplayer mode.

### Syntax

```sqf
is3DENMultiplayer
```


### Return Value

- Boolean - returns true in the following cases:
* Multiplayer preview launched directly from Eden Editor - true in preview and only for the creator
* MP mission is chosen for editing when creating a server: `Multiplayer - Server Browser - Host Server`. When *3D EDITOR* button is clicked for selected mission and Eden Editor is launched, command returns true within the editor environment

### Examples

#### Example 1

```sqf
if is3DENMultiplayer then {systemChat "You are hosting a test server!"};
```
