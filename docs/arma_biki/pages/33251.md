## ctrlAt

- Source: https://community.bistudio.com/wiki/ctrlAt
- Revision: 338355
- Updated: 2023-03-01T00:25:09Z

- Availability: arma3 2.12
- Groups: GUI Control

### Description

Returns the control at the specified coordinates.

### Syntax

```sqf
display ctrlAt [x, y]
```

### Parameters

- display: Display - the display to check
- x: Number - position (0 = left, 1 = right)
- y: Number - position (0 = top, 1 = bottom)

### Return Value

- Control - the control at the specified coordinates, controlNull if none

### Examples

#### Example 1

```sqf
private _ctrl = _myDisplay ctrlAt [0.5, 0.5];
```
