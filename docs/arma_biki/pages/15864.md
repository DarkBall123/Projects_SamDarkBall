## BIS fnc numberText

- Source: https://community.bistudio.com/wiki/BIS_fnc_numberText
- Revision: 336883
- Updated: 2023-01-04T16:43:51Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Math, Strings

### Description

Convert a number into string (avoiding scientific notation).

### Syntax

```sqf
[number, modulo] call BIS_fnc_numberText
```

### Parameters

- number: Number
- modulo: Number - (Optional, default 3)

### Return Value

- String

### Examples

#### Example 1

```sqf
[4096] call BIS_fnc_numberText; // "4 096"
```

#### Example 2

```sqf
[512, 1] call BIS_fnc_numberText; // "5 1 2"
```

#### Example 3

```sqf
[999999999999] call BIS_fnc_numberText; // "909 999 995 904"
```

#### Example 4

```sqf
[1234.5678] call BIS_fnc_numberText; // "1 234"
```
