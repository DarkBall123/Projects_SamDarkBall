## playableSlotsNumber

- Source: https://community.bistudio.com/wiki/playableSlotsNumber
- Revision: 319373
- Updated: 2022-05-13T09:23:58Z

- Availability: arma3 1.06
- Groups: Multiplayer

### Description

Returns the number of available slots in mission per side (both empty and taken). 
In singleplayer mission, it returns number of playable units per side.

### Syntax

```sqf
playableSlotsNumber side
```

### Parameters

- side: Side

### Return Value

- Number

### Examples

#### Example 1

```sqf
_maxBluforPlayers = playableSlotsNumber blufor;
```
