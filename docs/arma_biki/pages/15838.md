## BIS fnc randomPosTrigger

- Source: https://community.bistudio.com/wiki/BIS_fnc_randomPosTrigger
- Revision: 376281
- Updated: 2025-09-24T15:32:14Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Map and Markers

### Description

Selects random position within trigger, marker, location area or area defined by array

### Syntax

```sqf
param call BIS_fnc_randomPosTrigger
```

### Parameters

- param: can be one of:
* Object - trigger
* String - marker
* Location - location
* Array - array in format [center, distance] or [center, [a, b, angle, rect]] or [center, [a, b, angle, rect, height]]

Be aware that the `height` value is ignored.

### Return Value

- Array - random position in format [x,y,z]

### Examples

#### Example 1

```sqf
marker1 call BIS_fnc_randomPosTrigger;
```
