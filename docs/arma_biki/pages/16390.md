## BIS fnc isCuratorEditable

- Source: https://community.bistudio.com/wiki/BIS_fnc_isCuratorEditable
- Revision: 348581
- Updated: 2023-11-08T13:42:14Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Return true if given object is editable by player (when he's curator).

### Syntax

```sqf
[object] call BIS_fnc_isCuratorEditable
```

### Parameters

- object: Object - object to be checked

### Return Value

- Boolean - true if editable, otherwise false

### Examples

#### Example 1

```sqf
[object_1] call BIS_fnc_isCuratorEditable;
```
