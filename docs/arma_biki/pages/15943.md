## BIS fnc importImageLinks

- Source: https://community.bistudio.com/wiki/BIS_fnc_importImageLinks
- Revision: 369461
- Updated: 2024-09-06T08:51:22Z

- Availability: arma3 1.08
- Groups: Diagnostic

### Description

Imports CfgVehicles image links from the Community Wiki ([https://community.bistudio.com/](https://community.bistudio.com/)).
# Run the script. It will copy a text into clipboard
# Open your Sandbox and paste the text into edit field
# **Preview** the page (do not save it)
# Copy the resulting text and use it in your scripts

Result is in the following format:

```sqf
_imagesCfgVehicles = [
	"papercar","https://community.bistudio.com/wikidata/images/8/85/Arma3_CfgVehicles_PaperCar.jpg",
	"firesectortarget","",
	"building","",
	// etc
];
```

Be wary that this function is **CPU-demanding** and may lock your computer for 5-10 seconds.

### Syntax

```sqf
call BIS_fnc_importImageLinks
```


### Return Value

- Boolean - true when done

### Examples

#### Example 1

```sqf
call BIS_fnc_importImageLinks;
```
