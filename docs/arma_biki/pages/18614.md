## setAirplaneThrottle

- Source: https://community.bistudio.com/wiki/setAirplaneThrottle
- Revision: 310925
- Updated: 2022-05-07T20:46:43Z

- Availability: arma3 1.70
- Locality: argument local
- Groups: Object Manipulation

### Description

Sets a wanted throttle position - works only on player's vehicle.

### Syntax

```sqf
airplane setAirplaneThrottle value
```

### Parameters

- airplane: Object
- value: Number - wanted throttle

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setAirplaneThrottle 0.5;
```
