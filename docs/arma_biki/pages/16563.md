## setPosWorld

- Source: https://community.bistudio.com/wiki/setPosWorld
- Revision: 377460
- Updated: 2026-01-02T06:47:29Z

- Availability: arma3 1.32
- Locality: argument global, effect global
- Groups: Positions

### Description

Sets position of an object based on the model's centre position (see getPosWorld).

### Syntax

```sqf
object setPosWorld position
```

### Parameters

- object: Object
- position: PositionASL

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_obj setPosWorld getPosWorld _obj;
```
