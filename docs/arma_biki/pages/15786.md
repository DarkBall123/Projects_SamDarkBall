## BIS fnc dbValueReturn

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbValueReturn
- Revision: 348205
- Updated: 2023-11-08T11:40:13Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Returns content of given value.

### Syntax

```sqf
[database, path, (defaultValue)] call BIS_fnc_dbValueReturn
```

### Parameters

- database - Array: Databse array
- path - Array: Path to value
- (optional) defaultValue - anything: In case the value does not exist return this value (Default: nil)

### Return Value

- Anything: Value's content

### Examples

#### Example 1

```sqf
"#MILLER", ["&KILLS", 1000, "&RANK", "CAPTAIN", ["miller","kills"]] call BIS_fnc_dbValueReturn; // 1000
```
