## ctCurSel

- Source: https://community.bistudio.com/wiki/ctCurSel
- Revision: 310869
- Updated: 2022-05-07T20:24:09Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Returns index of the selected row. Will take only rows, but not headers into account.

### Syntax

```sqf
ctCurSel ctrl
```

### Parameters

- ctrl: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_curSel = ctCurSel _control;
```
