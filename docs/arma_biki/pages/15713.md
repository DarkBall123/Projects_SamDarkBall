## BIS fnc dotProduct

- Source: https://community.bistudio.com/wiki/BIS_fnc_dotProduct
- Revision: 341319
- Updated: 2023-05-21T15:52:21Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Vectors

### Description

Dot product of two vectors. In Arma 3 use vectorDotProduct.

### Syntax

```sqf
[vector1, vector2] call BIS_fnc_dotProduct
```

### Parameters

- vector1: Array
- vector2: Array

### Return Value

- Number

### Examples

#### Example 1

```sqf
[[1,2,3], [1,2,3]] call BIS_fnc_dotProduct; // returns: 1*1 + 2*2 + 3*3 = 14
```

#### Example 2

```sqf
[[1,2,3,4], [1,2,3,4]] call BIS_fnc_dotProduct; // returns 1*1 + 2*2 + 3*3 + 4*4 = 30
```
