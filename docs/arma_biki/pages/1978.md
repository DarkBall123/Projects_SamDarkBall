## composeText

- Source: https://community.bistudio.com/wiki/composeText
- Revision: 336896
- Updated: 2023-01-04T16:43:56Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Strings, Structured Text

### Description

Creates a Structured Text by joining the given structured or plain text arguments.

### Syntax

```sqf
composeText arguments
```

### Parameters

- arguments: Array of String and/or Structured Text - use Structured Text where necessary (see #Example 2)

### Return Value

- Structured Text

### Examples

#### Example 1

```sqf
hint composeText ["Image: ", image "\a3\Data_f\Flags\flag_Altis_co.paa"];
```

#### Example 2

```sqf
hint composeText ["line1", "
", "line2"];		// result displayed in one line
hint composeText ["line1", lineBreak, "line2"];	// result displayed in two lines
```
