## ctrlSetTooltipColorShade

- Source: https://community.bistudio.com/wiki/ctrlSetTooltipColorShade
- Revision: 377368
- Updated: 2026-01-02T06:42:12Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets tooltip background color of given control.

### Syntax

```sqf
control ctrlSetTooltipColorShade color
```

### Parameters

- control: Control
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetTooltipColorShade [1, 0, 0, 1];
```
