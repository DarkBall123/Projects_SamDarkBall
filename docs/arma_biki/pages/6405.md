## assignToAirport

- Source: https://community.bistudio.com/wiki/assignToAirport
- Revision: 352096
- Updated: 2024-02-01T23:24:49Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Roads and Airports

### Description

Assigns a plane to an airport ID or object.

### Syntax

```sqf
plane assignToAirport id
```

```sqf
plane assignToAirport target
```

### Parameters

- plane: Object - plane
- id: Number - airport id
- plane: Object - plane
- target: Object - airport object. For example an aircraft carrier, see Arma 3: Dynamic Airport Configuration

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
plane1 assignToAirport 0;
```

#### Example 2

```sqf
plane1 assignToAirport carrier1;
```
