## BIS fnc initVirtualUnit

- Source: https://community.bistudio.com/wiki/BIS_fnc_initVirtualUnit
- Revision: 348570
- Updated: 2023-11-08T13:42:08Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Initialize virtual unit. Disable it, turn the camera upwards and save its correct side.

### Syntax

```sqf
[object] call BIS_fnc_initVirtualUnit
```

### Parameters

- object: Object - object to be turned into virtual unit

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
someObject call BIS_fnc_initVirtualUnit;
```
