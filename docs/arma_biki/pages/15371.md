## vectorDistanceSqr

- Source: https://community.bistudio.com/wiki/vectorDistanceSqr
- Revision: 378368
- Updated: 2026-04-03T16:47:13Z

- Availability: arma3 1.22
- Groups: Math - Vectors

### Description

Squared distance between two 3D vectors.

### Syntax

```sqf
vector1 vectorDistanceSqr vector2
```

### Parameters

- vector1: Vector3D or Vector2D - 3D or 2.00 2D vector (z coordinate is defaulted to 0)
- vector2: Vector3D or Vector2D - 3D or 2.00 2D vector (z coordinate is defaulted to 0)

### Return Value

- Number

### Examples

#### Example 1

```sqf
_distSqr = getPos player vectorDistanceSqr [0,0,2];
```
