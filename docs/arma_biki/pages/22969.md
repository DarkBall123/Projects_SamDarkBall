## getDLCAssetsUsage

- Source: https://community.bistudio.com/wiki/getDLCAssetsUsage
- Revision: 310760
- Updated: 2022-05-07T20:21:35Z

- Availability: arma3 1.16
- Groups: DLC

### Description

Returns an array of the DLC usage times.

### Syntax

```sqf
getDLCAssetsUsage
```


### Return Value

- Array - array of DLC usage information, containing DLC items in format:

[<nowiki/>[name, dlcAppId, sessionTime, totalTime], [name, dlcAppId, sessionTime, totalTime], (…)]

**NOTE:** unused assets won't appear in the result (usage time = 0).

### Examples

#### Example 1

```sqf
_dlcAssetsUsageInfo = getDLCAssetsUsage;
```
