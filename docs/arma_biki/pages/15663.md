## BIS fnc listPlayers

- Source: https://community.bistudio.com/wiki/BIS_fnc_listPlayers
- Revision: 327566
- Updated: 2022-07-12T22:39:16Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Multiplayer

### Description

Returns a list of *currently played* units, alive or dead.

### Syntax

```sqf
call BIS_fnc_listPlayers
```


### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
private _allPlayers = call BIS_fnc_listPlayers;
```
