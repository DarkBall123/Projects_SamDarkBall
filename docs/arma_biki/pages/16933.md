## BIS fnc didJIP

- Source: https://community.bistudio.com/wiki/BIS_fnc_didJIP
- Revision: 336277
- Updated: 2022-12-21T11:09:46Z

- Availability: arma3 1.34
- Groups: Multiplayer

### Description

Return whether or not the local player joined the game while it was already in progress. 1.50 Use didJIP instead.

### Syntax

```sqf
[] call BIS_fnc_didJIP
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if ([] call BIS_fnc_didJIP) then { forceRespawn player };
```
