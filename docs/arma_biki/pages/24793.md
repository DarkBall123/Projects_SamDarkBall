## BIS fnc reviveGet3dIcons

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveGet3dIcons
- Revision: 349325
- Updated: 2023-11-08T14:52:30Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Returns structured text that can be displayed in 'Hold Action' tech as animated unconscious state icon.

### Syntax

```sqf
[unit] call BIS_fnc_reviveGet3dIcons
```

### Parameters

- unit: Object - unconscious unit

### Return Value

- Structured Text - structured text with animated unconscious state 'Hold Action' icon.

### Examples

#### Example 1

```sqf
private _structuredText = [BIS_unit] call BIS_fnc_reviveGet3dIcons;
```
