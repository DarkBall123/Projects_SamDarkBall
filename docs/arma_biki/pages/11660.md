## enableTraffic

- Source: https://community.bistudio.com/wiki/enableTraffic
- Revision: 309946
- Updated: 2022-05-05T12:17:00Z

- Availability: tkoh 1.01, arma3 0.50
- Groups: Environment

### Description

Enable ambient traffic. This command does nothing in Arma 3.

### Syntax

```sqf
enableTraffic enable
```

### Parameters

- enable: Boolean - enable or disable

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableTraffic true;
```
