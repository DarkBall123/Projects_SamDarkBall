## BIS fnc vectorMultiply

- Source: https://community.bistudio.com/wiki/BIS_fnc_vectorMultiply
- Revision: 327959
- Updated: 2022-07-13T13:15:38Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Vectors

### Description

Multiplies 3D vector by a scalar. Use vectorMultiply instead.

### Syntax

```sqf
[vector, factor] call BIS_fnc_vectorMultiply
```

### Parameters

- vector: Array of Numbers - to format [x,y,z]
- factor: Number

### Return Value

- Array of Numbers - result vector

### Examples

#### Example 1

```sqf
private _newVector = [[1,2,3], 3] call BIS_fnc_vectorMultiply; // returns [3,6,9]
```
