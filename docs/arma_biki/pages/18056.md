## taskAlwaysVisible

- Source: https://community.bistudio.com/wiki/taskAlwaysVisible
- Revision: 339143
- Updated: 2023-04-26T10:55:03Z

- Availability: arma3 1.58
- Groups: Briefing

### Description

Returns true if the task is flagged to be always visible or false if not.

### Syntax

```sqf
taskAlwaysVisible task
```

### Parameters

- task: Task

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isAlwaysVisible = taskAlwaysVisible (currentTask player);
```
