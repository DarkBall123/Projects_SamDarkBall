## getWaterFillPercentage

- Source: https://community.bistudio.com/wiki/getWaterFillPercentage
- Revision: 363321
- Updated: 2024-03-26T16:41:39Z

- Availability: arma3 2.16
- Locality: argument local
- Groups: Object Manipulation

### Description

Get an object's water filling.

### Syntax

```sqf
getWaterFillPercentage obj
```

### Parameters

- obj: Object - object to manipulate

### Return Value

- Number - water level in range 0..1 (empty to full)

### Examples

#### Example 1

```sqf
if (getWaterFillPercentage _myCar > 0) then
{
	hint "My feet are wet.";
};
```
