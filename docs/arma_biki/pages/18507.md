## lnbSort

- Source: https://community.bistudio.com/wiki/lnbSort
- Revision: 364169
- Updated: 2024-05-05T10:46:44Z

- Availability: arma3 1.08
- Groups: GUI Control - ListNBox

### Description

Sorts given multicolumn listbox by lnbText in given column in ascending or descending order.
This command does not support UNICODE, use lnbSortBy if it is needed instead

### Syntax

```sqf
lnbSort [idc, column, reversed]
```

```sqf
control lnbSort [column, reversed]
```

### Parameters

- idc: Number
- column: Number
- reversed: Boolean - (Optional, default false) false: descending / true: ascending
- control: Control
- column: Number
- reversed: Boolean - (Optional, default false) false: descending / true: ascending

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lnbSort [1800, 1, false];
```

#### Example 2

```sqf
_ctl lnbSort [1, true];
```
