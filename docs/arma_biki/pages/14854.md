## removeCuratorEditingArea

- Source: https://community.bistudio.com/wiki/removeCuratorEditingArea
- Revision: 348385
- Updated: 2023-11-08T12:59:59Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Removes editing area for given curator.

### Syntax

```sqf
curatorObj removeCuratorEditingArea editAreaID
```

### Parameters

- curatorObj: Object - curator module.
- editAreaID: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myCurator removeCuratorEditingArea 3;
```
