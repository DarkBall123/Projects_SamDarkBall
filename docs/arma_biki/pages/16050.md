## BIS fnc fixDate

- Source: https://community.bistudio.com/wiki/BIS_fnc_fixDate
- Revision: 329336
- Updated: 2022-07-27T10:16:56Z

- Availability: arma3 1.10
- Groups: Math, Environment

### Description

Checks the array with date data and makes sure the values are within the boundries.

### Syntax

```sqf
date call BIS_fnc_fixDate
```

### Parameters

- date: Array format Date - date to be checked

### Return Value

- Array format Date - resulting date

### Examples

#### Example 1

```sqf
private _fixedDate = [2033, -2, 89, 25, 75] call BIS_fnc_fixDate;
```
