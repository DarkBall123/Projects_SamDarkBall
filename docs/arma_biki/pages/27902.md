## breakWith

- Source: https://community.bistudio.com/wiki/breakWith
- Revision: 349341
- Updated: 2023-11-08T14:53:30Z

- Availability: arma3 2.02
- Groups: Program Flow

### Description

Skips all loop iterations and immediately returns the given value.

### Syntax

```sqf
breakWith return
```

### Parameters

- return: Anything - value to be returned when iterations are skipped

### Return Value

- Anything

### Examples

#### Example 1

```sqf
// stops once _i reaches 5 and outputs 0, 1, 2, 3, 4, END
systemChat call {
	for "_i" from 0 to 10 do {
		if (_i == 5) then { breakWith "END"; };
		systemChat str _i;
	};
};
```
