## getMarkerPos

- Source: https://community.bistudio.com/wiki/getMarkerPos
- Revision: 377402
- Updated: 2026-01-02T06:44:58Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Returns marker position.

### Syntax

```sqf
getMarkerPos markerName
```

```sqf
getMarkerPos [markerName, preserveElevation]
```

### Parameters

- markerName: String
- markerName: String
- preserveElevation: Boolean - (Optional, default false)

### Return Value

- PositionAGL - format [x,y,0]
- PositionAGL - if *preserveElevation* is true or [x,y,0] if *preserveElevation* is false

### Examples

#### Example 1

```sqf
_mPos1 = getMarkerPos "markerOne";
```

#### Example 2

```sqf
_mPos2 = getMarkerPos ["markerTwo", true];
```
