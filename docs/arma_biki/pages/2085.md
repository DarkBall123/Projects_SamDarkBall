## setWaypointSpeed

- Source: https://community.bistudio.com/wiki/setWaypointSpeed
- Revision: 377759
- Updated: 2026-01-03T00:58:18Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect global, server execution server
- Groups: Waypoints

### Description

Switches the group speed mode when the waypoint becomes active.

Possible values are:
* "UNCHANGED"
* "LIMITED"
* "NORMAL"
* "FULL"

### Syntax

```sqf
waypoint setWaypointSpeed mode
```

### Parameters

- waypoint: Waypoint
- mode: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointSpeed "FULL";
```
