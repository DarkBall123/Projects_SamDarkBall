## magazineCargo

- Source: https://community.bistudio.com/wiki/magazineCargo
- Revision: 348708
- Updated: 2023-11-08T14:29:30Z

- Availability: arma3 0.50
- Groups: Vehicle Inventory, Containers

### Description

Get array with magazines from ammo box (or any general weapon holder container).

### Syntax

```sqf
magazineCargo object
```

### Parameters

- object: Object - vehicle or ammo box

### Return Value

- Array - format: ["MagType1","MagType1","MagType2"...]

### Examples

#### Example 1

```sqf
hint str magazineCargo uniformContainer cursorTarget;
```
