## unitAimPosition

- Source: https://community.bistudio.com/wiki/unitAimPosition
- Revision: 378159
- Updated: 2026-02-26T16:15:33Z

- Availability: arma3 1.64
- Locality: argument global
- Groups: Object Manipulation, Positions

### Description

Returns the position on the unit other units can aim at. Same as aimPos only returns position in PositionAGL format and has render scope alternative unitAimPositionVisual.

### Syntax

```sqf
unitAimPosition unit
```

### Parameters

- unit: Object

### Return Value

- PositionAGL

### Examples

#### Example 1

```sqf
private _aimPosAGL = unitAimPosition player;
```
