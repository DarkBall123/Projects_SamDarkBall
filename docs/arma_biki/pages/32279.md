## getPiPViewDistance

- Source: https://community.bistudio.com/wiki/getPiPViewDistance
- Revision: 309130
- Updated: 2022-05-03T11:41:51Z

- Availability: arma3 2.08
- Locality: effect local
- Groups: System

### Description

Get the set PiP (Picture-in-Picture) view distance (that can be set by setPiPViewDistance).

### Syntax

```sqf
getPiPViewDistance
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
private _pipViewDistance = getPiPViewDistance;
```

#### Example 2

```sqf
private _pipViewDistanceRatio = getPiPViewDistance / viewDistance;
```
