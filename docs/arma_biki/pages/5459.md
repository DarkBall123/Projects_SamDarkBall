## setMarkerPosLocal

- Source: https://community.bistudio.com/wiki/setMarkerPosLocal
- Revision: 377550
- Updated: 2026-01-02T06:54:46Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Moves the marker. If position is given in 3D format, `z` coordinate is stored with the marker and will be used when marker is passed to commands like createVehicle, createUnit, createAgent, createMine, setVehiclePosition for example. In case of an object, the object's model [0,0,0] is used.

### Syntax

```sqf
markerName setMarkerPosLocal position
```

### Parameters

- markerName: String
- position: Position2D, PositionAGL or 1.94 Object. In case of an object, the object's model [0,0,0] is used.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"MarkerOne" setMarkerPosLocal getMarkerPos "MarkerTwo";
```
