## fadeSound

- Source: https://community.bistudio.com/wiki/fadeSound
- Revision: 376964
- Updated: 2026-01-01T05:56:16Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Sounds

### Description

Changes the sound volume smoothly within the given time. {{Feature|informative|The player's in-game setting is not changed by this command: {{hl|Final Volume {{=}} Client Setting * Scripted Volume}}.}}

### Syntax

```sqf
time fadeSound  volume
```

### Parameters

- time: Number - fade interval in seconds
- volume: Number in range 0..1 - sound volume

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
5 fadeSound 0;
```
