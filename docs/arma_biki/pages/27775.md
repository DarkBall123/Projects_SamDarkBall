## buldozer isEnabledRoadDiag

- Source: https://community.bistudio.com/wiki/buldozer_isEnabledRoadDiag
- Revision: 310886
- Updated: 2022-05-07T20:28:58Z

- Availability: arma3 1.26
- Groups: System

### Description

Returns if road diagnostics are enabled in buldozer.

### Syntax

```sqf
buldozer_isEnabledRoadDiag
```


### Return Value

- Boolean - true if enabled, otherwise false

### Examples

#### Example 1

```sqf
_isEnabled = buldozer_isEnabledRoadDiag;
```
