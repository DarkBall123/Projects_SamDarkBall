## diag remainsCollector

- Source: https://community.bistudio.com/wiki/diag_remainsCollector
- Revision: 377638
- Updated: 2026-01-02T08:52:35Z

- Availability: arma3 2.18
- Groups: Object Manipulation

### Description

Returns current settings for the remains collector and the list of monitored units if any.

### Syntax

```sqf
diag_remainsCollector option
```

### Parameters

- option: Number - can be one of:
* -1: 2.20 log remains collector entities into a file in the RPT directory - see also the [REMAINS](Arma 3: Cheats#REMAINS) cheat and the `[#logremains](Multiplayer Server Commands#Performance Profiling)` [server command](Multiplayer Server Commands).Only available in [Diagnostic](Arma 3: Diagnostics Exe)/[Profiling](Performance Profiling) branch.
* 0: corpses - returns [disposalPeriod, managerMode, removeLimit, removeMinTime, removeMaxTime, minPlayerDistance, unit1, unit2...]
* 1: wrecks - returns [disposalPeriod, managerMode, removeLimit, removeMinTime, removeMaxTime, minPlayerDistance, unit1, unit2...]
* 2: weaponholders - returns [disposalPeriod, managerMode, removeLimit, removeMinTime, removeMaxTime, minPlayerDistance, unit1, unit2...]
* 3: 2.20 overrideTimes - returns [overrideTimeCorpses, overrideTimeWrecks, overrideTimeWeaponholders]

### Return Value

- Array with [disposalPeriod, managerMode, removeLimit, removeMinTime, removeMaxTime, minPlayerDistance, unit1, unit2...] or [overrideTimeCorpses, overrideTimeWrecks, overrideTimeWeaponholders]

### Examples

#### Example 1

```sqf
hintSilent str diag_remainsCollector 0;
```
