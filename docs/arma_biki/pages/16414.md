## BIS fnc setFog

- Source: https://community.bistudio.com/wiki/BIS_fnc_setFog
- Revision: 336201
- Updated: 2022-12-14T14:12:44Z

- Availability: arma3 1.00
- Locality: server execution server
- Groups: Environment

### Description

Instantly set weather conditions and share it across network.

### Syntax

```sqf
[strength, density, altitude] call BIS_fnc_setFog
```

### Parameters

- strength: Number - fog strength from 0 to 1
- density: Number - fog density from 0 to 1
- altitude: Number - fog base altitude in metres.

### Return Value

- Array - array with set values

### Examples

#### Example 1

```sqf
[1,1,100] call BIS_fnc_setFog; // returns [1,1,100]
```
