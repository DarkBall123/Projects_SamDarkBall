## visibleCompass

- Source: https://community.bistudio.com/wiki/visibleCompass
- Revision: 319850
- Updated: 2022-05-13T09:25:35Z

- Availability: arma3 1.22
- Groups: Interaction

### Description

Checks if the player has compass opened and visible. Keep in mind that the GPS minimap in Arma 3 also shows the direction.

### Syntax

```sqf
**visibleCompass**
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (visibleCompass) then {hint "Compass is visible"};
```
