{{RV|type=command

|game1= arma3
|version1= 0.50

|gr1= Unit Inventory

|descr= Get array with all items linked to a given weapon.
{{Feature | important | This command does not return loaded magazines, see weaponsItems}}

|s1= unit weaponAccessories weapon

|p1= unit: Object

|p2= weapon: String - primary, secondary or handgun

|r1= Array - [silencer, laserpointer/flashlight, optics, bipod]

|x1=

```sqf
player weaponAccessories primaryWeapon player; //["","acc_pointer_IR","optic_Aco",""]
```
