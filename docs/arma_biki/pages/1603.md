## direction

- Source: https://community.bistudio.com/wiki/direction
- Revision: 376966
- Updated: 2026-01-01T05:58:04Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation, Locations

### Description

Returns the direction an object or a location is facing (differs from getDir in that this also works with locations).

### Syntax

```sqf
direction object
```

### Parameters

- object: Object or Location

### Return Value

- Number in range 0..360 - Direction in degrees

### Examples

#### Example 1

```sqf
player setDir 90;
_d = direction player;//returns 90
```
