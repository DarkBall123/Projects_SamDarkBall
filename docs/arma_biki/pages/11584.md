## surfaceNormal

- Source: https://community.bistudio.com/wiki/surfaceNormal
- Revision: 377547
- Updated: 2026-01-02T06:54:42Z

- Availability: arma2oa 1.60, tkoh 1.00, arma3 0.50
- Groups: Positions

### Description

Returns terrain's [surface normal](https://en.wikipedia.org/wiki/Normal_(geometry)) on given position.

### Syntax

```sqf
surfaceNormal position
```

### Parameters

- position: Position2D or Position3D - when using Position3D, Z is ignored

### Return Value

- Vector3D

### Examples

#### Example 1

```sqf
_normal = surfaceNormal [300, 500];
```

#### Example 2

```sqf
_normal = surfaceNormal getPosASL player;
```
