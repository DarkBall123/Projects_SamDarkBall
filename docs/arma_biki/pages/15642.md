## BIS fnc returnParents

- Source: https://community.bistudio.com/wiki/BIS_fnc_returnParents
- Revision: 376400
- Updated: 2025-10-10T20:44:01Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Configs

### Description

Returns list of all parent classes.

### Syntax

```sqf
[config, onlyClassNames] call BIS_fnc_returnParents
```

### Parameters

- config: Config - starting config class
- onlyClassNames: Boolean - (Optional, default false) true to return only class names

### Return Value

- Array - list of all classes (including starting one)

### Examples

#### Example 1

```sqf
[configFile >> "CfgVehicles" >> "Land_FirePlace_F", true] call BIS_fnc_returnParents;
//Returns ["Land_FirePlace_F","House_F","House","HouseBase","NonStrategic","Building","Static","All"]
```
