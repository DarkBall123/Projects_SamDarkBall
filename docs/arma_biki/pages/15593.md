## reverse

- Source: https://community.bistudio.com/wiki/reverse
- Revision: 377138
- Updated: 2026-01-01T10:29:57Z

- Availability: arma3 1.24
- Groups: Arrays

### Description

Reverses given array by reference (modifies the original array, just like resize). The alternative syntax can be used to reverse a ANSI string. If Unicode support is desired, see forceUnicode.

### Syntax

```sqf
reverse array
```

```sqf
reverse string
```

### Parameters

- array: Array of Anything
- string: String - string to be reversed

### Return Value

- Nothing
- String - reversed string

### Examples

#### Example 1

```sqf
_arr = [1,2,3];
reverse _arr;
hint str _arr; // [3,2,1]
```

#### Example 2

```sqf
_wordArr = toArray "gateman";
reverse _wordArr;
hint toString _wordArr; // nametag
```

#### Example 3

```sqf
reverse "treboR"; // Returns "Robert"
```
