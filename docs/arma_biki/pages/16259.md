## BIS fnc moduleEffectsShells

- Revision: 352194
- Updated: 2024-02-01T23:26:00Z

- Availability: arma3 1.00
- Groups: Modules

### Description

Creates empty ammo cartridges on position of the module logic. Mainly meant to be used by modules available in Eden Editor.

### Syntax

```sqf
[module] call BIS_fnc_moduleEffectsShells
```

### Parameters

- module: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_module] call BIS_fnc_moduleEffectsShells;
```
