## lockedInventory

- Source: https://community.bistudio.com/wiki/lockedInventory
- Revision: 338797
- Updated: 2023-04-07T06:40:04Z

- Availability: arma3 2.00
- Groups: Unit Inventory

### Description

Get a vehicle's inventory lock state. Can also be used on a unit's backback (see lockInventory).

### Syntax

```sqf
lockedInventory vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _isInventoryLocked = lockedInventory vehicle player;
```

#### Example 2

```sqf
private _isBackpackLocked = lockedInventory backpackContainer player;
```
