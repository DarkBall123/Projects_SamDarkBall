## lbSetPictureRightColorDisabled

- Source: https://community.bistudio.com/wiki/lbSetPictureRightColorDisabled
- Revision: 377803
- Updated: 2026-01-03T04:08:00Z

{{RV|type=command

|game1= arma3
|version1= 1.20

|gr1= GUI Control - ListBox

|descr= Sets the disabled color of second (right aligned) picture of the item with the given index of the listbox with id idc of the topmost user dialog to the given color.
Color which consists from only zeros means disable this override.

|s1= lbSetPictureRightColorDisabled [idc, index, color]

|p1= idc: Number

|p2= index: Number

|p3= color: Color (RGBA)

|r1= Nothing

|s2= control lbSetPictureRightColorDisabled [index, color]

|p21= control: Control

|p22= index: Number

|p24= color: Color (RGBA)

|r2= Nothing

|x1=

```sqf
lbSetPictureRightColorDisabled [101, 0, [1, 1, 1, 0.25]];
```

|x2=

```sqf
_ctrl lbSetPictureRightColorDisabled [0, [1, 1, 1, 0.25]];
```
