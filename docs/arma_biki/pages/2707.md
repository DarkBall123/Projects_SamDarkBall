## fog

- Revision: 310796
- Updated: 2022-05-07T20:21:54Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Environment

### Description

A getter for setFog. Returns the current value of the fog in range 0..1.

### Multiplayer

Before Arma 3, each client and the server could have different values. In Arma 3 the value is synced across network.

### Syntax

```sqf
fog
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
_foglevel = fog;
```
