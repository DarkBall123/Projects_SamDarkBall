## BIS fnc debugProfile

- Source: https://community.bistudio.com/wiki/BIS_fnc_debugProfile
- Revision: 309379
- Updated: 2022-05-05T12:04:33Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Purges user profile from unwanted BIS_fnc_diagAAR data. If more than 7500 entries are found, the user is asked to delete profileNamespace variable **BIS_fnc_diagAAR_data**.

### Syntax

```sqf
call BIS_fnc_debugProfile
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_debugProfile;
```
