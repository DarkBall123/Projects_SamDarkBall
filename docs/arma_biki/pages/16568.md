## ctrlModel

- Source: https://community.bistudio.com/wiki/ctrlModel
- Revision: 310856
- Updated: 2022-05-07T20:24:08Z

- Availability: arma3 1.32
- Groups: GUI Control - Object

### Description

Returns model used in 3D-Dialog.

### Syntax

```sqf
ctrlModel control
```

### Parameters

- control : Control - 3D control

### Return Value

- String - model path

### Examples

#### Example 1

```sqf
_model = ctrlModel _control3D;
```
