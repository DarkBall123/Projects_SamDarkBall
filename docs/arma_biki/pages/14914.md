## enableDiagLegend

- Source: https://community.bistudio.com/wiki/enableDiagLegend
- Revision: 310210
- Updated: 2022-05-05T13:10:42Z

- Availability: arma3 1.12
- Groups: Diagnostic

### Description

Enable or disable the legend for diagnostics. **Internal dev only!**

### Syntax

```sqf
enableDiagLegend enable
```

### Parameters

- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableDiagLegend false;
```
