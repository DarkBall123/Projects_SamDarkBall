## BIS fnc isThrowable

- Source: https://community.bistudio.com/wiki/BIS_fnc_isThrowable
- Revision: 376125
- Updated: 2025-09-01T08:18:13Z

- Availability: arma3 1.62
- Groups: Inventory

### Description

Returns true if given magazine is throwable.
see isThrowable.|arma3|2.18

### Syntax

```sqf
magazine call BIS_fnc_isThrowable
```

### Parameters

- magazine: String - magazine class name

### Return Value

- Boolean - true if throwable

### Examples

#### Example 1

```sqf
private _isThrowable = "SmokeShellGreen" call BIS_fnc_isThrowable;
```
