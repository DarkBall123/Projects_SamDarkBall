## setMass

- Source: https://community.bistudio.com/wiki/setMass
- Revision: 373893
- Updated: 2025-06-26T11:00:29Z

{{RV|type=command

|game1= arma3
|version1= 1.02

|arg= local

|eff= global

|gr1= PhysX

|descr= Changes the mass of a PhysX object. When using the alternative syntax the mass change is gradual during the given time. A time of zero means immediate change.{{Feature | important | When main syntax is used on local vehicle, the change is global. When alternative syntax is used with time transition on local vehicle, the gradual mass change doesn't happen on remote clients, only final mass is applied after the given time. If you need gradual change on remote clients too, remote execute setMass globally. }}

|s1= myObject setMass mass

|p1= myObject: Object

|p2= mass: Number

|r1= Nothing

|s2= myObject setMass [mass, time]

|p21= myObject: Object

|p22= mass: Number

|p23= time: Number

|r2= Nothing

|x1=

```sqf
myObject setMass [10, 0.5];
```

|x2=

```sqf
myObject setMass 10;
```

|seealso= getMass setCenterOfMass getCenterOfMass
}}

RopeCreate in MP will set the mass of the attached object to the server value upon execution.
