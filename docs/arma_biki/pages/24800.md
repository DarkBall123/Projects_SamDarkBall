## BIS fnc reviveEhRespawn

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveEhRespawn
- Revision: 349292
- Updated: 2023-11-08T14:52:16Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Sets  unit's state to respawned. Should probably only be called on respawn event.

### Syntax

```sqf
[unit] call BIS_fnc_reviveEhRespawn
```

### Parameters

- unit: Object - unit

### Return Value

- Boolean - true

### Examples

#### Example 1

```sqf
BIS_unit call BIS_fnc_reviveEhRespawn;
```
