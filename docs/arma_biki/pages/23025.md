## isAimPrecisionEnabled

- Source: https://community.bistudio.com/wiki/isAimPrecisionEnabled
- Revision: 349310
- Updated: 2023-11-08T14:52:24Z

- Availability: arma3 1.54
- Groups: Stamina System

### Description

Returns true if procedural aiming precision affects weapon sway.

### Syntax

```sqf
isAimPrecisionEnabled unit
```

### Parameters

- unit: Object - unit which should be checked

### Return Value

- Boolean - true if affected, false if not

### Examples

#### Example 1

```sqf
_isAffected = isAimPrecisionEnabled player;
```
