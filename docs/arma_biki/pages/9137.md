## enableAIFeature

- Source: https://community.bistudio.com/wiki/enableAIFeature
- Revision: 369972
- Updated: 2024-10-22T12:51:41Z

- Availability: arma2 1.05, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: AI Behaviour

### Description

Enables/disables given AI feature.

### Syntax

```sqf
feature enableAIFeature  enable
```

```sqf
unit enableAIFeature [feature, enable]
```

### Parameters

- feature: String - can be:
* `"AwareFormationSoft"`
* `"CombatFormationSoft"`
- enable: Boolean - true to enable, false to disable
- unit: Object - unit to test AI feature for
- feature: String - see disableAI / enableAI for possible values
- enable: Boolean - true to enable, false to disable

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
"AwareFormationSoft" enableAIFeature true;
```

#### Example 2

```sqf
bob enableAIFeature ["AUTOTARGET", false];
```
