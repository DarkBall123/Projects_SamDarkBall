## BIS fnc dirTo

- Source: https://community.bistudio.com/wiki/BIS_fnc_dirTo
- Revision: 327975
- Updated: 2022-07-13T14:37:05Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Geometry

### Description

Function which returns vector direction from pos1 to pos2.
Use 

```sqf
obj1 getDir obj2
```

 instead of BIS_fnc_dirTo.

### Syntax

```sqf
[param1, param2] call BIS_fnc_dirTo
```

### Parameters

- param1 - vector starting point, Position **or** Object
- param2 - vector ending point, Position **or** Object

### Return Value

- Number

### Examples

#### Example 1

sets unit1 in the direction of unit2

```sqf
unit1 setDir ([unit1, unit2] call BIS_fnc_dirTo);
```

{{Note
|user= AgentRev
|timestamp= 20150121142000
|text= Be careful when using this function in conjunction with BIS_fnc_rotateVector2D, which rotates vectors counterclockwise as per trigonometric conventions, while BIS_fnc_dirTo returns a clockwise angle.

To counter this, simply negate the output of BIS_fnc_dirTo:

```sqf
[0,1,0], -([_unit, _vehicle] call BIS_fnc_dirTo)] call BIS_fnc_rotateVector2D;
```
