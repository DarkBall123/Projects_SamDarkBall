## displayUpdate

- Source: https://community.bistudio.com/wiki/displayUpdate
- Revision: 338339
- Updated: 2023-02-28T14:38:10Z

- Availability: arma3 2.12
- Groups: GUI Control

### Description

Set the provided display to update its UI On Texture render.

### Syntax

```sqf
displayUpdate display
```

### Parameters

- display: Display - the display to update

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
displayUpdate _myDisplay;
```
