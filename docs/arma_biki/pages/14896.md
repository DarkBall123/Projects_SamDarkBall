## curatorMouseOver

- Source: https://community.bistudio.com/wiki/curatorMouseOver
- Revision: 318936
- Updated: 2022-05-13T09:22:04Z

- Availability: arma3 1.16
- Locality: argument local
- Groups: Curator

### Description

Returns Curator Editable Object under curator mouse pointer.

### Syntax

```sqf
curatorMouseOver
```


### Return Value

- Array
* [] - when not in curator mode
* [""] - if no curator editable object under the pointer in curator mode
* [<nowiki/>typeName, Curator Editable Object] - if there is curator editable object under the pointer in curator mode

### Examples

#### Example 1

```sqf
_mouseOver = curatorMouseOver; // Possible return value: ["OBJECT", 3594ab00# 164218: apc_wheeled_01_cannon_f.p3d]
```
