## markerShape

- Source: https://community.bistudio.com/wiki/markerShape
- Revision: 378609
- Updated: 2026-05-13T15:29:58Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Markers

### Description

Returns the shape of given marker. markerShape#Example_2

This command can be used as a fast way to check if a marker exists. See #Example 2.

### Syntax

```sqf
markerShape  name
```

### Parameters

- name: String - name of the marker

### Return Value

- String - shape of given marker. Can be return:
* `""` - if the marker does not exist
* `"ICON"`
* `"RECTANGLE"`
* `"ELLIPSE"`
* 1.60 `"POLYLINE"` - hand drawn markers
* 2.20 `"TRIANGLE"`
* 2.20 `"PENTAGON"`
* 2.20 `"HEXAGON"`
* 2.20 `"HEPTAGON"`
* 2.20 `"OCTAGON"`
* 2.20 `"NONAGON"`
* 2.20 `"DECAGON"`

### Examples

#### Example 1

```sqf
if (markerShape "Marker1" == "RECTANGLE") then { hint "Marker1 is a rectangle!" };
```

#### Example 2

```sqf
if (markerShape "Marker1" == "") then { hint "Marker1 does not exist!" };
```
