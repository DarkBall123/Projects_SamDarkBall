## isFlashlightOn

- Source: https://community.bistudio.com/wiki/isFlashlightOn
- Revision: 319047
- Updated: 2022-05-13T09:23:05Z

- Availability: arma3 0.50
- Groups: Object Manipulation, Weapons

### Description

Returns true if there is a linked and enabled flashlight on a given weapon.

### Syntax

```sqf
unit isFlashlightOn  weapon
```

### Parameters

- unit: Object
- weapon: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
player isFlashlightOn (currentWeapon player);
```
