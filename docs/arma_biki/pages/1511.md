## hintCadet

- Source: https://community.bistudio.com/wiki/hintCadet
- Revision: 308950
- Updated: 2022-04-18T20:23:13Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Interaction, Difficulty

### Description

Shows a text hint only when in cadetMode.

The text can contain several lines. \n is used to indicate the end of a line.

### Syntax

```sqf
hintCadet text
```

### Parameters

- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
hintCadet "Press W to move forward";
```
