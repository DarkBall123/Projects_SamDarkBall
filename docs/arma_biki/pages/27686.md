## tvIsSelected

- Source: https://community.bistudio.com/wiki/tvIsSelected
- Revision: 378325
- Updated: 2026-04-02T16:30:16Z

- Availability: arma3 2.02
- Groups: GUI Control - Tree View

### Description

Returns true if given treeview item is selected.

### Syntax

```sqf
control tvIsSelected path
```

### Parameters

- control: Control
- path: Tree View Path

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_control tvIsSelected [0];
```
