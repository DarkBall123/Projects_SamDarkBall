## BIS fnc gridToPos

- Source: https://community.bistudio.com/wiki/BIS_fnc_gridToPos
- Revision: 329531
- Updated: 2022-07-30T12:57:54Z

- Availability: arma3 1.00
- Groups: Positions

### Description

Converts grid coordinates to world position.
* Correct results outside of the map area are not guaranteed.
* Does not work on machines with no UI like Dedicated Server or Headless Client - see hasInterface.

### Syntax

```sqf
gridPosition call BIS_fnc_gridToPos
```

### Parameters

- gridPosition: String - (Optional, default 

```sqf
mapGridPosition position cameraOn
```

) accepts both "024577" or "De82" format

### Return Value

- Array of Numbers in format [<nowiki/>[gridX, gridY], [gridWidth, gridHeight]]

### Examples

#### Example 1

```sqf
private _realPosition = "183221" call BIS_fnc_gridToPos;
```

#### Example 2

```sqf
private _realPosition = "He11" call BIS_fnc_gridToPos;
```
