## isUAVConnectable

- Source: https://community.bistudio.com/wiki/isUAVConnectable
- Revision: 319168
- Updated: 2022-05-13T09:23:18Z

- Availability: arma3 1.24
- Groups: Remote Control

### Description

Returns true if UAV is connectable by AV terminal(s).

### Syntax

```sqf
object isUAVConnectable [uav, checkAllItems]
```

### Parameters

- object: Object
- uav: Object or Array
- checkAllItems: Boolean - true to check all terminals in unit's inventory, false to only check assigned terminal.

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _canConnect = myUnit isUAVConnectable [myUav, true];
```
