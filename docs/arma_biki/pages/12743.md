## removeAllItemsWithMagazines

- Source: https://community.bistudio.com/wiki/removeAllItemsWithMagazines
- Revision: 310275
- Updated: 2022-05-05T13:11:22Z

- Availability: arma3 1.04
- Groups: Unit Inventory, Containers

### Description

Removes all itemsWithMagazines from the uniform, vest and backpack. Command essentially clears all unit's containers.

### Syntax

```sqf
removeAllItemsWithMagazines unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllItemsWithMagazines player;
```
