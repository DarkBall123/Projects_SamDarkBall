## getCenterOfMass

- Source: https://community.bistudio.com/wiki/getCenterOfMass
- Revision: 377796
- Updated: 2026-01-03T03:53:42Z

- Availability: arma3 1.12
- Locality: argument global
- Groups: PhysX

### Description

Returns center of mass of an object.

### Syntax

```sqf
getCenterOfMass object
```

### Parameters

- object: Object - PhysX object

### Return Value

- PositionRelative - relative to the model centre

### Examples

#### Example 1

```sqf
_com = getCenterOfMass _myCar;
```
