## BIS fnc reenableRevive

- Source: https://community.bistudio.com/wiki/BIS_fnc_reenableRevive
- Revision: 348219
- Updated: 2023-11-08T11:40:22Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Enable revive on given unit. Revive system needs to be initialized and running.

### Syntax

```sqf
[player] call BIS_fnc_reenableRevive
```

### Parameters

- player: Object - affected player

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_unit] call BIS_fnc_reenableRevive;
```
