## isPlayerSupporter

- Source: https://community.bistudio.com/wiki/isPlayerSupporter
- Revision: 351578
- Updated: 2023-12-07T17:36:20Z

- Availability: argo 1.00
- Locality: argument global
- Groups: Argo

### Description

Get if the provided player has the supporter (VIP) status.

### Multiplayer

Only works in multiplayer.

### Syntax

```sqf
isPlayerSupporter unit
```

### Parameters

- unit: Object - the unit of player to check

### Return Value

- Boolean - true if the provided unit is a player and that player is a supporter, false otherwise

### Examples

#### Example 1

```sqf
_amIASupporter = isPlayerSupporter player;
_isHeASupporter = isPlayerSupporter _otherGuy;
```
