## tvPicture

- Source: https://community.bistudio.com/wiki/tvPicture
- Revision: 378317
- Updated: 2026-04-02T16:16:57Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Returns name of picture from item pointed to by path. IDC means id of parent Tree View.

### Syntax

```sqf
tvPicture [idc, path]
```

```sqf
ctrl tvPicture path
```

### Parameters

- idc: Number
- path: Tree View Path
- ctrl: Control
- path: Tree View Path

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
tvPicture [101, [0]];
```

#### Example 2

```sqf
_ctrl tvPicture [0,0,0];
```
