## posWorldToScreen

- Source: https://community.bistudio.com/wiki/posWorldToScreen
- Revision: 377539
- Updated: 2026-01-02T06:54:25Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Map, Positions

### Description

Converts world coordinates into map screen coordinates. This command is identical to ctrlMapWorldToScreen.

### Syntax

```sqf
map posWorldToScreen position
```

### Parameters

- map : Control - map control
- position : Position2D or Position3D - world position

### Return Value

- Position2D - screen coordinates in format [x, y]

### Examples

#### Example 1

```sqf
_screenCoord = _control posWorldToScreen _worldCoord;
```

#### Example 2

```sqf
_screenCoord = _control posWorldToScreen position player;
```
