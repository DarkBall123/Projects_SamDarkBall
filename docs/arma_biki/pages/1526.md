## primaryWeapon

- Source: https://community.bistudio.com/wiki/primaryWeapon
- Revision: 349379
- Updated: 2023-11-08T15:35:14Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns name of unit's primary weapon. This command will also return a weapon class name if the weapon is not used by the player, for example, it is on the unit's back. Use currentWeapon to get the weapon the unit is using.

### Syntax

```sqf
primaryWeapon unit
```

### Parameters

- unit: Object

### Return Value

- String - weapon class name or "" if no primary weapon

### Examples

#### Example 1

```sqf
_pWeap = primaryWeapon player;
```

#### Example 2

```sqf
hint primaryWeapon player; // "arifle_MX_ACO_pointer_F"
```
