## setCurrentChannel

- Source: https://community.bistudio.com/wiki/setCurrentChannel
- Revision: 376800
- Updated: 2025-11-20T17:47:43Z

- Availability: arma3 1.42
- Locality: effect local
- Groups: Radio and Chat

### Description

Sets given channel as current chat channel. Scripted way of selecting desired channel on the UI.
The given channel may be disabled (see enableChannel), this is why this command returns boolean, true on success or false on failure.

### Syntax

```sqf
setCurrentChannel channelID
```

### Parameters

- channelID: Number - channel ID

### Return Value

- Boolean - true on success

### Examples

#### Example 1

```sqf
_isDirectSelected = setCurrentChannel 5; // sets Direct channel as current active
```
