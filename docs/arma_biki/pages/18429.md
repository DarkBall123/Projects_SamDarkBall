## diag toggle

- Source: https://community.bistudio.com/wiki/diag_toggle
- Revision: 369317
- Updated: 2024-09-03T18:42:56Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Toggles various diagnostics.

### Syntax

```sqf
diag_toggle mode
```

### Parameters

- mode: String - see Arma 3: Diagnostics Exe

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
diag_toggle "Animation"; // enable
diag_toggle "Animation"; // disable
```
