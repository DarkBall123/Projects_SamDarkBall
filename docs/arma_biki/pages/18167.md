## tvSetPictureRightColorDisabled

- Source: https://community.bistudio.com/wiki/tvSetPictureRightColorDisabled
- Revision: 377789
- Updated: 2026-01-03T01:40:03Z

- Availability: arma3 1.62
- Groups: GUI Control - Tree View

### Description

Sets the color of the right picture of a tree item defined by path when item is disabled

### Syntax

```sqf
control tvSetPictureRightColorDisabled [path, color]
```

### Parameters

- control: Control
- path: Tree View Path
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control tvSetPictureRightColorDisabled [[0], [1,0,1,1]];
```
