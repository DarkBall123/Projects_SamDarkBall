## BIS fnc selectDiarySubject

- Source: https://community.bistudio.com/wiki/BIS_fnc_selectDiarySubject
- Revision: 348504
- Updated: 2023-11-08T13:01:33Z

- Availability: arma3 1.00
- Groups: Briefing

### Description

Selects a diary subject. 
This was a temporary replacement for selectDiarySubject scripting command which **had been broken** until v2.04.

### Syntax

```sqf
[diaryName] call BIS_fnc_selectDiarySubject
```

### Parameters

- diaryName: String - diary subject name

### Return Value

- Boolean - true if the subject was found and selected

### Examples

#### Example 1

```sqf
["someSubject"] call BIS_fnc_selectDiarySubject;
```
