## allDeadMen

- Source: https://community.bistudio.com/wiki/allDeadMen
- Revision: 378914
- Updated: 2026-08-12T19:45:30Z

- Availability: arma3 0.50
- Groups: Object Detection

### Description

Return a list of dead units including agents. Dead unit might be inside vehicle.

### Syntax

```sqf
allDeadMen
```


### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
{ deleteVehicle _x } forEach allDeadMen;
```

{{Note
|user= Pierre MGI
|timestamp= 20151015040800
|text= As dead men are civilian side, don't try to count them with 

```sqf
{ side _x isEqualTo east } count allDeadMen;
```

 result will always be 0.

Use the configfile "side" instead:

```sqf
0 spawn
{
	while { true } do
	{
		sleep 0.1;
		_westScore =
		{
			getNumber (configFile >> "CfgVehicles" >> typeOf _x >> "side") == 0
		} count allDeadMen;
		hintSilent format ["East killed: %1", _westScore];
	};
};
```
