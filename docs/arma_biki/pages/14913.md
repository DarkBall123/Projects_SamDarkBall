## addScoreSide

- Source: https://community.bistudio.com/wiki/addScoreSide
- Revision: 318736
- Updated: 2022-05-13T09:21:24Z

- Availability: arma3 1.12
- Locality: argument global, effect global, server execution server
- Groups: Sides, Multiplayer

### Description

Adds side score. This is shown in the MP score tab as the total score. **MP only**.

### Syntax

```sqf
side addScoreSide value
```

### Parameters

- side: Side
- value: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
west addScoreSide 10;
```
