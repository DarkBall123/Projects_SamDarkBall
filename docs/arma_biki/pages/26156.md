## forceAtPositionRTD

- Source: https://community.bistudio.com/wiki/forceAtPositionRTD
- Revision: 376360
- Updated: 2025-10-07T21:42:17Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Adds force generator to world.
{{Feature|afm}}

### Syntax

```sqf
forceAtPositionRTD position
```

### Parameters

- position: Array - position where to force generator is created.

### Return Value

- Number - force index

### Examples

#### Example 1

```sqf
forceAtPositionRTD [0,0,0];
```
