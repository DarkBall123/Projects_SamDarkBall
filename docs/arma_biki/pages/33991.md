## displayUniqueName

- Source: https://community.bistudio.com/wiki/displayUniqueName
- Revision: 338365
- Updated: 2023-03-01T10:17:02Z

- Availability: arma3 2.12
- Groups: GUI Control

### Description

Get the provided display's UI On Texture unique name.
See findDisplay to get a Display by its unique name.

### Syntax

```sqf
displayUniqueName display
```

### Parameters

- display: Display

### Return Value

- String - the unique display identifier

### Examples

#### Example 1

```sqf
private _displayName = displayUniqueName _myDisplay;
```
