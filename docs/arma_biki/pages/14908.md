## uniformMagazines

- Source: https://community.bistudio.com/wiki/uniformMagazines
- Revision: 321373
- Updated: 2022-05-14T10:55:55Z

- Availability: arma3 0.50
- Groups: Containers, Unit Inventory

### Description

Get array with all magazines from uniform of the given unit.

### Syntax

```sqf
uniformMagazines unit
```

### Parameters

- unit: Object

### Return Value

- Array of String

### Examples

#### Example 1

```sqf
uniformMagazines player;
// returns e.g
/*
[
	"6.5mm 30Rnd STANAG Mag(30/30)[id/cr:1/0](3x)"
]
*/
```
