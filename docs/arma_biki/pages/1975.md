## camUseNVG

- Source: https://community.bistudio.com/wiki/camUseNVG
- Revision: 369119
- Updated: 2024-09-03T10:30:51Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Set / clear using of night vision during cutscenes. This command only works with camCreate created camera that is currently the main camera for the player (see #Examples).

### Syntax

```sqf
camUseNVG set
```

### Parameters

- set: Boolean - enable/disable night vision

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
camUseNVG true;
```

#### Example 2

```sqf
setDate [2000, 12, 31, 0, 0];
_cam = "camera" camCreate [0, 0, 0];
_cam camSetTarget player;
_cam camSetRelPos [0, -5, 3];
_cam cameraEffect ["Internal", "Back"];
_cam camCommit 0;
camUseNVG true;
```
