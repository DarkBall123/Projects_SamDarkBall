## getWaterLeakiness

- Source: https://community.bistudio.com/wiki/getWaterLeakiness
- Revision: 378411
- Updated: 2026-04-04T08:32:46Z

- Availability: arma3 2.16
- Locality: argument global
- Groups: Object Manipulation

### Description

Get an object's water intake ratio when immersed.

### Syntax

```sqf
getWaterLeakiness obj
```

### Parameters

- obj: Object - object to check

### Return Value

- Number in range 0..1 - 0 is waterproof and 1 is full leak

### Examples

#### Example 1

```sqf
if (getWaterLeakiness _myCar > 0) then
{
	hint "don't go in the water with it!";
};
```
