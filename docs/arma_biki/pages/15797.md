## BIS fnc getIDD

- Source: https://community.bistudio.com/wiki/BIS_fnc_getIDD
- Revision: 349463
- Updated: 2023-11-08T16:49:17Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Returns IDD of given display.

### Syntax

```sqf
[config] call BIS_fnc_getIDD
```

### Parameters

- config: Config - config path to display

### Return Value

- Number - IDD

### Examples

#### Example 1

```sqf
private _IDD = [configFile >> "display3DENPublishMissionSelectImage"] call BIS_fnc_getIDD;
```
