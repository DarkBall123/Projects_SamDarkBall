## setPilotCameraRotation

- Source: https://community.bistudio.com/wiki/setPilotCameraRotation
- Revision: 323076
- Updated: 2022-06-28T21:43:12Z

- Availability: arma3 1.64
- Locality: argument local
- Groups: Pilot Camera

### Description

Sets rotation (relative to the centered camera position) of the object airplane or helicopter pilotCamera .

### Syntax

```sqf
object setPilotCameraRotation rotation
```

### Parameters

- object: Object
- rotation: Array - [x,y] - format [yaw (turn), pitch (elevation)]. Values are in radians, positive values are left yaw and down pitch from the center.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setPilotCameraRotation [rad 90, rad 45];
```
