## getArtilleryComputerSettings

- Source: https://community.bistudio.com/wiki/getArtilleryComputerSettings
- Revision: 377650
- Updated: 2026-01-02T09:01:56Z

- Availability: arma3 0.50
- Groups: Artillery

### Description

Returns settings from current vehicle weapon manned by player.

### Syntax

```sqf
getArtilleryComputerSettings
```


### Return Value

- Array with [fireMode, ammo, zero]
* fireMode: String - fire mode's display name
* ammo: String - used ammo display name (**not** class name)
* zero: Number - always 0

### Examples

#### Example 1

```sqf
hint str getArtilleryComputerSettings; // ["Semi (medium)", "HE Mortar Shells", 0]
```
