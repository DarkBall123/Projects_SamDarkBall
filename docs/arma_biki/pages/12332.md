## ctrlSetFontP

- Source: https://community.bistudio.com/wiki/ctrlSetFontP
- Revision: 318848
- Updated: 2022-05-13T09:21:55Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets P font of given HTML control or its size.

### Syntax

```sqf
control ctrlSetFontP fontOrSize
```

### Parameters

- control: Control
- fontOrSize: String or Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontP "TahomaB";
```

#### Example 2

```sqf
_control ctrlSetFontP 0.05;
```
