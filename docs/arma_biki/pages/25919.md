## setBehaviourStrong

- Source: https://community.bistudio.com/wiki/setBehaviourStrong
- Revision: 364285
- Updated: 2024-05-06T09:38:35Z

- Availability: arma3 1.92
- Locality: argument local, effect global
- Groups: Groups, AI Behaviour

### Description

Sets individual unit behaviour on every unit in a group and additionally tries to force this behaviour to the unit's group. Alternatively see setCombatBehaviour.
See AI Behaviour for details of the effect of this command on AI units.

{

### Syntax

```sqf
groupName setBehaviourStrong behaviour
```

### Parameters

- groupName: Group or Object - unit from the group
- behaviour: String - can be one of:
* "CARELESS"
* "SAFE"
* "AWARE"
* "COMBAT"
* "STEALTH"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_group1 setBehaviourStrong "SAFE";
```
