## remove3DENLayer

- Source: https://community.bistudio.com/wiki/remove3DENLayer
- Revision: 351677
- Updated: 2023-12-20T10:39:52Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Remove Eden Editor editing layer.
delete3DENEntities seems to be more reliable.

### Syntax

```sqf
remove3DENLayer layerID
```

### Parameters

- layerID : Number - layer ID as returned by add3DENLayer command

### Return Value

- Boolean - true if the layer was removed successfully (i.e., correct layer ID was used)

### Examples

#### Example 1

```sqf
private _myLayer = -1 add3DENLayer "Enemy Base";
remove3DENLayer _myLayer;
```
