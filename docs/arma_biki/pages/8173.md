## armoryPoints

- Source: https://community.bistudio.com/wiki/armoryPoints
- Revision: 310774
- Updated: 2022-05-07T20:21:44Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Returns, stored in [USERNAME].ArmaXProfile, value of *armoryPoints* entry. If the entry doesn't exist, it returns 0.

### Syntax

```sqf
**armoryPoints**
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
_points = armoryPoints;
```
