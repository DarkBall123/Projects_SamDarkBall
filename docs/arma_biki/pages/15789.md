## BIS fnc dbImportXML

- Revision: 348501
- Updated: 2023-11-08T13:01:32Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Import XML file into Scripted Database.

### Syntax

```sqf
xmlFile call BIS_fnc_dbImportXML
```

### Parameters

- xmlFile: String - XML file path

### Return Value

- Array - database

### Examples

#### Example 1

```sqf
private _xmlDB = "myFile.xml" call BIS_fnc_dbImportXML;
```
