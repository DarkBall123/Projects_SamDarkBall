## taskMarkerOffset

- Source: https://community.bistudio.com/wiki/taskMarkerOffset
- Revision: 319857
- Updated: 2022-05-13T09:25:36Z

- Availability: arma3 1.58
- Groups: Briefing

### Description

Returns model space position for the task marker

### Syntax

```sqf
taskMarkerOffset unit
```

### Parameters

- unit: Object

### Return Value

- Array - offset in format [x, y, z]

### Examples

#### Example 1

```sqf
_offset = taskMarkerOffset player;
```
