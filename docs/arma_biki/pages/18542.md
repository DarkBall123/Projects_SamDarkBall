## ctRemoveRows

- Source: https://community.bistudio.com/wiki/ctRemoveRows
- Revision: 376516
- Updated: 2025-10-22T23:05:37Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Takes array of row indices as a parameter and removes rows with those indices. Indices of remaining rows will be recomputed.

### Syntax

```sqf
ctrl ctRemoveRows [index1, index2, ...]
```

### Parameters

- ctrl: Control
- indexN: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctRemoveRows [0, 1, 2];
```
