## hcRemoveGroup

- Source: https://community.bistudio.com/wiki/hcRemoveGroup
- Revision: 363247
- Updated: 2024-03-26T10:51:22Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Removes group from unit's high command bar.

### Syntax

```sqf
unit hcRemoveGroup group
```

### Parameters

- unit: Object
- group: Group

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player hcRemoveGroup BIS_group;
```
