## setMissionOptions

- Source: https://community.bistudio.com/wiki/setMissionOptions
- Revision: 378913
- Updated: 2026-08-12T15:53:18Z

- Availability: arma3 2.18
- Locality: effect local
- Groups: System

### Description

Sets various mission options. The options are automatically reset between missions and are saved/restored with the save system.

Available Options:

* IgnoreNoDamage: Boolean - (default false) true to filter out no change in damage from [HandleDamage](Arma 3: Event Handlers#HandleDamage) calls
* IgnoreFakeHeadHit: Boolean - (default false) true to filter out FakeHeadHit context from [HandleDamage](Arma 3: Event Handlers#HandleDamage) calls
* IgnoreUpsideDownDamage: Boolean - (default false) true to ignore some minor upside down damage accumulation for a helicopter
* 2.20 SnakesCanOpenDoors: Boolean - (default false) true to revert to legacy behaviour when snakes would open doors when entering houses
* 2.20 AIThinkOnlyLocal: Boolean - (default false) true to disable processing targetting data for remote AI units, knowsAbout, targets and similar commands will cease to work on remote units. For a gain in client performance because they no longer have to calculate all AI units. 
* 2.24 MapSymbolIsHiddenWithTheObject: Boolean - (default true) true to hide map symbol when terrain object is hidden.
* 2.24 MapHideForests: Boolean - (default false) true to hide map symbols for forests.
* 2.24 MapHideRockFormations: Boolean - (default false) true to hide map symbols for rock formations.
* 2.24 MapHideTowns: Boolean - (default false) true to hide map symbols for towns.
* 2.24 MapHideRoads: Boolean - (default false) true to hide map symbols for roads.
* 2.24 MapHideRivers: Boolean - (default false) true to hide map symbols for rivers.
* 2.24 MapHideSigns: Boolean - (default false) true to hide map icons for objects.
* 2.24 MapHideSmallSigns: Boolean - (default false) true to hide map icons for trees, bushes, rocks.
* 2.24 MapHideLocations: Boolean - (default false) true to hide map icons for trees, bushes, rocks.

Providing a empty HashMap will reset all options to defaults.

### Syntax

```sqf
setMissionOptions options
```

### Parameters

- options: HashMap - a HashMap containing all the options to be changed

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setMissionOptions createHashMapFromArray [["IgnoreNoDamage", true], ["IgnoreFakeHeadHit", true], ["IgnoreUpsideDownDamage", true]];
```

#### Example 2

```sqf
setMissionOptions createHashMap; // reset options to default
```
