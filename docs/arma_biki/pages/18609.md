## getCustomAimCoef

- Source: https://community.bistudio.com/wiki/getCustomAimCoef
- Revision: 338293
- Updated: 2023-02-26T18:30:34Z

- Availability: arma3 1.54
- Locality: argument global
- Groups: Stamina System

### Description

Returns aimPrecision from animation state with custom value that will directly affects weapon sway size and speed.

### Syntax

```sqf
getCustomAimCoef unit
```

### Parameters

- unit: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
_coef = getCustomAimCoef player;
```
