## enableSatNormalOnDetail

- Source: https://community.bistudio.com/wiki/enableSatNormalOnDetail
- Revision: 310242
- Updated: 2022-05-05T13:11:02Z

- Availability: arma3 1.00
- Groups: System

### Description

Enables/Disables satellite normal map or detail maps.

### Syntax

```sqf
enableSatNormalOnDetail state
```

### Parameters

- state: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableSatNormalOnDetail true;
```
