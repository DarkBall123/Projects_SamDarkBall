## setTargetAge

- Source: https://community.bistudio.com/wiki/setTargetAge
- Revision: 363641
- Updated: 2024-04-09T21:20:52Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Sets how the target is known to the other centers. They behave like the target was seen age seconds ago.

### Syntax

```sqf
object setTargetAge age
```

### Parameters

- object: Object
- age: String - can be:
* "ACTUAL"
* "5 MIN"
* "10 MIN"
* "15 MIN"
* "30 MIN"
* "60 MIN"
* "120 MIN"
* "UNKNOWN"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setTargetAge "10 MIN";
```
