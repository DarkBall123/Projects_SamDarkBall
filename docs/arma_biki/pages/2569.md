## min

- Updated: 2022-05-13T15:21:16Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

The smaller of a and b.

### Syntax

```sqf
a min  b
```

### Parameters

- a: Number
- b: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
3 min 2 // Result is 2
```

#### Example 2

```sqf
-3 min -2 // Result is -3
```
