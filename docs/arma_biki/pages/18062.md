## BIS fnc sideIsFriendly

- Source: https://community.bistudio.com/wiki/BIS_fnc_sideIsFriendly
- Revision: 349197
- Updated: 2023-11-08T14:50:41Z

- Availability: arma3 1.56
- Groups: Sides

### Description

Determines if side B is friendly to side A the way the game engine does it. The relationship table can be found here:  Side Relations.

### Syntax

```sqf
[sideA, sideB] call BIS_fnc_sideIsFriendly
```

### Parameters

- sideA: Side
- sideB: Side

### Return Value

- Boolean - true if side B is friendly to side A.

### Examples

#### Example 1

```sqf
private _isFriendly = [west, east] call BIS_fnc_sideIsFriendly; //Checks if EAST is friendly to WEST.
```
