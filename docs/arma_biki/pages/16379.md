## BIS fnc listCuratorPlayers

- Revision: 309318
- Updated: 2022-05-05T12:04:27Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns list of playable units with access to curator.

### Syntax

```sqf
[] call BIS_fnc_listCuratorPlayers
```


### Return Value

- Array - list of players

### Examples

#### Example 1

```sqf
call BIS_fnc_listCuratorPlayers;
```
