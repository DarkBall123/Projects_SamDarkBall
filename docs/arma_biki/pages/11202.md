## BIS fnc wpCheckpoint

- Source: https://community.bistudio.com/wiki/BIS_fnc_wpCheckpoint
- Revision: 323177
- Updated: 2022-07-01T11:28:26Z

- Availability: tkoh 1.00
- Groups: Waypoints

### Description

CHECKPOINT custom waypoint.

Player has to reach waypoint position with certain precision (as opposed to normal Move waypoint, which became completed in around 500m).

### Syntax

```sqf
Custom Waypoint arguments: [posLimit]
```

### Parameters

- posLimit: Code - time in seconds unit is required to stay withing waypoint completion radius (default: -1)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, getPosASL dude, 10, 2] spawn BIS_fnc_wpCheckpoint;
```
