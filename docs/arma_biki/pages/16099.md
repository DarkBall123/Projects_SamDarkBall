## BIS fnc addClassOO

- Source: https://community.bistudio.com/wiki/BIS_fnc_addClassOO
- Revision: 348326
- Updated: 2023-11-08T12:59:44Z

- Availability: arma3 1.00
- Groups: OO

### Description

Registering a class for the OO scripting shell.

### Syntax

```sqf
class call BIS_fnc_addClassOO
```

### Parameters

- class: String - class for the OO scripting shell Class has to exist in CfgOO

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"someOOClass" call BIS_fnc_addClassOO;
```
