## setTaskState

- Source: https://community.bistudio.com/wiki/setTaskState
- Revision: 349143
- Updated: 2023-11-08T14:49:48Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Set the state of a given task.

### Syntax

```sqf
task setTaskState state
```

### Parameters

- task: Task
- state: String - state value may be one of:
*"None"
*"Created"
*"Assigned"
*"Succeeded"
*"Failed"
*"Canceled"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_tskKillSpongebob setTaskState "Succeeded";
```
