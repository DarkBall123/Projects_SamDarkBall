## disableNVGEquipment

- Source: https://community.bistudio.com/wiki/disableNVGEquipment
- Revision: 336380
- Updated: 2022-12-31T19:13:15Z

- Availability: arma3 1.52
- Locality: argument global, effect global
- Groups: Weapons

### Description

Enables or disables transport NV (Night Vision). To disable TI (Thermal Imaging) use disableTIEquipment.

### Syntax

```sqf
vehicle disableNVGEquipment state
```

### Parameters

- vehicle: Object
- state: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myTank disableNVGEquipment true;
```
