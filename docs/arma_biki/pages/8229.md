## detach

- Source: https://community.bistudio.com/wiki/detach
- Revision: 369227
- Updated: 2024-09-03T10:34:55Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Detaches previously attached with attachTo object.

### Multiplayer

Only has to be executed on one client.

### Syntax

```sqf
detach object
```

### Parameters

- object: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
obj1 attachTo [player];
detach obj1;
```
