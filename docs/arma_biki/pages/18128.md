## pixelGrid

- Source: https://community.bistudio.com/wiki/pixelGrid
- Revision: 376543
- Updated: 2025-10-27T00:18:56Z

- Availability: arma3 1.60
- Groups: GUI Control - Positioning

### Description

Returns grid size based on screen resolution, UI size and configs: uiScaleFactor, uiScaleMaxGrids.

### Syntax

```sqf
pixelGrid
```


### Return Value

- Number - grid size, see Arma 3: Pixel Grid System

### Examples

#### Example 1

```sqf
private _gridHeight = pixelH * pixelGrid;
```
