- Locality: argument global
- Groups: Sides

### Description

Count how many units in the array are unknown to the given unit.

### Syntax

```sqf
unit countUnknown others
```

### Parameters

- unit: Object
- others: Array of Objects

### Return Value

- Number

### Examples

#### Example 1

```sqf
_num = player countUnknown list _triggerOne;
```
