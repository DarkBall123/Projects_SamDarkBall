## ctrlModelVectorSide

- Source: https://community.bistudio.com/wiki/ctrlModelVectorSide
- Revision: 377877
- Updated: 2026-01-04T13:26:46Z

- Availability: arma3 2.18
- Groups: GUI Control - Object

### Description

Get the provided control model's vectorSide in 3D-Dialogs.

### Syntax

```sqf
ctrlModelVectorSide control
```

### Parameters

- control : Control - 3D control

### Return Value

- Vector3D - vectorSide of the model or empty array if *control* is null

### Examples

#### Example 1

```sqf
private _vectorSide = ctrlModelVectorSide _control3D;
```
