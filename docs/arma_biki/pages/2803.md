## commandFSM

- Source: https://community.bistudio.com/wiki/commandFSM
- Revision: 377186
- Updated: 2026-01-01T10:51:44Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control

### Description

Orders a unit to process command defined by FSM file (via the radio).

### Syntax

```sqf
unitName commandFSM [fsmFile, position, target]
```

### Parameters

- unitName: Object or Array of Objects
- fsmFile: String
- position: Position
- target: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldierOne commandFSM ["move.fsm", position player, player];
```
