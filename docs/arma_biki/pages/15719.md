## BIS fnc vectorAdd

- Source: https://community.bistudio.com/wiki/BIS_fnc_vectorAdd
- Revision: 349009
- Updated: 2023-11-08T14:47:05Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Vectors

### Description

Returns the sum of two vectors.
If the vector is either 2D or 3D use vectorAdd instead.

### Syntax

```sqf
[vector1, vector2] call BIS_fnc_vectorAdd
```

### Parameters

- vector1: Array of Numbers
- vector2: Array of Numbers

### Return Value

- Array of Numbers - resulting vector

### Examples

#### Example 1

```sqf
[[1, 1, 1, 1, 1], [2, 5, 3, 1, 1]] call BIS_fnc_vectorAdd; // returns [3,6,4,2,2]
```
