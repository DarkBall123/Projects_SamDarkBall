## setCustomAimCoef

- Source: https://community.bistudio.com/wiki/setCustomAimCoef
- Revision: 319776
- Updated: 2022-05-13T09:24:52Z

- Availability: arma3 1.54
- Locality: argument local, effect local
- Groups: Stamina System

### Description

Set custom aim precision coefficient for weapon sway

### Syntax

```sqf
unit setCustomAimCoef coef
```

### Parameters

- unit: Object
- coef: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setCustomAimCoef 3;
```
