## BIS fnc controlPoint setIsArrive

- Source: https://community.bistudio.com/wiki/BIS_fnc_controlPoint_setIsArrive
- Revision: 349230
- Updated: 2023-11-08T14:50:53Z

- Availability: arma3 1.78
- Groups: ControlPoint

### Description

Set's whether this control point is arrive or leave.

### Syntax

```sqf
[controlPoint, isArrive] call BIS_fnc_controlPoint_setIsArrive
```

### Parameters

- controlPoint: Object - the control point
- isArrive: Object - (Optional, default true) true - arrive
false -  leave

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[controlPoint,false] call BIS_fnc_controlPoint_setIsArrive;
```
