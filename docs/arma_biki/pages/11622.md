## radioChannelRemove

- Source: https://community.bistudio.com/wiki/radioChannelRemove
- Revision: 377811
- Updated: 2026-01-03T04:09:28Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Radio and Chat, Custom Radio and Chat

### Description

Remove the units from the custom radio channel.

### Syntax

```sqf
customChannelID radioChannelRemove units
```

### Parameters

- customChannelID: Number - custom channel ID returned by radioChannelCreate command
- units: Array of Objects - units

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
3 radioChannelRemove [blufor_unit_1, blufor_unit_2];
```
