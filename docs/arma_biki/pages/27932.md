## menuSetShortcut

- Source: https://community.bistudio.com/wiki/menuSetShortcut
- Revision: 378330
- Updated: 2026-04-02T16:30:41Z

- Availability: arma3 2.02
- Groups: GUI Control - Menu

### Description

Sets shortcut of given menu strip entry.

### Syntax

```sqf
menuSetShortcut [idc, path, shortcut]
```

```sqf
control menuSetShortcut [path, shortcut]
```

### Parameters

- idc: Number
- path: Tree View Path
- shortcut: Number
- control: Control
- path: Tree View Path
- shortcut: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_ctrlMenuStrip menuSetShortcut [[0,0], 2048 + 0x16]; // ALT + U
```
