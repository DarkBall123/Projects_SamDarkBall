## isFormationLeader

- Source: https://community.bistudio.com/wiki/isFormationLeader
- Revision: 349302
- Updated: 2023-11-08T14:52:18Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Groups

### Description

Returns true if the specified unit is subgroup leader.

### Syntax

```sqf
isFormationLeader unit
```

### Parameters

- unit: Object - unit being checked.

### Return Value

- Boolean - true if unit is subgroup leader.

### Examples

#### Example 1

```sqf
_isLeader = isFormationLeader player;
```
