## setMarkerDirLocal

- Source: https://community.bistudio.com/wiki/setMarkerDirLocal
- Revision: 348231
- Updated: 2023-11-08T11:40:28Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Sets the orientation of the marker.

### Syntax

```sqf
markerName setMarkerDirLocal angle
```

### Parameters

- markerName: String
- angle: Number - angle of the marker in degree

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"Marker1" setMarkerDirLocal 90;
```

### See Also

setMarkerDir markerDir
