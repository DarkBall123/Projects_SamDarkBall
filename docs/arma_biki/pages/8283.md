## hcSelectGroup

- Source: https://community.bistudio.com/wiki/hcSelectGroup
- Revision: 347546
- Updated: 2023-09-28T09:23:04Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: High Command

### Description

Select given group in high command bar.

### Syntax

```sqf
unit hcSelectGroup array
```

### Parameters

- unit: Object - HC Owner
- array: Array of Groups

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player hcSelectGroup [group_1,group_2];
```
