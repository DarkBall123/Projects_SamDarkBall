## setCuratorWaypointCost

- Source: https://community.bistudio.com/wiki/setCuratorWaypointCost
- Revision: 348446
- Updated: 2023-11-08T13:00:16Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Sets cost of waypoints (used for placing, editing and deleting).

### Syntax

```sqf
curatorObj setCuratorWaypointCost cost
```

### Parameters

- curatorObj: Object - curator module
- cost: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myCurator setCuratorWaypointCost 0.1;
```
