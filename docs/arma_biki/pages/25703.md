## ctrlSetPositionY

- Source: https://community.bistudio.com/wiki/ctrlSetPositionY
- Revision: 349336
- Updated: 2023-11-08T14:53:28Z

- Availability: arma3 1.92
- Groups: GUI Control - Positioning

### Description

Sets vertical position (y) of a 2D control. ctrlCommit is required to complete the operation.

### Syntax

```sqf
control ctrlSetPositionY y
```

### Parameters

- control: Control - 2D control
- y: Number - vertical position of the control

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl ctrlSetPositionY 0.5;
_ctrl ctrlCommit 1;
```
