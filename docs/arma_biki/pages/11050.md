## BIS fnc log

- Source: https://community.bistudio.com/wiki/BIS_fnc_log
- Revision: 351743
- Updated: 2023-12-30T21:31:42Z

- Availability: arma3 0.50
- Groups: Diagnostic

### Description

Log debug message.
`allowFunctionsLog` has to be set to **1** in Description.ext for this function to have any effect.

### Syntax

```sqf
param call BIS_fnc_log
```

### Parameters

- param: Anything

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
diag_tickTime call BIS_fnc_log;
```

#### Example 2

```sqf
[dayTime, overcast, fog] call BIS_fnc_log;
```

#### Example 3

```sqf
(name player) call BIS_fnc_log;
```
