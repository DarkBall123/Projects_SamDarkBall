## menuDelete

- Source: https://community.bistudio.com/wiki/menuDelete
- Revision: 378336
- Updated: 2026-04-02T16:31:01Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Deletes menu entry on given path.

### Syntax

```sqf
menuDelete [idc,path]
```

```sqf
control menuDelete path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
(findDisplay 313 displayCtrl 120) menuDelete [1]; // removes the second entry from Eden Editor menu strip. Restart Eden Editor to reset the menu.
```
