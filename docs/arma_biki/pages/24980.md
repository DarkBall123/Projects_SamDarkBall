## BIS fnc interpolateVectorConstant

- Source: https://community.bistudio.com/wiki/BIS_fnc_interpolateVectorConstant
- Revision: 349200
- Updated: 2023-11-08T14:50:42Z

- Availability: arma3 1.78
- Groups: Interpolation, Vectors

### Description

Interpolates vector to target linearly.

### Syntax

```sqf
[currentValue, targetValue, delta, interpSpeed] call BIS_fnc_interpolateVectorConstant
```

### Parameters

- currentValue: Array - the current value
- targetValue: Array - the target value
- delta: Number - (Optional, default 0) the delta time
- interpSpeed: Number - (Optional, default 0) the interpolation speed

### Return Value

- Array - the interpolated value

### Examples

#### Example 1

```sqf
[[1,1,1], [20,20,20], 0.2, 0.1] call BIS_fnc_interpolateVectorConstant;
```
