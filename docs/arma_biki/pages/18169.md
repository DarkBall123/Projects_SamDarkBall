## tvSetPictureRightColor

- Source: https://community.bistudio.com/wiki/tvSetPictureRightColor
- Revision: 377790
- Updated: 2026-01-03T01:40:04Z

- Availability: arma3 1.62
- Groups: GUI Control - Tree View

### Description

Sets color of the right picture on the tree view item defined by path

### Syntax

```sqf
tvSetPictureRightColor [idc, path, color]
```

```sqf
control tvSetPictureRightColor [path, color]
```

### Parameters

- idc: Number
- path: Tree View Path
- color: Color (RGBA)
- control: Control
- path: Tree View Path
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvSetPictureRightColor [101, [0], [1,0,1,1]];
```

#### Example 2

```sqf
_ctrl tvSetPictureRightColor [[0], [1,0,1,1]];
```
