## setVehicleArmor

- Source: https://community.bistudio.com/wiki/setVehicleArmor
- Revision: 369388
- Updated: 2024-09-03T18:43:16Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Sets the armor (or health for men) state of the vehicle (a value from 0 to 1). 

Works like setDamage, but the other way around: 1 is full health - see #Example 2.

### Syntax

```sqf
vehicleName setVehicleArmor value
```

### Parameters

- vehicleName: Object
- value: Number - in range 0..1

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setVehicleArmor 0.5;
```

#### Example 2

```sqf
player setVehicleArmor 1;
// is the same as
player setDamage 0;

player setVehicleArmor 0;
// is the same as
player setDamage 0.97;
```
