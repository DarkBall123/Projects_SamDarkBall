## getMissionLayers

- Source: https://community.bistudio.com/wiki/getMissionLayers
- Revision: 377088
- Updated: 2026-01-01T09:46:21Z

- Availability: arma3 1.56
- Groups: Mission Information

### Description

Returns a list of all layers created in Eden Editor. Designed to be used during a scenario. Default layers (BLUFOR, OPFOR...) are not returned.

### Syntax

```sqf
getMissionLayers
```


### Return Value

- Array of Strings - names of layers

### Examples

#### Example 1

```sqf
getMissionLayers; // ["Electronics","Camp Endurance","UGV Workstation","Comments","Extraction Air","Comments","Extraction Ground","Extraction","test"]
```
