## getPosATLVisual

- Source: https://community.bistudio.com/wiki/getPosATLVisual
- Revision: 377529
- Updated: 2026-01-02T06:53:11Z

- Availability: arma3 1.32
- Locality: argument global
- Groups: Object Manipulation, Render Time Scope

### Description

Returns an object's rendered ATL position (z value above ground) in render time scope.

### Syntax

```sqf
getPosATLVisual object
```

### Parameters

- object: Object

### Return Value

- PositionATL

### Examples

#### Example 1

```sqf
_playerRenderedPosATL = getPosATLVisual player;
```
