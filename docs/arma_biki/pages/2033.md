## waypointAttachVehicle

- Source: https://community.bistudio.com/wiki/waypointAttachVehicle
- Revision: 319971
- Updated: 2022-05-13T09:25:48Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Attaches the Waypoint to the provided vehicle Object.
{{Feature | important | Use this command to associate a transport with `"GETIN"` waypoint, other types of waypoints might or might not work.
See also setWaypointType to set the waypoint type to "GETIN".}}

### Syntax

```sqf
waypoint waypointAttachVehicle vehicleName
```

### Parameters

- waypoint: Waypoint
- vehicleName: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] waypointAttachVehicle vehicle player;
```

#### Example 2

```sqf
((waypoints player) select 0) waypointAttachVehicle _soldier1;
```
