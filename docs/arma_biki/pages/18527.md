## ctAddRow

- Source: https://community.bistudio.com/wiki/ctAddRow
- Revision: 310853
- Updated: 2022-05-07T20:24:08Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Adds one row of controls according to the RowTemplate class. It returns an array containing row index and array of created controls in a format [<rowIndex>, [<control0>, <control1>...<control n>]].

Note that rows and headers are indexed separately.

### Syntax

```sqf
ctAddRow control
```

### Parameters

- control: Control

### Return Value

- Array

### Examples

#### Example 1

```sqf
_array = ctAddRow _control;
```
