## setCurrentTask

- Source: https://community.bistudio.com/wiki/setCurrentTask
- Revision: 319791
- Updated: 2022-05-13T09:24:54Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Set the task as a current task of the person.

### Syntax

```sqf
object setCurrentTask task
```

### Parameters

- object: Object - the unit having the task
- task: Task - the task you want to select

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setCurrentTask tskKillSpongebob;
```
