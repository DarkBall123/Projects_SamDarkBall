## removeItems

- Source: https://community.bistudio.com/wiki/removeItems
- Revision: 319499
- Updated: 2022-05-13T09:24:12Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Unit Inventory

### Description

Removes all items with given class name from the inventory.

### Syntax

```sqf
unit removeItems item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeItems "FirstAidKit";
```
