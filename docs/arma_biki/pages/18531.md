## ctSetCurSel

- Source: https://community.bistudio.com/wiki/ctSetCurSel
- Revision: 310076
- Updated: 2022-05-05T12:25:08Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Selects the line with the given index. Will take only rows, but not headers into account. -1 deselects all. Returns Nothing.

### Syntax

```sqf
control ctSetCurSel index
```

### Parameters

- control: Control
- index: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctSetCurSel 0;
```
