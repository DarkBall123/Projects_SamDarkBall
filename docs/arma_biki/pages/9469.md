## enableEngineArtillery

- Source: https://community.bistudio.com/wiki/enableEngineArtillery
- Revision: 310205
- Updated: 2022-05-05T13:10:41Z

- Availability: arma2oa 1.54, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Artillery

### Description

Enable/disable the artillery engine. This allows the user to use the artillery computer on mortar/artillery, and for AI to use it for indirect fire.

### Syntax

```sqf
enableEngineArtillery enabled
```

### Parameters

- enabled: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableEngineArtillery false;
```
