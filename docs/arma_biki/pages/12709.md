## canAddItemToVest

- Source: https://community.bistudio.com/wiki/canAddItemToVest
- Revision: 369122
- Updated: 2024-09-03T10:33:08Z

- Availability: arma3 1.04
- Groups: Unit Inventory

### Description

Checks if given object can be stored into soldier's vest.

Avoid passing an empty string 

```sqf
""
```

 to this command as it will create a warning dialog:
none|alt= Warning Message: Bad vehicle type|Warning Message: Bad vehicle type
This message will show once per mission restart.

### Syntax

```sqf
unit canAddItemToVest item
```

```sqf
unit canAddItemToVest [item, count, ignoreSoldierMaxLoad]
```

### Parameters

- unit: Object
- item: String
- unit: Object
- item: String
- count: Number
- ignoreSoldierMaxLoad: Boolean - (Optional, default true) true to ignore 'soldierMaxLoad' param, container maxLoad is still counted.

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
_item = "HandGrenade";
private _fits = player canAddItemToVest _item;
if (_fits) then {
	player addItemToVest _item;
} else {
	hint "no room!";
};
```
