## BIS fnc tridentGetRelationship

- Source: https://community.bistudio.com/wiki/BIS_fnc_tridentGetRelationship
- Revision: 349070
- Updated: 2023-11-08T14:47:22Z

- Availability: arma3 1.00
- Groups: Sides

### Description

Gets the relationship of competing Trident sides. The value slowly decreases towards 0.

### Syntax

```sqf
[sideA, sideB] call BIS_fnc_tridentGetRelationship
```

### Parameters

- sideA: Side
- sideB: Side

### Return Value

- Number - relationship value

### Examples

#### Example 1

```sqf
[west, east] call BIS_fnc_tridentGetRelationship;
```
