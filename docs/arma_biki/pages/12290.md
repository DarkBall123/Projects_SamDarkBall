## saveJoysticks

- Source: https://community.bistudio.com/wiki/saveJoysticks
- Revision: 319552
- Updated: 2022-05-13T09:24:28Z

- Availability: arma3 0.50
- Groups: System

### Description

Saves joysticks key mappings into the joysticks.cfg file. Engine add these joysticks to the Joystick Scheme mapping dialog in options controls section.

### Syntax

```sqf
saveJoysticks
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
saveJoysticks;
```
