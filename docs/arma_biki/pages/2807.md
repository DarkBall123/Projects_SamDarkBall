## controlNull

- Source: https://community.bistudio.com/wiki/controlNull
- Revision: 369405
- Updated: 2024-09-03T18:43:23Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

A non-existing Control. To compare non-existent objects use isNull or isEqualTo (see examples).

### Syntax

```sqf
controlNull
```


### Return Value

- Control

### Examples

#### Example 1

```sqf
if (_myCtrl isEqualTo controlNull) then { hint "_myCtrl is null!"; };
```

#### Example 2

```sqf
controlNull == controlNull;			// returns false
isNull controlNull;						// returns true
controlNull isEqualTo controlNull;		// returns true
```

#### Example 3

```sqf
str controlNull; // No control
```
