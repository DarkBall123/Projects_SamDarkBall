## infoPanels

- Source: https://community.bistudio.com/wiki/infoPanels
- Revision: 378367
- Updated: 2026-04-03T16:46:20Z

- Availability: arma3 1.72
- Groups: Custom Panels

### Description

Returns array all info panels configured for given object or object and turret path.

### Syntax

```sqf
infoPanels unit
```

```sqf
infoPanels [unit, turretPath]
```

### Parameters

- unit: Object - the concerned vehicle
- unit: Object - the concerned vehicle
- turretPath: Turret Path - turret index

### Return Value

- Array - format [<nowiki/>[infoPanelId1, infoPanelShortcutId1], [infoPanelId2, infoPanelShortcutId2], ...]:
* infoPanelId: String - name of the info panel class as defined in vehicle config
* infopanelShortcutId: String - shortcut representation of *infopanelId*, currently are supported only shortcuts "left" and "right"
- Array - format [<nowiki/>[infoPanelId1, infoPanelShortcutId1], [infoPanelId2, infoPanelShortcutId2], ...]:
* infoPanelId: String - name of the info panel class as defined in vehicle config
* infopanelShortcutId: String - shortcut representation of *infopanelId*, currently are supported only shortcuts "left" and "right"

### Examples

#### Example 1

```sqf
infoPanels [vehicle player, [0]];
```
