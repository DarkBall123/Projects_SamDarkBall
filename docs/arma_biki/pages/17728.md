## current3DENOperation

- Source: https://community.bistudio.com/wiki/current3DENOperation
- Revision: 348917
- Updated: 2023-11-08T14:44:04Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns the currently performed editing operation in Eden Editor.

### Syntax

```sqf
current3DENOperation
```


### Return Value

- String - operation name. Can be:
{{Columns|2|
* `""` (no operation)
* `"CreateObject"`
* `"CreateMarker"`
* `"CreateTrigger"`
* `"MoveItems"`
* `"RotateItems"`
* `"ScaleItems"`
* `"SyncWith"`
* `"GroupWith"`
* `"SetTriggerOwner"`
* `"AddRandomStart"`
}}

### Examples

#### Example 1

```sqf
if (current3DENOperation == "MoveItems") then { hint "Moving things are we"; };
```
