## configSourceModList

- Source: https://community.bistudio.com/wiki/configSourceModList
- Revision: 369411
- Updated: 2024-09-03T18:43:26Z

- Availability: arma3 1.40
- Groups: Mods and Addons

### Description

Returns an array of mods (CfgMods) in which the given config class is defined.

### Syntax

```sqf
configSourceModList config
```

### Parameters

- config: Config

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
_mods = configSourceModList (configFile >> "CfgVehicles" >> "Man");
hint str _mods; // ["A3","curator","heli"]
```
