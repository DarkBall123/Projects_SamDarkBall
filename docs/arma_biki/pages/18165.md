## tvSetPictureColorSelected

- Source: https://community.bistudio.com/wiki/tvSetPictureColorSelected
- Revision: 377366
- Updated: 2026-01-02T06:40:38Z

- Availability: arma3 1.62
- Groups: GUI Control - Tree View

### Description

Sets the color of the left picture of a tree item defined by path when item is selected

### Syntax

```sqf
control tvSetPictureColorSelected [path, color]
```

### Parameters

- control: Control
- path: Array of Numbers - path to tree view item
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control tvSetPictureColorSelected [[0], [1,0,1,1]];
```
