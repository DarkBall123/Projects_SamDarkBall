## addItemPool

- Source: https://community.bistudio.com/wiki/addItemPool
- Revision: 318565
- Updated: 2022-05-13T09:21:06Z

- Availability: arma3 1.04
- Groups: Weapon Pool

### Description

Adds count items of type name into the weapon pool (used in the campaign to transfer items to the next mission)

### Syntax

```sqf
addItemPool [itemName, count]
```

### Parameters

- itemName: String - item name
- count: Number - number of items to add

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
addItemPool ["ItemGPS", 5];
```
