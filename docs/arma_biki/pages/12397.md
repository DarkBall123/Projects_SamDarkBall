## lbSetTooltip

- Source: https://community.bistudio.com/wiki/lbSetTooltip
- Revision: 364888
- Updated: 2024-06-29T14:38:30Z

- Availability: arma3 0.58
- Groups: GUI Control - ListBox

### Description

Sets tooltip for item with given index of the listbox or combobox with id idc of the topmost user dialog to the given data.

### Syntax

```sqf
lbSetTooltip [idc, index, tooltip]
```

```sqf
control lbSetTooltip [index, tooltip]
```

### Parameters

- idc: Number
- index: Number
- tooltip: String
- control: Control
- index: Number
- tooltip: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lbSetTooltip [101, 1, "tooltip"];
```

#### Example 2

```sqf
_control lbSetTooltip [0, "another tooltip"];
```
