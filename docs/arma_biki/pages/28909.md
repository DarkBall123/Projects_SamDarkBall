<onlyinclude>
Order of operations, also called operator precedence, is a set of rules specifying which procedures should be performed first in a mathematical expression.

#### Precedence Overview

{{Feature | Informative |
- Highest precedence means highest priority
- Associativity is (then) done from left to right, for example

```sqf
3 + 5 + 8
```

 will be processed as

```sqf
((3 + 5) + 8)
```

#### Examples

```mediawiki-table
{| class="wikitable"
! Input
! Process
! Comment
|-
|

```sqf
1 + 2 * 3
```

|

```sqf
1 + (2 * 3)
```

| result equals 7, and not 9 (see also [PEMDAS](https://en.wikipedia.org/wiki/Order_of_operations))
|-
|

```sqf
sleep 10 + random 20
```

|

```sqf
(sleep 10) + random 20
```

|

```sqf
sleep 10
```

 will return Nothing, then

```sqf
+ random 20
```

 will be calculated but not used.

```sqf
sleep (10 + random 20)
```

 should be used instead
