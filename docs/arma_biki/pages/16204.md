## BIS fnc baseWeapon

- Source: https://community.bistudio.com/wiki/BIS_fnc_baseWeapon
- Revision: 349362
- Updated: 2023-11-08T15:35:11Z

- Availability: arma3 1.00
- Groups: Weapons

### Description

Determines base weapon class, with no attachments.

### Syntax

```sqf
[weaponName] call BIS_fnc_baseWeapon
```

### Parameters

- weaponName: String - weapon classname.

### Return Value

- String - weapon classname that features no attachments.

### Examples

#### Example 1

```sqf
["arifle_Mk20_MRCO_pointer_F"] call BIS_fnc_baseWeapon; // Returns "arifle_Mk20_F"
```
