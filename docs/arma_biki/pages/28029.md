## leaderboardRequestRowsGlobal

- Source: https://community.bistudio.com/wiki/leaderboardRequestRowsGlobal
- Revision: 349053
- Updated: 2023-11-08T14:47:19Z

- Availability: arma3 1.56
- Groups: Leaderboards

### Description

Requests given leaderboard to download values from global table.

### Syntax

```sqf
leaderboardRequestRowsGlobal [leaderboard, offset, rows]
```

### Parameters

- leaderboard: String - name of the leaderboard
- offset: Number - defines how many rows are skipped
- rows: Number - defines how many rows are requested

### Return Value

- Boolean - returns true if request has been started

### Examples

#### Example 1

```sqf
_isGettingValues = leaderboardRequestRowsGlobal ["TT01", 0, 10];
```
