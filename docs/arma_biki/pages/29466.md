## getCruiseControl

- Source: https://community.bistudio.com/wiki/getCruiseControl
- Revision: 377878
- Updated: 2026-01-04T15:56:01Z

- Availability: arma3 2.06
- Locality: argument local, effect local
- Groups: Unit Control, Object Manipulation

### Description

Returns cruise control settings set with setCruiseControl command.

### Syntax

```sqf
getCruiseControl vehicle
```

### Parameters

- vehicle: Object - the vehicle

### Return Value

- Array with [speedLimit, cruiseControlActive]
* speedLimit: Number - defined speed limit
* cruiseControlActive: Boolean - true if cruise control is enabled, false if only speed was limited

### Examples

#### Example 1

```sqf
getCruiseControl vehicle player params ["_speedLimit", "_cruiseControlActive"];
```
