## attachedObject

- Source: https://community.bistudio.com/wiki/attachedObject
- Revision: 318758
- Updated: 2022-05-13T09:21:27Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns the object a location is attached to. If the location is unattached, then objNull is returned.

### Syntax

```sqf
attachedObject location
```

### Parameters

- location: Location

### Return Value

- Object

### Examples

#### Example 1

```sqf
_locAttachedObj = attachedObject myLocation;
```
