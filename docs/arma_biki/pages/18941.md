## BIS fnc 3DENExportAttributes

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENExportAttributes
- Revision: 364854
- Updated: 2024-06-25T09:14:18Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Copies all available attributes to the clipboard.

### Syntax

```sqf
class call BIS_fnc_3DENExportAttributes
```
