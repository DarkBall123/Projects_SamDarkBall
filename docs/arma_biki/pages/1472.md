## inflamed

- Source: https://community.bistudio.com/wiki/inflamed
- Revision: 310855
- Updated: 2022-05-07T20:24:08Z

- Availability: ofp 1.04, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Checks if fireplace is inflamed (burning) or not. To check if a unit is receiving damage from fire, use isBurning command.

### Syntax

```sqf
inflamed fireplace
```

### Parameters

- fireplace: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_inflamed = inflamed _fireplaceOne;
```
