## getUnloadInCombat

- Source: https://community.bistudio.com/wiki/getUnloadInCombat
- Revision: 377617
- Updated: 2026-01-02T08:51:47Z

- Availability: arma3 2.12
- Groups: Object Manipulation

### Description

A getter for setUnloadInCombat. To return global config value see canUnloadInCombat

### Syntax

```sqf
getUnloadInCombat vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array with [cargo, turrets]

### Examples

#### Example 1

```sqf
getUnloadInCombat _vehicle params ["_cargo", "_turrets"];
```
