## BIS fnc respawnGroup

- Source: https://community.bistudio.com/wiki/BIS_fnc_respawnGroup
- Revision: 328614
- Updated: 2022-07-13T17:04:09Z

- Availability: arma3 1.00
- Groups: Respawn

### Description

Camera script used by the "group respawn" template - when the player dies and gets transferred to the new group member.

### Syntax

```sqf
[oldUnit, newUnit] call BIS_fnc_respawnGroup
```

### Parameters

- oldUnit: Object
- newUnit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
// in onPlayerRespawn.sqf
params ["_newUnit", "_oldUnit", "_respawn", "_respawnDelay"];
[_oldUnit, _newUnit] spawn BIS_fnc_respawnGroup;
```
