## registerTask

- Source: https://community.bistudio.com/wiki/registerTask
- Revision: 319377
- Updated: 2022-05-13T09:23:58Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing, Teams

### Description

Registers a new task type. Parameters are defined in the given config class (subclass of `CfgTasks`)

### Syntax

```sqf
teamMember registerTask entryName
```

### Parameters

- teamMember: Team Member - teamMember agent
- entryName: String - `CfgTasks` classname

### Return Value

- Boolean - true on success

### Examples

#### Example 1

```sqf
teamMember _agent registerTask "MyTask";
```
