borderless|60px|right|link=Global Mobilization
Find below an overview of the classnames for available vehicles in Arma 3 Creator DLC: Global Mobilization - Cold War Germany.

### Explanation
The listed class name in **bold** is already enough to create the vehicle via scripting. If you wish to create a vehicle with a specific color scheme through script, add the suffix to the classname as listed in the Additional Color Variants list.

Example:

To spawn a default green SPW-40P via script, use this classname:
 gm_gc_army_brdm2

To spawn a SPW-40P with winter camo paint applied:

 gm_gc_army_brdm2**_win**

Naming of classes follows a very strict structure. Nationality of an asset is indicated by using the [two-Letter NATO County Code](https://en.wikipedia.org/wiki/List_of_NATO_country_codes).
```mediawiki-table
{| class="wikitable"
|-
! Suffix
! Meaning
|-
| _gc
| image:gm_nation_gc2.png East Germany
|-
|_ge
| image:gm_nation_ge2.png West Germany
|-
|_dk
| image:gm_nation_dk2.png Denmark
|-
|_pl
| image:gm_nation_pl.png Poland
|}
```

National Organizations that the vehicle/asset belongs to is indicated by the following suffixes:
```mediawiki-table
{| class="wikitable"
|-
! Suffix
! Meaning
|-
| _army
| Army
|-
|_bgs
| Borderguards
|-
|_pol
| Police Authority
|-
|_civ
| Civilian
|}
```

```mediawiki-table
|-
|_inv
| Invasion Stripes

| Woodland / 3-Color pattern
|-
|_win
| Winter Camo Pattern

|-
|_trp
| Tropical Camo Pattern
|-
|_wiw
| Winter Camo Pattern (Alternative Variant)
|-
|_rc
| Red Diamond (Medical vehicle, suffix applied additionally to color paint)
|}
```
