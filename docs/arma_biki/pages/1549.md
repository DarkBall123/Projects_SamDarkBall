## moveInGunner

- Source: https://community.bistudio.com/wiki/moveInGunner
- Revision: 378020
- Updated: 2026-01-22T17:04:27Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Control

### Description

Move the unit into vehicle gunner position (immediate, no animation).
See AI Group Vehicle Management for more information.
If the unit is already in a vehicle, nothing will happen.
You should use moveOut to move the unit out of his vehicle before trying to move him into a new (or same) vehicle.

### Syntax

```sqf
unitName moveInGunner vehicle
```

### Parameters

- unitName: Object
- vehicle: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
soldierOne moveInGunner tankOne;
```
