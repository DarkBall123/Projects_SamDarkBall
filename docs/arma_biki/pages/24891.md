## BIS fnc controlPoint isArrive

- Source: https://community.bistudio.com/wiki/BIS_fnc_controlPoint_isArrive
- Revision: 349268
- Updated: 2023-11-08T14:51:09Z

- Availability: arma3 1.78
- Groups: ControlPoint

### Description

Whether given control point is arrive, not leave.

### Syntax

```sqf
[controlPoint] call BIS_fnc_controlPoint_isArrive
```

### Parameters

- controlPoint: Object - the control point

### Return Value

- Boolean - returns true if control point is arrive, false if leave

### Examples

#### Example 1

```sqf
private _isArrive = [controlPoint] call BIS_fnc_controlPoint_isArrive;
```
