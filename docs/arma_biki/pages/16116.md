## BIS fnc ORBATRemoveGroupOverlay

- Source: https://community.bistudio.com/wiki/BIS_fnc_ORBATRemoveGroupOverlay
- Revision: 378104
- Updated: 2026-02-14T10:39:28Z

- Availability: arma3 1.00
- Groups: Strategic

### Description

Unregister texture(s) to be displayed over CfgORBAT group.

### Syntax

```sqf
[path, displayID] call BIS_fnc_ORBATRemoveGroupOverlay
```

### Parameters

- path: Config - path to `CfgORBAT` group config
- displayID: Number - overlay ID returned by BIS_fnc_ORBATAddGroupOverlay

### Return Value

- Boolean - true if overlay entry was removed

### Examples

#### Example 1

```sqf
[configFile >> "CfgORBAT" >> "BIS" >> "O_Brigade", 4] call BIS_fnc_ORBATRemoveGroupOverlay;
```
