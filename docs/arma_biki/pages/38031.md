## ignore3DENHistory

- Source: https://community.bistudio.com/wiki/ignore3DENHistory
- Revision: 370529
- Updated: 2025-01-02T11:51:16Z

- Availability: arma3 2.18
- Groups: Eden Editor

### Description

Ignores all history steps created by executing the given code.

### Syntax

```sqf
ignore3DENHistory code
```

### Parameters

- code: Code

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
ignore3DENHistory {
	create3DENEntity ["Object", "B_Soldier_F", screenToWorld [0.5, 0.5]]; // no Ctrl+Z available for this operation
};
```
