## enableMimics

- Source: https://community.bistudio.com/wiki/enableMimics
- Revision: 310253
- Updated: 2022-05-05T13:11:11Z

- Availability: arma3 1.22
- Groups: Object Manipulation

### Description

Enables/disables mimics on a given unit.

### Syntax

```sqf
unit enableMimics enabled
```

### Parameters

- unit: Object
- enabled: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
cursorTarget enableMimics false;
```
