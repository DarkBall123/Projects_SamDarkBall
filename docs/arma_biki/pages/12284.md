## getPosASLW

- Source: https://community.bistudio.com/wiki/getPosASLW
- Revision: 377793
- Updated: 2026-01-03T01:42:08Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Positions

### Description

Returns the object position height above water surface (waves and pond objects included).

### Syntax

```sqf
getPosASLW obj
```

### Parameters

- obj: Object

### Return Value

- PositionASLW

### Examples

#### Example 1

```sqf
_pos = getPosASLW _diver;
```
