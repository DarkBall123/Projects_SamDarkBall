## tvValue

- Source: https://community.bistudio.com/wiki/tvValue
- Revision: 347317
- Updated: 2023-09-10T15:24:11Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Returns numeric value set for given tree view path.

### Syntax

```sqf
tvValue [idc, path]
```

```sqf
ctrl tvValue path
```

### Parameters

- idc: Number
- path: Array of Numbers
- ctrl: Control
- path: Array of Numbers

### Return Value

- Number - set value; if no value was set, 0 is returned
- Number - set value; if no value was set, 0 is returned

### Examples

#### Example 1

```sqf
tvValue [101, [0]];
```

#### Example 2

```sqf
_ctrl tvValue [0,0,0];
```
