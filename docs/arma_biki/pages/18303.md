## menuText

- Source: https://community.bistudio.com/wiki/menuText
- Revision: 378349
- Updated: 2026-04-02T16:31:38Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns current text set in menu entry on given path.

### Syntax

```sqf
menuText [idc, path]
```

```sqf
control menuText path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
_ctrlMenuStrip menuText [1];
```
