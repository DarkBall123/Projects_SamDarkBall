## lnbSize

- Source: https://community.bistudio.com/wiki/lnbSize
- Revision: 377872
- Updated: 2026-01-04T11:45:13Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Returns size of CT_LISTNBOX. This command supports CT_TOOLBOX control since Arma 3 v2.06. For CT_COMBO or CT_LISTBOX see lbSize.

### Syntax

```sqf
lnbSize controlOrIDC
```

### Parameters

- controlOrIDC: Control or Number - control or control's IDC

### Return Value

- Array - in format [rows, columns]
* rows: Number - Number of rows
* columns: Number - Number of columns

### Examples

#### Example 1

```sqf
lnbSize _control;
```

#### Example 2

```sqf
lnbSize _someIDC;
```
