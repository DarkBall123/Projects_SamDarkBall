## copyWaypoints

- Source: https://community.bistudio.com/wiki/copyWaypoints
- Revision: 320957
- Updated: 2022-05-13T10:04:50Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Copy the chain of waypoints from source to target group. The target group will start to process waypoints from the first one.

### Syntax

```sqf
groupTo copyWaypoints groupFrom
```

### Parameters

- groupTo: Group
- groupFrom: Group

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
group1 copyWaypoints group2;
```
