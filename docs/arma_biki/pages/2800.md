### Description

The ceil value of x.

### Syntax

```sqf
ceil  x
```

### Parameters

- x: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
ceil 5.25; // Result is 6
```

#### Example 2

```sqf
ceil -5.25; // Result is -5
```
