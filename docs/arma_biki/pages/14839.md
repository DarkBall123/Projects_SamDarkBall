## curatorPoints

- Source: https://community.bistudio.com/wiki/curatorPoints
- Revision: 376976
- Updated: 2026-01-01T06:06:14Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns number of points that curator have.

### Syntax

```sqf
curatorPoints curatorObj
```

### Parameters

- curatorObj: Object - curator module.

### Return Value

- Number in range 0..1

### Examples

#### Example 1

```sqf
_points = curatorPoints myCurator;
```
