## BIS fnc timeline getPlayFromStart

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_getPlayFromStart
- Revision: 349057
- Updated: 2023-11-08T14:47:19Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Whether timeline is flagged as play from start on scenario begin.

### Syntax

```sqf
[timeline] call BIS_fnc_timeline_getPlayFromStart
```

### Parameters

- timeline: Object - the timeline object

### Return Value

- Boolean - returns true if timeline should play from start, otherwise false

### Examples

#### Example 1

```sqf
private _playFromStart = [timeline] call BIS_fnc_timeline_getPlayFromStart;
```
