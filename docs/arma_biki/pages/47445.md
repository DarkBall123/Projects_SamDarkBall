## childAttached

- Source: https://community.bistudio.com/wiki/childAttached
- Revision: 378906
- Updated: 2026-08-11T14:57:07Z

- Availability: arma3 2.22
- Locality: argument local
- Groups: PhysX

### Description

Get the child that has been attached via attachChild

### Syntax

```sqf
childAttached parent
```

### Parameters

- parent: Object -  Must be a Transport vehicle like Car/Tank (Maybe helicopter/airplane works?).

### Return Value

- Object
### See Also
