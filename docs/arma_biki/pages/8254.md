## faction

- Source: https://community.bistudio.com/wiki/faction
- Revision: 370764
- Updated: 2025-02-10T08:05:51Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation, Sides

### Description

Gets unit faction. Factions were introduced in {{arma2}} and are defined under *CfgFactionClasses*.

### Syntax

```sqf

```

### Parameters

- unitName: Object

### Return Value

- String

### Examples

#### Example 1

```sqf

```
