## addCuratorAddons

- Source: https://community.bistudio.com/wiki/addCuratorAddons
- Revision: 378390
- Updated: 2026-04-04T07:50:38Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Allow curator use of given addon.

### Multiplayer

Can be executed only on server

### Syntax

```sqf
curatorObj addCuratorAddons addons
```

### Parameters

- curatorObj: Object - curator module.
- addons: Array of Strings - CfgPatches class names

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
curatorObj addCuratorAddons ["A3_Armor_F_AMV","A3_Armor_F_Panther"];
```

#### Example 2

```sqf
curatorObj addCuratorAddons ["A3_Modules_F_Curator_Lightning"];
```

#### Example 3

Addons can be stacked:

```sqf
curatorObj addCuratorAddons ["A3_Armor_F_AMV","A3_Armor_F_Panther"];
curatorObj addCuratorAddons ["A3_Modules_F_Curator_Lightning"];
diag_log curatorAddons curatorObj;
```

```sqf
[
	"A3_Armor_F_AMV",

```
