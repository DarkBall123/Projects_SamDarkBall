## customWaypointPosition

- Source: https://community.bistudio.com/wiki/customWaypointPosition
- Revision: 377508
- Updated: 2026-01-02T06:50:11Z

- Availability: arma3 1.92
- Groups: Waypoints

### Description

Returns player's custom waypoint ({{Controls|LShift|LMB}}) position.

### Syntax

```sqf
customWaypointPosition
```


### Return Value

- Position as [x,y,0], or empty array [] if the waypoint does not exist

### Examples

#### Example 1

```sqf
if (customWaypointPosition isNotEqualTo []) then
{
	hint format ["You are %1m away from your custom waypoint.", round (player distance customWaypointPosition)];
};
```
