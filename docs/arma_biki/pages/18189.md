## waypointForceBehaviour

- Source: https://community.bistudio.com/wiki/waypointForceBehaviour
- Revision: 377583
- Updated: 2026-01-02T06:56:41Z

- Availability: arma3 1.58
- Groups: Waypoints

### Description

Returns true if the waypoint behavior is forced.

### Syntax

```sqf
waypointForceBehaviour waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- Boolean - is forced

### Examples

#### Example 1

```sqf
_isForced = waypointForceBehaviour [groupOne, 1];
```
