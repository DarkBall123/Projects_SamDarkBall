## clearItemPool

- Source: https://community.bistudio.com/wiki/clearItemPool
- Revision: 309902
- Updated: 2022-05-05T12:16:48Z

- Availability: arma3 1.00
- Groups: Weapon Pool

### Description

Removes all items from ammo box (or any general weapon holder container)

### Syntax

```sqf
clearItemPool box
```

### Parameters

- box: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
clearItemPool jeepOne;
```
