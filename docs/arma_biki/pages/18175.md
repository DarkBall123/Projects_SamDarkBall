## getAllOwnedMines

- Source: https://community.bistudio.com/wiki/getAllOwnedMines
- Revision: 347576
- Updated: 2023-09-28T10:10:09Z

- Availability: arma3 1.62
- Groups: Mines

### Description

Gets all mine objects this unit has ownership over.

### Syntax

```sqf
getAllOwnedMines unit
```

### Parameters

- unit: Object

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_mines = getAllOwnedMines player;
```
