## lockedTurret

- Source: https://community.bistudio.com/wiki/lockedTurret
- Revision: 377494
- Updated: 2026-01-02T06:49:19Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Turrets

### Description

Check whether gunner position of the vehicle turret is locked.

### Syntax

```sqf
vehicle lockedTurret turretPath
```

### Parameters

- vehicle: Object
- turretPath: Turret Path

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_locked = tank lockedTurret [0];
```
