## lbData

- Source: https://community.bistudio.com/wiki/lbData
- Revision: 364197
- Updated: 2024-05-05T10:46:54Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListBox

### Description

Returns the data set in given index of the CT_LISTBOX or CT_COMBO.

### Syntax

```sqf
lbData [idc, index]
```

```sqf
control lbData  index
```

### Parameters

- idc: Number - control's IDC
- index: Number
- control: Control
- index: Number

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
_data = lbData [101, 0];
```

#### Example 2

```sqf
_data = _control lbData 0;
```
