## lnbSetCurSelRow

- Source: https://community.bistudio.com/wiki/lnbSetCurSelRow
- Revision: 369217
- Updated: 2024-09-03T10:34:53Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Selects the row with the given index of the 2D listbox.

### Syntax

```sqf
lnbSetCurSelRow [idc, index]
```

```sqf
ctrl lnbSetCurSelRow index
```

### Parameters

- idc: Number
- index: Number
- ctrl: Control
- index: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
disableSerialization;
_ctrl = (findDisplay 300) displayCtrl 304;
_ctrl lnbSetCurSelRow 1;
```
