## taskResult

- Source: https://community.bistudio.com/wiki/taskResult
- Revision: 319905
- Updated: 2022-05-13T09:25:42Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Send a result of the task to the task sender.

### Syntax

```sqf
taskResult task
```

### Parameters

- task: Task

### Return Value

- Array - format [state, result] (see setTaskResult)

### Examples

#### Example 1

```sqf
taskResult (player createSimpleTask ["NewTask"]);
```
