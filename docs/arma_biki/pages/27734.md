## isSensorTargetConfirmed

- Source: https://community.bistudio.com/wiki/isSensorTargetConfirmed
- Revision: 310733
- Updated: 2022-05-07T20:04:52Z

- Availability: arma3 1.72
- Groups: Sensors

### Description

Returns if given unit is confirmed target for given side.

### Syntax

```sqf
unit isSensorTargetConfirmed side
```

### Parameters

- unit: Object
- side: Side

### Return Value

- Boolean - true if confirmed target, otherwise false

### Examples

#### Example 1

```sqf
private _enemyConfirmed = _possibleEnemy isSensorTargetConfirmed opfor;
```
