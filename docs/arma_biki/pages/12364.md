## BIS fnc showNotification

- Source: https://community.bistudio.com/wiki/BIS_fnc_showNotification
- Revision: 351692
- Updated: 2023-12-26T15:55:29Z

- Availability: arma3 0.50
- Locality: effect local
- Groups: GUI

### Description

Show a config-defined notification.

### Syntax

```sqf
[template, arguments] call BIS_fnc_showNotification
```

### Parameters

- **template**: String - notification class name from CfgNotifications
- **arguments**: Array - (Optional, default 

```sqf
[]
```

) additional format arguments to fill notification's fields (`title`, `description`, `iconPicture`, `iconText`, `soundRadio`)

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
["TaskSucceeded", ["", "Disable the nuke"]] call BIS_fnc_showNotification;
```

#### Example 2

```sqf
["ScoreAdded", ["Disabled the nuke without triggering an alarm.", 5]] call BIS_fnc_showNotification;
```
