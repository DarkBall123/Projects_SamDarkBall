## BIS fnc reviveEhKilled

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveEhKilled
- Revision: 328476
- Updated: 2022-07-13T16:11:11Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Should be called from Killed event handler. Handles what happens if unit dies if revive system is enabled.

### Syntax


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
BIS_unit addEventHandler ["Killed", 
{
 _this call BIS_fnc_reviveEhKilled;
}];
```
