## BIS fnc invString

- Source: https://community.bistudio.com/wiki/BIS_fnc_invString
- Revision: 349394
- Updated: 2023-11-08T16:27:25Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Inventory

### Description

Returns inventory contents of given vehicle (unit).
	
	Note: for vehicles it returns mounted gun and its ammo, not cargo weapons and ammo.

### Syntax

```sqf
[object] call BIS_fnc_invString
```

### Parameters

- object: Object

### Return Value

- Array - weapons and magazines

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_invString;
```
