## setPlayerVoNVolume

- Source: https://community.bistudio.com/wiki/setPlayerVoNVolume
- Revision: 309265
- Updated: 2022-05-04T11:09:04Z

- Availability: arma3 2.00
- Locality: argument global, effect local
- Groups: Radio and Chat

### Description

Sets provided player's Voice over Network (VoN) volume.

### Syntax

```sqf
unit setPlayerVoNVolume volume
```

### Parameters

- unit: Object - the other player's unit
- volume: Number - the wanted volume

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_loudPlayer setPlayerVoNVolume 0.5;
```
