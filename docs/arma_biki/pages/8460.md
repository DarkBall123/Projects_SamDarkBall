## synchronizeObjectsRemove

- Source: https://community.bistudio.com/wiki/synchronizeObjectsRemove
- Revision: 377072
- Updated: 2026-01-01T09:31:25Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Removes given objects from the unit's list of synchronized objects.

### Syntax

```sqf
unit synchronizeObjectsRemove objects
```

### Parameters

- unit: Object
- objects: Array of Objects

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player synchronizeObjectsRemove [_object1, _object2, _object3];
```
