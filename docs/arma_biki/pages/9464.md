## currentVisionMode

- Source: https://community.bistudio.com/wiki/currentVisionMode
- Revision: 378560
- Updated: 2026-05-08T13:11:39Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Weapons

### Description

Returns current vision mode of unit's weapon. Vision mode could be one of:
* 0 - normal vision
* 1 - night vision
* 2 - thermal vision
Alternative syntaxes additionally return FLIR index (see setCamUseTI) of the thermal vision mode (See also "VisionModeChanged" entity event handler)

### Syntax

```sqf
currentVisionMode entity
```

```sqf
currentVisionMode [entity]
```

```sqf
vehicle currentVisionMode turretPath
```

```sqf
unit currentVisionMode weapon
```

### Parameters

- entity: Object - unit or vehicle. Unit query returns current vision mode of the unit. Vehicle query returns driver seat vision mode
- entity: Object - unit or vehicle. Unit query returns current vision mode of the unit. Vehicle query returns driver seat vision mode
- vehicle: Object - vehicle with vision modes
- turretPath: Turret Path - path to vehicle's turret. Use [-1] for driver turret, [] for default primary gunner turret
- unit: Object - soldier
- weapon: String - unit's weapon. Use "" for current weapon

### Return Value

- Number - vision mode (**0** on error, e.g on objNull)
- Array format [visionMode, flirIndex] where:
* visionMode: Number
* flirIndex: Number
[-1, -1] on error
- Array format [visionMode, flirIndex] where:
* visionMode: Number
* flirIndex: Number
[-1, -1] on error
- Array format [visionMode, flirIndex] where:
* visionMode: Number
* flirIndex: Number
[-1, -1] on error

### Examples

#### Example 1

```sqf
_visionMode = currentVisionMode gunner _tank;
```

#### Example 2

```sqf
if (currentVisionMode player == 1) then
{
	hint "nightvision active";
};
```

#### Example 3

```sqf
private _detailedVisionMode = currentVisionMode [gunner _tank];
_detailedVisionMode params ["_mode", "_flirIndex"];
```

#### Example 4

```sqf
private _detailedGunnerVisionMode = _tank currentVisionMode [0];
```

#### Example 5

```sqf
private _detailedWeaponVisionMode = player currentVisionMode "";
```

The return value is somewhat erratic for UAVs. For example, if you are connected to a UAV, with the turret set to thermal vision and PIP feed enabled, 

```sqf
currentVisionMode gunner _uav
```

 returns 2 when controlling the turret, but returns 0 after releasing control, even thought the PIP feed is still in thermal mode. With nightvision, it will return 1 whether or not you are controlling the turret, but if you switch from 1st to 3rd person before releasing control, then it returns 0 afterwards...
