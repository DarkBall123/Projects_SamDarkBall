## isAllowedCrewInImmobile

- Source: https://community.bistudio.com/wiki/isAllowedCrewInImmobile
- Revision: 309127
- Updated: 2022-05-03T11:11:34Z

- Availability: arma3 2.08
- Locality: argument global
- Groups: Object Manipulation

### Description

Whether or not units can be in a vehicle with broken tracks/wheels.

### Syntax

```sqf
isAllowedCrewInImmobile vehicle
```

### Parameters

- vehicle: Object - transport

### Return Value

- Boolean - true - allowed, false - not allowed

### Examples

#### Example 1

```sqf
if !(isAllowedCrewInImmobile _tank) then
{
	_tank allowCrewInImmobile true;
};
```
