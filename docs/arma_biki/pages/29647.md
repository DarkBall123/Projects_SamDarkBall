## displayChild

- Source: https://community.bistudio.com/wiki/displayChild
- Revision: 310334
- Updated: 2022-05-05T16:57:20Z

- Availability: arma3 2.06
- Groups: GUI Control

### Description

Returns child display of the given display.

### Syntax

```sqf
displayChild display
```

### Parameters

- display: Display

### Return Value

- Display

### Examples

#### Example 1

```sqf
_display = displayChild findDisplay 313; // display #46
```
