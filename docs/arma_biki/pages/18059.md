## taskCustomData

- Source: https://community.bistudio.com/wiki/taskCustomData
- Revision: 376365
- Updated: 2025-10-07T21:46:44Z

- Availability: arma3 1.58
- Groups: Briefing

### Description

Returns custom data attached to the local task or an empty array if there are no custom data attached.

### Syntax

```sqf
taskCustomData task
```

### Parameters

- task: Task

### Return Value

- Array of string - iconPath, iconText, descriptionText

### Examples

#### Example 1

```sqf
_data = taskCustomData someTask;
```
