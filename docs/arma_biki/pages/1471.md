## inflame

- Source: https://community.bistudio.com/wiki/inflame
- Revision: 319281
- Updated: 2022-05-13T09:23:29Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Sets the state of a fireplace.

### Syntax

```sqf
fireplace inflame  burn
```

### Parameters

- fireplace: Object
- burn: Boolean - true to let it burn, false to extinguish it.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_fireplaceOne inflame true;
```
