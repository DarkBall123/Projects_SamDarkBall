## ctrlSetScale

- Source: https://community.bistudio.com/wiki/ctrlSetScale
- Revision: 369376
- Updated: 2024-09-03T18:43:13Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Positioning

### Description

Sets scale of a control. Top left corner remains same. This command requires ctrlCommit.

### Syntax

```sqf
control ctrlSetScale  scale
```

### Parameters

- control: Control
- scale: Number - scale e.g. 2 = 200% in size

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetScale 0.5;// Makes the control 50% smaller
_control ctrlCommit 0;
```
