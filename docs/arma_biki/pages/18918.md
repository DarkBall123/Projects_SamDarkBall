## BIS fnc dataTerminalAnimate

- Source: https://community.bistudio.com/wiki/BIS_fnc_dataTerminalAnimate
- Revision: 327212
- Updated: 2022-07-12T22:11:46Z

- Availability: arma3 1.42
- Groups: Scripts

### Description

Animate a Data Terminal ("Land_DataTerminal_01_F").

### Syntax

```sqf
[dataTerminal, step] call BIS_fnc_dataTerminalAnimate
```

### Parameters

- dataTerminal: Object
- step: Number - in range 0..3, steps being:
* 0: closed terminal
* 1: case opened
* 2: antenna up (but closed)
* 3: antenna opened and transmitting.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[myTerminal, 3] call BIS_fnc_dataTerminalAnimate;
```
