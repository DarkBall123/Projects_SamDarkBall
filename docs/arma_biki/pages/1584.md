## forceMap

- Source: https://community.bistudio.com/wiki/forceMap
- Revision: 363365
- Updated: 2024-03-27T23:45:43Z

- Availability: ofp 1.27, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Map, Interaction

### Description

Opens non-interactive main map in background that overrides user screen. To force open interactive map use openMap command.
When the map is forced open with this command, the user is still able to fire but cannot see the world, just the map.
The map cannot be closed manually and the user can get stuck requiring a game restart. Make sure you provide scripted mechanics to de-force the map at a later stage.

### Syntax

```sqf
forceMap show
```

### Parameters

- show: Boolean - true to force, false to go back to normal map behaviour

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
forceMap true;
```
