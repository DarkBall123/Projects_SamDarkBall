## BIS fnc HEXtoRGB

- Source: https://community.bistudio.com/wiki/BIS_fnc_HEXtoRGB
- Revision: 378164
- Updated: 2026-03-02T12:35:10Z

- Availability: arma3 1.00
- Groups: Math

### Description

Convert {{Color|red|R}}{{Color|green|G}}{{Color|blue|B}}{{Color|grey|A}} hexcode color into RGBA array format.

### Syntax

```sqf
[hexString] call BIS_fnc_HEXtoRGB
```

### Parameters

- hexString: String - string representing **4 bytes** of HEX color

### Return Value

- Array format Color (RGBA) - array of **4** numbers in range 0..1

### Examples

#### Example 1

```sqf
["025D00FF"] call BIS_fnc_HEXtoRGB; // [0.007843, 0.843138, 0, 1]
```

#### Example 2

Usually HEX code is represented as 3 bytes without alpha, so you can add it yourself:

```sqf
_hexstring = "025D00";
[_hexString + "FF"] call BIS_fnc_HEXtoRGB; // add alpha 4th byte
```
