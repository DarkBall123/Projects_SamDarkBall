## getWeaponCargo

- Source: https://community.bistudio.com/wiki/getWeaponCargo
- Revision: 319293
- Updated: 2022-05-13T09:23:30Z

- Availability: arma2oa 1.54, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Vehicle Inventory, Containers

### Description

Returns all weapons types and count from the cargo space

### Syntax

```sqf
getWeaponCargo object
```

### Parameters

- object: Object - object to check

### Return Value

- Array - format [all_types_array, all_counts_array]. Eg: [["a", "b"], [3, 2]]

### Examples

#### Example 1

```sqf
_content = getWeaponCargo carName;
```

#### Example 2

```sqf
_content = getWeaponCargo ammoBoxName;
```
