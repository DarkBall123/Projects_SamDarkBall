## BIS fnc removeNestedElement

- Source: https://community.bistudio.com/wiki/BIS_fnc_removeNestedElement
- Revision: 327527
- Updated: 2022-07-12T22:34:05Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays

### Description

Function to remove an item in a nested array. Modifies the array by reference.

### Syntax

```sqf
[array, itemToRemove] call BIS_fnc_removeNestedElement
```

### Parameters

- array: Array
- itemToRemove: Anything

### Return Value

- Boolean - true on success, false on failure

### Examples

#### Example 1

```sqf
private _array = [[1, 2], [3, 3, 4]];
private _success = [_array, 3] call BIS_fnc_removeNestedElement; // _array is now [[1, 2], [4]]
```
