## isIRLaserOn

- Source: https://community.bistudio.com/wiki/isIRLaserOn
- Revision: 310267
- Updated: 2022-05-05T13:11:19Z

- Availability: arma3 0.50
- Groups: Lights

### Description

Returns true if there is a linked and enabled IR on the given weapon.

### Syntax

```sqf
unit isIRLaserOn weapon
```

### Parameters

- unit: Object
- weapon: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
player isIRLaserOn currentWeapon player;
```
