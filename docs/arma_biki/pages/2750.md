## drawLine

- Source: https://community.bistudio.com/wiki/drawLine
- Revision: 377558
- Updated: 2026-01-02T06:55:00Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Map

### Description

Draw a line on the map. Can decrease framerate!

### Syntax

```sqf
map drawLine [from, to, color, width]
```

### Parameters

- map: Control
- from: Object or Position2D or Position3D
- to: Object or Position2D or Position3D
- color: Color (RGBA)
- width: Number - (Optional, default 3)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
(findDisplay 12 displayCtrl 51) ctrlAddEventHandler ["Draw",
	"(_this select 0) drawLine [
		player,
		[0,0,0],
		[0,0,1,1]
	];"
];
```

2.02 toString version:

```sqf
(findDisplay 12 displayCtrl 51) ctrlAddEventHandler ["Draw", toString {
	(_this select 0) drawLine [
		player,
		[0,0,0],
		[0,0,1,1] // blue
	];
}];
```
