## menuPicture

- Source: https://community.bistudio.com/wiki/menuPicture
- Revision: 378338
- Updated: 2026-04-02T16:31:12Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns picture set into item on given path.

### Syntax

```sqf
menuPicture [idc, path]
```

```sqf
control menuPicture path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
private _picturePath = (findDisplay 313 displayCtrl 120) menuPicture [0, 1];
```
