## openCuratorInterface

- Source: https://community.bistudio.com/wiki/openCuratorInterface
- Revision: 321434
- Updated: 2022-05-14T14:17:08Z

- Availability: arma3 1.16
- Locality: effect local
- Groups: Curator

### Description

Force opens curator interface.

### Syntax

```sqf
openCuratorInterface
```


### Return Value

- Nothing

### Examples

#### Example 1

Open interface:

```sqf
openCuratorInterface;
```

#### Example 2

Close interface:

```sqf
findDisplay 312 closeDisplay 2;
```

#### Example 3

Detect if user used "Zeus" key to open curator interface in the absence of event handler for it:

```sqf
findDisplay 46 displayAddEventHandler ["KeyDown", {
	if (inputAction "CuratorInterface" > 0) then
	{
		hint "Curator interface is open";
	};
	false
}];
```
