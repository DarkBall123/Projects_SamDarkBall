## BIS fnc taskCompleted

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskCompleted
- Revision: 352054
- Updated: 2024-02-01T23:24:34Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Checks if task is completed. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskID call BIS_fnc_taskCompleted
```

### Parameters

- taskID: String - ID or name of the task

### Return Value

- Boolean - returns true if task state is either "SUCCEEDED", "FAILED" or "CANCELED". Returns false for all other states and if task does not exist

### Examples

#### Example 1

```sqf
private _completed = "task_1" call BIS_fnc_taskCompleted;
```
