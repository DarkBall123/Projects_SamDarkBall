## progressPosition

- Source: https://community.bistudio.com/wiki/progressPosition
- Revision: 348954
- Updated: 2023-11-08T14:45:39Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns the current position in the progress bar.

### Syntax

```sqf
progressPosition control
```

### Parameters

- control:  Control - progress bar

### Return Value

- Number - progress from 0 to 1

### Examples

#### Example 1

```sqf
_progress = progressPosition _control;
```
