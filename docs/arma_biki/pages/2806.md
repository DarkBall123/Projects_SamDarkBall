## configName

- Source: https://community.bistudio.com/wiki/configName
- Revision: 339071
- Updated: 2023-04-26T10:53:59Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Config

### Description

Returns name of config entry.

### Syntax

```sqf
configName config
```

### Parameters

- config: Config

### Return Value

- String

### Examples

#### Example 1

```sqf
_name = configName (configFile >> "CfgVehicles"); // result is "CfgVehicles"
```
