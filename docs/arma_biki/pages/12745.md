## BIS fnc rscLayer

- Source: https://community.bistudio.com/wiki/BIS_fnc_rscLayer
- Revision: 348814
- Updated: 2023-11-08T14:38:17Z

- Availability: arma3 1.00
- Groups: GUI

### Description

Register RSC layer and returns a **unique** ID.

### Syntax

```sqf
[layerName] call BIS_fnc_rscLayer
```

### Parameters

- layerName: String - layer name. Parent function name is used automatically when param is nil.

### Return Value

- Number - layer ID

### Examples

#### Example 1

```sqf
private _id = ["myLayerName"] call BIS_fnc_rscLayer;
```
