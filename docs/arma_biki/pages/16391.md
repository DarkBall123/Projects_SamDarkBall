## BIS fnc curatorAutomatic

- Source: https://community.bistudio.com/wiki/BIS_fnc_curatorAutomatic
- Revision: 376126
- Updated: 2025-09-01T08:21:54Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Spawn units based on curator settings. Used when curator role is not taken.

### Syntax

```sqf
[curator, sides, cheatCoef, infantryProb, groundProb, airProb, marineProb] call BIS_fnc_curatorAutomatic
```

### Parameters

- curator: Object - curator module, costs and coefficients will be read from it
- sides: Array - array of sides of the placed entities
- cheatCoef: Number - cheat coefficient (1 means default costs, 0.5 means 50% values; allows spawning of more units)
- infantryProb: Number - infantry probability (probabilities are compared together, the ones with higher number have better chance of spawning)
- groundProb: Number - ground vehicle probability
- airProb: Number - aircraft probability
- marineProb: Number - marine probability

### Return Value

- Array of Groups

### Examples

#### Example 1

```sqf
[curator_module, [west, independent, 0.1, 40, 30, 20, 10] call BIS_fnc_curatorAutomatic;
```
