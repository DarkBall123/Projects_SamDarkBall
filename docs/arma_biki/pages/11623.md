## radioChannelSetCallSign

- Source: https://community.bistudio.com/wiki/radioChannelSetCallSign
- Revision: 378308
- Updated: 2026-04-01T22:46:59Z

- Availability: tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Radio and Chat, Custom Radio and Chat

### Description

Set the custom radio chat channel's callsign / VoN callsign.

### Syntax

```sqf
customChannelID radioChannelSetCallSign callSign
```

### Parameters

- customChannelID: Number - custom channel ID returned by radioChannelCreate command
- callSign: String or 2.22 Array - custom chat callsign or [callSign, callSignVoN]. Available parameters: 
{

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
4 radioChannelSetCallSign "(%UNIT_ID) %UNIT_RANK %UNIT_NAME%UNIT_GRP_LEADER"; // (1) Sgt Ben Kelly, group leader
```

#### Example 2

```sqf
4 radioChannelSetCallSign ["%UNIT_VEH_POSITION, %UNIT_VEH_NAME", "%UNIT_NAME%UNIT_GRP_LEADER"];
```
