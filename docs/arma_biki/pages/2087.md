## setWaypointTimeout

- Source: https://community.bistudio.com/wiki/setWaypointTimeout
- Revision: 377755
- Updated: 2026-01-03T00:58:12Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Defines the time between condition satisfaction and waypoint finish (randomly from min to max, with an average value mid).

### Syntax

```sqf
waypoint setWaypointTimeout [min, mid, max]
```

### Parameters

- waypoint: Waypoint
- min: Number
- mid: Number
- max: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointTimeout [5, 10, 6];
```
