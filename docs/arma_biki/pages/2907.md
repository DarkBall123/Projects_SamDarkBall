## ctrlScale

- Source: https://community.bistudio.com/wiki/ctrlScale
- Revision: 310878
- Updated: 2022-05-07T20:24:10Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Positioning

### Description

Returns the current scale of the control.

### Syntax

```sqf
ctrlScale control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_scale = ctrlScale _control;
```
