## lnbSetText

- Source: https://community.bistudio.com/wiki/lnbSetText
- Revision: 321488
- Updated: 2022-05-16T14:15:09Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Sets the text in the item with the given position of the 2D listbox.

### Syntax

```sqf
lnbSetText [idc, [row, column], data]
```

```sqf
ctrl lnbSetText [<nowiki/>[row, column], data]
```

### Parameters

- idc: Number
- row: Number
- column: Number
- data: String
- ctrl: Control
- row: Number
- column: Number
- data: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lnbSetText [101, [0,1], "#1"];
```

#### Example 2

```sqf
_ctrl lnbSetText [[0,1], "#1"];
```
