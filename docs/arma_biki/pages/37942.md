## angularVelocity

- Source: https://community.bistudio.com/wiki/angularVelocity
- Revision: 377246
- Updated: 2026-01-02T05:26:22Z

- Availability: arma3 2.18
- Locality: argument global
- Groups: Object Manipulation

### Description

Gets the angular velocity of the object in world space as a 3D vector. The units are in Rad/s (radians per second) and rotations are clockwise.

### Syntax

```sqf
angularVelocity obj
```

### Parameters

- obj: Object

### Return Value

- Vector3D - angular velocity of the object in world space ([0,0,0] if angular velocity is not supported by the object)

### Examples

#### Example 1

```sqf
angularVelocity myHeli; // [0.01, 0.03, 0.95]
```
