## getPilotCameraTarget

- Source: https://community.bistudio.com/wiki/getPilotCameraTarget
- Revision: 378360
- Updated: 2026-04-03T16:01:12Z

- Availability: arma3 1.64
- Locality: argument local
- Groups: Pilot Camera

### Description

Returns the target of the object airplane or helicopter pilotCamera tracking. Returns 

```sqf
[false, [0,0,0], objNull]
```

 if camera is not in a tracking mode or if object has no pilotCamera.

### Syntax

```sqf
getPilotCameraTarget object
```

### Parameters

- object: Object

### Return Value

- Array with [isTracking, targetPosition, targetObject]
* isTracking: Boolean - returns whether the camera is in a tracking mode 
* targetPosition: PositionASL - returns the position of the tracked area or object
* targetObject: Object - returns the tracked object, objNull if camera is only tracking an area

### Examples

#### Example 1

```sqf
getPilotCameraTarget vehicle player params ["_pilotCamTracking", "_pilotCamTargetPos", "_pilotCamTarget"];
```
