## items

- Source: https://community.bistudio.com/wiki/items
- Revision: 377151
- Updated: 2026-01-01T10:36:00Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns an array of names of all unit's stored items, including weapons but excluding magazines (see itemsWithMagazines) and assignedItems.

### Syntax

```sqf
items unit
```

### Parameters

- unit: Object

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
_itemsPlayer = items player;
```

#### Example 2

```sqf
player sideChat format ["%1", items player];
```
