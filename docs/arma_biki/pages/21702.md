## lbSetPictureRightColor

- Source: https://community.bistudio.com/wiki/lbSetPictureRightColor
- Revision: 377351
- Updated: 2026-01-02T06:40:13Z

{{RV|type=command

|game1= arma3
|version1= 1.22

|gr1= GUI Control - ListBox

|descr= Sets the color of the second (right aligned) picture of the given index of the listbox with id idc of the topmost user dialog to the given color.
Color which consists from only zeros means disable this override.

|s1= lbSetPictureRightColor [idc, index, color]

|p1= idc: Number - control id

|p2= index: Number

|p3= color: Color (RGBA)

|r1= Nothing

|s2= control lbSetPictureRightColor [index, color]

|p21= control: Control

|p22= index: Number

|p24= color: Color (RGBA)

|r2= Nothing

|x1=

```sqf
lbSetPictureRightColor [101, 0, [0, 1, 0, 0.5]];
```

|x2=

```sqf
_ctrl lbSetPictureRightColor [0, [1, 1, 1, 1]];
```
