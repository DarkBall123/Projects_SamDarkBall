## BIS fnc taskAlwaysVisible

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskAlwaysVisible
- Revision: 352047
- Updated: 2024-02-01T23:24:30Z

- Availability: arma3 1.00
- Locality: argument global
- Groups: Tasks

### Description

Returns true if task is forced to be always visible (default: false). See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskID call BIS_fnc_taskAlwaysVisible
```

### Parameters

- taskID: String - ID of the task

### Return Value

- Boolean - returns true if forced visible, otherwise false

### Examples

#### Example 1

```sqf
private _isForcedVisible = "task_1" call BIS_fnc_taskAlwaysVisible;
```
