## leader

- Source: https://community.bistudio.com/wiki/leader
- Revision: 319064
- Updated: 2022-05-13T09:23:07Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Groups

### Description

Returns the group leader for the given **unit** or **group**. For dead units, objNull is returned.

### Syntax

```sqf
leader  unitOrGroup
```

### Parameters

- unitOrGroup: Object or Group

### Return Value

- Object

### Examples

#### Example 1

```sqf
leader group player == leader player;
```

#### Example 2

```sqf
leader group vehicle player;
```

#### Example 3

```sqf
leader player;
```
