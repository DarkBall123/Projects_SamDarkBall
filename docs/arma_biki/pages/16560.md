## removeFromRemainsCollector

- Source: https://community.bistudio.com/wiki/removeFromRemainsCollector
- Revision: 377097
- Updated: 2026-01-01T09:56:53Z

- Availability: arma3 1.32
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Removes vehicles/units from the garbage collector, so they do not get deleted automatically; added earlier with addToRemainsCollector.

### Syntax

```sqf
removeFromRemainsCollector remains
```

### Parameters

- remains: Array of Objects

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeFromRemainsCollector [unit1, unit2, vehicle1];
```
