## BIS fnc camera getVisionMode

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_getVisionMode
- Revision: 378107
- Updated: 2026-02-15T11:03:14Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Returns camera vision mode.

### Syntax

```sqf
[camera] call BIS_fnc_camera_getVisionMode
```

### Parameters

- camera: Object - the camera

### Return Value

- Number - one of:
* 0 - normal vision
* 1 - night vision
* 2 - thermal imaging

### Examples

#### Example 1

```sqf
[BIS_camera] call BIS_fnc_camera_getVisionMode;
```
