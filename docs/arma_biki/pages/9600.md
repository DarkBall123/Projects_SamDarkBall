## BIS fnc 3Dcredits

- Source: https://community.bistudio.com/wiki/BIS_fnc_3Dcredits
- Revision: 327969
- Updated: 2022-07-13T14:24:24Z

- Availability: arma2oa 1.56, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: GUI

### Description

Displays structured text in 3D world. GUI layer for indicator is `2733`.

### Syntax

```sqf
[text, position, minDist, fadeDist] spawn BIS_fnc_3Dcredits
```

### Parameters

- text: String with optional Structured Text formatting
- position: Array in format Position
- minDist: Number - (Optional, default 20) distance in which text is displayed
- fadeDist: Number - (Optional, default is 1.5) distance in which text starts fading again

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["<t size='2'>Hello World</t>", getPosATL helloWorld, 15, 0] spawn BIS_fnc_3Dcredits;
```

#### Example 2

```sqf
["<img size='2' image='img\myImage.paa'/>
Some text on the second line", getPosATL someObject] spawn BIS_fnc_3Dcredits;
```
