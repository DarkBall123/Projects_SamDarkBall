|gr1= Positions

|descr= Returns whether there is water at given position. In Arma 3, it also detects pond objects, but only if they are loaded in memory (normally only true if the objects are within the object view distance)

|s1= surfaceIsWater position

|p1= position: Position2D  or Position3D - when using Position3D Z will be ignored

|r1= Boolean

|x1=

```sqf

```

```sqf

```
