## BIS fnc isInFrontOf

- Source: https://community.bistudio.com/wiki/BIS_fnc_isInFrontOf
- Revision: 328436
- Updated: 2022-07-13T16:00:51Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation, Geometry

### Description

Check if an object is in front of another object (in the front 180°)

### Syntax

```sqf
[reference, checked, offset] call BIS_fnc_isInFrontOf
```

### Parameters

- reference: Object - the reference object
- checked: Object - the object that has to be in front of *reference*
- offset: Number - (Optional, default 0) allows to check from *offset* meters in front of (positive), or behind (negative) *reference*

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _isInstructorInFrontOfPlayer = [player, instructor, 0] call BIS_fnc_isInFrontOf;
```
