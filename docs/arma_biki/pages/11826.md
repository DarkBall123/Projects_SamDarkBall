## visiblePositionASL

- Source: https://community.bistudio.com/wiki/visiblePositionASL
- Revision: 377444
- Updated: 2026-01-02T06:46:56Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Positions, Render Time Scope

### Description

Returns an object's rendered ASL position (z value above sea level) in render time scope.

### Syntax

```sqf
visiblePositionASL object
```

### Parameters

- object: Object - name of the object

### Return Value

- PositionASL

### Examples

#### Example 1

```sqf
_playerRenderedPosASL = visiblePositionASL player;
```
