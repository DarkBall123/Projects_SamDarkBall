## menuEnabled

- Source: https://community.bistudio.com/wiki/menuEnabled
- Revision: 378333
- Updated: 2026-04-02T16:30:48Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns if menu entry on given path is enabled or not.

### Syntax

```sqf
menuEnabled [idc, path]
```

```sqf
control menuEnabled path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
_isEnabled = findDisplay 313 displayCtrl 120 menuEnabled [0];
```
