## scopeName

- Source: https://community.bistudio.com/wiki/scopeName
- Revision: 363355
- Updated: 2024-03-27T12:05:28Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Defines name of current scope. Name is visible in debugger, and name is also used as reference in some commands like breakOut and breakTo.
Scope name should be defined only once per scope. Trying to set a different name on the scope that has already defined scope name will result in error.

### Syntax

```sqf
scopeName name
```

### Parameters

- name: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
scopeName "main";
while { sleep 0.1; true } do
{
	scopeName "loop1";

	while { sleep 0.1; true } do
	{
		scopeName "loop2";

		// ...
	};
};
```

#### Example 2

```sqf
if (true) then
{
	scopeName "mainScope";
	scopeName "main_scope"; // error
};
```
