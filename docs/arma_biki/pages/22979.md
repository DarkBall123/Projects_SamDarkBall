- Revision: 309231
- Updated: 2022-05-04T10:19:29Z

### Description

Returns array of user text variables used in MFD.

### Syntax

```sqf
getUserMFDText vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array of Strings

### Examples

```sqf
getUserMFDText _vehicle;
```
