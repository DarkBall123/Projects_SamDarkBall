## menuAdd

- Source: https://community.bistudio.com/wiki/menuAdd
- Revision: 378324
- Updated: 2026-04-02T16:28:30Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Adds new submenu entry into item on given path.

### Syntax

```sqf
menuAdd [idc, path, text]
```

```sqf
control menuAdd [path, text]
```

### Parameters

- idc: Number
- path: Tree View Path
- text: String
- control: Control
- path: Tree View Path - path where the items should be added
- text: String - displayed name for the entry

### Return Value

- Number
- Number - index of the item

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuAdd [[], "Custom Tools"]; // Add new entry at the top level to the menu strip in Eden Editor
```
