## sliderRange

- Source: https://community.bistudio.com/wiki/sliderRange
- Revision: 377269
- Updated: 2026-01-02T06:36:28Z

- Availability: ofp 1.85, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns limits of CT_SLIDER or CT_XSLIDER.

### Syntax

```sqf
sliderRange idc
```

```sqf
sliderRange control
```

### Parameters

- idc: Number - idc of the control
- control: Control

### Return Value

- Array format  [minValue, maxValue]
- Array format  [minValue, maxValue]

### Examples

#### Example 1

```sqf
sliderRange _ctrlSlider params ["_minValue", "_maxValue"];
```
