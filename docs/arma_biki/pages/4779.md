## camPrepareTarget

- Source: https://community.bistudio.com/wiki/camPrepareTarget
- Revision: 318609
- Updated: 2022-05-13T09:21:11Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Prepares the camera target to a position or to a target. Needs the call of camCommitPrepared to be conducted.

### Syntax

```sqf
camera camPrepareTarget position
```

```sqf
camera camPrepareTarget target
```

### Parameters

- camera: Object - object of type "camera"
- position: Position - target location
- camera: Object - object of type "camera"
- target: Object

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_camera camPrepareTarget getPos player;
```

#### Example 2

```sqf
_camera camPrepareTarget player;
```
