## forceAddUniform

- Source: https://community.bistudio.com/wiki/forceAddUniform
- Revision: 318837
- Updated: 2022-05-13T09:21:54Z

- Availability: arma3 1.22
- Locality: argument global, effect global
- Groups: Containers, Unit Inventory

### Description

Create a new uniform and hard link it into slot (without any restrictions).

### Syntax

```sqf
unit forceAddUniform type
```

### Parameters

- unit: Object
- type: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_unit forceAddUniform "U_B_CombatUniform_mcam";
```
