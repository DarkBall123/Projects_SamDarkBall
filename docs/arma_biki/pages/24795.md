## BIS fnc reviveDamageReset

- Source: https://community.bistudio.com/wiki/BIS_fnc_reviveDamageReset
- Revision: 363940
- Updated: 2024-04-26T21:33:55Z

- Availability: arma3 1.42
- Locality: argument local, effect local
- Groups: Revive

### Description

Resets player's damage data and received damage.

### Multiplayer

Works only locally for player.

### Syntax

```sqf
[player] call BIS_fnc_reviveDamageReset
```

### Parameters

- player: Object - player

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_reviveDamageReset;
```
