## menuAction

- Source: https://community.bistudio.com/wiki/menuAction
- Revision: 378323
- Updated: 2026-04-02T16:28:16Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns action stored in item on given path in CT_MENU_STRIP control.

### Syntax

```sqf
menuAction [idc, path]
```

```sqf
control menuAction path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- String - action
- String - action

### Examples

#### Example 1

```sqf
menuAction [120, [1, 0]];
```

#### Example 2

```sqf
findDisplay 313 displayCtrl 120 menuAction [1, 0];
```
