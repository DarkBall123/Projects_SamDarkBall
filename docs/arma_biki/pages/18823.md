## BIS fnc deleteCounter

- Source: https://community.bistudio.com/wiki/BIS_fnc_deleteCounter
- Revision: 363649
- Updated: 2024-04-11T15:44:05Z

- Availability: arma3 1.00
- Locality: argument global, effect local
- Groups: Systems

### Description

Delete the provided counter added by BIS_fnc_counter.

### Syntax

```sqf
[varName] call BIS_fnc_deleteCounter
```

### Parameters

- varName: String or Array format [varName, namespace] - default namespace is missionNamespace

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"TAG_Score", player call BIS_fnc_deleteCounter;
```
