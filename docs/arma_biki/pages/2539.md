### Description

Remove a unit from the list of units available for Team Switch.

### Syntax

```sqf
removeSwitchableUnit  unitName
```

### Parameters

- unitName: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeSwitchableUnit _unit1;
```
