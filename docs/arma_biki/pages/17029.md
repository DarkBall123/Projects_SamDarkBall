## controlsGroupCtrl

- Source: https://community.bistudio.com/wiki/controlsGroupCtrl
- Revision: 310912
- Updated: 2022-05-07T20:33:32Z

- Availability: arma3 1.42
- Groups: GUI Control

### Description

Returns a child control with specified idc from a controls group

### Syntax

```sqf
ctrlgrp controlsGroupCtrl idc
```

### Parameters

- ctrlgrp: Control
- idc: Number

### Return Value

- Control

### Examples

#### Example 1

```sqf
_control = _controlsGroup controlsGroupCtrl 101;
```
