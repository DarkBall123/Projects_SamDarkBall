## BIS fnc colorRGBAtoTexture

- Source: https://community.bistudio.com/wiki/BIS_fnc_colorRGBAtoTexture
- Revision: 340322
- Updated: 2023-04-30T00:15:24Z

- Availability: arma3 1.00
- Groups: Arrays

### Description

Converts RGB color format to procedural texture, e.g `[0,0,0,1]` becomes `"#(argb,8,8,3)color(0,0,0,1)"`.

Values are in range 0..1.

### Syntax

```sqf
color call BIS_fnc_colorRGBAtoTexture
```

### Parameters

- color: Array - format [{{Color|red|R}},{{Color|green|G}},{{Color|blue|B}},{{Color|grey|A}}]

### Return Value

- String - procedural texture to format "#(argb,8,8,3)color(R,G,B,A)"

### Examples

#### Example 1

```sqf
private _texture = [0,0,0,1] call BIS_fnc_colorRGBAtoTexture;
```
