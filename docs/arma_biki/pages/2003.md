## keyImage

- Source: https://community.bistudio.com/wiki/keyImage
- Revision: 338908
- Updated: 2023-04-17T14:33:23Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Returns a structured text, containing an image or name (if no image is found) of the button, on the keyboard, mouse or joystick, with the given code.

### Syntax

```sqf
keyImage  dikCode
```

### Parameters

- dikCode: Number or 2.08 String

### Return Value

- Structured Text

### Examples

#### Example 1

```sqf
_image = keyImage 28; // result is "Enter"
```

#### Example 2

From Arma 3 v2.08:

```sqf
_image = keyImage "-1660944350"; // result is "Right Ctrl+G"
```
