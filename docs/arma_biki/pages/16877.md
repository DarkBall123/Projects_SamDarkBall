## getObjectTextures

- Source: https://community.bistudio.com/wiki/getObjectTextures
- Revision: 370025
- Updated: 2024-10-27T20:33:06Z

- Availability: arma3 1.38
- Locality: argument global
- Groups: Object Manipulation

### Description

Gets all custom textures (hiddenSelectionsTextures) associated with the object. Prior to Arma 3 v2.20 it will return an empty Array when executed on simple objects.

### Syntax

```sqf
getObjectTextures obj
```

```sqf
obj getObjectTextures sels
```

### Parameters

- obj: Object
- obj: Object - entity
- sels: Array - array of index(es) and/or selection(s). If array is empty [] - default object textures are returned (see example 3)

### Return Value

- Array of Strings - array of textures
- Array of Strings - array of textures in order of 'sels'. Non existing textures filled with nils.

### Examples

#### Example 1

```sqf
_textures = getObjectTextures player;
```

#### Example 2

```sqf
player setObjectTexture ["clan", "\a3\missions_f_epa\data\img\orbat\b_111_texture_ca.paa"];
player getObjectTextures ["clan", 1, 0, player, "dskjhkjhsad"]; 
// ["a3\missions_f_epa\data\img\orbat\b_111_texture_ca.paa","","a3\characters_f\blufor\data\clothing1_co.paa",<null>,<null>]
```

#### Example 3

```sqf
player setObjectTexture [0, ""];
player getObjectTextures []; // ["a3\characters_f\blufor\data\clothing1_co.paa",""]
```
