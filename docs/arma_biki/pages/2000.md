## isKeyActive

- Source: https://community.bistudio.com/wiki/isKeyActive
- Revision: 319058
- Updated: 2022-05-13T09:23:07Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Checks whether the given key is active in the current user profile.

See keys, keysLimit and doneKeys in the description.ext file of the missions.

### Syntax

```sqf
isKeyActive keyName
```

### Parameters

- keyName: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_active = isKeyActive "Mission04Key";
```
