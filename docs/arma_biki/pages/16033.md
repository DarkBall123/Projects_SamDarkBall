## BIS fnc textureVehicleIcon

- Source: https://community.bistudio.com/wiki/BIS_fnc_textureVehicleIcon
- Revision: 327466
- Updated: 2022-07-12T22:12:10Z

- Availability: arma3 1.00
- Groups: Object Manipulation

### Description

Checks whether icon is defined in CfgVehicleIcons and if so, returns the icon.

### Syntax

```sqf
[wantedIcon] call BIS_fnc_textureVehicleIcon
```

### Parameters

- wantedIcon: String

### Return Value

- String - icon texture path, or *wantedIcon* if not found

### Examples

#### Example 1

```sqf
private _mediTexture = ["iconManMedic"] call BIS_fnc_textureVehicleIcon;
```
