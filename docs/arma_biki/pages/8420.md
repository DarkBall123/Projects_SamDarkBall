## setArmoryPoints

- Source: https://community.bistudio.com/wiki/setArmoryPoints
- Revision: 319633
- Updated: 2022-05-13T09:24:36Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Stores passed number into [USERNAME].ArmaXProfile file, where it assigns it as a value to *armoryPoints* entry. If entry doesn't exist, it is created.

### Syntax

```sqf
setArmoryPoints points
```

### Parameters

- points: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setArmoryPoints (armoryPoints + 20);
```

#### Example 2

```sqf
setArmoryPoints 3.14;
```
