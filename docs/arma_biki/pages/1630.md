## lbSize

- Source: https://community.bistudio.com/wiki/lbSize
- Revision: 353733
- Updated: 2024-03-22T10:26:54Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListBox

### Description

Returns the number of items in a CT_LISTBOX or CT_COMBO control. For CT_TOOLBOX size see lnbSize.

### Syntax

```sqf
lbSize idc
```

```sqf
lbSize control
```

### Parameters

- idc: Number - control's id
- control: Control

### Return Value

- Number
- Number

### Examples

#### Example 1

```sqf
_size = lbSize 101;
```

#### Example 2

```sqf
_size = lbSize _control;
```
