## namedProperties

- Source: https://community.bistudio.com/wiki/namedProperties
- Revision: 338564
- Updated: 2023-03-20T14:40:54Z

- Availability: arma3 2.00
- Groups: Object Manipulation

### Description

Returns a list of named properties on Geometry LOD.

### Syntax

```sqf
namedProperties object
```

```sqf
object namedProperties [LOD]
```

### Parameters

- object: Object
- object: Object
- LOD: String or Number - can be one of:
* `"Memory"`
* `"Geometry"`
* `"FireGeometry"`
* `"LandContact"`
* `"HitPoints"`
* `"ViewGeometry"`
When Number is used, command searches for a LOD with the similar LOD resolution

### Return Value

- Array of Arrays of Strings, in format: [[namedProperty1, propertyValue1], [namedProperty2, propertyValue2], ...]
- HashMap

### Examples

#### Example 1

```sqf
private _properties = namedProperties _object; // [["sbsource","shadowvolume"],["prefershadowvolume","1"],["reversed","1"],["buoyancy","1"]]
```

#### Example 2

```sqf
private _namedProperties = cursorObject namedProperties ["FireGeometry"];
```
