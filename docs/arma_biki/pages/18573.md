```sqf
execVM "A3\Functions_F\Debug\Utilities\lib\index.sqf"
```

### Jukebox

Plays music from CfgMusic. One can navigate through the track by dragging the progress bar left or right and pause/resume by clicking again on the song in the list. The track information for played track in window shows the actual track duration, while the track duration in the list comes from config and could be inaccurate.
```mediawiki-table
{|
! Shortcut:
| `utils 4`
|-
! Script:

```sqf

```

|}
```

### Script Commands

Lists all available script commands and their arguments.
```mediawiki-table
{|
! Shortcut:
| `utils 5`
|-
! Script:
|

```sqf
execVM "A3\Functions_F\Debug\Utilities\utility_scriptCommands.sqf"
```

|}
```

Limited modifiers can be used with search:
```mediawiki-table
{|
! <pre>"<word>"</pre>
| Searches for exact word, for example:
| <pre>"addmagazine"</pre>
|-
! <pre>*</pre>
| Replaces asterisk with anything, for example:
| <pre>add*global</pre>
|-
! <pre>-</pre>
| Ignores given word, for example:
| <pre>addMagazine-cargo</pre>
|}
```

### Notepad++ Export (2.22)

All script commands can be exported in Notepad++ syntax highlight template format (light and dark).

Follow the instructions on the export page, here is a short transcript:
1. Copy this content to clipboard with {{Controls|Ctrl|A}}/{{Controls|Ctrl|C}}
1. Open Notepad++ and open a new file
1. Paste the copied content into the new file with {{Controls|Ctrl|V}}
1. Save the file as `arma3sqf.xml`
1. Open Notepad++ template directory via Notepad++ menu: Language → User Defined Language → Open User Defined Language folder...
1. Move arma3sqf.xml in this directory and restart Notepad++
1. From the Language menu, select:
#* ARMA 3 SQF (Default) - for Default style
#* ARMA 3 SQF (DarkModeDefault) - for DarkModeDefault style
The style can be chosen in: Settings  → Style Configurator...
