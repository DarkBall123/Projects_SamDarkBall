## ropeSegments

- Source: https://community.bistudio.com/wiki/ropeSegments
- Revision: 364777
- Updated: 2024-06-10T12:28:27Z

- Availability: arma3 2.04
- Groups: Ropes and Sling Loading

### Description

Returns provided rope's segments.

2.12 use objectParent to return the rope parent from a rope segment.

### Syntax

```sqf
ropeSegments rope
```

### Parameters

- rope: Object

### Return Value

- Array of Objects - the rope's segments

### Examples

#### Example 1

```sqf
private _segments = ropeSegments _myRope;
```
