## getTextRaw

- Source: https://community.bistudio.com/wiki/getTextRaw
- Revision: 347409
- Updated: 2023-09-18T13:18:49Z

- Availability: arma3 2.02
- Groups: Config, Localization

### Description

Returns raw text from config entry. If entry is subject to localization, the translation key is returned. To obtain the localized text, see getText.

### Syntax

```sqf
getTextRaw config
```

### Parameters

- config: Config

### Return Value

- String - raw text value

### Examples

#### Example 1

```sqf
private _text = getText (configFile >> "CfgVehicles" >> "Thing" >> "displayName");			// "Get in %1 as Driver"
private _rawText = getTextRaw (configFile >> "CfgVehicles" >> "Thing" >> "displayName");	// "$STR_ACTION_GETIN_DRIVER"
private _localized = localize _text;														// "Get in %1 as Driver"
_localized == _text; // true
```
