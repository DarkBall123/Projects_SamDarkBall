## setLightConePars

- Source: https://community.bistudio.com/wiki/setLightConePars
- Revision: 376693
- Updated: 2025-11-05T22:52:10Z

- Availability: arma3 2.06
- Locality: argument local, effect local
- Groups: Lights

### Description

Sets the `#lightreflector`'s cone params.

### Syntax

```sqf
lightReflector setLightConePars [outerAngle, innerAngle, fadeCoef]
```

### Parameters

- lightReflector: Object - object of class `#lightreflector`
- outerAngle: Number
- innerAngle: Number
- fadeCoef: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_light setLightConePars [90, 45, 1];
```
