## isDamageAllowed

- Source: https://community.bistudio.com/wiki/isDamageAllowed
- Revision: 336947
- Updated: 2023-01-04T16:44:11Z

- Availability: arma3 1.70
- Locality: argument global, effect local
- Groups: Object Manipulation

### Description

A getter for allowDamage command. The command indicates if damage is allowed at current locality, hence local effect of the command.
For complete solution for being able to tell whether or not an object can be damaged at current locality see #Example 1.

### Multiplayer

Always returns false when called on non-local objects

### Syntax

```sqf
isDamageAllowed object
```

### Parameters

- object: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _canBeDamaged = local _obj && isDamageAllowed _obj;
```
