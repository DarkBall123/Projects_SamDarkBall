## BIS fnc diagKeyTest

- Source: https://community.bistudio.com/wiki/BIS_fnc_diagKeyTest
- Revision: 348390
- Updated: 2023-11-08T13:00:00Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Returns all user actions according to mode.

### Syntax

```sqf
mode call BIS_fnc_diagKeyTest
```

### Parameters

- mode: Number - can be:

0 - Log all categories

1 - Log Uncategorized

2 - Log unassigned

3 - Log undefined

4 - Log localized names

### Return Value

- String

### Examples

#### Example 1

```sqf
0 call BIS_fnc_diagKeyTest;
```
