## synchronizedWaypoints

- Source: https://community.bistudio.com/wiki/synchronizedWaypoints
- Revision: 377125
- Updated: 2026-01-01T10:21:46Z

- Availability: arma3 0.50
- Groups: Waypoints, Triggers

### Description

Returns the list of waypoints synchronized with a given trigger or waypoint.

### Syntax

```sqf
synchronizedWaypoints obj
```

### Parameters

- obj: Object or Waypoint

### Return Value

- Array of Waypoints

### Examples

#### Example 1

```sqf
synchronizedWaypoints _someTrigger;
```
