## tvClear

- Source: https://community.bistudio.com/wiki/tvClear
- Revision: 309901
- Updated: 2022-05-05T12:16:47Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Removes all items from Tree View with given idc.

### Syntax

```sqf
tvClear idc
```

```sqf
tvClear control
```

### Parameters

- idc: Number
- control: Control

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvClear 101;
```
