## simulSetHumidity

- Source: https://community.bistudio.com/wiki/simulSetHumidity
- Revision: 373025
- Updated: 2025-03-18T15:57:35Z

- Availability: arma3 0.50
- Groups: Environment, Broken Commands

### Description

Sets simul cloud cover. This command does not affect overcast value.

This command was not implemented up until 2.18

### Syntax

```sqf
simulSetHumidity humidity
```

### Parameters

- humidity: Number - 0 (min): clear sky, 1 (max): heavy cloud cover

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
simulSetHumidity 1;
```

#### Example 2

When combined with setOvercast 1 this command will also start random strength rain.

```sqf
skipTime -24;
86400 setOvercast 1;
skipTime 24;
simulSetHumidity 1;
```

Creates rainy looking weather, followed by thunder in about 10 seconds and rain in about 20.
