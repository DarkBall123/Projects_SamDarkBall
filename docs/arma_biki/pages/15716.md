### Description

<pre>
/************************************************************
	Unit Vector

Returns the unit vector for the passed vector (vector pointing
in the same direction, but with magnitude == 1)
This does not modify the original array.
The array can have any number of elements (2, 3, etc).
************************************************************/</pre>
