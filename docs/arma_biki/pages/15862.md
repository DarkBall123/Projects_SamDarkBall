## BIS fnc MPexec

- Source: https://community.bistudio.com/wiki/BIS_fnc_MPexec
- Revision: 363814
- Updated: 2024-04-22T18:52:30Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Multiplayer

### Description

Execute received remote execution. This function is used by BIS_fnc_MP and should not be called directly.
Obsolete and entirely effectless (empty file) since 1.52 and the introduction of remoteExec/remoteExecCall.

### Syntax

```sqf
[packetName, packetValue] call BIS_fnc_MPexec
```

### Parameters

- packetName: String - packet variable name - always "BIS_fnc_MP_packet" (not used in the function)
- packetValue: Array format [params, functionName, target, isSpawn, isPersistent] - packet sent by BIS_fnc_MP; see its page for more details

### Return Value

- Boolean - true if function was executed successfully

### Examples

#### Example 1

```sqf
["BIS_fnc_MP_packet", ["Hello World", "hint", true, true]] call BIS_fnc_MPexec;
```
