## forEachMemberAgent

- Source: https://community.bistudio.com/wiki/forEachMemberAgent
- Revision: 330640
- Updated: 2022-10-03T11:04:22Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Executes the given command recursively for each agent that is a member of the given team. For just teams use forEachMemberTeam. For both teams and agents use forEachMember.

### Syntax

```sqf
command forEachMemberAgent team
```

### Parameters

- command: Code
- team: Team Member

### Return Value

- Nothing
