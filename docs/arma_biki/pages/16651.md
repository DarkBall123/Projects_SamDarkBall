### Description

Subtracts numbers or arrays from each another, negates a number. For arrays also see deleteAt and deleteRange.
In Arma 3 it is possible to subtract nested arrays.

### Syntax

```sqf
numberA - numberB
```

```sqf
- numberA
```

```sqf
arrayA - arrayB
```

### Parameters

- numberA: Number
- numberB: Number
- numberA: Number
- arrayA: Array of Anything
- arrayB: Array of Anything

### Return Value

- Number
- Number - the negative of *numberA*
- Array of Anything

### Examples

#### Example 1

```sqf
_result = 10 - 7; // result is 3
```

#### Example 2

```sqf
_numA = 4;
_numB = -_numA; // result is -4
_numB = -_numB; // result is  4
```

#### Example 3

```sqf
_result = [1, 2, 2, player, "String"] - [2, player, player, "String"]; // _result is [1]
```

#### Example 4

```sqf
_result = [0, [0], 0] - [0]; // [[0], 0]
```

#### Example 5

```sqf
_result = [0, [0], 0] - 0;		// [0, [<nowiki/>[0]]]	- Since Arma 3
_result = [0, [0], 0] - [0];	// [0, [0]]		- Since Arma 3
```
