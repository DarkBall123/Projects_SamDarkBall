## setLightUseFlare

- Source: https://community.bistudio.com/wiki/setLightUseFlare
- Revision: 341209
- Updated: 2023-05-13T22:45:31Z

- Availability: arma3 0.50
- Locality: argument local, effect local
- Groups: Lights

### Description

Sets if light has flare.

### Syntax

```sqf
light setLightUseFlare bool
```

### Parameters

- light: Object
- bool: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLight setLightUseFlare true;
```
