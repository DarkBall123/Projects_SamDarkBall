## displaySetEventHandler

- Source: https://community.bistudio.com/wiki/displaySetEventHandler
- Revision: 369398
- Updated: 2024-09-03T18:43:19Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Event Handlers, Event Handlers

### Description

Sets given event handler of given display.
The return code of the provided function should indicate whether this event was handled correctly. This implies telling the engine whether it is default code should be executed. 
See User Interface Event Handlers for the full list of handler names.

If applicable, see DIK KeyCodes for a list of key code constants, which are relevant to key related user interface events like [onKeyDown](User Interface Event Handlers#onKeyDown) and [onKeyUp](User Interface Event Handlers#onKeyUp).
When using the event names listed here with the ctrlAddEventHandler, ctrlSetEventHandler, displayAddEventHandler or displaySetEventHandler commands, the prefix "on" in the event name must be removed (e.g. **'ButtonDown**' instead of **'onButtonDown**').

### Syntax

```sqf
display displaySetEventHandler [handlerName, function]
```

### Parameters

- display: Display
- handlerName: String
- function: String - code

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control displaySetEventHandler ["KeyDown", ""];
```

#### Example 2

`init.sqf`:

```sqf
KeysPressed = compile preprocessFile "keysPressed.sqf";
private _display = findDisplay 46;
_display displaySetEventHandler ["KeyDown", "_this call KeysPressed"];
```

`keysPressed.sqf`:

```sqf
private _handled = false;
switch (_this select 1) do {
	// F key
	case 33: {
		// code here
		_handled = true;
	};
};
_handled;
```
