## edit3DENMissionAttributes

- Source: https://community.bistudio.com/wiki/edit3DENMissionAttributes
- Revision: 363773
- Updated: 2024-04-19T09:32:17Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Open a window with scenario attribute in given section.

### Syntax

```sqf
edit3DENMissionAttributes  section
```

### Parameters

- section: String - attribute section from 

```sqf
configFile >> "Cfg3DEN" >> "Mission"
```

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
edit3DENMissionAttributes "Multiplayer";
```
