## ctrlEnabled

- Source: https://community.bistudio.com/wiki/ctrlEnabled
- Revision: 338573
- Updated: 2023-03-20T14:59:19Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: GUI Control

### Description

Returns if a control on the currently active user dialog is enabled. Disabled controls cannot be focused. Read Arma: GUI Configuration for more information about user dialogs and controls.

### Syntax

```sqf
ctrlEnabled idc
```

```sqf
ctrlEnabled controlName
```

### Parameters

- idc: Number - control's IDC
- controlName: Control

### Return Value

- Boolean - true if the control is enabled, false if not
- Boolean - true if the control is enabled, false if not

### Examples

#### Example 1

```sqf
if !(ctrlEnabled 100) then
{
	ctrlEnable [100, true];
};
```

#### Example 2

```sqf
_enabled = ctrlEnabled _control;
```
