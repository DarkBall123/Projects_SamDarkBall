## setPosASLW

- Source: https://community.bistudio.com/wiki/setPosASLW
- Revision: 377592
- Updated: 2026-01-02T06:59:02Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Positions

### Description

Sets the object position above sea surface. The pos array uses the PositionASLW format.

### Syntax

```sqf
obj setPosASLW pos
```

### Parameters

- obj: Object
- pos: PositionASLW

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_diver setPosASLW [(position _diver) select 0, (position _diver) select 1, -10];
```
