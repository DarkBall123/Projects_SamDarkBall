### Assets

#### Old Laptop

The **"Land_Laptop_02_unfolded_F"** Old Laptop has an action to "Get Back to Main Menu" when the mission date is set to 2001-06-22 ({{GameCategory|ofp|link= y}} release date).
Completing the action causes the Old Laptop to display a video showcasing the {{GameCategory|ofp|link= y}}'s main menu. The BIS_fnc_laptopInit function can be used to apply this Easter Egg on other computers.

#### Chimney's galaxy

Some Arma 3 performance issues can be explained by the fact the Real Virtuality engine has to render **a whole galaxy** in **"Land_SCF_01_chimney_F"** Sugar Cane Factory chimney tower.

### Missions/Campaigns

#### Dutch flag and oranges

In one of the IDAP tents that you see at the beginning from the van of Remnants of War, there are small dutch flags and a couple of oranges, which usually one can not see during gameplay.
This is a reference to the fact that Arma 3 Laws of War (codename *orange*) is made by the Bohemia Interactive Amsterdam Studio.
