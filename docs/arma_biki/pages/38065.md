## serverConfigTopLevelEntry

- Source: https://community.bistudio.com/wiki/serverConfigTopLevelEntry
- Revision: 364595
- Updated: 2024-05-17T12:58:28Z

- Availability: argo 1.00
- Locality: server execution server
- Groups: Argo

### Description

Get top-level entry (i.e. entry directly below config root) of the desired name from the [server config](Arma 3: Server Config File), making it some kind of secured ***serverConfigFile*** command.

### Multiplayer

Only works on **dedicated** servers.

### Syntax

```sqf
serverConfigTopLevelEntry configEntry
```

### Parameters

- configEntry: String - any server config entry but `password` and `passwordAdmin` which are ignored

### Return Value

- Config - requested server config entry or configNull on error

### Examples

#### Example 1

```sqf
_kickDupes = getNumber serverConfigTopLevelEntry "kickDuplicate" != 0;
```
