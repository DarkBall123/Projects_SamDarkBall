## addWeaponCargoGlobal

- Source: https://community.bistudio.com/wiki/addWeaponCargoGlobal
- Revision: 376384
- Updated: 2025-10-09T02:14:17Z

- Availability: arma2oa 1.55, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Containers

### Description

Add weapons to the cargo space of vehicles, which can be taken out by infantry units.

### Syntax

```sqf
vehicleName addWeaponCargoGlobal [weaponName, count]
```

### Parameters

- vehicleName: Object - vehicle to which add the weapons
- weaponName: String - weapon name. See the topic :Category:Weapons for reference about possible values
- count: Number - number of weapons to add. 2.14 negative count will remove weapons.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_truck addWeaponCargoGlobal ["M16", 5];
```
