## canUnloadInCombat

- Source: https://community.bistudio.com/wiki/canUnloadInCombat
- Revision: 363231
- Updated: 2024-03-26T10:51:07Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns config value of `unloadInCombat` for a vehicle. Alternatively see getUnloadInCombat

### Syntax

```sqf
canUnloadInCombat vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (canUnloadInCombat _vehicle) then { hint "unload in combat is possible!" };
```
