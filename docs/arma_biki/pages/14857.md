## setCuratorEditingAreaType

- Source: https://community.bistudio.com/wiki/setCuratorEditingAreaType
- Revision: 348452
- Updated: 2023-11-08T13:00:17Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Set whether curator can edit in all editing areas (true) or outside of them (false).

### Syntax

```sqf
curatorObj setCuratorEditingAreaType bool
```

### Parameters

- curatorObj: Object - curator module.
- bool: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
curatorModule setCuratorEditingAreaType true;
```
