## ctHeaderCount

- Source: https://community.bistudio.com/wiki/ctHeaderCount
- Revision: 309979
- Updated: 2022-05-05T12:17:02Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Returns number of headers (rows not included) in the RscControlsTable.

### Syntax

```sqf
ctHeaderCount ctrl
```

### Parameters

- ctrl: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
ctHeaderCount _control;
```
