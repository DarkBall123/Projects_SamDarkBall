## linkItem

- Source: https://community.bistudio.com/wiki/linkItem
- Revision: 369226
- Updated: 2024-09-03T10:34:55Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Unit Inventory

### Description

Create and assign item to the correct slot. If there is an item in the targeted slot, it gets replaced. See also assignItem.

### Syntax

```sqf
unit linkItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
bluforUnit linkItem "NVGoggles";
opforUnit linkItem "NVGoggles_OPFOR";
independentUnit linkItem "NVGoggles_INDEP";
```
