## triggerActivation

- Source: https://community.bistudio.com/wiki/triggerActivation
- Revision: 378816
- Updated: 2026-06-30T23:55:03Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Triggers

### Description

Returns trigger activation. 

{{Feature | important | The trigger could be local or remote but the result returned by this command will be for the trigger activation set up locally on the client that executed the command. See createTrigger for more info.}}

### Syntax

```sqf
triggerActivation trigger
```

### Parameters

- trigger: Object

### Return Value

- Array with [by, type, repeating, persistent]
* by: String - See setTriggerActivation
* type: String - See setTriggerActivation
* repeating: Boolean - See setTriggerActivation
* persistent: Boolean 2.24 - See setTriggerActivation

### Examples

#### Example 1

```sqf
_activation = triggerActivation someTrigger;
```
