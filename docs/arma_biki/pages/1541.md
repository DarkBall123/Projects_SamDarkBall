## missionStart

- Source: https://community.bistudio.com/wiki/missionStart
- Revision: 329154
- Updated: 2022-07-25T12:25:22Z

- Availability: ofp 1.80, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mission Information

### Description

Returns date and time when mission started. Because this command returns the time of the actual start of the mission, it might not be available in *pre-init* or *init*, but is guaranteed to be available in *post-init* when 

```sqf
time > 0
```

.

### Multiplayer

Command only has the desired return value in multiplayer.

### Syntax

```sqf
missionStart
```


### Return Value

- Array format `[year, month, day, hour, minute, second]` in multiplayer, which differs from date format only by seconds. In SP returns `[0,0,0,0,0,0]`

### Examples

#### Example 1

```sqf
setDate (missionStart select [0,5]);
```

#### Example 2

Set real date:

```sqf
//postInit = 1;
if (isServer) then
{
	waitUntil { time > 0 };
	setDate (missionStart select [0, 5]);
};
```
