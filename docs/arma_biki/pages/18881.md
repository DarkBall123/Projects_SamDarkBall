## BIS fnc ffvUpdate

- Source: https://community.bistudio.com/wiki/BIS_fnc_ffvUpdate
- Revision: 327742
- Updated: 2022-07-13T10:45:35Z

- Availability: arma3 1.34
- Groups: Vehicles

### Description

Update Firing From Vehicle feature depending on condition defined in turret's config.

### Syntax

```sqf
vehicle call BIS_fnc_ffvUpdate
```

### Parameters

- vehicle: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
if (local _vehicle) then
{
	_vehicle animate ["Door_1", 1];
	_vehicle call BIS_fnc_ffvUpdate;
};
```
