## setCollisionLight

- Source: https://community.bistudio.com/wiki/setCollisionLight
- Revision: 319554
- Updated: 2022-05-13T09:24:28Z

- Availability: arma3 1.32
- Locality: argument local, effect global
- Groups: Lights

### Description

Switches collision lights of a vehicle on/off.

### Syntax

```sqf
vehicle setCollisionLight set
```

### Parameters

- vehicle: Object
- set: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
heli setCollisionLight true;
```
