## nearSupplies

- Source: https://community.bistudio.com/wiki/nearSupplies
- Revision: 377405
- Updated: 2026-01-02T06:45:03Z

- Availability: arma3 0.50
- Groups: Object Detection

### Description

Find supplies (weapon holders, ammo crates, fuel feeds, other units) in the sphere with given radius.

### Syntax

```sqf
origin nearSupplies radius
```

```sqf
origin nearSupplies [typeName, radius]
```

### Parameters

- origin: Object or PositionAGL or Position2D
- radius: Number
- origin: Object or PositionAGL or Position2D
- typeName: String
- radius: Number

### Return Value

- Array of Objects
- Array of Objects

### Examples

#### Example 1

```sqf
_list = player nearSupplies 50;
```
