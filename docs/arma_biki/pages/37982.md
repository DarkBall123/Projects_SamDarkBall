## isThrowable

- Source: https://community.bistudio.com/wiki/isThrowable
- Revision: 369755
- Updated: 2024-10-08T15:08:55Z

- Availability: arma3 2.18
- Groups: Weapons, Unit Inventory

### Description

Returns true if the given magazine is a throwable.

### Syntax

```sqf
isThrowable magazine
```

### Parameters

- magazine: String

### Return Value

- Boolean - true if throwable

### Examples

#### Example 1

```sqf
isThrowable "HandGrenade"; // true
```
