## equipmentDisabled

- Source: https://community.bistudio.com/wiki/equipmentDisabled
- Revision: 377613
- Updated: 2026-01-02T08:51:39Z

- Availability: arma3 2.12
- Locality: argument global
- Groups: Object Manipulation

### Description

Returns current state for NVG and TI equipment availability.

### Syntax

```sqf
equipmentDisabled vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array with [NVG, TI]

### Examples

#### Example 1

```sqf
equipmentDisabled tank1 params ["_nvg", "_ti"];
```
