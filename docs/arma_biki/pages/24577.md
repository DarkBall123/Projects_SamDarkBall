## BIS fnc timeline getSimulatedCurves

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_getSimulatedCurves
- Revision: 349075
- Updated: 2023-11-08T14:47:23Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Returns the simulated curves of a timeline.

### Syntax

```sqf
[timeline] call BIS_fnc_timeline_getSimulatedCurves
```

### Parameters

- timeline: Object - the timeline object

### Return Value

- Array - returns a list of vurves that are simulated by this timeline

### Examples

#### Example 1

```sqf
private _curves = [timeline] call BIS_fnc_timeline_getSimulatedCurves;
```
