## BIS fnc playerSideFaction

- Source: https://community.bistudio.com/wiki/BIS_fnc_playerSideFaction
- Revision: 311124
- Updated: 2022-05-10T14:43:05Z

- Availability: arma3 1.06
- Groups: Sides

### Description

Return representative faction of the given side. Faction of the first detected player is used.

### Syntax

```sqf
side call BIS_fnc_playerSideFaction
```

### Parameters

- side: Side

### Return Value

- String - CfgFactionClasses class

### Examples

#### Example 1

```sqf
west call BIS_fnc_playerSideFaction;
```
