- Revision: 369657
- Updated: 2024-10-01T12:04:41Z

- Availability: arma3 2.02
- Groups: Markers

### Description

Returns the channel to which a marker belongs.

### Syntax

```sqf
markerChannel marker
```

### Parameters

- marker: String

### Return Value

- Number

### Examples

#### Example 1

```sqf
markerChannel "marker_1";
```
