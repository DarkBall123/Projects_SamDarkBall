## setPosATL

- Source: https://community.bistudio.com/wiki/setPosATL
- Revision: 377533
- Updated: 2026-01-02T06:53:18Z

- Availability: arma2 1.03, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Positions

### Description

Sets the position of an object relative to the terrain.

### Syntax

```sqf
object setPosATL pos
```

### Parameters

- object: Object
- pos: PositionATL

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setPosATL [getPosATL player select 0, (getPosATL player select 1) - 10, getPosATL player select 2];
```

{{Note
|user= Hypoxic125
|timestamp= 20220930040303
|text= As of **Verson 2.10**, if you use **setPosX** commands on a remote unit within a vehicle, the unit will remain in the vehicle. In order to avoid this, **remoteExec** the command to the remote client.

```sqf
if !(isNull objectParent _unit) then {
	[_unit, [0,0,0]] remoteExec ["setPosATL", _unit];
};
```
