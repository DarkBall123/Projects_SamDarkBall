## vectorWorldToModel

- Source: https://community.bistudio.com/wiki/vectorWorldToModel
- Revision: 377866
- Updated: 2026-01-04T11:33:08Z

- Availability: arma3 1.72
- Groups: Math - Vectors

### Description

Converts vector direction from world to model space.
For scaled objects, the resulting vector's magnitude will be divided by the object scale.

### Syntax

```sqf
object vectorWorldToModel worldDir
```

### Parameters

- object: Object
- worldDir: Vector3D - vector direction in world space in format [x,y,z]

### Return Value

- Vector3D - vector direction in model space in format [x,y,z]

### Examples

#### Example 1

Convert world space vector [0,-10,4] to model space of object _airplane: 

```sqf
_airplane vectorWorldToModel [0,-10,4];
```
