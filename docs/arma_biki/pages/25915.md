## BIS fnc parseNumberSafe

- Source: https://community.bistudio.com/wiki/BIS_fnc_parseNumberSafe
- Revision: 348666
- Updated: 2023-11-08T13:50:56Z

- Availability: arma3 1.96
- Groups: Arrays

### Description

Converts expression into a number. Can also convert array of expressions into an array of numbers. If expression does not return a number, 0 is returned.

### Syntax

```sqf
[input] call BIS_fnc_parseNumberSafe
```

### Parameters

- input: Number, String, Side, Config or Array - if type is array, array may contain any of the mentioned data types

### Return Value

- Number or Array of Numbers if *input* is an Array

### Examples

#### Example 1

```sqf
[safeZoneX, safeZoneWAbs, configFile] call BIS_fnc_parseNumberSafe;	// returns [-0.452381,1.90476,0]
```

#### Example 2

```sqf
["1337", "2013", date] call BIS_fnc_parseNumberSafe;					// returns [1337,2013,[2036,1,1,6,58]]
```

#### Example 3

```sqf
[blufor, opfor, independent, civilian] call BIS_fnc_parseNumberSafe;	// returns [1,0,2,3]
```
