## createTask

- Source: https://community.bistudio.com/wiki/createTask
- Revision: 351331
- Updated: 2023-11-27T05:30:49Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing, Teams

### Description

Create a new AI task (subtask of parentTask). Type is name of registered task type.

### Syntax

```sqf
teamMember createTask [<nowiki/>[type, parentTask], priority, name1, value1, ...]
```

### Parameters

- teamMember: Team Member
- type: String - `name` defined in `CfgTasks`
- parentTask: Task - (Optional)
- priority: Number
- nameN: String
- valueN: String

### Return Value

- Task
