## BIS fnc sceneGetObjects

- Revision: 370889
- Updated: 2025-02-21T10:44:04Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Broken Functions, Scenes

### Description

This function is broken (at least in Arma 3) as it has a typo, displaying an error on each use!  (typo **line 63**, `[centrum]` instead of `[_centrum]`).
This function gets objects (but centre object) positions and direction relative to the choosen object and copies the result to the clipboard via copyToClipboard.

Result is to format:

```sqf
[
	// 11 elements for one object
	_nameOfObject, _objectClass, _objectToGet, _computedAngle, _distance, _newDir, _vectorUp, _vectorDir, _animation, _elevASL, _elev,
	_nameOfObject, _objectClass, _objectToGet, _computedAngle, _distance, _newDir, _vectorUp, _vectorDir, _animation, _elevASL, _elev,
	// ...
]
```

Please note that the clipboard result is a one-level array, meaning that all parameters are defined one after the other!

### Syntax

```sqf
[centre, radius, type] call BIS_fnc_sceneGetObjects
```

### Parameters

- centre: Object or String - object or marker name - **NOT** a Position
- radius: Number - (Optional, default 20)
- type: String - (Optional, default "All") - objects type (see nearestObjects)

### Return Value

- Script Handle

### Examples

#### Example 1

```sqf
[player, 20, "Car"] call BIS_fnc_sceneGetObjects;
```
