## kbRemoveTopic

- Source: https://community.bistudio.com/wiki/kbRemoveTopic
- Revision: 319147
- Updated: 2022-05-13T09:23:16Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Conversations

### Description

Unregister conversation topic from given person. See Conversations for more details.

### Syntax

```sqf
person kbRemoveTopic topicName
```

### Parameters

- person: Object
- topicName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_unit1 kbRemoveTopic "howsTheWeather";
```
