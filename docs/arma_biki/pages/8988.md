## mapGridPosition

- Source: https://community.bistudio.com/wiki/mapGridPosition
- Revision: 319458
- Updated: 2022-05-13T09:24:06Z

- Availability: arma2 1.04, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Positions, Map

### Description

Returns the map grid position of an object or position.

The format is determined by the Grid format specified in the CfgWorlds for the current world. Eg: "024577" or "De82" or similar.

### Syntax

```sqf
mapGridPosition param
```

### Parameters

- param: Object or Position - determines reference position

### Return Value

- String - grid position

### Examples

#### Example 1

```sqf
_gridPos = mapGridPosition player;
```

#### Example 2

```sqf
_gridPos = mapGridPosition getPos player;
```
