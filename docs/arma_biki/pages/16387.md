## BIS fnc drawCuratorDeaths

- Source: https://community.bistudio.com/wiki/BIS_fnc_drawCuratorDeaths
- Revision: 349318
- Updated: 2023-11-08T14:52:27Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Show skull unit for curator when the unit dies.

### Syntax

```sqf
[unit] call BIS_fnc_drawCuratorDeaths
```

### Parameters

- unit: Object - unit

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
player call BIS_fnc_drawCuratorDeaths;
```
