## removeGoggles

- Source: https://community.bistudio.com/wiki/removeGoggles
- Revision: 309949
- Updated: 2022-05-05T12:17:00Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Unit Inventory

### Description

Removes goggles from unit (diver goggles for example). This command does not remove NVGoggles. Use unassignItem and removeItem or just unlinkItem for latter.

### Syntax

```sqf
removeGoggles unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeGoggles assaultDiver;
```

### See Also

goggles addGoggles
