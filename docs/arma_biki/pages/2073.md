## setVehicleId

- Source: https://community.bistudio.com/wiki/setVehicleId
- Revision: 364524
- Updated: 2024-05-16T20:46:23Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation, Broken Commands

### Description

Sets ID to vehicle. By this ID vehicle is referenced by triggers and waypoints.

This command is **not** to be used.

### Syntax

```sqf
vehicleName setVehicleId id
```

### Parameters

- vehicleName: Object
- id: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setVehicleId 1;
```
