## ctSetValue

- Source: https://community.bistudio.com/wiki/ctSetValue
- Revision: 310049
- Updated: 2022-05-05T12:23:39Z

- Availability: arma3 1.70
- Groups: GUI Control - Controls Table

### Description

Associates metadata (number) with the row determined by the index. Returns Nothing.

### Syntax

```sqf
control ctSetValue [index, value]
```

### Parameters

- control: Control
- index: Number
- value: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctSetValue [0, 23];
```
