## BIS fnc createLogRecord

- Source: https://community.bistudio.com/wiki/BIS_fnc_createLogRecord
- Revision: 328379
- Updated: 2022-07-13T16:00:48Z

- Availability: arma3 1.00
- Locality: argument local, effect local
- Groups: GUI

### Description

Create a dated, timed diary record in the owner's "Log" subject.

### Syntax

```sqf
[owner, title, text] call BIS_fnc_createLogRecord
```

### Parameters

- owner: Object
- title: String - (Optional, default "")
- text: String - (Optional, default "")

### Return Value

- String

### Examples

#### Example 1

```sqf
[player, "Title", "This is a log entry. Have fun!"] call BIS_fnc_createLogRecord;
```
