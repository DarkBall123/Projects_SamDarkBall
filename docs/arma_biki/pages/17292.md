## currentThrowable

- Source: https://community.bistudio.com/wiki/currentThrowable
- Revision: 377712
- Updated: 2026-01-02T09:03:53Z

- Availability: arma3 1.48
- Groups: Weapons, Unit Inventory

### Description

Returns currently selected throwable (and the muzzle it is loaded into), which will be launched if the user presses {{Controls|G}}.

### Syntax

```sqf
currentThrowable unit
```

### Parameters

- unit: Object

### Return Value

- Array with [magazineName, muzzleName, id, ammoCount]
* magazineName: String
* muzzleName: String
* id: Array of Number pairs: [itemWorldID, creatorID]
* 2.22 ammoCount: Number - magazine ammo

### Examples

#### Example 1

```sqf
currentThrowable player; // ["SmokeShellGreen", "SmokeShellGreenMuzzle", [1.00002e+007, 0], 1]
```

#### Example 2

```sqf
_ct = currentThrowable player;				// ["HandGrenade", "HandGrenadeMuzzle", [1e+007, 0], 1]
_id = (_ct select 2 select 0) - 1e7;		// 18
```
