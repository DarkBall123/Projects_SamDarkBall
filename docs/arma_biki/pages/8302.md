## joinAs

- Source: https://community.bistudio.com/wiki/joinAs
- Revision: 330016
- Updated: 2022-08-15T14:38:07Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Groups

### Description

Joins the unit to the given group, if position id is available, this one is used.

### Syntax

```sqf
unit joinAs [group, id]
```

### Parameters

- unit: Object
- group: Group
- id: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player joinAs [_group, 4];
```

#### Example 2

To get the position id:

```sqf
getUnitPositionId = {
	private ["_vvn", "_str"];
	_vvn = vehicleVarName _this;
	_this setVehicleVarName "";
	_str = str _this;
	_this setVehicleVarName _vvn;
	parseNumber (_str select [(_str find ":") + 1])
};
player joinAs [createGroup west, 5];
_id = player call getUnitPositionId;
hint str _id; // 5
```
