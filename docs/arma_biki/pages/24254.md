## BIS fnc isDateTimeNewer

- Source: https://community.bistudio.com/wiki/BIS_fnc_isDateTimeNewer
- Revision: 323994
- Updated: 2022-07-01T11:58:31Z

- Availability: arma3 1.86
- Groups: Environment

### Description

Returns true if the first passed datetime is newer than the second one.

### Syntax

```sqf
[date1, date2] call BIS_fnc_isDateTimeNewer
```

### Parameters

- date1: Array format Date
- date2: Array format Date

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _isNewer = [[2035,5,28,13,37], [2032,5,28,13,37]] call BIS_fnc_isDateTimeNewer;
```
