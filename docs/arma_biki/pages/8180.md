## buildingExit

- Source: https://community.bistudio.com/wiki/buildingExit
- Revision: 377513
- Updated: 2026-01-02T06:50:20Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns the given indexed exit in a building. The returned value is in format Position.

### Syntax

```sqf
building buildingExit index
```

### Parameters

- building: Object
- index: Number

### Return Value

- Position

### Examples

#### Example 1

```sqf
_building buildingExit 0;
```
