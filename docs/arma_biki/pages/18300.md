## menuHover

- Source: https://community.bistudio.com/wiki/menuHover
- Revision: 339129
- Updated: 2023-04-26T10:54:57Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns path to menu entry mouse is currently hovering over.

### Syntax

```sqf
menuHover idc
```

```sqf
menuHover control
```

### Parameters

- idc: Number
- control: Control

### Return Value

- Array
- Array

### Examples

#### Example 1

```sqf
private _path = menuHover (findDisplay 313 displayCtrl 120);
```
