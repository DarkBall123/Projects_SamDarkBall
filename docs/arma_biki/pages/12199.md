## removeAllAssignedItems

- Source: https://community.bistudio.com/wiki/removeAllAssignedItems
- Revision: 352419
- Updated: 2024-02-09T15:26:08Z

- Availability: arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Unassigns and deletes all linked items from inventory.
The commands operates on assignedItems array, which does not include goggles or headgear but includes binoculars, which is a weapon.

Use removeGoggles and removeHeadgear for those.

### Syntax

```sqf
removeAllAssignedItems unit
```

```sqf
removeAllAssignedItems [unit, allItems, includeBinocs]
```

### Parameters

- unit: Object
- unit: Object - soldier
- allItems: Boolean - true to include all slot items, false exclude goggles and headgear
- includeBinocs: Boolean - true to include binoculars (which is a weapon), false to exclude it

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
removeAllAssignedItems player;
```
