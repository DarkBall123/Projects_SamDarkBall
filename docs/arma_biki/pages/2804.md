## compile

- Source: https://community.bistudio.com/wiki/compile
- Revision: 321043
- Updated: 2022-05-13T12:05:32Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Strings

### Description

Compiles String expression into Code.

### Syntax

```sqf
compile expression
```

### Parameters

- expression: String - expression to be compiled

### Return Value

- Code - compiled expression

### Examples

#### Example 1

```sqf
_string = "a = a + 1";
_code = compile _string;
call _code;
```

#### Example 2

```sqf
hint str compile "a = b";
// result: { a = b }
```
