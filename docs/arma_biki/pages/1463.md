## a greater b

- Source: https://community.bistudio.com/wiki/a_greater_b
- Revision: 318547
- Updated: 2022-05-13T09:21:04Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math, Variables

### Description

Returns true if **a** is greater than **b**, else returns false.

### Syntax

```sqf
a > b
```

### Parameters

- a: Number
- b: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (fuel truck1 > 0) then { hint "Truck1 has some fuel left."; };
```
