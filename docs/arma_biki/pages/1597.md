## debugLog

- Source: https://community.bistudio.com/wiki/debugLog
- Revision: 352160
- Updated: 2024-02-01T23:25:24Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Broken Commands

### Description

Dump argument type and value to debugging output. 

This command is non-functional in the retail version. Use diag_log instead.

### Syntax

```sqf
debugLog anything
```

### Parameters

- anything: Anything

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
debugLog player;
```
