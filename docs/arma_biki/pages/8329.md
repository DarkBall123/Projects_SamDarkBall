## lnbSetValue

- Source: https://community.bistudio.com/wiki/lnbSetValue
- Revision: 321489
- Updated: 2022-05-16T14:15:36Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - ListNBox

### Description

Sets the additional **integer** value in the item with the position index of the 2D listbox.

### Syntax

```sqf
lnbSetValue [idc, [row, column], value]
```

```sqf
control lnbSetValue [<nowiki/>[row, column], value]
```

### Parameters

- idc: Number
- row: Number
- column: Number
- value: Number
- control: Control
- row: Number
- column: Number
- value: Number

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_ctrl lnbSetValue [[0,0],1];
```
