## displayParent

- Source: https://community.bistudio.com/wiki/displayParent
- Revision: 318897
- Updated: 2022-05-13T09:22:00Z

- Availability: arma3 1.58
- Groups: GUI Control

### Description

Returns parent display of the given display.

### Syntax

```sqf
displayParent display
```

### Parameters

- display: Display

### Return Value

- Display

### Examples

#### Example 1

```sqf
_display = displayParent findDisplay 49; // Display #46
```
