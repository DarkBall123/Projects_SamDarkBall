## currentCommand

- Source: https://community.bistudio.com/wiki/currentCommand
- Revision: 318985
- Updated: 2022-05-13T09:22:08Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control

### Description

Return the current command type (empty string when no command) for the commander of given vehicle (or for a given soldier). Returned value can be one of:
{{Columns|4|
* "WAIT"
* "ATTACK"
* "HIDE"
* "MOVE"
* "HEAL"
* "REPAIR"
* "REFUEL"
* "REARM"
* "SUPPORT"
* "JOIN"
* "GET IN"
* "FIRE"
* "GET OUT"
* "STOP"
* "EXPECT"
* "ACTION"
* "ATTACKFIRE"
* "Suppress"
}}

### Syntax

```sqf
currentCommand vehicleName
```

### Parameters

- vehicleName: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
_command = currentCommand player;
```
