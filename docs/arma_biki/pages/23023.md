## enginesPowerRTD

- Source: https://community.bistudio.com/wiki/enginesPowerRTD
- Revision: 349357
- Updated: 2023-11-08T15:35:08Z

- Availability: arma3 1.34
- Groups: RTD

### Description

Returns power produced by engines in Watts.
{{Feature|afm}}

### Syntax

```sqf
enginesPowerRTD RTD_helicopter
```

### Parameters

- RTD_helicopter: Object - helicopter with advanced flight model enabled

### Return Value

- Array of Numbers - watts produced by the engines, to format [engine1, engine2]. Returns an empty array if Advanced Flight Model is disabled.

### Examples

#### Example 1

```sqf
_array = enginesPowerRTD vehicle player;
```
