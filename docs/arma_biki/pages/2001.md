## isKindOf

- Source: https://community.bistudio.com/wiki/isKindOf
- Revision: 341247
- Updated: 2023-05-18T10:50:41Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Checks whether the given object or type is (a subtype) of the given type.

While #Syntax 1 and #Syntax 2 only support **CfgVehicles**, {{GVI|arma2|1.00|size= 0.75}}**CfgAmmo** and **CfgNonAIVehicles**, #Syntax 3 can be used with any config, including the mission config.

### Syntax

```sqf
object isKindOf typeName
```

```sqf
class1 isKindOf class2
```

```sqf
class1 isKindOf [class2, targetConfig]
```

### Parameters

- object: Object
- typeName: String
- class1: String
- class2: String
- class1: String
- class2: String
- targetConfig: Config

### Return Value

- Boolean
- Boolean
- Boolean

### Examples

#### Example 1

```sqf
vehicle player isKindOf "Tank";
```

#### Example 2

```sqf
"BMP2" isKindOf "Tank";
```

#### Example 3

```sqf
currentWeapon player isKindOf ["Rifle", configFile >> "CfgWeapons"];
```

#### Example 4

```sqf
private _isSoldier = player isKindOf "CAManBase";
```

```sqf
"CA_Magazine" in ([configFile >> "CfgMagazines" >> "HandGrenade", true] call BIS_fnc_returnParents);	// 0.12111 ms
"HandGrenade" isKindOf ["CA_Magazine", configFile >> "CfgMagazines"];									// 0.00439453 ms
```

When checking in CfgVehicles the syntax from #Example 2 performs a little faster.
