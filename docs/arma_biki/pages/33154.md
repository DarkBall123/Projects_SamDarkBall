## setTIParameter

- Source: https://community.bistudio.com/wiki/setTIParameter
- Revision: 330291
- Updated: 2022-08-30T11:36:06Z

- Availability: arma3 2.10
- Groups: Environment

### Description

Sets the provided Thermal Imaging parameter's value.
The settings are **not** saved in savegame and must be reapplied after loading.

### Syntax

```sqf
setTIParameter [paramName, newValue]
```

### Parameters

- paramName: String - the parameter name. See getTIParameters for a list of possible values
- newValue: Number - the set number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setTIParameter ["OutputRangeStart", 0];
setTIParameter ["OutputRangeWidth", 1];
```
