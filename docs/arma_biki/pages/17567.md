## set3DENGrid

- Source: https://community.bistudio.com/wiki/set3DENGrid
- Revision: 353050
- Updated: 2024-03-12T12:23:19Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Sets the grid increment for the given transformation type.

### Syntax

```sqf
set3DENGrid [type, value]
```

### Parameters

- type: String - name of transformation type. Can be:
* `"r"` - Rotation
* `"t"` - Translation
* `"s"` - Scale
- value: Number - transformation increment

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
set3DENGrid ["t", 100]; // 100m movement increment
```
