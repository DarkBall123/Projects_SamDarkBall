## removeMagazine

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Unit Inventory

### Description

Remove magazine from the unit or static weapon.

### Syntax

```sqf
unitName removeMagazine magazineName
```

### Parameters

- unitName: Object
- magazineName: String - see weapons

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeMagazine "M16";
```
