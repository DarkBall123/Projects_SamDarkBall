## aimPos

- Source: https://community.bistudio.com/wiki/aimPos
- Revision: 378158
- Updated: 2026-02-26T16:15:24Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Positions

### Description

Returns the position of the object other units can aim to.

### Syntax

```sqf
aimPos  unit
```

### Parameters

- unit: Object

### Return Value

- PositionASL

### Examples

#### Example 1

```sqf
_aimPos = aimPos player;
```

#### Example 2

***aimPosVisual*** equivalent:

```sqf
private _aimPosVisual = AGLToASL unitAimPositionVisual player;
```
