## tvCollapse

- Source: https://community.bistudio.com/wiki/tvCollapse
- Revision: 377801
- Updated: 2026-01-03T04:01:37Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Collapses tree item pointed to by the path. IDC means id of parent Tree View.

### Syntax

```sqf
tvCollapse [idc, path]
```

```sqf
control tvCollapse path
```

### Parameters

- idc: Number
- path: Tree View Path - [] will collapse the whole tree and it will disappear
- control: Control
- path: Tree View Path - [] will collapse the whole tree and it will disappear

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvCollapse [101, [0]];
```

#### Example 2

```sqf
_ctrl tvCollapse [0];
```
