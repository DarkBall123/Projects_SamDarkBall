## ctrlSetModel

- Source: https://community.bistudio.com/wiki/ctrlSetModel
- Revision: 336418
- Updated: 2023-01-03T08:09:24Z

- Availability: arma3 1.32
- Groups: GUI Control - Object

### Description

Sets model for 3D-Dialogs (see Arma 3: createSimpleObject/objects for a p3d models' list).

### Syntax

```sqf
control ctrlSetModel model
```

### Parameters

- control : Control - 3D control
- model : String - model path

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control3D ctrlSetModel "\a3\Ui_f\objects\Compass.p3d";
```
