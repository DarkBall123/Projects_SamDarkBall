## getMusicPlayedTime

- Source: https://community.bistudio.com/wiki/getMusicPlayedTime
- Revision: 309232
- Updated: 2022-05-04T10:20:06Z

- Availability: arma3 1.78
- Groups: Sounds

### Description

Returns elapsed time in seconds for currently playing music track.

### Syntax

```sqf
getMusicPlayedTime
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
playMusic ["LeadTrack06_F_Tank", 0];
onEachFrame {hintSilent str getMusicPlayedTime};
```
