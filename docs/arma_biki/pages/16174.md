## BIS fnc taskSetState

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskSetState
- Revision: 364616
- Updated: 2024-05-22T11:37:48Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Set a task's state. See Arma 3: Task Framework for more information.

### Syntax

```sqf
[taskName, taskState, showHint] call BIS_fnc_taskSetState
```

### Parameters

- taskName: String
- taskState: String - can be:
*"CREATED"
*"ASSIGNED"
*"SUCCEEDED"
*"FAILED"
*"CANCELED"
- showHint: Boolean - (Optional, default true) true to show a hint

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
["BIS_task_01","CANCELED"] call BIS_fnc_taskSetState;
```
