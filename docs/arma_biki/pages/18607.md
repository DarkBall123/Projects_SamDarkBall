## setAmmoOnPylon

- Source: https://community.bistudio.com/wiki/setAmmoOnPylon
- Revision: 310926
- Updated: 2022-05-07T20:47:37Z

- Availability: arma3 1.70
- Groups: Vehicle Loadouts

### Description

Set count of ammo in magazine on pylon (supports pylon name since Arma 3 v1.94)

### Syntax

```sqf
vehicle setAmmoOnPylon [pylon, ammocount]
```

### Parameters

- vehicle: Object
- pylon: Number or String - pylon index (index starts from 1) or pylon name (see getCompatiblePylonMagazines Example 4)
- ammocount: Number - ammo count

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setAmmoOnPylon [1, 12];
```

#### Example 2

```sqf
vehicle player setAmmoOnPylon ["pylon1", 12];
```
