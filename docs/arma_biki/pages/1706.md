## ctrlShow

- Source: https://community.bistudio.com/wiki/ctrlShow
- Revision: 370565
- Updated: 2025-01-09T18:12:50Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control

### Description

Shows or hides a control, or group of controls together with all the controls inside that group of controls.

Read Arma: GUI Configuration for more information about user dialogs and controls.

{{ Feature | Informative | Using ctrlShow on a controls group will show or hide all controls within the controls group (including controls that are placed in nested controls groups). }}

### Syntax

```sqf
ctrlShow [idc, show]
```

```sqf
control ctrlShow show
```

### Parameters

- idc: Number - control IDC
- show: Boolean - true to show the control, false to hide it
- control: Control
- show: Boolean - true to show the control, false to hide it

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
ctrlShow [100, false];
```

#### Example 2

```sqf
_control ctrlShow false;
```
