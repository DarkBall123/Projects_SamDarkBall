## allUsers

- Source: https://community.bistudio.com/wiki/allUsers
- Revision: 378526
- Updated: 2026-05-04T01:56:35Z

- Availability: arma3 2.06
- Locality: server execution server
- Groups: Multiplayer, Object Detection

### Description

Returns a list of player ids of all the users on an MP server.
This also lists Headless Clients.

### Syntax

```sqf
allUsers
```


### Return Value

- Array of Strings - user network IDs (see getPlayerID, getUserInfo)

### Examples

#### Example 1

```sqf
if (isServer) then
{
	private _allUserIDs = allUsers;
	for "_i" from 0 to (count _allUserIds - 1) do
	{
		diag_log format ["User #%1 ID: %2", _i + 1, _allUserIds select _i];
	};
};
```
