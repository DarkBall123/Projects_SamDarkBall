## BIS fnc unitAddon

- Source: https://community.bistudio.com/wiki/BIS_fnc_unitAddon
- Revision: 349389
- Updated: 2023-11-08T16:27:00Z

- Availability: arma3 1.00
- Groups: Configs

### Description

Return addon from CfgPatches to which a given object belongs to.

### Syntax

```sqf
[object] call BIS_fnc_unitAddon
```

### Parameters

- object: Object - object whose addon should be returned

### Return Value

- String - addon class

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_unitAddon;
```
