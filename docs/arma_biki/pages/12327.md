## ctrlHTMLLoaded

- Source: https://community.bistudio.com/wiki/ctrlHTMLLoaded
- Revision: 369233
- Updated: 2024-09-03T10:35:01Z

- Availability: arma3 0.50
- Groups: GUI Control - HTML

### Description

Returns true when HTML content was successfully loaded.

### Syntax

```sqf
ctrlHTMLLoaded control
```

### Parameters

- control: Control

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_control htmlLoad "test.html";
if (!ctrlHTMLLoaded _control) then {
	hint "Loading test.html failed!";
};
```
