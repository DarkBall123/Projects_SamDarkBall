## allControls

- Source: https://community.bistudio.com/wiki/allControls
- Revision: 352271
- Updated: 2024-02-04T22:03:55Z

- Availability: arma3 1.38
- Groups: GUI Control

### Description

Returns a list of all controls in the provided display or controls group, including "sub"-controls from other CT_CONTROLS_GROUPs.

### Syntax

```sqf
allControls display
```

```sqf
allControls controlsGroup
```

### Parameters

- display: Display
- controlsGroup: Control - CT_CONTROLS_GROUP

### Return Value

- Array of Controls
- Array of Controls

### Examples

#### Example 1

```sqf
_allCtrls = allControls findDisplay 46;
```

#### Example 2

```sqf
_allSubCtrls = allControls _myControlsGroup;
```
