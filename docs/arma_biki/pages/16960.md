## waypointsEnabledUAV

- Source: https://community.bistudio.com/wiki/waypointsEnabledUAV
- Revision: 369353
- Updated: 2024-09-03T18:43:04Z

- Availability: arma3 1.40
- Groups: Waypoints, Remote Control

### Description

Checks if the UAV has waypoints enabled.

### Syntax

```sqf
waypointsEnabledUAV uav
```

### Parameters

- uav: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_uav enableUAVWaypoints false;
hint str waypointsEnabledUAV _uav; // returns false
```
