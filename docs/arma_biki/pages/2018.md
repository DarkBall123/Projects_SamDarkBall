## preloadSound

- Source: https://community.bistudio.com/wiki/preloadSound
- Revision: 376517
- Updated: 2025-10-22T23:11:17Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Sounds

### Description

Makes sure that a sound can start playing without any delay once it is needed.
Command works in Arma 3 but might not be implemented in earlier {{arma}} installments.

### Syntax

```sqf
preloadSound soundName
```

### Parameters

- soundName: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _sounds = getArray (missionConfigFile >> "CfgSounds" >> "sounds");
waitUntil { _sounds findIf { !(preloadSound _x) } == -1 };
```
