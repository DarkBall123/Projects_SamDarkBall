## enableIRLasers

- Source: https://community.bistudio.com/wiki/enableIRLasers
- Revision: 310272
- Updated: 2022-05-05T13:11:21Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Weapons

### Description

Allows the AI to use IR lasers. Units should be in "Combat" behaviour.

### Syntax

```sqf
unitOrGroup enableIRLasers value
```

### Parameters

- unitOrGroup: Object or Group - the unit or the group allowed to use IR lasers
- value: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
group player enableIRLasers true;
```
