## enableEndDialog

- Source: https://community.bistudio.com/wiki/enableEndDialog
- Revision: 325303
- Updated: 2022-07-10T22:52:51Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Camera Control, Mission Information

### Description

Enables the execution of a custom camera sequence after the players death, coded in onPlayerKilled.sqs.

### Syntax

```sqf
enableEndDialog
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableEndDialog;
```
