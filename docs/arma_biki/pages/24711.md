## BIS fnc CPWaitUntil

- Source: https://community.bistudio.com/wiki/BIS_fnc_CPWaitUntil
- Revision: 348068
- Updated: 2023-11-08T11:29:53Z

- Availability: arma3 1.72
- Groups: CombatPatrol, Program Flow

### Description

Function waits until condition becomes true. Condition is checked with given interval.

### Syntax

```sqf
[condition, interval] spawn BIS_fnc_CPWaitUntil
```

### Parameters

- condition: Code - (Optional, default 

```sqf
{ true }
```

) condition to be checked
- interval: Number - (Optional, default 0.5) interval in which the condition will be checked

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[{ not alive player }, 2] spawn BIS_fnc_CPWaitUntil;
```
