## setRectangular

- Source: https://community.bistudio.com/wiki/setRectangular
- Revision: 319790
- Updated: 2022-05-13T09:24:53Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations

### Description

Set the shape of a location to be either rectangular or elliptical. Locations default shape is elliptical.

### Syntax

```sqf
location setRectangular set
```

### Parameters

- location: Location
- set: Boolean - true set rectangular, false set elliptical

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLocation setRectangular true;
```
