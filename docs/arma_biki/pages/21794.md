## forceFollowRoad

- Source: https://community.bistudio.com/wiki/forceFollowRoad
- Revision: 346816
- Updated: 2023-08-05T12:44:00Z

- Availability: arma3 1.64
- Groups: Unit Control

### Description

Forces the vehicle to stay on road.

### Syntax

```sqf
vehicle forceFollowRoad state
```

### Parameters

- vehicle: Object - vehicle
- state: Boolean - true: Force on road, false: default behaviour

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
car forceFollowRoad true;
```
