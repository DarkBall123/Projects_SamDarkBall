## ctrlText

- Source: https://community.bistudio.com/wiki/ctrlText
- Revision: 378493
- Updated: 2026-04-26T15:11:35Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns the text of a control of the currently active user dialog. This command can be used on static texts, buttons, edit lines and active texts as well as for images, where it returns the image path. Does not work on HTML control and returns empty string "". Since 2.05 supported control types are:
{{Columns|4|* CT_STATIC

* CT_EDIT
* CT_XKEYDESC
* CT_XBUTTON
* CT_SHORTCUTBUTTON
* CT_STRUCTURED_TEXT
* CT_BUTTON
* CT_ACTIVETEXT
}}

Since 2.20 CT_PROGRESS is also supported.

### Syntax

```sqf
ctrlText  idc
```

```sqf
ctrlText  controlName
```

### Parameters

- idc: Number - control ID
- controlName: Control - control

### Return Value

- String - the text or image path or texture is returned, dependent on the control type
- String - the text or image path or texture is returned, dependent on the control type

### Examples

#### Example 1

```sqf
_text = ctrlText 100;
```

#### Example 2

```sqf
_text = ctrlText _control;
```
