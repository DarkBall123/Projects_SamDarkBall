## group

- Source: https://community.bistudio.com/wiki/group
- Revision: 377962
- Updated: 2026-01-18T09:47:05Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Groups

### Description

Returns the group a unit is assigned to.

### Syntax

```sqf
group object
```

### Parameters

- object: Object

### Return Value

- Group - for dead units, the returned group equals grpNull.

### Examples

#### Example 1

```sqf
_playerGrp = group player;
```
