## else

- Revision: 364827
- Updated: 2024-06-16T09:33:24Z

- Availability: ofp 1.85, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Executes else code when if condition returns false.

### Syntax

```sqf
thenCode else  elseCode
```

### Parameters

- thenCode: Code
- elseCode: Code

### Return Value

- Array with [thenCode, elseCode]
* thenCode: Code
* elseCode: Code

### Examples

#### Example 1

```sqf
if (a > b) then { c = 0 } else { c = 1 };
```

#### Example 2

```sqf
if (a < b) then {
	hint "B is greater than A";
} else {
	hint "A is greater than B";
};
```
