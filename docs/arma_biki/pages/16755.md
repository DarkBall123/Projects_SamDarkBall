## ropeAttachedTo

- Source: https://community.bistudio.com/wiki/ropeAttachedTo
- Revision: 350037
- Updated: 2023-11-20T22:12:04Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Returns the owner of the first rope - the transport to which other entities are attached with ropes. This command is the opposite of ropeAttachedObjects. To return all owners see ropesAttachedTo.

400px

### Syntax

```sqf
ropeAttachedTo cargo
```

### Parameters

- cargo: Object - entity attached to the end of the first rope

### Return Value

- Object - a transport from which the first rope originates, the rope owner

### Examples

#### Example 1

```sqf
_heli = ropeAttachedTo veh1;
```
