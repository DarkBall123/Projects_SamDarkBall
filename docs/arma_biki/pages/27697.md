## ctrlTextColor

- Source: https://community.bistudio.com/wiki/ctrlTextColor
- Revision: 377354
- Updated: 2026-01-02T06:40:18Z

- Availability: arma3 2.02
- Groups: GUI Control

### Description

Returns control's text color

### Syntax

```sqf
ctrlTextColor control
```

### Parameters

- control: Control

### Return Value

- Color (RGBA) - text color

### Examples

#### Example 1

```sqf
ctrlTextColor _control;
```
