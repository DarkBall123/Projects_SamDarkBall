## speechVolume

- Source: https://community.bistudio.com/wiki/speechVolume
- Revision: 376983
- Updated: 2026-01-01T06:23:31Z

- Availability: arma3 2.04
- Groups: Sounds

### Description

Returns the current speech volume (set by fadeSpeech)

### Syntax

```sqf
**speechVolume**
```


### Return Value

- Number in range 0..2

### Examples

#### Example 1

```sqf
hint str speechVolume;
```
