## save3DENInventory

- Source: https://community.bistudio.com/wiki/save3DENInventory
- Revision: 330340
- Updated: 2022-08-31T21:24:40Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Saves the current state of entities' inventory to the Mission.sqm.

### Syntax

```sqf
save3DENInventory entities
```

### Parameters

- entities: Array of Eden Entity or Eden ID

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
save3DENInventory [_soldier1, _soldier2];
```

#### Example 2

```sqf
save3DENInventory [11234, 21251];
```
