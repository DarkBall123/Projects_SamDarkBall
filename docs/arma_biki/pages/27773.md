## ctrlSetTextColorSecondary

- Source: https://community.bistudio.com/wiki/ctrlSetTextColorSecondary
- Revision: 377731
- Updated: 2026-01-03T00:21:36Z

- Availability: ofp, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets the secondary text color of a text control.

### Syntax

```sqf
control ctrlSetTextColorSecondary color
```

### Parameters

- control: Control - text control
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrlText ctrlSetTextColorSecondary [1, 0.5, 0.1, 0.5];
```
