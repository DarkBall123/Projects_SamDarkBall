## get3DENLayer

- Source: https://community.bistudio.com/wiki/get3DENLayer
- Revision: 369778
- Updated: 2024-10-08T15:09:00Z

- Availability: arma3 2.18
- Groups: Eden Editor

### Description

Returns the provided entity's layer ID.

### Syntax

```sqf
get3DENLayer edenEntity
```

### Parameters

- edenEntity: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
hint format ["Entity %1 is in layer %2", typeOf _entity, get3DENLayer _entity];
```
