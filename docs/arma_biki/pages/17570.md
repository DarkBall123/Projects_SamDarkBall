## flagSide

- Source: https://community.bistudio.com/wiki/flagSide
- Revision: 376347
- Updated: 2025-10-07T17:04:44Z

- Availability: arma3 1.54
- Locality: argument global, effect local
- Groups: Flags

### Description

Returns Side of the local instance of the flag. A getter for setFlagSide.

### Syntax

```sqf
flagSide flag
```

### Parameters

- flag: Object - flag

### Return Value

- Side

### Examples

#### Example 1

```sqf
_flagSide =  flagSide aFlag;
```
