## endLoadingScreen

- Source: https://community.bistudio.com/wiki/endLoadingScreen
- Revision: 376713
- Updated: 2025-11-10T18:45:49Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: System

### Description

Finishes loading screen started by startLoadingScreen.

* Use BIS_fnc_endLoadingScreen to prevent potential usage conflicts.
* 2.18 The loading screen can be force-ended with the [ENDLOAD cheat code](Arma 3: Cheats#ENDLOAD).

### Syntax

```sqf
endLoadingScreen
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
startLoadingScreen ["Loading My Mission"];
// code
progressLoadingScreen 0.5;
// code
endLoadingScreen;
```

#### Example 2

```sqf
// this structure prevents error-prone or lengthy code to miss endLoadingScreen.
private _maxTime = diag_tickTime + 30; // max 30s of loading

startLoadingScreen ["Loading"];
private _handle = 0 spawn {
	// code that may crash or take too long
};

waitUntil { sleep .01; scriptDone _handle || diag_tickTime > _maxTime };
endLoadingScreen;
```
