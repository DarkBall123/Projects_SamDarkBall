## isNotEqualRef

- Source: https://community.bistudio.com/wiki/isNotEqualRef
- Revision: 338493
- Updated: 2023-03-10T17:30:50Z

- Availability: arma3 2.12
- Groups: Variables

### Description

Compares two values by reference, returns true if not equal.

### Syntax

```sqf
val1 isNotEqualRef val2
```

### Parameters

- val1: Anything
- val2: Anything

### Return Value

- Boolean - true if not the same reference

### Examples

#### Example 1

```sqf
_arr1 = [1,[2,[3]]];
_arr2 = _arr1;
_arr1 isEqualTo _arr2;		// true
_arr1 isNotEqualRef _arr2;	// false

_arr2 = +_arr1;				// array copy
_arr1 isEqualTo _arr2;		// true
_arr1 isNotEqualRef _arr2;	// true
```
