## overcast

- Source: https://community.bistudio.com/wiki/overcast
- Revision: 310759
- Updated: 2022-05-07T20:21:35Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Environment

### Description

Return the current overcast level. Zero is clear skies, one is maximum cloud cover.

### Multiplayer

Before Arma 3, each client and the server can have differing overcast values.

### Syntax

```sqf
overcast
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
_cloudLevel = overcast;
```
