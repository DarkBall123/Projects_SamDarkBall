## lightAttachObject

- Source: https://community.bistudio.com/wiki/lightAttachObject
- Revision: 377510
- Updated: 2026-01-02T06:50:14Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Lights

### Description

Attach light to given object at given position on object.

### Syntax

```sqf
light lightAttachObject [object, position]
```

### Parameters

- light: Object
- object: Object
- position: Position

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLight lightAttachObject [myVehicle, [-0.5,-0.25,1]];
```
