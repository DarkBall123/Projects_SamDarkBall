## curatorCameraAreaCeiling

- Source: https://community.bistudio.com/wiki/curatorCameraAreaCeiling
- Revision: 348441
- Updated: 2023-11-08T13:00:15Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Returns ceiling height for curator camera.

### Syntax

```sqf
curatorCameraAreaCeiling curatorObj
```

### Parameters

- curatorObj: Object - curator module

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _height = curatorCameraAreaCeiling BIS_curatorUnit;
```
