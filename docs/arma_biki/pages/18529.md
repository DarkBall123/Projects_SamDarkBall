## ctClear

- Source: https://community.bistudio.com/wiki/ctClear
- Revision: 309971
- Updated: 2022-05-05T12:17:02Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Removes all the lines from the RscControlsTable. Returns Nothing.

### Syntax

```sqf
ctClear ctrl
```

### Parameters

- ctrl: Control

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
ctClear _control;
```
