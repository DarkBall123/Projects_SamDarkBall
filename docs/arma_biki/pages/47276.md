- Availability: arma3 2.20
- Locality: argument local, effect global

### Description

Removes all magazines from the unit.

### Syntax

```sqf
removeAllMagazines unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllMagazines player;
```
