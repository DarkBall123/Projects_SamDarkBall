## lnbSetColorRight

- Source: https://community.bistudio.com/wiki/lnbSetColorRight
- Revision: 377728
- Updated: 2026-01-03T00:21:09Z

- Availability: arma3 1.00
- Groups: GUI Control - ListNBox

### Description

Sets the right color.

### Syntax

```sqf
lnbSetColorRight [idc, [row, column], color]
```

```sqf
ctrl lnbSetColorRight [<nowiki/>[row, column], color]
```

### Parameters

- idc: Number
- row: Number - index of the row
- column: Number - index of the column
- color: Color (RGBA)
- ctrl: Control
- row: Number - index of the row
- column: Number - index of the column
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_control lnbSetColorRight [[0, 0], [1,1,1,0.5]];
```
