## BIS fnc missionFlow

- Source: https://community.bistudio.com/wiki/BIS_fnc_missionFlow
- Revision: 364294
- Updated: 2024-05-06T09:38:39Z

- Availability: arma3 1.00
- Groups: Missions

### Description

This function is automatically run in post-init by a CfgFunctions declaration. If the mission contains a `missionFlow.fsm` file, it will be loaded, otherwise an empty, default one will be used.

### Syntax

```sqf
call BIS_fnc_missionFlow
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_missionFlow;
```
