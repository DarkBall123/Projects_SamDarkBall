## ATLToASL

- Source: https://community.bistudio.com/wiki/ATLToASL
- Revision: 377536
- Updated: 2026-01-02T06:53:28Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Positions

### Description

Converts a position from PositionATL to PositionASL

### Syntax

```sqf
ATLToASL pos
```

### Parameters

- pos: PositionATL - position to convert

### Return Value

- PositionASL

### Examples

#### Example 1

```sqf
ATLToASL (getPosATL player) isEqualTo getPosASL player;
```

#### Example 2

```sqf
_camPosASL = ATLToASL positionCameraToWorld [0,0,0];
```
