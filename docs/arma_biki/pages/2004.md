## keyName

- Source: https://community.bistudio.com/wiki/keyName
- Revision: 338910
- Updated: 2023-04-17T14:36:36Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Returns the name of a button with extra quotation marks (on the keyboard, mouse or joystick) with the given code.

### Syntax

```sqf
keyName dikCode
```

### Parameters

- dikCode: Number or 2.08 String

### Return Value

- String

### Examples

#### Example 1

```sqf
_name = keyName 28; // result is """Enter"""
```

#### Example 2

From Arma 3 v2.08:

```sqf
private _name = keyName "-1660944350"; // result is """Right Ctrl+G"""
```
