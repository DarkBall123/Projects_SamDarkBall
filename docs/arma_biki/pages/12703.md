## Arma 3: Replacement Config Tutorial

- Source: https://community.bistudio.com/wiki/Arma_3:_Replacement_Config_Tutorial
- Revision: 369678
- Updated: 2024-10-02T11:01:42Z

{{TOC|side}}
This is a guide how to create an addon to replace the look of a given weapon/unit/vehicle with a different model from another community made addon. To avoid issues the replacement should be of the same type and behavior as close as possible. Generally the goal is to achieve a better visual look or better sound experience.

### Required tools

- A good text editor; best with [regular expression](http://www.regular-expressions.info) support. Recommended: [EditPadPro](http://www.editpadpro.com) (and/or [PowerGREP](http://www.powergrep.com))
- Ability to create a config dump from system memory while the game is running
- A tool to create pbos. Recommended: [mikero's tool suite](https://mikero.bytex.digital/) (makePbo)

### Overall process

#### Basic preparation

1. Download the desired addon(s) you want to use for the replacement
1. Load it/them via a modfolder
1. Make a config overview for the above mentioned **config dump** mission in the editor; **cfgVehicles** for infantry or vehicles, **cfgWeapons** for weapons (or make subsets like CAManBase, AllVehicles, Tank, Cars, etc); for sounds **cfgAmmo** and **cfgMagazines** are also relevant and a few other specific classes for UI or terrain sounds
1. Extract the classes of the desired vehicle/infantry/weapon item/set/type/faction to replace
1. Extract the classes of the replacements
1. Clean both their content for all but the relevant parameters (see below for more information); this regex will remove all but the mentioned parameters:

 ^(?!.*?(^\tclass|parameterA|parameterB|etc)).*\r\n

#### Preparing the addon

1. Create a new folder in your @test\addons modfolder
1. Give the folder a descriptive name like YourTAG_ReplacementSet_With_AddonName
1. Create an empty text file
1. Rename it to config.cpp ([make sure to have windows show file extensions](http://windows.microsoft.com/en-us/windows/show-hide-file-name-extensions#show-hide-file-name-extensions))
1. Add a cfgPatches header - see sample below
  1. Give it the same name as the folder
  1. Add the cfgPatches class dependency of the addon used for the replacement in requiredAddons definition
1. Add the cfgWeapons/cfgVehicles body
1. Add the desired vehicles/infantry/weapons classes you want to replace
  1. It should include the base class
  1. The definitions should be strip of all unnecessary parameters at this point
  1. Disable all the remaining parameters (by adding '//' at the start of each line to comment it out) - they only serve as a reminder what you **have to** replace for a given class

	};

#### Defining the replacement

1. Next you have to select which addon unit should replace each given source class; generally one copies GL over GL, MG over MG and so on
1. You do so by copying the parameters of the addon class into your replacement addon for the given class
1. **Very important** is to keep the parameter **inheritance** in mind in both addon and source class; in other words you need to check carefully where each required parameter is set and if you need to replace it in the given/specific class or at the base class level
To make some examples for infantry classes:
- class Wounds or the model are often set only in the base class; except for specific types like snipers, officer, pilot/crew classes
- whereas the linkedItems list/array is mostly defined per specific class
- make sure what parameters are set in the base class of the replacement addon

#### Building the addon

1. Once each class of has the required parameters set/overwritten with new definitions from the desired addon
1. Check your config for error (brackets, semicolons, etc) - rapify/mikero's tools have the feature to verify a config for correctness
1. Build your addon folder to pbo
1. Load your new pbo in a modfolder, as well as the addon it depends on
1. Verify in the editor that the replacement works as desired and that you have no onscreen errors and none in the rpt

### Different types

#### Visual replacement

##### Infantry

Relevant config parameters:

- model
- hiddenSelections[]
- hiddenSelectionsTextures[]
- class Wounds
- nakedUniform
- uniformClass
- linkedItems[]
- respawnlinkedItems[]
- backpack (somewhat problematic as it may have gameplay impact - better to replace the backpack look itself in its definition/class)

Sample config:

```
class CfgPatches
{
	class AiA_ModelReplacement_BAF_With_STALKERGBs_BritishInfantry
	{
		units[] = {};
		weapons[] = {};
		requiredVersion = 0.1;
		requiredAddons[] = { "AiA_ActivateA3Models_ModelReplacement_CO", "STKR_BritMTP" };
	};
};
class CfgVehicles
{
	class SoldierWB;

	class BAF_Soldier_base_EP1 : SoldierWB
	{
		model = "\STKR_BritMTP\Rifleman";
		uniformClass = "STKR_UBACS";
		backpack = "Brit_MLode";
		linkedItems[] = { "STKR_Osprey_R", "STKR_MK7_Scrim", "STKR_HMNVS", "ItemMap", "ItemCompass", "ItemWatch", "ItemRadio" };
		respawnLinkedItems[] = { "STKR_Osprey_R", "STKR_MK7_Scrim", "NVGoggles", "ItemMap", "ItemCompass", "ItemWatch", "ItemRadio" };
		class Wounds
		{
			tex[] = {};
			mat[] = { /* ... */ };
		};
	};
// ...
};
```
