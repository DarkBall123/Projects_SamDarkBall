## BIS fnc sceneSetBehaviour

- Source: https://community.bistudio.com/wiki/BIS_fnc_sceneSetBehaviour
- Revision: 349150
- Updated: 2023-11-08T14:49:48Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Scenes

### Description

Enables / disables a specific set of AI units, usable for cutscenes.

### Syntax

```sqf
param call BIS_fnc_sceneSetBehaviour
```

### Parameters

- String - string to toggle AI ("enableAI","disableAI")
- Array - AI units that should be affected by function.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["disableAI", [unit1, player, unit2, unit3]] call BIS_fnc_sceneSetBehaviour;
```
