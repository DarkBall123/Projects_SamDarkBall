- Updated: 2023-11-08T14:52:19Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Returns is revive is enabled or not for the unit.

### Syntax

```sqf
[unit] call BIS_fnc_reviveEhRespawn
```

### Parameters

- unit: Object - unit that is checked

### Return Value

- Boolean - true if enabled, false if not

### Examples

#### Example 1

```sqf
private _reviveEnabled = [BIS_unit] call BIS_fnc_reviveEnabled;
```
