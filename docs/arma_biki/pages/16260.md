## BIS fnc moduleEffectsSmoke

- Source: https://community.bistudio.com/wiki/BIS_fnc_moduleEffectsSmoke
- Revision: 352193
- Updated: 2024-02-01T23:25:58Z

- Availability: arma3 1.00
- Groups: Modules

### Description

Creates smoke on position of module (called usually by BIS_fnc_moduleEffectsEmitterCreator).Mainly meant to be used by modules available in Eden Editor

### Syntax

```sqf
[module] call BIS_fnc_moduleEffectsSmoke
```

### Parameters

- module: Object - module

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_module] call BIS_fnc_moduleEffectsSmoke;
```
