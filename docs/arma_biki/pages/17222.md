## diag activeMissionFSMs

- Source: https://community.bistudio.com/wiki/diag_activeMissionFSMs
- Revision: 349639
- Updated: 2023-11-16T21:59:22Z

- Availability: arma3 1.44
- Groups: Diagnostic

### Description

Returns array with active Mission FSMs. To see number of all scripts currently in the scheduler use diag_activeScripts.

### Syntax

```sqf
diag_activeMissionFSMs
```


### Return Value

- Array - format [<nowiki/>[name, state, timeout],...]:
* name: String 
* state:
* timeout:

### Examples

#### Example 1

```sqf
{ systemChat str _x } forEach diag_activeMissionFSMs;
```
