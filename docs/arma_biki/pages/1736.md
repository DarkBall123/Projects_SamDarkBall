## sliderSpeed

- Source: https://community.bistudio.com/wiki/sliderSpeed
- Revision: 378110
- Updated: 2026-02-16T11:24:51Z

- Availability: ofp 1.85, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns slider step value for line and page movement of CT_SLIDER or CT_XSLIDER.

### Syntax

```sqf
sliderSpeed idc
```

```sqf
sliderSpeed control
```

### Parameters

- idc: Number: idc of the control
- control: Control

### Return Value

- Array format [minSpeed, maxSpeed, 2.08 step]
- Array format [minSpeed, maxSpeed, 2.08 step]

### Examples

#### Example 1

```sqf
sliderSpeed _ctrlSlider params ["_min", "_max", "_step"];
```
