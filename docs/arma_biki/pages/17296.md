## roleDescription

- Source: https://community.bistudio.com/wiki/roleDescription
- Revision: 329074
- Updated: 2022-07-21T23:46:21Z

- Availability: arma3 1.48
- Groups: Object Manipulation, Multiplayer

### Description

Returns unit description set in the editor and visible on role selection screen in multiplayer.

### Syntax

```sqf
roleDescription unit
```

### Parameters

- unit: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
_playerRole = roleDescription player;
```
