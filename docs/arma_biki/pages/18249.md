## unitAimPositionVisual

- Source: https://community.bistudio.com/wiki/unitAimPositionVisual
- Revision: 377836
- Updated: 2026-01-03T04:32:14Z

- Availability: arma3 1.64
- Locality: argument global
- Groups: Object Manipulation, Render Time Scope

### Description

Returns the position on the unit other units can aim at in render scope. See also aimPos, unitAimPosition.

### Syntax

```sqf
unitAimPositionVisual unit
```

### Parameters

- unit: Object

### Return Value

- PositionAGL - position

### Examples

#### Example 1

```sqf
unitAimPositionVisual player;
```

### See Also

unitAimPosition aimPos eyePos getPosASL weaponDirection

Be careful when using it!
