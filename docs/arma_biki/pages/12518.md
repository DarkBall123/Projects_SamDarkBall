## markAsFinishedOnSteam

- Source: https://community.bistudio.com/wiki/markAsFinishedOnSteam
- Revision: 369150
- Updated: 2024-09-03T10:34:38Z

- Availability: arma3 0.74
- Groups: Mission Information

### Description

Marks current mission as finished on Steam. Returns true if Steam query is successfully started or false otherwise.

### Syntax

```sqf
**markAsFinishedOnSteam**
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
markAsFinishedOnSteam;
endMission "END1";
```
