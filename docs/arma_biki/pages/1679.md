## clearWeaponPool

- Source: https://community.bistudio.com/wiki/clearWeaponPool
- Revision: 318753
- Updated: 2022-05-13T09:21:26Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool

### Description

Remove all weapons from the weapon pool, of which the player may choose in the following missions. Available in campaigns only.

### Syntax

```sqf
clearWeaponPool
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
clearWeaponPool;
```
