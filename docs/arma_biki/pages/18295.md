## menuSetData

- Source: https://community.bistudio.com/wiki/menuSetData
- Revision: 378345
- Updated: 2026-04-02T16:31:30Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Sets data into menu entry on given path.

### Syntax

```sqf
menuSetData [idc, path, data]
```

```sqf
control menuSetData [path, data]
```

### Parameters

- idc: Number
- path: Tree View Path
- data: String
- control: Control
- path: Tree View Path
- data: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuSetData [[0, 1], "[true, player, 'Hello World!', 1337]"];
```
