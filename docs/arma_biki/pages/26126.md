## isGameFocused

- Source: https://community.bistudio.com/wiki/isGameFocused
- Revision: 309152
- Updated: 2022-05-03T14:13:47Z

- Availability: arma3 1.96
- Groups: System

### Description

Returns the state of game focus changed by pressing {{Controls|ALT|TAB}} or similar action.

### Syntax

```sqf
isGameFocused
```


### Return Value

- Boolean - true if game window is focused, false if not

### Examples

#### Example 1

```sqf
if (!isGameFocused) then { endMission "End" };
```
