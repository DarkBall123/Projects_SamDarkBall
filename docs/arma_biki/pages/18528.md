## ctAddHeader

- Source: https://community.bistudio.com/wiki/ctAddHeader
- Revision: 377658
- Updated: 2026-01-02T09:02:08Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Adds a header line of controls according to the HeaderTemplate class. Note that rows and headers are indexed separately.

### Syntax

```sqf
ctAddHeader control
```

### Parameters

- control: Control

### Return Value

- Array with [headerIndex, createdControls]
* headerIndex: Number
* createdControls: Array of Controls

### Examples

#### Example 1

```sqf
private _array = ctAddHeader _control;
```
