## BIS fnc taskType

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskType
- Revision: 352026
- Updated: 2024-02-01T23:24:23Z

- Availability: arma3 1.58
- Locality: argument global
- Groups: Tasks

### Description

Returns type of given task. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskID call BIS_fnc_taskType
```

### Parameters

- taskID: String - task ID

### Return Value

- String - task type or type 'Default' if not defined.

### Examples

#### Example 1

```sqf
["BIS_Task_01"] call BIS_fnc_taskType;
```
