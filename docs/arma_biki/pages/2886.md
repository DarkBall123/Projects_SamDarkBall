## ctrlSetForegroundColor

- Source: https://community.bistudio.com/wiki/ctrlSetForegroundColor
- Revision: 377732
- Updated: 2026-01-03T00:21:53Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets foreground color of the given control.
Also try ctrlSetTextColor, if this command doesn't have the desired effect.

### Syntax

```sqf
control ctrlSetForegroundColor color
```

### Parameters

- control: Control
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetForegroundColor [1, 0, 0, 1];
```
