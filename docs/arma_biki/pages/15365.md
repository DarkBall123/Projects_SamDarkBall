1.22 Algorithm:

```sqf
Vector1 = [x1,y1,z1]; Vector2 = [x2,y2,z2];
Result = (x1 * x2) + (y1 * y2) + (z1 * z2);
```

It is recommended to use vectorDotProduct instead of BIS_fnc_dotProduct.
