## orderGetIn

- Source: https://community.bistudio.com/wiki/orderGetIn
- Revision: 377143
- Updated: 2026-01-01T10:31:44Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Control

### Description

Force all units in the array to get in or out of their assigned vehicles. Units must be assigned to a vehicle before this command will do anything.
See AI Group Vehicle Management for more information.

### Syntax

```sqf
unitArray orderGetIn order
```

### Parameters

- unitArray: Array of Objects
- order: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_unitOne, _unitTwo] orderGetIn true;
```

#### Example 2

```sqf
[_unitOne, _unitTwo] orderGetIn false;
```
