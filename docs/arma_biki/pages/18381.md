## getPilotCameraPosition

- Source: https://community.bistudio.com/wiki/getPilotCameraPosition
- Revision: 377379
- Updated: 2026-01-02T06:43:43Z

- Availability: arma3 1.64
- Locality: argument global
- Groups: Pilot Camera

### Description

Returns model space coordinates of the object airplane or helicopter pilotCamera.

### Syntax

```sqf
getPilotCameraPosition object
```

### Parameters

- object: Object

### Return Value

- PositionRelative - offset relative to the model centre. Returns [0,0,0] if object has no pilotCamera.

### Examples

#### Example 1

```sqf
_pilotCamPos = getPilotCameraPosition vehicle player;
```
