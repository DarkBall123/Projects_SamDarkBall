## BIS fnc EXP camp playTimelineVideo

- Source: https://community.bistudio.com/wiki/BIS_fnc_EXP_camp_playTimelineVideo
- Revision: 348964
- Updated: 2023-11-08T14:45:40Z

- Availability: arma3 1.62
- Locality: effect local
- Groups: Campaign

### Description

Plays a video with BIS_fnc_EXP_camp_setCinematicMode enabled.

### Syntax

```sqf
[videoPath] call BIS_fnc_EXP_camp_playTimelineVideo
```

### Parameters

- videoPath: String - path to video

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"someVideoPath" call BIS_fnc_EXP_camp_playTimelineVideo;
```
