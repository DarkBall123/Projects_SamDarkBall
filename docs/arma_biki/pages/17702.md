## isEqualType

- Source: https://community.bistudio.com/wiki/isEqualType
- Revision: 325195
- Updated: 2022-07-01T14:49:21Z

- Availability: arma3 1.54
- Groups: Variables

### Description

Compares two values' types. A much faster alternative to 

```sqf
typeName a == typeName b
```

.

### Syntax

```sqf
val1 isEqualType val2
```

### Parameters

- val1: Anything
- val2: Anything

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _var = [1,2,3];
_var isEqualType 0; // false
_var isEqualType []; // true
```
