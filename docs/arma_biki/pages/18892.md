## BIS fnc getVehicleCustomization

- Source: https://community.bistudio.com/wiki/BIS_fnc_getVehicleCustomization
- Revision: 363635
- Updated: 2024-04-08T21:57:47Z

- Availability: arma3 1.00
- Groups: Vehicles

### Description

Return vehicle customization settings.

### Syntax

```sqf
[object, class] call BIS_fnc_getVehicleCustomization
```

### Parameters

- object: Object
- class: String - (Optional, default "") object class override

### Return Value

- Array in format: [<texture>, <animations>], for example ([["wasp",1],["AddTread",0,"AddTread_Short",1]])

### Examples

#### Example 1

```sqf
[vehicle player] call BIS_fnc_getVehicleCustomization;
```
