## getMarkerSize

- Source: https://community.bistudio.com/wiki/getMarkerSize
- Revision: 377676
- Updated: 2026-01-02T09:02:39Z

- Availability: ofp 1.21, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Markers

### Description

Returns the size of the given marker. A getter for setMarkerSize and an alias of markerSize.

### Syntax

```sqf
getMarkerSize markerName
```

### Parameters

- markerName: String

### Return Value

- Array with [a_axis, b_axis]
* a_axis: Number - 1/2 width of marker
* b_axis: Number - 1/2 height of marker

### Examples

#### Example 1

```sqf
"MarkerOne" setMarkerSize [100,200];
_size = getMarkerSize "MarkerOne"; //returns [100,200]
```
