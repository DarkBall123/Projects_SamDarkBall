## visibleGPS

- Source: https://community.bistudio.com/wiki/visibleGPS
- Revision: 378434
- Updated: 2026-04-07T19:38:22Z

- Availability: arma3 1.22
- Groups: Interaction

### Description

Checks if the player has GPS receiver (minimap) opened and visible.

### Syntax

```sqf
visibleGPS
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (visibleGPS) then
{
	hint "GPS is visible";
};
```
