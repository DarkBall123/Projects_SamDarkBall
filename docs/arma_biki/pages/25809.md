## removeDiaryRecord

- Source: https://community.bistudio.com/wiki/removeDiaryRecord
- Revision: 340844
- Updated: 2023-05-10T15:17:04Z

- Availability: arma3 1.96
- Locality: effect local
- Groups: Briefing

### Description

Remove a log record.

### Syntax

```sqf
unit removeDiaryRecord [subject, diaryRecord]
```

### Parameters

- unit: Object
- subject: String
- diaryRecord: Diary Record

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
private _diaryRecord = player createDiaryRecord ["Diary", ["Subject", "Text"]];
// ...
player removeDiaryRecord ["Diary", _diaryRecord];
```
