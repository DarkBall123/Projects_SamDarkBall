## difficultyEnabledRTD

- Source: https://community.bistudio.com/wiki/difficultyEnabledRTD
- Revision: 339089
- Updated: 2023-04-26T10:54:08Z

- Availability: arma3 1.34
- Groups: RTD, Difficulty

### Description

Returns true if Advanced Flight Model is enabled.
Forcing of rotorlib simulation could be done with mission param forceRotorLibSimulation.

### Syntax

```sqf
difficultyEnabledRTD
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_rtdOn = difficultyEnabledRTD;
```

### See Also

difficultyEnabled isObjectRTD forceRotorLibSimulation
