## unassignTeam

- Source: https://community.bistudio.com/wiki/unassignTeam
- Revision: 309954
- Updated: 2022-05-05T12:17:00Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Groups

### Description

Unassigns the unit (in the case of a vehicle its commander unit) from his team. This is equal to unit assignTeam "MAIN".

### Syntax

```sqf
unassignTeam vehicleName
```

### Parameters

- vehicleName: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
unassignTeam _soldier2;
```

### See Also

assignTeam dissolveTeam
