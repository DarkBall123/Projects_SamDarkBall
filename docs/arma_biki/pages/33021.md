## ctrlSetShadow

- Source: https://community.bistudio.com/wiki/ctrlSetShadow
- Revision: 330159
- Updated: 2022-08-23T12:23:54Z

- Availability: arma3 2.10
- Groups: GUI Control

### Description

Sets 'shadow' property of the control:
* 0 - no shadow
* 1 - shadow
* 2 - outline

### Syntax

```sqf
control ctrlSetShadow shadow
```

### Parameters

- control: Control
- shadow: Number - shadow value, see description

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetShadow 1;
```
