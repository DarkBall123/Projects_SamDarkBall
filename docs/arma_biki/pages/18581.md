## getForcedFlagTexture

- Source: https://community.bistudio.com/wiki/getForcedFlagTexture
- Revision: 348629
- Updated: 2023-11-08T13:46:06Z

- Availability: arma3 1.70
- Groups: Flags

### Description

A getter for forceFlagTexture. Forced texture is different from your normal flag texture, which can be retrieved with flagTexture

### Syntax

```sqf
getForcedFlagTexture object
```

### Parameters

- object: Object - vehicle, unit or flag pole

### Return Value

- String

### Examples

#### Example 1

```sqf
getForcedFlagTexture player;
```
