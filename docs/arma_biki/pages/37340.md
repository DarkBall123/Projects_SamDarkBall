## isRemoteControlling

- Source: https://community.bistudio.com/wiki/isRemoteControlling
- Revision: 347218
- Updated: 2023-09-05T16:49:02Z

- Availability: arma3 2.14
- Locality: argument local
- Groups: Remote Control

### Description

Returns true if the given player is remote-controlling a unit.
See also Remote Control Tutorial.

### Syntax

```sqf
isRemoteControlling person
```

### Parameters

- person: Object - a player

### Return Value

- Boolean - true if the given player is remote controlling a unit

### Examples

#### Example 1

```sqf
if (isRemoteControlling player) then
{
	hint format ["You are controlling %1", remoteControlled player];
}
else
{
	hint "Why not remote-control something?";
};
```
