Arma 3 comes with a variety of shooting targets. Most of these targets come with a somewhat hidden functionality which is explained on this page.

### Changing pop-up-behaviour

The pop-up-behaviour can be changed by setting the variable</tt>noPop</tt> in missionNamespace.

```sqf
missionNamespace setVariable ["noPop", true];	// will prevent the targets from popping up again once they were hit
missionNamespace setVariable ["noPop", false];	// targets will pop up normally again after they were hit
```

### Animating the targets

All of the above listed targets have an animation source called `terc`. This can be used to change the angle of the target.
Let's say we have a pop up target place in the editor with the name `popUpTarget`:

```sqf
popUpTarget animateSource ["terc", 0.5];	// target will have an angle of 45°
popUpTarget animateSource ["terc", 1];		// target will have an angle of 180°
popUpTarget animateSource ["terc", 0];		// target will have an angle of 90° e.g. the target will stand up straight
```

**Random Fact:** "terc" is Czech and means Object.

### Example mission with "noPop" and "terc"

1. Open a new mission in Eden Editor and save it.
1. Place three pop-up targets. Make sure they are compatible. See Arma 3: Shooting Targets#Targets.
1. Name the pop-up targets `target_0`, `target_1`, `target_2`.
1. Place any object you would like to use to control the targets' states and name it `flag_control_targets`.
1. Navigate to *Menu Strip* → *Scenario* → *Open Scenario Folder*.
1. In that folder create a file called `initPlayerLocal.sqf`. See Event Scripts for more information.
1. Paste the following code into that file and save it.

```sqf
// Three local actions are added to the object flag_control_targets. These actions are available for every player
// Rset the animation state of all three targets
flag_control_targets addAction ["Reset Targets", { [target_0, target_1, target_2] apply { _x animateSource ["terc", 0] } }];
```

```sqf
// Disable the pop-up functionality by setting "noPop" to true globally
flag_control_targets addAction ["Disable pop-up", { missionNamespace setVariable ["noPop", true, true] }];
```

```sqf
// Enable the pop-up functionality by setting "noPop" to false globally. The targets will not automatically reset. Use the Reset Targets action
flag_control_targets addAction ["Enable pop-up", { missionNamespace setVariable ["noPop", false, true] }];
```

1. Preview the mission and play around with the targets.
