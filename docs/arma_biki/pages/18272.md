## set3DENModelsVisible

- Source: https://community.bistudio.com/wiki/set3DENModelsVisible
- Revision: 351312
- Updated: 2023-11-27T04:55:31Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Enables or disables trigger area visibility.

### Syntax

```sqf
set3DENModelsVisible [map, scene]
```

### Parameters

- map: Boolean
- scene: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
set3DENModelsVisible [true, true];
```
