## setTrafficGap

- Source: https://community.bistudio.com/wiki/setTrafficGap
- Revision: 319775
- Updated: 2022-05-13T09:24:52Z

- Availability: tkoh 1.01, arma3 0.50
- Groups: Environment

### Description

Set the average gap between ambient cars in a rectangle (in meters). This command does nothing in Arma 3.

### Syntax

```sqf
setTrafficGap [gap, xMin, xMax, zMin, zMax]
```

### Parameters

- gap: Number - average gap between ambient cars (in meters)
- xMin: Number - western border of the affected rectangle
- xMax: Number - eastern border of the affected rectangle
- zMin: Number - southern border of the affected rectangle
- zMax: Number - northern border of the affected rectangle

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setTrafficGap [50, 31000, 32500, 28000, 32000];
```
