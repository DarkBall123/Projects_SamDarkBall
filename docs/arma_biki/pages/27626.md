## configOf

- Source: https://community.bistudio.com/wiki/configOf
- Revision: 309234
- Updated: 2022-05-04T10:23:40Z

- Availability: arma3 2.00
- Locality: argument global
- Groups: Config

### Description

Returns config path of the provided object.

### Syntax

```sqf
configOf object
```

### Parameters

- object: Object

### Return Value

- Config

### Examples

#### Example 1

```sqf
configOf player; // returns bin\config.bin/CfgVehicles/B_W_Soldier_TL_F
```
