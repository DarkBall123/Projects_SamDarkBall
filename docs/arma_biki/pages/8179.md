## boundingCenter

- Source: https://community.bistudio.com/wiki/boundingCenter
- Revision: 377382
- Updated: 2026-01-02T06:43:49Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns the position of the original (loaded) center of an object in model coordinates. Despite its name, it has nothing to do with boundingBox or boundingBoxReal, it returns offset where `[0, 0, 0]` was Object Builder / Oxygen 2 when model was created.

### Syntax

```sqf
boundingCenter object
```

### Parameters

- object: Object

### Return Value

- PositionRelative

### Examples

#### Example 1

```sqf
_center = boundingCenter TruckOne;
```
