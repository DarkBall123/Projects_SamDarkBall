## diag getTerrainGrid

- Source: https://community.bistudio.com/wiki/diag_getTerrainGrid
- Revision: 322636
- Updated: 2022-06-20T11:53:38Z

- Availability: arma3 2.04
- Groups: Diagnostic

### Description

Returns terrain cell size (size of each grid cell in the Heightmap).
This command is subject to be removed and replaced with: getTerrainInfo|arma3|2.10

### Syntax

```sqf
diag_getTerrainGrid
```


### Return Value

- Number - terrain grid

### Examples

#### Example 1

```sqf
private _terrainGrid = diag_getTerrainGrid;
```
