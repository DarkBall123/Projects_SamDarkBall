## resetCamShake

- Source: https://community.bistudio.com/wiki/resetCamShake
- Revision: 321939
- Updated: 2022-05-22T12:55:05Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Camera Control

### Description

Stops any ongoing camera shake effects. Does not prevent new effects from being created. To disallow new effects altogether, enableCamShake should be used.

### Syntax

```sqf
resetCamShake
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
resetCamShake;
```
