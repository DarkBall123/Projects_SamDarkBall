## forceEnd

- Source: https://community.bistudio.com/wiki/forceEnd
- Revision: 318934
- Updated: 2022-05-13T09:22:03Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Mission Information

### Description

Forces mission ending (set with endMission) even if a camera effect or any another condition delays the endMission (mostly in {{ofp}}).

### Syntax

```sqf
forceEnd
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
forceEnd;// in an ending trigger to ensure no camera is delaying mission ending
```
