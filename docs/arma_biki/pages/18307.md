## menuChecked

- Source: https://community.bistudio.com/wiki/menuChecked
- Revision: 378328
- Updated: 2026-04-02T16:30:35Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Returns if item on given path is checked or not.

### Syntax

```sqf
menuChecked [idc, path]
```

```sqf
control menuChecked path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- Boolean
- Boolean

### Examples

#### Example 1

```sqf
private _isChecked = findDisplay 313 displayCtrl 120 menuChecked [0, 1];
```
