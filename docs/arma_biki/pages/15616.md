## BIS fnc swapVars

- Source: https://community.bistudio.com/wiki/BIS_fnc_swapVars
- Revision: 328403
- Updated: 2022-07-13T16:00:49Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Variables

### Description

Swaps the values of two variables **passed as String**.

Nothing is returned as this function modifies the variables directly.

### Syntax

```sqf
[variableName1, variableName2] call BIS_fnc_swapVars
```

### Parameters

- variableName1: String
- variableName2: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
private _a = 1;
_b = 2;
["_a", "_b"] call BIS_fnc_swapVars;
_a == 2; // true
_b == 1; // true
```
