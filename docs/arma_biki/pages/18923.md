## BIS fnc 3DENToolbar

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENToolbar
- Revision: 349085
- Updated: 2023-11-08T14:47:24Z

- Availability: arma3 1.58
- Groups: Eden Editor

### Description

Interacts with the Eden Editor toolbar

### Syntax

```sqf
[mode] call BIS_fnc_3DENToolbar
```

### Parameters

- mode: String - can be:

{{Columns|3|
*"init"
*"VerticalToggle"
*"SurfaceSnapToggle"
*"MoveGridToggle"
*"RotateGridToggle"
*"ScaleGridToggle"
*"WidgetToggle"
*"ToggleMap"
*"ToggleVision"
*"ToggleFlashlight"
*"MissionSection"
}}

### Return Value

- Boolean - returns true if it was added successfully

### Examples

#### Example 1

```sqf
"ToggleFlashlight" call BIS_fnc_3DENToolbar;
```
