## setObjectMaterial

- Source: https://community.bistudio.com/wiki/setObjectMaterial
- Revision: 370026
- Updated: 2024-10-27T23:18:53Z

- Availability: arma3 0.50
- Locality: argument global, effect local
- Groups: Object Manipulation

### Description

Sets material of object selection. The selection number is defined through the hiddenselection[] = {} array in the vehicle's config (starting with 0).

### Syntax

```sqf
obj setObjectMaterial [selectionNumber, material]
```

### Parameters

- obj: Object
- selectionNumber: Number or String (since 2.10).
- material: String - material path. Since 2.20 using **"#reset"** would reset to default material.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
car setObjectMaterial [0,"A3\Structures_F\Data\Windows\window_set.rvmat"];
car setObjectMaterial [1,"A3\Structures_F\Data\Windows\window_set.rvmat"];
```
