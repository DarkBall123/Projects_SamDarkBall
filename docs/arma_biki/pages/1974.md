## camSetFocus

- Source: https://community.bistudio.com/wiki/camSetFocus
- Revision: 377681
- Updated: 2026-01-02T09:02:47Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Sets camera focus range. It does not automatically commit changes (see camCommit). Use [-1, -1] to disable focus completely.

### Syntax

```sqf
camera camSetFocus focusRange
```

### Parameters

- camera: Object
- focusRange: Array with [distance, blur]
* distance: Number
* blur: Number -  sets the camera focus blur

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_camera camSetFocus [50, 1];
```
