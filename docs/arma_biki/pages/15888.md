## BIS fnc enemyTargets

- Source: https://community.bistudio.com/wiki/BIS_fnc_enemyTargets
- Revision: 326899
- Updated: 2022-07-12T21:44:37Z

- Availability: arma3 1.00
- Groups: Combat

### Description

Return list of nearby enemy targets for given unit.

### Syntax

```sqf
unit call BIS_fnc_enemyTargets
```

### Parameters

- unit - Object: unit that is inspected

### Return Value

- Array of enemies, empty if unit doesn't know about any enemy

### Examples

#### Example 1

```sqf
private _targets = _unit call BIS_fnc_enemyTargets;
```
