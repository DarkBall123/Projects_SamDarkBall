## get3DENAttributes

- Source: https://community.bistudio.com/wiki/get3DENAttributes
- Revision: 370464
- Updated: 2024-12-15T11:56:46Z

- Availability: arma3 2.18
- Groups: Eden Editor

### Description

Retrieve all attributes and their values of the specified (optional) category.

### Syntax

```sqf
entity get3DENAttributes category
```

### Parameters

- entity: Object
- category: String ("" to get all attributes, typeOf to get Object Specific attributes)

### Return Value

- Array
