## set3DENLogicType

- Source: https://community.bistudio.com/wiki/set3DENLogicType
- Revision: 310924
- Updated: 2022-05-07T20:45:59Z

- Availability: arma3 1.70
- Groups: Eden Editor

### Description

Sets the new type of Logic object(s). For other objects use set3DENObjectType.

### Syntax

```sqf
objects set3DENLogicType classname
```

### Parameters

- objects: Array of Objects
- classname: String - name of the cfgVehicles class

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[get3DENSelected "logic" select 0] set3DENLogicType "MiscOR_F";
```
