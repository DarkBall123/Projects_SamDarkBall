## keys

- Source: https://community.bistudio.com/wiki/keys
- Revision: 377092
- Updated: 2026-01-01T09:48:45Z

- Availability: arma3 2.02
- Groups: HashMap

### Description

Retrieves a list of all keys in a HashMap.

### Syntax

```sqf
keys hashMap
```

### Parameters

- hashMap : HashMap

### Return Value

- Array of Anything - array of all keys in the HashMap

### Examples

#### Example 1

```sqf
keys _myHashMap;
```
