## lnbSetColor

- Source: https://community.bistudio.com/wiki/lnbSetColor
- Revision: 377345
- Updated: 2026-01-02T06:40:01Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListNBox

### Description

Sets the color of the item with the given position of the 2D listbox. Color is in format Color (RGBA).

### Syntax

```sqf
lnbSetColor [idc, [row, column], color]
```

```sqf
ctrl lnbSetColor [<nowiki/>[row, column], color]
```

### Parameters

- idc: Number
- row: Number
- column: Number
- color: Color (RGBA)
- ctrl: Control
- row: Number
- column: Number
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_ctrl lnbSetColor [[0,0], [1,0,0,1]];
```
