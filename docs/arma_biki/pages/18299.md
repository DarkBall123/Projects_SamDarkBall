## menuClear

- Source: https://community.bistudio.com/wiki/menuClear
- Revision: 339137
- Updated: 2023-04-26T10:55:01Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Removes all entries from given menu strip.

### Syntax

```sqf
menuClear idc
```

```sqf
menuClear control
```

### Parameters

- idc: Number
- control: Control

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
menuClear (findDisplay 313 displayCtrl 120); // removes all entries from Eden Editor. Restart the editor to reset the menu.
```
