## ctrlSetFontH3

- Source: https://community.bistudio.com/wiki/ctrlSetFontH3
- Revision: 323048
- Updated: 2022-06-28T21:43:10Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H3 font of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontH3 fontName
```

### Parameters

- controlName: Control
- fontName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontH3 "TahomaB";
```
