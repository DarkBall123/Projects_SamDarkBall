## removeAllPrimaryWeaponItems

- Source: https://community.bistudio.com/wiki/removeAllPrimaryWeaponItems
- Revision: 310215
- Updated: 2022-05-05T13:10:44Z

- Availability: arma3 0.70
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes all items from primaryWeapon, except magazine.

### Syntax

```sqf
removeAllPrimaryWeaponItems unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllPrimaryWeaponItems player;
```
