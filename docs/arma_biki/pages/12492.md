## tvText

- Source: https://community.bistudio.com/wiki/tvText
- Revision: 330021
- Updated: 2022-08-15T14:44:30Z

- Availability: arma3 0.74
- Groups: GUI Control - Tree View

### Description

Returns shown text in the item on given path. IDC means id of parent Tree View.

### Syntax

```sqf
tvText [idc, path]
```

```sqf
control tvText path
```

### Parameters

- idc: Number
- path: Array of Numbers
- control: Control
- path: Array of Numbers

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
tvText [101, [0]];
```

#### Example 2

```sqf
_ctrl tvText [0,0,0];
```
