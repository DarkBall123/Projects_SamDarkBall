## getPylonMagazines

- Source: https://community.bistudio.com/wiki/getPylonMagazines
- Revision: 364988
- Updated: 2024-07-04T19:58:05Z

- Availability: arma3 1.70
- Groups: Vehicle Loadouts

### Description

Return array of magazines on pylons.

### Syntax

```sqf
getPylonMagazines  vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Array of Strings - magazine names

### Examples

#### Example 1

```sqf
getPylonMagazines vehicle player;
```
