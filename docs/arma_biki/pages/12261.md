## debriefingText

- Source: https://community.bistudio.com/wiki/debriefingText
- Revision: 318861
- Updated: 2022-05-13T09:21:57Z

- Availability: arma3 0.50
- Groups: Briefing

### Description

Returns debriefing text of provided end.

### Syntax

```sqf
debriefingText end
```

### Parameters

- end: String

### Return Value

- String - *end* debriefing text. If it does not exist in config, empty string is returned.

### Examples

#### Example 1

```sqf
_deathText = debriefingText "endDeath";
```
