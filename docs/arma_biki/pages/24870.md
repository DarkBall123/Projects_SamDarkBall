## BIS fnc camera setVisionMode

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_setVisionMode
- Revision: 349280
- Updated: 2023-11-08T14:51:14Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Sets camera vision mode.

### Syntax

```sqf
[camera, mode] call BIS_fnc_camera_setVisionMode
```

### Parameters

- camera: Object - the camera
- mode: Number - (Optional, default 0)
*0 - no vision mode
*1 - Night vision
*2 - Ti

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera,1] call BIS_fnc_camera_setVisionMode;
```
