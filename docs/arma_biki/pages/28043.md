## get

- Source: https://community.bistudio.com/wiki/get
- Revision: 348437
- Updated: 2023-11-08T13:00:13Z

- Availability: arma3 2.02
- Groups: HashMap

### Description

Retrieves a value out of a HashMap after looking it up by its key.

### Syntax

```sqf
hashMap get key
```

### Parameters

- hashMap: HashMap
- key: HashMapKey - case sensitive key

### Return Value

- Anything, or Nothing if *key* is not found

### Examples

#### Example 1

```sqf
private _myValue = _myHashMap get "a";
```
