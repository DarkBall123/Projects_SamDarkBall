## estimatedEndServerTime

- Source: https://community.bistudio.com/wiki/estimatedEndServerTime
- Revision: 370564
- Updated: 2025-01-08T22:11:23Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Time, Mission Information, Multiplayer

### Description

Estimated end of MP game in seconds converted to serverTime.

### Syntax

```sqf
estimatedEndServerTime
```


### Return Value

- Number - seconds left

### Examples

#### Example 1

Estimated minutes left: 

```sqf
_min = ceil (estimatedEndServerTime - serverTime) / 60;
```
