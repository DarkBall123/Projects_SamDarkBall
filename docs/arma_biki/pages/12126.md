## addHeadgear

- Source: https://community.bistudio.com/wiki/addHeadgear
- Revision: 318581
- Updated: 2022-05-13T09:21:08Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Unit Inventory

### Description

Creates a headgear item and tries to link it to headgear slot. If slot is occupied with another item, the item in the slot will be replaced.

### Syntax

```sqf
unit addHeadgear item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addHeadgear "H_HelmetB";
```

### See Also

headgear removeHeadgear
