## uiTime

- Source: https://community.bistudio.com/wiki/uiTime
- Revision: 370498
- Updated: 2024-12-26T17:46:41Z

- Availability: arma3 2.20
- Groups: Time, Mission Information

### Description

Returns UI time elapsed since mission started (in seconds). Unlike time the uiTime does not stop when game is paused.

### Syntax

```sqf
uiTime
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
private _future = uiTime + 30;
waitUntil { uiTime >= _future };  // continue after 30 seconds
```
