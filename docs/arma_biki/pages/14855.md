## setCuratorCameraAreaCeiling

- Source: https://community.bistudio.com/wiki/setCuratorCameraAreaCeiling
- Revision: 339085
- Updated: 2023-04-26T10:54:07Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Sets maximal (ATL) height to which curator camera can move.

### Syntax

```sqf
curatorObj setCuratorCameraAreaCeiling height
```

### Parameters

- curatorObj: Object - Curator module
- height: Number - ATL, in metres

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myCurator setCuratorCameraAreaCeiling 50;
```
