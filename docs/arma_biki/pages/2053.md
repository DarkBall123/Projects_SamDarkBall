## setMusicEffect

- Source: https://community.bistudio.com/wiki/setMusicEffect
- Revision: 377584
- Updated: 2026-01-02T06:56:42Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Sounds, Triggers, Waypoints

### Description

Defines a music track played on activation. If another track is playing already, this will stop it and start the new track.

Track is a subclass name of CfgMusic. In addition, "$STOP$" (stops the current music track) or use 

```sqf
playMusic ""
```

.
When used in a trigger, the track starts on activation but does not automatically stop on deactivation.

### Syntax

```sqf
trigger setMusicEffect track
```

```sqf
waypoint setMusicEffect track
```

### Parameters

- trigger: Object
- track: String
- waypoint: Waypoint
- track: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_trigger setMusicEffect "Track1";
```

#### Example 2

```sqf
[_group1,1] setMusicEffect "$STOP$";
```
