## setVisibleIfTreeCollapsed

- Source: https://community.bistudio.com/wiki/setVisibleIfTreeCollapsed
- Revision: 378401
- Updated: 2026-04-04T08:10:10Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Sets whether or not the object is visible even if the tree is collapsed.
Some Old Editor Command

### Syntax

```sqf
map setVisibleIfTreeCollapsed [object, visible]
```

### Parameters

- map: Control
- object: EditorObject
- visible: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_map setVisibleIfTreeCollapsed ["_unit_0", true];
```
