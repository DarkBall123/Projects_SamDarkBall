## waypointCombatMode

- Source: https://community.bistudio.com/wiki/waypointCombatMode
- Revision: 377742
- Updated: 2026-01-03T00:57:51Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Gets the waypoint's combat mode setting.

### Syntax

```sqf
waypointCombatMode waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- String - one of "BLUE", "GREEN", "WHITE", "YELLOW" and "RED" or "ERROR"

### Examples

#### Example 1

```sqf
waypointCombatMode [groupOne, 1];
```
