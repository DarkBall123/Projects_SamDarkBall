## setMarkerShadowLocal

- Source: https://community.bistudio.com/wiki/setMarkerShadowLocal
- Revision: 349276
- Updated: 2023-11-08T14:51:11Z

- Availability: arma3 2.04
- Locality: effect local
- Groups: Markers

### Description

Sets the shadow property of given marker.

### Syntax

```sqf
marker setMarkerShadowLocal shadowState
```

### Parameters

- marker: String - the marker
- shadowState: Boolean - true to enable the shadow, false to disable it

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_myMarker setMarkerShadowLocal true; // enable shadow
```
