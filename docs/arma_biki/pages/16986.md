## configSourceMod

- Source: https://community.bistudio.com/wiki/configSourceMod
- Revision: 318766
- Updated: 2022-05-13T09:21:28Z

- Availability: arma3 1.38
- Groups: Mods and Addons

### Description

Returns modDir of the mod that given config class was loaded from.

### Syntax

```sqf
configSourceMod config
```

### Parameters

- config: Config

### Return Value

- String

### Examples

#### Example 1

```sqf
configSourceMod (configFile >> "CfgVehicles" >> "Heli_Transport_04_base_F"); // returns "heli"
```

#### Example 2

```sqf
configSourceMod (configFile >> "CfgVehicles" >> "Car"); // returns "A3"
```
