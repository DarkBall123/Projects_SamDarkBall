## BIS fnc posToGrid

- Source: https://community.bistudio.com/wiki/BIS_fnc_posToGrid
- Revision: 327012
- Updated: 2022-07-12T21:44:44Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Positions

### Description

Converts array position to map grid position.
This function is replaced by mapGridPosition.|arma2|1.04

### Syntax

```sqf
element call BIS_fnc_posToGrid
```

### Parameters

- element: Object, Array in format Position or String marker name

### Return Value

- Array of Strings - format ["X", "Y"]

### Examples

#### Example 1

```sqf
player call BIS_fnc_posToGrid; // ["046", "049"]
```
