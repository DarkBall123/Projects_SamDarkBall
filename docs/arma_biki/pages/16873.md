## allVariables

- Source: https://community.bistudio.com/wiki/allVariables
- Revision: 338534
- Updated: 2023-03-15T15:11:36Z

- Availability: arma3 1.38
- Groups: Namespaces, Variables

### Description

Returns a list of all variables from the desired namespace.

### Multiplayer

{{Feature|important|Using profileNamespace and uiNamespace with this command has been disabled in multiplayer in 1.40 - see {{Link|https://forums.bohemia.net/forums/topic/140837-development-branch-changelog/?do{{=}}findComment&comment{{=}}2869646|Changelog}}.}}

### Syntax

```sqf
allVariables namespace
```

### Parameters

- namespace: Namespace, Object, Group, Task, Location, Team Member, 2.02 Control, 2.02 Display

### Return Value

- Array of Strings - array of variable names. All names are in lower case (see toLower)

### Examples

#### Example 1

```sqf
_allVarsUINamespace = allVariables uiNamespace;
```

#### Example 2

```sqf
_allVarsTrigger = allVariables trigger1;
```
