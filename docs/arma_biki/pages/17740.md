## get3DENLayerEntities

- Source: https://community.bistudio.com/wiki/get3DENLayerEntities
- Revision: 369163
- Updated: 2024-09-03T10:34:40Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Return all entities and sub-layer in Eden Entity layer. In order to get all layer entities during a scenario use getMissionLayerEntities.

### Syntax

```sqf
get3DENLayerEntities layerID
```

### Parameters

- layerID: Number - layer ID as returned by add3DENLayer command

### Return Value

- Array of Eden Entities

### Examples

#### Example 1

```sqf
_myLayer = -1 add3DENLayer "CTRG";
player set3DENLayer _myLayer;
_entities = get3DENLayerEntities _myLayer;
```
