## save3DENPreferences

- Source: https://community.bistudio.com/wiki/save3DENPreferences
- Revision: 369740
- Updated: 2024-10-08T15:05:37Z

- Availability: arma3 2.18
- Groups: Eden Editor

### Description

Saves current 3DEN preferences into .3den.Arma3Profile file.

### Syntax

```sqf
save3DENPreferences
```


### Return Value

- Boolean - true on success

### Examples

#### Example 1

```sqf
"Preferences" set3DENMissionAttribute ["SaveBinarized", true];
save3DENPreferences;
```
