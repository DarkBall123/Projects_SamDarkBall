## createSoundSourceLocal

- Source: https://community.bistudio.com/wiki/createSoundSourceLocal
- Revision: 369781
- Updated: 2024-10-08T15:09:02Z

- Availability: arma3 2.18
- Locality: argument global, effect local
- Groups: Sounds

### Description

Same as createSoundSource but with local effect - the created sound is not transferred to other clients.

### Syntax

```sqf
see createSoundSource
```

### Parameters

- see createSoundSource

### Return Value

- see createSoundSource

### Examples

#### Example 1

```sqf
createSoundSource		["LittleDog", position player, [], 0]; // global
createSoundSourceLocal	["LittleDog", position player, [], 0]; // local
```
