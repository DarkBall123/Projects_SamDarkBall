## slingLoadAssistantShown

- Source: https://community.bistudio.com/wiki/slingLoadAssistantShown
- Revision: 369265
- Updated: 2024-09-03T18:42:42Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Returns true if Sling Load Assistant is open.

### Syntax

```sqf
slingLoadAssistantShown
```


### Return Value

- Boolean - true if sling load assistant is shown, false otherwise

### Examples

#### Example 1

```sqf
waitUntil { slingLoadAssistantShown };
hint "You lack rudimentary motor skills and basic eye-hand coordination."; // scold user for unethical practices
```
