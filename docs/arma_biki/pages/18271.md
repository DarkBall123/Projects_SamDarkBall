## createMPCampaignDisplay

- Source: https://community.bistudio.com/wiki/createMPCampaignDisplay
- Revision: 368963
- Updated: 2024-08-21T08:49:17Z

- Availability: arma3 1.62
- Locality: argument local, effect local
- Groups: GUI Control

### Description

Create a MP campaign display. The class name must be a mission collection declared in the configs; for example, 

```sqf
configFile >> "CfgMissions" >> "MPMissions" >> "Apex"
```

If the class does not exist or is not a mission collection, the display will be created empty.

### Syntax

```sqf
display createMPCampaignDisplay class
```

### Parameters

- display: Display
- class: String - mission collection classname

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
findDisplay 46 createMPCampaignDisplay "Apex";
```
