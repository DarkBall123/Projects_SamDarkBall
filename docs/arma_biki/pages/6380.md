## createMissionDisplay

- Source: https://community.bistudio.com/wiki/createMissionDisplay
- Revision: 368962
- Updated: 2024-08-21T08:48:56Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Create single missions display as a child of given display. The mission dialog will be set to the directory given as an argument "root".

### Syntax

```sqf
display createMissionDisplay missionRootDirectoryString
```

```sqf
display createMissionDisplay [missionRootDirectoryString, cfgMissionsClass]
```

### Parameters

- display: Display
- missionRootDirectoryString: String
- display: Display
- missionRootDirectoryString: String - root direction from `\Arma 3\Missions\ROOT`
- cfgMissionsClass: String - cfgMissions class to use

### Return Value

- Display
- Display

### Examples

#### Example 1

```sqf
_ChildDisplay = _Rootdisplay createMissionDisplay "Tutorial";
```

#### Example 2

In Arma 3 this creates the scenarios UI:

```sqf
findDisplay 46 createMissionDisplay "";
```

#### Example 3

Other options for Arma 3:

```sqf
private _missionDisplay = findDisplay 46;
_missionDisplay createMissionDisplay ["", "Cutscenes"];
_missionDisplay createMissionDisplay ["", "Campaigns"];
_missionDisplay createMissionDisplay ["", "MPMissions"];
_missionDisplay createMissionDisplay ["", "Challenges"];
_missionDisplay createMissionDisplay ["", "Showcases"];
```
