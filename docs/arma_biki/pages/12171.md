## handgunItems

- Source: https://community.bistudio.com/wiki/handgunItems
- Revision: 321090
- Updated: 2022-05-13T13:46:43Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns array with all items assigned to the handgunWeapon except magazines. Use handgunMagazine command for the latter. This command is used for infantry weapons only.

### Syntax

```sqf
handgunItems unit
```

### Parameters

- unit: Object

### Return Value

- Array - [silencer, laserpointer/flashlight, optics, bipod]

### Examples

#### Example 1

```sqf
handgunItems player;
/*
[
	"muzzle_snds_L",	// silencer
	"",					// laser
	"",					// optics
	""					// bipod
]
*/
```
