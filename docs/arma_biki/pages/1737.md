## sliderSetSpeed

- Source: https://community.bistudio.com/wiki/sliderSetSpeed
- Revision: 376729
- Updated: 2025-11-15T04:49:49Z

- Availability: ofp 1.85, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets slider line step and page step delta amount as well as optional step amount of CT_SLIDER or CT_XSLIDER with given idc of topmost user dialog. 
* Click to arrow - move by line
* Click to scale outside thumb - move by page.

CT_XSLIDER does not use the *page* parameter, it acts as scrollbar when clicked on the bar. It also can only be horizontal.

### Syntax

```sqf
sliderSetSpeed [idc, line, page, step]
```

```sqf
control sliderSetSpeed [line, page, step]
```

### Parameters

- idc: Number - control's idc
- line: Number - value delta to move the slider when clicking on the outer arrows
- page: Number - value delta to move the slider when clicking inside the slider bar
- step: Number - (Optional, default 0) slider step
- control: Control
- line: Number - value delta to move the slider when clicking on the outer arrows
- page: Number - value delta to move the slider when clicking inside the slider bar
- step: Number - (Optional, default 0) slider step

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
sliderSetSpeed [101, 0.5, 2];
```
