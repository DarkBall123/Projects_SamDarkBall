## onTeamSwitch

- Source: https://community.bistudio.com/wiki/onTeamSwitch
- Revision: 353308
- Updated: 2024-03-15T17:11:45Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Team Switch, Event Handlers

### Description

Defines an action performed when the team switch is finished.
Commandset receives the following special variables: *_from* object previous unit, *_to* object current unit.
Consecutive use of onTeamSwitch command will overwrite previously set commandset. 
This command is deprecated. Since **Arma 3** *v1.57* a stackable version of this EH is available: TeamSwitch

{{Feature|informative|When player switches and leaves behind AI unit, you need to enable "TeamSwitch" AI on it (with 

```sqf
onTeamSwitch { _from enableAI "TeamSwitch" };
```

) so that the unit continues with waypoints.}}

### Syntax

```sqf
onTeamSwitch commandset
```

### Parameters

- commandset:  String or Code

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
onTeamSwitch { [_from, _to] execVM "myTeamSwitchScript.sqf"; };
```
