## setLightDayLight

- Source: https://community.bistudio.com/wiki/setLightDayLight
- Revision: 319755
- Updated: 2022-05-13T09:24:49Z

- Availability: arma3 0.50
- Locality: argument local, effect local
- Groups: Lights

### Description

Sets if light can be used during the day.

### Syntax

```sqf
light setLightDayLight bool
```

### Parameters

- light: Object
- bool: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLight setLightDayLight true;
```
