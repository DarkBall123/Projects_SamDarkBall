- Availability: arma3 2.02
- Groups: GUI Control

### Description

Returns the tooltip property of a button control. Getter for ctrlSetTooltip.

### Syntax

```sqf
ctrlTooltip control
```

### Parameters

- control: Control

### Return Value

- String

### Examples

#### Example 1

```sqf
ctrlTooltip _control;
```
