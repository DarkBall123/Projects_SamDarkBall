## leaderboardGetRows

- Source: https://community.bistudio.com/wiki/leaderboardGetRows
- Revision: 377273
- Updated: 2026-01-02T06:36:42Z

- Availability: arma3 1.56
- Groups: Leaderboards

### Description

Returns values for the given leaderboard; this can be called after the one of the row request function has been called and successfully finished!

### Syntax

```sqf
leaderboardGetRows boardName
```

### Parameters

- boardName: String

### Return Value

- Array format: [[player1Name, score, rank], [player2Name, score, rank], [player3Name, score, rank] ...]

### Examples

#### Example 1

```sqf
leaderboardGetRows "TT01";
```
