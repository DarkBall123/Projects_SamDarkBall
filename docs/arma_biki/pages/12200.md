## removeAllContainers

- Source: https://community.bistudio.com/wiki/removeAllContainers
- Revision: 338829
- Updated: 2023-04-10T10:24:35Z

- Availability: arma3 0.50
- Groups: Unit Inventory

### Description

Removes all containers (vest, uniform, backpack) from the provided unit.

### Syntax

```sqf
removeAllContainers unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllContainers player;
```
