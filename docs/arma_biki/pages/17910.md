## channelEnabled

- Source: https://community.bistudio.com/wiki/channelEnabled
- Revision: 378505
- Updated: 2026-05-03T16:53:27Z

- Availability: arma3 1.42
- Groups: Radio and Chat

### Description

Returns Array of Booleans in format [enabledChat, enabledVoN] for the given channel.
For more information about enabling/disabling of chat channels see enableChannel.

### Syntax

```sqf
channelEnabled channelID
```

### Parameters

- channelID: Number - Channel ID (see description)

### Return Value

- Array with [chat, VoN, mapMarkers, mapDrawing]
* chat: Boolean - is use of the text chat enabled
* VoN: Boolean - is use of the voice chat enabled
* 2.20 mapMarkers: Boolean - can map markers be created
* 2.20 mapDrawing: Boolean - can players draw on the map

### Examples

#### Example 1

```sqf
_isGlobalChatEnabled = (channelEnabled 0) select 0; // check if user can use text on global channel
```

#### Example 2

```sqf
_isGlobalVoiceEnabled = (channelEnabled 0) select 1; // check if user can use the VoN on global channel
```

#### Example 3

```sqf
// sets all variables
(channelEnabled 0) params [
	"_isGlobalChatEnabled",
	"_isGlobalVoiceEnabled",
	"_areMarkersEnabled",
	"_isMapDrawingEnabled"
];
```
