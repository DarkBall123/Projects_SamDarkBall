## BIS fnc initParams

- Source: https://community.bistudio.com/wiki/BIS_fnc_initParams
- Revision: 352540
- Updated: 2024-02-12T16:42:20Z

- Availability: arma3 1.00
- Groups: Mission Parameters

### Description

Initialize mission params and create log in the diary.

Since 2.18 it is possible to deactivate automatic parameter initialization in **singleplayer** by setting `BIS_fnc_initParams_skip` to true in preInit.

### Syntax

```sqf
[modules] call BIS_fnc_initParams
```


### Return Value

- Boolean

### Examples

#### Example 1

```sqf
call BIS_fnc_initParams;
```
