## ctrlMousePosition

- Source: https://community.bistudio.com/wiki/ctrlMousePosition
- Revision: 378524
- Updated: 2026-05-04T01:55:42Z

- Availability: arma3 2.00
- Groups: GUI Control - Positioning

### Description

Returns position of the mouse on the screen relative to UI Control in UI coordinates. Also works within CT_CONTROLS_GROUPs. In that case, returned position is relative to the position of the group.

### Syntax

```sqf
ctrlMousePosition control
```

### Parameters

- control: Control

### Return Value

- Position2D - x and y UI coordinates of the mouse position

### Examples

#### Example 1

```sqf
private _mouseRelPos = ctrlMousePosition _ctrl;
```
