## removeAllEventHandlers

- Source: https://community.bistudio.com/wiki/removeAllEventHandlers
- Revision: 349140
- Updated: 2023-11-08T14:49:47Z

- Availability: ofp 1.85, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Event Handlers

### Description

Removes all event handlers of given type that were added by addEventHandler **and** resets event handler's creation index to 0.

### Syntax

```sqf
target removeAllEventHandlers handlerType
```

### Parameters

- target: Object or 2.10 Group
- handlerType: String - see Event Handlers

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeAllEventHandlers "Killed";
```
