## ctSetHeaderTemplate

- Source: https://community.bistudio.com/wiki/ctSetHeaderTemplate
- Revision: 310130
- Updated: 2022-05-05T12:25:42Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Takes config path to the new header template. Clears the whole RscControlsTable and sets the new header template.

### Syntax

```sqf
control ctSetHeaderTemplate config
```

### Parameters

- control: Control
- config: Config

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctSetHeaderTemplate _configPath;
```
