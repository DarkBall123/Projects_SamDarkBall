## BIS fnc tasksUnit

- Source: https://community.bistudio.com/wiki/BIS_fnc_tasksUnit
- Revision: 352094
- Updated: 2024-02-01T23:24:49Z

- Availability: arma3 1.00
- Locality: argument global
- Groups: Tasks

### Description

Grab all tasks currently created for a given unit. See Arma 3: Task Framework for more information.

### Syntax

```sqf
target call BIS_fnc_tasksUnit
```

### Parameters

- target: Object

### Return Value

- Array - array with task names

### Examples

#### Example 1

```sqf
player call BIS_fnc_tasksUnit;
```
