## lockedDriver

- Source: https://community.bistudio.com/wiki/lockedDriver
- Revision: 363262
- Updated: 2024-03-26T10:51:33Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Check whether driver position of the vehicle turret is locked.

### Syntax

```sqf
lockedDriver vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_driverLocked = lockedDriver vehicle player;
```
