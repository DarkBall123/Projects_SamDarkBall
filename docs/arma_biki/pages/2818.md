## ctrlSetFont

- Source: https://community.bistudio.com/wiki/ctrlSetFont
- Revision: 323058
- Updated: 2022-06-28T21:43:11Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets the font for given control (see available fonts)

### Syntax

```sqf
control ctrlSetFont fontName
```

### Parameters

- control: Control
- fontName: String - one of the fonts defined in CfgFontFamilies

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFont "TahomaB";
```
