## taskHint

- Source: https://community.bistudio.com/wiki/taskHint
- Revision: 377725
- Updated: 2026-01-02T09:36:56Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Briefing

### Description

Shows info about new, changed or failed task. The text can contain several lines. `\n` is used to set a line return.
It is recommended to use BIS_fnc_showNotification in order to maintain Arma 3's visual style.

### Syntax

```sqf
taskHint [text, color, icon]
```

### Parameters

- text: String
- color: Color (RGBA)
- icon: String - one of:
{{Columns|2|
* "taskNew"
* "taskCurrent"
* "taskDone"
* "taskFailed"
}}

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
taskHint ["Task failed.\nBad job!", [1, 0, 0, 1], "taskFailed"];
```
