## getPlateNumber

- Source: https://community.bistudio.com/wiki/getPlateNumber
- Revision: 309220
- Updated: 2022-05-03T22:51:33Z

- Availability: arma3 1.82
- Groups: Object Manipulation

### Description

Get the license plates from any vehicle which has plates configured.

### Syntax

```sqf
getPlateNumber vehicle
```

### Parameters

- vehicle: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
if (getPlateNumber vehicle player != "H4X0RZ") then { hint "u no 1337 bro" };
```
