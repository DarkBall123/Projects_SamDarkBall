## BIS fnc 3DENVisionMode

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENVisionMode
- Revision: 349152
- Updated: 2023-11-08T14:49:49Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Toggle or set Eden Editor vision mode. Has to be executed while Eden interface is opened.

### Syntax

```sqf
mode call BIS_fnc_3DENVisionMode
```

### Parameters

- mode: Number - can be:
* -2: restore the current mode
* -1: toggle mode
*  0: Normal
*  1: Night vision
*  2: Thermal

### Return Value

- Number - selected mode

### Examples

#### Example 1

```sqf
private _mode = 0 call BIS_fnc_3DENVisionMode;
```
