## BIS fnc credits

- Source: https://community.bistudio.com/wiki/BIS_fnc_credits

- Updated: 2022-07-13T09:50:31Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Opens credits, identical to those found in main menu (Arma 3). Also present in Arma 3.

### Syntax

```sqf
[] spawn BIS_fnc_credits
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[] spawn BIS_fnc_credits;
```
