### Description

Returns the natural logarithm of x.  thumb|400|ln(x) and ln(e)

### Syntax

```sqf
ln  x
```

### Parameters

- x: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
_nlog = ln 10;
```

#### Example 2

```sqf
_euler = exp 1;
_euler = ln _euler; // Returns 1
```
