## groups

- Source: https://community.bistudio.com/wiki/groups
- Revision: 338341
- Updated: 2023-02-28T14:38:39Z

- Availability: arma3 2.12
- Groups: Groups

### Description

Returns an array with all groups of given side.

### Syntax

```sqf
groups side
```

### Parameters

- side: Side

### Return Value

- Array of Groups

### Examples

#### Example 1

```sqf
private _allBluforGroups = groups blufor; // equivalent of allGroups select { side _x == blufor };
```
