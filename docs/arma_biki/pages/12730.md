## tvExpand

- Source: https://community.bistudio.com/wiki/tvExpand
- Revision: 377800
- Updated: 2026-01-03T04:01:32Z

- Availability: arma3 0.74
- Locality: argument local, effect local
- Groups: GUI Control - Tree View

### Description

Expands tree item pointed to by the path. IDC means id of parent Tree View.

### Syntax

```sqf
tvExpand [idc, path]
```

```sqf
control tvExpand path
```

### Parameters

- idc: Number
- path: Tree View Path - [] will expand the whole tree if it was collapsed previously with []
- control: Control
- path: Tree View Path - [] will expand the whole tree if it was collapsed previously with []

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
tvExpand [101, [0]];
```

#### Example 2

```sqf
_ctrl tvExpand [1];
```
