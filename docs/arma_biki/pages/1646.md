## lock

- Source: https://community.bistudio.com/wiki/lock
- Revision: 353298
- Updated: 2024-03-15T17:11:43Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Lock vehicle (disable mounting / dismounting) for player.
This command will remove user get in/get out actions but will not stop player getting into or out of vehicle via script commands (e.g moveInCargo).
Alternative syntax is similar to setVehicleLock but with numbers.

### Syntax

```sqf
vehicleName lock locked
```

```sqf
vehicleName lock lockstate
```

### Parameters

- vehicleName: Object
- locked: Boolean - true to lock, false to unlock
- vehicleName: Object
- lockstate: Number - can be one of the following:

0 - Unlocked

1 - Default (player subordinate cannot enter until his leader says so)

2 - Locked

3 - Locked for player

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_jeepOne lock true;
```

#### Example 2

```sqf
heli lock true;
locked heli; // 2

heli lock false;
locked heli; // 0

heli lock 1;
locked heli; // 1
```
