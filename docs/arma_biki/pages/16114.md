- Availability: arma3 1.00
- Groups: Strategic

### Description

Returns group params from CfgORBAT.

### Syntax

```sqf
[path] call BIS_fnc_ORBATGetGroupParams
```

### Parameters

- path: Config - path to group in CfgORBAT.

### Return Value

- Array

### Examples

#### Example 1

```sqf
[configFile >> "CfgORBAT" >> "BIS" >> "B_1_A_1"] call BIS_fnc_ORBATGetGroupParams;
```
