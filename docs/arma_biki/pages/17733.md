## set3DENLinesVisible

- Source: https://community.bistudio.com/wiki/set3DENLinesVisible
- Revision: 342208
- Updated: 2023-07-09T12:27:19Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Toggle visibility of Eden Editor lines.

### Syntax

```sqf
set3DENLinesVisible [showMap, showScene]
```

### Parameters

- showScene: Boolean - visibility in the scene
- showMap : Boolean - visibility in the map

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
set3DENLinesVisible [false, false];// Hide all lines
```
