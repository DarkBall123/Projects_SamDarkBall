## getUnitFreefallInfo

- Source: https://community.bistudio.com/wiki/getUnitFreefallInfo
- Revision: 377879
- Updated: 2026-01-04T16:08:21Z

- Availability: arma3 2.10
- Locality: argument local
- Groups: Object Manipulation

### Description

Returns a unit's freefall information.

### Syntax

```sqf
getUnitFreefallInfo unit
```

### Parameters

- unit: Object - unit

### Return Value

- Array with [isFalling, isInFreefallPose, minFreefallHeight]
* isFalling: Boolean - true if unit is falling
* isInFreefallPose: Boolean - true if unit is in freefall pose
* minFreefallHeight: Number - current minimum freefall height (see setUnitFreefallHeight)

### Examples

#### Example 1

```sqf
getUnitFreefallInfo player;
```
