## BIS fnc setIdentity

- Source: https://community.bistudio.com/wiki/BIS_fnc_setIdentity
- Revision: 373727
- Updated: 2025-06-23T13:18:19Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Sets the unit's identity.
{{Feature|informative|
* When executed on server, the identity will be JIP compatible.
* Before 1.92, this function was {{Icon|serverExec|32}}.
}}

### Syntax

```sqf
[object, face, speaker, pitch, callsign, name, glasses] call BIS_fnc_setIdentity
```

### Parameters

- object: Object
- face: String - (Optional, default "") face from [CfgFaces](Arma 3: CfgIdentities#Faces)
- speaker: String - (Optional, default "") speaker from [CfgVoice](Arma 3: CfgIdentities#Speakers)
- pitch: String - (Optional, default -1) speaker pitch (1 is normal pitch, 2 = chipmunk, 0.5 = Darth Vader, etc)
- callsign: String - (Optional, default "") callsign
- name: String - (Optional, default "") unit name
- glasses: String - (Optional, default nil) glasses from [CfgGlasses](Arma 3: CfgGlasses) - use "" to remove glasses

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[player, "Kerry", "Male01ENGB", 1.05, "Big Daddy"] call BIS_fnc_setIdentity;
```

#### Example 2

```sqf
[bob, nil, nil, 1.6, nil, "Miki Maus", "G_Shades_Black"] call BIS_fnc_setIdentity;
```
