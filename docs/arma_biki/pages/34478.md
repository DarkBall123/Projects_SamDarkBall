## vectorSide

- Updated: 2026-04-04T08:14:48Z

- Availability: arma3 2.14
- Locality: argument global
- Groups: Math - Vectors

### Description

thumb|right|An object with its vectorDir, [[vectorUp and vectorSide (vectors not to scale)]]
Returns an object's side vector in world space.

The vector is **not necessarily normalized**. The magnitude of the vector depends on the object's scale.

### Syntax

```sqf
vectorSide object
```

### Parameters

- object: Object

### Return Value

- Vector3D

### Examples

#### Example 1

```sqf
_vecSide = vectorSide MyObject;
```
