## groupId

- Source: https://community.bistudio.com/wiki/groupId
- Revision: 337336
- Updated: 2023-01-18T11:45:01Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Groups

### Description

Returns a group's name or a unit's group ID number.

### Syntax

```sqf
groupId group
```

```sqf
groupId unit
```

### Parameters

- group: Group
- unit: Object - a group's unit

### Return Value

- String - the group's name (e.g "Alpha Red")
- Number - the unit's group ID (e.g "**2**, taking command")

### Examples

#### Example 1

```sqf
_name = groupId group player;			// e.g "B Alpha 1-1"
```

#### Example 2

```sqf
private _unitGroupId = groupId player;	// e.g 3 (number, not a string)
```
