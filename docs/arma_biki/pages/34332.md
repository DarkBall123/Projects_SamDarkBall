## waterDamaged

- Source: https://community.bistudio.com/wiki/waterDamaged
- Revision: 347219
- Updated: 2023-09-05T16:49:02Z

- Availability: arma3 2.14
- Locality: argument global
- Groups: Object Manipulation

### Description

Checks if the engine was water damaged. When a vehicle is Drowned, the engine gets water damaged and might need full repair either with setDamage or setHitPointDamage to be able to start.

### Syntax

```sqf
waterDamaged object
```

### Parameters

- object: Object

### Return Value

- Boolean - true if the engine was water damaged

### Examples

#### Example 1

```sqf
waterDamaged tank1;
```

### See Also

setDamage damage alive
