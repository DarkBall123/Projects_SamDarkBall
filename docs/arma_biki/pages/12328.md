- Updated: 2024-05-16T09:58:13Z

- Availability: arma3 0.50
- Groups: GUI Control

### Description

Returns control IDC.

### Syntax

```sqf
ctrlIDC  control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
ctrlIDC _ctrl;
```

#### Example 2

```sqf
ctrlIDC controlNull; // returns -1
```
