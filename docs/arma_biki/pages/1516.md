## pickWeaponPool

- Source: https://community.bistudio.com/wiki/pickWeaponPool
- Revision: 310249
- Updated: 2022-05-05T13:11:07Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapon Pool

### Description

Transfers weapons and magazines from cargo of object into the weapon pool. This is used in the campaign to transfer weapons into the next mission.

### Syntax

```sqf
pickWeaponPool object
```

### Parameters

- object: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
pickWeaponPool vehicle player;
```
