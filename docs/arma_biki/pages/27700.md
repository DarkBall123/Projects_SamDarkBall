## addBinocularItem

- Source: https://community.bistudio.com/wiki/addBinocularItem
- Revision: 309278
- Updated: 2022-05-04T15:19:43Z

- Availability: arma3 2.02
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Adds weapon item, including magazine, directly to the binocular weapon. This is used for infantry weapons.

### Syntax

```sqf
unit addBinocularItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addBinocularItem "Laserbatteries";
```
