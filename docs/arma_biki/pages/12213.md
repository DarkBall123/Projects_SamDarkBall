## setParticleClass

- Source: https://community.bistudio.com/wiki/setParticleClass
- Revision: 369209
- Updated: 2024-09-03T10:34:52Z

{{RV|type=command

|game1= arma3
|version1= 0.50

|arg= global
|eff= local

|gr1= Particles

|descr= Sets particle source parameters using existing particle config from `CfgCloudlets` class. Use setParticleParams subsequently if you need to overwrite some values.
{{Feature | important | If `CfgCloudlets` class contains simple expressions, they will not be evaluated by this command, which might make the whole class unusable in script.}}

|s1= source setParticleClass className

|p1= source: Object - particle source

|p2= className: String - CfgCloudlets class

|r1= Nothing

|x1=

```sqf
_source01 = "#particlesource" createVehicleLocal _pos01;
_source01 setParticleClass "ObjectDestructionFire1Smallx";
_source01 attachTo [_object,[0,0,0]];
```

|seealso= Arma 3: Particle Effects ParticleArray setParticleParams setParticleRandom setParticleCircle setParticleFire setDropInterval drop
}}
