## tvPictureRight

- Source: https://community.bistudio.com/wiki/tvPictureRight
- Revision: 378316
- Updated: 2026-04-02T16:16:44Z

- Availability: arma3 1.00
- Groups: GUI Control - Tree View

### Description

Returns the right picture of a CT_TREE on given path.

### Syntax

```sqf
tvPictureRight [idc, path]
```

```sqf
ctrl tvPictureRight path
```

### Parameters

- idc: Number
- path: Tree View Path
- ctrl: Control
- path: Tree View Path

### Return Value

- String - path to picture
- String - path to picture

### Examples

#### Example 1

```sqf
private _result = _controlTV tvPictureRight [0, 0];
```
