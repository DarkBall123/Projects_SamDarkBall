## htmlLoad

- Source: https://community.bistudio.com/wiki/htmlLoad
- Revision: 369066
- Updated: 2024-09-02T20:24:56Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Load HTML from file or URI using given control. File path is relative to current mission dir or an absolute path (with drive letter etc.).
The command is subject to restrictions, imposed by CfgCommands class.
Since 2.10 the 'title' attribute is supported within <img> and <a> html tags
For unknown reasons, URL's length is limited to 255 characters.

### Syntax

```sqf
control htmlLoad filename
```

### Parameters

- control: Control
- filename: String - local file name or remote file URL

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control htmlLoad "briefing.html";
```

#### Example 2

```sqf
_control htmlLoad "http://www.bistudio.com/newsfeed/arma3_news.php?build=main&language=English";
```

#### Example 3

Display news item:

```sqf
0 spawn {
	disableSerialization;
	private _html = findDisplay 46 createDisplay "RscCredits" ctrlCreate ["RscHTML", -1];
	_html ctrlSetBackgroundColor [0,0,0,0.8];
	_html ctrlSetPosition [safeZoneX, safeZoneY, safeZoneW, safeZoneH];
	_html ctrlCommit 0;
	_html htmlLoad "http://www.bistudio.com/newsfeed/arma3_news.php?build=main&language=English";
};
```

|text= (Arma 3) In order to use URLs, they must be included in CfgCommands -> allowedHTMLLoadURIs. In order to use URIs with params a wildcard * character is supported:
**Script**

```sqf
_newsOnline = "http://alivemod.com/alive_news.php?map=" + _map + "&mission=" + _mission + "&player=" + _player;
_ctrlHTML htmlLoad _newsOnline;
```

**Config**

```
class CfgCommands {
	allowedHTMLLoadURIs[] += {
		"http://alivemod.com/alive_news.php*"
	};
};
```
