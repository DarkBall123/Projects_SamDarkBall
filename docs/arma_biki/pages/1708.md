## ctrlVisible

- Source: https://community.bistudio.com/wiki/ctrlVisible
- Revision: 348410
- Updated: 2023-11-08T13:00:06Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: GUI Control

### Description

Returns if a control of the currently active user dialog is shown or not. Read Arma: GUI Configuration for more information about user dialogs and controls.

### Syntax

```sqf
ctrlVisible  idc
```

### Parameters

- idc: Number - control IDC

### Return Value

- Boolean - true if the control is shown, false if not

### Examples

#### Example 1

```sqf
_bool = ctrlVisible 100;
```
