## addToRemainsCollector

- Source: https://community.bistudio.com/wiki/addToRemainsCollector
- Revision: 353431
- Updated: 2024-03-18T11:57:19Z

- Availability: arma3 1.32
- Locality: argument global, effect global
- Groups: Object Manipulation

### Description

Adds an array of vehicles/units to disposal manager for automatic wreck/body removal. The disposal manager follows wreck/body removal values set in description.ext

### Syntax

```sqf
addToRemainsCollector remains
```

### Parameters

- remains: Array of Objects - array of vehicles/units

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
addToRemainsCollector [unit1, unit2, vehicle1];
```
