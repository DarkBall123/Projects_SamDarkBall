## assignedTeam

- Source: https://community.bistudio.com/wiki/assignedTeam
- Revision: 341182
- Updated: 2023-05-13T22:13:46Z

{{RV|type=command

|game1= arma2oa
|version1= 1.60

|game2= tkoh
|version2= 1.00

|game3= arma3
|version3= 0.50

|gr1= Object Manipulation

|arg= global

|descr= Returns the team the unit belongs to. Possible values:

- `"MAIN"` (default and white)
- `"RED"`
- `"GREEN"`
- `"BLUE"`
- `"YELLOW"`
- 1.94 `""` if given unit is objNull or remoteControlling another unit

|s1= assignedTeam unitName

|p1= unitName: Object

|r1= String (or, prior to Arma 3 v1.94, Nothing if given unit is objNull or remoteControlling another unit)

|x1=

```sqf
_team = assignedTeam player;
```

|seealso= assignTeam
}}
