## BIS fnc shakeCuratorCamera

- Source: https://community.bistudio.com/wiki/BIS_fnc_shakeCuratorCamera
- Revision: 349507
- Updated: 2023-11-08T17:09:13Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Shake curator camera.

### Syntax

```sqf
[strength,duration,area] spawn BIS_fnc_shakeCuratorCamera
```

### Parameters

- strength: Number - (Optional, default 0.01) shaking strength
- duration: Number - (Optional, default 0.7) duration in seconds
- area: Array - (Optional, default 

```sqf
[]
```

) shake only when camera is in given distance from center. In format:

0: Position - Center

1: Number - Radius

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[] spawn BIS_fnc_shakeCuratorCamera;
```

#### Example 2

```sqf
[0.1, 5, [BIS_explosion_center,500]] spawn BIS_fnc_shakeCuratorCamera;
```
