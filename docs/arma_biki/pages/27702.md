## removeAllBinocularItems

- Source: https://community.bistudio.com/wiki/removeAllBinocularItems
- Revision: 310163
- Updated: 2022-05-05T13:07:56Z

- Availability: arma3 2.02
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes all items from binocular weapon, except magazine.

### Syntax

```sqf
removeAllBinocularItems unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllBinocularItems player;
```
