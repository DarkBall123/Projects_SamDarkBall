## toLower

- Source: https://community.bistudio.com/wiki/toLower
- Revision: 308975
- Updated: 2022-04-21T14:51:35Z

- Availability: arma1 1.09, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Strings

### Description

Converts the supplied Unicode string to all lowercase characters. If the string doesn't have characters with codes > 255, use toLowerANSI.

### Syntax

```sqf
toLower string
```

### Parameters

- string: String

### Return Value

- String

### Examples

#### Example 1

```sqf
hint toLower "AaBb1"; // returns "aabb1"
```
