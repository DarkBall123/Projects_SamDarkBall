## openSteamApp

- Source: https://community.bistudio.com/wiki/openSteamApp
- Revision: 309224
- Updated: 2022-05-04T10:07:21Z

- Availability: arma3 1.78
- Groups: System

### Description

Opens a Steam application, returns false if it was not possible to run the application.

### Syntax

```sqf
openSteamApp appID
```

### Parameters

- appID: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
openSteamApp 553228;
```
