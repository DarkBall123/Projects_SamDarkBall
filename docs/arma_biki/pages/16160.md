## BIS fnc taskChildren

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskChildren
- Revision: 353700
- Updated: 2024-03-21T17:10:39Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Return a task's sub-tasks. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskID call BIS_fnc_taskChildren
```

### Parameters

- taskID: String - ID of the task

### Return Value

- Array or Object - array with sub tasks or objNull if parent task ID does not exist

### Examples

#### Example 1

```sqf
"task_1" call BIS_fnc_taskChildren;
```
