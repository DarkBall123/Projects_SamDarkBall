### Joysticks & Gamepads

Unfortunately, Steam’s standard only supports standard Xbox and Windows XInput gamepad schemes, which means that more sophisticated schemes present in Arma 3, and using DirectInput and allowing reconfiguration of gamepads and joysticks in-game, had to be turned off in the ports.
It is possible to reconfigure them by modifying the mapping text, but it is not intuitive. Alternatively you can try to remap your keybinding using third-party software (e.g. AntiMicro).
