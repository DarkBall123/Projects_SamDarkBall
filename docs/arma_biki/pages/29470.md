### Example Class

```
class CfgMarkers
{
	class Flag
	{
		name = "Marker description";
		icon = "\ca\ui\data\markers\marker1.paa";
		color[] = {1, 0, 0, 1};
		size = 32;
		shadow = true;
		scope = private;
	};
};
```
