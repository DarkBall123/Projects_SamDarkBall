## max

- Source: https://community.bistudio.com/wiki/max
- Revision: 321188
- Updated: 2022-05-13T15:20:51Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

The greater value of a and b.

### Syntax

```sqf
a max  b
```

### Parameters

- a: Number
- b: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
3 max 2; // Result is 3
```

#### Example 2

```sqf
-3 max -2; // Result is -2
```
