## copyFromClipboard

- Source: https://community.bistudio.com/wiki/copyFromClipboard
- Revision: 310206
- Updated: 2022-05-05T13:10:41Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System, Strings

### Description

Return ANSI content of the (text) clipboard. If Unicode support is desired, see forceUnicode.

### Multiplayer

This command is disabled in multiplayer for security reasons.

### Syntax

```sqf
copyFromClipboard
```


### Return Value

- String

### Examples

#### Example 1

```sqf
hint copyFromClipboard;
```
