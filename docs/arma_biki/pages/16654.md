## enablePersonTurret

- Source: https://community.bistudio.com/wiki/enablePersonTurret
- Revision: 377479
- Updated: 2026-01-02T06:48:53Z

- Availability: arma3 1.34
- Groups: Turrets

### Description

Enables or disables firing from a vehicle cargo position. To get the turret path use assignedVehicleRole or getCargoIndex command.

### Syntax

```sqf
vehicle enablePersonTurret [turretPath, enable]
```

### Parameters

- vehicle: Object
- turretPath: Turret Path
- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
heli enablePersonTurret [[1], true];
```
