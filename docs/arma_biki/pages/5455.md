## setMarkerTextLocal

- Source: https://community.bistudio.com/wiki/setMarkerTextLocal
- Revision: 319570
- Updated: 2022-05-13T09:24:29Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Sets the text label of an existing marker.

### Syntax

```sqf
markerName setMarkerTextLocal text
```

### Parameters

- markerName: String
- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"Marker1" setMarkerTextLocal "You are here.";
```
