## magazinesDetailBackpack

- Source: https://community.bistudio.com/wiki/magazinesDetailBackpack
- Revision: 377201
- Updated: 2026-01-01T11:36:34Z

- Availability: arma3 1.04
- Groups: Unit Inventory

### Description

Returns an array with the type names of all the unit's backpack magazines.

### Syntax

```sqf
magazinesDetailBackpack unit
```

```sqf
magazinesDetailBackpack [unit, includeEmpty, includeLoaded]
```

### Parameters

- unit: Object
- unit: Object - unit
- includeEmpty: Boolean - (Optional, default false) true to include empty magazines
- includeLoaded: Boolean - (Optional, default false) true to include magazines loaded in weapons (Since Arma 3 v2.07.148195)

### Return Value

- Array of Strings
- Array of Strings

```sqf
magazinesDetailBackpack player apply {
	private _reverse = reverse _x;
	private_i1 = (_reverse find "[)") + 1;
	private_i2 = (_reverse find ["/", _id1]) + 1;
	private_i3 = _reverse find ["(", _id2];
	parseNumber reverse (_reverse select [_i2, _i3 - _i2]); // return cnt
};
```
