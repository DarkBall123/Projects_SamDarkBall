### Description

Toggle curator vision mode.

### Syntax

```sqf
[curator, mode] call BIS_fnc_toggleCuratorVisionMode
```

### Parameters

- curator: Object - curator
- mode: Number - (Optional, default 1) mode index

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[Curator, -2] call BIS_fnc_toggleCuratorVisionMode;
```
