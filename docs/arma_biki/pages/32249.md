## pose

- Source: https://community.bistudio.com/wiki/pose
- Revision: 351637
- Updated: 2023-12-12T20:33:12Z

- Availability: arma3 2.08
- Locality: argument global
- Groups: Unit Control

### Description

Returns the pose of the given unit.

### Syntax

```sqf
pose unit
```

### Parameters

- unit: Object

### Return Value

- String - can be one of:
{{Columns|3|
* `"Dead"`
* `"Weapon"` (special weapon - AT)
* `"BinocLying"`
* `"LyingNoWeapon"`
* `"Lying"`
* `"HandGunLying"`
* `"Crouch"`
* `"HandGunCrouch"`
* `"Combat"`
* `"HandGunStand"`
* `"Stand"`
* `"Swimming"`
* `"BottomSwimming"`
* `"SurfaceSwimming"`
* `"Diving"`
* `"BottomDiving"`
* `"SurfaceDiving"`
* `"NoWeapon"` (civilian moves)
* `"Binoc"` (binocular pose)
* `"BinocStand"` (binocular pose (weapon on back))
* `"Healing"`
* `"Dragged"`
* `"Carrying"`
* `"Freefall"`
}}

### Examples

#### Example 1

```sqf
if (pose player == "SurfaceSwimming") then { hint "How's water?" };
```
