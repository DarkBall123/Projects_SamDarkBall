## BIS fnc taskDestination

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskDestination
- Revision: 352150
- Updated: 2024-02-01T23:25:18Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Return a task's destination. See Arma 3: Task Framework for more information.

### Syntax

```sqf
taskName call BIS_fnc_taskDestination
```

### Parameters

- taskName: String

### Return Value

- Object or Array - either position in format [x,y,z], or [object,precision] as used by setSimpleTaskTarget command. Returns just objNull if task was not found

### Examples

#### Example 1

```sqf
"BIS_task_01" call BIS_fnc_taskDestination;
```
