## menuSort

- Source: https://community.bistudio.com/wiki/menuSort
- Revision: 378342
- Updated: 2026-04-02T16:31:22Z

- Availability: arma3 1.56
- Groups: GUI Control - Menu

### Description

Sorts subentries of item on given path by their text.

### Syntax

```sqf
menuSort [idc, path, sortOrder]
```

```sqf
control menuSort [path, sortOrder]
```

### Parameters

- idc: Number
- path: Tree View Path
- sortOrder: Boolean - true to sort from A to Z, false to sort from Z to A
- control: Control
- path: Tree View Path
- sortOrder: Boolean - true to sort from A to Z, false to sort from Z to A

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
findDisplay 313 displayCtrl 120 menuSort [[], true];
```
