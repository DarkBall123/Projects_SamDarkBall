## removeHandgunItem

- Source: https://community.bistudio.com/wiki/removeHandgunItem
- Revision: 348319
- Updated: 2023-11-08T12:59:40Z

- Availability: arma3 0.70
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes given weapon item, including magazine, from the handgunWeapon

### Syntax

```sqf
unit removeHandgunItem item
```

### Parameters

- unit: Object
- item: String - config class

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player removeHandgunItem "muzzle_snds_L";
```
