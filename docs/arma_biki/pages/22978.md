## setUserMFDText

- Source: https://community.bistudio.com/wiki/setUserMFDText
- Revision: 309223
- Updated: 2022-05-04T10:05:28Z

- Availability: arma3 1.78
- Groups: GUI Control

### Description

Stored user text value in MFD, limit is 50, user0...user49

### Syntax

```sqf
vehicle setUserMFDText [index, value]
```

### Parameters

- vehicle: Object - vehicle with MFD
- index: Number
- value: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_vehicle setUserMFDText [0, "some text"];
```
