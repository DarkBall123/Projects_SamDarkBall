## BIS fnc diagKey

- Source: https://community.bistudio.com/wiki/BIS_fnc_diagKey
- Revision: 309361
- Updated: 2022-05-05T12:04:31Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Tracks pressed keys. (getNumber (missionConfigFile >> "diagKey") > 0) has to be true.

### Syntax

```sqf
call BIS_fnc_diagKey
```


### Return Value

- Boolean - true when activated

### Examples

#### Example 1

```sqf
call BIS_fnc_diagKey;
```
