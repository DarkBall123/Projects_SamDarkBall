## ctrlSetFontHeightH2

- Source: https://community.bistudio.com/wiki/ctrlSetFontHeightH2
- Revision: 322946
- Updated: 2022-06-28T21:42:46Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - HTML

### Description

Sets H2 font size of given HTML control.

### Syntax

```sqf
controlName ctrlSetFontHeightH2 height
```

### Parameters

- controlName: Control
- height: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetFontHeightH2 0.05;
```
