## setPilotCameraOpticsMode

- Source: https://community.bistudio.com/wiki/setPilotCameraOpticsMode
- Revision: 347224
- Updated: 2023-09-05T17:11:27Z

- Availability: arma3 2.14
- Locality: argument local
- Groups: Pilot Camera

### Description

Sets the optics mode index (zoom) for the pilotCamera

### Syntax

```sqf
object setPilotCameraOpticsMode index
```

### Parameters

- object: Object
- index: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setPilotCameraOpticsMode 0
```
