## setVehicleReceiveRemoteTargets

- Source: https://community.bistudio.com/wiki/setVehicleReceiveRemoteTargets
- Revision: 311071
- Updated: 2022-05-07T20:56:47Z

- Availability: arma3 1.70
- Groups: Sensors

### Description

Sets that the vehicle will be able to receive targets acquired by someone else via datalink from the Side center.

### Syntax

```sqf
vehicle setVehicleReceiveRemoteTargets bool
```

### Parameters

- vehicle: Object
- bool: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicle player setVehicleReceiveRemoteTargets true;
```
