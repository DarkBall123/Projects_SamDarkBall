## findCover

- Source: https://community.bistudio.com/wiki/findCover
- Revision: 377600
- Updated: 2026-01-02T07:01:58Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Broken Commands

### Description

Returns the object around where the unit finds cover. The minDist, visibilityPosition and ignoreObject parameters are optional.
{{Feature|important|Not implemented in {{arma2}} and later titles (always returns objNull).}}

### Syntax

```sqf
object findCover [position, hidePosition, maxDist, minDist, visibilityPosition, ignoreObject]
```

### Parameters

- object: Object
- position: Position
- hidePosition: PositionATL - getHideFrom-like position from which the unit should hide
- maxDist: Number
- minDist: Number - (Optional)
- visibilityPosition: Position - (Optional) used to select cover that unit can see in that direction from
- ignoreObject: Object - (Optional) ignore this object in visibility check

### Return Value

- Object - always objNull

### Examples

#### Example 1

```sqf
unit1 findCover [ASLToATL aimPos unit2, 30];
```
