## actionName

- Source: https://community.bistudio.com/wiki/actionName
- Revision: 321154
- Updated: 2022-05-13T15:05:12Z

- Availability: arma3 0.50
- Groups: Interaction

### Description

Returns localized name of action.

### Syntax

```sqf
actionName action
```

### Parameters

- action: String

### Return Value

- String

### Examples

#### Example 1

```sqf
actionName "ReloadMagazine"; // returns "Reload"
```
