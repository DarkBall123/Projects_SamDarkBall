## goggles

- Source: https://community.bistudio.com/wiki/goggles
- Revision: 320934
- Updated: 2022-05-13T10:04:40Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns name of currently used goggles (for NVGoggles use hmd).

### Syntax

```sqf
goggles unit
```

### Parameters

- unit: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
_goggles = goggles assaultDiver; //G_Diving
```

#### Example 2

```sqf
_goggles = goggles reconTeamLeader; //G_Shades_Black
```
