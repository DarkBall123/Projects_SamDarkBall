## setGroupIdGlobal

- Source: https://community.bistudio.com/wiki/setGroupIdGlobal
- Revision: 369314
- Updated: 2024-09-03T18:42:56Z

- Availability: arma3 1.48
- Locality: argument global, effect global
- Groups: Groups

### Description

A global equivalent of  setGroupId.

### Syntax

```sqf
group setGroupIdGlobal [format, keyword1, keyword2, ...]
```

### Parameters

- group: Object or Group
- format: String - format template (e.g "%keyword1 - %keyword2 / %keyword4 (%keyword3)")
- keywordN: String - keyword value

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
group player setGroupIdGlobal ["PAPA BEAR"];
hint groupId group player; // "PAPA BEAR"
```
