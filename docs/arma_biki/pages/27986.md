## tvSortAll

- Source: https://community.bistudio.com/wiki/tvSortAll
- Revision: 377598
- Updated: 2026-01-02T07:01:08Z

- Availability: arma3 2.02
- Groups: GUI Control - Tree View

### Description

Sorts all children, including trees deriving from given path. Text of Tree View entries is used for sorting.

### Syntax

```sqf
control tvSortAll [path, reversed]
```

### Parameters

- control: Control
- path: Tree View Path - path to start sorting from
- reversed: Boolean - true to reverse sort it.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl tvSortAll [[], false]; // sorts the complete Tree View
```
