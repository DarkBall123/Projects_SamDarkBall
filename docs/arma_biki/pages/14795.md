## currentWeaponTurret

- Source: https://community.bistudio.com/wiki/currentWeaponTurret
- Revision: 378861
- Updated: 2026-07-22T17:03:52Z

- Availability: arma3 1.12
- Groups: Turrets

### Description

Returns the name of the currently selected weapon on specified turret. Use turret path [-1] for driver's turret.

### Syntax

```sqf
vehicle currentWeaponTurret turretPath
```

### Parameters

- vehicle: Object
- turretPath: Turret Path

### Return Value

- String

### Examples

#### Example 1

```sqf
_weapon = MBT_Kuma currentWeaponTurret [0];
```
