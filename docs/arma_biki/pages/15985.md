## BIS fnc liveFeedSetTarget

- Source: https://community.bistudio.com/wiki/BIS_fnc_liveFeedSetTarget
- Revision: 324234
- Updated: 2022-07-01T12:00:39Z

- Availability: arma3 1.00
- Groups: Live Feed

### Description

Set the target of the current live feed.

### Syntax

```sqf
target call BIS_fnc_liveFeedSetTarget
```

### Parameters

- target: Object or Position

### Return Value

- Boolean - true if successful, false if not.

### Examples

#### Example 1

```sqf
player call BIS_fnc_liveFeedSetTarget;
```
