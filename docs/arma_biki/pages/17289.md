## serverName

- Source: https://community.bistudio.com/wiki/serverName
- Revision: 319671
- Updated: 2022-05-13T09:24:40Z

- Availability: arma3 1.48
- Groups: Multiplayer

### Description

Returns name of the hosting server in MP, "" in SP.

### Syntax

```sqf
serverName
```


### Return Value

- String

### Examples

#### Example 1

```sqf
hint format ["Welcome to the %1 server!", serverName];
```
