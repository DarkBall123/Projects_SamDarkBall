## BIS fnc absSpeed

- Source: https://community.bistudio.com/wiki/BIS_fnc_absSpeed
- Revision: 376534
- Updated: 2025-10-25T14:37:02Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Returns absolute speed of a vehicle in kilometres per hour (km/h).

### Syntax

```sqf
Object call BIS_fnc_absSpeed
```

### Parameters

- Object - vehicle

### Return Value

- Number

### Examples

#### Example 1

```sqf
if (((vehicle player) call BIS_fnc_absSpeed) > 150) then
{
	hint "There goes my driver's license :(";
};
```

#### Example 2

```sqf
_kmh = (vehicle player) call BIS_fnc_absSpeed;
_mph = _kmh / 1.609344; // miles per hour
```
