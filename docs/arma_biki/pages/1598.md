### Description

Converts given value in radians to degrees. 1 degree equals 0.01745 radians or pi / 180.

`1= 2 * pi ≙ 360° → 1 rad = 2 * pi / 360°`

### Syntax

```sqf
deg value
```

### Parameters

- value: Number - radians

### Return Value

- Number - degrees

### Examples

#### Example 1

```sqf
_degrees = deg 1; // Returns 57.2958
```

#### Example 2

```sqf
deg (2 * pi / 360); // Returns 1
```
