## assignAsTurret

- Source: https://community.bistudio.com/wiki/assignAsTurret
- Revision: 377474
- Updated: 2026-01-02T06:48:45Z

- Availability: arma3 0.50
- Groups: Turrets

### Description

Assigns the soldier to turret.
See AI Group Vehicle Management for more information.

### Syntax

```sqf
unit assignAsTurret [vehicle, turretPath]
```

### Parameters

- unit: Object
- vehicle: Object
- turretPath: Turret Path

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player assignAsTurret [BIS_vehicle, [0,1]];
```
