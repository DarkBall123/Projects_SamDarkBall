## fogForecast

- Source: https://community.bistudio.com/wiki/fogForecast
- Revision: 310773
- Updated: 2022-05-07T20:21:44Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Environment

### Description

Returns the forecast fog value. A value of 0 means no fog, 1 means maximum fog.

### Multiplayer

This command returns the local forcast fog value. Each client and the server can have differing values.

### Syntax

```sqf
**fogForecast**
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
_level = fogForecast;
```
