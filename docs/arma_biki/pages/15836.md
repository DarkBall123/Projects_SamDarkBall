## BIS fnc worldArea

- Source: https://community.bistudio.com/wiki/BIS_fnc_worldArea
- Revision: 328874
- Updated: 2022-07-15T17:37:41Z

- Availability: tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Map and Markers

### Description

Creates (or returns if it already exists) trigger with size of map.

### Syntax

```sqf
call BIS_fnc_worldArea
```


### Return Value

- Object: a trigger covering the whole *defined* terrain. Referenced by **hsim_worldArea** variable

### Examples

#### Example 1

```sqf
private _bigTrigger = call BIS_fnc_worldArea;
```
