## diag allMissionEventHandlers

- Source: https://community.bistudio.com/wiki/diag_allMissionEventHandlers
- Revision: 363556
- Updated: 2024-04-06T08:27:26Z

- Availability: arma3 2.00
- Locality: effect local
- Groups: Diagnostic, Event Handlers

### Description

Returns an array with all mission event handlers.

### Syntax

```sqf
diag_allMissionEventHandlers
```


### Return Value

- Array - in format ["EH1name", EH1count, "EH2name", EH2count, ...]
