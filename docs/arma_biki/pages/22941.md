## lbSetColorRight

- Source: https://community.bistudio.com/wiki/lbSetColorRight
- Revision: 377346
- Updated: 2026-01-02T06:40:03Z

- Availability: ofp, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: GUI Control - ListBox

### Description

Sets the color of the item (right) with the given index of the listbox or combobox with id idc of the topmost user dialog to color.

### Syntax

```sqf
lbSetColorRight [idc, index, color]
```

```sqf
control lbSetColorRight [index, color]
```

### Parameters

- idc: Number - control id
- index: Number
- color: Color (RGBA)
- control: Control
- index: Number
- color: Color (RGBA)

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
lbSetColorRight [101, 0, [0, 1, 0, 0.5]];
```

#### Example 2

```sqf
_control lbSetColorRight [0, [0, 1, 0, 0.5]];
```
