## BIS fnc clampVector

- Source: https://community.bistudio.com/wiki/BIS_fnc_clampVector
- Revision: 327749
- Updated: 2022-07-13T11:07:26Z

- Availability: arma3 1.00
- Groups: Vectors

### Description

Clamps vector values between provided min/max boundaries.

This function can be used to clamp any Array of Numbers (even though it is not its main usage).

### Syntax

```sqf
[vector, min, max] call BIS_fnc_clampVector
```

### Parameters

- vector: Vector3D - (Optional, default [0,0,0]) the vector to be clamped
- min: Number - (Optional, default 0)
- max: Number - (Optional, default 0)

### Return Value

- Vector3D - the clamped *vector*

### Examples

#### Example 1

```sqf
private _newVelocity = [velocity vehicle player, -100, 100] call BIS_fnc_clampVector;
vehicle player setVelocity _newVelocity;
```
