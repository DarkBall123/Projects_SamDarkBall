## lockDriver

- Source: https://community.bistudio.com/wiki/lockDriver
- Revision: 364987
- Updated: 2024-07-04T19:58:05Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Object Manipulation

### Description

Lock the driver position of the vehicle. This command must be executed where vehicle is local. This command will remove user get in action (not get out) but will also stop player getting into vehicle via script commands unlike lock command

### Syntax

```sqf
vehicle lockDriver lock
```

### Parameters

- vehicle: Object
- lock: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicleName lockDriver true;
```
