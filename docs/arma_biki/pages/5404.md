## ctrlMapScale

- Source: https://community.bistudio.com/wiki/ctrlMapScale
- Revision: 378435
- Updated: 2026-04-07T21:06:22Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Map

### Description

Returns the current scale of given map control.

### Syntax

```sqf
ctrlMapScale ctrl
```

### Parameters

- ctrl: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_control = (findDisplay 12) displayCtrl 51; // Arma 3
_scale = ctrlMapScale _control; // returns number from 1 to 0.001
```

```sqf
800 * (1 / ctrlMapScale _ctrlMap) * (1 / getTerrainInfo#1)
```

The thresholds are defined in 
ptsPerSquare* ctrl map properties, e.g:

```sqf
getNumber (configFile >> "ctrlMap" >> "ptsPerSquareObj")
```
