## BIS fnc isInZoom

- Source: https://community.bistudio.com/wiki/BIS_fnc_isInZoom
- Revision: 349128
- Updated: 2023-11-08T14:49:41Z

- Availability: arma3 1.00
- Groups: Map and Markers

### Description

Checks if map zoom level is in between given interval.

### Syntax

```sqf
[<nowiki/>[min, max]] call BIS_fnc_isInZoom
```

### Parameters

- min: Number - start of interval
- max: Number - end of interval

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (0.001, 0.02 call BIS_fnc_isInZoom) then 
{
  hint "Zoom level is in between 0.001 and 0.02";
};
```
