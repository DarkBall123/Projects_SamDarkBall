## BIS fnc channelNumToRadioChannelID

- Source: https://community.bistudio.com/wiki/BIS_fnc_channelNumToRadioChannelID
- Revision: 378101
- Updated: 2026-02-13T20:44:52Z

- Availability: arma3 2.22
- Groups: Radio

### Description

Converts chat channel number, used in currentChannel, enableChannel, etc to radio channel id, used in radioChannelAdd, radioChannelSetLabel, etc.

### Syntax

```sqf
channelNum call BIS_fnc_channelNumToRadioChannelID
```

### Parameters

- channelNum: Number - channel number (6..15, 26..65)

### Return Value

- Number - radio channel id (1..50)

### Examples

#### Example 1

```sqf
26 call BIS_fnc_channelNumToRadioChannelID; // 11
```
