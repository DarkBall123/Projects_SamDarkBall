## isAutonomous

- Source: https://community.bistudio.com/wiki/isAutonomous
- Revision: 364996
- Updated: 2024-07-04T19:58:06Z

- Availability: arma3 1.16
- Locality: argument global
- Groups: Remote Control

### Description

Returns whether the UAV is in autonomous mode or not.

### Syntax

```sqf
isAutonomous uav
```

### Parameters

- uav: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _isAutonomous = isAutonomous uav;
```
