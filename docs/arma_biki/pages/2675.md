## isHideBehindScripted

- Source: https://community.bistudio.com/wiki/isHideBehindScripted
- Revision: 363583
- Updated: 2024-04-07T14:54:22Z

- Availability: arma1 1.00
- Groups: Broken Commands, Object Manipulation

### Description

Return whether the vehicle has set the hideBehindScripted to true or not.

### Syntax

```sqf
isHideBehindScripted vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isHidden = isHideBehindScripted _vehicle;
```
