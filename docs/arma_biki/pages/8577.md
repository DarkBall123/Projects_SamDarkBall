## setLeader

- Source: https://community.bistudio.com/wiki/setLeader
- Revision: 330647
- Updated: 2022-10-03T11:09:06Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect local
- Groups: Teams

### Description

To set a Group leader, see selectLeader.
Set the leader of the given Team. Effect is local, unless both leader unit and team are local to PC on which command is executed, then effect is global.

### Syntax

```sqf
team setLeader leader
```

### Parameters

- team: Team Member
- leader: Team Member

### Return Value

- Nothing
