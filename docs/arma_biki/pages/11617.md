## setRotorBrakeRTD

- Source: https://community.bistudio.com/wiki/setRotorBrakeRTD
- Revision: 363578
- Updated: 2024-04-07T14:41:13Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Toggles a helicopter's rotor brake. {{Feature|afm}}

### Syntax

```sqf
helicopterRTD setRotorBrakeRTD enable
```

### Parameters

- helicopterRTD : Object - helicopter
- enable: Number - can be:
* 0: off
* 1: on

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myHelicopterRTD setRotorBrakeRTD 1;
```
