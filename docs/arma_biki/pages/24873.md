## BIS fnc camera setFOV

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_setFOV
- Revision: 349262
- Updated: 2023-11-08T14:51:06Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Sets the FOV of given camera.

### Syntax

```sqf
[camera, FOV] call BIS_fnc_camera_setFOV
```

### Parameters

- camera: Object - the camera
- FOV: Number - (Optional, default 0,75) wanted FOV

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera,0.5] call BIS_fnc_camera_setFOV;
```
