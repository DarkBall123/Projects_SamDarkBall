## BIS fnc kbCanSpeak

- Source: https://community.bistudio.com/wiki/BIS_fnc_kbCanSpeak
- Revision: 327091
- Updated: 2022-07-12T21:44:49Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Conversations

### Description

Check if person is not locked by some conversation.

### Syntax

```sqf
unit call BIS_fnc_kbCanSpeak
```

### Parameters

- unit: Object - checked person

### Return Value

- Boolean - if the person can speak

### Examples

#### Example 1

```sqf
private _canPlayerTalk = player call BIS_fnc_kbCanSpeak;
```
