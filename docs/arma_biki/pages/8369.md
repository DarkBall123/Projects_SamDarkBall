## owner

- Source: https://community.bistudio.com/wiki/owner
- Revision: 363241
- Updated: 2024-03-26T10:51:18Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, server execution server
- Groups: Multiplayer

### Description

On server machine, returns the machine network ID of the client to which the object is local. Otherwise returns 0. For use on clients clientOwner command is available. To find out the owner of a Group, use groupOwner.

### Syntax

```sqf
owner object
```

### Parameters

- object: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
_clientID = owner _someobject;
```
