## BIS fnc curatorAttachObject

- Source: https://community.bistudio.com/wiki/BIS_fnc_curatorAttachObject
- Revision: 348595
- Updated: 2023-11-08T13:44:38Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Attach an object on another one under cursor.

### Syntax

```sqf
[object] call BIS_fnc_curatorAttachObject
```

### Parameters

- object: Object - some object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[BIS_vehicle] call BIS_fnc_curatorAttachObject;
```
