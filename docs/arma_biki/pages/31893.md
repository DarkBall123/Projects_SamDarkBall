## getAllEnv3DSoundControllers

- Source: https://community.bistudio.com/wiki/getAllEnv3DSoundControllers
- Revision: 377625
- Updated: 2026-01-02T08:52:04Z

- Availability: arma3 2.08
- Groups: Sounds

### Description

Returns an array containing the names and values of environmental 3D sound controllers, variables that can be used in simple expressions when configuring sounds.
* Controller names are case sensitive
* Wind param difference:
** `wind` is for **3D** controller
** `wind**y**` is for **2D** controller (getAllEnvSoundControllers)

### Syntax

```sqf
getAllEnv3DSoundControllers object
```

### Parameters

- object: Object - environmental sound source like a tree or a house, see allEnv3DSoundSources

### Return Value

- Array with [<nowiki/>["controllerA", valueA], ["controllerB", valueB], ...], controllers being, in order:
{{Columns|3|
* `"rain"`
* `"night"`
* `"wind"`
* `"daytime"`
* `"distance"`
* `"shooting"`
* `"meadows"`
* `"trees"`
* `"houses"`
* `"forest"`
* `"sea"`
* `"altitudeSea"`
* `"altitudeGround"`
* `"rainDrops"`
* `"yearTime"`
* `"ambientTemp"`
* `"snow"`
}}

### Examples

#### Example 1

```sqf
getAllEnv3DSoundControllers _thatTreeOverThere;
/*
	returns e.g
	[
		["rain",0],
		["night",0],
		["wind",0.161588],
		...
	]
*/
```
