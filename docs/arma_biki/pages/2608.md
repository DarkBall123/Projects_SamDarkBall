### Description

Register knowledge base database to given person. See Conversations for more details.
{{Feature|important|This command is no longer available in {{arma2}} and Arma 3.}}

### Syntax

```sqf
person kbAddDatabase fileName
```

### Parameters

- person: Object
- fileName: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_hasBeenAdded = _unit kbAddDatabase "chat.txt";
```
