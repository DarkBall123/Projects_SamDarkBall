## set3DENIconsVisible

- Source: https://community.bistudio.com/wiki/set3DENIconsVisible
- Revision: 342174
- Updated: 2023-07-09T12:26:58Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Toggle visibility of Eden Editor icons.

### Syntax

```sqf
set3DENIconsVisible [showMap, showScene]
```

### Parameters

- showScene: Boolean - visibility in the scene
- showMap : Boolean - visibility in the map

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
set3DENIconsVisible [false, false]; // Hide all icons
```
