## setTitleEffect

- Source: https://community.bistudio.com/wiki/setTitleEffect
- Revision: 377582
- Updated: 2026-01-02T06:56:39Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Triggers, Waypoints

### Description

Defines the title effect to show on activation via [Type, Effect, Text] where

'Type' 

The title effect does not disappear on deactivation, this should be done manually if required.

### Syntax

```sqf
triggerOrWaypoint setTitleEffect [type, effect, text]
```

### Parameters

- triggerOrWaypoint: Object or Waypoint
- type: String - defines Title Effect Type when not NONE, can be one of:
* "NONE"
* "OBJECT" - *text* defines the shown object , a subclass of `CfgTitles` (see cutObj)
* "RES" - *text* defines a resource class, a subclass of RscTitles (see cutRsc)
* "TEXT" - *text* defines text string to show (see cutText)
- effect: String
- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_trigger setTitleEffect ["TEXT", "PLAIN DOWN", "Hello world."];
```
