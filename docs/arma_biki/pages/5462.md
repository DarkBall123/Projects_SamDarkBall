## setMarkerSizeLocal

- Source: https://community.bistudio.com/wiki/setMarkerSizeLocal
- Revision: 330367
- Updated: 2022-09-04T20:18:20Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Set marker size.

### Syntax

```sqf
markerName setMarkerSizeLocal [axisA, axisB]
```

### Parameters

- markerName: String
- axisA: Number - 1/2 width of marker
- axisB: Number - 1/2 height of marker

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"MarkerOne" setMarkerSizeLocal [100, 200];
```
