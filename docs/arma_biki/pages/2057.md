## setPosASL

- Source: https://community.bistudio.com/wiki/setPosASL
- Revision: 377438
- Updated: 2026-01-02T06:46:46Z

- Availability: ofpe 1.00, ofp 1.99, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect global
- Groups: Positions

### Description

Sets the object position above sea level. Given position must be in PositionASL format.

### Syntax

```sqf
object setPosASL pos
```

### Parameters

- object: Object
- pos: PositionASL

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player setPosASL [getPosASL player select 0, (getPosASL player select 1) + 10, getPosASL player select 2];
```

#### Example 2

```sqf
_position = getPosASL _object;
_position set [2, 10]; // 10m above sea level
_object setPosASL _position;
```
