## BIS fnc wpSlingLoadDetach

- Source: https://community.bistudio.com/wiki/BIS_fnc_wpSlingLoadDetach
- Revision: 349251
- Updated: 2023-11-08T14:51:02Z

- Availability: tkoh 1.00
- Groups: Waypoints

### Description

DETACH SLINGLOAD custom waypoint.

Unload an object which was previously loaded using BIS_fnc_wpSlingLoadAttach.

### Syntax

```sqf
Custom Waypoint arguments: [posLimit,limitDir]
```

### Parameters

- posLimit: Number - time in seconds it takes to detach the cargo (default: -1)
- limitDir: Array - direction range in which cargo has to be detached (default: [0,360])

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[player, position dude, 50, 10, [42, 52]] spawn BIS_fnc_wpSlingLoadDetach;
```
