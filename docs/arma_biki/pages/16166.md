## BIS fnc taskExists

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskExists
- Revision: 352030
- Updated: 2024-02-01T23:24:28Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Return true if a task exists. See Arma 3: Task Framework for more information.

### Syntax

```sqf
[taskName] call BIS_fnc_taskExists
```

### Parameters

- taskName: String - task name

### Return Value

- Boolean - true if it exists

### Examples

#### Example 1

```sqf
private _exists = ["MyTask"] call BIS_fnc_taskExists;
```
