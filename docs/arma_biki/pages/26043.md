## diag deltaTime

- Source: https://community.bistudio.com/wiki/diag_deltaTime
- Revision: 309147
- Updated: 2022-05-03T14:08:33Z

- Availability: arma3 1.96
- Groups: Diagnostic, Time

### Description

Returns the duration of the previous frame in seconds

### Syntax

```sqf
diag_deltaTime
```


### Return Value

- Number

### Examples

#### Example 1

```sqf
private _frameTime = diag_deltaTime;
```

#### Example 2

```sqf
private _fps = 1 / diag_deltaTime;
```
