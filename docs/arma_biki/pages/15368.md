1.22 Algorithm:

```sqf
Vector = [x,y,z];
Result = (x ^ 2) + (y ^ 2) + (z ^ 2);
```

It is recommended to use vectorMagnitudeSqr instead of BIS_fnc_magnitudeSqr.
