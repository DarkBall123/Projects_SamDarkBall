## nearestBuilding

- Source: https://community.bistudio.com/wiki/nearestBuilding
- Revision: 377548
- Updated: 2026-01-02T06:54:43Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Detection

### Description

Finds the nearest building to a given object or position. A "building" is defined as an object that is of class "House" and contains a path LOD.

### Syntax

```sqf
nearestBuilding position
```

### Parameters

- position: Object or Position2D or PositionAGL

### Return Value

- Object

### Examples

#### Example 1

```sqf
_nBuilding = nearestBuilding player;
```

#### Example 2

```sqf
_nBuilding = nearestBuilding position player;
```
