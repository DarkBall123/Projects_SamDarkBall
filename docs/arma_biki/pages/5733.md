## assignedVehicle

- Source: https://community.bistudio.com/wiki/assignedVehicle
- Revision: 330331
- Updated: 2022-08-31T15:20:27Z

- Availability: arma1 1.05, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Object Manipulation

### Description

Returns the vehicle to which a unit is assigned, usually with *assignAsXXX* command. If no vehicle is assigned objNull is returned.
See AI Group Vehicle Management for more information.

### Syntax

```sqf
assignedVehicle unit
```

### Parameters

- unit: Object

### Return Value

- Object

### Examples

#### Example 1

```sqf
_vehicle = assignedVehicle player;
```

#### Example 2

```sqf
_units apply { _x leaveVehicle (assignedVehicle _x) };
```
