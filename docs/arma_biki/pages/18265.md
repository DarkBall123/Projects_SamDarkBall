## getWeaponSway

- Source: https://community.bistudio.com/wiki/getWeaponSway
- Revision: 376211
- Updated: 2025-09-15T15:00:52Z

- Availability: arma3 1.62
- Groups: Stamina System, Weapons

### Description

Returns current size of weapon sway of a given unit, in radians. This command may still return a value greater 0 even if sway was effectively set to 0 with 

```sqf
player setCustomAimCoef 0;
```

.

### Syntax

```sqf
getWeaponSway unit
```

### Parameters

- unit: Object

### Return Value

- Number - weapon sway

### Examples

#### Example 1

```sqf
_sway = getWeaponSway player;
```
