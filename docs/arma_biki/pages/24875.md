## BIS fnc camera setCam

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_setCam
- Revision: 349229
- Updated: 2023-11-08T14:50:53Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Sets camera instance of camera object.

### Syntax

```sqf
[camera, cameraInstance] call BIS_fnc_camera_setCam
```

### Parameters

- camera: Object - the camera
- cameraInstance: Object - camera instance

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera,BIS_camera_instance] call BIS_fnc_camera_setCam;
```
