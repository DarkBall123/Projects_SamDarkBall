## backpackItems

- Source: https://community.bistudio.com/wiki/backpackItems
- Revision: 377191
- Updated: 2026-01-01T10:54:17Z

- Availability: arma3 0.50
- Groups: Containers

### Description

Get array with all items (of any kind, even weapons) in backpack of the given unit.

### Syntax

```sqf
backpackItems unit
```

### Parameters

- unit: Object

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
backpackItems player; // returns e.g ["hgun_P07_F", "Titan_AT"]
```
