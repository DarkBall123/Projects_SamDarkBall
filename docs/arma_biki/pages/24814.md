## BIS fnc disableRevive

- Source: https://community.bistudio.com/wiki/BIS_fnc_disableRevive
- Revision: 348214
- Updated: 2023-11-08T11:40:18Z

- Availability: arma3 1.42
- Groups: Revive

### Description

Disable revive on given unit.

### Syntax

```sqf
[player] call BIS_fnc_disableRevive
```

### Parameters

- player: Object - affected player

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_unit] call BIS_fnc_disableRevive;
```
