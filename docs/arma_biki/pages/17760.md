## setStaminaScheme

- Source: https://community.bistudio.com/wiki/setStaminaScheme
- Revision: 364828
- Updated: 2024-06-16T09:53:48Z

- Availability: arma3 1.54
- Groups: Stamina System

### Description

Sets the scheme used for the Stamina system.

### Syntax

```sqf
setStaminaScheme scheme
```

### Parameters

- scheme: String Enum
* "Normal"
* "FastDrain"
* "Exhausted"
* "Default"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setStaminaScheme "Default";
```
