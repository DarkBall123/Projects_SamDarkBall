## move3DENCamera

- Source: https://community.bistudio.com/wiki/move3DENCamera
- Revision: 377459
- Updated: 2026-01-02T06:47:27Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Moves the Eden Editor camera.

### Syntax

```sqf
move3DENCamera [position, useOffset]
```

### Parameters

- position: PositionASL - new position
- useOffset: Boolean
* if true the camera will move to the *position*, add the offset defined in 

```sqf
configFile >> "Cfg3DEN" >> "Camera" >> "moveOffset"
```

 and look at the *position*.  Default camera offset: `[0, -25, 25]`
* if false, the camera will be moved to the exact *position*

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
move3DENCamera [getPosASL player, true];
```
