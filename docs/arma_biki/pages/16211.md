## BIS fnc getVirtualWeaponCargo

- Source: https://community.bistudio.com/wiki/BIS_fnc_getVirtualWeaponCargo
- Revision: 348647
- Updated: 2023-11-08T13:48:23Z

- Availability: arma3 1.24
- Groups: Inventory

### Description

Get virtual weapons from an object (e.g., ammo box). Virtual items can be selected in the Arsenal.

### Syntax

```sqf
object call BIS_fnc_getVirtualWeaponCargo
```

### Parameters

- object: Object

### Return Value

- Array of Strings - all virtual weapons

### Examples

#### Example 1

```sqf
BIS_ammoBox call BIS_fnc_getVirtualWeaponCargo;
```
