- Updated: 2026-01-03T00:21:54Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50

### Description

Sets background color of given control. Only affects:
{{Columns|2|
* CT_COMBO
* CT_STATIC
* CT_STRUCTURED_TEXT
* CT_MAP
* CT_MAP_MAIN
* 2.02 CT_BUTTON
* 2.02 CT_SHORTCUTBUTTON
* 2.02 CT_ACTIVETEXT
}}

### Syntax

```sqf
control ctrlSetBackgroundColor color
```

### Parameters

- control: Control
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetBackgroundColor [1, 0, 0, 1];
```
