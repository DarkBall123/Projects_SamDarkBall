## setMarkerShapeLocal

- Source: https://community.bistudio.com/wiki/setMarkerShapeLocal
- Revision: 370123
- Updated: 2024-11-01T19:52:42Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Selects shape (actual type) of the local marker. Non-existing marker shape defaults to "RECTANGLE".

### Syntax

```sqf
markerName setMarkerShapeLocal shape
```

### Parameters

- markerName: String
- shape: String - the shape, can be one of:
* `"ICON"`
* `"RECTANGLE"`
* `"ELLIPSE"`
* 1.60 `"POLYLINE"`
* 2.20 `"TRIANGLE"`
* 2.20 `"PENTAGON"`
* 2.20 `"HEXAGON"`
* 2.20 `"HEPTAGON"`
* 2.20 `"OCTAGON"`
* 2.20 `"NONAGON"`
* 2.20 `"DECAGON"`

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
"Marker1" setMarkerShapeLocal "RECTANGLE";
```
