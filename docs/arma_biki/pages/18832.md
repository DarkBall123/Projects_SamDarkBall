## BIS fnc paramReviveRequiredTrait

- Source: https://community.bistudio.com/wiki/BIS_fnc_paramReviveRequiredTrait
- Revision: 370326
- Updated: 2024-11-27T10:38:52Z

- Availability: arma3 1.62
- Groups: Mission Parameters

### Description

Stores the provided value in the global `BIS_reviveParam_requiredTrait` mission variable.

### Syntax

```sqf
[value] call BIS_fnc_paramReviveRequiredTrait
```

### Parameters

- value: Number - (Optional, default -100)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[42] call BIS_fnc_paramReviveRequiredTrait;	// BIS_reviveParam_requiredTrait is now 42
"hi" call BIS_fnc_paramReviveRequiredTrait;	// BIS_reviveParam_requiredTrait is now -100
42 call BIS_fnc_paramReviveRequiredTrait;	// BIS_reviveParam_requiredTrait is now 42
call BIS_fnc_paramReviveRequiredTrait;		// BIS_reviveParam_requiredTrait is now -100
```
