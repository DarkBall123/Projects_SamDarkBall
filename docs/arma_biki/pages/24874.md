## BIS fnc camera setCinemaBordersEnabled

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_setCinemaBordersEnabled
- Revision: 378073
- Updated: 2026-02-11T08:04:24Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Sets cinema borders.

### Syntax

```sqf
[camera, enabled] call BIS_fnc_camera_setCinemaBordersEnabled
```

### Parameters

- camera: Object - the camera
- enabled: Boolean - (Optional, default false) true to show cinema borders, false to hide them.

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera, true] call BIS_fnc_camera_setCinemaBordersEnabled;
```
