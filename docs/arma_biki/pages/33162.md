## Arma 3: Invaders

- Source: https://community.bistudio.com/wiki/Arma_3:_Invaders
- Revision: 347368
- Updated: 2023-09-14T10:36:54Z

thumb|right|The first level of Invaders
**Invaders** is a minigame in the Arma 3 main menu. By default, it is only available during [Arma 3 Steam sales](https://store.steampowered.com/app/107410/Arma_3/). Completing the minigame unlocks the *Arma Invaders* achievement and turns the Arma 3 logo in the main menu golden.

Invaders first appeared during the [Bohemia Interactive Publisher Sale 2022](https://store.steampowered.com/news/group/32984825/view/3400798954869678243) (2.10).

A New Game+ mode and player vehicle swap to the T-100X railgun tank were added in 2.14.

### Known Issues

*Invaders does not start if Arma 3 is launched with mods that modify the main menu (unless they were whitelisted: ACE).
*Sometimes pressing {{Controls|Space}} opens the Steam overlay; close the Steam overlay and click on a non-interactive part of the main menu.
This might be related to {{Controls|Alt|Tab}} usage, with {{Controls|Tab}} moving the focus and {{Controls|Space}} clicking the selected button.

### Advanced

The Invaders minigame can be opted out of (or back in) by executing the following code (for example with the Debug Console in the Eden Editor):
```mediawiki-table
{| class="wikitable"
!Opt out of Invaders
!Opt in to Invaders
|-
|

```sqf
profileNamespace setVariable ["BIN_ArmaInvadersOff", true];
saveProfileNamespace;
```

|

```sqf
profileNamespace setVariable ["BIN_ArmaInvadersOff", nil];
saveProfileNamespace;
```

|}
```

The following code can be used to activate and play Invaders regardless of ongoing Arma 3 sales:
```mediawiki-table
{| class="wikitable valign-bottom"
!Override default behaviour
!Restore default behaviour
|-
|

```sqf
/*
	Possible values:
		0: deactivate Invaders
		1: set a 'lite' sale promotion mode
		2: activate Invaders
*/
profileNamespace setVariable ["BIN_ArmaInvadersOfflineBypass", 2];
saveProfileNamespace;
```

|

```sqf
profileNamespace setVariable ["BIN_ArmaInvadersOfflineBypass", nil];
saveProfileNamespace;
```

|}
```
