## diag getTerrainSegmentOffset

- Source: https://community.bistudio.com/wiki/diag_getTerrainSegmentOffset
- Revision: 377557
- Updated: 2026-01-02T06:54:58Z

- Availability: arma3 2.04
- Groups: Diagnostic

### Description

Returns the terrain segment. It is basically the same as:

```sqf
_worldPos params ["_x", "_y"];
[floor (_x / diag_getTerrainGrid), floor (_y / diag_getTerrainGrid)];
```

### Syntax

```sqf
diag_getTerrainSegmentOffset  worldPos
```

### Parameters

- worldPos: Position2D or Position3D - world coordinates

### Return Value

- Position2D - [x,y] of terrain segment (integer, basically pixel coordinates in heightmap)

### Examples

#### Example 1

```sqf
private _segmentOffset = diag_getTerrainSegmentOffset getPosWorld player;
```
