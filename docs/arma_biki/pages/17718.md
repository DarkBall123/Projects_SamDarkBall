## Eden Entity

- Source: https://community.bistudio.com/wiki/Eden_Entity
- Revision: 342177
- Updated: 2023-07-09T12:26:58Z

Eden Entity is an entity which can be created, edited or deleted in the Eden Editor.

It is not a unique data type; instead it represents one of the existing types:
```mediawiki-table
{| class="wikitable"
|-
! Data Type !! Eden Entity
|-
| Object || Eden Editor Object
|-
| Group || Eden Editor Group
|-
| Object || Eden Editor Trigger
|-
| Object || Eden Editor System
|-
| Array || Eden Editor Waypoint
|-
| String || Eden Editor Marker
|-
| Number || Eden Editor Layer
|-
| Number || Eden Editor Comment
|}
```
