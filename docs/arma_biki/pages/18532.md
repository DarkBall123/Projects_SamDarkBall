## ctRowControls

- Source: https://community.bistudio.com/wiki/ctRowControls
- Revision: 377175
- Updated: 2026-01-01T10:46:47Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Returns array of controls on the row with the given index.

### Syntax

```sqf
control ctRowControls index
```

### Parameters

- control: Control
- index: Number

### Return Value

- Array of Controls

### Examples

#### Example 1

```sqf
_array = _control ctRowControls 0;
```
