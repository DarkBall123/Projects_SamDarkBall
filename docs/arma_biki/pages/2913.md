## ctrlShown

- Source: https://community.bistudio.com/wiki/ctrlShown
- Revision: 310874
- Updated: 2022-05-07T20:24:10Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns whether given control is shown.

### Syntax

```sqf
ctrlShown controlName
```

### Parameters

- controlName: Control

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_bool = ctrlShown _ctrl;
```

ctrlShow ctrlVisible
