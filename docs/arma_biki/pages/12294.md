## removeAllMusicEventHandlers

- Source: https://community.bistudio.com/wiki/removeAllMusicEventHandlers
- Revision: 322941
- Updated: 2022-06-28T21:42:45Z

- Availability: arma3 0.50
- Groups: Event Handlers, Sounds

### Description

Removes all music track event handlers of given type.

### Syntax

```sqf
removeAllMusicEventHandlers type
```

### Parameters

- type: String - "MusicStart" or "MusicStop"

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllMusicEventHandlers "MusicStart";
```

#### Example 2

```sqf
removeAllMusicEventHandlers "MusicStop";
```
