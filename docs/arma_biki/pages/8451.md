## showSubtitles

- Source: https://community.bistudio.com/wiki/showSubtitles
- Revision: 363292
- Updated: 2024-03-26T10:51:59Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Radio and Chat

### Description

Enables / disables showing of subtitles in a chat. Only scripted/engine chatter is affected, player manual chat is unaffected. Returns the previous state.

### Syntax

```sqf
showSubtitles enable
```

### Parameters

- enable: Boolean

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
showSubtitles false;
```
