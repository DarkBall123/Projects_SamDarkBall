## vectorModelToWorldVisual

- Source: https://community.bistudio.com/wiki/vectorModelToWorldVisual
- Revision: 378406
- Updated: 2026-04-04T08:14:52Z

- Availability: arma3 1.72
- Groups: Math - Vectors, Render Time Scope

### Description

Converts vector from model to world space in render time scope.
For scaled objects, the resulting vector's magnitude will also be multiplied by the object scale.

### Syntax

```sqf
object vectorModelToWorldVisual modelDir
```

### Parameters

- object: Object
- modelDir: Vector3D - vector direction in model space in format [x,y,z]

### Return Value

- Vector3D - vector direction in world space in format [x,y,z]

### Examples

#### Example 1

Convert model space vector [0,-10,4] to world space; vector gets rotated according to _airplane: 

```sqf
_airplane vectorModelToWorldVisual [0,-10,4];
```
