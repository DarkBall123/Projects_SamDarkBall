## values

- Source: https://community.bistudio.com/wiki/values
- Revision: 376075
- Updated: 2025-07-27T22:51:40Z

- Availability: arma3 2.04
- Groups: HashMap

### Description

Returns all values stored in the given HashMap. The order of the returned Array corresponds to the order of the Array returned by the keys command.

### Syntax

```sqf
values hashmap
```

### Parameters

- hashmap: HashMap

### Return Value

- Array - all values stored in *hashmap*

### Examples

#### Example 1

```sqf
private _values = values _myHashMap;
```
