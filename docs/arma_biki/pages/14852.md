### Description

Removes curator camera area.

### Syntax

```sqf
curatorObj removeCuratorCameraArea cameraAreaID
```

### Parameters

- curatorObj: Object - curator module.
- cameraAreaID: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myCurator removeCuratorCameraArea 3;
```
