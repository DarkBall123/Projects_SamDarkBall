## deleteMarkerLocal

- Source: https://community.bistudio.com/wiki/deleteMarkerLocal
- Revision: 338570
- Updated: 2023-03-20T14:55:35Z

- Availability: arma1 1.04, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: Markers

### Description

Destroys the given marker.

### Syntax

```sqf
deleteMarkerLocal markerName
```

### Parameters

- markerName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
deleteMarkerLocal "Marker1";
```
