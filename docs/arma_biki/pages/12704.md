## everyBackpack

- Source: https://community.bistudio.com/wiki/everyBackpack
- Revision: 376077
- Updated: 2025-07-28T13:01:43Z

- Availability: arma3 1.04
- Groups: Containers

### Description

Returns array of backpacks stored in given crate or vehicle. Used for accessing backpack content of a backpack on ground.

### Syntax

```sqf
everyBackpack box
```

### Parameters

- box: Object

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
everyBackpack cursorTarget;
```

#### Example 2

```sqf
_vehicleBackpacks = everyBackpack vehicle player;
```
