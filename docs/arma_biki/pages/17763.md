## isStaminaEnabled

- Source: https://community.bistudio.com/wiki/isStaminaEnabled
- Revision: 321931
- Updated: 2022-05-22T12:50:06Z

- Availability: arma3 1.54
- Locality: argument global
- Groups: Stamina System

### Description

Check if stamina depletion is enabled.

### Syntax

```sqf
isStaminaEnabled  unit
```

### Parameters

- unit: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (isStaminaEnabled player) then { hint "You can get exhausted." };
```
