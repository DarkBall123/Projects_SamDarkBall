## waypointShow

- Source: https://community.bistudio.com/wiki/waypointShow
- Revision: 378529
- Updated: 2026-05-04T02:16:33Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

A getter for showWaypoint command.

### Syntax

```sqf
waypointShow waypoint
```

### Parameters

- waypoint: Waypoint

### Return Value

- String - can return:
* "NEVER" - Never show
* "EASY" - Show only in cadet mode
* "ALWAYS" - Always show
* "ERROR" - When set to any different string

### Examples

#### Example 1

```sqf
_wpShow = waypointShow [groupOne, 1];
```
