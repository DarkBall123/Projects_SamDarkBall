## ropeUnwound

- Source: https://community.bistudio.com/wiki/ropeUnwound
- Revision: 369179
- Updated: 2024-09-03T10:34:44Z

- Availability: arma3 1.34
- Groups: Ropes and Sling Loading

### Description

Returns false if rope length changing animation is in progress. Returns true if animation is done.

### Syntax

```sqf
ropeUnwound rope
```

### Parameters

- rope: Object - given rope object

### Return Value

- Boolean - true if unwinding is complete

### Examples

#### Example 1

```sqf
waitUntil { ropeUnwound (ropes heli1 select 0) };
hint "Unwinding Complete";
```
