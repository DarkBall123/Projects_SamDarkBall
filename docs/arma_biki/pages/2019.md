## preloadTitleObj

- Source: https://community.bistudio.com/wiki/preloadTitleObj
- Revision: 363768
- Updated: 2024-04-19T08:56:31Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Preloads data for the given resource object.

### Syntax

```sqf
preloadTitleObj [name, type, speed, showInMap]
```

### Parameters

- name: String - defined in 

```sqf
configFile >> "CfgTitles" >> name
```
- type: String - see Title Effect Types
- speed: Number - (Optional, default -1)
- showInMap: Boolean - (Optional, default true)

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_ok = preloadTitleObj ["BISLogo", "PLAIN"];
```
