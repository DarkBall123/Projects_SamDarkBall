## groupChat

- Source: https://community.bistudio.com/wiki/groupChat
- Revision: 376775
- Updated: 2025-11-17T00:05:36Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Radio and Chat

### Description

Types text to the group radio channel. The text will be visible only on the PC where command was executed. If you need the message to show on all computers, you have to execute it globally (see remoteExec). Use clearRadio to clear chat history

The unit must have an assigned radio item (such as ***"ItemRadio"***) to see or transmit the messages. A radio item must have the property 

```
simulation = "ItemRadio";
```

 in its CfgWeapons config.

### Syntax

```sqf
unit groupChat chatText
```

### Parameters

- unit: Object - unit transmitting message
- chatText: String - message to transmit

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldierOne groupChat "Show this text";
```
