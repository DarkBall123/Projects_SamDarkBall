## addCuratorCameraArea

- Source: https://community.bistudio.com/wiki/addCuratorCameraArea
- Revision: 378612
- Updated: 2026-05-13T17:01:55Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Adds or changes curator camera area (depends on if ID is already used).

### Syntax

```sqf
curatorObj addCuratorCameraArea [cameraAreaID, position, radius]
```

### Parameters

- curatorObj: Object - curator module.
- cameraAreaID: Number
- position: Position
- radius: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myCurator addCuratorCameraArea [3, position mySoldier, 300];
```
