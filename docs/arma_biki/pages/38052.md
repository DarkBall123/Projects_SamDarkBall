## getLoginStatus

- Source: https://community.bistudio.com/wiki/getLoginStatus
- Revision: 351572
- Updated: 2023-12-07T17:00:51Z

- Availability: argo 1.00
- Groups: Argo

### Description

Get the client's current Cloud service login status.

### Syntax

```sqf
getLoginStatus
```


### Return Value

- Number - can be one of:
*  0: Not logged in
*  1: Logged in with a bi account
*  2: Logged in as guest
* -1: Internal error

### Examples

#### Example 1

```sqf
switch (getLoginStatus) do
{
	case 0:		{ hint "Not logged" };
	case 1:		{ hint "You are BI-approved, gooooood" };
	case 2:		{ hint "Logged in as a Guest? 2, target that man!" };
	case -1:	{ hint "Something went wrong" };
};
```
