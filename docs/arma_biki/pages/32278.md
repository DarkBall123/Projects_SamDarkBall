## setPiPViewDistance

- Source: https://community.bistudio.com/wiki/setPiPViewDistance
- Revision: 309141
- Updated: 2022-05-03T11:52:25Z

- Availability: arma3 2.08
- Locality: effect local
- Groups: System

### Description

Set the PiP (Picture-in-Picture) view distance. This has no impact if PiP is disabled (see isPiPEnabled).

### Syntax

```sqf
setPiPViewDistance distance
```

### Parameters

- distance: Number - distance in meters, minimum value is 100, maximum is current view distance

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setPiPViewDistance 100;
```

#### Example 2

```sqf
setPiPViewDistance viewDistance;
```

#### Example 3

```sqf
setPiPViewDistance getObjectViewDistance;
```
