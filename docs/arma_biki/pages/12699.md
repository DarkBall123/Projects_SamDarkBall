## HUDMovementLevels

- Source: https://community.bistudio.com/wiki/HUDMovementLevels
- Revision: 378504
- Updated: 2026-05-03T16:49:48Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Interaction

### Description

Returns movement borders for HUD

### Syntax

```sqf
HUDMovementLevels
```


### Return Value

- Array with [minSpeed, maxSpeed, minAlt, maxAlt, minDir, maxDir, positionOrTarget]
* minSpeed: Number - in m/s
* maxSpeed: Number - in m/s
* minAlt: Number - in meters
* maxAlt: Number - in meters
* minDir: Number - in degrees
* maxDir: Number - in degrees
* positionOrTarget: Position, Object

### Examples

#### Example 1

```sqf
HUDMovementLevels; // returns e.g [0,0,0,0,0,0,[0,0,0]]
```
