- Revision: 329329
- Updated: 2022-07-27T10:15:19Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect local
- Groups: GUI

### Description

thumb|right|Example (Click to enlarge) Display a text in the "mission" GUI area with some effects. Good for the beginning of a mission.

### Syntax

```sqf
[string_1, string_2, string_n] spawn BIS_fnc_infoText
```

### Parameters

- Array of Strings

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["Somewhere on Altis", format ["Year %1", date select 0], mapGridPosition player] spawn BIS_fnc_infoText;
```
