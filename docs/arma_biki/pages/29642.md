## ctrlSetTooltipMaxWidth

- Source: https://community.bistudio.com/wiki/ctrlSetTooltipMaxWidth
- Revision: 310331
- Updated: 2022-05-05T16:44:26Z

- Availability: arma3 2.06
- Groups: GUI Control

### Description

Set maximum width of a control's tooltip.

### Syntax

```sqf
ctrl ctrlSetTooltipMaxWidth width
```

### Parameters

- ctrl: Control
- width: Number - in screen measurement units

### Return Value

- Number - the previous maximum width of the tooltip

### Examples

#### Example 1

```sqf
private _previousMaxWidth = _myControl ctrlSetTooltipMaxWidth (SafeZoneW / 2);
```
