## setWaypointDescription

- Source: https://community.bistudio.com/wiki/setWaypointDescription
- Revision: 377757
- Updated: 2026-01-03T00:58:15Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Waypoints

### Description

Sets the description shown in the HUD while the waypoint is active.

### Syntax

```sqf
waypoint setWaypointDescription text
```

### Parameters

- waypoint: Waypoint
- text: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointDescription "Move here.";
```
