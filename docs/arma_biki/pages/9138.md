## checkAIFeature

- Source: https://community.bistudio.com/wiki/checkAIFeature
- Revision: 369971
- Updated: 2024-10-22T12:51:32Z

- Availability: arma2 1.05, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: AI Behaviour

### Description

Checks if the given AI feature is currently enabled.

### Syntax

```sqf
checkAIFeature feature
```

```sqf
unit checkAIFeature feature
```

### Parameters

- feature: String - can be one of:
* `"AwareFormationSoft"`
* `"CombatFormationSoft"`
* AI skill - see disableAI#Syntax 1 (since Arma 3 v1.96)
- unit: Object - unit to test AI feature for
- feature: String - disableAI / enableAI feature

### Return Value

- Boolean - true if is enabled
- Boolean - true if is enabled

### Examples

#### Example 1

```sqf
_featureUsed = checkAIFeature "AwareFormationSoft";
```

#### Example 2

```sqf
_autotargetOn = bob checkAIFeature "AUTOTARGET";
```
