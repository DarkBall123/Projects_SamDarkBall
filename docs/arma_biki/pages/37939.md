## focusOn

- Source: https://community.bistudio.com/wiki/focusOn
- Revision: 363319
- Updated: 2024-03-26T16:41:39Z

- Availability: arma3 2.16
- Groups: Camera Control, Remote Control

### Description

Returns the person the camera is focused on. If you need the vehicle, see cameraOn.

### Syntax

```sqf
focusOn
```


### Return Value

- Object - controlled person or objNull if no unit is controlled

### Examples

#### Example 1

```sqf
private _currentlyControlledUnit = focusOn;
```

#### Example 2

```sqf
if (isNull player) exitWith { /* no player */ };

if (player == focusOn) then
{
	hint "You are controlling your player unit";
}
else
{
	hint "You are remote-controlling a unit";
};
```
