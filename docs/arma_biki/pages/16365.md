## BIS fnc isForcedCuratorInterface

- Source: https://community.bistudio.com/wiki/BIS_fnc_isForcedCuratorInterface
- Revision: 327095
- Updated: 2022-07-12T21:44:49Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Return if curator interface is forced (user cannot leave it by pressing Zeus key).

### Syntax

```sqf
[] call BIS_fnc_isForcedCuratorInterface
```


### Return Value

- Boolean - true if forced, else false

### Examples

#### Example 1

```sqf
private _isForced = call BIS_fnc_isForcedCuratorInterface;
```
