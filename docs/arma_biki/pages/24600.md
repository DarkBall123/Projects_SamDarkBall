## BIS fnc hideMarker

- Source: https://community.bistudio.com/wiki/BIS_fnc_hideMarker
- Revision: 373735
- Updated: 2025-06-24T12:24:32Z

- Availability: arma3 1.78
- Locality: argument global, effect global
- Groups: Map and Markers

### Description

Gradual hiding of a marker by setting its alpha to 0.

### Syntax

```sqf
[marker, duration] spawn BIS_fnc_hideMarker
```

### Parameters

- marker: String - marker name
- duration: Number - (Optional, default 1) duration of the hiding

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["BIS_marker",2] spawn BIS_fnc_hideMarker;
```
