## lockTurret

- Source: https://community.bistudio.com/wiki/lockTurret
- Revision: 377482
- Updated: 2026-01-02T06:48:59Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Turrets

### Description

Lock the gunner position of the vehicle turret.
This command will remove user "get in" action (not "get out") but will also stop player getting into vehicle via script commands unlike lock command.

### Syntax

```sqf
vehicle lockTurret [turretPath, lock]
```

### Parameters

- vehicle: Object
- turretPath: Turret Path
- lock: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
vehicleName lockTurret [[0,0], true];
```

#### Example 2

```sqf
vehicle player lockTurret [[0], true];
```
