## backpackMagazines

- Source: https://community.bistudio.com/wiki/backpackMagazines
- Revision: 321381
- Updated: 2022-05-14T11:03:57Z

- Availability: arma3 0.50
- Groups: Containers, Unit Inventory

### Description

Get array with all magazines from backpack of the given unit.

### Syntax

```sqf
backpackMagazines unit
```

### Parameters

- unit: Object

### Return Value

- Array of String

### Examples

#### Example 1

```sqf
backpackMagazines player;
// returns e.g
/*
[
	"Titan AT Missile(1/1)[id/cr:16/0](2x)"
]
*/
```
