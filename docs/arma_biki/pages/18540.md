## ctFindRowHeader

- Source: https://community.bistudio.com/wiki/ctFindRowHeader
- Revision: 310883
- Updated: 2022-05-07T20:26:57Z

- Availability: arma3 1.70
- Locality: argument local, effect local
- Groups: GUI Control - Controls Table

### Description

Gets index of the closest header above this row.

### Syntax

```sqf
ctrl ctFindRowHeader rowIndex
```

### Parameters

- ctrl: Control
- rowIndex: Number

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _index = _control ctFindRowHeader 0;
```
