## assignedCommander

- Source: https://community.bistudio.com/wiki/assignedCommander
- Revision: 318788
- Updated: 2022-05-13T09:21:30Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control, Object Manipulation

### Description

Returns the soldier assigned to the given vehicle as a commander.

### Syntax

```sqf
assignedCommander  vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Object

### Examples

#### Example 1

```sqf
_commander = assignedCommander vehicleName;
```
