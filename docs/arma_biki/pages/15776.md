## BIS fnc dbClassCheck

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbClassCheck
- Revision: 327252
- Updated: 2022-07-12T22:11:49Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Check if class exists in Scripted Database.

### Syntax

```sqf
[databaseArray, path] call BIS_fnc_dbClassCheck
```

### Parameters

- databaseArray - Array: An array in the Scripted Database format
- path - Array: Database path to be checked

### Return Value

- Boolean: True if class exists

### Examples

#### Example 1

```sqf
[["#MILLER", ["&NAME", "Miller", "&UID", "1234", "&MONEY", 1000], ["miller"]] call BIS_fnc_dbClassCheck // true
```
