## locked

- Source: https://community.bistudio.com/wiki/locked
- Revision: 310835
- Updated: 2022-05-07T20:23:59Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Check if vehicle is locked. If it is locked, Persons cannot mount / dismount without order.

### Syntax

```sqf
locked vehicle
```

### Parameters

- vehicle: Object

### Return Value

- * Number - since 0.50
** 0: Unlocked
** 1: Default - a subordinate player cannot enter without AI leader order
** 2: Locked
** 3: Locked for player
** -1: vehicle is null
* Boolean for older games

### Examples

#### Example 1

```sqf
_locked = locked _jeepOne;
```
