## forcedMap

- Source: https://community.bistudio.com/wiki/forcedMap
- Revision: 377695
- Updated: 2026-01-02T09:03:18Z

- Availability: arma3 1.62
- Groups: Map, Interaction

### Description

Returns if map was forced by using forceMap command or openMap command with force option

### Syntax

```sqf
forcedMap
```


### Return Value

- Array with [forceMapForced, openMapForced]
* forceMapForced: Boolean - true if map was forced with forceMap command
* openMapForced: Boolean - true if map was forced with openMap command.

### Examples

#### Example 1

```sqf
_forceMapForced = forcedMap select 0;
_openMapForced = forcedMap select 1;
```
