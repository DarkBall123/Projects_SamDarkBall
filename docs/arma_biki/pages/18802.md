## BIS fnc animalRandomization

- Source: https://community.bistudio.com/wiki/BIS_fnc_animalRandomization
- Revision: 325112
- Updated: 2022-07-01T12:25:00Z

- Availability: arma3 1.00
- Locality: argument local, effect global
- Groups: Ambient

### Description

Randomise animals skin.

Works on:
* "Alsatian_Random_F"
* "ButterFly_random"
* "Cock_random_F"
* "Fin_random_F"
* "Goat_random_F"
* "Sheep_random_F"
* "Snake_random_F"

### Syntax

```sqf
animal call BIS_fnc_animalRandomization
```

### Parameters


### Return Value

- Nothing

```sqf
myDog call BIS_fnc_animalRandomization;
```
