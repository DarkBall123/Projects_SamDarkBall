## attackEnabled

- Source: https://community.bistudio.com/wiki/attackEnabled
- Revision: 321158
- Updated: 2022-05-13T15:07:49Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Groups, Unit Control

### Description

Return whether a group's leader can issue attack commands to soldiers under his command.

### Syntax

```sqf
attackEnabled name
```

### Parameters

- name: Object or Group

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
if (not attackEnabled _soldier) then { _soldier setCombatMode "Careless" };
```
