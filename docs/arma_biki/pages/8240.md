## displayRemoveAllEventHandlers

- Source: https://community.bistudio.com/wiki/displayRemoveAllEventHandlers
- Revision: 319041
- Updated: 2022-05-13T09:22:14Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Event Handlers, Event Handlers

### Description

Remove all event handlers from the given display.

### Syntax

```sqf
display displayRemoveAllEventHandlers eventName
```

### Parameters

- display: Display
- eventName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
findDisplay 46 displayRemoveAllEventHandlers "KeyDown";
```
