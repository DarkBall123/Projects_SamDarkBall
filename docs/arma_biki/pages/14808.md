## setSpeech

- Source: https://community.bistudio.com/wiki/setSpeech
- Revision: 319558
- Updated: 2022-05-13T09:24:28Z

- Availability: arma3 1.12
- Groups: Locations

### Description

Add speech to location.

### Syntax

```sqf
location setSpeech speech
```

### Parameters

- location: Location
- speech: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_location setSpeech "SomeSpeech";
```
