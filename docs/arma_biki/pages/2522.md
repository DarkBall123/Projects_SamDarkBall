## verifySignature

- Source: https://community.bistudio.com/wiki/verifySignature
- Revision: 319877
- Updated: 2022-05-13T09:25:38Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Mods and Addons

### Description

Check if file is signed by any key present in game keys folders. On clients, it does not check against the keys accepted by server.

### Syntax

```sqf
verifySignature filename
```

### Parameters

- filename: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
verifySignature "@MyAddon\Addons\SomeAddon.pbo";
```

#### Example 2

```sqf
verifySignature "@MyAddon\Somefnc.dll";
```
