## moveToCompleted

- Source: https://community.bistudio.com/wiki/moveToCompleted
- Revision: 369921
- Updated: 2024-10-19T12:27:30Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Unit Control

### Description

Check if latest low level moveTo command is finished. Returns true if given AI pilot unit state == COMPLETED

### Syntax

```sqf
moveToCompleted  person
```

### Parameters

- person: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_isCompleted = moveToCompleted _unit;
```
