## setWindForce

- Source: https://community.bistudio.com/wiki/setWindForce
- Revision: 322971
- Updated: 2022-06-28T21:42:53Z

- Availability: arma3 0.50
- Groups: Environment

### Description

Set max. wind overall wind changes in time. A time of zero means there will be an immediate change. A wind level of zero is minimal changes and a wind level of one means that wind can change rapidly.

### Syntax

```sqf
time setWindForce wind
```

### Parameters

- time: Number
- wind: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
1800 setWindForce 0.5;
```
