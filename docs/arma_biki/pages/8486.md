### Description

Sets the text and command for the menu item. Index is index returned by addMenuItem command. Command is optional.
Some Old Editor Command

### Syntax

```sqf
map updateMenuItem [menu item index, text, command]
```

### Parameters

- map: Control
- menu item index: Number - See addMenuItem
- text: String
- command: String

### Return Value

- Nothing
