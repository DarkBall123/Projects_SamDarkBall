## setFromEditor

- Source: https://community.bistudio.com/wiki/setFromEditor
- Revision: 322969
- Updated: 2022-06-28T21:42:52Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Set if given team member was inserted directly from editor.

### Syntax

```sqf
teamMember setFromEditor fromEditor
```

### Parameters

- teamMember: Team Member
- fromEditor: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_teamMember setFromEditor true;
```
