## BIS fnc invSlotsEmpty

- Source: https://community.bistudio.com/wiki/BIS_fnc_invSlotsEmpty
- Revision: 349403
- Updated: 2023-11-08T16:27:25Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Inventory

### Description

Returns empty inventory slots of given unit.

### Syntax

```sqf
[object] call BIS_fnc_invSlotsEmpty
```

### Parameters

- object: Object

### Return Value

- Array - array with empty slots

### Examples

#### Example 1

```sqf
[player] call BIS_fnc_invSlotsEmpty;//Can return [0,0,-1,-7,0,-1,0,-12]
```
