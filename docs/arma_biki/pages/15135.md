## BIS fnc call

- Source: https://community.bistudio.com/wiki/BIS_fnc_call
- Revision: 327597
- Updated: 2022-07-13T09:49:02Z

- Availability: arma3 0.50
- Groups: Program Flow

### Description

Execute given code with or without parameter.
Since 1.50, use remoteExec/remoteExecCall instead.

### Syntax

```sqf
[params, code] call BIS_fnc_call
```

```sqf
code call BIS_fnc_call
```

### Parameters

- params: Anything - function arguments
- code: Code - function code
- code: Code

### Return Value

- Anything
- Anything

### Examples

#### Example 1

Show a message for the current player.

```sqf
[["Hello"], {hint (_this select 0);}] call BIS_fnc_call;
```

#### Example 2

Alternative syntax

```sqf
{ hint "Hello"; } call BIS_fnc_call;
```
