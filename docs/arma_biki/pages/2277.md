## Error Generic Error in Expression

- Source: https://community.bistudio.com/wiki/Error_Generic_Error_in_Expression
- Revision: 363360
- Updated: 2024-03-27T12:35:11Z

This error occurs when the type of data an operator is expecting does not match.

**Compatibility:**

Version **1.96**

**Example:**

```sqf
_myString = "The meaning of life is " + 42;					// error
_myString = "The meaning of life is " + str 42;				// OK
_myString = "The meaning of life is " + format ["%1", 42];	// OK - ofp
```

Category:Common Scripting Errors
