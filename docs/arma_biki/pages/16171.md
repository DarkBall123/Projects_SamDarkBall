## BIS fnc taskSetCurrent

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskSetCurrent
- Revision: 352102
- Updated: 2024-02-01T23:24:52Z

- Availability: arma3 1.00
- Locality: argument global, effect global
- Groups: Tasks

### Description

Set a task to current. Identical to assigning a task. See Arma 3: Task Framework.

### Syntax

```sqf
taskName call BIS_fnc_taskSetCurrent
```

### Parameters

- taskName: String
- showNotification: Boolean - (Optional, default true) true to show notification, false to disable it

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
"BIS_task_01" call BIS_fnc_taskSetCurrent;
```

#### Example 2

```sqf
["BIS_task_01", false] call BIS_fnc_taskSetCurrent; //Assign without notificiation
```
