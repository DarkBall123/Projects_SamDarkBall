## isUniformAllowed

- Source: https://community.bistudio.com/wiki/isUniformAllowed
- Revision: 319160
- Updated: 2022-05-13T09:23:17Z

- Availability: arma3 1.22
- Locality: argument global
- Groups: Unit Inventory

### Description

Check whether given uniform can be dressed by target soldier.

### Syntax

```sqf
unit isUniformAllowed type
```

### Parameters

- unit: Object
- type: String

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_canUse = _unit isUniformAllowed "U_B_CombatUniform_mcam";
```
