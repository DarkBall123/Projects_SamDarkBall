## hasPilotCamera

- Source: https://community.bistudio.com/wiki/hasPilotCamera
- Revision: 310236
- Updated: 2022-05-05T13:10:59Z

- Availability: arma3 1.64
- Locality: argument global
- Groups: Pilot Camera

### Description

Returns true if the object airplane or helicopter has a pilotCamera.

### Syntax

```sqf
hasPilotCamera object
```

### Parameters

- object: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
hasPilotCamera vehicle player;
```
