## BIS fnc simpleMoveMarker

- Source: https://community.bistudio.com/wiki/BIS_fnc_simpleMoveMarker
- Revision: 376118
- Updated: 2025-08-31T21:15:35Z

- Availability: arma3 1.78
- Locality: argument global, effect global
- Groups: Map and Markers

### Description

Move the provided marker to a new position. Simple version of BIS_fnc_moveMarker.

### Syntax

```sqf
[marker, newPosition, duration] call BIS_fnc_simpleMoveMarker
```

### Parameters

- marker: String - marker to move
- newPosition: Array - new position, 2D or 3D
- duration: Number - (Optional, default 5) how long it takes to move the marker in seconds

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
["BIS_marker", [1111,2222, 0]] call BIS_fnc_moveMarker;
```

#### Example 2

```sqf
["BIS_marker", getMarkerPos "BIS_marker2", 2] call BIS_fnc_simpleMoveMarker;
```
