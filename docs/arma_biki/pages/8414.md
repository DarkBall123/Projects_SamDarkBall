## selectedEditorObjects

- Source: https://community.bistudio.com/wiki/selectedEditorObjects
- Revision: 377133
- Updated: 2026-01-01T10:26:59Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Game 2 Editor

### Description

Returns a list of currently selected editor objects. 
Some Old Editor Command

### Syntax

```sqf
selectedEditorObjects map
```

### Parameters

- map: Control

### Return Value

- Array of Objects

### Examples

#### Example 1

```sqf
_selObjects = selectedEditorObjects _map; // result can be: ["_vehicle_0","_vehicle_9","_vehicle_11"]
```
