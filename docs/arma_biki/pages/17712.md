## isEqualTypeAny

- Source: https://community.bistudio.com/wiki/isEqualTypeAny
- Revision: 377153
- Updated: 2026-01-01T10:37:25Z

- Availability: arma3 1.54
- Groups: Variables

### Description

Compares type of given value to every type in the given array and if match is found, true is returned.

### Syntax

```sqf
val isEqualTypeAny types
```

### Parameters

- val: Anything
- types: Array of Anything

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_var = [1, 2, 3];
_var isEqualTypeAny [0, "", objNull]; //false
_var isEqualTypeAny [0, "", objNull, []]; //true
```
