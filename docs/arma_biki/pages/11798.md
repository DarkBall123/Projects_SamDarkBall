## terrainIntersect

- Source: https://community.bistudio.com/wiki/terrainIntersect
- Revision: 377407
- Updated: 2026-01-02T06:45:07Z

- Availability: arma2oa 1.62, tkoh 1.00, arma3 0.50
- Groups: Math - Geometry

### Description

Checks for intersection of terrain between two AGL positions. Returns true if intersects with terrain. For ASL variant see terrainIntersectASL.

### Syntax

```sqf
terrainIntersect [start, end]
```

### Parameters

- start: PositionAGL - start position
- end: PositionAGL - end position

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_intersects = terrainIntersect [getPos player, getPos chopper];
```

#### Example 2

```sqf
_intersects = terrainIntersect [position player, position enemy1];
```
