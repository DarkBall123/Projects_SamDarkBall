## setBrakesRTD

- Source: https://community.bistudio.com/wiki/setBrakesRTD
- Revision: 377777
- Updated: 2026-01-03T01:32:30Z

- Availability: tkoh 1.00, arma3 1.34
- Groups: RTD

### Description

Enable landing gear wheel brakes for a helicopter.
* value 0: brakes off
* value 1: brakes on

* index 1: left wheels
* index 2: right wheels
* index 3: both sides
{{Feature|afm}}
This command is implemented, but not fully supported.

### Syntax

```sqf
helicopterRTD setBrakesRTD [value, wheelIndex]
```

### Parameters

- helicopterRTD: ObjectRTD - helicopter
- value: Number - value of the brakes
- wheelIndex: Number - wheel index

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myHelicopterRTD setBrakesRTD [1, 3];
```
