## setType

- Source: https://community.bistudio.com/wiki/setType
- Revision: 323021
- Updated: 2022-06-28T21:43:07Z

- Availability: arma1 1.08, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Locations

### Description

Changes a location to the specified class. Location classes are defined in CfgLocationTypes.

### Syntax

```sqf
location setType name
```

### Parameters

- location: Location
- name: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myLocation setType "RockArea";
```
