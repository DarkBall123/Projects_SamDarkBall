## getObjectID

- Source: https://community.bistudio.com/wiki/getObjectID
- Revision: 365078
- Updated: 2024-07-19T18:20:06Z

- Availability: arma3 2.10
- Groups: Map

### Description

Returns Visitor ID of the given object. Visitor IDs of static map objects can change if map is in development and updated with new static objects.

### Syntax

```sqf
getObjectID object
```

### Parameters

- object: Object

### Return Value

- String - Visitor ID

### Examples

#### Example 1

```sqf
getObjectID _tree;
```
