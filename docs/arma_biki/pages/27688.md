## ctrlSetURL

- Source: https://community.bistudio.com/wiki/ctrlSetURL
- Revision: 325207
- Updated: 2022-07-03T07:02:32Z

- Availability: arma3 2.02
- Groups: GUI Control

### Description

Sets URL property of the given control subject to `allowedHTMLLoadURIs[]` whitelisting in CfgCommands config. Supported controls are:
* `CT_BUTTON`
* `CT_SHORTCUTBUTTON` 
* `CT_ACTIVETEXT`

### Syntax

```sqf
control ctrlSetURL URL
```

### Parameters

- control: Control
- URL: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetURL "http://arma3.com/";
```
