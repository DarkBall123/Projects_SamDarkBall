## BIS fnc paramGuerFriendly

- Source: https://community.bistudio.com/wiki/BIS_fnc_paramGuerFriendly
- Revision: 352525
- Updated: 2024-02-12T16:42:17Z

- Availability: arma3 1.00
- Locality: server execution server
- Groups: Mission Parameters

### Description

Set relationship between Independents and remaining sides.

### Syntax

```sqf
number call BIS_fnc_paramGuerFriendly
```

### Parameters

- number: Number - side relation, can be:

-1 - Nobody

0 - OPFOR

1 - BLUFOR

2 - Everybody

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
2 call BIS_fnc_paramGuerFriendly;
```
