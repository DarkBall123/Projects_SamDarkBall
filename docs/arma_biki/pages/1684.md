## commandFollow

- Source: https://community.bistudio.com/wiki/commandFollow
- Revision: 370900
- Updated: 2025-02-21T10:44:32Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Unit Control

### Description

Order the given unit(s) to follow another from his own group (via radio).
It can also be used to resume unit formation after e.g doStop.

### Syntax

```sqf
unit commandFollow unitLead
```

### Parameters

- unit: Object or Array of Objects
- unitLead: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldier1 commandFollow _soldier2;
```

#### Example 2

```sqf
(units group _leader - [_leader]) commandFollow _leader; // returns all the units (but the leader) to formation
```
