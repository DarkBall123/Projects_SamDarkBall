## scoreSide

- Source: https://community.bistudio.com/wiki/scoreSide
- Revision: 321011
- Updated: 2022-05-13T11:05:55Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Multiplayer, Sides

### Description

Returns score for the given side. MP Only.

### Syntax

```sqf
scoreSide side
```

### Parameters

- side: Side

### Return Value

- Number

### Examples

#### Example 1

```sqf
_number = scoreSide west;
```
