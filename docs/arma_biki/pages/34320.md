## backpacks

- Source: https://community.bistudio.com/wiki/backpacks
- Revision: 377190
- Updated: 2026-01-01T10:53:56Z

- Availability: arma3 2.14
- Locality: argument global
- Groups: Unit Inventory

### Description

Returns an array of all backpack names a unit has in its inventory, excluding the one it carries on the back.

### Syntax

```sqf
backpacks unit
```

### Parameters

- unit: Object

### Return Value

- Array of Strings

### Examples

#### Example 1

```sqf
private _allCarriedBackpackTypes = backpacks player + [backpack player];
```
