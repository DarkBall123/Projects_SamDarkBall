## userInputDisabled

- Source: https://community.bistudio.com/wiki/userInputDisabled
- Revision: 373273
- Updated: 2025-04-13T14:32:18Z

- Availability: arma3 1.60
- Groups: Interaction

### Description

Returns whether or not user input is disabled.
The disabled input system internally *counts* how many times 

```sqf
disableUserInput true
```

 has been called - see #Example 2.

### Syntax

```sqf
userInputDisabled
```


### Return Value

- Boolean

### Examples

#### Example 1

Toggles user input

```sqf
disableUserInput !userInputDisabled;
```

#### Example 2

```sqf
disableUserInput true;
disableUserInput true;
disableUserInput true;

diag_log str userInputDisabled; // true

disableUserInput false;
diag_log str userInputDisabled; // true

disableUserInput false;
diag_log str userInputDisabled; // true

disableUserInput false;
diag_log str userInputDisabled; // false - control is regained only here
```
