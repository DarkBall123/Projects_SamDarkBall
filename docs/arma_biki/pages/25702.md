## ctrlSetPositionX

- Source: https://community.bistudio.com/wiki/ctrlSetPositionX
- Revision: 309181
- Updated: 2022-05-03T18:04:56Z

- Availability: arma3 1.92
- Groups: GUI Control - Positioning

### Description

Sets horizontal position (x) of the 2D control. ctrlCommit is required to complete the operation.

### Syntax

```sqf
control ctrlSetPositionX x
```

### Parameters

- control: Control - 2D control
- x: Number - horizontal position of the control

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ctrl ctrlSetPositionX 0.5;
_ctrl ctrlCommit 1;
```
