## BIS fnc timeline init

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_init
- Revision: 348102
- Updated: 2023-11-08T11:31:57Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Initialized a timeline.

### Syntax

```sqf
[timeline, initPosition, length, playRate, loop] call BIS_fnc_timeline_init
```

### Parameters

- timeline: Object - the timeline object
- initPosition: Number - (Optional, default 

```sqf
_timeline getVariable ["Pos", 0.0]
```

) initial position
- length: Number - (Optional, default 	

```sqf
_timeline getVariable ["Length", 10.0]
```

) length
- playRate: Number - (Optional, default 

```sqf
_timeline getVariable ["PlayRate", 1.0]
```

) play rate
- loop: Boolean - (Optional, default 

```sqf
_timeline getVariable ["Loop", false]
```

) true - loop enabled, false - loop disabled
- reverse: Boolean - (Optional, default 

```sqf
_timeline getVariable ["Reverse", false]
```

) true - reverse, false - Do not reverse
- playOnStart: Boolean - (Optional, default 

```sqf
_timeline getVariable ["PlayFromStart", false]
```

) true - play at scenario start, false - Do not play at scenario start
- destroyWhenFinished: Boolean - (Optional, default 

```sqf
_timeline getVariable ["DestroyWhenFinished", false]
```

) true - Destroy when done, false - Do not destroy when done

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[timeline] call BIS_fnc_timeline_init;
```
