## BIS fnc moduleDate

- Source: https://community.bistudio.com/wiki/BIS_fnc_moduleDate
- Revision: 347968
- Updated: 2023-11-08T09:35:12Z

- Availability: arma3 1.00
- Groups: Modules

### Description

Used by the Date module.

### Syntax

```sqf
[logic, null, activated] call BIS_fnc_moduleDate
```

### Parameters

- logic: Object - date module
- null: Anything - not used
- activated: Boolean - (Optional, default true) if false nothing will happen

### Return Value

- Boolean - always true

### Examples

#### Example 1

```sqf
[logic, nil, true] call BIS_fnc_moduleDate;
```
