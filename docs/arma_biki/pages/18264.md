## getShotParents

- Source: https://community.bistudio.com/wiki/getShotParents
- Revision: 378943
- Updated: 2026-08-27T16:27:34Z

- Availability: arma3 1.62
- Groups: Weapons

### Description

Returns shot information for the given projectile.
If shot was fired by a soldier on foot or in FFV position in vehicle, the soldier is returned for the vehicle.

### Syntax

```sqf
getShotParents projectile
```

### Parameters

- projectile: Object - the actual projectile shot

### Return Value

- Array - [vehicle, instigator] - Where vehicle is the vehicle the shot was fired from, and the instigator is the person who pulled the trigger

### Examples

#### Example 1

```sqf
_shotParents = getShotParents myProjectile;
```

#### Example 2

```sqf
batmobile addEventHandler ["Fired", { systemChat str getShotParents (_this select 6) }];
```
