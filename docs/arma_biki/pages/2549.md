## precision

- Source: https://community.bistudio.com/wiki/precision
- Revision: 369414
- Updated: 2024-09-03T18:46:04Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Object Manipulation

### Description

Return the movement precision of the given entity, how is the entity able to be precise when moving to given target.
See CfgVehicles Config Reference#precision.

### Syntax

```sqf
precision entity
```

### Parameters

- entity: Object

### Return Value

- Number - accuracy in metres

### Examples

#### Example 1

```sqf
// used in formationCDanger.fsm
if (getPosATL _this distance _dangerPos <= precision _this) then { /* ... */ };
```
