## BIS fnc briefingAnimate

- Source: https://community.bistudio.com/wiki/BIS_fnc_briefingAnimate
- Revision: 327693
- Updated: 2022-07-13T10:03:03Z

- Availability: arma3 1.78
- Groups: Briefing

### Description

Animate briefing markers.

### Syntax

```sqf
[markerName, stepId, delay] call BIS_fnc_briefingAnimate
```

### Parameters

- markerName: String - marker to animate
- stepId: Number - step ID (steps are invisible markers named `<*markerName*>_<*stepId*>`)
- delay: String - commit time (transition duration)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
// given you have 6 markers:
// - "myMarker"
// - "myMarker_0"
// - "myMarker_1"
// - "myMarker_2"
// - "myMarker_3"
// - "myMarker_4"
for "_i" from 0 to 4 do {
	private _commit = 1;
	["myMarker", 5, _commit] call BIS_fnc_briefingAnimate;
	sleep _commit;
};
```
