## menuSetText

- Source: https://community.bistudio.com/wiki/menuSetText
- Revision: 378350
- Updated: 2026-04-02T16:31:40Z

- Availability: arma3 2.02
- Groups: GUI Control - Menu

### Description

Sets text of given menu strip entry.

### Syntax

```sqf
menuSetText [idc, path, text]
```

```sqf
control menuSetText [path, text]
```

### Parameters

- idc: Number
- path: Tree View Path
- text: String
- control: Control
- path: Tree View Path
- text: String

### Return Value

- Nothing
- Nothing

### Examples

#### Example 1

```sqf
_ctrlMenuStrip menuSetText [[0,0,1], "Hello World!"];
```
