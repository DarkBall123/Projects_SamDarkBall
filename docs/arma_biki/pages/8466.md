## taskDestination

- Source: https://community.bistudio.com/wiki/taskDestination
- Revision: 349537
- Updated: 2023-11-08T17:18:22Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing

### Description

Returns the position of the task (as specified by destination parameter in config).

### Syntax

```sqf
taskDestination task
```

### Parameters

- task: Task

### Return Value

- Array (A3 1.28 Returns Nothing if identity is taskNull)

### Examples

#### Example 1

```sqf
if (!isNull currentTask player) then { hint str taskDestination currentTask player };
```
