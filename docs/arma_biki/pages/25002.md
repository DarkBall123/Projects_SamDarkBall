## BIS fnc berp

- Source: https://community.bistudio.com/wiki/BIS_fnc_berp
- Revision: 338047
- Updated: 2023-02-23T21:15:20Z

- Availability: arma3 1.78
- Groups: Interpolation

### Description

Derivative of the [Kelvin function](https://en.wikipedia.org/wiki/Kelvin_functions) [ber](https://en.wikipedia.org/wiki/Kelvin_functions#ber(x)).

### Syntax

```sqf
[a, b, delta] call BIS_fnc_berp
```

### Parameters

- a: Number - (Optional, default 0) first point (start)
- b: Number - (Optional, default 0) second point (end)
- delta: Number - (Optional, default 0) the delta time, 0..1

### Return Value

- Number - the interpolated value

### Examples

#### Example 1

```sqf
private _value = [0, 1, 0.5] call BIS_fnc_berp;
```
