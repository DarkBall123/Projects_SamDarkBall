## completedFSM

- Source: https://community.bistudio.com/wiki/completedFSM
- Revision: 310814
- Updated: 2022-05-07T20:23:36Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: System

### Description

Checks whether the given FSM is completed. The FSM handle is the number returned by the execFSM command.

### Syntax

```sqf
completedFSM fsmHandle
```

### Parameters

- fsmHandle: Number

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_completed = completedFSM _fsmHandle;
```
