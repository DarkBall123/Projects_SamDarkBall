## BIS fnc helicopterSeatMove

- Source: https://community.bistudio.com/wiki/BIS_fnc_helicopterSeatMove
- Revision: 327331
- Updated: 2022-07-12T22:11:54Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Helicopters

### Description

Plays cockpit animation. **{{tkoh}} only**.

### Syntax

```sqf
[unit, gesture] call BIS_fnc_helicopterSeatMove
```

### Parameters

- unit: Object
- gesture: String - can be one of:
* "greet"
* "look"
* "point"
* "thumbDown"
* "thumbUp"

### Return Value

- String - animation full name - "" if animation not found

### Examples

#### Example 1

```sqf
[instructor, "thumbUp"] call BIS_fnc_helicopterSeatMove;
```
