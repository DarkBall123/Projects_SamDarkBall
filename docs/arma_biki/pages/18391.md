## BIS fnc vectorDirAndUpRelative

- Source: https://community.bistudio.com/wiki/BIS_fnc_vectorDirAndUpRelative
- Revision: 325129
- Updated: 2022-07-01T12:35:35Z

- Availability: arma3 1.64
- Groups: Vectors

### Description

Returns vectorDirAndUp of object 1 relative to object 2

### Syntax

```sqf
[object1, object2, visual] call BIS_fnc_vectorDirAndUpRelative
```

### Parameters

- object1: Object
- object2: Object
- visual: Boolean - (Optional, default true) true for a render scope result, false for simulation scope

### Return Value

- Array in format [<nowiki/>vectorDir, vectorUp]

### Examples

#### Example 1

```sqf
private _vectorDirAndUp = [tank, car] call BIS_fnc_vectorDirAndUpRelative;
```
