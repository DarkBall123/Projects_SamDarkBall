## enableUAVWaypoints

- Source: https://community.bistudio.com/wiki/enableUAVWaypoints
- Revision: 369357
- Updated: 2024-09-03T18:43:05Z

- Availability: arma3 1.40
- Groups: Waypoints, Remote Control

### Description

Enables/disables the option for player to set waypoints for UAV in AV terminal.

### Syntax

```sqf
uav enableUAVWaypoints enable
```

### Parameters

- uav: Object
- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_uav enableUAVWaypoints false;
hint str waypointsEnabledUAV _uav; // returns false
```
