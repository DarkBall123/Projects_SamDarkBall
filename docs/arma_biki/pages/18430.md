## diag enabled

- Source: https://community.bistudio.com/wiki/diag_enabled
- Revision: 369346
- Updated: 2024-09-03T18:43:02Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Checks whether specific diagnostic mode is activated.

### Syntax

```sqf
diag_enabled  mode
```

### Parameters

- mode: String - see Arma 3: Diagnostics Exe

### Return Value

- Boolean - true when enabled, false when disabled

### Examples

#### Example 1

```sqf
"Animation" diag_enable true;
diag_enabled "Animation"; // returns true
```
