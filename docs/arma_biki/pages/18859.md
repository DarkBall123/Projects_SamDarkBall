## BIS fnc taskTypeIcon

- Source: https://community.bistudio.com/wiki/BIS_fnc_taskTypeIcon
- Revision: 352033
- Updated: 2024-02-01T23:24:28Z

- Availability: arma3 1.58
- Groups: Tasks

### Description

Returns path to the icon texture associated with given task type. See Arma 3: Task Framework for more information.

### Syntax

```sqf
[type, default] call BIS_fnc_taskTypeIcon
```

### Parameters

- type: String - task type
- default: Config - config path to get default path from, if **type** does not exist

### Return Value

- String - path to the task type texture.

### Examples

#### Example 1

```sqf
["attack",configFile >> "CfgTaskTypes" >> "Run" >> "icon"] call BIS_fnc_taskTypeIcon;
```
