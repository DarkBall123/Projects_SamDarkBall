## enableDebriefingStats

- Source: https://community.bistudio.com/wiki/enableDebriefingStats
- Revision: 318957
- Updated: 2022-05-13T09:22:06Z

- Availability: arma3 1.00
- Groups: Briefing

### Description

Enable debriefing score table.

### Syntax

```sqf
enableDebriefingStats [left, top, width, height]
```

### Parameters

- left: Number
- top: Number
- width: Number
- height: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
enableDebriefingStats [0.1, 0.1, 0.8, 0.8];
```
