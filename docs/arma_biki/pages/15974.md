## BIS fnc terrainGradAngle

- Source: https://community.bistudio.com/wiki/BIS_fnc_terrainGradAngle
- Revision: 328359
- Updated: 2022-07-13T16:00:47Z

- Availability: arma3 1.00
- Groups: Geometry

### Description

Returns the gradient angle (in radians) of the terrain at a specified position and a compass direction.
It is an angle of the slope of a tangent plane to the terrain at the specified position in the specified direction.

### Syntax

### Parameters

- object: Object or Position
- direction: Number - direction where should be gradient calculated (compass direction)
- delta: Number - which stepsize should be used

### Return Value

- Number - gradient angle in radians

### Examples

#### Example 1

```sqf
private _radGrad = [getPos player, getDir player] call BIS_fnc_terrainGradAngle;
```
