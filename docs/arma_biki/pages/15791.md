## BIS fnc dbPrint

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbPrint
- Revision: 327390
- Updated: 2022-07-12T22:11:58Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Copy Scripted Database content into clipboard for evaluation. Text will be formatted as config.
1.92 The function does not insert semicolons at the end of values (not intentional?). You have to manually add them to make the config functional.

### Syntax

```sqf
[database, tabs] call BIS_fnc_dbPrint
```

### Parameters

- database - Array: Database array
- tabs - Number: Number of tabs

### Return Value

- String: Printed text

### Examples

#### Example 1

```sqf
[["#MILLER", ["&KILLS", 1000, "&RANK", "CAPTAIN"], "#TERRA", ["&WEAPON", "MX 6.5mm"]]] call BIS_fnc_dbPrint;
```

#### Example 2

```sqf
[["#MILLER", ["&KILLS", 1000, "&RANK", "CAPTAIN"], "#TERRA", ["&WEAPON", "MX 6.5mm"]], 1] call BIS_fnc_dbPrint;
```
