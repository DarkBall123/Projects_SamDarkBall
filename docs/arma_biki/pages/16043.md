## BIS fnc progressLoadingScreen

- Source: https://community.bistudio.com/wiki/BIS_fnc_progressLoadingScreen
- Revision: 369453
- Updated: 2024-09-06T08:44:48Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: GUI

### Description

Progress scripted loading screen. The value will be preserved even when a new screen is opened.
The loading screen can be force-ended with the [ENDLOAD cheat code](Arma 3: Cheats#ENDLOAD).

### Syntax

```sqf
[progress] call BIS_fnc_progressLoadingScreen
```

### Parameters

- progress: Number - progress in range from 0 to 1

### Return Value

- Number - progress

### Examples

#### Example 1

```sqf
private _IDD = _prog = [0.75] call BIS_fnc_progressLoadingScreen;
```
