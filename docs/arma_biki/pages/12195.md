## ppEffectForceInNVG

- Source: https://community.bistudio.com/wiki/ppEffectForceInNVG
- Revision: 348736
- Updated: 2023-11-08T14:32:10Z

- Availability: arma3 0.50
- Locality: effect local
- Groups: Camera Control

### Description

Forces use of Post Process Effects in NVG.

### Syntax

```sqf
ppHandle ppEffectForceInNVG force
```

### Parameters

- ppHandle: Number - handle of the post processing returned by ppEffectCreate
- force: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_ppGrain ppEffectForceInNVG true;
```
