## removeAllMissionEventHandlers

- Source: https://community.bistudio.com/wiki/removeAllMissionEventHandlers
- Revision: 319390
- Updated: 2022-05-13T09:23:59Z

- Availability: arma3 0.50
- Locality: effect local
- Groups: Event Handlers

### Description

Removes all mission event handlers of the given type which were added by addMissionEventHandler.

{{Feature | important | Prior to 2.08 this command would also reset the Event Handler creation index to 0.}}

### Syntax

```sqf
removeAllMissionEventHandlers type
```

### Parameters

- type: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllMissionEventHandlers "Loaded";
```

### See Also

removeMissionEventHandler addMissionEventHandler
