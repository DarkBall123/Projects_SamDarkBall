## isForcedWalk

- Source: https://community.bistudio.com/wiki/isForcedWalk
- Revision: 319117
- Updated: 2022-05-13T09:23:13Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Stamina System

### Description

Returns true if player is forced to walk with forceWalk.

### Syntax

```sqf
isForcedWalk unitName
```

### Parameters

- unitName : Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_bool = isForcedWalk player;
```
