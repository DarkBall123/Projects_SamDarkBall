## BIS fnc setCuratorVisionModes

- Source: https://community.bistudio.com/wiki/BIS_fnc_setCuratorVisionModes
- Revision: 378130
- Updated: 2026-02-22T20:24:30Z

- Availability: arma3 1.16
- Groups: Curator

### Description

Set which vision modes curator can access.

### Syntax

```sqf
[curator, mode] call BIS_fnc_setCuratorVisionModes
```

### Parameters

- curator: Object
- mode: Array of Numbers - vision modes, can be:
* -2 - Night vision mode
* -1 - Normal mode
* 0, 1, ... - Thermal vision mode - see setCamUseTi for detailed information

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[BIS_curator, [-1, -2]] call BIS_fnc_setCuratorVisionModes;
```
