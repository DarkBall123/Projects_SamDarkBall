## BIS fnc timeline setPause

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_setPause
- Revision: 310487
- Updated: 2022-05-06T11:02:01Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Pauses or unpauses timeline.

### Syntax

```sqf
[timeline, pause] call BIS_fnc_timeline_setPause
```

### Parameters

- timeline: Object - the timeline object
- pause: Boolean - (Optional, default true) true to pause, false to unpause

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[timeline] call BIS_fnc_timeline_setPause;
```
