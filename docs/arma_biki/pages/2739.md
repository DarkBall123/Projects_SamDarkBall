## setMousePosition

- Source: https://community.bistudio.com/wiki/setMousePosition
- Revision: 340820
- Updated: 2023-05-07T11:05:54Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Positioning

### Description

Moves mouse pointer to specified position on the screen. **x** and **y** could be any number, but will be clipped so mouse never leaves the screen area.

### Syntax

```sqf
setMousePosition [x, y]
```

### Parameters

- x: Number - x in screen coordinates
- y: Number - y in screen coordinates

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setMousePosition [0.5, 0.5];
```
