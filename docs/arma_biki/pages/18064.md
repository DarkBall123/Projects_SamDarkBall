## BIS fnc netId

- Source: https://community.bistudio.com/wiki/BIS_fnc_netId
- Revision: 327003
- Updated: 2022-07-12T21:44:44Z

- Availability: arma3 1.58
- Groups: Multiplayer

### Description

Extends MP-only netId functionality to SP

### Syntax

```sqf
objOrGrp call BIS_fnc_netId
```

### Parameters

- objOrGrp: Object or Group

### Return Value

- String - net Id in format "owner:id" or "".

### Examples

#### Example 1

```sqf
private _objNetId = player call BIS_fnc_netId; // "0:2"
```

#### Example 2

```sqf
private _grpNetId = group player call BIS_fnc_netId; // "0:3"
```
