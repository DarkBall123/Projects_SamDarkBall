## rank

- Source: https://community.bistudio.com/wiki/rank
- Revision: 337318
- Updated: 2023-01-16T09:46:20Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Unit Identity

### Description

Returns the rank of the given unit. Rank can be one of the following:
* `"PRIVATE"`
* `"CORPORAL"`
* `"SERGEANT"`
* `"LIEUTENANT"`
* `"CAPTAIN"`
* `"MAJOR"`
* `"COLONEL"`

### Syntax

```sqf
rank unit
```

### Parameters

- unit: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
_rank = rank player;
```
