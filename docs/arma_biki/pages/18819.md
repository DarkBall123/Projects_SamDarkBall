## BIS fnc disableLoading

- Source: https://community.bistudio.com/wiki/BIS_fnc_disableLoading
- Revision: 348269
- Updated: 2023-11-08T11:40:36Z

- Availability: arma3 1.00
- Groups: Missions

### Description

Disables the load/restart button. Currently only for BIS_fnc_cinemaBorder used within the Prologue and Survive campaigns. Only works in single player.

### Syntax

```sqf
call BIS_fnc_disableLoading
```


### Return Value

- Boolean - always true

### Examples

#### Example 1

```sqf
call BIS_fnc_disableLoading;
```
