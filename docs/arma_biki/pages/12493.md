## tvData

- Source: https://community.bistudio.com/wiki/tvData
- Revision: 378318
- Updated: 2026-04-02T16:17:09Z

- Availability: arma3 0.74
- Groups: GUI Control - Tree View

### Description

Returns string data from item on given path. IDC means id of parent CT_TREE.

### Syntax

```sqf
tvData [idc, path]
```

```sqf
control tvData path
```

### Parameters

- idc: Number
- path: Tree View Path
- control: Control
- path: Tree View Path

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
tvData [101, [0]];
```

#### Example 2

```sqf
(_display displayCtrl 101) tvData [0];
```
