## ammo

- Source: https://community.bistudio.com/wiki/ammo
- Revision: 364083
- Updated: 2024-05-03T19:33:29Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Unit Inventory

### Description

Check how many rounds are left in the currently loaded magazine in the given muzzle.
In older titles and before Arma 3 v1.56, the command did not return ammo for units in vehicles.

### Syntax

```sqf
unit ammo muzzle
```

### Parameters

- unit: Object
- muzzle: String - weapon's muzzle - see the Weapons topic for reference about possible values

### Return Value

- Number

### Examples

#### Example 1

```sqf
_count = player ammo "M16"; // returns 30 in case of a full magazine
```

#### Example 2

```sqf
_count = player ammo "M203Muzzle";
```

#### Example 3

```sqf
_count = player ammo primaryWeapon player;
```
