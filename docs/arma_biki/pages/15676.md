## BIS fnc randomInt

- Source: https://community.bistudio.com/wiki/BIS_fnc_randomInt
- Revision: 327175
- Updated: 2022-07-12T22:07:31Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Math

### Description

Returns a random integer between the two passed numbers (inclusive). The order of parameters doesn't matter: it can be `[min, max]` or `[max, min]`.

### Syntax

```sqf
[min, max] call BIS_fnc_randomInt
```

### Parameters

- min: Number - minimum value, included
- max: Number - maximum value, included

### Return Value

- Number

### Examples

#### Example 1

```sqf
[1, 3] call BIS_fnc_randomInt; // will return 1, 2 or 3
```
