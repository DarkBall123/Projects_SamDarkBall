## loadUniform

- Source: https://community.bistudio.com/wiki/loadUniform
- Revision: 320992
- Updated: 2022-05-13T10:22:04Z

- Availability: arma3 0.50
- Groups: Unit Inventory

### Description

Returns current percentage of mass from items stored in a uniform relative to the maximum capacity of the uniform.

It is equivalent to this formula:

```sqf
private _loadUniform = massOfAllItemsInUniform / getContainerMaxLoad uniform player;
```

### Syntax

```sqf
loadUniform unit
```

### Parameters

- unit: Object

### Return Value

- Number

### Examples

#### Example 1

```sqf
private _weight = loadUniform player;
```
