## BIS fnc exportCfgPatches

- Source: https://community.bistudio.com/wiki/BIS_fnc_exportCfgPatches
- Revision: 353277
- Updated: 2024-03-15T16:37:26Z

- Availability: arma3 1.00
- Groups: Diagnostic

### Description

Export list of addons for Community Wiki - {{GameCategory|arma3|Assets|link= y}}.

### Syntax

```sqf
[config, classes] call BIS_fnc_exportCfgPatches
```

### Parameters

- config: String - (Optional, default "CfgVehicles")
- classes: Array of Strings - list of `CfgPatches` classes

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
call BIS_fnc_exportCfgPatches;
```

#### Example 2

```sqf
["CfgVehicles"] call BIS_fnc_exportCfgPatches;	// exports Arma 3: CfgPatches CfgVehicles
["CfgWeapons"]  call BIS_fnc_exportCfgPatches;	// exports Arma 3: CfgPatches CfgWeapons
```
