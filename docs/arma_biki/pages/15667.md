## BIS fnc colorRGBtoHTML

- Source: https://community.bistudio.com/wiki/BIS_fnc_colorRGBtoHTML
- Revision: 323934
- Updated: 2022-07-01T11:58:28Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Arrays

### Description

Converts RGB color format to HTML color format.

### Syntax

```sqf
colorArray call BIS_fnc_colorRGBtoHTML
```

### Parameters

- colorArray: Color (RGBA) - can be [r, g, b, a] or [r, g, b], alpha value will be ignored in both cases

### Return Value

- String - format #{{Color|red|RR}}{{Color|green|GG}}{{Color|blue|BB}}

### Examples

#### Example 1

```sqf
private _htmlColor = [0,0,0,1] call BIS_fnc_colorRGBtoHTML; // will return #000000
```

#### Example 2

```sqf
private _htmlColor = [2,93,0,1] call BIS_fnc_colorRGBtoHTML; // will return #025D00
```
