## removeAllSecondaryWeaponItems

- Source: https://community.bistudio.com/wiki/removeAllSecondaryWeaponItems
- Revision: 310170
- Updated: 2022-05-05T13:10:24Z

- Availability: arma3 2.02
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Removes all items from secondaryWeapon, except magazine.

### Syntax

```sqf
removeAllSecondaryWeaponItems unit
```

### Parameters

- unit: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
removeAllSecondaryWeaponItems player;
```
