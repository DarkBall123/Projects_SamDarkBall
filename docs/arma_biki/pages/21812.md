## BIS fnc getCloudletParams

- Source: https://community.bistudio.com/wiki/BIS_fnc_getCloudletParams
- Revision: 349529
- Updated: 2023-11-08T17:16:25Z

- Availability: arma3 1.76
- Groups: Systems

### Description

Return particle params of CfgCloudlets class.

### Syntax

```sqf
[cfgCloudletClass] call BIS_fnc_getCloudletParams
```

### Parameters

- cfgCloudletClass: String - wanted class in cfgCloudlets

### Return Value

- Array - format [<nowiki/>setParticleParams, setParticleRandom, setDropInterval]

 [
 	[
 		[particleShape, particleFSNtieth, particleFSIndex, particleFSFrameCount, particleFSLoop],
 		animationName,
 		particleType,
 		timerPeriod,
 		lifeTime,
 		position,
 		moveVelocity,
 		rotationVelocity,
 		weight,
 		volume,
 		rubbing,
 		size,
 		color,
 		animationSpeed,
 		randomDirectionPeriod,
 		randomDirectionIntensity,
 		onTimerScript,
 		beforeDestroyScript,
 		"",
 		angle,
 		onSurface,
 		bounceOnSurface,
 		emissiveColor
 	],
 	[
 		lifeTimeVar,
 		positionVar,
 		moveVelocityVar,
 		rotationVelocityVar,
 		sizeVar,
 		colorVar,
 		randomDirectionPeriodVar,
 		randomDirectionIntensityVar,
 		angleVar,
 		bounceOnSurfaceVar
 	],
 	interval
]

### Examples

#### Example 1

```sqf
["AmmoLightSmokeParticles"] call BIS_fnc_getCloudletParams;
```
