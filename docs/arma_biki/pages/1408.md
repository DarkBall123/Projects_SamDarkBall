## buttonAction

- Source: https://community.bistudio.com/wiki/buttonAction
- Revision: 376407
- Updated: 2025-10-11T00:59:12Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: GUI Control

### Description

Returns the action assigned to a control of the currently active user dialog. Can be used for buttons and active texts. Read Arma: GUI Configuration for more information about user dialogs and controls.

### Syntax

```sqf
buttonAction  idc
```

```sqf
buttonAction  control
```

### Parameters

- idc: Number - button IDC
- control: Control

### Return Value

- String
- String

### Examples

#### Example 1

```sqf
buttonSetAction [100, { player exec "reply.sqs" }];
_action = buttonAction 100; // Returns { player exec "reply.sqs" };
```
