## ctrlType

- Source: https://community.bistudio.com/wiki/ctrlType
- Revision: 318899
- Updated: 2022-05-13T09:22:00Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns number representing the type of control, which is also defined by *type* property in config. For more information see Arma: GUI Configuration

### Syntax

```sqf
ctrlType control
```

### Parameters

- control: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_type = ctrlType _rscEdit; // 2
```
