## BIS fnc onPlayerConnected

- Source: https://community.bistudio.com/wiki/BIS_fnc_onPlayerConnected
- Revision: 349536
- Updated: 2023-11-08T17:16:42Z

- Availability: arma3 1.00
- Groups: Multiplayer, Event Handlers

### Description

Executes a function on server every time a player connects the mission.

### Syntax

```sqf
[code, params]] call BIS_fnc_onPlayerConnected
```

### Parameters

- code: Code or String - function name or code to be executed. Following parameters are passed to the function or code:
*0: Player
*1: Params
- params: Anything - parameters passed to the code or function

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
[
 {
   params ["_player", "_params"];
   hint name _player; hint _params;
 }, 
 "Parameter" 
] call BIS_fnc_onPlayerConnected;
```
