## enableSimulationGlobal

- Source: https://community.bistudio.com/wiki/enableSimulationGlobal
- Revision: 329206
- Updated: 2022-07-25T16:01:42Z

- Availability: arma3 1.12
- Locality: argument global, effect global, server execution server
- Groups: Object Manipulation

### Description

Enable or disable simulation for given entity, globally. Has the same effect as enableSimulation when used in singleplayer.

### Multiplayer

Since 2.06 the command can also be executed client-side, with a local argument.

### Syntax

```sqf
entity enableSimulationGlobal enable
```

### Parameters

- entity: Object
- enable: Boolean

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_myObject enableSimulationGlobal false;
```

#### Example 2

```sqf
[_object, false] remoteExec ["enableSimulationGlobal", 2];
```
