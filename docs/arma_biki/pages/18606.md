## ammoOnPylon

- Source: https://community.bistudio.com/wiki/ammoOnPylon
- Revision: 347947
- Updated: 2023-11-07T05:27:04Z

- Availability: arma3 1.70
- Groups: Vehicle Loadouts

### Description

Returns ammo count on given pylon (or false on failure).

### Syntax

```sqf
vehicle ammoOnPylon pylon
```

### Parameters

- vehicle: Object
- pylon: String or Number - pylon's name or index

### Return Value

- Number or Boolean - false on failure

### Examples

#### Example 1

```sqf
private _ammoCount = (vehicle player) ammoOnPylon "pylon1";
```

#### Example 2

```sqf
hint str (vehicle player ammoOnPylon "pylonCenter");
```
