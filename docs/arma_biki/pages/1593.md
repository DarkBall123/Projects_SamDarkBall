## fuel

- Source: https://community.bistudio.com/wiki/fuel
- Revision: 376958
- Updated: 2026-01-01T05:49:41Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Checks how much fuel is left in the gas tank of a vehicle.

### Syntax

```sqf
fuel vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Number in range 0..1 - 0 (empty tank) to 1 (full tank).

### Examples

#### Example 1

```sqf
if (fuel vehicle player == 0) then { hint "The vehicle is out of fuel!" };
```
