## BIS fnc 3DENGrid

- Source: https://community.bistudio.com/wiki/BIS_fnc_3DENGrid
- Revision: 348431
- Updated: 2023-11-08T13:00:12Z

- Availability: arma3 1.58
- Groups: Eden Editor

### Description

Handles action when grid button is pressed in the toolbar in Eden Editor.

### Syntax

```sqf
[mode, input] call BIS_fnc_3DENGrid
```

### Parameters

- mode: String - can be:
*"increase"
*"decrease"
*"init"
*"OnGridChange"
- input: Array - array in form:

0: Control

1: Config - Path to control

### Return Value

- Nothing
