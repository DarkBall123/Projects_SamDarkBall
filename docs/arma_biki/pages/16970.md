### left|25pxHistory
[PFC] Polish Flashpoint Community was founded as a community of Polish OFP/ARMA:CWA and ARMA3 players. The main goal of PFC is to have fun playing OFP/ARMA:CWA online. PFC co-operates with a number of OFP and ARMA series clans, groups and communities.

### left|25pxDedicated server
PFC hosts dedicated servers for ARMA:CWA and ARMA3. More details about the server can be found [here](http://pfc.paradoxstudio.pl).

### left|25pxCommunity Masterserver
On 31st of May, 2014 (effectively on 31st of July), GameSpy servers were closed. As a result, the in-game server browser of OFP/ARMA:CWA stopped working. Thanks to [text= Poweruser's](link= http://forums.bistudio.com/member.php?985-Poweruser) effort, it was possible to overcome this difficult situation. Poweruser created a program that alternates the former GameSpy masterserver by a new one that is hosted by PFC. The PFC masterserver was hosted from 31.05.2014 till 31.12.2016. A new community masterserver has been launched - more about it here.

### left|25pxOFP.INFO 2.0 (revival project)
On 2nd of June, 2018, OFP(R).INFO - the greatest OFP/CWA content-oriented website that was founded around 2001-2018, was closed down. On 15th of July, 2018, [text= OFP.INFO 2.0 (revival project)](link= https://forums.bohemia.net/forums/topic/217443-ofpinfo-20-revival-project/?tab=comments#comment-3302703) was launched. More about it - here.
