## dialog

- Revision: 318841
- Updated: 2022-05-13T09:21:55Z

- Availability: ofp 1.78, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Tests whether any user dialog is open.

### Syntax

```sqf
dialog
```


### Return Value

- Boolean - true if a dialog is open, false if not

### Examples

#### Example 1

```sqf
if (!dialog) then { createDialog "Dialog1"; };
```
