## BIS fnc camera setHUDEnabled

- Source: https://community.bistudio.com/wiki/BIS_fnc_camera_setHUDEnabled
- Revision: 349223
- Updated: 2023-11-08T14:50:50Z

- Availability: arma3 1.00
- Groups: Camera

### Description

Enables or disables camera HUD.

### Syntax

```sqf
[camera, state] call BIS_fnc_camera_setHUDEnabled
```

### Parameters

- camera: Object - the camera
- state: Boolean - (Optional, default false) true to enable HUD, false to disable

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[BIS_camera,true] call BIS_fnc_camera_setHUDEnabled;
```
