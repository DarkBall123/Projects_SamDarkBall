## get3DENActionState

- Source: https://community.bistudio.com/wiki/get3DENActionState
- Revision: 349130
- Updated: 2023-11-08T14:49:44Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Returns state of given Eden Editor action.

### Syntax

```sqf
get3DENActionState  action
```

### Parameters

- action: String - see Eden Editor: Actions

### Return Value

- Number

### Examples

#### Example 1

```sqf
if (get3DENActionState "ToggleMap" == 1) then {systemChat "Editor map is open!"};
```
