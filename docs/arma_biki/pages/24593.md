## BIS fnc timeline setReverse

- Source: https://community.bistudio.com/wiki/BIS_fnc_timeline_setReverse
- Revision: 310700
- Updated: 2022-05-06T11:18:29Z

- Availability: arma3 1.76
- Groups: Timeline

### Description

Change direction of timeline.

### Syntax

```sqf
[timeline, reverse] call BIS_fnc_timeline_setReverse
```

### Parameters

- timeline: Object - the timeline object
- reverse: Boolean - (Optional, default true) true to reverse timeline, false to not reverse it

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[timeline, false] call BIS_fnc_timeline_setReverse;
```
