## BIN fnc colorHSLtoRGB

- Source: https://community.bistudio.com/wiki/BIN_fnc_colorHSLtoRGB
- Revision: 338046
- Updated: 2023-02-23T21:14:59Z

- Availability: arma3 1.94
- Groups: Contact

### Description

Converts [HSL colour format](https://en.wikipedia.org/wiki/HSL_and_HSV) to RGB.
{{Feature|arma3contact}}

### Syntax

```sqf
[hue, saturation, lightness] call BIN_fnc_colorHSLtoRGB
```

### Parameters

- hue: Number - (Optional, default 0)
- saturation: Number - (Optional, default 0)
- lightness: Number - (Optional, default 0)

### Return Value

- Array of Numbers - to format [{{Color|red|R}}, {{Color|green|G}}, {{Color|blue|B}}]

### Examples

#### Example 1

```sqf
private _rgb = [0, 100, 50] call BIN_fnc_colorHSLtoRGB;
```
