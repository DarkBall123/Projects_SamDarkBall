## BIS fnc initExpo

- Source: https://community.bistudio.com/wiki/BIS_fnc_initExpo
- Revision: 309326
- Updated: 2022-05-05T12:04:28Z

- Availability: arma3 1.00
- Groups: Systems

### Description

Disable parts of the main menu during public presentation. Press {{Controls|Ctrl|Shift|U}} to toggle the lock.

### Syntax

```sqf
call BIS_fnc_initExpo
```


### Return Value

- Nothing

### Examples

#### Example 1

```sqf
call BIS_fnc_initExpo;
```
