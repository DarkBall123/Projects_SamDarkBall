## set3DENObjectType

- Source: https://community.bistudio.com/wiki/set3DENObjectType
- Revision: 364151
- Updated: 2024-05-05T10:44:17Z

- Availability: arma3 1.56
- Groups: Eden Editor

### Description

Sets the classname of one or more given Eden Editor objects. For Logic objects use set3DENLogicType.

### Syntax

```sqf
objects set3DENObjectType classname
```

### Parameters

- objects: Array of Objects
- classname: String - name of the cfgVehicles class

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[get3DENMouseOver select 1] set3DENObjectType "B_crew_F"; // turns object under cursor into a blufor crewman
```
