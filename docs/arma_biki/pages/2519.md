## worldToModel

- Source: https://community.bistudio.com/wiki/worldToModel
- Revision: 377406
- Updated: 2026-01-02T06:45:05Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Positions

### Description

Converts position from world space to object model space.
For scaled objects, the relative position will be divided by the object scale.

### Syntax

```sqf
model worldToModel position
```

### Parameters

- model: Object
- position: PositionAGL or Position2D - world position

### Return Value

- PositionRelative - position relative to model

### Examples

#### Example 1

```sqf
_relPos = myObject worldToModel [0,0,0];
```

#### Example 2

```sqf
_relPos = player worldToModel ASLToAGL getPosASL car;
```

#### Example 3

```sqf
_relPos = car worldToModel [12000,5000];
```
