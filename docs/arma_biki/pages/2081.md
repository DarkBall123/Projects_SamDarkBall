## setWaypointFormation

- Source: https://community.bistudio.com/wiki/setWaypointFormation
- Revision: 377761
- Updated: 2026-01-03T00:58:21Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: effect global, server execution server
- Groups: Waypoints

### Description

Switches the group formation when the waypoint becomes active.

Possible values are: 
* "NO CHANGE"
* "COLUMN"
* "STAG COLUMN"
* "WEDGE"
* "ECH LEFT"
* "ECH RIGHT"
* "VEE"
* "LINE"
* "FILE"
* "DIAMOND"

### Syntax

```sqf
waypoint setWaypointFormation formation
```

### Parameters

- waypoint: Waypoint
- formation: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
[_grp, 2] setWaypointFormation "LINE";
```
