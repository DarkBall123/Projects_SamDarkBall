## attachedObjects

- Source: https://community.bistudio.com/wiki/attachedObjects
- Revision: 369106
- Updated: 2024-09-03T10:27:01Z

- Availability: arma3 1.14
- Groups: Object Manipulation

### Description

Returns a list of objects attached to the given object.

### Syntax

```sqf
attachedObjects obj
```

### Parameters

- obj: Object - given object

### Return Value

- Array of Objects attached to the given object

### Examples

#### Example 1

```sqf
{ detach _x } forEach attachedObjects player;
```

#### Example 2

```sqf
if (count attachedObjects player == 0) then
{
	hint "There are no objects attached to player";
};
```
