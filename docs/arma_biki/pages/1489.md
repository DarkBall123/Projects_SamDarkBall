## onBriefingGroup

- Source: https://community.bistudio.com/wiki/onBriefingGroup
- Revision: 322956
- Updated: 2022-06-28T21:42:49Z

- Availability: ofp 1.75, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Briefing, Sounds, Groups, Event Handlers

### Description

Select a sound declared in the Description.ext of the mission to be played the first time the Group tab is selected in the briefing.

### Syntax

```sqf
onBriefingGroup  soundName
```

### Parameters

- soundName: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
onBriefingGroup "GroupVoiceOver";
```
