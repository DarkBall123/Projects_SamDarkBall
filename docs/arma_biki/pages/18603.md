## setPylonsPriority

- Source: https://community.bistudio.com/wiki/setPylonsPriority
- Revision: 310928
- Updated: 2022-05-07T20:51:11Z

- Availability: arma3 1.70
- Groups: Vehicle Loadouts

### Description

Overrides default pylons priorities.

### Syntax

```sqf
vehicle setPylonsPriority priorities
```

### Parameters

- vehicle: Object
- priorities: Array of Numbers

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
(vehicle player) setPylonsPriority [0,1,2,3,4,5,5,4,3,2,1,0];
```
