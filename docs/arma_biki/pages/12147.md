## clearItemCargoGlobal

- Source: https://community.bistudio.com/wiki/clearItemCargoGlobal
- Revision: 309899
- Updated: 2022-05-05T12:16:44Z

- Availability: arma3 0.50
- Locality: argument global, effect global
- Groups: Containers

### Description

Removes all items from ammo box (or any general weapon holder container). It also removes vests and uniforms.

### Syntax

```sqf
clearItemCargoGlobal box
```

### Parameters

- box: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
clearItemCargoGlobal _ammoBox;
```
