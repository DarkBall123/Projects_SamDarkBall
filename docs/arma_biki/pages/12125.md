## addHandgunItem

- Source: https://community.bistudio.com/wiki/addHandgunItem
- Revision: 320941
- Updated: 2022-05-13T10:04:43Z

- Availability: arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Inventory

### Description

Adds weapon item, including magazine, directly to the handgunWeapon. This is used for infantry weapons.

### Syntax

```sqf
unit addHandgunItem item
```

### Parameters

- unit: Object
- item: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addHandgunItem "muzzle_snds_L";
```
