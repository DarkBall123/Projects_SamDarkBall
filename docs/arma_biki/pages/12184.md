## load

- Source: https://community.bistudio.com/wiki/load
- Revision: 347534
- Updated: 2023-09-28T08:15:16Z

- Availability: arma3 0.50
- Groups: Unit Inventory

### Description

Returns the percentage of fullness of a unit's cargo. Output is usually in range 0..1, but can be higher after using certain scripting commands (like addWeaponWithAttachmentsCargoGlobal) which ignore load values when adding items.
See #Example 2 for load calculation.

### Syntax

```sqf
load unit
```

### Parameters

- unit: Object - (before 2.08 the command did not support containers, ammo boxes, weapon holders, vehicle cargos)

### Return Value

- Number

### Examples

#### Example 1

```sqf
load player;
```

#### Example 2

unit load calculation formula:

```sqf
private _unitLoad = loadAbs _unit / getNumber (configFile >> "CfgInventoryGlobalVariable" >> "maxSoldierLoad");
```
