## useAIOperMapObstructionTest

- Source: https://community.bistudio.com/wiki/useAIOperMapObstructionTest
- Revision: 310172
- Updated: 2022-05-05T13:10:25Z

- Availability: arma3 1.64
- Groups: System

### Description

Toggle secondary obstruction test on road paths.

### Syntax

```sqf
useAIOperMapObstructionTest state
```

### Parameters

- state: Boolean - true to enable, false to disable

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
useAIOperMapObstructionTest true;
```
