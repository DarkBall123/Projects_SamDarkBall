## ctrlFade

- Source: https://community.bistudio.com/wiki/ctrlFade
- Revision: 363799
- Updated: 2024-04-21T13:19:40Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Returns the current fade factor of control.

{{ Feature | Informative | Despite having 

```
fade = 1;
```

 inside a control's config, 

```sqf
ctrlFade
```

 will **still report a fade of 0**.

Only the value actually set by ctrlSetFade will be returned by ctrlFade.}}

### Syntax

```sqf
ctrlFade controlName
```

### Parameters

- controlName: Control

### Return Value

- Number

### Examples

#### Example 1

```sqf
_fade = ctrlFade _control;
```
