## uniformItems

- Source: https://community.bistudio.com/wiki/uniformItems
- Revision: 377118
- Updated: 2026-01-01T10:13:43Z

- Availability: arma3 0.50
- Groups: Unit Inventory

### Description

Get array with all items (of any kind, even weapons) from uniform.

### Syntax

```sqf
uniformItems unit
```

### Parameters

- unit: Object

### Return Value

- Array of Strings - Class names of items

### Examples

#### Example 1

```sqf
uniformItems player;
// returns e.g
/*
[
	"FirstAidKit",
	"30Rnd_65x39_caseless_mag",
	"30Rnd_65x39_caseless_mag",
	"30Rnd_65x39_caseless_mag"
]
*/
```
