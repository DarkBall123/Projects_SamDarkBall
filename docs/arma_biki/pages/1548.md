## getDir

- Source: https://community.bistudio.com/wiki/getDir
- Revision: 364132
- Updated: 2024-05-04T22:14:16Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Returns the object heading in the range 0..360.
The alternative syntax gets heading from one object or position to another object or position, and should be used instead of BIS_fnc_dirTo.

### Syntax

```sqf
getDir object
```

```sqf
pos1 getDir pos2
```

### Parameters

- object: Object
- pos1: Object, Position2D or Position3D - from where
- pos2: Object, Position2D or Position3D - to where

### Return Value

- Number
- Number

### Examples

#### Example 1

```sqf
_azimuth = getDir player;
```

#### Example 2

```sqf
_azimuth = player getDir tank;
```

{{Note
|user= AgentRev01
|timestamp= 20131023103100
|text= Be careful when using this command in conjunction with BIS_fnc_rotateVector2D, which rotates vectors counterclockwise as per trigonometric conventions, while getDir returns a clockwise angle.

To counter this, simply negate the output of getDir:

```sqf
[[0,1,0], -(getDir _object)] call BIS_fnc_rotateVector2D;
```
