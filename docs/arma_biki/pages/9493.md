## forceWalk

- Source: https://community.bistudio.com/wiki/forceWalk
- Revision: 310282
- Updated: 2022-05-05T13:11:25Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local
- Groups: Stamina System

### Description

Forces unit to walk even if run or sprint is selected.

### Syntax

```sqf
unit forceWalk value
```

### Parameters

- unit: Object - the unit forced to walk
- value: Boolean - true/false

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player forceWalk true;
```
