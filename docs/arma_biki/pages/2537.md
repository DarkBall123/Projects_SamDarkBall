## reloadEnabled

- Source: https://community.bistudio.com/wiki/reloadEnabled
- Revision: 370147
- Updated: 2024-11-02T13:33:13Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Weapons

### Description

A getter for enableReload. The value returned is wether or not auto-reload is enabled for current client only.

### Syntax

```sqf
reloadEnabled unitName
```

### Parameters

- unitName: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
private _aiCanReload = reloadEnabled _unit1;
```
