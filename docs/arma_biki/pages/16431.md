## BIS fnc playMusic

- Source: https://community.bistudio.com/wiki/BIS_fnc_playMusic
- Revision: 349204
- Updated: 2023-11-08T14:50:43Z

- Availability: arma3 1.00
- Groups: Sound

### Description

Plays given song.

### Syntax

```sqf
[class,start,volume] call BIS_fnc_playMusic
```

### Parameters

- class: String - classname of song
- start: Number - time of start in seconds - Default: 0
- volume: Number - music volume from 0 to 1 - Default: musicVolume

### Return Value

- Boolean - true

### Examples

#### Example 1

```sqf
["LeadTrack04_F", 10, 0.5] call BIS_fnc_playMusic; // song starts at 10 seconds with 50% volume.
```
