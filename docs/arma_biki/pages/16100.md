- Availability: arma3 1.00
- Groups: OO

### Description

Instantiates an object of a certain class.

### Syntax

```sqf
[class,params] call BIS_fnc_createObjectOO
```

### Parameters

- class: String - class for the OO scripting shell Class has to exist in CfgOO
- params: Array - (Optional, default 

```sqf
[]
```

) optional parameters for constructor

### Return Value

- Logic - created logic object

### Examples

#### Example 1

```sqf
["someOOClass", [1,2,3]] call BIS_fnc_createObjectOO;
```
