## BIS fnc dbIsValue

- Source: https://community.bistudio.com/wiki/BIS_fnc_dbIsValue
- Revision: 328377
- Updated: 2022-07-13T16:00:48Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Database

### Description

Checks if string is value definition.

### Syntax

```sqf
text call BIS_fnc_dbIsValue
```

### Parameters

- text - String: Check if text is in value format

### Return Value

- Boolean: true when the argument starts with "&" (value symbol returned with BIS_fnc_dbSymbolValue)

### Examples

#### Example 1

```sqf
"&MYVALUE" call BIS_fnc_dbIsValue; // true
"&myvalue" call BIS_fnc_dbIsValue; // true
"MYVALUE" call BIS_fnc_dbIsValue; // false
1234 call BIS_fnc_dbIsValue; // false
```
