## moveInDriver

- Source: https://community.bistudio.com/wiki/moveInDriver
- Revision: 363679
- Updated: 2024-04-16T14:31:18Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument local, effect global
- Groups: Unit Control

### Description

Moves soldier into vehicle driver position (immediate, no animation).
See AI Group Vehicle Management for more information.
{{Feature|important|If the unit is already in a vehicle, nothing will happen unless moveOut (since {{arma2}}) is used first to move the unit out of their vehicle (see #Example 2).}}

### Multiplayer

*unit* must be local, while the vehicle's locality does not matter.

### Syntax

```sqf
unit moveInDriver vehicle
```

### Parameters

- unit: Object
- vehicle: Object

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_soldierOne moveInDriver _tankOne;
```

#### Example 2

```sqf
if (not isNull vehicle player) then
{
	moveOut player;
};

player moveInDriver _myTruck;
```
