## kickPlayer

- Source: https://community.bistudio.com/wiki/kickPlayer
- Revision: 351584
- Updated: 2023-12-07T18:24:25Z

- Availability: argo 1.00
- Locality: argument global, server execution server
- Groups: Argo

### Description

Kick the player controlling the provided unit from the server.

### Syntax

```sqf
kickPlayer [unit, kickMessage]
```

### Parameters

- unit: Object - the player to kick
- kickMessage: String - (Optional) shown as disconnect message on the kicked client

### Return Value

- Boolean - true on success, false otherwise

### Examples

#### Example 1

```sqf
kickPlayer [_teamKiller, "We don't do that here."];
```

#### Example 2

```sqf
if (not isPlayerSupporter _dude) then
{
	kickPlayer [_dude, "Give money to BI or else!"];
};
```
