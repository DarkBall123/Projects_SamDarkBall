## BIS fnc ORBATAnimate

- Source: https://community.bistudio.com/wiki/BIS_fnc_ORBATAnimate
- Revision: 349429
- Updated: 2023-11-08T16:27:36Z

- Availability: arma3 1.00
- Groups: Strategic

### Description

Animates an ORBAT viewer.

### Syntax

```sqf
[target, zoom, duration] spawn BIS_fnc_ORBATAnimate
```

### Parameters

- target: Config or Array - path to group in CfgORBAT or offset position from structure center in format **[X, Y]**.
* When empty, view is reset to original level where whole structure is visible
- zoom: Number - zoom in range from 0 (max. zoom) to 1 (min. zoom)
- duration: Number - commit time in seconds

### Return Value

- Boolean - true when animation is applied

### Examples

#### Example 1

```sqf
[configFile >> "CfgORBAT" >> "BIS" >> "B_1_A_1", 0.5, 3] spawn BIS_fnc_ORBATAnimate;
```
