## setShotParents

- Source: https://community.bistudio.com/wiki/setShotParents
- Revision: 349182
- Updated: 2023-11-08T14:50:39Z

- Availability: arma3 1.66
- Locality: argument global, effect global, server execution server
- Groups: Weapons

### Description

Sets vehicle and instigator pair for the given projectile.

### Syntax

```sqf
projectile setShotParents [vehicle, instigator]
```

### Parameters

- projectile: Object - the actual projectile shot
- vehicle: Object - vehicle shooting projectile (appears as the 'killer' in "Killed" EH)
- instigator: Object - person pulling the trigger (appears as the 'instigator' in "Killed" EH)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myProjectile setShotParents [vehicle bob, bob];
```

#### Example 2

```sqf
tank addEventHandler ["Fired", {_this select 6 setShotParents [tank, commander tank]}];
```
