## backpackSpaceFor

- Source: https://community.bistudio.com/wiki/backpackSpaceFor
- Revision: 378506
- Updated: 2026-05-03T16:57:31Z

- Availability: arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Containers

### Description

Returns how much space is in backpack for given weapon or magazine

### Syntax

```sqf
backpack backpackSpaceFor weaponName
```

### Parameters

- backpack: Object
- weaponName: String

### Return Value

- Array with [weapons, magazines]
* weapons: Number
* magazines: Number

### Examples

#### Example 1

```sqf
(backpackContainer player) backpackSpaceFor "m16"; // [weapons, magazines]
```
