## itemCargo

- Source: https://community.bistudio.com/wiki/itemCargo
- Revision: 376929
- Updated: 2025-12-31T20:24:50Z

- Availability: arma3 0.50
- Locality: argument global
- Groups: Vehicle Inventory

### Description

Get array with items from ammo box (or any general weapon holder container).

### Syntax

```sqf
itemCargo object
```

### Parameters

- object: Object - vehicle or ammo box

### Return Value

- Array of Strings - ["ItemType1","ItemType2","ItemType3"...]

### Examples

#### Example 1

```sqf
hint str itemCargo vestContainer player;
```
