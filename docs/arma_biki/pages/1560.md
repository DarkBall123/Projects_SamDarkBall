## exit

- Source: https://community.bistudio.com/wiki/exit
- Revision: 329489
- Updated: 2022-07-29T12:29:43Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Program Flow

### Description

Stops the execution of a SQS script.

It is ignored in SQF Scripts.

### Syntax

```sqf
exit
```


### Return Value

- Nothing

### Examples

#### Example 1

SQS Syntax:
<sqs>? not alive player : exit</sqs>
