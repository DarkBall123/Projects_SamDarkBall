## missionVersion

- Source: https://community.bistudio.com/wiki/missionVersion
- Revision: 342111
- Updated: 2023-07-09T12:26:37Z

- Availability: arma3 1.56
- Groups: Mission Information

### Description

Returns the version of the current mission.
* Mission from the 2D Editor: 12
* Mission from the Eden Editor: 15 and higher (for example current version for Eden Editor mission in Arma 3 v1.57 is 51)

### Syntax

```sqf
missionVersion
```


### Return Value

- Number - SQM version

### Examples

#### Example 1

```sqf
_version = missionVersion;
```
