### Description

Continue sequence of for construct. It sets the end value of the index variable.

### Syntax

```sqf
forType to b
```

### Parameters

- forType: For Type
- b: Number

### Return Value

- For Type

### Examples

#### Example 1

```sqf
for "_i" from 10 to 20 do
{
	hint str _i; // will hint from 10 to 20, spaced by 1 second
	sleep 1;
};
```
