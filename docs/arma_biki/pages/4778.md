## camPrepareRelPos

- Source: https://community.bistudio.com/wiki/camPrepareRelPos
- Revision: 377385
- Updated: 2026-01-02T06:43:54Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Prepares the camera position relative to the current position of the currect target (see camPrepareTarget). Needs the call of camCommitPrepared to be conducted.

### Syntax

```sqf
camera camPrepareRelPos position
```

### Parameters

- camera: Object
- position: PositionRelative

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_camera camPrepareRelPos [10,5,-2];
```
