## triggerAttachObject

- Source: https://community.bistudio.com/wiki/triggerAttachObject
- Revision: 336715
- Updated: 2023-01-04T15:24:43Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Triggers

### Description

Assigns a static object to the trigger. The activation source is changed to "STATIC".

### Syntax

```sqf
triggerName triggerAttachObject objectId
```

### Parameters

- triggerName: Object
- objectId: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_trigger triggerAttachObject 1234;
```
