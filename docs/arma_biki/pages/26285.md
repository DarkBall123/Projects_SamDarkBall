## triggerInterval

- Source: https://community.bistudio.com/wiki/triggerInterval
- Revision: 349226
- Updated: 2023-11-08T14:50:51Z

- Availability: arma3 1.98
- Locality: argument global
- Groups: Triggers

### Description

Returns trigger condition check frequency in seconds. 

 

{{Feature | important | The trigger could be local or remote but the result returned by this command will be for the trigger interval set up locally on the client that executed the command. See createTrigger for more info.}}

### Syntax

```sqf
triggerInterval trigger
```

### Parameters

- trigger: Object - trigger object

### Return Value

- Number - trigger interval in seconds

### Examples

#### Example 1

```sqf
_interval = triggerInterval someTrigger;
```
