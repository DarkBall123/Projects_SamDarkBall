## isEngineOn

- Source: https://community.bistudio.com/wiki/isEngineOn
- Revision: 370470
- Updated: 2024-12-16T18:09:58Z

- Availability: ofp 1.90, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Returns true if engine is on, false if it is off.

### Syntax

```sqf
isEngineOn vehicle
```

### Parameters

- vehicle: Object

### Return Value

- Boolean

### Examples

#### Example 1

```sqf
_carEngineIsOn = isEngineOn _carOne;
```

Bind Engine action to User Action 1

```sqf
this addAction ["", 
{
	_this select 1 action 
	[
		["EngineOn", "EngineOff"] select isEngineOn (_this select 0), 
		_this select 0
	];
}, "", -10, false, true, "User1", "_this == driver _target"];
```
