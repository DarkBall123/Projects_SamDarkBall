## groupFromNetId

- Source: https://community.bistudio.com/wiki/groupFromNetId
- Revision: 364977
- Updated: 2024-07-04T17:39:28Z

- Availability: arma3 0.50, arma2oa 1.63
- Groups: Groups, Multiplayer

### Description

Get group from the provided unique ID. For objects, use objectFromNetId.

### Multiplayer

<nowiki/>
* In singleplayer: 2.18 works as described (returned grpNull before v2.18 - see BIS_fnc_groupFromNetId)
* In multiplayer: works as described

### Syntax

```sqf
groupFromNetId id
```

### Parameters

- id: String

### Return Value

- Group

### Examples

#### Example 1

```sqf
_group = groupFromNetId "4:45";
```
