## cameraView

- Source: https://community.bistudio.com/wiki/cameraView
- Revision: 378176
- Updated: 2026-03-03T19:06:53Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Camera Control

### Description

Returns mode of active camera view. Mode is one of: 
* "INTERNAL" (1st person)
* "EXTERNAL" (3rd person)
* "GUNNER" (optics / sights)
* "GROUP" (commander view)

### Syntax

```sqf
cameraView
```


### Return Value

- String

### Examples

#### Example 1

```sqf
if (cameraOn == _vehicle && cameraView == "EXTERNAL") then
{
	_vehicle switchCamera "INTERNAL";
};
```
