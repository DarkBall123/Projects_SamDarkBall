## removeCuratorEditableObjects

- Source: https://community.bistudio.com/wiki/removeCuratorEditableObjects
- Revision: 377069
- Updated: 2026-01-01T09:30:27Z

- Availability: arma3 1.16
- Locality: server execution server
- Groups: Curator

### Description

Unregister objects which can be edited by a curator.

### Syntax

```sqf
curatorObj removeCuratorEditableObjects [objects, removeCrew]
```

### Parameters

- curatorObj: Object - curator module
- objects: Array of Objects
- removeCrew: Boolean - (Optional, default true)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
curatorModule removeCuratorEditableObjects [[cursorTarget], true];
```
