## addGoggles

- Source: https://community.bistudio.com/wiki/addGoggles
- Revision: 318656
- Updated: 2022-05-13T09:21:15Z

- Availability: arma3 0.50
- Groups: Unit Inventory

### Description

Create a new item and try to link it into goggles (glasses) slot.
{{Feature | informative | This command does **not** add NVGs, which are hmd slot items (see linkItem instead).}}

### Syntax

```sqf
unit addGoggles type
```

### Parameters

- unit: Object
- type: String

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
player addGoggles "G_Tactical_Clear";
```

#### Example 2

```sqf
diver addGoggles "G_Diving";
```

### See Also

goggles removeGoggles
