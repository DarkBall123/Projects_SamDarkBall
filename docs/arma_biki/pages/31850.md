## ctrlForegroundColor

- Source: https://community.bistudio.com/wiki/ctrlForegroundColor
- Revision: 377364
- Updated: 2026-01-02T06:40:35Z

- Availability: arma3 2.06
- Groups: GUI Control

### Description

Returns control's foreground color.

### Syntax

```sqf
ctrlForegroundColor control
```

### Parameters

- control: Control

### Return Value

- Color (RGBA)

### Examples

#### Example 1

```sqf
ctrlForegroundColor _control;
```
