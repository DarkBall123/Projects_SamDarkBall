## ctrlSetTooltipColorBox

- Source: https://community.bistudio.com/wiki/ctrlSetTooltipColorBox
- Revision: 378388
- Updated: 2026-04-04T06:25:53Z

- Availability: arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control

### Description

Sets tooltip border color of given control.

### Syntax

```sqf
control ctrlSetTooltipColorBox  color
```

### Parameters

- control: Control
- color: Color (RGBA)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_control ctrlSetTooltipColorBox [1, 0, 0, 1];
```
