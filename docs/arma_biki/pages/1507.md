## handsHit

- Source: https://community.bistudio.com/wiki/handsHit
- Revision: 329502
- Updated: 2022-07-29T13:32:42Z

- Availability: ofp 1.00, ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Object Manipulation

### Description

Checks if a soldier's hands are hit, which results in inaccurate aiming.

### Syntax

```sqf
handsHit unitName
```

### Parameters

- unitName: Object

### Return Value

- Number - if the hands are not damaged, the returned value is 0. If the hands are hit or the unit is dead, the returned value is 1.

### Examples

#### Example 1

<sqs>? (handsHit player == 1) : player globalChat "Ouch! Don't shoot at my hands dammit!"</sqs>
