## vestContainer

- Source: https://community.bistudio.com/wiki/vestContainer
- Revision: 369325
- Updated: 2024-09-03T18:42:58Z

- Availability: arma3 1.04
- Groups: Containers, Unit Inventory

### Description

Returns a cargo container of a unit's vest.

### Syntax

```sqf
vestContainer unit
```

### Parameters

- unit: Object

### Return Value

- Object - cargo container or objNull if *unit* does not wear a vest

### Examples

#### Example 1

```sqf
hint str vestContainer player; // 2df7d600# 163942: dummyweapon.p3d
```

#### Example 2

```sqf
hint str getMagazineCargo vestContainer player;
/*
	returns e.g
	[
		[
			"30Rnd_65x39_caseless_mag",
			"16Rnd_9x21_Mag",
			"HandGrenade",

		],[
			2,
			2,
			2,
			3,
			1,

			2
		]
	]
*/
```
