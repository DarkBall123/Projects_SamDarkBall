## triggerText

- Source: https://community.bistudio.com/wiki/triggerText
- Revision: 319934
- Updated: 2022-05-13T09:25:45Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global
- Groups: Triggers

### Description

Returns trigger text.

### Multiplayer

The trigger could be local or remote but the result returned by this command will be for the trigger text set up locally on the client that executed the command. See createTrigger for more info.

### Syntax

```sqf
triggerText trigger
```

### Parameters

- trigger: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
_text = triggerText triggerName;
```
