## ctrlRemoveEventHandler

- Source: https://community.bistudio.com/wiki/ctrlRemoveEventHandler
- Revision: 329861
- Updated: 2022-08-07T23:04:48Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: GUI Control - Event Handlers, Event Handlers

### Description

Remove a given event handler from the given control.

### Syntax

```sqf
control ctrlRemoveEventHandler [type, id]
```

### Parameters

- control: Control
- type: String
- id: Number

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
_map ctrlRemoveEventHandler ["Draw", _id];
```
