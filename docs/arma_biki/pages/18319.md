## diag activeScripts

- Source: https://community.bistudio.com/wiki/diag_activeScripts
- Revision: 318940
- Updated: 2022-05-13T09:22:04Z

- Availability: arma3 1.64
- Groups: Diagnostic

### Description

Returns 4 element array with numbers of currently running scripts in format: [<nowiki/>spawn-ed, execVM-ed, exec-ed, execFSM-ed]

### Syntax

```sqf
diag_activeScripts
```


### Return Value

- Array

### Examples

#### Example 1

```sqf
hint str diag_activeScripts; //[0,0,0,1]
```
