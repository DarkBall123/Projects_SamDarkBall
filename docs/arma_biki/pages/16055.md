## BIS fnc executeStackedEventHandler

- Source: https://community.bistudio.com/wiki/BIS_fnc_executeStackedEventHandler
- Revision: 347967
- Updated: 2023-11-08T08:54:25Z

- Availability: arma3 1.00
- Groups: Event Handlers

### Description

This function executes the stacked items.
This function should not be called independently.

### Syntax

```sqf
[eventHandlerType] call BIS_fnc_executeStackedEventHandler
```

### Parameters

- eventHandlerType: String - the onXXX event handler

### Return Value

- Boolean - always true

### Examples

#### Example 1

```sqf
["onEachFrame"] call BIS_fnc_executeStackedEventHandler;
```
