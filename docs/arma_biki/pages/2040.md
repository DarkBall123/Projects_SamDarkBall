## setCameraEffect

- Source: https://community.bistudio.com/wiki/setCameraEffect
- Revision: 377585
- Updated: 2026-01-02T06:56:44Z

- Availability: ofpe 1.00, arma1 1.00, arma2 1.00, arma2oa 1.50, tkoh 1.00
- Groups: Camera Control

### Description

Applies an effect to the current camera of the player.

This command is not present in Arma 3.

### Syntax

```sqf
triggerOrWaypoint setCameraEffect [type, position]
```

### Parameters

- triggerOrWaypoint: Object or Waypoint
- type: String - effect type (a subclass of CfgCameraEffects.Array)

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
myTrigger setCameraEffect ["ZoomIn", "FRONT"];
```

#### Example 2

```sqf
_waypoint1 setCameraEffect ["FIXED", "RIGHT TOP"];
```
