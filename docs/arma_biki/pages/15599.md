## getPlayerUIDOld

- Source: https://community.bistudio.com/wiki/getPlayerUIDOld
- Revision: 353563
- Updated: 2024-03-19T12:01:43Z

- Availability: arma2oa 1.63
- Groups: Multiplayer

### Description

Returns the old UniqueID of Arma 2 OA of the given unit as string if it is player and empty value if it is AI. The uniqueID may be up to 100 characters long and may contain numbers, uppercase letters and underscores (the value can be used to construct a valid variable name by appending to another valid variable name).

{{Feature | important | While for {{GameCategory|arma2|link= y}} or {{arma2oa}} until version 1.60 the result always contains a number, it should be always handled as an opaque string. Converting it to a Number can cause precision problems, as it cannot accurately represent integers above 16777216 (2^24).
Moreover, game versions since {{arma2oa}} 1.61 provide a non-numeric value as a result.}}

Not present in Arma 3.

### Multiplayer

UID string is returned only in multiplayer.

### Syntax

```sqf
getPlayerUIDOld unit
```

### Parameters

- unit: Object

### Return Value

- String

### Examples

#### Example 1

```sqf
_uid = getPlayerUIDOld player;
```
