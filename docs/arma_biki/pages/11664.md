## setTrafficSpeed

- Source: https://community.bistudio.com/wiki/setTrafficSpeed
- Revision: 310009
- Updated: 2022-05-05T12:20:43Z

- Availability: tkoh 1.01, arma3 0.50
- Groups: Environment

### Description

Set ambient traffic speed in a rectangle (in kilometers per hour). This command does nothing in Arma 3.

### Syntax

```sqf
setTrafficSpeed [speed, xMin, xMax, zMin, zMax]
```

### Parameters

- speed: Number - traffic speed (in kilometers per hour)
- xMin: Number - western border of the affected rectangle
- xMax: Number - eastern border of the affected rectangle
- zMin: Number - southern border of the affected rectangle
- zMax: Number - northern border of the affected rectangle

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
setTrafficSpeed [50, _xMin, _xMax, _zMin, _zMax];
```
