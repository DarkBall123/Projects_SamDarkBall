## deleteResources

- Source: https://community.bistudio.com/wiki/deleteResources
- Revision: 321170
- Updated: 2022-05-13T15:14:30Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Locality: argument global, effect local
- Groups: Teams

### Description

Delete (unregister) resources of the team member. Resources are deleted in the order they were added. Case insensitive.

### Syntax

```sqf
teamMember deleteResources resources
```

### Parameters

- teamMember: Team Member
- resources: Array of Strings

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
teamMember _agent deleteResources ["Legs"];
```

resources addResources
