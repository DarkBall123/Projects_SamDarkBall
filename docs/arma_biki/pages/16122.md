## BIS fnc getUnitInsignia

- Source: https://community.bistudio.com/wiki/BIS_fnc_getUnitInsignia
- Revision: 328412
- Updated: 2022-07-13T16:00:50Z

- Availability: arma3 1.24
- Groups: Object Manipulation

### Description

Get a unit's uniform insignia class set with BIS_fnc_setUnitInsignia.

### Syntax

```sqf
[target] call BIS_fnc_getUnitInsignia
```

### Parameters

- target: Object - object from which to return its insignia's class

### Return Value

- String - insignia classname

### Examples

#### Example 1

```sqf
private _insigniaClass = [player] call BIS_fnc_getUnitInsignia
```
