## simulCloudDensity

- Source: https://community.bistudio.com/wiki/simulCloudDensity
- Revision: 365017
- Updated: 2024-07-10T18:22:01Z

- Availability: arma3 1.00
- Groups: Environment

### Description

Returns density of clouds at given position.

### Syntax

```sqf
simulCloudDensity pos
```

### Parameters

- pos: Position

### Return Value

- * Number - density (0-1)
* Nothing - If arguments are incorrect
* Boolean - Returns false if simulWeather is disabled

### Examples

#### Example 1

```sqf
simulCloudDensity getPos player;
```
