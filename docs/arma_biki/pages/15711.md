## BIS fnc showTime

- Source: https://community.bistudio.com/wiki/BIS_fnc_showTime
- Revision: 347907
- Updated: 2023-11-02T11:38:15Z

- Availability: arma2 1.00, arma2oa 1.50, tkoh 1.00, arma3 0.50
- Groups: Environment

### Description

Shows time gap between two dates.

### Syntax

```sqf
[startDate, endDate] spawn BIS_fnc_showTime
```

### Parameters

- startDate: Array in date format
- endDate: Array in date format

### Return Value

- Resource Layer

### Examples

#### Example 1

```sqf
private _dayStart = date;
_dayStart set [3, 0]; // set hours to 0
_dayStart set [4, 0]; // set minutes to 0
_now = date;
[_dayStart, _now] spawn BIS_fnc_showTime;
```
