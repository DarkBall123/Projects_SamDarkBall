## radioChannelSetLabel

- Source: https://community.bistudio.com/wiki/radioChannelSetLabel
- Revision: 319392
- Updated: 2022-05-13T09:24:00Z

- Availability: tkoh 1.00, arma3 0.50
- Groups: Radio and Chat, Custom Radio and Chat

### Description

Set the custom radio channel's label.

### Syntax

```sqf
customChannelID radioChannelSetLabel label
```

### Parameters

- customChannelID: Number - custom channel ID returned by radioChannelCreate command
- label: String - label

### Return Value

- Nothing

### Examples

#### Example 1

```sqf
5 radioChannelSetLabel "Q-dance Radio";
```
