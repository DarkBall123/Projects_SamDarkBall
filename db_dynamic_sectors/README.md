# Dynamic Sector Zones

Простой аддон для Arma 3, который:

- строит сетку секторов по всей карте;
- оставляет только клетки, где есть суша;
- считает присутствие `WEST`, `EAST` и `INDEPENDENT`;
- рисует локальные маркеры на карте для каждого клиента.

Логика цветов:

- пустой сектор: серый;
- сектор с одной стороной: сплошной цвет стороны;
- сектор с несколькими сторонами: базовый фон лидирующей стороны или боевой оранжевый при ничьей, поверх штриховки цветов активных сторон;
- `CIVILIAN` игнорируется.

Настройка через CBA Addon Options:

- `Grid Size Override` - принудительный размер клетки, `0` оставляет авто-подбор по размеру карты.
- `Update Interval` - интервал пересчета секторов на сервере.

Настройка через `missionNamespace` до старта цикла:

```sqf
missionNamespace setVariable ["DB_DS_gridSizeOverride", 700];
missionNamespace setVariable ["DB_DS_updateInterval", 3];
```

Переменные:

- `DB_DS_gridSizeOverride` - принудительный размер клетки в метрах.
- `DB_DS_updateInterval` - интервал пересчета состояния в секундах.
